# 毒藥 (Poison)

## ⚙️ 規則條文 (Rule Text)

| 類型 | 使用方式 |
| :--- | :--- |
| 接觸 | 塗於物件，直到洗去；裸露皮膚接觸時生效。 |
| 服用 | 必須吞下完整劑量；可加入食物或液體。 |
| 吸入 | 粉末或氣體影響 5 呎立方內生物並立刻消散；即使屏息仍有效。 |
| 損傷 | 以附贈動作塗於武器、彈藥或類似物件；造成揮砍或穿刺傷害時，經傷口生效。 |

### 提取毒藥

可從失能或死亡的有毒生物提取。花費 1d6 分鐘後，以製毒工具進行 DC 20 智力（自然）檢定；成功提取一劑且該生物不能再被提取。失敗時無所得，且若差距為 5 以上，提取者受該毒藥影響。
