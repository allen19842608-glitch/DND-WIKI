# 危害 (Hazards)

## ⚙️ 規則條文 (Rule Text)

- 除怪物外，冒險者也可能面臨燃燒、脫水、墜落、營養不良與窒息等環境危害。
- 本節僅建立危害分類；各危害的觸發、傷害、豁免與恢復方式依 Rules Glossary 的對應詞條處理。（來源：玩家手冊 2024；SRD 5.2.1 對照，p. 12）

### 《地下城主指南 2024》危害物

《地下城主指南 2024》將危害物依其對指定等級範圍的威脅標示為「妨礙」或「致命」。將危害用於低於標示範圍的角色時，原本的妨礙危害也可能致命。

| 危害物 | 預設危害度與等級 |
| :--- | :--- |
| 棕黴菌 | 致命（5–10 級）或妨礙（11–16 級） |
| 火球菇 | 致命（5–10 級） |
| 綠軟泥 | 妨礙（1–4 級） |
| 燎原烈火 | 致命（5–10 級）或妨礙（11–16 級） |
| 毒氣 | 妨礙（1–4 級） |
| 流沙陷坑 | 妨礙（1–4 級） |
| 刃藤 | 妨礙（1–4 級） |
| 冥河 | 妨礙（11–16 級） |
| 巖崩 | 致命（1–4 級） |
| 惡毒活藤 | 妨礙（1–4 級） |
| 蛛網 | 妨礙（1–4 級） |
| 黃黴菌 | 致命（1–4 級）或妨礙（5–10 級） |

各危害物的觸發、傷害、豁免、解除與高等級調整，依《地下城主指南 2024》第三章的對應實例處理。（來源：地下城主指南 2024，〈危害〉）

### 限制與例外

- 不應只因場景描述出現火焰、高處或缺水就直接套用結果；先確認角色是否實際滿足對應危害的觸發條件。
