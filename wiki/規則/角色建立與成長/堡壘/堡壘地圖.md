# 堡壘地圖 (Bastion Maps)

## ⚙️ 規則條文 (Rule Text)

### 設施空間

| 空間 | 最大面積 |
| :--- | :--- |
| 狹窄 | 4 個 5 呎方格 |
| 寬敞 | 16 個 5 呎方格 |
| 龐大 | 36 個 5 呎方格 |

- 設施可跨多個樓層配置。盥洗室、走廊、坡道、樓梯、門與窗均不另計費或增加設施面積。
- 防禦牆每個 5 呎方格需 **10 天**與 **250 GP**。完整包圍堡壘時，遭攻擊而決定衛兵損失所擲的骰子數減少 2。
- 合併堡壘不改變各角色設施數量、控制權或僱員歸屬；但任一角色可替另一座合併堡壘承擔衛兵損失。

### 基礎設施

- 可選：臥室、餐廳、客廳、庭院、廚房與儲藏室。基礎設施沒有直接遊戲效應，但可作為角色扮演與場景素材。

| 新增空間 | 價格 | 所需時間 |
| :--- | :--- | :--- |
| 狹窄 | 500 GP | 20 天 |
| 寬敞 | 1,000 GP | 45 天 |
| 龐大 | 3,000 GP | 125 天 |

| 擴大 | 價格 | 所需時間 |
| :--- | :--- | :--- |
| 狹窄至寬敞 | 500 GP | 25 天 |
| 寬敞至龐大 | 2,000 GP | 80 天 |
