# 堡壘事件 (Bastion Events)

## ⚙️ 規則條文 (Rule Text)

- 角色對整座堡壘下達維護指令時，DM 立刻擲一次事件；事件在下次堡壘回合前結算。合併的堡壘仍須各自擲骰並個別結算。

| d100 | 事件 |
| :--- | :--- |
| 01–50 | 一切順利 |
| 51–55 | 攻擊 |
| 56–58 | 罪犯僱員 |
| 59–63 | 機不可失 |
| 64–72 | 友好來訪者 |
| 73–76 | 客人 |
| 77–79 | 失去僱員 |
| 80–83 | 魔法發現 |
| 84–91 | 難民 |
| 92–98 | 請求援助 |
| 99–00 | 寶藏 |

- **攻擊**：擲 6d6；每顆骰出 1 時失去一名堡壘衛兵。若無衛兵，隨機一項特色設施關閉至下個回合後。
- **罪犯僱員／失去僱員**：未補位的設施在下一回合無法使用；後續會有新僱員接手。
- **機不可失**：可付 500 GP 換取一次重擲事件的機會；重複擲出本結果時重擲。
- **友好來訪者、客人、難民、請求援助與寶藏**：依事件敘述取得金錢、衛兵、物品或冒險鉤子；DM 與玩家共同補定細節。
- **魔法發現**：取得一件自行選擇的非普通藥劑或卷軸。

### 事件詳解

#### 一切順利 (All Is Well)

- 沒有重大規則後果。DM 可擲 d8 決定日常小事，例如修繕完成、僱員收養流浪狗、惡作劇或目擊鬼魂，並可自行增添細節。

#### 攻擊 (Attack)

- 敵對勢力的襲擊已被擊退。擲 **6d6**；每顆骰出 **1**，失去 1 名堡壘衛兵，並從名單移除。
- 若沒有堡壘衛兵，隨機一項特色設施受損並關閉至下次堡壘回合；之後免費修復。完整防禦牆、軍械庫與作戰指揮室可能改變此損失骰的處理。

#### 罪犯僱員 (Criminal Hireling)

- 一名僱員遭執法人員或賞金獵人追捕。可支付 **1d6 × 100 GP** 保住該僱員；否則他被捕。
- 若使某項設施沒有任何僱員，該設施下個堡壘回合不能使用；隨後免費補進新僱員。

#### 機不可失 (Extraordinary Opportunity)

- 與 DM 決定機會內容，例如承辦慶典、資助研究或安撫貴族。接受時支付 **500 GP**，DM 重新擲一次堡壘事件；再次擲出本事件時重擲。拒絕則沒有成本與後果。

#### 友好來訪者 (Friendly Visitors)

- 訪客借用一項特色設施，支付 **1d6 × 100 GP**。借用不妨礙該設施執行你已下達的指令。

#### 客人 (Guest)

| d4 | 結果 |
| :--- | :--- |
| 1 | 名流暫住 7 天，離開時給予推薦信。 |
| 2 | 避難者暫住 7 天，離開時贈與 **1d6 × 100 GP**。 |
| 3 | 傭兵成為額外堡壘衛兵，至死亡或被遣散前留在堡壘。 |
| 4 | 友好怪物暫住；若期間遭攻擊，牠保護堡壘，使你不損失衛兵，之後離開。 |

#### 失去僱員 (Lost Hirelings)

- 隨機一項特色設施失去全部僱員；該設施下個回合不能使用，之後免費補入新僱員。離職原因由玩家決定。

#### 魔法發現 (Magical Discovery)

- 僱員找到或意外創造一件免費的**非普通**魔法物品；你選擇一件藥劑或卷軸。

#### 難民 (Refugees)

- **2d4 名**難民尋求庇護。若無足夠基礎設施，他們在堡壘外紮營；其支付 **1d6 × 100 GP**。
- 他們留至你尋得新家，或敵對勢力襲擊堡壘。

#### 請求援助 (Request for Aid)

- 派出一名或更多衛兵；每名衛兵擲 **1d6**。總和 **10 以上**時問題解決並獲 **1d6 × 100 GP**；低於 10 時仍解決，但報酬減半且一名派出衛兵死亡。

#### 寶藏 (Treasure)

| d100 | 寶藏類別 |
| :--- | :--- |
| 01–40 | 25 GP 藝術品表 |
| 41–63 | 250 GP 藝術品表 |
| 64–73 | 750 GP 藝術品表 |
| 74–75 | 2,500 GP 藝術品表 |
| 76–90 | 自選普通魔法物品表：奧秘、武具、器具或聖物 |
| 91–98 | 自選非普通魔法物品表：奧秘、武具、器具或聖物 |
| 99–00 | 自選珍稀魔法物品表：奧秘、武具、器具或聖物 |

- 由 DM 與玩家決定寶藏來歷；角色不在堡壘時，物品留在儲藏室直到角色領取。

## 💡 實戰應用與裁量 (DM Ruling)

- 事件是可立即結算的規則結果，但特別適合延伸為冒險、交涉或僱員視角的劇情片段。
