# 生命值降至 0 (Dropping to 0 Hit Points)

## ⚙️ 規則條文 (Rule Text)



- 生物生命值降至 0 時會立即死亡或陷入昏迷；怪物通常立即死亡，但地下城主可讓重要怪物依角色規則處理。
- 生命值上限降至 0 時立即死亡。角色因傷害降至 0 且剩餘傷害等於或高於其生命值上限時，也立即死亡。
- 未立即死亡者陷入昏迷，並在生命值仍為 0 時於每回合開始進行死亡豁免檢定：擲 1d20，10 以上成功；累積三次成功則穩定，累積三次失敗則死亡。
- 死亡豁免擲出 1 算兩次失敗；擲出 20 則恢復 1 點生命值。生命值為 0 時受到傷害會增加一次失敗，若該傷害來自重擊則增加兩次；剩餘傷害等於或高於生命值上限時仍立即死亡。
- 可採取協助動作並成功通過 DC 10 感知（醫藥）檢定，使生命值為 0 的生物穩定。穩定者不再進行死亡豁免，但仍昏迷；受到傷害後失去穩定。（來源：玩家手冊 2024；SRD 5.2.1 對照，pp. 17–18）

### 限制與例外

- 三次成功與三次失敗不必連續；恢復任何生命值或變為穩定時，兩者都重置為 0。
- 臨時生命值不會讓生命值為 0 的生物恢復意識。
