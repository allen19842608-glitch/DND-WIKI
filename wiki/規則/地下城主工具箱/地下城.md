# 地下城

## ⚙️ 規則條文 (Rule Text)

**地下城 Dungeons**

有些地下城是被建造者遺棄的古老據點，還有一些是天然的洞穴或怪物鑿掘出的巢穴。地下城吸引著邪教、怪物群落和離群索居的生物。由於其起源和目的用途各不相同，地下城會具有一系列與眾不同的特質。例如，作為大地精士兵據點的地下城和蛇人居住的古代廟殿有著截然不同的氛圍和特徵。
你可以使用地下城奇聞表格為你正在創作的地下城，或是已經發布冒險中的地下城增添獨有的特徵。表中的奇聞反映了一個地下城的特點、它被建造出來的預期目的、它的位置，或是曾在該地下城中發生的某些（通常是災難性的）事件。你可以使用單獨的一條奇聞，或者根據自己的需要組合這些奇聞，通過投擲骰子和自主選擇其中或許能激發你靈感的一條奇聞。

**繪製地下城地圖 Mapping a Dungeon**
一個地下城的規模可以小到只是幾個房間，也可以大到是錯綜複雜的建築群，其中的通道能蔓延幾百尺長。冒險者的目標往往離地下城的入口越遠越好，這可以迫使角色們深入探查地下或是更進一步地探索建築的中心。
地下城通常繪製在網格圖紙上，圖紙上每個方格代表5尺乘5尺的區域。附錄 B 展示了幾個範例。如果你運行戰鬥的方式是在網格地圖上使用微縮模型，這樣的比例尺可以使你輕鬆地將地下城地圖轉變為戰鬥網格。

**繪圖原則 Mapping Principles**
在繪製或修改地下城地圖時，請牢記以下幾點。

**非對稱**。不對稱的房間和地圖佈局會讓地下城變得有趣而且更難揣測。
**立體佈局**。樓梯、坡道、升降臺、平臺、壁架、露臺、坑洞和其他高低變化可以使地下城變得有趣起來，並使得發生在這些區域的戰鬥遭遇變得具有挑戰性。
**多條途徑**。為整個地下城和各個房間添加多個入口和出口。提供多個可供選擇的路徑，這能給玩家帶來有意義的選擇。
**損毀和崩裂**。如果你想要展現由時間或其他因素造成的損毀，那便可以讓坍塌的通道隨處可見，以此將地下城原本相連的部分切斷。過去發生的地震可能會在地下城中造出裂隙，切割開房間，隔斷走廊，形成有趣的阻礙。
**自然特徵**。許多地下城會帶有自然特徵。可能會有地下溪流從據點中間穿過，造成房間形狀和大小的變化，並迫使人們建造出橋樑和排水溝等設施。
**秘密**。加上暗門和密室，獎勵花費時間尋找它們的玩家。對於每個密門和密室，請思考一下它們最初的用途：暗門是為了抵禦入侵者？還是地下城的居民們想對彼此保守自己的秘密？秘密可以幫助你展開地下城的故事。

**設計地下城房間 Designing Dungeon Rooms**
在設計地下城房間時，請牢記以下幾點。

**天花板支撐**。地下的洞室很容易坍塌，因此許多房間（尤其是大房間）都會採用拱形天花板或支柱來支撐頭頂岩石的重量。
**裝飾。**大多數有智慧的生物都會裝點它們的巢穴。雕塑、浮雕、壁畫、馬賽克等裝飾通常會出現在地下城的房間裡，同樣常見的還有潦草的塗鴉信息、痕跡，以及其他經過該地區的人們留下的路徑圖。這些標記有些只是塗鴉，而另一些則可能為仔細研究它們的冒險者提供有用的信息。
**出口。**不會開門的生物無法在封閉的房間內憑空建立巢穴，除非有人幫助它們這樣做。那些不會開門的強大生物會在必要時親手砸個門。穴居生物則可能會自己挖掘一個出口。

常見的地下城房間大致分為以下幾類。

**墓室 Crypts**
雖然墓室多數時候作為一個獨立的大號房間，被人看作一個“大寶庫”；但它也可以是一系列分開的房間，每個房間都放置單獨的石棺；又或者，是一個長長的大廳，兩側有凹室用於放置棺材或遺體。
一些墓室的建造者擔心亡靈從墳墓中復活，因此將墓室從外面上鎖並封死，使其易於進入但難以逃出。另一些人想防範盜墓賊，因此將自己的墓室設計得難以進入。還有的墓室既難以進入，又無法逃出——這叫安全起見。

**崗哨 Guard Posts**
**具有智慧和社會性的地下城居民通常會設置人手守衛公共區域的入口。崗哨可能只是一個帶有桌子的房間，裡面無聊的哨兵會在桌子上玩某種骰子游戲；或者，崗哨可能由一對鐵魔像組成，背後有隱藏在上方露臺的施法者支援。**
當你在設計崗哨時，要決定有多少守衛值班，記錄他們的被動察覺數值，然後決定他們發現入侵者時會怎麼做（見第四章“怪物行為”一節）。有些守衛會一頭扎進戰場，另外一些可能會嘗試談判、發出警報或是逃跑以呼叫支援。

**生活區 Living Quarters**
大多數生物都有一個自己的巢穴，他們可以在這裡休憩、進食和存放自己的財寶。居住區通常包括床或窩（如果生物需要睡眠），財物（包括貴重物品和普通物件），還有某種準備食物的區域（可能的形式包括一個設備齊全的廚房、一個簡陋的火坑、又或是一塊接近腐爛的肉）。

**天然地下區域 Natural Subterranean Areas**
人工建造的地下城往往會連接著天然形成的洞穴，與巖窟和隧道相交。這些區域是地下生物的家園，並包含有奇特的岩層、水池、黴菌、蘑菇和發光的苔蘚。

**聖祠 Shrines**
任何智慧生物都有可能會有專門用於祭祀敬拜的地方。取決於生物的可用資源和虔誠程度，這樣的聖祠可能狹小而簡陋，也可能寬敞而豪華。冒險者可能會在那裡遭遇到祭司，邪教徒或類似的生物；而怪物在受傷後可能會逃到聖祠尋求治療。

**寶庫 Vaults**
寶庫裡自然是有寶藏。寶庫通常用上鎖的門或密門保護著，很多寶庫會用上其他防禦手段，例如放置陷阱（見本章“陷阱”一節）、施加魔法防護、或是在內部佈置無需食水的怪物守衛寶庫。

**工作區 Work Areas**
智慧生物通常都會有實驗室、工坊、圖書館、鍛造間和工作室。由於這些區域內通常放置著貴重設備，工作區的門通常都是鎖著的，有時甚至會被守衛刻紋法術或類似的效果所保護著。

**地下城衰落 Dungeon Decay**
破敗程度表可以幫助你確定地下城的總體狀況。

**破敗程度 States of Ruin**

| **d6** | **特徵** |
| --- | --- |
| 1 | 危險。該區域損毀嚴重，容易坍塌。建築受到任何的撞擊和破壞，包括法術和其他區 域效應的影響時，都有50%的幾率引發坍塌。 |
| 2 | 塌陷。該地下城內的區域被碎石所塞滿，並有50%的幾率變為困難地形。半身掩護和可供隱匿的地方比比皆是。 |
| 3 | 無人打理。地下城中存在某一種危害物，例如棕黴菌、綠軟泥或黃黴菌（見本章“危 害”一節）。 |
| 4 | 廢棄。 地下城的大部分區域都已被荒廢。在這裡進行的敏捷（隱匿）檢定具有劣勢，因為任何聲響都會顯得不同尋常。 |
| 5 | 固若金湯。為破門、開鎖或類似活動所進行的技能檢定都具有劣勢。 |
| 6 | 人員熙攘。地下城人口稠密。任何大動靜都會引起附近生物的注意。 |
