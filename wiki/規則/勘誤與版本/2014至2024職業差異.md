# 2014 至 2024 職業差異

> [!NOTE]
> 本頁直接列出最會改變角色玩法的職業差異。職業或子職有同名版本時，使用 2024 條目；等級、資源與完整例外仍以職業頁為準。

## ⚙️ 共通結構變化

| 共通項目 | 2014                    | 2024                            |
| :--- | :---------------------- | :------------------------------ |
| 職業分支的機制名稱 | 以原初道途、神聖領域、祕術傳統等職業專屬名稱指稱選擇的分支。 | 選擇分支的職業特性統一標為「［職業］子職」；但道途、領域、誓言、學院等仍保留為該職業子職的名稱或敘事分類。 |
| 準備法術 | 多數職業為「職業等級 + 施法屬性調整值」。  | 多數職業改用隨職業等級成長的固定數量。             |
| 已知法術 | 學得的法術通常不能隨意調整。          | 許多職業以「始終準備」表述，升職業等級時可調整戲法或準備法術。 |
| 19 級 | 屬性值提升。                  | 可改選符合條件的專長或史詩恩賜。                |

## 🧙 職業核對表

| 職業 | 2014 | 2024 |
| :--- | :--- | :--- |
| [[職業/野蠻人\|野蠻人 (Barbarian)]] | 狂暴 1 分鐘；只能靠攻擊或受傷延長。9 級為殘酷重擊。 | 狂暴最長 10 分鐘；使生物作豁免或以附贈動作都可延長。取得武器精通；9 級以殘酷打擊取代殘酷重擊，可放棄魯莽攻擊優勢換傷害與附加效果。 |
| [[職業/吟遊詩人\|吟遊詩人 (Bard)]] | 激勵骰 10 分鐘內、擲骰前使用；專精在 3、10 級；安魂曲存在。 | 激勵骰 1 小時內、失敗後才用；專精移至 2、9 級；移除安魂曲。10 級祕法奧祕改能從吟遊、牧師、德魯伊、法師清單選擇並重訓。 |
| [[職業/牧師\|牧師 (Cleric)]] | 領域決定較多的武器／防具傾向；引導神力主要為不死生物驅散與領域選項。 | 1 級神聖秩序可選守護者或神秘學者；引導神力新增神聖火花。摧毀不死生物改為灼燒不死生物，7 級祝福打擊可自行選擇。 |
| [[職業/德魯伊\|德魯伊 (Druid)]] | 野性形態通常花動作，使用野獸自身生命值，且可保留種族特質。 | 野性形態改附贈動作、使用暫時生命值而非另一套生命值，初始僅知道 4 種形態；不再保留種族特質。1 級原初秩序另給施法或武裝方向。 |
| [[職業/戰士\|戰士 (Fighter)]] | 沒有武器精通；子職外的選擇較少。 | 1 級取得武器精通，戰鬥風格以專長呈現；基礎職業增加更多可調整的武器戰術選擇。 |
| [[職業/武僧\|武僧 (Monk)]] | 使用氣點；徒手與武僧武器的基礎節奏較受武藝限制。 | 氣點改稱專注點；武藝、附贈徒手打擊與疾風連擊的資源結構重寫，並增加更多恢復與攻擊選項。 |
| [[職業/聖騎士\|聖騎士 (Paladin)]] | 神聖打擊不是法術；兼職法術位半等級向下取整。 | 神聖打擊改為法術，並有每回合施展限制；聖騎士兼職法術位等級向上取整。 |
| [[職業/遊俠\|遊俠 (Ranger)]] | 獵人印記是可選法術，職業核心辨識度較低；兼職法術位向下取整。 | 獵人印記成為核心職業特性並獲得多次強化；取得武器精通；兼職法術位等級向上取整。 |
| [[職業/遊蕩者\|遊蕩者 (Rogue)]] | 偷襲只加傷害；高等級的反應與戰術選項較少。 | 偷襲可改用狡詐打擊施加不同附加效果；保留穩定瞄準，並有更明確的偷襲戰術選擇。 |
| [[職業/術士\|術士 (Sorcerer)]] | 先天術法與超魔法選項較少，術法點恢復主要依長休。 | 先天術法擴充，超魔法選項與法術清單重排，並提供更早或更多術法點調度。 |
| [[職業/契術師\|契術師 (Warlock)]] | 3 級選契約恩賜，與魔能祈喚分開。 | 契約恩賜改為可選魔能祈喚；祈喚數量與部分前置條件重排。 |
| [[職業/法師\|法師 (Wizard)]] | 秘法回復僅恢復法術位；法術書與學派特色依舊版編排。 | 秘法回復可在短休時調整一個準備法術，另恢復法術位；法術學派特性重新編排。 |
| [[職業/奇械師\|奇械師 (Artificer)]] | 《玩家手冊 2014》中的完整職業。 | 不收錄於《玩家手冊 2024》；但已由《艾伯倫：奇械鍛爐》提供適用 2024 的正式版本。 |

## 🧭 使用舊版子職

- 先確認 2024 是否已重印該子職；若已重印，使用新版。
- 未重印的 2014 子職必須檢查其是否在 1 或 2 級提供特性；套用至 2024 職業時，依相容規則調整其取得時機。
- 同名或功能重疊的特性不可重複取得；以 2024 基礎職業的文字決定保留哪一項選擇。
