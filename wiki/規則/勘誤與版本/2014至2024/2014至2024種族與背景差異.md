# 2014 至 2024 種族與背景差異

> [!NOTE]
> 本頁整理原始差異文章的比較結果。種族與背景的實際特性、法術與數值以各 2024 條目為準。

## 背景

《玩家手冊 2024》列出 16 個背景與 10 個種族；新增背景為農夫、守衛、嚮導、商人、抄書吏與流浪者，並新增通用手語。新增核心種族為阿斯莫、歌利亞與獸人。（來源：D&D Beyond，〈Updates in the Player’s Handbook (2024)〉，〈Origins〉）

| 項目 | 2014 | 2024 |
| :--- | :--- | :--- |
| 屬性值提升 | 通常來自種族。 | 由背景指定的 3 項屬性中，選擇一項 +2、另一項 +1，或三項各 +1。 |
| 專長 | 角色是否在 1 級取得專長取決於其他選項。 | 每個背景提供 1 項起源專長。 |
| 工具與語言 | 背景可提供工具與語言熟練。 | 背景提供 1 項工具熟練，不再提供語言熟練。 |
| 敘事機制 | 使用特質、理想、牽絆、缺點與背景特性。 | 不再提供上述固定欄位與背景特性；角色細節改由角色敘事處理。 |

## 種族共通變化

| 項目 | 2014 | 2024 |
| :--- | :--- | :--- |
| 用語與章節 | 使用「種族」，置於角色建立流程。 | 使用「種族」，並與背景同列於角色起源。 |
| 屬性值提升 | 含於種族／子種族。 | 移至背景；種族特質不再提供屬性值提升。 |
| 子種族 | 多以固定子種族提供分歧特質。 | 多改用血脈或譜系選項；選項的法術通常可選施法屬性，並能以法術位重施。 |

## 個別種族

| 種族 | 2014 或舊版基準 | 2024 |
| :--- | :--- | :--- |
| [[種族/阿斯莫\|阿斯莫 (Aasimar)]] | 不在《玩家手冊 2014》核心種族內；《多元宇宙的怪物》版本需在取得時固定天界揭示類型。 | 進入核心種族；每次天界揭示時可重選其變形類型。 |
| [[種族/龍裔\|龍裔 (Dragonborn)]] | 吐息武器的線形或錐形由祖先固定，傷害使用 d6；沒有通用黑暗視覺與飛行。 | 每次吐息時可選線形或錐形，傷害改為 d10；取得黑暗視覺，5 級起每日可飛行一次、持續 10 分鐘。 |
| [[種族/矮人\|矮人 (Dwarf)]] | 山丘／山地矮人分支；黑暗視覺 60 呎，武器熟練由子種族提供，石中通道感知是敘事性能力。 | 黑暗視覺 120 呎；所有矮人取得原山丘矮人的生命值增益；石中通道感知改為暫時震顫感知；不再有該些武器熟練與山丘／山地分支。 |
| [[種族/精靈\|精靈 (Elf)]] | 子種族提供各自特質與部分武器熟練。 | 新增妖精血統；敏銳感官改從 3 項技能擇一；以精靈血脈取代子種族，並在 3、5 級提供血脈法術；不再有武器熟練。卓爾不再有陽光敏感。 |
| [[種族/侏儒\|侏儒 (Gnome)]] | 森林／岩石侏儒各有固定子種族特質。 | 以侏儒血脈取代子種族；森林血脈可施展動物交談，岩石侏儒取得修復術與魔法伎倆的機械造物運用。 |
| [[種族/歌利亞\|歌利亞 (Goliath)]] | 不在《玩家手冊 2014》核心種族內；以石之耐力為代表性能力。 | 進入核心種族；巨人血脈取代單一石之耐力並提供選項；新增巨化形態；強健體格另使脫離擒抱具有優勢。 |
| [[種族/半身人\|半身人 (Halfling)]] | 輕足與強心兩種子種族。 | 不再區分兩者；所有半身人使用輕足半身人的敏捷方向。 |
| [[種族/人類\|人類 (Human)]] | 基本人類提供全屬性 +1；變體人類提供 1 級專長。 | 具備近似變體人類的專長取向；完成長休時獲得英雄激勵。背景已提供起源專長，因此 1 級專長不再是人類獨有優勢。 |
| [[種族/獸人\|獸人 (Orc)]] | 《玩家手冊 2014》使用半獸人；獸人不在核心玩家種族中。 | 獸人進入核心種族；黑暗視覺提升至 120 呎，且不再具有強健體格。 |
| [[種族/提夫林\|提夫林 (Tiefling)]] | 基本提夫林有固定的煉獄血脈法術組合；其他選項散見擴充書。 | 邪魔血脈整理為三種選擇，各自提供抗性與法術；可選施法屬性並以法術位重施；另取得奇術。 |
