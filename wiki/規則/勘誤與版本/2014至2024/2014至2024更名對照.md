# 2014 至 2024 更名對照

> [!NOTE] 閱讀方式
> 本頁整理官方更新清單明列的名稱變更。更名本身不代表規則機制完全相同；完整效果、等級與例外仍以對應的 2024 條目為準。為保持可與官方清單逐字比對，下表保留英文名稱。

## 子職名稱

| 職業 | 2014 子職名稱 | 2024 子職名稱 |
| :--- | :--- | :--- |
| 野蠻人 | Path of the Totem Warrior | Path of the Wild Heart |
| 武僧 | Way of Mercy | Warrior of Mercy |
| 武僧 | Way of Shadow | Warrior of Shadow |
| 武僧 | Way of the Four Elements | Warrior of the Elements |
| 武僧 | Way of the Open Hand | Warrior of the Open Hand |
| 術士 | Aberrant Mind | Aberrant Sorcery |
| 術士 | Clockwork Soul | Clockwork Sorcery |
| 術士 | Draconic Bloodline | Draconic Sorcery |
| 術士 | Wild Magic | Wild Magic Sorcery |
| 契術師 | The Archfey | Archfey Patron |
| 契術師 | The Celestial | Celestial Patron |
| 契術師 | The Fiend | Fiend Patron |
| 契術師 | The Great Old One | Great Old One Patron |
| 法師 | School of Abjuration | Abjurer |
| 法師 | School of Divination | Diviner |
| 法師 | School of Evocation | Evoker |
| 法師 | School of Illusion | Illusionist |

Way of Mercy、Aberrant Mind 與 Clockwork Soul 最初出自《塔莎的萬事坩堝》；The Celestial 最初出自《珊娜薩的萬事指南》。（來源：D&D Beyond，〈Updates in the Player’s Handbook (2024)〉，〈New Subclass Names〉）

## 法術更名

| 2014 法術 | 2024 法術 | 判定與 Wiki 落點 |
| :--- | :--- | :--- |
| Branding Smite | Shining Smite | 官方更新表列為更名。[[法術/2014/2環/印記斬\|印記斬 (Branding Smite，2014 Legacy)]] → [[法術/2環/閃耀斬\|閃耀斬 (Shining Smite)]] |
| Feeblemind | Befuddlement | 官方更新表列為更名。[[法術/2014/8環/弱智術\|弱智術 (Feeblemind，2014 Legacy)]] → [[法術/8環/摧心術\|摧心術 (Befuddlement)]] |
| Summon Draconic Spirit | Summon Dragon | 社群導讀列為更名；2024 版移除寶石龍選項，不能只因名稱關係視為機制相同。[[法術/2014/5環/龍類靈魄召喚術\|龍類靈魄召喚術 (Summon Draconic Spirit，2014 Legacy)]] → [[法術/5環/龍類召喚術\|龍類召喚術 (Summon Dragon)]] |

前兩項來源為 D&D Beyond 官方更新表；第三項來源為社群導讀，實際法術效果仍以兩個版本的個別法術頁為準。（來源：D&D Beyond，〈Updates in the Player’s Handbook (2024)〉，〈New Terminology〉；社群導讀，〈Spells〉／〈Summon Dragon〉）
