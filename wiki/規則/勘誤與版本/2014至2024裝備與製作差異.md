# 2014 至 2024 裝備與製作差異

> [!NOTE]
> 本頁只列遷移差異；物品的價格、傷害與完整特性以 2024 裝備條目為準。

## 裝備與武器

| 項目       | 2014                       | 2024                             |
| :------- | :------------------------- | :------------------------------- |
| 酸液、煉金火、油 | 通常作為沒有熟練加值的遠程攻擊使用。         | 可在攻擊動作中取代一次攻擊；目標作敏捷豁免。           |
| 蒺藜       | 命中或觸發後以舊版速度懲罰處理。           | 豁免失敗者的速度降為 0，直到其下一回合開始。          |
| 網        | 以遠程武器攻擊處理，且有不利的近戰使用限制。     | 可在攻擊動作中取代一次攻擊，目標作敏捷豁免。           |
| 治療藥水     | 自己飲用需動作；餵給他人的動作經濟沒有明確核心規則。 | 自己飲用或餵給盟友皆為附贈動作。                 |
| 槍械       | 不在《玩家手冊 2014》的基本裝備表。       | 手槍與火槍列為軍用遠程武器；仍受裝填特性限制。          |
| 重型特性     | 依生物體型限制。                   | 近戰武器要求力量 13，遠程武器要求敏捷 13；不再以體型判定。 |
| 長矛       | 傷害為 1d12。                  | 傷害為 1d10。                        |
| 三叉戟      | 傷害為 1d6／1d8。               | 傷害為 1d8／1d10。                    |
| 戰錘       | 沒有雙手使用時的額外傷害骰。             | 取得雙用（1d10）特性。                    |
| 雙武器戰鬥    | 規則主要由戰鬥章節處理，限近戰輕型武器。       | 主要由輕型武器特性處理，不限近戰武器；可搭配手弩。        |
| 武器精通     | 無。                         | 新增武器精通；特定職業以此取得武器的額外戰術效果。        |

## 製作

| 項目 | 2014 | 2024 |
| :--- | :--- | :--- |
| 一般物品製作 | 《玩家手冊》沒有完整、通用的玩家製作流程。 | 花費物品售價一半的材料；每 10 GP 售價需 1 天。 |
| 治療藥水 | 依舊版休整期或主持人規則處理。 | 固定為 1 天完成的例外。 |
| 法術卷軸 | 可以製作，但玩家手冊中的時間與成本說明不完整。 | 提供依環位區分的製作成本與時間表。 |
