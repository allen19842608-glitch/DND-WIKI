# 2014 至 2024 專長差異

> [!NOTE]
> 專長的完整先決條件、屬性值提升與例外以各 2024 專長頁為準。本頁只列原始差異文章指明的跨版本改動。

## 分類與取得時機

| 項目 | 2014 | 2024 |
| :--- | :--- | :--- |
| 分類 | 專長大多為同一類的可選規則。 | 分為起源、通用、戰鬥風格與史詩恩賜。 |
| 1 級專長 | 取決於種族、變體規則或主持人允許。 | 背景固定提供 1 項起源專長。 |
| 通用專長 | 數值提升與專長通常互為選擇。 | 除屬性值提升外，多數通用專長同時提供一項 +1 屬性值提升，且通常要求 4 級。 |
| 史詩恩賜 | 屬於《地下城主指南》的高等級可選獎勵。 | 成為 19 級可選專長類型，並通常提供 +1 屬性值提升，最高可達 30。 |

| 專長 | 2014 | 2024 |
| :--- | :--- | :--- |
| [[專長/起源專長/警覺\|警覺 (Alert)]] | 先攻固定 +5。 | 先攻改加熟練加值，且可與自願盟友交換先攻。 |
| [[專長/起源專長/治療師\|治療師 (Healer)]] | 使用治療包以舊版固定治療公式與每目標限制處理。 | 治療時讓目標花費生命骰，且治療骰可重擲 1。 |
| [[專長/起源專長/幸運\|幸運 (Lucky)]] | 幸運點用於重擲。 | 幸運點數等於熟練加值；改為給自己優勢或令對你的攻擊具劣勢。 |
| [[專長/起源專長/魔法學徒\|魔法學徒 (Magic Initiate)]] | 從一種職業清單學習；一環法術通常每日一次。 | 限牧師、德魯伊、法師清單；可用法術位重施、升級時重選法術，且可複選。 |
| [[專長/起源專長/野蠻攻擊者\|野蠻攻擊者 (Savage Attacker)]] | 只適用近戰武器攻擊。 | 也適用遠程武器攻擊。 |
| [[專長/起源專長/技巧嫻熟\|技巧嫻熟 (Skilled)]] | 通常不可重複選擇。 | 可複選。 |
| [[專長/起源專長/酒館拳王\|酒館拳王 (Tavern Brawler)]] | 提供屬性值提升，且以舊版徒手／即興武器規則運作。 | 不提供屬性值提升；可重擲徒手傷害骰的 1，且每回合一次可在徒手打擊時同時造成傷害與推撞。 |
| [[專長/起源專長/匠師\|匠師 (Crafter)]]、[[專長/起源專長/音樂家\|音樂家 (Musician)]] | 沒有對應的核心專長。 | 新增起源專長。 |

| :--- | :--- | :--- |
| [[專長/通用專長/運動健將\|運動健將 (Athlete)]] | 著重起身與跳躍。 | 取得攀爬速度。 |
| [[專長/通用專長/衝鋒手\|衝鋒手 (Charger)]] | 以衝刺後的近戰攻擊為核心。 | 衝刺增加 10 呎移動，直線移動 10 呎後每回合可加傷害或推開目標。 |
| [[專長/通用專長/強弩專家\|強弩專家 (Crossbow Expert)]] | 手弩附贈動作攻擊是核心收益。 | 裝填不再要求空手；移除手弩附贈動作攻擊，改與輕型武器的雙武器機制互動。 |
| [[專長/通用專長/雙持客\|雙持客 (Dual Wielder)]] | 提高可雙持的武器範圍。 | 提供獨立於輕型武器特性的附贈動作攻擊。 |
| [[專長/通用專長/摔角手\|摔角手 (Grappler)]] | 擒抱後的限制與優勢依舊版擒抱規則。 | 每回合一次徒手命中可同時造成傷害與擒抱；對自己擒抱的目標攻擊具優勢，且可更有效率移動被擒抱者。 |
| [[專長/通用專長/巨武器大師\|巨武器大師 (Great Weapon Master)]] | 可承受 −5 命中換取 +10 傷害。 | 移除該交換；傷害加值改為熟練加值，並限你的攻擊動作。 |
| [[專長/通用專長/重甲大師\|重甲大師 (Heavy Armor Master)]] | 固定減少 3 點非魔法鈍擊、穿刺、揮砍傷害。 | 傷害減免為熟練加值，且不再以魔法武器排除。 |
| [[專長/通用專長/法師殺手\|法師殺手 (Mage Slayer)]] | 對施法者有反應攻擊與豁免優勢。 | 移除反應攻擊；每短休或長休一次可自動成功智力、感知或魅力豁免。 |
| [[專長/通用專長/長柄大師\|長柄大師 (Polearm Master)]] | 敵人進入觸及範圍時的攻擊是借機攻擊。 | 該攻擊明定不是借機攻擊。 |
| [[專長/通用專長/神射手\|神射手 (Sharpshooter)]] | 可承受 −5 命中換取 +10 傷害。 | 移除該交換；可在敵人 5 呎內進行遠程攻擊而不具劣勢。 |
| [[專長/通用專長/盾牌大師\|盾牌大師 (Shield Master)]] | 盾擊需要附贈動作。 | 盾擊不再花費附贈動作。 |
| [[專長/通用專長/迅捷\|迅捷 (Speedy)]] | 對應舊版機動，近戰攻擊後可免於借機攻擊。 | 取代機動；不再要求近戰攻擊，但只令借機攻擊具劣勢。 |
| [[專長/通用專長/法術射手\|法術射手 (Spell Sniper)]] | 提供戲法並使射程加倍。 | 不再提供戲法；可在敵人 5 呎內作遠程法術攻擊，額外射程改為 +60 呎。 |

## 戰鬥風格與史詩恩賜

- 戰鬥風格在 2024 以專長形式呈現，且必須先具有「戰鬥風格」特性；巨武戰鬥將擲出的 1 或 2 視為 3，守護則令受保護者直到你下回合開始前承受的所有攻擊具有劣勢。
- 史詩恩賜中，傑出戰技改為每回合一次自動命中；命運恩賜從 1d10 改為擲出 D20 後使用的 2d4；次元旅行恩賜改為在採取魔法動作時傳送；能量抗性恩賜為新增項目。
- 原始文章列出的未重印 2014 恩賜為：高等魔法、永生、無敵、火焰之魂、完美健康、位面旅行、快速施法、暴風之裔、無拘無束與無法偵測。2024 並未給出它們的相容處理。
