# 2014 至 2024 遊戲與角色差異

> [!NOTE]
> 本頁直接列出可影響遊戲操作的差異。右欄是 2024 主規則；遇到例外時，仍以連結條目為準。

## ⚙️ 規則編排與術語

| 主題     | 2014           | 2024                          | 官方核對落點                             |
| :----- | :------------- | :---------------------------- | :--------------------------------- |
| 規則編排   | 共通規則分散在各章。     | 技術定義大量集中於術語匯編；查到關鍵術語時應再看彙編定義。 | [[規則/規則索引\|規則索引]]                  |
| D20 檢定 | 三類擲骰分別說明。      | 「D20 檢定」明確統稱屬性檢定、攻擊檢定與豁免檢定。   | [[規則/核心檢定/D20檢定\|D20 檢定]]          |
| 英雄激勵   | 重擲前使用，且只限 D20。 | 擲骰後立即使用，可重擲任意骰。               | 《玩家手冊 2024》「進行遊戲」                  |
| 魔法動作   | 不一定有統一的動作標記。   | 以「魔法動作」明示魔法性質，因此會受反魔法等效果影響。   | [[規則/動作與戰鬥/動作附贈動作與反應\|動作、附贈動作與反應]] |

## ⚔️ 戰鬥與動作

| 主題 | 2014 | 2024 |
| :--- | :--- | :--- |
| 抽出／收起武器 | 武器互動通常另占一次免費物件互動。 | 攻擊動作的每次攻擊可抽出或收起一把武器，且不必是該次攻擊所用的武器。 |
| 固定傷害 | 傷害調整值的適用常以個別規則判讀。 | 未擲骰的固定傷害，除非條文明示，**不加**屬性調整值。 |
| 多目標傷害 | 同時傷害多個目標時，通常只擲一次傷害骰。 | 以效應與法術文字為準；要求豁免的同一傷害效應擲一次，但不能把舊版「同時命中」規則自動套到每一種法術。 |
| 借機攻擊 | 針對離開威脅範圍的敵對生物。 | 可對你看得見、離開觸及範圍的生物進行；因此也可能對盟友使用反應法術。 |
| 穿越盟友空間 | 視為困難地形。 | 可自由穿越盟友空間。 |
| 突襲 | 被突襲者首回合不能移動、不能動作或反應。 | 被突襲者的先攻檢定具有劣勢；不再整個首回合失去行動。 |
| 雙武器戰鬥 | 限近戰輕型武器。 | 由「輕型」武器特性處理，不限近戰武器。 |
| 徒手打擊：擒抱／推撞 | 以力量（運動）對抗力量（運動）或敏捷（特技）。 | 擒抱或推撞是徒手打擊的選項；目標作力量或敏捷豁免，且一手一次只能維持一個擒抱。 |
| 開鎖 | 使用盜賊工具的敏捷檢定。 | 鎖明載為 DC 15 敏捷（巧手）檢定，並使用盜賊工具。 |

## ❤️ 休息、傷害與恢復

| 主題 | 2014 | 2024 |
| :--- | :--- | :--- |
| 短休與長休起始 | 沒有明定最低生命值。 | 必須至少有 1 點生命值才能開始。 |
| 長休恢復生命骰 | 恢復最多一半已消耗的生命骰。 | 恢復所有已消耗的生命骰。 |
| 長休中斷 | 中斷規則較簡略。 | 中斷後可續休，但每次列舉的中斷都會增加 1 小時休息時間。 |
| 穩定的 0 HP 生物 | 穩定後仍需另行處理甦醒。 | 於 1d4 小時後以 1 點生命值甦醒，之後才能開始休息。 |

詳見 [[規則/生命值與休息/短休|短休 (Short Rest)]]、[[規則/生命值與休息/長休|長休 (Long Rest)]]、[[規則/生命值與休息/生命值降至0|生命值降至 0]]。

## 🧭 角色建立、起源與兼職

| 主題 | 2014 | 2024 |
| :--- | :--- | :--- |
| 建立順序 | 通常先選種族，再選職業與背景。 | 第 1 步選職業；第 2 步選起源（背景與種族）；第 3 步決定屬性值。 |
| 背景機制 | 提供技能、特性、裝備與敘事欄位；屬性值提升通常來自種族。 | 提供屬性值提升與 1 項起源專長；種族不再提供屬性值提升。 |
| 角色紙敘事欄 | 特質、理想、牽絆、缺點是固定欄位。 | 移除上述固定機制欄位，改以角色細節承載。 |
| 兼職施法位 | 聖騎士、遊俠等級除以 2 後向下取整。 | 聖騎士、遊俠等級除以 2 後向上取整。 |
| 19 級 | 取得屬性值提升。 | 可選屬性值提升、其他符合條件的專長或史詩恩賜。 |

詳見 [[規則/角色建立與成長/創建角色|創建角色 (Create Your Character)]]、[[規則/角色建立與成長/起源構成部分|起源構成部分 (Parts of an Origin)]]、[[規則/角色建立與成長/兼職|兼職 (Multiclassing)]]。

## 🌱 背景、種族與專長

| 主題 | 2014 | 2024 |
| :--- | :--- | :--- |
| 種族架構 | 多數種族另有子種族，並含屬性值提升。 | 以血脈／譜系選項取代許多子種族結構，屬性值提升移至背景；歌利亞與獸人進入核心種族。 |
| 專長分類 | 大多只有「專長」與可選規則的概念。 | 明分為起源、通用、戰鬥風格、史詩恩賜；背景在 1 級直接提供起源專長。 |
| 舊背景／種族 | 直接使用原書內容。 | 舊背景改選 3 個屬性中一項 +2、另一項 +1，並選 1 項起源專長；舊種族忽略其屬性值提升，其餘照用。 |

參照 [[背景/背景索引|背景索引 (Background Index)]]、[[種族/種族索引|種族索引 (Species Index)]]、[[專長/專長索引|專長索引 (Feat Index)]]。

## 🛡️ 裝備與製作

| 主題         | 2014                 | 2024                                       |
| :--------- | :------------------- | :----------------------------------------- |
| 武器         | 沒有武器精通。              | 部分職業取得武器精通，武器特性直接改變攻擊動作的運用。                |
| 治療藥水       | 飲用通常花費動作；餵給他人的程序不明確。 | 自己飲用或餵給盟友皆為附贈動作。                           |
| 酸液、煉金火、油、網 | 常以獨立的遠程攻擊處理。         | 可在攻擊動作中取代一次攻擊，目標作敏捷豁免。                     |
| 製作         | 玩家手冊中休整期製作規則不完整。     | 一般物品花費售價一半材料，且每 10 GP 售價需 1 天；治療藥水例外為 1 天。 |

詳見 [[規則/裝備與物件/裝備與物件索引|裝備與物件索引 (Equipment and Objects Index)]]。
