# 17-20級 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

| d100 | 遭遇 |
| :--- | :--- |
| 01–02 | 2d10的**還魂鬼 revenant** |
| 03–04 | 2d8 隻**巨魔 troll** |
| 05–06 | 2d10的**熊人 werebear** |
| 07–08 | 1 個**霜巨人 frost giant** |
| 09–10 | 2d4 隻**青年百足魔獸 young remorhaz** |
| 11–20 | 1d4的**霜巨人 frost giant** |
| 21–25 | 佔據地面上一小片圓形區域的黑色的冰。這塊冰附近的氣溫比其他地方要高一些，檢查黑冰的角色會看到凍結在裡面的小塊機械。 |
| 26–35 | 1 隻**遠古白龍 ancient white dragon** |
| 36–40 | 一具凍在冰面下六呎的冒險者的屍體；屍體有50%的幾率攜帶著一件由 DM 選擇的稀有魔法物品 |
| 41–50 | 1d3 隻**巨惡雪怪 abominable yeti** |
| 51–60 | 1d4 隻**百足魔獸 remorhaz** |
| 61–65 | 一堵高500 呎，厚300 呎，長1d4裡的冰牆 |
| 66–75 | 1d4 隻**鵬鳥 roc** |
| 76–80 | 一個面容嚴厲，長髮飛舞的女人的肖像，刻在一座山的巖壁上 |
| 81–90 | 1d10的**霜巨人 frost giant**和2d4 隻**白熊 polar bear** |
| 91–96 | 1d3 隻**成年白龍 adult white dragon** |
| 97–99 | 2d4 隻**巨惡雪怪 abominable yeti** |
| 00 | 1 隻**遠古白龍 ancient white dragon**和1d3 隻**青年白龍 young white dragon** |
