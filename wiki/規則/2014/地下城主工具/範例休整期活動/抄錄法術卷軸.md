# 抄錄法術卷軸 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

只要有時間和耐心，一名施法者就可以將法術轉變為卷軸，從而創造法術卷軸。這個活動表現了生產卷軸所需要的時間和精力。

資源

抄寫魔法卷軸所需要的時間和金錢基於你希望抄錄的法術等級，如法術卷軸成本表所顯示。你必須同時提供法術所需要的任何材料成分。此外，你必須已經準備了這個法術，或者你想要抄錄的法術在你的已知法術中。你還必須擁有奧秘技能的熟練。

如果你抄錄一個戲法，卷軸將如1級施法者般工作。

表：法術卷軸成本

| 等級 | 成本 | 時間 |
| --- | --- | --- |
| 戲法 | 15 GP | 1天 |
| 一環 | 25 GP | 1天 |
| 二環 | 250 GP | 3天 |
| 三環 | 500 GP | 1工作周 |
| 四環 | 2,500 GP | 2工作周 |
| 五環 | 5,000 GP | 4工作周 |
| 六環 | 15,000 GP | 8工作周 |
| 七環 | 25,000 GP | 16工作周 |
| 八環 | 50,000 GP | 32工作周 |
| 九環 | 250,000 GP | 48工作周 |

難題

製作卷軸是一項孤獨的工作，一般不太可能引起人們的注意。難題的產生更有可能涉及到抄錄卷軸的準備工作。

角色進行製作卷軸的每個休整期都有10%的機會引發難題，製作卷軸難題如表中示例。

表：抄錄卷軸難題

| d6 | 難題 |
| --- | --- |
| 1 | 你買下了所有的稀有墨水用於製作卷軸，激怒了城鎮上的法師。 |
| 2\* | 一個善良的神殿祭司控告你參與了黑暗魔法的交易。 |
| 3 | 一名法師渴望收集在你法術書中的某項法術，並逼迫你向他售賣卷軸。 |
| 4 | 由於你在創造卷軸時犯下了一個奇怪的錯誤，一項同等級的隨機法術取代了卷軸法術。 |
| 5 | 你為抄錄卷軸購買的稀有羊皮紙上畫著一張幾乎不可見的地圖。 |
| 6\* | 有個小偷試圖闖入你的工作室。 |

\*可能涉及對手
