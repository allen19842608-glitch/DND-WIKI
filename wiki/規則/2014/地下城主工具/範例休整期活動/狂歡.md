# 狂歡 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

狂歡對於大部分角色而言是一個很好的預設休整期活動。在兩次冒險之間，誰不想和一打朋友在當地的酒吧中好好喝上幾杯放鬆一下？

資源

狂歡代表著用精美的食物、壯烈的飲酒和社交覆蓋這個工作周。一名角色可以試圖混入下層階級、中層階級或上層階級狂歡。與下層階級的狂歡需要花費10 GP，與中層階級則需要50 GP。與上層階級一同狂歡需要花費250 GP 每工作周，且必須有資格接觸上層階級。

擁有貴族背景的角色可以自然融入到上層階級當中，不過其他角色只有當你，作為 DM，判斷這個角色與貴族有足夠的來往時才能這麼做。或者，角色可以使用偽裝工具和欺騙技能 b 成來自遠方城市的貴族來訪。

決議

經過一工作周的狂歡，角色與選定的社會階層產生聯絡。這個角色參考**狂歡表**進行一次魅力（遊說）檢定。

表：狂歡

| 檢定值 | 結果 |
| --- | --- |
| 1-5 | 角色建立了一個敵對的聯絡 |
| 6-10 | 沒有任何結果 |
| 11-15 | 角色建立了一個友善的聯絡 |
| 16-20 | 角色建立了兩個友善的聯絡 |
| 21+ | 角色建立了三個友善的聯絡 |

聯絡人是與角色建立起紐帶的 NPC。他們當中的每一個都對角色懷有好感或者因為某種理由抱有怨恨。一個敵對的聯絡者與角色作對，設定障礙但並不付諸於犯罪或者暴力。友善的聯絡人對角色友好併為自願為他提供援助，不過也不會拼上他們的性命。

一個有害的聯絡人可能會把城鎮守衛引向角色的方向或者是在把城鎮推往某個事業時與角色們爭論。友善的聯絡人則站在角色的立場並儘可能為他們提供幫助。

下層階級的聯絡人包括犯罪分子、勞工、傭兵、城鎮守衛，以及其他任何經常光顧城鎮的廉價酒館的民眾。

中層階級的聯絡人包括公會成員、施法者、城鎮公務員，以及其他一些會光顧高檔社交設施的民眾。

上層階級的聯絡人包括貴族和他們的直系隨從。這種類型的狂歡包括正式的宴席、國宴等類似的場合。

一旦一名聯絡人幫助或者妨礙了角色，角色需要再次宴請這位 NPC 來維持他的好感。一名聯絡人往往只會提供一次幫助而非一生。聯絡人將會保有對角色的好感，這會影響角色扮演和如何與角色們進行互動，但並不保證提供幫助。

你可以指定特定的 NPC 作為聯絡人。你可能會指定在不幸的戈爾貢中的某個酒保和駐守在西城門的某個守衛是角色的友善聯絡人。分配具體的聯絡人會給予玩傢俱體的選擇。它會將生活帶入戰役並且使角色關心的 NPC 與這片區域的聯絡更為緊密。否則，他可能會顯得被難以記住並且可能會顯得很無用，如果聯絡人從未進入你的遊戲裡。

或者，你可以允許玩家現場選定某個特定的 NPC 成為聯絡人，在某次狂歡以後。當角色在他們曾舉行過狂歡的某片區域中時，玩家可以花費一個友善的聯絡，並且立即指定一個會面中的 NPC 作為聯絡人，只要這個 NPC 處於角色曾宴請的社會階級當中。玩家需要為這段友情提供一個合理的解釋，並將其表現在遊戲裡。

在遊戲中混合這兩種途徑是一個好主意，因為它即給予你了新增一名特定聯絡人的深度，同時也給了玩家們自由以確保他們積累的聯絡人是有用的。

相同的過程可以適用於一名敵對的聯絡人。你可以給予角色一名他們需要避開的特定 NPC，或者你也可能引入他們在一個不合時宜的或是戲劇性的場合。

一名角色在同一時間只能保有最多1+角色魅力調整值（至少為1）數量的、未特別指定的友善聯絡。特別的、被給予命名的聯絡人並不包含之內，只有那些可以隨時在現場被宣言使用為聯絡人的 NPC 被計入限制。

難題

狂歡中的角色可能被捲入酒吧鬥毆、積累了討厭的謠言、並在城鎮中建立了不良的聲譽。你可以骰**狂歡難題表**來創造一個難題，或者選擇其中一個你認為適合的，或者是自己設計。通常來說，在每個進行狂歡的工作周之後角色有10%的機率觸發難題是比較合適的。

| 7 | 裸奔穿越街道在眼下看起來是個好主意。 |
