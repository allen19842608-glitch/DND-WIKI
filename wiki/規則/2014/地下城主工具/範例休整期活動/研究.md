# 研究 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

有備則無患。研究活動允許一名角色深入鑽研有關怪物、地區、魔法物品或者其他主題的學識。

資源

研究需要1個工作周的工作時間和至少50 GP 的花費用於材料、行賄、送禮，以及其他開銷。通常，一名角色需要拜訪圖書館或者一名賢者從而開展研究。

決議

首先角色決定他想要研究的焦點——一個特定人物，地點或事件。經過一個工作周的研究，人物需要進行一次智力檢定，他投入用於研究的每超出50 GP 資金都可以使這次檢定得到+1加值（不包括起始的50 GP），最多+6。此外，角色可以透過拜訪一個藏書特別豐富的圖書館或者學識特別淵博的賢者來使這次檢定獲得優勢。參考研究表來確定人物學到多少學識。

表：研究

| 檢定值 | 結果 |
| --- | --- |
| 1-5 | 無效果 |
| 6-10 | 你學到一條有用的知識 |
| 11-20 | 你學到兩條有用的知識 |
| 21+ | 你學到三條有用的知識 |

每一條有用的知識都等同於對某個人物、地點、事件的真實陳述。例子包括一個生物的抗性知識，進入一個封閉的地下城所需要的密碼，一個高階法師通常會命令手下準備的法術，以及其他類似的事情。

對於某個怪物或 NPC，你可以直接揭示資料或個性等元素。對於一個地區，你可以揭示有關它的秘密，比如一個隱藏的入口，一個謎題的答案，或者是守護這片地區的生物性質。

你也可以透過研究釋出一條特別的資訊，尤其是如果你的玩家想要知道某件特定的事情。或者，你的玩家也可以記錄他的角色積累了幾條不特定的學識。在遊戲中的任何時間，玩家可以花費其中一條學識來立即知曉某個怪物、地點或人物等等，表現為角色的靈光一閃或是回憶起了這條資訊。

在同一時間，角色可以同時持有、未被花費完的不特定知識數量最多等於1+他的智力調整值（至少1條）。

難題

研究的最大危險是得知了虛假資訊。並非所有知識都是真實的。一個有學術性的對手或許會誤導角色走進歧途，尤其是在他自己已經知道了這個知識的時候。對手可能散佈虛假資訊，賄賂賢者給予錯誤的提議，或者是偷走找到真相所必須的關鍵卷冊。

此外，角色也有可能在研究過程中遇上其他難題。如果你想要引入一個難題，參考研究難題表或是自己設計一個。

表：研究難題

| d6 | 難題 |
| --- | --- |
| 1 | 你不小心損壞了一本珍貴的書。 |
| 2\* | 你冒犯了一位賢者，他要求你給他一件珍貴的禮物。 |
| 3 | 如果你事先知道這本書被詛咒了，你或許永遠不會開啟它。 |
| 4\* | 一個對於現實世界有奇怪理論的賢者糾纏著想要說服你。 |
| 5\* | 你的行為導致你被禁止進入圖書館，直到你做出賠償。 |
| 6 | 你發現了一條有用的知識，但必須承諾完成一件危險的任務作為回報。 |

\*可能涉及對手
