# 賭博 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

機會遊戲是賺錢的一種方式，不過也許是一種更好的方式去輸得一敗塗地。

資源

這項活動需要一名角色一個工作周的努力，加上角色所必須支付的至少100 GP，最多1,000 GP 的賭注。除非你裁定認為這場賭博足夠巨大以支援更大的賭注，否則不能超過這個上限。

決議

玩家必須進行一系列的檢定，基於與角色同時進行遊戲的對手質量來隨機決定 DC。賭博的一部分風險在於，你永遠也不知道誰最終坐在你對面的桌子上。

角色必須進行三次檢定：感知（洞悉）、魅力（欺瞞）和魅力（威嚇）。如果角色有合適的工具熟練，其可以取代對應的技能檢定。

檢定的 DC 為5+2d10，為每一次檢定單獨決定 DC。參考賭博結果表來決定角色做了什麼。

表：賭博結果

| 結果 | 價值 |
| --- | --- |
| 0成功 | 失去了所有作為賭注的錢，並且得到了與這個金額相等的債務。 |
| 1成功 | 失去了用於賭注的錢的一半。 |
| 2成功 | 贏了用於賭注的錢的一半。 |
| 3成功 | 贏了一倍的你用於賭注的錢。 |

難題

賭博往往描繪了各種負面角色。它的潛在難題往往涉及到了來自法律上的爭議，和與之聯絡的多種犯罪行為。

每次花在博上的休整期有10%的機率引發難題，相關的例子在賭博難題表上。

表：賭博難題

| d8 | 難題 |
| --- | --- |
| 1\* | 你被指控為作弊。你決定你是否實際做過或只是被汙衊。 |
| 2\* | 鎮上的警衛突擊了賭場並把你扔進了監獄。 |
| 3 | 你在遊戲中累積了債務。你的一個對手堅持要你透過承擔一個任務來付清。 |
| 4\* | 城鎮中的一名貴族在與你的遊戲中大輸特輸，並且大聲宣誓要對你復仇。 |
| 5 | 你從盜賊工會的一名低階成員手裡贏了一大筆錢，工會希望你能把錢交還。 |
| 6 | 地方犯罪頭目堅持要你獨自一人光顧他的賭博休息室。 |
| 7 | 你的好運氣使你聲名遠揚，這引來了其他賭徒的追隨並要求與你組隊。 |
| 8 | 一個以高賭注聞名的賭徒來到了這個城鎮，並咬定你來參加一場比賽。 |

\*可能涉及對手
