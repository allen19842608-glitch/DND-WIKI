# 鬧鬼

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**鬧鬼 Hauted**

鬧鬼的環境包括揹負黑暗過往的房屋、大屠殺的舊址，以及有人曾因為經歷強烈的恐懼、背上和怨恨而死去的地點。鬧鬼之處有著像幽靈一樣過去的迴音，不斷侵擾著訪客，不讓他們在此地經年的創傷中有得片刻喘息。很少有地方會無緣無故鬧鬼，而你可以輕易對錶格中的結果進行定製，以與可怕的故事相襯。
當區域中發生以下情況時，可以考慮根據鬧鬼效應表擲骰決定發生的效應。
·一個生物獲得恐慌狀態時。
·複數生物無法視物時。
·一個生物落單時。
·午夜時分或另外某個不詳的時點到來時。
·一個幽靈或其他生物與此處的可怕歷史相關的生物對隊伍構成威脅時。
**鬧鬼效應 Hauted Effect**

| **d100** | **效應** |
| --- | --- |
| 01-05 | 一場猛烈的風暴開始以該區域為中心形成，直到隊伍離開該區域前，它都不會結束。 |
| 06-10 | 一棟區域內的隨機建築在接下來持續24小時內獲得_銅牆鐵壁 guards and wards_的法術效應（豁免 DC13）。 |
| 11-15 | 一位隨機角色周圍物品中的尋常幾件——也許是樹幹或動物頭顱活化持續1分鐘並低語著警告或威脅要洩露這位角色的秘密。 |
| 16-20 | 所有的明亮關照在之後24小時內轉為昏暗。提供昏暗的光照的光源，比如蠟燭，將不再發出任何光線。 |
| 21-25 | 在接下來1d6小時內，區域內的氣溫每小時降低10華氏度。溫度將在之後回到正常。如果足夠寒冷，冰晶將會結成不祥的圖案。 |
| 26-30 | 一個隨機生物的影子在24小時內開始自主活動。影子的動作與主人不同步，可能會戲劇性地作窒息哽咽狀或試圖謀殺另一個影子。 |
| 31-35 | 在下一次黃昏之後，太陽在36小時內不會再度升起。在此期間，區域上空會高懸一輪猩紅的月亮，被翻滾的霧氣所覆蓋，或是閃爍著異界的星辰。 |
| 36-40 | 在下一個夜晚中，一個隨機睡著的生物會消失並出現在睡下之處的地下1 呎——通常是被毫無知覺地埋在泥土或者地板下層中。該生物能夠透過成功的 DC13力量（運動）檢定解救自己。 |
| 41-45 | 區域內一個隨機的生物被_浮空術 levitate_（豁免 DC15）影響1分鐘。 |
| 46-50 | 一個不暴力但令人不安的**幽魂 ghost**——也許是一隻寵物，一個容易出事的孩子，或一隻被肢解的拇指出現在一位隨機角色身邊並在24小時後消失前緊隨他們。幽魂會在生命值降低到0時消失。 |
| 51-55 | 一位玩家角色的外貌在24小時中變得能反映出這一區域的鬧鬼歷史。比如說，他們可能會會生出一條與死於本地的著名暴君有關的疤痕。 |
| 56-60 | 在接下來24小時中，一切在這一區域被殺死的類人生物肉體會立即腐爛分解並在死去10分鐘後復生為一具**骷髏 skeleton**。 |
| 61-65 | 在接下來24小時中，當任何生物受到傷害時，它的血液（或者類似的體液）會流淌成一則短訊或一幅可怕的圖案。 |
| 66-70 | 一個靈體寄宿於一位角色的一把簡易或軍用武器之中，直到角色離開該區域前，該武器會被化作一把智慧魔法物品。透過《城主指南》“智慧魔法物品”一節隨機生成決定該物品的屬性。 |
| 71-75 | 一股神秘力量對一位角色顯現，該角色能問出一個問題，並如同_卜筮術 augury_般收到回答。該靈力可能表現為自主動作的說話板，起霧玻璃上書寫的文字，或者成群昆蟲形成的訊息。 |
| 76-80 | 在下一個夜晚間，一位在區域中睡著的角色會如同被施展了_託夢術 dream_一般收到一則幻象。夢境短暫且令人不安，它展示出一些歷史環境中的要素，並將角色置身於橫遭慘劇之人的視角。 |
| 81-85 | 一具棺材或其他區域內密閉的狹小空間——可能是古董箱子，石頭洞窟或者用石頭堵住的樹樁中散發出顯而易見的惡意。當一個生物第一次開啟它時，進行一次擲骰。若結果為偶數，則該生物會收到一個可怕的幻象，並在接下來24小時內陷入對一切生物的恐慌狀態。如果結果為奇數，則一個如同_永珍無常牌 deck of many things_中頭骨牌召喚的死亡化身從中出現併發起攻擊。 |
| 86-90 | 接下來24小時內，區域內一個生物透過法術恢復生命值時，這道法術會留下傷痕。這可能同時伴隨著黑色膽汁變得純淨，或是一股靈體力量從生物體內掙脫出來。這些傷疤只能透過_高等復原術 greater restoration_或_祈願術 wish_去除。 |
| 91-95 | 接下來24小時內，一縷明亮的蒸汽會在該區域內的屍體或墳塋上空飄蕩。如果蒸汽被裝入一個容器中，持有該容器的生物能夠施展一次無須任何成分的_復生術 resurrection_這同時也會導致蒸汽消失。任何以這種方式復活的生物都會經歷古怪的夢境。 |
| 96-00 | 一股神秘的霧氣自陰影中升起。濃霧會對以區域內一個隨機生物為中心、50 呎半徑球狀區域內的一切構成重度遮蔽。任何在霧中開始回合的生物必須成功透過 DC10的體質豁免否則獲得一級力竭等級。在霧氣中時，該力竭無法被去除。此外，生物會在霧中看到令人不安的景象，比如不祥的廢墟或無聲的人影在逃離追捕。霧氣無法被任何風所吹散，但會在1分鐘後自行消失。 |
