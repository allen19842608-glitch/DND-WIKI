# 魔菇

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**魔菇 Magic Mushrooms**

蘑菇可以是致命的，是美味的，或兩者都是。有些蘑菇帶有魔法效果，特別是那些在充滿神秘能量的地點，比如幽暗地域或妖精荒野生長的蘑菇。擁有醫藥、自然或生存熟練項的生物可能熟悉真菌這一學問，特別是有關魔菇的學問，因為其益處可以救命或賦予人們奇異的能力。不過，只有專家才能在遇見未知種類的真菌時檢定它並確定它的效益。為了判斷食用這些蘑菇會產生的效果，在神奇蘑菇效果表上骰點。

**神奇魔法**

| --- | --- |
| 1 | 該生物的皮膚變成與眾不同的顏色。擲一個 d4：1，斑駁著黃色的紫色；2，帶虎斑的亮橙色；3，有紅色曲線的樹蛙綠；4，有黃色斑點的亮粉色。這個改變是永久的，除非被高等復原術或類似法術消除。 |
| 2 | 該生物在1小時內獲得變巨/縮小術的效果之一（變大或縮小的機會五五開）。 |
| 3 | 該生物恢復5d8+20點生命值。 |
| 4 | 該生物的嗓子只能發出雞一樣的咕咕和呱呱聲。這個生物也能和雞溝通。這個詛咒持續1小時，除非它被移除詛咒或是類似魔法所消除。 |
| 5 | 1d4天裡，該生物可以理解和說所有語言。 |
| 6 | 該生物在24小時內獲得心靈感應這個法術的益處。 |
| 7 | 該生物獲得植物交談這個法術的益處。 |
| 8 | 該生物馬上施放時間停止，無需任何材料。體質是這個法術的施法屬性。 |
| 9 | 該生物馬上施放偵測思想，無需任何材料。體質是這個法術的施法屬性。 |
| 10 | 魔法的迷霧從這個生物的眼睛和耳朵裡流淌出來。將其視作以這個生物為中心的雲霧術，持續1小時。 |
