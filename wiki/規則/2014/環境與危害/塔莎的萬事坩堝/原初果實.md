# 原初果實

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**原初果實 Primal Fruit**

在充滿自然力量的荒野之地，由古怪巫師精心照料的花園，以及上帝眷顧的受祝福的小樹林，有時植物會結出充滿原始魔法的果實。並不是每一種結果的植物都保有這種魔力，但那些有這種魔力的植物卻有著明顯的特徵：它們的顏色更鮮、造型更奇特，它們的表皮在日光下閃閃發亮或在黑暗中散發光芒，它們發出柔和的嗡嗡聲，或者它們擁有特別的觸感。

一株充滿魔力的果樹每週可以產出1d6個原初果實。原初果實在一週內仍然有效，之後它失去了它的神奇的特性，但仍然可以食用。

以一個動作，一名生物可以吃下一塊原初果實來獲得它的效果。這種果實可以擠成果汁，也可以煮成菜，這仍能讓它保持魔力。選擇一個效果、或在原初果實效果表上投擲，以確定當食用一片水果時會發生什麼。一個_鑑定術_或類似的魔法可以在吃下水果之前瞭解到它的好處，但不會顯示出詛咒或者副作用。

**原初果實效果表**

| **D8** | **效果** |
| --- | --- |
| 1 | 該生物恢復3d8 + 4點生命，它的皮膚在在1小時內散發5英呎半徑明亮的光，並額外散發5英呎的微光。 |
| 2 | 該生物感到一股力量的湧動。在1小時內，該生物在使用力量、力量檢定和力量豁免投擲的攻擊骰上具有優勢。當該效應結束時，該生物獲得1級耗竭。 |
| 3 | 澎湃的生命力衝擊著這個生物。該生物的生命值上限增加2d10，並獲得相同數量的生命值。該加值將持續到該生物完成一次長休，此時該生物必須成功進行 DC 15魅力豁免檢定，否則將被詛咒變成一種隨機的獸化人（參見《怪物圖鑑》中的“獸化人”）。 |
| 4 | 該生物的皮膚感到隱約刺痛。在1小時內，它獲得對一種傷害型別的抗性（由 DM 選擇）。 |
| 5 | 該生物的腦中充滿了光明的幻想。該生物在8小時內獲得防死結界效果，並且必須在 DC 13體質豁免檢定中成功，否則在該時間內陷入中毒狀態。 |
| 6 | 在1小時內，該生物聽到的所有聲音都會有微弱的嗡嗡聲，在此期間，該生物在對抗法術的豁免上有優勢。 |
| 7 | 該生物在1d4天內不需要進食、飲水和睡眠。在此期間，該生物不能被魔法催眠，而且它的夢境會侵入它清醒時的思想，它的感知（察覺）檢定具有劣勢。 |
| 8 | 低語聲入侵該生物的大腦24小時。在此期間，該生物可以與它在120英呎內看到的任何生物進行心靈感應交流。如果另一個生物至少懂一種語言，它就能進行心靈感應。 |
