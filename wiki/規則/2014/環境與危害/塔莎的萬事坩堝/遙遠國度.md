# 遙遠國度

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**遙遠國度 Far Realm**

當靈魂在死後離開物質位面時，他們會作為精魂停留在星界或前往外層位面之一繼續自己的旅行。但一些存在找到了前往外層位面之外的方式，並定居於遙遠國度之中。在那裡，他們經歷亙古的歲月化作可憎異形和上古邪物，於自身法則構成的現實中蠢蠢欲動。所有在遙遠國度停留之人最終都會被那裡的魔力所扭曲，化作異界的形狀。
遙遠國度的有害影響通常細微難辨，它們透過現實的薄弱之處或導致生命沿著異界的路徑發展的侵入性思想滲入物質位面。
當為遙遠國度所接觸的區域中發生以下情況時，可以考慮根據遙遠國度效應表擲骰決定發生的效應。
·一位舊日支配者異界宗主的魔契師在一次屬性檢定、攻擊檢定或豁免檢定中使用 d20投出1或20。
·角色們在區域中進行一次短休或長休之後。
·一個生物花費一個小時以上閱讀一本由親眼見過或以其他方式接觸過遙遠國度之人所寫的可怖卷冊。
**遙遠國度效應 Far Realm Effects**

| **d100** | **效應** |
| --- | --- |
| 01-09 | 區域內的一座建築在喃喃低語。任何在建築60 呎內能聽見聲音的生物都必須成功透過 DC12的感知豁免否則被魅惑。因此陷入魅惑時，生物必須朝著低語的源頭移動，並避開明顯的危險。當到達源頭時，生物便會平靜下來。該生物在受到傷害和每個小時結束時能夠重複豁免，失敗則結束自身上的效應。 |
| 10-18 | 該區域吸引了一位上古邪物的注意，其存在深不可測的威壓被投向這一區域。每個在這一區域結束一次休息的生物必須成功透過 DC12的魅力豁免，否則不會衝休息中獲得任何好處。取而代之的是，它會在附近發現奇怪的塗鴉、堆起的石頭，或者自己的物品被排列成錯綜複雜、難以捉摸的圖案 |
| 19-27 | 當地的動植物都獲得了邪惡的智慧。投一個 d6,。骰值1-2時，一個_疫病蟲群 insect plague_法術以一個區域中的隨機生物為中心爆發。骰值3-4時，1d4**渡鴉群 swarm of ravens**和1d4**鼠群 swarm of rats**聚集形成並攻擊一切區域內的其他生物。骰值5-6時，一個**樹人 treant**（在森林地帶）或**格萊石人 galeb duhr**出現併發起攻擊。 |
| 28-36 | 距離不再以通常可理解的方式作用。生物進行遠端攻擊時具有劣勢，同時這些攻擊的射程也會減半。 |
| 37-45 | 地面開始融化變形，化作蠕動的血肉、眼球和長滿獠牙的大嘴。從血肉化的地面中未被佔據的區域內升起1d4+5個**囈語之口 gibbering mouthers**，並攻擊一切它們看見的生物。 |
| 46-54 | 難以名狀的低語威脅著區域內一個隨機生物的心智。在該生物回合開始時，它必須成功透過 DC13的智力豁免，否則以其動作對它能看見的最近一個生物進行一次近戰攻擊。如果沒有生物在觸及範圍內，則目標會以動作用於含混不清地喃喃自語。 |
| 55-63 | 古怪的附肢在地面之下和樹木建築周圍蠕動。數十條肢體突然迸出，糾纏一個隨機生物為中心30 呎球狀區域內的所有目標。球狀範圍內的每一個生物都必須透過 DC14的敏捷豁免，否則受到3d6鈍擊傷害並受到束縛。任何在該區域內結束回合的生物都會受到3d6鈍擊傷害。一個生物能夠透過一個動作成功進行 DC14的力量或敏捷（由其選擇）檢定將自己或觸及範圍內的另一個生物從束縛中釋放出來。 |
| 64-72 | 區域內的生物無法離開這片土地，他們會一遍又一遍兜圈子。當意識到這一點時，時間已經過去了2d10小時。這段時間中，他們試圖離開的努力都是徒勞無功。然後效果結束，每個生物必須成功透過 DC10的體質豁免否則獲得1級力竭。 |
| 73-79 | 區域內一個隨機生物聆聽到詭異的低語，它必須成功透過 DC14的感知豁免，否則將被魅惑。以此方式被魅惑時，該生物會專注於以它擁有的任何媒介（墨水、木炭、米兔或自己的鮮血）複製自己腦海中瀆神的圖案。除非被妨礙，否則它將在一小時內完成繪製。當生物完成工作後，它將不會再受到魅惑。一隻**史拉亡蟾 death slaad**出現在它的30 呎內，並攻擊一切看到的生物。 |
| 80-85 | 這一區域的自然特徵和建築形態扭曲，能夠拼出詞句並形成古怪的符號。任何試圖閱讀資訊的生物都必須進行 DC20的智力（奧秘）檢定。成功的呃情況下，該生物獲得如同施展_異界探知 contact with other plane_的啟悟。失敗的情況下，該生物會受到如同在_困惑術 confusion_中豁免失敗一樣的效果。這一效果在該生物下一回合結束時結束。 |
| 86-90 | 這一區域內，圓形的東西（比如紐扣，水晶球，太陽等）看上去離奇失常。一個在區域內開始回合的隨機生物必須成功透過 DC14智力豁免，否則會在其回合中大聲地試圖摧毀這些事物。 |
| 90-95 | 圓睜的淚眼出現在整個區域中的無生命物體上。這些眼睛會監視角色們。只要眼睛存在，區域內的生物就不會被角色所突襲。如果受到傷害，一隻眼睛會閉上並消失。如果你已經投出過這一效應，則重新擲骰。 |
| 96-100 | 現實的裂痕在這一區域中迸開，類似於_異界之門 gate_法術，溝通了遙遠國度和一個隨機位面。任何進入裂縫的角色都會受到來自遙遠國度恐怖之物的10d10心靈傷害並出現在裂縫隨機位面的另一端一處未被佔據的區域中。裂縫會在2d10+2小時後消失不見。 |
