# 蟲災

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**蟲災 Infested**

在許多世界上，昆蟲生物的數量都遠遠高於高等生命。大規模遷徙和致命的種類也許會危害到比它們更大的生物，大部分昆蟲也仍然只是惹人厭煩的程度。然而，透過不受拘束地繁衍，魔法操控，超自然的生長速度，與異界生物的雜交和古怪的環境，昆蟲能夠在整片地區氾濫成災。蟲群成為的地區的優勢物種，他們吞噬動物和植物，製造出錯綜複雜的巢穴或隧道，並在建築和土地上肆虐。
以下效應表現出被蟲群或類似生物的巢群所統治的區域，它們可能是為魔法所操控，為異界的智慧所驅使，或者環境因素導致它們滋生無數並侵擾其他生物。
考慮在區域中出現以下狀況時按照蟲災效應表格擲骰決定效果。
·蛛網、蟲蛹、蜂巢、蟻冢或者其他蟲類居所受到驚擾。
·一個生物攻擊一個蟲群或一個小型以上的蟲類，比如巨蜈蚣或巨蜘蛛。
·角色們在區域中開始一次短休或長休之後。
**蟲災效應 Infected Effect**

| **d100** | **效應** |
| --- | --- |
| 01-05 | 接下來24小時內，刺耳的嗡鳴和不休的噪音充滿了整個區域。除了嘈雜的聲音外，生物只能聽到10 呎內的聲響和說話聲。 |
| 06-10 | 蟲群開始大規模遷徙，細小的蟲子成群結隊地在該地區的所有地方爬行。生物在接下來的24小時內不能在該區域內長休或短休。 |
| 11-15 | 一大群閃閃發光的蒼蠅聚集在區域中一個隨機生物的身上，接下來一分鐘內，該上午發出10 呎微光 ，當攻擊者能看到它時，任何對其進行的攻擊具有優勢，同時該生物無法從隱形獲益。 |
| 16-20 | 一群白蟻從地面上湧出，帶著一系列骨骸和一件 DM 選擇的寶藏（見《城主指南》中的“隨機寶藏”）。 |
| 21-25 | 一隻蟋蟀形狀，使用**貓 cat**資料的生物與一位角色出現在一位隨機生物周圍，並 像關切的寵物一樣與他形影不離，但會在24小時後蹦跳著離開。 |
| 26-30 | 一團共1d4+2條發光的蠐螬出現在隊伍30 呎內一處未佔據空間。吃下這樣一條多汁蠐螬的角色將會獲得一瓶治療藥水的好處。 |
| 31-35 | 一隻色彩斑斕的巨大飛蛾從隊伍上空掠過，灑下五彩的粉末。其飛過的生物必須透過 DC16的體質豁免，否則在一小時內被所有生物所魅惑。 |
| 36-45 | 區域被細密的蛛網所堵塞，視作困難地形。 |
| 46-50 | 幾乎所有的地面上都覆蓋著被拋棄的蟬蛻般的外殼，踩上去嘎吱作響，這讓移動的同時進行的敏捷（隱匿）檢定具有劣勢。外殼會在一個小時之後消失。 |
| 51-55 | 一隻肥大而腫脹的蛆蟲在距離隊伍不到10 呎的地方冒出，然後爆炸，其膿液覆蓋1 呎中心的地面。在1分鐘內，這片區域受到_油膩術 grease_（豁免 DC13）影響。 |
| 56-60 | 地面在一個隨機生物身下開洞，形成一個流沙坑。（見《城主指南》） |
| 61-65 | 一個區域中的隨機生物必須成功透過 DC16的體質豁免檢定否則感染腐眼症（見《城主指南》）。 |
| 66-70 | 糞便顏色的蟲子們覆蓋著地面。生物能夠以半速無視這些蟲子移動。移動更快的生物必須透過 DC16的體質豁免否則直到其下個回合開始陷入中毒。由於受不了蟲堆的惡臭因此而中毒的生物速度降低為0。不需要呼吸的生物自動豁免成功。 |
| 71-75 | 區域中的一個角色必須成功透過 DC15的感知豁免，否則如同受到_變形術 polymorph_影響一般被變形成一隻巨蜘蛛，該法術持續1個小時或直到被解除。 |
| 76-80 | 區域中的一個隨機生物必須成功透過 DC16的體質豁免，否則將會獲得一種貪婪的蛀蟲在危害其裝備。當該生物下一次完成短休或長休後，他便會發現這種蛀蟲。如果該生物有任何紙質材料，蛀蟲便會隨機啃食破壞一本書或一份非魔法的紙製品。 |
| 81-85 | 區域內的一個隨機生物必須成功透過 DC16的體質豁免否則成為一種格外危險的絛蟲的宿主。受影響的生物在治癒疾病之前無法透過進食得到任何好處。一個免疫疾病的生物自動透過這次豁免。 |
| 86-90 | 四處叮咬的蟎蟲落到了區域中的角色們的衣服上。任何穿著中甲或重甲的生物都在接下來24小時中的攻擊檢定、屬性檢定和豁免檢定中具有劣勢。 |
| 91-95 | 細小的蜘蛛進入到不受注意的地方。下一次區域中一個隨機生物在結束長休後穿上衣服或盔甲時，它必須成功透過 DC16的體質豁免否則受到11（2d10）毒素傷害。 |
| 96-00 | 無數的吸血昆蟲在接下來1d6小時中這一區域肆虐。每個小時，每個區域中的生物必須成功透過 DC10的體質豁免否則獲得一級力竭。這些昆蟲無法影響免疫疾病的生物。 |
