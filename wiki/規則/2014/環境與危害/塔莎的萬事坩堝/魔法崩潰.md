# 魔法崩潰

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**魔法崩潰 Unraveling Magic**

這一區域的魔法之源遭到了破壞或腐化。魔法並不穩定，並會在一個生物施展法術時產生古怪的結果。這一區域可能會形成在出錯的強大儀式的場所（或者是在危險和破壞性的情況下成功），災難性的魔法戰鬥之後，或一件聖物被摧毀的地方。
考慮在區域中出現以下狀況時按照魔法崩潰效應表格擲骰決定效果。
·魔法物品的充能被消耗。
·一個1環及以上的法術位被消耗。
·一個挑戰等級在5以上的龍、妖精或元素生物死去時。
**魔法崩潰效應 Unraveled Magic Effect**

| **d100** | **效應** |
| --- | --- |
| 01-05 | 1小時中，所有區域內的魔法物品都不再具有其魔法屬性，變成非魔法物品。神器不受影響。當魔法物品恢復效果時，生物與它的同調也會恢復。 |
| 06-10 | 1小時中，該區域變為死魔區。在此期間，整個區域被反魔法場_antimagic field_效果所影響。 |
| 11-15 | 區域內的一個隨機生物必須成功透過 DC15敏捷豁免否則被封閉於_歐提路克彈力法球 Otiluke's resilient sphere_之中。 |
| 16-20 | 一個區域內的隨機消耗過法術位的生物獲得一個被消耗過的隨機環位法術位。 |
| 21-25 | 魔法的閃光在整個區域內閃爍長達1分鐘。在此期間，先攻輪到20時（同先攻值最後），一個隨機生物受到2d4傷害。其型別透過 d6決定：1，強酸；2，寒冷；3，火焰；4，力場；5，閃電；6，雷鳴。 |
| 26-30 | 一位區域內的角色必須成功透過 DC15的感知豁免否則如同被施展了_變形術 polymorph_一般被變形為一隻**閃現犬 blink dog**。該法術持續一個小時或直到被解除。 |
| 31-35 | 一個區域內具有法術位的隨機生物在一陣無害的火花和聲響中失去一個法術位。 |
| 36-40 | 區域中的所有火焰都凍結成冰，發出與其原本亮度相等的藍光。此外，該區域陷入長達一天的嚴寒（見《城主指南》）。 |
| 41-45 | 一個區域內具有法術位的隨機生物成為周圍環境中魔法的焦點。每個生物回合結束時，在其5 呎內的生物必須成功透過對抗該施法者法術豁免 DC 的敏捷豁免否則受到1d6力場傷害。 |
| 46-50 | _熾焰法球 flaming sphere_法術（豁免 DC15）出現在隊伍5 呎之內並自行動作。先攻輪到20時，法球朝著最近的生物移動30 呎。法球在1分鐘後消失。 |
| 51-55 | 非魔法的簡易武器和軍用武器被注入了力量。在1小時內，它們變為在攻擊和傷害擲骰中具有+1加值的魔法武器。 |
| 56-60 | 在24小時中，旋轉的能量包圍著一個隨機生物。在此期間，該生物獲得對力場傷害的抗性，並且其速度被降低至10 呎。 |
| 61-65 | 每個區域內的角色突然習得了一些魔法。一名角色習得一個自己選擇的法師戲法並在1d8日內不會忘掉它。 |
| 66-70 | 一個區域內的隨機生物散發著火花般的光芒長達1個小時。在此期間，這些生物魔法地發出10 呎明亮光照和額外10 呎微光光照。此外，任何觸碰（如果目標非自願，則需要徒手打擊）到目標的生物都會受到1d6力場傷害。 |
| 71-75 | 5 呎寬的電弧出現在區域內兩個彼此30 呎內未處於全身掩護下的生物之間。每個線上狀區域中的生物（包括兩頭的兩個生物）都必須進行 DC13的敏捷豁免，失敗的情況下，受到4d6閃電傷害，成功則受到一半傷害。 |
| 76-80 | 以一個區域中的隨機生物為中心，_反轉重力 reverse gravity_法術啟用長達1分鐘 . |
| 81-85 | 先攻輪到20時,兩個區域內的隨機生物必須進行 DC16的魅力豁免。如果其中一個失敗，則他們被魔法傳送並交換位置。如果兩方都成功，則都不會被傳送。 |
| 86-90 | 一個隨機生物在1小時內獲得打破魔法的能力。當任何人在其20 呎內對該生物施展魔法時，該施法者必須成功透過使用其施法屬性、DC15的豁免檢定，否則法術會消散而不產生任何效應。產生該法術的法術位，充能或特性會被浪費。 |
| 91-95 | 在接下來24小時內，當一個區域內的生物以一個其他生物為目標施展法術時，施法者必須進行使用其施法屬性、DC11的豁免檢定。失敗的情況下，法術目標變為施法者自己。成功的情況下，法術照常生效。該效應會隨後消失。 |
| 96-00 | 一個隨機生物獲得在1分鐘內立即施展_祈願術 wish_的能力。如果你在24小時內投出過這一效應，重新擲骰。 |
