# 契術師可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 契術師的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

**契術師 Warlock**
魔契師在這一部分得到了一些新的特性與子職。
**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為魔契師的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特效能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。

**魔契恩澤選項 Pact Boon Option**
_第3級魔契師特性_
_當你選用魔契恩澤的時候，下列選項可供你選擇。_
**符之魔契 Pact of the Talisman**
你的宗主賜予你一個護身符，一個當需要的時候可以幫助佩戴者的護身符。當佩戴者在一次屬性檢定中失敗，他們可以在骰擲結果上增加一個 d4骰，這可能將結果變為成功。這一能力可使用的次數等於你的熟練加值，且所有已消耗的次數將會在你完成一次長休之後全部恢復。
如果你弄丟了護身符，你可以進行一個1小時的儀式從你的宗主那裡得到一個替代品。這一儀式可以在一個短休或一個長休過程中完成，且它將會破壞之前的護身符。護身符將會在你死亡時消散為灰塵。
**替換魔能 Eldritch Versatility**
_第4級魔契師特性_
每當你的魔契師達到了可以獲得屬性值提升的等級，你可以做以下的一件事來代表你在奧秘研究當中重點的轉變。
可以將你從該職業契約法術中學到的戲法替換為另一個魔契師法術列表中的戲法。
可以將你從魔契恩澤中選擇的一個選項替換為此魔契的另一選項。
如果你的角色已經12級或者更高，你可以將一個玄奧秘法的法術替換為另一個同環魔契師法術。

如果這些轉變讓你不再符合某些魔能祈喚的條件，你必須現在選擇那些符合你條件的祈喚來替換它們。
