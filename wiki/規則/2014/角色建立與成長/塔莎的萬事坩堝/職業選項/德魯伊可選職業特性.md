# 德魯伊可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 德魯伊的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

**德魯伊 Druid**

德魯伊職業在本節中獲得了新的職業特性與子職業選項。

**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為德魯伊的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特效能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。

**德魯伊法術擴充套件 Additional Druid Spells**
_第1級德魯伊特性_

**荒野夥伴 Wild companion**
_第2級德魯伊特性_
你獲得召喚呈現動物形態的精魂的能力，以一個動作，你能夠消耗一次荒野變形使用次數來施放一次無需材料的尋獲魔寵法術。
當你以此方法施放該法術時，魔寵的型別是妖精而不是野獸，魔寵會在等同於你德魯伊等級一半的小時數後消失。

**替換戲法 Cantrip Versatility**
_第4級德魯伊特性_
每當你達到該職業提升屬性值的等級時，你就可以用德魯伊法術列表中的另一個戲法來替換你從該職業的施法特性中學到的一個戲法。
