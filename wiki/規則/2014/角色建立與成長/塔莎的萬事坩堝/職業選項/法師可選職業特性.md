# 法師可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 法師的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

**法師 Wizard**
法師職業在本節中獲得了新的職業特性與子職業選項。
**可選職業特性 Optional Class Features**
當你在某一職業達到特定等級，你將從《玩家手冊》中取得相應的職業特性。本節提供了可供法師獲得的額外職業特性。與《玩家手冊》中的職業特性不同，這些特性並非自動取得；若你滿足相應的等級要求，你應當詢問 DM 以決定是否獲得本節所提供的特性。這些特性是彼此獨立的、並不需要被一併選擇：你可以使用其中的一部分、全部、或是完全不用。

**戲法公式 Cantrip Formulas**
_第3級法師特性_
你在法術書中寫下了一套奧法公式，並能藉此在心中推演出一個戲法。每當你完成一次長休，你可以查閱法術書中所記的公式，以將你的一個已知法師戲法替換為另一個來自法師法術列表的戲法。
