# 野蠻人可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 野蠻人的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

****

野蠻人 Barbarian

****

野蠻人職業在本節中獲得了新的職業特性與子職業選項。
**可選職業特性 Optional Class Features**
**你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為野蠻人的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特效能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。**
**原初學識 Primal Knowledge**
_第3級野蠻人特性_
當你的野蠻人職業等級達到3級和10級時，你可以從野蠻人1級所提供的技能熟練項列表中選擇一個技能，獲得該技能的熟練。
**莽馳 Instinctive Pounce**
_第7級__野蠻人__特性_
作為你進入狂暴狀態的附贈動作的一部分，你可以至多移動一段等同於你速度的一半的距離。
