# 牧師可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 牧師的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

**牧師 Cleric**
**牧師職業在本節中獲得了新的職業特性與子職業選項。**
**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為牧師的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特效能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。
若你將一個特性替換為另一個特性，那麼你將不會受到被替換的特性所帶來的好處，你也不會滿足在遊戲中任何需求被替換的特性的東西。
**額外牧師法術 Additional Cleric Spells**
_第1級牧師特性_
下方列出的法術是對《玩家手冊》中牧師法術列表的補充。若一個法術能夠以儀式施法的方式施展，那麼儀式標籤會記在法術名字後方。除了標有星號(說明這是一個來自第三章的法術)的法術以外，其他法術均來自玩家手冊。薩娜珊的萬事指南中也提供了更多的法術。

**神力掌控 Harness Divine Power**
_第2級牧師特性_
你可以將一次引導神力次數轉化為你法術的魔力。以一個附贈動作，你觸碰你的聖徽進行祈禱，以此，你恢復一枚環階 不超過你熟練加值的一半（向上取整） 的法術位。
你能使用這一特性一次，當你在此職業上達到更高等級後你可以使用更多次：6級後兩次；18級三次。
在你完成一次長休後，你恢復所有已消耗的使用次數。

**替換戲法 Cantrip Versatility**
_第4級牧師特性_
當你在此職業獲得了屬性值提升時，你可以將一個你透過此職業的施法特性學會的牧師戲法替換為牧師法術列表中的另一個戲法。

**受祝打擊 Blessed Strikes**
_第8級牧師特性，替代 神聖打擊 Divine Strike 特性或 強力施法 Potent Spellcasting 特性_
在戰鬥中，你受到神力的祝福。當你透過戲法或武器攻擊來傷害一個生物時，你能夠對該生物造成額外1d8光耀傷害。當你造成一次此傷害後，你直到自己的下一個回合開始前無法再次使用此特性。
