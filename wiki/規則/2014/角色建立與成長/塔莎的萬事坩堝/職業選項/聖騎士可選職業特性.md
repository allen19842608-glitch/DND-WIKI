# 聖騎士可選職業特性

> [!WARNING]
> 本頁整理《塔莎的萬事坩堝》的 2014 舊版可選規則；是否採用由 DM 與玩家在建立角色或取得特性時共同決定。

適用於 2014 聖騎士的額外與替換職業特性。

## ⚙️ 規則條文 (Rule Text)

**聖騎士 Paladin**
聖騎士職業在本節中獲得了新的特性與子職業選項。

**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為聖騎士的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特效能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。

**額外聖騎士法術 Addtional Paladin Spells**
_第2級聖騎士特性_
下表中的法術擴充了聖騎士在《玩家手冊》中的法術列表。此列表以法術環數而非角色等級排序。以下法術均存在於玩家手冊中，除非其標有星號\*（這說明該法術來自本書的第三章）。《珊娜薩的萬事指南》同樣提供了更多可使用的新法術。

| **2環** | **3環** | **5環** |
| --- | --- | --- |
| 遺體防腐 Gentle Repose | 魂靈環繞 Spirit Shroud\* | 天界召喚術 Summon Celestial\* |
| 治療禱言 Prayer of Healing |  |  |
| 守護之鏈 Warding Bond |  |  |

**戰鬥風格選項 Fighting Style Options**
_第2級聖騎士特性_
當你選擇戰鬥風格時，以下戰鬥風格加入可選戰鬥風格列表。

> **受祝福的勇士 Blessed Warrior**
> 從牧師法術列表中選擇兩種戲法。你習得這些戲法，它們對你來說是聖騎士法術，這些戲法的施法屬性是魅力。當你提升此職業的等級時，你能夠將一個已知戲法替換為牧師法術列表中的另一個戲法。
> 
> **盲戰 Blind Fighting**
> 你獲得10 呎的盲視感官。在此範圍內，你可以切實的看見非 完全身掩護 total cover 的任何東西，即使你處於 目盲 Blinded 狀態或是身處黑暗之中。不僅如此，你還可以看見此範圍內的 隱形 Invisible 生物（除非對你而言該生物成功躲藏了起來）。
> 
> **攔截 Interception**
> 當一個你可見的生物攻擊距離你5 呎以內你以外的目標時，你能以一個反應將目標受到的傷害減少1d10+你熟練加值（最多減到0傷害）。當你手持一面盾牌或者一把簡單或軍用武器時才能執行此反應。

**神力掌控 Harness Divine Power**
_第3級聖騎士特性_
你可以將一次引導神力次數轉化為你法術的魔力。以一個附贈動作，你觸碰你的聖徽進行祈禱，以此，你恢復一枚環階 不超過你熟練加值的一半（向上取整） 的法術位。
你能使用這一特性一次，當你在此職業上達到更高等級後你可以使用更多次：7級後兩次；15級三次。
在你完成一次長休後，你恢復所有已消耗的使用次數。

**替換武術 Martial Versatility**
_第4級聖騎士特性_
每當你透過提升聖騎士等級獲得屬性值提升時，你可以用另一個聖騎士能夠選擇的戰鬥風格替換你當前的戰鬥風格。這一變化代表著你在戰鬥訓練上重心的轉移。
