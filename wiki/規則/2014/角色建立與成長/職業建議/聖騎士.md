# 聖騎士角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_衡量一個聖騎士的價值，絕不在於計算他掠奪地城或打敗敵人的數量。聖騎士的真正價值，在於他拯救的生命，以及他對於正義仁慈之事業的決心。_

_\--伊斯特沃（Isteval）_

一個聖騎士是其誓言的鮮活象徵，且這位神聖的鬥士有著能力與決心見證自己誓言的終結。一些聖騎士專注於保護無辜者並以此在世間貫徹正義，而另一些聖騎士則透過征服並統治叛逆者來達到這個目標。

雖然世上沒有一個聖騎士是典型的，但他們中確實有一部分是那種在狹隘定義上的好人，拒絕容忍那些甚至與他們只有毫釐之差的觀點。不過，作為冒險者的那些聖騎士，則很少保持這種僵硬的態度，哪怕只是為了避免與同伴疏遠。

你可以使用下面的一些建議來充實你的聖騎士角色。請記住，大多數聖騎士並不是機器人，他們的內心中也有懷疑與偏見、糾結與矛盾，就像其他人一樣。有些聖騎士有自己的想法，而這有時可能會與他們的誓言不一致。

個人目標

聖騎士宣誓的規則為角色提供了一個其所遵循與推進的終極目標，或稱整體目標。此外，一些聖騎士其實是受其個人的目標驅動的，這項個人目標可以補充甚至超越他們的誓言。遵守不同誓言的聖騎士也可能有著相同的個人目標，只是在堅持誓言的過程中，他們以不同的方式將這項個人目標貫徹到行動中。如果你的聖騎士角色有一項個人的目標，它也許誕生自一些生活事件，從而並不與誓言直接掛鉤。

個人目標

| d6 | 個人目標 |
| --- | --- |
| 1 | 和平。你為之奮鬥，而後代不必。 |
| 2 | 復仇。你的誓言是你糾正一個過往錯誤的工具。 |
| 3 | 職責。你不會辜負你的諾言，至少你拼死確保如此。 |
| 4 | 領導。你將贏得一場為人傳誦的大戰，以此成為激勵他人的榜樣。 |
| 5 | 信念。你知道你的道路是正義的，否則眾神不會讓你踏入其中。 |
| 6 | 榮耀。你將引領世界進入一個新時代，它必被冠以你的名字。 |

符號

聖騎士注意到了符號的影響，他們之中許多人採用甚至親自設計出一個具有獨特形象的藝術符號。你的符號代表了你的誓言，並向周圍的人彰顯敵我。你的符號也許是光明正大地擺在旗幟、橫幅或衣服上給所有人看的，但它也可以不那麼明顯，就像是隱藏在你身上的私密飾品或標記。

符號

| d6 | 符號 |
| --- | --- |
| 1 | 一條龍。象徵你平和的高貴和激烈的奮鬥。 |
| 2 | 握緊的拳頭。因為你隨時準備為信仰而戰。 |
| 3 | 張開的手掌。表明你比起爭鬥更偏好外交。 |
| 4 | 紅色的心。向世人展現你對正義的承諾。 |
| 5 | 黑色的心。表示憐憫之類的情緒不會影響你對誓言的奉獻。 |
| 6 | 不眨的眼珠。你對所有可能危害到你的事業的潛在威脅永遠保持警惕。 |

剋星

聖騎士們嚴守的誓言要求他們以積極的態度傳播他們的信仰，而這種行為自然會與反對這種信仰的生物或實體發生衝突。

在這些對手之中，一名剋星--常常是一名聖騎士最頑固或最可怕的敵人--的存在或影響是聖騎士生命中的常態。你的聖騎士角色很可能從起步時就有了這樣一位敵人。

也許在你成為聖騎士的時候，你就吸引了那些會與你發生衝突的人的注意，而你成為了他們的目標。如果你有一個剋星，那他是誰？或者說，是什麼？你認為誰是你的敵人，誰是你實現目標的最大威脅？

剋星

| d6 | 剋星 |
| --- | --- |
| 1 | 一個強大的獸人酋長，威脅要超越並摧毀你的一切。 |
| 2 | 一個惡魔或天族，外層位面力量的代理人，你被指名受其腐敗或救贖，視情況而定。 |
| 3 | 一條龍，它的僕人纏住了你，阻礙你的步伐。 |
| 4 | 大祭司將你看作誤入歧途的愚昧之徒，想要你放棄你的信仰。 |
| 5 | 一個曾與你一同訓練的聖騎士，如今背棄了誓言，與你對立。 |
| 6 | 被某人打敗的吸血鬼，發誓要對所有聖騎士復仇。 |

惑念

儘管聖騎士為誓言獻身，但他們終究是凡人，有所缺陷。大多數聖騎士依然會表現出某種並不符合他們最高理想的態度或行為。你的角色容易向怎樣的誘惑屈服？抑或是發現有什麼是難以抵擋的？

惑念

| d6 | 惑念 |
| --- | --- |
| 1 | 暴怒。當你被惹火，你就難以冷靜思考，甚至可能會做一些日後將會為之懊惱的事情。 |
| 2 | 驕傲。你的行徑值得注意，沒有人比你更注意它們。 |
| 3 | 色慾。你無法抗拒一張誘人的臉和一個愉快的笑容。 |
| 4 | 嫉妒。你注意到一些著名人士。當你的行為不足以與他們比肩，你就感到不爽。 |
| 5 | 絕望。你認識到你需要打敗的敵人擁有的強大力量，而有時你感覺無法看到哪怕一絲勝利的希望。 |
| 6 | 貪婪。無論是多少榮耀與財富，都無法滿足你的貪慾。 |

神聖誓言

在3級時，聖騎士獲得神聖誓言特性。除了玩家手冊中提供的選項，這裡給出了下列額外的誓言選項：征服誓言和救贖誓言。
