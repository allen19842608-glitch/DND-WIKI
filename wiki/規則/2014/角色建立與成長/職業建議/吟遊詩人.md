# 吟遊詩人角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_“音樂是由創生聖言從神木上搖下的果實。但我問你一個問題，一個詩人能尋得此樹的根嗎？誰能探究這力量的根源？啊，他們想為這個世界帶來怎樣的音樂！”_

_\--Fletcher Danairia，吟遊詩人大師_

從俏皮到莊重，吟遊詩人將帶來不同的時光；他們傳授知識以彌補無知，致使荒謬彷彿崇高。吟遊詩人是悠久歷史的傳承者，他們的歌聲與故事延續著偉大的記憶--那些透過口耳相傳被熟記的見聞，即便沒有書面記載仍能存續。

同樣的吟遊詩人也會充當更小的、更現代的事件的記錄者--關於現在的英雄們的故事，無論是他們的英勇事蹟，還是他們拿不易被注意到的失敗。

當然，世界上有很多人會哼哼小調或講個好故事，甚至有著比冒險中的吟遊詩人更油腔滑調的舌頭和妙曼的聲音。然而真正使吟遊詩人和他們不同--以及和其他吟遊詩人不同--是他們的表演風格和內容。吟遊詩人那通常華麗而張揚的表演，將緊緊抓住並保持觀眾的注意力。

在 D＆D 世界中最有名的吟遊詩人相當於流行明星。如果你扮演一個吟遊詩人，你可以考慮用你最喜歡的音樂家作為角色形象的參考。你可以透過參考下述建議為你的吟遊詩人角色新增獨特之處。

拿手作品

每一位成功的吟遊詩人都至少有一項聞名的表演藝術，通常是一首受所有人歡迎的歌曲或詩詞。這些作品被觀眾討論了好幾年，甚至一些人因此改變了自己的人生。如果你的角色才剛剛起步，你可能要在未來才能最後描繪出你的作品。但是任何一種你賴於謀生的專業，都有機會早已準備好一兩首已被證明確實能取悅觀眾的劇目。

| d6 | 拿手作品 |
| --- | --- |
| 1 | “三個弗拉賓尼斯”，一首關於身份錯位和不受約束的慾望的下流歌曲。 |
| 2 | “蕈人圓舞曲”，孩子們特別喜歡的歡快調子。 |
| 3 | “阿斯摩蒂斯的黃金屁股”，一首戲劇性的詩，你聲稱靈感來源於你在地獄的私人拜訪。 |
| 4 | “路斯坎海盜”，你在小時候被海盜劫持的第一手記錄。 |
| 5 | “一個箍，兩隻鴿子，以及一頭地獄獵犬”，一首惡搞某個無能貴族的滑稽詩。 |
| 6 | “蠢貨在深淵”，一首關於一個小丑在惡魔間旅行的喜劇詩。 |

樂器

在吟遊詩人對頂級表演和至高喝彩的追求中，樂器同他的聲音一樣重要。樂器的做工是關鍵要素，當然，最好的樂器演奏最好的音樂，和一些吟遊詩人不斷尋求精進。或許是同樣重要的是--儘管那是樂器自身的娛樂價值--那些有著奇怪的構造、或是由罕見的材料製作的樂器可能會給觀眾留下持久的印象。你可能會有一個“批次生產”樂器，也許是因為你僅僅只能買得起。或著，你的第一臺樂器是別人贈予你的禮物，它可能更為精緻。你對你擁有的樂器是滿意的，還是希望有真正與眾不同的東西取代它？

| d6 | 樂器 |
| --- | --- |
| 1 | 一把大師手工製作的半身人小提琴。 |
| 2 | 一把精靈製作的秘銀號角。 |
| 3 | 一把卓爾蜘蛛絲製成的齊特琴\*（一種類似箏的樂器）。 |
| 4 | 一面獸人鼓。 |
| 5 | 一個木製的啵靈蛙呱聲盒。 |
| 6 | 一把侏儒設計的豎琴。 |

窘迫

幾乎每個吟遊詩人都至少有一次在觀眾面前出糗過，你也不會例外。畢竟沒人能馬上成功，在你職業生涯的早期你也許碰到過一點小麻煩；或是在一個令人痛苦的夜晚，命運秘密地為你的聲望帶來戲劇性的毀滅，致使你需要花費很長時間才能恢復你的名聲。一場演出失誤的方式如同海里的魚一樣多樣，不管怎樣的災難都有可能發生，當然，一個吟遊詩人有勇氣和信心恢復過來--繼續演出（如果可能）或是許諾在不遠的將來帶著新的表演重新來過。

| d6 | 窘迫 |
| --- | --- |
| 1 | 當你表演喜劇歌“大湯姆的狂歡”時--儘管你覺得發揮得很好--你和大湯姆引來一陣噓聲。 |
| 2 | 日場演出時，馬戲團的梟熊嚇散了驚恐的人群。 |
| 3 | 你的開場歌是你熱衷的“沼喉怪之歌”，但這對普通人來說是場噩夢。 |
| 4 | 你第一次也是最後一次公開演出是“Mirt，Man about Town”\*。 |
| 5 | 在舞臺上你的假髮著火了，你扔下了它--然後它點燃了舞臺。 |
| 6 | 在你演奏“星光小夜曲”的最後一節時，你因為失誤坐在了你的魯特琴上。 |

吟遊詩人的繆斯

自然，每個吟遊詩人都有歌曲和故事的才能。有些詩人是所有表演領域的通才，併為他的多才多藝自豪。其他人採取更私人的方式攀登他們的藝術之峰，由他們被μ‘s 的迷戀所驅動--鼓舞他們在觀眾面前展現的某種特別之物。跟隨μ‘s 的吟遊詩人通常是為了更深的理解μ‘s 的意義並知曉如何更好的用表演傳達給其他人。如果你的吟遊詩人角色有一個繆斯，它可能是這裡描述的三項之一，也可能是你自己的設計。
