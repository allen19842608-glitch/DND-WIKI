# 契術師角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_你覺得我瘋了？我倒覺得明知道在塵世之外，知識和力量觸手可及，你們卻整天營營苟且於俗事，這才真是瘋了呢。_

_\--夏壬，阿卡瑪之兆景_

　　契術師是探密者，契術師是守密人。他們擴張著我們對世界認知的邊界，總是尋覓超越他們理解的事物。當賢者和法師們發現確鑿的危險預兆，從而終止他們的實驗時，契術師們卻勇往直前，不計後果。因此，一個契術師總是由天分、好奇和魯莽混合塑造成的獨特存在。許多普通人會把這些特質當成瘋狂的典型證據；契術師們則將其視為勇氣的象徵。

　　契術師由兩個基本要素塑造；這兩個基本要素相互協作，鑄就契術師生涯的道路。第一個元素是，是什麼事件亦或是環境，導致了一名契術師與一個位面存在訂立了契約；第二個元素是，契術師所立契的存在，究竟有什麼樣的天性。和主動接受神和神理念的牧師不同，一個契術師有可能對宗主毫無認同，也有可能完全相反。

　　接下來的章節提供了塑造契術師角色的一些方法，幫助你創造複雜有趣的故事和角色扮演的契機。

宗主態度

\--------------------

　　所有的關係都是相互的，但對於契術師和他們的宗主而言，雙方的關係就不一定平等了。契術師對他的宗主所持有的態度，無論是積極的還是消極的，可能會被宗主同等地回報，但也可能契約雙方對彼此有完全相反的感情。

　　當你決定你的契術師角色對宗主抱持的態度時，也要考慮宗主一方是如何看待的。你的宗主會對你做什麼？你的宗主是一個朋友和同盟，還是因你威逼利誘下才賜予你力量的敵手？

表格：宗主態度

| d6 | 態度 |
| --- | --- |
| 1 | 你的宗主世世代代引導、幫助你的家族，並且對你也十分友善。 |
| 2 | 每次與你任性宗主的互動都令人驚異，無論是驚喜還是驚恐。 |
| 3 | 你的宗主是一位逝去已久的英雄，他將與你立下的契約視作繼續影響世界的方法。 |
| 4 | 你的宗主極度嚴格地奉行規矩，但對你抱著尊重的態度。 |
| 5 | 你的宗主欺騙你立下契約，並把你當做奴隸。 |
| 6 | 你基本上被丟在一邊做自己的事，宗主幾乎無所作為。有的時候你會擔心它出現時將會提出什麼要求。 |

契約特別條款

\--------------------

　　一份契約可能是鬆散如口頭約定，也可能嚴格如有冗長而詳細的條款、附有需求列表的正式合同。契約的條款--契術師為了獲取宗主的恩惠，必須去做的事情--總是由宗主來決定。偶爾這些條款裡會包含古怪或者完全異想天開的條目，但契術師們會將這些條目與契約中其他條目一樣嚴肅對待。

　　你的角色是否有一份需要你以不尋常或者瑣碎古怪的方式，改變你的行為的契約？即使你的宗主還沒有加予你這樣的義務，還是不能說以後也仍然不會。

表格：特殊條款

| d6 | 條款 |
| --- | --- |
| 1 | 當指示下達時，你必須立刻對宗主的一名特定的敵人採取行動。 |
| 2 | 你的契約考驗著你的意志力；你不能飲酒或者類似的醉人之物。 |
| 3 | 每天至少一次，你必須在牆上塗鴉或刻下宗主的名諱或者徽記。 |
| 4 | 你偶爾需要進行古怪的儀式來維持契約。 |
| 5 | 你不能第二次穿上曾經穿過的外套；你的宗主認為這種可預測性非常無聊。 |
| 6 | 當你使用魔能祈喚時，要麼高聲呼喊你宗主的名字，要麼承擔它感到不快的風險。 |

契約印記

\--------------------

　　有些宗主有這樣的習慣--或者，更通常的情況是，愛好--以某種形式宣稱契術師在它們的掌控之下。對那些知道內情的人而言，一個契約印記會很明確的表現出面前這個個體受縛於服務這位宗主的義務。一個契術師可能能透過展示作為契約證據的印記獲得一些優勢，也可能選擇讓它隱藏在遮蔽物下（如果可能的話）來避免它帶來的難題。

　　如果你的契術師契約帶來一個契約印記的話，你對印記的感受可能取決於你和給予你印記的宗主的關係。這印記是你驕傲的源泉呢，還是你暗中引以為恥的東西？

表格：契約印記

| d6 | 印記 |
| --- | --- |
| 1 | 你其中一隻眼睛看起來和宗主的眼睛一模一樣。 |
| 2 | 每次你醒來，你臉上的一個小瑕疵都會改變位置。 |
| 3 | 你的外表顯示出疾病的症狀，但對你並沒有實際危害。 |
| 4 | 你的舌頭顏色很不自然。 |
| 5 | 你有一條返祖的尾巴。 |
| 6 | 你的鼻子在暗處會發光。 |

異界宗主

從1級起，契術師獲得異界宗主職業特性。在玩家手冊提供的職業選項之外，契術師可以選擇下列的子職業選項：天界和咒劍。
