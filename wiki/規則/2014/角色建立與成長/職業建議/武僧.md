# 武僧角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_勿將吾之沉靜看做對汝惡行之領受。汝咆哮威脅之刻，吾已計劃好四種途徑用吾之雙手摺斷汝之頸脖。_

_\--燼，花卉宗師_

　　武僧們走的是一條矛盾的道路。他們如同法師般研習他們的技藝，也如同法師般不著護具，通常不使用武器。但儘管如此，他們仍是致命的武士，他們的能力與狂暴的野蠻人或訓練有素的戰士不相上下。武僧們接受這種存於表象的矛盾，因為它是所有修道研究的核心。透過完全瞭解自身，從而去了解更加廣闊的世界。

　　一名武僧專注於自我內心的掌控，這讓他們大多脫離了社會，且更關心他們的個人經歷而非其他地方發生的事情。參與到冒險當中的武僧在英雄中是稀有且罕見的，他們為了追求完美而越過了修道院的圍牆，進入了俗世之中。

　　扮演一個僧侶角色提供了許多有趣的機會去嘗試不同的東西。為了進一步區分你的僧侶角色，你可以考慮如下小節中的選項。

修道院

　　一個在修道院學習的武僧通常是在為修道者的禁慾生活作出準備。大部分進入修道院的人都將其作為他們餘生的家，除了那些冒險者和其他有理由離開的人。對於這些人來說，修道院可以成為旅行之間的避所，或在其需要的時候作為援助來源。

　　你的修道院是怎麼樣的，它位於哪裡？參與它會讓你的角色經歷變得獨特或與眾不同嗎?

| d6 | 修道院 |
| --- | --- |
| 1 | 你的修道院是從山腰上被雕刻成型的，它位於一個若隱若現的危險道路。 |
| 2 | 你的修道院在一片浩瀚無邊的參天大樹群的樹枝高處，它位於妖精荒野。 |
| 3 | 你的修道院很早以前由一個雲巨人建立，它位於一座只能透過飛行才能抵達的雲城堡內。 |
| 4 | 你的修道院建在溫泉，間歇泉和硫磺池的火山旁邊。你經常會收到來自火矮人貿易商的訪問。 |
| 5 | 你的修道院是由侏儒建立的，如地下迷宮般充斥著大量隧道和房間。 |
| 6 | 你的修道院是在冰山之上，從冰塊之中雕琢而出的。 |

修道院標識

　　儘管武僧的生活方式中避開了物質主義和個人財產，但修道院標識在維持戒律和確認身份時仍然起到重要的作用。一些修道院戒律會對某些動物給予特殊的重視，這往往是因為這個動物與其歷史有所聯絡，或者是因為它是武僧們試圖效仿的品質的典範。

　　如果你的角色的修道院有一個特殊的戒律，你可能會在衣服上不顯眼的地方穿戴其粗糙的圖案，作為識別標記。也有可能你的標識圖示沒有物理形式，但你可以透過手勢或姿勢表達，而其他的武僧也許會知道其作何解釋。

| d6 | 修道院標識 |
| --- | --- |
| 1 | 猴子。你的戒律欣賞猴子的快速反應及穿越林木的迅捷。 |
| 2 | 龍龜。你的修道院位置在海邊，他們透過背誦古代的祈禱和提供鮮花花環來紀念龍龜，這種海洋中生活的精魂。 |
| 3 | 麒麟。你的修道院認為他們存在的意義是如同麒麟一樣守望和保護這片土地。 |
| 4 | 梟熊。 你的修道院敬仰一群梟熊家族，並已與它們一起共存了好幾個世代。 |
| 5 | 九頭蛇。你的戒律嚮往九頭蛇那樣在瞬間打出複數次攻擊的能力。 |
| 6 | 龍。一條龍曾存在於你的修道院中，它所帶來的影響在它離開之後仍然長久。 |

大師

　　你的學習很有可能是在一位向你傳授戒律的大師指導下進行的。大師塑造你對武術的理解和你對此世的態度。你的大師是位什麼樣的人？你和大師的關係又如何影響了你？

| d6 | 大師 |
| --- | --- |
| 1 | 你的大師是一個專橫的人，你必須在單人戰鬥中擊敗他才算是完成他對你的授業。 |
| 2 | 你的大師很和善，他教導你去追求和平的事業。 |
| 3 | 你的大師總是嚴厲地將你逼向極限。在一次極其殘酷的試煉中你差點失去你的一隻眼睛。 |
| 4 | 你的大師在教導你時看起來很善良，但最後卻背叛了你的修道院。 |
| 5 | 你的大師總是對你冷漠而疏遠。你經常懷疑你倆之間的關係。 |
| 6 | 你的大師是善良和慷慨的，從不挑剔你的進步。然而你覺得你從來沒有滿足他對你的期望。 |

武僧宗派

　　當你到達第三級時，武僧將獲得其武僧宗派特質。下列選項給出了在玩家手冊提供的宗派以外的額外宗派選項，醉拳宗，劍聖宗，和日魂宗。
