# 牧師角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_“成為牧師便是成為神之使者。神授之力很強大，但它往往伴隨著重要的責任。”_

_\--大主教裡格比_

　　在世間，幾乎所有信奉神明的人都沒有直接接觸過神明，因此，他們中的很多人都不知道作為牧師是什麼感受--牧師不只是虔誠的崇拜者，而且被賜予了神的力量。

　　有一個問題被爭議已久--凡人成為牧師，是因為他對某個神的虔誠信仰，從而獲得了神的青睞？還是神明發現了他的潛能並且感召他來為自己服務？說到底，也許這個答案並不重要。不論是如何成為牧師，這個世界都需要他們，如同他們和神明需要彼此。

　　如果你要扮演一個牧師角色，以下內容會提供一些方法來完善他的過去和性格。

神廟

　　大多數牧師按部就班地從成為一名教士開始他們侍奉神的生活，之後，他們意識到自己被神祝福，擁有成為一名牧師的資格。為了做好應對新職責的準備，候選牧師們通常會接受來自神廟或者其他侍神之地的牧師的教導。

　　一些神廟與世隔絕以求可以讓人們專注於祈禱，另一些則大開方便之門，服務，治療民眾。你曾呆過的神廟有什麼特色？

神廟

| d6 | 神廟 |
| --- | --- |
| 1 | 你的神廟據說是你侍奉的神的神廟中現存最古老的。 |
| 2 | 幾名同盟的神明的侍奉者們都在此接受神明的引導。 |
| 3 | 你來自一個以釀酒聞名的神廟。有的人說你聞起來就像是那裡產的酒。 |
| 4 | 你的神廟是一座堡壘，一個戰鬥祭祀的訓練場。 |
| 5 | 你的神廟和平而簡樸，充滿了菜園和樸素的牧師。 |
| 6 | 你來自外層位面的神廟。 |

紀念品

　　許多牧師的個人裝備中有一些象徵著他們的信仰，提醒他們的誓言，或者其他的，可以幫助他們不走上邪路的物品。即使這樣的物品沒有神聖力量，它也因其象徵意義而對他的主人無比重要。

紀念品

| d6 | 紀念品 |
| --- | --- |
| 1 | 聖徒的手指骨 |
| 2 | 金屬裝訂的，講述如何狩獵和毀滅地獄生物的書 |
| 3 | 豬哨子，可以讓你回憶起你謙虛而被敬愛的老師 |
| 4 | 獨角獸尾巴毛辮 |
| 5 | 講述如何最好地消滅亡靈巫師的書 |
| 6 | 據說被神祝福的符文石 |

秘密

　　沒有那個凡物的靈魂完全擺脫他人的影響或懷疑，即使是牧師也要和背離神的教導的黑暗慾望以及禁忌誘惑鬥爭。

　　如果你從未思考過你角色的這一面，看一看這個提供一些可能的表格，或者用它們來獲取靈感。你深沉，黑暗的秘密可能和你做過，或是正在做的事情有關，亦或它就根植於你對世界的看法和你在中扮演的角色。

秘密

| d6 | 秘密 |
| --- | --- |
| 1 | 一個小惡魔給你提供“忠告”，你試圖無視它，但有時它的建議的確有用。 |
| 2 | 你相信，歸根結底，神明只是有超強力量的凡物。 |
| 3 | 你承認神的力量，但是你認為大多數事情都純屬偶然。 |
| 4 | 即使你可以使用神術，你從未真正感到自己內心聖潔本質的存在。 |
| 5 | 神明因為你某些未知的錯誤而驅逐你的噩夢折磨著你。 |
| 6 | 在絕望時，你認為你不過是諸神的玩物，你憎恨他們的高高在上。 |

_邊欄:侍奉眾神，哲學觀念，原理_

　　_一名典型的牧師是某一個特定神明的侍者，他會選擇一個屬於神明的神聖領域。他的神術源於神明或是神明的神國，同時，他總會攜帶象徵著這位神明的聖徽。_

　　_一些牧師，特別是艾伯倫的牧師，侍奉整個神系而不是某個神明。在一些模組中，一名牧師可能轉而侍奉宇宙原力，例如生命或死亡，或是哲學觀念或概念，例如愛情，和平，或是九大陣營之一。在 DMG 第一章的“世界上的神”部分中提供了這些選項。_

　　_和你的 DM 聊一聊模組中的這些信仰選項，不論是神，眾神，哲學觀念還是宇宙原力。不論你最終侍奉什麼生物或是事物，為其選擇一個適合的神聖領域。如果你侍奉的存在沒有聖徽，和你的 DM 一同設計一個。_

　　_牧師的職業特性通常與神有關。如果你投身於眾神，哲學觀念或是宇宙原力，你的職業特性如同你選擇的那樣起效。將提及神的部分看作是提及你侍奉的，賜予你神術的神聖存在。_
