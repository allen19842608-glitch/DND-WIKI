# 遊蕩者角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_人們總是忘記走進一個滿是灰塵的墳墓是為了要把藏在那裡的獎品全部拿回來。戰鬥是愚蠢的，死人不能支配他們的財富。--巴納巴斯.斷刃者_

在蠻力無法完成任務，或當魔法不可用、不合適時，遊蕩者脫穎而出。由於有與秘密、詭計和詭計有關的技能，遊蕩者可以用很少其他角色可以效仿的方式在麻煩中進退。

一些轉向冒險的遊蕩者過去曾是罪犯，他們認為躲避怪物比在挑戰法律底線更為可取。另一些則是職業殺手，他們尋找有利可圖的勾當以發揮自己的天賦。還有些人僅僅只是喜歡克服任何挑戰的快感。

在冒險的過程中，遊蕩者可能會採取表面謹慎的做法（因為很少有盜賊喜歡戰鬥），同時也會表現出對戰利品的十分渴望。大多數時候，在一個盜賊的頭腦中，拿起武器對抗一個生物不是為了殺死生物而是要成為它的新主人。

下面幾節將探討作為一個遊蕩者的某些方面，你可以用它來增加你的角色的扮演程度。

罪樂感

遊蕩者的大部分工作圍繞著獲取財富和阻止他人做同樣的事情。很少有人能達到這些目標，一些盜賊不得不透過強迫自己的方法離開那條充滿誘惑力的道路--那是一種不可抗拒的、必須被滿足的需求，即使這樣做不可避免地將自己置於風險之中。

一個遊蕩者的罪樂感可能是一件得到一個現實性的物品，一件需要經歷的事情，或是在特定時刻指揮自己進行行動的方式。例如，一個遊蕩者可能不會放過任何銀製的戰利品，即使他想要搶劫的東西掛在某個城堡守衛的脖子上。另一個人不能在城市裡度過一天而不偷一兩個錢包，只是為了繼續練習。

當機會出現時，你的遊蕩者角色無法抗拒的一種誘惑是什麼，即使這樣做會給你和你的同伴帶來麻煩？

| d6 | 罪樂感 |
| --- | --- |
| 1 | 大寶石 |
| 2 | 美麗的臉龐上的微笑 |
| 3 | 你手指上的一個新戒指 |
| 4 | 有機會壓制某人的自尊心 |
| 5 | 最好的食物和飲料 |
| 6 | 新增異國情調的硬幣到您的收集 |

對手

自然，遵守法律的人必然會遇到觸犯法律的人，而很少有遊蕩者沒有被至少一張通緝令選中。除此之外，由於職業的性質遊蕩者往往會接觸犯罪分子，無論是出於選擇還是出於必要。他們其中一些人也可能成為你的對手，而且他們可能比城市的看守者更難對付。

如果你的角色的背景還沒有包括這樣的人物，你可以和你的 DM 一起合作，找出一個對手出現在你人生中的原因。也許你已經被一個想要利用你的邪惡目的的人監視了一段時間，現在你已經知道了。這樣的事件可能是即將到來的冒險的基礎。

你的遊蕩者角色是否有一個對手，也碰巧是個罪犯？如果是，這種關係如何影響你的生活？

| d6 | 對手 |
| --- | --- |
| 1 | 海盜船長站在你曾經的船上，對於你所說的前進，他稱做叛變。 |
| 2 | 一個間諜大師因為你給的錯誤資訊，導致了錯誤的目標被暗殺 |
| 3 | 當地盜賊工會的主人，他想要你加入組織或離開城鎮 |
| 4 | 用非法手段獲得傑作的藝術品收藏家 |
| 5 | 一個銷贓犯用你們當信使來發起違法聚會 |
| 6 | 你曾經投注的非法格鬥場的老闆 |

恩人

在得到別人幫助之前，少有遊蕩者能在人生中走得很遠，但這也意味著此後他欠了某個恩人一大筆債。

如果你的角色的背景故事還沒有來得及加入這類人物，你可以和你的 DM 合作，確認為什麼一個恩人出現在你的生活。也許你從你的恩人為你所做的事中受益，卻不知道是誰幹的直到現在。過去誰幫助過你？無論你當時是否知道，那你欠那個人什麼作為回報？

| d6 | 恩人 |
| --- | --- |
| 1 | 一個走私犯阻止你被捉，但這樣做的時候損失了一批貴重貨物。 |
| 2 | 乞丐王多次把你從追蹤者身上隱藏起來，在為未來考慮回報。 |
| 3 | 一個地方法官曾把你關在監獄裡，以獲取關於一個強大的犯罪領主的資訊。 |
| 4 | 你的父母用他們的積蓄在你年輕的時候救了你，現在窮困潦倒了。 |
| 5 | 一條龍在有機會的時候沒有吃掉你，作為回報，你答應為它預留一些寶貴的財富。 |
| 6 | 德魯伊曾經幫助你走出困境，現在你看到的任何隨機的動物都可能是捐助者，也許是來要求回報的。 |

遊蕩者泛型

當你到達第3級時，遊蕩者將獲得其遊蕩者泛型特徵。下列選項給出了在玩家手冊提供的泛型以外的額外泛型選項：調查員，策士，斥候，遊蕩劍客。
