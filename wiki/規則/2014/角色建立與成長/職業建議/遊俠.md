# 遊俠角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_為了守護文明，我一生大多數的時間都遊走於它的邊界來守護它。不要以為我不向你的國王效忠，我的貢獻就比所有保護他的騎士加起來少。_

　　　　　　　　　　　　　　　　　　　　 _\--索維里斯_

遊俠是一群無憂無慮的漫遊者和搜尋者，他們出沒於文明世界的邊緣，抵禦外域居民。這是一份無償的工作，自從他們的事業鮮有人理解且不計回報。而且遊俠們恪盡職守，堅信他們的工作會讓世界變得安全。

與文明世界之間的關係會體現每個遊俠的個性和經歷。有些遊俠視自己為不受王權約束的，文明邊境的法律與正義的使者。其他則是完全規避文明社會的生存主義者。當他們居住和遊歷於世界上危險的荒野之地時，他們會為了保護自己而獵殺怪物。如果他們的所作所為對他們躲避的王國和文明地區有益，他們也照做不誤。

如果你想創造或者遊玩一個遊俠角色，以下選項能提供一些辦法來豐富角色和增加你的表演經驗。

世界觀

一個遊俠的世界觀開始（有時候結束）於角色對文明種族和他們的領地的看法。有些遊俠對文明抱有一種根深蒂固的偏見，當其他人同情那些他曾發誓要保護的人時，即使是在戰場上，它也有可能體現出兩個遊俠之間的不同。事實上，為了那些看到過自己的卓越技藝並能從他們的力量中受益的人，遊俠完全可以自作主張。然而即便如此，沒有兩個遊俠會以同一種方式來體現他們的特性。

如果你還未想好你的角色世界觀的具體內容，可以考慮透過一個簡短觀點（如下表所例）的概述來提取要點。你的情感如何影響你的行為？

世界觀

| D6 | 觀點 |
| --- | --- |
| 1 | 城鎮和城市是那些無法自我生存的人最好的去處。 |
| 2 | 文明進步的最好辦法就是阻止混亂，但它的範圍必須被監視。 |
| 3 | 城鎮和城市是必要的，可一旦荒野的超自然威脅解除了，我們將不再需要他們。 |
| 4 | 城牆是為那些當別人還在為和平奮鬥自己卻躲在後面的懦夫準備的。 |
| 5 | 剛開始拜訪一處城鎮還不錯，但沒過幾天我就會因感受到不可抗拒的呼喚而回歸山野。 |
| 6 | 城市會因將族群從野外的艱難挑戰中隔離開來而產生弱點。 |

家鄉

所有的遊俠，無論他們如何開始從事自己的專業，對自然世界和多樣的地貌都會有一種強烈的聯絡。對於一些遊俠而言，荒野是他們成長的地方，也是他們出生於此或者早年移居於此的結果。對於其他遊俠而言，文明社會是原本的家，而荒野是他們的第二個家。

考慮你角色的背景故事並決定最想家的地方，以及你是否出生在那裡。對於你個人來說那個地方叫什麼名字？它是否影響你學習什麼樣的法術？你在那裡的經歷是否決定了你的宿敵？

家鄉

| D6 | 家鄉 |
| --- | --- |
| 1 | 你曾巡邏過一片被些許穿插於其中的暗影墮界所汙染和毀壞的遠古森林。 |
| 2 | 作為遊牧族群的一份子，你的荒野生存技藝爐火純青。 |
| 3 | 你的早期在幽暗地區的生活讓你對毆打別人有了充足的準備。 |
| 4 | 你居住在一片澡澤的邊緣，那裡被一種水生的存在所威脅。 |
| 5 | 因為你成長於山頂，尋找最好的路來穿山越嶺是你的本能。 |
| 6 | 你漫遊過北境，知道如何保護自己並在冰天雪地裡生存。 |

宿敵

每個遊俠都有宿敵。宿敵的決定因素可源自於角色早期的特殊事件，或者完全取決於選擇。

什麼鞭策你選擇了一個特殊的敵人？做這個選擇是因為傳統還是好奇心，或者仇恨？

宿敵

| D6 | 敵人 |
| --- | --- |
| 1 | 為了你的敵人曾犯下的大罪，你在自然的支援下需求復仇。 |
| 2 | 你的祖先或者前輩曾和某種生物作戰過，現在輪到你了。 |
| 3 | 你對你的敵人沒有絲毫恨意。你只是像一個獵人追蹤獵物一樣靠近別人。 |
| 4 | 你沉迷於搜尋你對敵人，你還蒐集與它相關的傳說和歷史書籍。 |
| 5 | 你從你的敵人身上搜集標誌以來紀念你的每一次屠殺。 |
| 6 | 你尊重你所選擇的敵人，而且你視你的戰鬥為各項技巧的測試。 |
