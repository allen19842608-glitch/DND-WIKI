# 戰士角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_你話講完了告訴我一下。_

　　　　　　　　　　　　 _\--託達克_

在 DND 世界裡所有的冒險者中，戰士可能有著最大的分歧。一方面，沒有兩個戰士會用同一種方式來體現職業的一種特性：比如他們的武器，鎧甲和戰鬥方式會顯得大相逕庭。另一方面，無論他們使用的是何種武器和戰鬥方式，每一個戰士心中都有一種相同的信念：傷害別人好過被別人傷害。

雖然有些冒險中的戰士是為了榮譽和財寶而冒險，但也有戰士會為了他人的利益而著想。他們會為了社會、村鎮和團體的安定幸福而努力且不顧自己的安危。即使金子就在眼前，對於大多數戰士來說真正的獎勵也是金子能讓敵人們走向滅亡。

接下來一些提供的選項能給你的戰士角色一些深度和個人特徵。

紋章標誌

戰士經常會為了某些緣由而戰鬥。比如一些戰士會為了王國的利益而和怪物戰鬥，一些只是為了尋求個人的榮耀。無論是那種情況，一個戰士通常會展示一個標誌來體現這些原因，你既可以從一個王國或者貴族那裡獲得標誌，也可以僅憑自己的興趣製作一個裝飾。

你的角色可以與一個組織或者一件事情的起因聯絡在一起，也可以為了某個偉大的目的而旅行。如果這些都不是你想要的，你也可以考慮用紋章標誌來象徵你的內在本質或者訴說你在這個世界的目標。

表格：紋章標誌

| D6 | 標誌 |
| --- | --- |
| 1 | 一條佇立於綠野上的狂躁金龍，象徵著勇猛和對財富的追求 |
| 2 | 於雲端緊握閃電的風暴巨人之拳，象徵著憤怒與力量 |
| 3 | 在城堡門前交叉的綠色對劍，象徵著城市或者王國的守衛 |
| 4 | 一顆被匕首刺穿的顱骨，象徵著你為你的敵人帶來的毀滅 |
| 5 | 火環裡的鳳凰，象徵著不屈的靈魂 |
| 6 | 在黑幕中從臥刃落下的三滴血，象徵著三名你發誓要剷除的敵人 |

導師

有些戰士天生就是能從戰場上存活下來的鬥士。其他則需要在年輕時就在軍隊或者其他軍事組織裡磨鍊戰鬥技藝的基礎，當他們被組織的導師教導時。

以下列舉的三種泛型的戰士都會接受來自於陪同的經驗豐富的人的一對一技巧訓練。取決於學生的背景，導師曾經或一直都是某個戰鬥領域的佼佼者。

如果你決定了你的角色曾有一個獨特的導師，那麼他會特別在什麼地方呢？你是會模仿你的導師那樣戰鬥，還是會取其精華，棄其糟粕，自成一派呢？

表格：導師

| D6 | 導師 |
| --- | --- |
| 1 | 角鬥士 你的導師是一個在某個地區為了自由而戰的，或者為了獲取錢財和名望甘願成為角鬥士的奴隸。 |
| 2 | 軍人 你的導師在一隊士兵中工作且瞭解團隊合作。 |
| 3 | 城市守衛 把控群眾和保衛和平是你的導師的強項。 |
| 4 | 部落勇士 你的導師成長於一個為某人幹架是家常便飯的部落 |
| 5 | 街頭打手 你的導師擅長城市作戰，沉默且高效的近身戰鬥。 |
| 6 | 武器大師 你的導師會幫助你，告訴你如何高效的使用你選擇的武器。 |

鮮明風格

很多戰士會透過展現和完善一種特別的戰鬥風格和方法來從自己的同類中區分自己。雖然這種風格可能是戰士長期積累的個人特點，但事情並不總是這樣，畢竟在危急關頭，一味貫徹自己的戰鬥風格就顯得沒必要了。

你有會反應在你的生活中的戰鬥風格嗎？或者是戰鬥時某些內在的東西？

表格 鮮明風格

| D6 | 風格 |
| --- | --- |
| 1 | 簡練 你的行動精準優雅，收放自如，從沒有多餘的動作。 |
| 2 | 野蠻 你的攻擊猶如呼呼作響的錘子，要別人粉身碎骨血沫橫飛。 |
| 3 | 狡猾 你能夠在一瞬間做出攻擊，喜歡用小計謀獲得優勢。 |
| 4 | 從容 你在戰鬥中很少出汗且喜歡及時行樂。 |
| 5 | 活力 你在戰鬥中又唱又笑彷彿你的靈魂都在高漲，手握武器，面對強敵是你最快樂的時刻。 |
| 6 | 陰險 你在戰鬥中會怒視和譏諷對手，你尤其享受在擊敗對手後羞辱他們的感覺。 |
