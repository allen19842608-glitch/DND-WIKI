# 術士角色扮演指引 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

_真正的力量是與身俱來的，非主流才需要學習與鍛鍊。_

_Practice and study are for amateurs. Ture power is a brithright._

_\--__海涅特 提亞馬特後裔_

_\--Hennet, scion of Tiamat_

介紹

神秘起源 ARCANE ORIGIN

\----------

一些術士知道他們的力量源自何處，基於他們的能力如何展現。其他術士只能推測，因他們的力量以不固定的原因及形式展現。

你的角色知道你的魔法力量嗎？它是否與某個遙遠的親戚，一個宇宙事件，或者是某種機緣巧合聯絡在一起？如果你的術士不知道他的力量是從哪來的，你的 DM 可以使用以下表格（或選擇一個起源），並在冒險中向你揭示它。

神秘起源 ARCANE ORIGIN

| d6 | 起源 Origin |
| --- | --- |
| 1 | 你的力量來自於你家族的血統。你與某些強大的生物有關，或你繼承了祝福或詛咒。 |
| 2 | 你是另一個存在的本位面的化身。 |
| 3 | 一個強大的實體進入了這個世界。它的魔力改變了你。 |
| 4 | 你的出生被古代的經文所預言，它預言了你的力量將被用來達到可怕的目的。 |
| 5 | 你是幾代人精心培育的產物。 |
| 6 | 你是在一個鍊金術士的大桶裡做成的。 |

反應 REACTION

\----------

當一個新的術士進入這個世界，無論是在出生的時候，還是當他的力量變得明顯的時候，這個事件的後果很大程度上取決於它的目擊者對他們所看到的事物的反應。

當你的魔法力量出現時，你周圍的世界是如何反應的？旁人是支援，害怕，還是介於兩者之間？

| d6 | 反應 Reaction |
| --- | --- |
| 1 | 你的力量被你周圍的人視為一種巨大的祝福，你也被期望用它們來為身邊人服務。 |
| 2 | 你的力量在他們變得明顯的時候造成了毀滅，甚至死亡，你被當作罪犯對待。 |
| 3 | 你的鄰居憎恨你，害怕你的力量，他們離你躲得遠遠的。 |
| 4 | 你開始注意到有一個邪惡的邪教組織，他們計劃著利用你的能力。 |
| 5 | 你周圍的人都認為你的力量是對你的家庭的一種詛咒，因為過去的罪行。 |
| 6 | 據傳，你的力量與一個古老的瘋王、在一個世紀前的血腥起義中有某些關聯。 |

超自然標記 SUPERNATURAL MARK

\----------

| d6 | 標記 Mark |
| --- | --- |
| 1 | 你的眼睛是一種不尋常的顏色，比如紅色。 |
| 2 | 你的腳上有一個額外的腳趾。 |
| 3 | 你的一隻耳朵明顯比另一隻大。 |
| 4 | 你的頭髮長得驚人。 |
| 5 | 當你咀嚼的時候，你會不斷地皺起鼻子。 |
| 6 | 某天你的脖子上出現一個紅色斑點，但一小時後就消失了。 |

魔法跡象 SIGN OF SORCERY

\----------

正如世人所知道的，一些術士在控制他們的法術時比其他人更出色。有時，一種魔力的瘋狂表現，來自於一個法術的魔法師。但是，即使當一個人的魔法按計劃進行時，演員的表演通常也會有一個明顯的跡象，讓人清楚地知道魔法能量是從哪裡來的。

當你的術士角色施展咒語時，會顯示出魔法的跡象嗎？這個符號與你的法術起源，或其他方面有關，還是一個看似隨機的現象？

| d6 | 跡象 SIGN |
| --- | --- |
| 1 | 你用泰坦的聲音來傳遞你法術的言語成分。 |
| 2 | 在你施展魔法之後的一段時間裡，你周圍的區域會變得黑暗而陰鬱。 |
| 3 | 你在施放一段時間的法術和之後的幾秒內大量出汗。 |
| 4 | 你的頭髮和衣服在你發出咒語的時候，會像是被微風吹過一般。 |
| 5 | 如果你在施放一個咒語，你會在空氣中上升6寸，然後輕輕地浮在空中。 |
| 6 | 當你開始鑄造時，虛幻的藍色火焰纏繞在你的頭上，然後突然消失。 |

術法起源 SORCEROUS ORIGINS

一級起，一名術士獲得了一種術法起源的特性。除了玩家手冊（Player's Handbook）的內容外，可額外為一名術士提供下列選項：神聖之魂 Divine Soul，暗影魔法 Shadow Magic，和風暴巫術 Storm Sorcery。
