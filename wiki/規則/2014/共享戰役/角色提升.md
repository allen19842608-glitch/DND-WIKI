# 角色提升 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

**角色提升 Character Advancement**
在共享戰役中，玩家不以經驗值為升級的條件，改而使用經驗點來升級。這一系統將激勵每一個角色（與其玩家）參與到一場遊戲的程序中去。

一個角色在冒險者將根據其進行的冒險設計的時間獲取經驗點，以1 小時=1經驗點的方式換算。請注意這裡的獎勵是基於冒險的設計遊玩時間，而非實際在桌上游玩的時間。這一獎勵在冒險完成時才生效。打個比方，如果你完成了一場設計時2 小時的冒險，你將獲得2點經驗點，即使你的團中花費了超過2個小時去遊玩完成它也是2點。

此外，如果一個角色完成了一場為更高 階段 Tier 設計的冒險，那個角色將可以額外獲得1點經驗點。舉例來說，如果一個2級角色完成了一場為6級設計的冒險（設計時2 小時），這個角色將獲得3點經驗點。

根據遊戲時間來衡量經驗獎勵似乎的一種奇怪的方式，但這一概念與共享戰役的運作方式是一致的。若某個角色玩了10個小時，它與其他10 小時角色獲得的經驗點數量是相同的，無論該角色是在討伐巨龍，還是一直蟄伏在酒館裡竊取情報。這種方法可以確保玩家喜歡的風格既不會受到懲罰，也不會得到獎勵。無論玩家是專注於角色扮演和社互動動，還是在戰鬥中擊敗怪物，抑或是尋找巧妙的方法避免戰鬥，該系統都會給予角色相應的獎勵。

**使用經驗點 Using Checkpoints**
獲得下一級所需的經驗點數量取決於升級前角色的等級：

-   在1~4級時，你只需要4點經驗點就足以去提升至下一級了。
    
-   在5級或更高等級時，你需要8點經驗點才能提升至下一級。
    

當一次遊戲程序結束時，如果角色有足夠升級的經驗點，那角色必須得在此升級。而升級後多出來的經驗點可被用於下次有升級機會的時候使用。
