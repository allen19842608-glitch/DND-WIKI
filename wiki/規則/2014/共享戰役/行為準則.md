# 行為準則 (2014 Legacy)

> [!WARNING] 本頁保留《珊娜薩的萬事指南》的 2014 條文與表格；如與現行規則衝突，以採用的規則版本為準。

**行為準則 Code of Conduct**

核心規則書中一而再，再而三的強調，DND 的遊戲程序中最重要就是讓所有玩家都能獲得到樂趣。為了保持這一目標，在一場共同戰役中制定一份行為準則將會是個很好的注意。畢竟大家都不一定會與自己熟悉的人一同在同桌上游玩共享戰役，因此制定基本的行為準則是很有幫助和必要的。

進一步來說，共享戰役中的每個人都有責任讓其他人都能度過愉快的時光。如果有人因其他人的行為的感到被冒犯、被輕視、或被欺凌，那麼大家一起愉快玩耍的初衷就落空了。

共享戰役的行為準則可以參考其他組織或地點用的類似檔案。此外，因為 DM 和 PL 的特殊關係，可能還需要新增一點特殊的準則。作為起步點，請參考以下摘自 **冒險者聯盟 Adventurers League** 行為準則的材料。

在一場遊戲程序中，參與者應當：

-   聽從 DM 的指引，並儘可能不要與 DM 或其他玩家爭論規則。
    
-   讓別的玩家也能說上話，並允許每個玩家都能從 DM 那邊得到反饋。
    
-   避免太多與冒險無關的討論。
    
-   阻止他人使用社交媒體欺凌、羞辱、或恐嚇其他參與者。
    
-   讓 DM 或戰役的管理員瞭解破壞性或攻擊性行為，以便採取適當措施。
