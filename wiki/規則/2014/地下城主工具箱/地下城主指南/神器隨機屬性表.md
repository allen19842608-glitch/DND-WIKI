# 神器隨機屬性表 (Artifact Properties，2014 Legacy)

> [!WARNING]
> 本頁只適用於引用 2014《地下城主指南》神器屬性表的物品，不與 2024 版表格混用。

三張表原始出處為 *Dungeon Master's Guide* (2014) 第七章「Treasure」→「Artifacts」→「Artifact Properties」，p.219–220。本機已收錄該版英文鏡像；〈畢格比裨益臂鐲〉僅引用這些表，並非表格來源。

## ⚙️ 規則條文 (Rule Text)

神器可有額外增益或減益屬性，由 DM 從對應表選擇或擲 d100 決定。下列三表供引用它們的 2014 版物品使用；「00」代表 100。除表列的單次觸發外，效果均以與該神器同調期間為前提。（來源：*Dungeon Master's Guide* (2014)，p.219–220，Artifacts > Artifact Properties。）

### 弱效增益屬性 (Minor Beneficial Properties)

| d100 | 屬性 |
| :---: | :--- |
| 01–20 | 獲得 DM 選定的一項技能熟練。 |
| 21–30 | 免疫疾病。 |
| 31–40 | 不會陷入魅惑或恐慌狀態。 |
| 41–50 | 對 DM 選定的一種傷害類型具有抗性。 |
| 51–60 | 可以用一個動作，透過神器施展 DM 選定的一道戲法。 |
| 61–70 | 可以用一個動作，透過神器施展 DM 選定的一道一環法術。每次施展後擲 1d6；結果為 1–5 時，直到下次黎明前都不能再透過此屬性施展該法術。 |
| 71–80 | 同 61–70，但改為一道二環法術。 |
| 81–90 | 同 61–70，但改為一道三環法術。 |
| 91–00 | 護甲等級獲得 +1 加值。 |

### 強效增益屬性 (Major Beneficial Properties)

| d100 | 屬性 |
| :---: | :--- |
| 01–20 | DM 選定的一項屬性值提高 2，最高至 24。 |
| 21–30 | 若你至少有 1 點生命值，則在自己的每回合開始時恢復 1d6 點生命值。 |
| 31–40 | 以武器攻擊命中時，目標額外受到 1d6 點傷害，傷害類型與該武器相同。 |
| 41–50 | 步行速度增加 10 呎。 |
| 51–60 | 可以用一個動作，透過神器施展 DM 選定的一道四環法術。每次施展後擲 1d6；結果為 1–5 時，直到下次黎明前都不能再透過此屬性施展該法術。 |
| 61–70 | 同 51–60，但改為一道五環法術。 |
| 71–80 | 同 51–60，但改為一道六環法術。 |
| 81–90 | 同 51–60，但改為一道七環法術。 |
| 91–00 | 不會陷入目盲、耳聾、石化或震懾狀態。 |

### 弱效減益屬性 (Minor Detrimental Properties)

| d100 | 屬性 |
| :---: | :--- |
| 01–05 | 對抗法術的豁免檢定具有劣勢。 |
| 06–10 | 與神器同調後首次觸碰一顆寶石或一件珠寶時，該物件的價值減半。 |
| 11–15 | 距離神器超過 10 呎時陷入目盲狀態。 |
| 16–20 | 對抗毒素的豁免檢定具有劣勢。 |
| 21–30 | 散發酸臭氣味，最遠在 10 呎外可察覺。 |
| 31–35 | 你周圍 10 呎內的所有聖水都被摧毀。 |
| 36–40 | 身體不適；使用力量或體質的屬性檢定與豁免檢定均具有劣勢。 |
| 41–45 | 體重增加 1d4 × 10 磅。 |
| 46–50 | 外貌依 DM 的決定改變。 |
| 51–55 | 距離神器超過 10 呎時陷入耳聾狀態。 |
| 56–60 | 體重減少 1d4 × 5 磅。 |
| 61–65 | 失去嗅覺。 |
| 66–70 | 你周圍 30 呎內的非魔法火焰都熄滅。 |
| 71–80 | 你周圍 300 呎內的其他生物無法短休或長休。 |
| 81–85 | 你觸碰的非生物植物受到 1d6 點暗蝕傷害。 |
| 86–90 | 你周圍 30 呎內的動物都對你抱持敵意。 |
| 91–95 | 每天必須攝取正常份量六倍的食物與飲水。 |
| 96–00 | 你的缺點依 DM 決定的方式加劇。 |
