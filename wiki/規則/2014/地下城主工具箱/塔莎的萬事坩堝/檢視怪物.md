# 檢視怪物

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**檢視怪物 Monster Research**

冒險者可以檢視怪物，來確定怪物更喜歡或偏好什麼事物。怪物檢視表提供了某些生物型別該使用哪些技能來瞭解其偏好的建議。使用相關技能進行屬性檢定的 DC 為 10 + 目標生物的挑戰等級。

**怪物檢視**

| **型別** | **建議技能** |
| --- | --- |
| 異怪 Aberration | 奧秘 |
| 野獸 Beast | 馴獸、自然、生存 |
| 天族 Celestial | 奧秘、宗教 |
| 構裝生物 Construct | 奧秘 |
| 龍類 Dragon | 奧秘、歷史、自然 |
| 元素生物 Elemental | 奧秘、自然 |
| 妖精 Fey | 奧秘、自然 |
| 邪魔 Fiend | 奧秘、宗教 |
| 巨人 Giant | 歷史 |
| 類人生物 Humanoid | 歷史 |
| 怪獸 Monstrosity | 自然、生存 |
| 泥怪 Ooze | 奧秘、生存 |
| 植物 Plant | 自然、生存 |
| 亡靈 Undead | 奧秘、宗教 |
