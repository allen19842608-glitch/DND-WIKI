# 權貴

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 可選規則與 DM 指引；採用與否由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

**權貴 Aristocrat**

> _強盜之國有句話，大意是 "貪財之人在收藏家來時最為親切。"我不記得具體措辭了，但它用在這很應景。
> _
> 
> ——塔莎

你的團隊有幸為一些權貴效力。為了獲得金錢、力量與政權，你的贊助人借你們的手做些髒活來推進他們的計劃；或是派遣你們作為求和使節前往敵人的領地。你們的贊助人是一個強大的盟友，作為你的忠心與謹慎的回報，他為你們提供難以用金錢衡量的恩惠。
**權貴的型別 Types of Aristocrats**
從足智多謀的商業世家掌權者到不朽的術士女皇，每一位權貴都掌握著的龐大的財富與權力，並渴望更多。一位男爵可能希望奪回他過去所擁有的影響力；而一位商業王國的新首領尋求著讓他們的財富更上一層樓的機遇。與這些贊助人結盟，你將從他們的雄心壯志中獲得巨大的利益。
從權貴型別表格中擲骰或是選擇，以確定你們團隊隸屬於哪種權貴。
**權貴型別 Aristocrat Types**

| **d6** | **權貴型別** |
| --- | --- |
| **1** | **當地領主 Local Lord。**這位小貴族堅信權力與威望就在前方，他會抓住任何機會提升地位。 |
| **2** | **商業領袖 Merchant Mastermind。**對於一個生意遍及世界的商業家族頭領來說，名譽、財富與權力本就是三位一體的。 |
| **3** | **雲遊的王子 Nomadic Princeling。**沒有什麼比財寶更加吸引這個小王子了。他龐大的商隊尾隨著他的轎子，蔓延到視線之外。 |
| **4** | **背叛者 Double Dealer。**這位貴族家族的領袖為了個人利益或是其他原因，已經背叛了他的君主和他的國家。 |
| **5** | **野心勃勃的創業者 Ambitious Entrepreneur。** 作為一筆龐大財富的唯一繼承人，這位企業家尋求著能達成國際間、全球乃至位面間商業合作的盟友，公共增長他們的財富。 |
| **6** | **未來的統治者 Future Ruler。**這位年輕的貴族註定要權御一方，但目前他心血來潮的想法是詭變而危險的。 |

**權貴特權 Aristocrat Perks**
當你們的團隊贊助者是權貴時，你們獲得以下特權。
**費用 Expenses。**你的贊助人為你支付你在工作中產生的各類費用。你需要核算你的花費並解釋一些非常規的支出，但差旅支出、尋常裝備開銷、基本消費等無需多言。
**免疫 Immunity。**只要你還受贊助人的青睞，在他的地盤上你幾乎免受法律的束縛。當你在執行贊助人的指令時，你有很大的餘地選擇你的手段，法律不再是你的阻礙。但犯下嚴重的罪行，尤其是與工作無關或不必要的罪行，會使你失去贊助人的恩寵。
**奢華生活 Luxury。**作為優秀地完成工作的回報，你的贊助人決定邀你到他家或是其他奢華的府邸，款待你一小段時間。這樣的時光一般每年不超過兩週，在此期間你將免費享受貴族的生活方式。你基本上可以獲得隨心所欲的放鬆時間，但必要時你也必須保衛那裡。需要注意的是，窮困潦倒的客人（或徹頭徹尾的破壞狂）很少能再次收到邀請。
**報酬 Salary。**你被權貴僱傭，每日可獲得1金幣的報酬或是足以維持儉樸生活的收入。DM 會根據贊助人的性格、工作型別和僱傭時間的長短而調整你的報酬。
**權貴聯絡人 Aristocrat Contact**
除了少數例外，權貴們更傾向於差遣他人與他的僱工溝通。因此你的聯絡人是一位贊助人選擇的中介。
從權貴聯絡人表格選擇或擲一個來決定是什麼樣的人處理你與權貴的關係。

| **d6** | **聯絡人** |
| --- | --- |
| **1** | **尋常聯絡人 Common Contact。**一個決心獲得官銜的僕從擔當你贊助人的中介。 |
| **2** | **專家 Professional。**一個頭腦清醒的顧問或是贊助人生意的管理者指揮著你，以確保你那莽撞的僱主的安全。 |
| **3** | **家族調解者 Family Peacemaker。**你的贊助人指派了一位天真的權貴，他希望你協助他維繫家族成員間的岌岌可危的關係，而不是贊助人的首要任務。 |
| **4** | **親密關係者 Intimate Connection。** 你的聯絡人是贊助人出身平平的知己或愛人，他指導你以最大化贊助人的家族利益為目的進行工作。 |
| **5** | **出局的家人 Insider Outside。**一位被逐出家族的貴族被你的贊助人信賴並指派為聯絡人，儘管已被流放，他還是把家族的利益放在首位。 |
| **6** | **入局的外人 Outsider Inside。** 一個神秘的存在掌控著一個貴族家族的命運。他透過你的贊助人僱傭你，利用你操控這個被選中的家族數世紀的命運軌跡。 |

**權貴的僱傭 Aristocrat Retainers**
權貴們為達成他們在商業、政治、罪謀或個人領域的目的而尋找代理人。你或許是單純為了報酬而聽命於他們；或是為了獲取某些資訊、為了接觸某個特殊的工具、為了獲得政治影響力；亦或者你只是一個地位較低家族成員，遵從領導者的旨意行事。無論你出身何處、有何技能和社會地位如何，你的贊助人都有足夠的遠見和想像力，為你找到用武之地。
權貴僱傭者身份表提供了一些你們能在贊助人麾下扮演的身份的建議，以及每個身份一般相關聯的背景。

| --- | --- |

| 保鏢 Bodyguard | 罪犯、平民英雄、貴族、化外之民、士兵 |
| 線人 Informant | 騙子、罪犯、藝人、士兵、流浪兒 |
| 家臣 Home Staff | 藝人、公會工匠、水手、士兵、流浪兒 |

**權貴的任務 Aristocrat Quests**
每一封你收到的贊助人的信件都會提出一個不同型別的任務。有時你會充當使者參與一次極難談妥的商業談判，下次你便跋山涉水為宴會採擷一種贊助人喜愛的花朵。昨日的盟友可能成為明天的對手，你的敵人是無窮無盡的。唯一不變的事情便是，你的贊助人的奇思妙想總會與日俱增。
權貴任務表中給出了幾種你高貴的贊助人可能委派的任務
**權貴任務表 Aristocrat Quests**

| **d6** | **任務** |
| --- | --- |
| **1** | **貴族聯盟 Noble Union。**你斡旋於多個貴族派系之間，聯合原本相互敵視的家族。 |
| **2** | **商業突破 Business Breakthrough。**你尋找並謀求贊助人視為財運鑰匙的奇蹟。 |
| **3** | **妨礙競爭對手 Sabotage Rival。**你染指敵對貴族家族的生意和產業，破壞他們的政治上或是專業領域的事業。 |
| **4** | **遺失的傳承 Lost Lineage。**你要查證一個貴族家族被遺忘的一支血脈，或是證明某人並不具備貴族的血統。 |
| **5** | **權貴的起源 Origin of Nobility。**你揭示某些人被晉升成貴族的秘密以及他們是如何很快達成晉升的。 |
| **6** | **新貴的誕生 The New Nobility。**你重現了使某些家族得以崛起並獲得貴族地位的重大事件。 |
