# 軍事組織

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 可選規則與 DM 指引；採用與否由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

**軍事組織 Military Force**

> _戰爭本身野蠻不堪。在一個理智世界裡，應該用能造成世界末日的魔法或者讓靈魂驅動的巨型爬行動物打一場能重塑大地的大亂鬥來解決衝突。這才合理，你懂吧。
> _
> 
> _——塔莎_

你的團隊是服務於一支規模較大軍事力量計程車兵小組，專門用於執行戰鬥任務或其他危險工作。你們可以是一幫僱傭兵，一支特種部隊或是一隊正規步兵。也許你們會保護一個民族免受怪物的襲擊，或許你們會在一場據稱已經結束的戰爭背後進行秘密鬥爭，又或者你們將作為處於文明邊緣的國家軍事力量來保衛邊疆和開疆擴土。
**軍事組織型別 Types of Military Forces**
軍事力量代表各種有組織的戰士團隊。他們可以是一支遵守紀律的國家常備軍，可以是一支由王國軍艦組成的海軍，也可以是一群帶來毀滅的戰士和魔獸。一個王國的軍隊可能是一支有條不紊的部隊也可能是一群嗜血成性的暴徒。
從軍事組織表格中擲骰或是選擇，以確定你們團隊隸屬於哪種軍事組織。
**軍事組織型別 Military Forces Type**

| **d6** | **軍事組織型別** |
| --- | --- |
| **1** | **常備軍 Standing Army。**一支紀律嚴明且結構嚴謹的常備軍作為一支衛隊隸屬於一個省份或一整個國家。嚴格的指揮層確保著部隊各部門之間的協調。 |
| **2** | **僱傭兵團 Mercenary Company。**一群飽受無數激戰折磨的頑強老兵，他們為僱主服務是為了金錢而不是出於忠誠 |
| **3** | **遠徵軍 Expeditionary Force。**這支軍隊遠離家鄉，在敵後作戰或步入荒野。這隻部隊必須行動迅速，自給自足，無論是使用外交手腕還是先下手為強他們都以確保部隊續存為己任。 |
| **4** | **部落 Horde。**這個部落如同一股自然之力，它缺乏紀律而由兇猛來彌補。它沒有嚴格的指揮階層，而是像小股部隊組成的金字塔一樣運作。部落指揮官忠於他們之上的更強者，最高階指揮官則是軍閥。 |
| **5** | **位面徵召兵 Planar Conscripts。**這支部隊在多元宇宙的遙遠位面上爭奪宇宙利益，或與物質位面上的與外來入侵者作鬥爭。其中的戰士包括在血戰中被強徵計程車兵，殘酷的尤格羅斯魔僱傭兵陣營中的炮灰，或抵禦邪魔入侵的榮耀天族。 |
| **6** | **天空戰士 Sky Warriors。**這支軍事部隊由有翼生物，魔法飛行者，以及飛艇構成的空中艦隊。傳統的防禦措施無法有效抵抗空中攻擊，因此天空戰士往往都是令人恐懼的國度或者昂貴而令人垂涎的僱傭軍。 |

**軍事組織特權 Military Forces Perks**
當你們的團隊贊助者是軍事組織，你們獲得以下特權。
**軍械庫 Armory。**你們可以在你軍事組織的設施裡以20％的折扣購買非魔法武器和盔甲。DM 可以讓你們購買魔法物品，但沒有折扣。
**指揮鏈 Chain of Command。**你們是為你們提供命令的軍隊階級的一部分。如果你在自己所屬的國家闖禍，你會被你的長官問話，而不是當地的執法部門。
**授權訪問 Official Access。** 你們在軍隊中的等級可以準許你進入平民無法進入的地方。 在指揮官的允許下，你們可以進入危險的訓練場或軍事設施，例如軍隊的地區司令部或絕密情報庫。你還可以要求指揮官授予你以他們名義行事的許可權或提供與指揮系統中更高階別的專家或領導聯絡的通道
**命令 Orders。**你們在一名指揮官的指導下執行任務，他期望你們絕對服從。這些任務有明確而精確的目標來指引你們冒險。在極少數情況下，你會被委託開放式的任務讓你們在執行任務時有餘地。
**薪水 Salary。**團隊中的每個成員都獲得固定薪金或軍隊的部分戰利品。金額取決於你的組織及在組織中的職位，但是至少你能享受到簡樸的生活方式。你將獲得少量薪水（每天少至1 sp）以及軍事基地的食物和住房。或者，你每天會收到1 gp 的收入，但要靠這筆錢來維持食宿。等級越高，薪酬越高。作為一名軍官，你將保持舒適的生活方式。
**軍事組織聯絡人 Military Force Contact**
你在軍事集團之中的主要聯絡人是您的上級軍官，上級軍官是向你下達命令並對你的成敗負責的人。
從指揮聯絡人表格選擇或擲一個來決定是什麼樣的人處理你與軍事組織的關係。
**指揮聯絡人 Commanding Contact**

| **d6** | **聯絡人** |
| --- | --- |
| **1** | **久經考驗的老兵 Tested Veteran。** 你的指揮官是一個飽經戰場的軍官，他曾在戰鬥中直面恐懼。他依靠某種東西來減輕記憶或傷口造成的痛苦，從他喜歡作家的散文到用來分散注意力的惡習。 |
| **2** | **任務主管 Taskmaster。**這位憤怒的軍官會對你們大喊大叫，即使你們僅僅犯了小錯也是如此。而且，他認為你們會在所有任務上失敗。這可能是一種嚴厲的愛，也可能僅僅是混蛋罷了。 |
| **3** | **寵溺的軍官 Protective Officer。**這位友善的軍官不願將你們帶入危險之中，並不斷提醒你們要小心。 |
| **4** | **心懷仇恨計程車兵 Bitter Soldier。**你的指揮官對你們的敵人有深仇大恨。即使你的團隊可能面臨巨大風險，他也會抓住任何機會來擊敗敵人。 |
| **5** | **滿懷希望的指揮官 Hopeful Commander。**這位樂觀的軍官認為新的和平時代即將來臨。你只需要完成最後的幾個任務，然後一切都應該結束了。 |
| **6** | **虔誠領袖 Devout Leader。**你的指揮官是一個虔誠的信徒。他相信你們的成功或失敗完全取決於神的意圖，而你們則是貫徹神之旨意的工具。 |

**軍事組織特使 Military Force Envoys**
你可能出於多種原因參軍或被招募。具有專業技能者可以對各類任務做出貢獻，從滲透和秘密行動到外交和戰略。也許你過去的事蹟或你家人的意願會促使你服兵役，不管你是否相信自己適合這樣的生活。
軍事組織特使身份表提供了一些你們能在軍事組織中所扮演身份的建議，以及每個身份一般相關聯的背景。
**軍事組織特使身份 Military Force Envoy Roles**

| **身份** | **背景** |
| --- | --- |
| 戰鬥員 Combatant | 罪犯、平民英雄、化外之民、水手、士兵 |
| 戰術家 Tactician | 侍僧、平民英雄、貴族、智者、士兵 |
| 軍醫 Medic | 侍僧、平民英雄、隱士、智者、士兵 |
| 偵察兵 Scout | 隱士、化外之民、水手、士兵、流浪兒 |
| 煽動者 Provocateur | 侍僧、騙子、罪犯、藝人、貴族 |
| 間諜 Spy | 任意 |

**軍事任務 Military Quests**
軍事部門範圍廣泛的工作既需要實力也需要城府。你的任務可能會破壞與一個敵對國家最近建立的脆弱和平，並有著把多個國家重新拖入戰爭泥潭的危險。又或者你們團隊因任務需要而與敵方士兵直接交戰，因此影響了戰況。敵對僱傭兵公司，武裝抵抗力量和被血引來的怪物也是常見的威脅。
軍事任務表中給出了幾種你負責完成的任務。
**軍事任務 Military Quests**

| **d6** | **任務** |
| --- | --- |
| **1** | **突擊部隊 Strike Force。**你們對敵人的部隊進行快速的、戰略性的、毀滅性的打擊。 |
| **2** | **防禦行動 Defensive Operations。**你們必須保護重要地點的安全，例如平民人口聚集處，補給站或具有戰略意義的橋樑或海港。 |
| **3** | **特種部隊 Special Forces。** 你們被分配到敵後進行秘密行動。 這與間諜或刺客的工作類似，但範圍更廣。你們從事裝置破壞活動或對高價值目標執行針對性打擊。 |
| **4** | **偵察 Reconnaissance。**你們收集有關敵軍人數，位置，動向或隱藏補給處和補給路線的資訊。 |
| **5** | **獵殺並殲滅 Seek and Destroy。**你們的責任是追捕特定的高價值危險目標，其中包括逃兵，可疑的敵方特種部隊或橫行的魔法戰爭機器。 |
| **6** | **圍攻 Siege。**你們被指派對敵人的據點發起圍攻，或破壞一個正在對友軍要塞進行的圍攻。 |
