# 行會

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 可選規則與 DM 指引；採用與否由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

**行會 Guild**

> _人多力量大。一隻蜜蜂不過是小蟲，但蜂群沒人敢招惹。_
> 
> _——塔莎_

你的團隊與強大的專業人士聯盟緊密聯絡，他們相互合作，互惠互利。你可能是這樣一個行會的長期會員，從匠人家庭或商人處繼承了會籍，或者你正在努力爭取自己的功績來進入行會。 如果你乾的活兒讓行會滿意，它絕對不會虧待你。行會不願意浪費寶貴的資產，那可不是好的商業決定。
**行會型別 Types of Guild**
行會的結構涵蓋了一大批商業企業，它們的專業性與眾不同。一群鐵匠，珠寶商，木匠，裁縫，鍊金術士，法學家和賢哲都可以組織為行會。無論從事何種貿易，這些專家都可以共享聯絡人，交換材料或工具之類的資源，並利用他們的集體影響力影響政治以謀取利益。或者，商人和其他企業主也可以組織成行會。透過對經濟的鐵定控制有效地統治一個城市或國家的商人大亨，或者分享新聞和供應路線的旅館老闆網路，都可以代表行會的贊助人。行會甚至可以包含著一個更加險惡的團體，例如一個從事諸如致命的怪物，危險的知識或靈魂之類的恐怖商品交易的團體。
從行會表格中擲骰或是選擇，以確定你們團隊隸屬於哪種行會。
**行會型別 Guild Type**

| **d6** | **行會型別** |
| --- | --- |
| **1** | **工匠行會 Crafters’ Guild。**這個工匠集團彙集了資源和影響力，以確保其工藝品的黃金穩定交換。 |
| **2** | **商人聯盟 Merchant Consortium。**這些企業家不會兜售他們所建立的商品，而是專門致力於將產品和潛在所有者聯絡在一起。如果沒有，他們會找到它。 |
| **3** | **奇蹟製造者協會 Miracle Makers’ Association。**該行會中有使用魔法的工匠專門為物品新增魔法效果。有傳言說他們可以從現有的附魔物品之中剝離魔法，並可能願意購買或交易冒險家的戰利品。 |
| **4** | **金融家 Moneychangers。**這些商人從事各種形式的貨幣交易，充當銀行家、貸款代理人，以及身為冒險者和其他個體處理鉅額財富的重要聯絡人。他們甘心用硬幣交換寶石就像他們樂意去尋找追尋歷史古蹟和回收藝術品的買家一樣。 |
| **5** | **哲學派系 Philosophical Faction。**這些志同道合的人遵循特定的教義，透過他們的服務和培訓傳播他們的專業知識。 |
| **6** | **身份交易者 Identity Traders。**這些神秘的商人買賣檔案、記憶和那些透著人情味的飾品，賣給那些需要重新開始的人。 |

**行會特權 Guild Perks**
當你們的團隊贊助者是行會，你們獲得以下特權。
有了行會作為團隊的贊助人，你將獲得以下好處。這些特權需要每年向行會支付15 gp 的捐款（取代具有行會工匠背景的角色每月支付5 gp 的費用）。這些會費為行會的服務和活動提供資金。
**宿舍 Accommodations。**你可以呆在組織的會館。房間可與舒適旅館的房間相媲美，但只需付出一個儉樸的價格（每天5 sp）。
**裝置 Equipment。**你可以要求在會館內使用專用工具，實驗室，圖書館或其他工藝所需的空間和裝置。當你使用行會內的專用裝置來進行一個工具屬性檢定時，將你正常的熟練加值翻倍。
**資源 Resources。** 你可以利用行會的廣泛聯絡來尋找稀有的工藝品原料，施法材料或魔法物品，或為它們找到買家（在《城主指南》和《珊娜薩的萬事指南》之中休整期活動）。 你可以使用行會的資源去尋找或出售合法商品，在任何定價上都會給你10％的優惠。
**訓練 Training。** 行會常駐著一些知識淵博的導師，講授與其興趣相關的學科。當你進行訓練這一休整期活動時（如《玩家手冊》和《珊娜薩的萬事指南》之中所述），如果你正在學習該行會專門研究的科目，則該培訓將花費一半的時間。由 DM 來決定這個行會是否有指定科目的導師。
**行會聯絡人 Guild Contact**
即使身為一個有著良好聲譽的行會成員，你也不能簡單地向行會負責人面前走去並要求他們的注意。你的上級在行會內管理工作合同，請求使用行會資源，並促進你的團隊與合適的人進行聯絡，以確保他們的利益。
從行會聯絡人表格選擇或骰一個來決定是什麼樣的人處理你與行會的關係。
**行會聯絡人 Guild Contact**

| **d6** | **聯絡人** |
| --- | --- |
| **1** | **完美主義者 The Perfectionis。**你的聯絡人是一位技術嫻熟但執著的創作者，致力於創造完美的事物，以定義他們的一生並確保自己的遺產。他們追求最好的材料和令人興奮的機會而忽略了是非。 |
| **2** | **細心的監工 Attentive Overseer。**行會代表對你的團隊的任務很感興趣。 在你返回報告之前，他們會跟蹤你的行為並瞭解你的冒險經歷。儘管他們學識的深淺令人不安，但他們似乎真的很渴望去指導你的工作。 |
| **3** | **隱秘贊助商 Hidden Benefactor。**無論你怎麼聯絡，他們都不會直接溝通。他們透過快遞或信件傳送訊息。行會中沒有人知道聯絡人是誰，或者如果他們知道也沒有告訴你。 無論如何，往來的資訊都十分良好，他們也會按時付款。 |
| **4** | **敏銳的導師 Discerning Mentor。**無論你的表現多麼出色，或者你的創作有多麼完美，對於這種聯絡人來說都遠遠不夠。他們會指出了每個缺陷和錯過的機會。他們是苦澀的以至於對周圍的人大肆抨擊，還是他們認識到你的潛力並試圖將你推向輝煌？ |
| **5** | **魔像嚮導 Golem Guide。**你的行會聯絡人是儲存在構造體中的逝去多時的工匠的靈魂。這種魔像是明智和博學的，但與它原本的時代相比，它很難把握時間的流逝和世界的狀況。 |
| **6** | **墮落的繆斯 Fallen Muse。**你的聯絡人是墮落的天族。無論他們為自己的過往感到後悔還是渴望復仇，他們都會為你和行會提供神聖的靈感和指導。你的團隊和行會以某種方式激發了他們上升的希望。 |

**行會代表 Guild Representatives**
作為行會成員，你可能是直接從事行會專業工作或其職業符合行會利益的專業人員。 或者，你可以為行會成員去辦一些他們不適合去辦的業務。例如，警衛，探險家，談判者和間諜可對一個行會十分有用，無論其利益在於貿易商品，娛樂活動，還是更多可疑商業投機。行會是否完全在法律範圍內運作以及其利益的公開程度也影響著行會認為其最有價值的技能。
行會代表身份表提供了一些你們能在行會中所扮演身份的建議，以及每個身份一般相關聯的背景。
**行會代表身份 Guild Representatives Roles**

| **身份** | **背景** |
| --- | --- |
| 研究員 Researcher | 侍僧、藝人、行會工匠、智者 |
| 談判者 Negotiator | 騙子、藝人、行會工匠、貴族、水手 |
| 怠工者 Saboteur | 騙子、罪犯、行會工匠、士兵、流浪兒 |
| 警衛 Guard | 罪犯、平民英雄、化外之民、水手、士兵 |
| 探險家 Explorer | 侍僧、平民英雄、行會工匠、化外之民、水手 |
| 專家 Expert | 任意 |

**行會任務 Guild Quests**
作為行會的成員，你被要求發揮自己的技能來為組織服務。你被要求承擔各種任務，無論是為了行會的利益，還是代表一個有影響力的客戶。商業世界中的競爭非常激烈，競爭對手或環境所帶來的挑戰可能會迫使你進行令人不齒的交易。
行會任務表中給出了幾種你負責完成的任務。
**行會任務 Guild Quests**

| **d6** | **任務** |
| --- | --- |
| **1** | **運送貨物 Deliver Goods。**你需要將清單上的貨物交付給行會的重要客戶或合作伙伴。無論是誰或是什麼試圖阻止你，交付都必須在關鍵的截止日期之前到達。 |
| **2** | **獲取材料 Acquire Materials。**你的行會需要稀有且難以獲得的材料，無論是為行會的專案還是為支付了費用的客戶。你的團隊必須從一個危險的地方或者一個頑固的擁有者那裡收集缺少的成分，同時要超過競爭對手。 |
| **3** | **消除競爭對手 Eliminate a Rival。** 競爭對手已經羞辱了行會太多次了，是時候停止了。你的團隊負責保證競爭對手不再玷汙行會的聲譽。你能讓他們永遠蒙羞嗎？還是需要採取更直接的方法呢？ |
| **4** | **傑作 The Masterpiece。**一件為具有影響力的客戶設計的精美藝術品，由行會製作或透過代理商獲取的，已經丟失不見了。你必須追蹤其下落，並在時間用盡之前確保其安全，來讓行會避免受到處罰。 |
| **5** | **收藏者 The Collector。**你的行會的任務是為富有但機密的客戶的建立收藏或獲取奇妙的東西。 以前未能完成任務的行會成員最終失蹤了。如果你能提供收藏者想要的東西，收藏者承諾會找回你的同事，但如果你失敗了，也許你也將成為收集的一部分。 |
| **6** | **該還錢了 The Bill Comes Due.**你的行會負責人透過一個超凡脫俗的交易獲得了他們引以為豪的地位。這個交易賬單到期了，他們拼命逃避付款。你必須擊敗任何來收取負責人債務的東西或者找到另一種可以接受的付款方式。 |
