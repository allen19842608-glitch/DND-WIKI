# 教團

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 可選規則與 DM 指引；採用與否由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

**教團 Religious Order**

> _嗯，為教團服務，然後很快你就會忙於處理成百上千件大祭司的洗衣雜活，因為——這可以方便地說——那是神的意願。_
> 
> _——塔莎_

你的隊伍為宗教機構服務，但教團的贊助不僅僅是隊伍成員們有著共同信仰這麼簡單。信仰的管理組織——它具有自己的資源，目標和領袖——會直接贊助並對你的冒險進行指導。
**教團的型別 Types of Religious Orders**
並非所有教團都是獻身於虔誠理想的信徒們的聯盟。也許你的隊伍是一支為信仰奮鬥的虔誠信徒，也許你們是一群利己主義者，利用了富有的教團信眾。你們的共同信仰會迫使你去追獵邪惡的怪物或阻止異界的入侵，去保護弱者免於壓迫，或是去充滿敵意的土地上散播教義。你也可以透過讓敵人悄然消失來為一位腐敗的主教服務——然而就算是憤世嫉俗的僱傭殺手在面對神蹟時也能成為真正的信徒。
從教團贊助者表格中擲骰或是選擇，以確定你們團隊隸屬於哪種教團贊助者。
**教團型別 Religious Order Type**

| **d6** | **教團型別** |
| --- | --- |
| **1** | **亡靈獵手 Undead Hunters。** 這個由學者和怪物獵手組成的組織不辭辛勞地調查著躁動的亡靈，追蹤到他們的老巢，並讓他們得到永恆的安息。 |
| **2** | **虔誠學者 Devout Scholars。** 這一聯合組織珍視和他們神靈有關的知識和文字，他們收集神聖的書籍，並記錄帶來神蹟的先知們生平的故事。 |
| **3** | **聖物收集者 Relic Collectors。** 這個考古學家侍僧團體試圖以故事中的聖物裝滿他們博物館般的廟宇殿堂。 |
| **4** | **慈善傳教士 Charitable Missionaries。** 這一教團相信著宗教將會賦予文明力量，他們不遠萬裡去幫助被壓迫者，以自己的道德榜樣吸引新的信眾。 |
| **5** | **激進派審判官 Militant Inquisitors。** 一位武斷而頑固的主教希望能排除一切信仰的威脅。 |
| **6** | **末日傳道者 Doomsaying Evangelists。** 這個教團認為世界將要迎來終結，他們認為說服他人相信這個事實可能會讓自己在將至的厄運前倖免於難。 |

**教團特權 Religious Order Perks**
當你們的團隊贊助者是教團時，你們獲得以下特權。
**神術服務 Divine Service**如有所需，你的團隊能向同一信仰的祭司尋求魔法幫助。一位與你同屬於一個信仰、具有足夠等級的 NPC 牧師或德魯伊能為你的隊伍施展最高五環的法術。只要你證明自己的確需要並懷有對信仰的堅定虔誠，施法者會自行提供法術所需的一切指定價格的材料成分。
**裝備 Equipment。** 團隊的每一個成員都會獲得一個聖徽或者一件德魯伊法器，即便他們並不需要這些來進行施法。你們同樣每人獲得一本記載了信仰的祈禱詞、儀式和經文的書冊。
**熟練 Proficiencies。** 如果你們之前不具備，團隊的每一位成員都會獲得宗教技能的熟練。
**教團聯絡人 Religious Order Contact**
你的教團有著大量的追隨者。它可能是一個使以你的團隊作為冒險者武裝的學者修會，也可能是一個聖武士軍團，他們會利劍與堅盾行不通的時候召喚你們團隊技巧的幫助。你們可能直接聽命與所崇拜的不朽存在或者透過一位世俗的代理人，比如大祭司和大德魯伊進行聯絡。
從教團聯絡人表格選擇或擲一個來決定是什麼樣的人處理你與教團的關係。
**教團聯絡人 Religious Order Contact**

| **d6** | **聯絡人** |
| --- | --- |
| **1** | **幕後發言人 Shadow Tongue。** 一位神秘的教團代言人為你們提供下一步行動的建議，但卻害怕被敵對的強大信仰所發現。 |
| **2** | **受啟迪的創作者 Inspired Creator。**一位天才的藝術家透過帶預言的歌謠或藝術品來傳遞神的意志。 |
| **3** | **神秘文字 Mysterious Text。** 一副神秘文字被逐句翻譯出來，引領你們一步步走向神聖的命運。 |
| **4** | **狂熱審判官 Fierce Inquisitor。** 一位狂熱的主教命令你在一處地區，一個教團或你們自己內部清除邪惡。 |
| **5** | **神眷治療師 Beloved Healer。** 一位著名的治療師引導你到最需要你之處，儘管在你到達之前，他們這麼做的緣由還不甚明瞭。 |
| **6** | **神之聲 Divinity's Voice。** 來自異界的訊息指引你前去執行神聖的任務。 |

**教團成員 Religious Order Member**
你對教團的主要職責是進一步擴大神明的影響力。這一職責包括傳教、執行神罰或找回丟失的聖物。此外，你所屬教團還可能有各種各樣的需求。你的贊助者因為你們獨特的技藝或者神的心血來潮而依靠你的團隊。
教團成員身份表提供了一些你們能在教團中所扮演身份的建議，以及每個身份一般相關聯的背景。
**教團成員身份 Religious Order Member Roles**

| 顧問 Councilor | 侍僧、平民英雄、隱士、化外之民、智者、流浪兒 |
| 衛士 Defender | 侍僧、罪犯、平民英雄、化外之民、士兵 |
| 修士 Ascetic | 侍僧、藝人、隱士、智者、士兵 |
| 審判官 Inquisitor | 侍僧、罪犯、貴族、水手、士兵 |
| 特使 Emissary | 侍僧、騙子、藝人、貴族、水手 |

**教團任務 Religious Order Quests**
你為教團所提供的服務因你侍奉的神和你隊伍的才能而有所不同。無論如何，教團都會受到對立信仰的反對，他們與你教團的競爭趕得上各自神靈之間的敵對。一些教團也會追獵和摧毀邪魔，亡靈或者其他他們認為褻瀆可憎的生物，試圖減少他們對世界的影響。其他的則投身於剷除真實或假象的異端，以證明自己的神至高無上。
教團任務表中給出了幾種為神靈服務併為 k 帶來榮耀的方法。
**教團任務 Religious Order Quests**

| **d6** | **任務** |
| --- | --- |
| **1** | **安全逃離 Safe Escape。** 一群信徒闖入了敵視你們教團的區域，你們必須找到他們並護送他們到安全的地方 |
| **2** | **尋回聖物 Relic Recovery。** 你們要在危險之地或敵人手裡尋找一件失落的教團象徵。 |
| **3** | **獵殺邪教 Cult Hunt。** 你們要追獵一群對教團或凡人具有危險的狂熱邪教徒。 |
| **4** | **亡命朝聖 Desperate Pilgrimage。** 你們要保護教團的幾位朝聖的成員，帶領他們穿過危機四伏的土地。 |
| **5** | **清剿異端 Expunge Heresy。** 你們要找出紮根於教團內部的褻瀆源頭。 |
| **6** | **阻止預言 Prevent Prophecy。** 一個對立的教團正致力於實現一個具有致命後果的預言，而你們要試圖破壞它們褻瀆神明的計劃。 |
