# 犯罪集團

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 可選規則與 DM 指引；採用與否由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

**犯罪集團 Criminal Syndicate**

> _違法犯罪——有什麼意義啊？既然智力已經完全碾壓對手，或者能把別人變成蛤蟆，為什麼還要靠偷的？_
> 
> _——塔莎_

你們的隊伍受一個犯罪網路所僱傭。你們可以是在組織內完全合格的正式成員，也可能才剛正要闖出名頭、贏取信任的新人。你們的隊伍可能並非是出於自己的意願而為集團服務：可能你曾經做岔了什麼以至於欠他們一大筆錢，也許你不小心殺錯了人，又或者僅僅是因為你直接就出生在一個和無良的強大傢伙有過仇怨的家庭裡。
**犯罪集團型別 Types of Criminal Syndicate**
犯罪集團囊括了本地的盜賊公會到腐敗的鉅富財閥，甚至可以是一個滲透到了社會各階層的異界入侵者團夥。無論是以什麼形式，犯罪集團通常都是在犧牲社會而為其成員榨取大筆的財富。
不過反過來說，犯罪集團也可能會是秉持善心的人為了對抗邪惡勢力而組建的地下組織。這種尚義任俠的犯罪集團可以是一群從殘暴的男爵手裡奪回稅收並還給那些受壓迫人們的不法分子，也可以是一群與來犯家鄉的侵略者戰鬥的無情流亡者。
從犯罪集團表格中擲骰或是選擇，以確定你們團隊隸屬於哪種犯罪集團。
**犯罪集團型別 Criminal Syndicate Type**

| **d6** | **犯罪集團型別** |
| --- | --- |
| **1** | **盜賊公會 Thieves’Guild。**一個由小偷、密探、走私犯和其他無賴惡棍組成的混亂集會控制著城內一塊片區的犯罪活動。 |
| **2** | **刺客協會 Assassin Society。**這些傢伙都是以他人的死謀生。協會成員磨鍊自己的技能，像是割喉、投毒、棄屍或者別的專注於結束生命的行當。這樣的一個協會受著利益或更偉大的事業而驅動。 |
| **3** | **魔武商團****Magical Arms Dealer****。**這個財團壟斷了致命魔法裝置的市場。他們以高價提供服務和商品，併為那些有需要的人找來驚人的魔法力量。 |
| **4** | **海盜艦隊 Pirate Fleet。**這個由海盜船長組成的聯盟在一名佔統治地位的船長或艦隊司令的管制下統一，並遵守嚴格的榮譽準則。只有在應對外來威脅的時候他們才會一同行動。 |
| **5** | **異形奪舍 Body Snatcher。**集團主要由控制了或假冒了其他人的生物組成，或者全部都是。它們試圖用自己組織的成員替換整個社會裡任何有影響力的人。 |
| **6** | **思維竊賊 Thought Thieves。**這些心靈罪犯潛入其目標的大腦之中盜取秘密，並隱蔽自身的存在。 |

**犯罪集團特權 Criminal Syndicate Perks**
當你們的團隊贊助者是犯罪集團時，你們獲得以下特權。
**指派工作 Assignments。**犯罪集團不會給你出穩定薪水，而是代表客戶或親自指派你去完成特定的任務。如果是有人僱傭犯罪集團執行任務（例如暗殺），組織會給你們的隊伍轉遞85%的酬金。如果是為了充實犯罪集團的金庫（例如一場大劫案），你們有權保留自己85%的盜取所得。DM 可以決定其他犯罪集團收走的部分多於或少於15%。
**黑貨市場 Contraband。**你能夠聯絡集團內的違禁品業務，例如毒素或者麻醉藥品。這些個玩意沒折扣可談，但是隻要你想，就總有地方能搞到手。
**設法銷贓 Fences。**集團裡有人——或者起碼有合夥人——擅長於處理贓物，你也能找他們幫忙。當然了，這些銷贓的除了搞非法的行當，也能幫忙賣掉昂貴的物件，例如藝術品和魔法物品。如果是魔法物品，就等於是你把尋找買家（如同在城主指南和珊娜薩的萬事指南中描述的休整期活動）的工作委託給了這些傢伙，此時你不會在尋找買家時被欺騙或遇到其他意外，但犯罪集團會收取20%的售價作為尋找費。
**藏身之處 Safe Houses。**犯罪集團會跨越廣大地區設定安全屋或其他秘密的藏身處。你們的隊伍如何找到這些不起眼的堡壘，而且可以在裡面免費維持窮困的生活方式。如果你洩露了一個安全屋，無論你是不是故意的，集團都不會再青睞於你，還可能會不再允許你使用安全屋。
**財團企業 Syndicate-Owned Businesses。**犯罪集團擁有幾家商務企業，主要是用來洗錢的。當你從這些店鋪購買物品時，你可以享受5%的折扣。DM 決定哪些商品或服務適用此折扣。
**犯罪集團聯絡人 Criminal Syndicate Contact**
犯罪集團的每個成員在組織中都有著自己的位置。你給聯絡人彙報，他會給你分配任務，代集團從你的工作報酬裡收錢，或者給你找外面的客戶催債。如果你需要找到犯罪集團的高層成員，最先要問的也還是你的聯絡人。
從犯罪集團聯絡人表格選擇或骰一個來決定是什麼樣的人處理你與犯罪組織內的聯絡。
**犯罪集團聯絡人 Criminal SyndicateContact**

| **d6** | **聯絡人** |
| --- | --- |
| **1** | **私人導師 Personal Mentor。**這是集團裡的老資格了，在你還年輕的時候，就是他總在照顧和保護你，擔當了父母一樣的角色。 |
| **2** | **機靈頑童 Clever Urchin。**一個沒有惡意的傢伙，可能在當乞丐或者是什麼小雜活。他認識所有你需要的人，而且也會幫你介紹這些關係。 |
| **3** | **前執法****者 Former Law Enforcement。**你的聯絡人曾經（也許現在還是）當地執法部門的一份子。他們對你所在地區的法律流程瞭如指掌，但也因此有點偏執和多疑。 |
| **4** | **娛樂人生 Bon Vivant。**一個享樂主義者在本地經營著一個犯罪窩點——賭博，迷幻藥或者別的什麼樂子。只要他還沒把自己沉到麥酒裡，你就總是能得到他的幫助。 |
| **5** | **背叛之徒 Traitor。**你知道你的聯絡人其實已經背叛了集團，可他們的勢力太大，涉及太深，你不太敢跨過他們和集團直接交流——暫時是這樣。 |
| **6** | **犯罪皇室 Criminal Royalty。**大多數人都不知道，你的聯絡人是當地的貴族甚至皇室成員。他們與集團保持聯絡的原因依然是一個令人不安的謎。 |

**犯罪集團代理人**
無論你是幹了快有一輩子的惡棍，還是自命不凡的新手，在犯罪集團你都會求財、求名或設法增進影響力。集團是被利益驅動的，會誠聘各類人才成為它的特工。事實證明，靈活和創新不僅對於開拓市場新前景至關重要，也相當有助於規避法律。你展現了罕見的經驗和技術，大膽踏步在投機犯罪的新時代前沿。
犯罪集團代理人身份表提供了一些你們能以什麼身份加入犯罪集團，以及每個身份一般相關聯的背景。

**犯罪集團任務 Criminal Syndicate Quests**
作為犯罪集團的成員，你的工作絕不是簡單的街頭詐騙或扒竊。憑你這種本事，可以為了更崇高的目的而與他人合作，雖然會承擔極大的風險，但也能帶來豐盛的回報。當地的律法是你最頑固的敵人，但其他犯罪集團也可能和你作對——或者被你捕食。
犯罪集團任務表中給出了幾種你能為犯罪集團做的工作。
**犯罪集團任務 Criminal Syndicate Quests**

| **d6** | **任務** |
| --- | --- |
| **1** | **檢索獲取 Acquisition and Retrieval。**你們為犯罪集團獲取資產。你們偷到了重要的檔案或者整理出了一個可用的安全屋。 |
| **2** | **搶劫活動 Heists。**你們精心計劃並執行一起大劫案。這可是對團隊綜合技能的一大考驗。 |
| **3** | **幫派鬥爭 Gang Warfare。**你們需要確保勢力範圍上沒有其他犯罪集團的立足之地。 |
| **4** | **內部肅清 Enforcement。**集團裡那些腐敗、任性和貪婪的傢伙必須遵守組織的規章制度，與集團目標一致。你來實現這件事。 |
| **5** | **刺殺陰謀 Assassination。**你們要設法解決某個顯赫人物——就是那種要解決眾多保鏢和繞過精心設計的安保系統的型別。 |
| **6** | **顛復****強權 Topple the Powerful。**你的組織是群罪犯，你的手段不合律法，但你的目標公正合理。你們要幫助無能為力的人對抗強者的剝削。 |
