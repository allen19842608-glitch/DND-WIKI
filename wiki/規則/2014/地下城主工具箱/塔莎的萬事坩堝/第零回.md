# 第零回

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**第零回 Session Zero**

劃定好底線。有人越過去了，那就說出來。如果他不聽，那總還是可以用_死雲術 cloudkill_的……

——塔莎

建立角色或是開始遊戲之前，DM 和玩家們可以舉辦一次俗稱“第零回”的特別聚會，來設立期望、勾畫社會契約的細則、以及分享房規。建立並遵守這些規則能幫助確保這場遊戲對所有人而言都會是愉快的體驗。

通常，第零回的作用也包含了將玩家角色們聚集起來。作為 DM，你也能以建議他們選擇會在接下來的冒險或戰役具有作用的選項的方式，來幫助玩家建立角色。

### 建立角色與小隊 Character and Party Creation

每個玩家都有自由選擇角色種族、職業、與背景的權利，但你也可以對你認為不適合本場戰役的特定選項做出限制。如果有不止一位的玩家，你應當鼓勵他們選擇互不相同的職業，來保證小隊具有廣泛的能力。選擇不完全相同的背景就沒那麼重要了，畢竟，扮演一個全是軍人的小隊或是一支四處冒險的藝人也挺有趣的。玩家們所選擇的背景定下了他們的角色在成為冒險者之前是怎樣的人，同時也以理念、牽絆以及缺點的形式提供了扮演契機。比如，如果某個玩家選擇罪犯作為背景， “我試圖償還欠一位慷慨資助者的舊債/舊人情”就是他的牽絆選項之一。如果這就是他的角色的牽絆，那麼你就應該與這位玩家商量，決定這位慷慨的資助者是什麼人，並構造與之相關的故事線、將其融入戰役之中。

### 組建小隊 Party Formation

你在第零回裡的任務，是讓玩家們構建自己想要的角色、以及幫他們構思他們的角色是如何聚集起來成為冒險隊伍的。認定角色們彼此相識、並有一段共度的過往（無論這個過往是多麼短暫），是很有幫助的。你可以在玩家們建立角色時向他們提出下列問題，以瞭解隊伍內部的關係：

·這些角色中間、有人與其他角色具有關聯麼？

·是什麼讓玩家們作為同一支隊伍留在一起？

·對於每個角色而言，隊伍裡的其他角色最讓他們喜歡的地方是什麼？

·這支隊伍有贊助人麼？參考第二章“隊伍贊助人”來獲得贊助人的範例。

如果玩家們想不出他們的角色彼此結識的方法，他們可以從下面的“隊伍起源表”中自選一項、或是投擲一枚 d6來決定。你應該在第零回裡花一些時間來幫玩家們勾勒細節。例如，如果角色們是為了戰勝同一個敵人而聚集起來的，就要決定誰是這位共同的敵人；如果是一場葬禮將玩家們聚集了起來，就要補充關於死者的身份粉與每個角色與死者的關係的細節。

| **d6** | **起源故事 Origin Story** |
| --- | --- |
| 1 | 角色們在同一地區長大，彼此結識已有多年。 |
| 2 | 角色們為了戰勝同一個敵人聯合起來。 |
| 3 | 角色們由同一位想要為他們冒險提供資助的贊助者聚集而來。 |
| 4 | 一場葬禮讓角色們聚在了一起。 |
| 5 | 一場宴會讓角色們聚在了一起。 |
| 6 | 角色們被困在了一起。 |
