# 怪物偏好

> [!WARNING] 本頁整理《塔莎的萬事坩堝》的 2014 DM 工具；屬 DM 指引或可選規則時，須由 DM 決定是否採用。

## ⚙️ 規則條文 (Rule Text)

**怪物偏好 Monsters' Desires**

**異怪 Aberrations**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 奇珍異獸的大腦，或是其他器官 |
| 2 | 奉承和諂媚（俗稱拍馬屁） |
| 3 | 其還不知道的秘密或是學識 |
| 4 | 你接受陌生的有機體移植到你身體上 |

**野獸 Beasts**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 新鮮的肉 |
| 2 | 一段舒緩的旋律 |
| 3 | 色彩鮮豔的珠子、布料、羽毛、或絲繩 |
| 4 | 一個老舊的毛絨動物玩偶，或是別的什麼柔軟小飾品 |

**天族 Celestials**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一段關於英雄史詩的傳奇故事 |
| 2 | 你發誓，在下個黎明前你會完成三項善事 |
| 3 | 一個被討伐的暴君的王冠 |
| 4 | 一個神聖的聖物，或珍貴的傳家之寶 |

**構裝生物 Constructs**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一些能加入到構裝生物關節處的潤滑油 |
| 2 | 一個還剩充能數的魔法物品，給它當作燃料使用 |
| 3 | 一個裝滿了元素能量的容器 |
| 4 | 精金零部件，或是秘銀零部件 |

**龍類 Dragons**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 黃金或寶石 |
| 2 | 任何與之敵對的龍的寶庫裡的任何東西 |
| 3 | 一件至少傳承了3個世代的古董 |
| 4 | 一件以它為形象製造的精美藝術雕塑品 |

**元素 Elementals**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一顆至少價值50gp 的寶石，當然，作為它的食物 |
| 2 | 一份極度純淨的、它喜好的元素的樣本 |
| 3 | 一個能讓其回到它的家鄉位面的方法 |
| 4 | 你跳一支它家鄉位面特有的舞蹈 |

**妖精 Fey**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 你首次接吻的記憶 |
| 2 | 你眼睛的顏色 |
| 3 | 對你來說主觀意義上有極大意義與價值的物件 |
| 4 | 你吟誦一手崇高的詩歌 |

**邪魔 Fiends**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 你的靈魂 |
| 2 | 一個被褻瀆的神聖物品 |
| 3 | 你活著的親戚朋友，或近期被殺害的親戚朋友的血液 |
| 4 | 在它的面前打破你的神聖誓言 |

**巨人 Giants**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 讓一個矮人承認巨人工藝比矮人工藝好，好得多！ |
| 2 | 一隻強而有力工作用生畜 |
| 3 | 數大桶麥酒 |
| 4 | 從與之敵對的巨人那邊偷來的寶藏 |

**類人生物 Humanoids**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 承諾找回那件遺失的、對他/她的文化有著重大意義的物品 |
| 2 | 向他/她發起一次友好的比試，像是比歌，比舞，比酒之類的 |
| 3 | 尋找他/她丟失的某些東西 |
| 4 | 關於他/她宿敵秘密或是弱點的資訊 |

**怪獸 Monstrosities**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 清理這生物上一餐卡牙縫裡的殘羹剩飯 |
| 2 | 這生物最喜歡吃的食物 |
| 3 | 驅趕走與之敵對的生物 |
| 4 | 模仿它的交配舞蹈做出相應的動作 |

**泥怪 Oozes**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一小瓶腐臭的液體 |
| 2 | 一塊攜帶著惡臭氣味的布料 |
| 3 | 任何它能消化得了的骨或肉 |
| 4 | 一加侖任意營養液 |

**植物 Plants**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一磅腐殖物 |
| 2 | 從充滿妖精荒野魔力的泉水中打上來的水 |
| 3 | 清理植物領地內的入侵植被 |
| 4 | 摧毀你隊伍中所有斧頭與生火工具以證明友善 |

**亡靈 Undead**

| **d4** | **偏好事物** |
| --- | --- |
| 1 | 一小瓶血液 |
| 2 | 它自己生前自己的遺物 |
| 3 | 為其破爛墳墓提供避陽用的材料、工具、或是技能（指用，不是消耗技能） |
| 4 | 完成一項它生前未能完成的任務 |
