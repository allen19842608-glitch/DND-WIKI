# 效應區域 (Area of Effect)

- 效應區域具有源點，能量自源點擴散。若源點至區域中某處無法畫出不受障礙物阻擋的直線，該處不屬於效應區域；只有提供完全掩護的障礙物會阻擋這些直線。
- 若創造者將源點置於看不見的位置，且中間有合適障礙物，源點改為出現在該障礙物較靠近創造者的一側。

| 形狀 | 源點與範圍 |
| :--- | :--- |
| 錐狀 | 自源點向指定方向擴散；各距離的寬度等於距離。源點通常不包含。 |
| 立方 | 源點位於任一面；尺寸為每邊長度。源點通常不包含。 |
| 柱狀 | 源點位於頂面或底面中心；指定半徑與高度。源點包含。 |
| 光環 | 自生物或物件向各方向擴散；除非立即或固定，隨源頭移動。源頭通常不包含。 |
| 線狀 | 自源點沿直線傳播；指定長度與寬度。源點通常不包含。 |
| 球狀 | 自源點向所有方向擴散；指定半徑。源點包含。 |
