# 魔法學派 (Schools of Magic)

每個法術屬於一個魔法學派。學派主要用於描述與其他規則的參照，本身不會額外賦予規則效果。

| 學派 | 典型效果 |
| :--- | :--- |
| 防護 | 抵禦或逆轉有害效應 |
| 咒法 | 轉移生物或物件 |
| 預言 | 揭露訊息 |
| 惑控 | 影響心智 |
| 塑能 | 引導能量創造效應，通常具破壞性 |
| 幻術 | 欺騙感官與心靈 |
| 死靈 | 操縱生與死 |
| 變化 | 轉變生物或物件 |

（來源：玩家手冊 2024，魔法學派）
