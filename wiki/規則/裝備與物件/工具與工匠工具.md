# 工具與工匠工具 (Tools and Artisan’s Tools)

- 工具描述會列出價格、重量、常用屬性、使用物件動作可達成的操作、可製造物品與變體。（來源：2024 玩家手冊，工具）
- 若你具有某工具的熟練，使用該工具進行屬性檢定時可加入熟練加值；若你同時具有該檢定使用的技能熟練，該檢定還具有優勢。（來源：2024 玩家手冊，工具熟練）
- 每一種工具變體的熟練彼此獨立，例如不同賭具或不同樂器分別計算熟練。（來源：2024 玩家手冊，工具）

## ⚙️ 規則條文 (Rule Text)

### 工具欄位說明

| 欄位 | 意義 |
| :--- | :--- |
| 屬性 | 使用工具進行屬性檢定時最常採用的屬性。 |
| 操作 | 以使用物件動作操作工具時可嘗試的事項與 DC。 |
| 製造 | 該工具可製造的物品；細節依製作裝備規則。 |
| 變體 | 同一工具類別下的不同獨立熟練。 |

## 💡 實戰應用與裁量 (DM Ruling)

- 工具熟練與技能熟練重疊時，2024 規則的重點是「同時具備兩種熟練則取得優勢」，不是把熟練加值加兩次。
- 工具操作的 DC 是常見用途的基準；若環境特別有利或不利，DM 可依情境調整 DC 或要求不同屬性。
- 製造欄列出工具可製造的物品範圍，實際花費與時間仍依製作裝備規則處理。
