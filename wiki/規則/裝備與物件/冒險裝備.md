# 冒險裝備 (Adventuring Gear)

## ⚙️ 規則條文 (Rule Text)
- 冒險裝備表列出常用冒險用品的重量與價格；同一列中標示「多種」者，須查閱其子表或個別物品說明。（來源：2024 玩家手冊，裝備章）
- 若物品描述要求以動作操作，通常使用「使用物件」動作；若物品描述允許取代攻擊，則在你執行攻擊動作時，以一次攻擊替換為該物品的使用方式。（來源：2024 玩家手冊，冒險裝備）
- 單位採本 Wiki 標準寫法：磅數與「磅」之間保留空格，價格以 CP、SP、GP 表示。（來源：[[翻譯詞彙表|翻譯詞彙表 (Translation Glossary)]])

### 具子表的冒險裝備

| 類別 | 規則摘要 |
| :--- | :--- |
| 彈藥 (Ammunition) | 包含箭矢、弩矢、槍械子彈、投石索子彈與吹矢等；需要搭配具有彈藥特性的武器使用。 |
| 奧術法器 (Arcane Focus) | 寶珠、水晶、權杖、法杖或魔杖等；吟遊詩人、術士、契術師與法師可作為施法法器。 |
| 德魯伊法器 (Druidic Focus) | 槲寄生枝、木質法杖或紫杉魔杖等；德魯伊與遊俠可作為施法法器。 |
| 聖徽 (Holy Symbol) | 護符、聖徽或聖物匣等；牧師與聖騎士可作為施法法器。 |
| 套組 (Pack) | 竊賊套組、外交套組、地城套組、藝人套組、探索套組、祭司套組與學者套組是多件冒險裝備的打包購買選項。 |

### 有特殊使用規則的常見物品

| 物品 | 使用摘要 |
| :--- | :--- |
| 強酸 (Acid) | 可在攻擊動作中以一次攻擊替換為投擲小瓶，目標通常進行敏捷豁免；失敗時受到強酸傷害。 |
| 熾火膠 (Alchemist's Fire) | 可在攻擊動作中以一次攻擊替換為投擲瓶子，目標敏捷豁免失敗時受到火焰傷害並開始燃燒。 |
| 抗毒劑 (Antitoxin) | 飲用後在對抗或結束中毒狀態的豁免上獲得優勢，持續 1 小時。 |
| 滾珠 (Ball Bearings) | 可覆蓋 10 呎方形區域；進入區域的生物可能因敏捷豁免失敗而伏地。 |
| 鐵蒺藜 (Caltrops) | 可覆蓋 5 呎方形區域；進入區域的生物可能受穿刺傷害且速度暫時降為 0。 |
| 鏈條、鐐銬、繩索 (Chain, Manacles, Rope) | 可用來束縛不願意的生物；其逃脫、破壞或解除有各自 DC。 |
| 醫療包 (Healer's Kit) | 具有 10 次使用次數；可消耗一次使用來穩定生命值為 0 的生物，並在適用的感知（醫藥）檢定上提供優勢。 |
| 聖水 (Holy Water) | 可在攻擊動作中以一次攻擊替換為投擲；邪魔或不死生物豁免失敗時受到光耀傷害。 |
| 捕網 (Net) | 可在攻擊動作中以一次攻擊替換為投擲；目標敏捷豁免失敗時陷入束縛，直到逃脫或捕網被破壞。 |
| 燃油 (Oil) | 可潑灑在生物、物件或空間上；點燃後造成火焰傷害，也可作為油燈與提燈燃料。 |
| 治療藥水 (Potion of Healing) | 魔法物品；使用附贈動作飲用或餵給 5 呎內另一個生物，恢復 2d4 + 2 生命值。 |
| 便攜式攻城錘 (Ram, Portable) | 撞門時使力量檢定獲得 +4 加值；另一名角色可協助使用。 |
| 火把 (Torch) | 燃燒 1 小時，提供明亮光照與微光；也可作為近戰武器造成少量火焰傷害。 |

## 💡 實戰應用與裁量 (DM Ruling)

- 冒險裝備通常不是角色能力的替代品，而是讓角色用準備與創意改變局勢；例如滾珠與鐵蒺藜能迫使敵人改變移動路線。
- 若玩家想用表中物品做未列明用途，先判斷是否只是敘事效果；若會影響成功率、傷害或狀態，再要求適當的屬性檢定或豁免。
- 魔法物品性質的治療藥水與法術卷軸仍應連回魔法物品或施法規則處理，冒險裝備表只提供購買與基本使用入口。
