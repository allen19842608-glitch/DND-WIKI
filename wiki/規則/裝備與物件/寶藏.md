# 寶藏 (Treasure)

冒險中的寶藏可包含錢幣、貴重物品與魔法物品；地下城主可依怪物或地點的主題決定其組成。

## ⚙️ 規則條文 (Rule Text)

### 寶藏主題 (Treasure Themes)

怪物的寶藏偏好可用下列主題決定。此表協助選擇寶庫中的非魔法貴重物品與魔法物品類型；隨機魔法物品則使用本章的隨機表。

| 主題 | 對應寶藏 |
| :--- | :--- |
| 奧秘 | 寶石，以及超自然或充盈魔能的魔法物品 |
| 武備 | 錢幣或貿易金屬條，以及適合戰鬥的魔法物品 |
| 器具 | 錢幣、貿易金屬條或貿易貨品，以及偏重實用性的魔法物品 |
| 聖物 | 藝術品，以及具有宗教起源或歸宿的魔法物品 |

### 寶藏類型

- [[服務與錢幣|錢幣 (Currency)]]：使用玩家手冊的錢幣換算與重量規則。
- [[貿易貨品|貿易貨品 (Trade Goods)]]：可直接以物易物的常見貨物。
- [[貿易金屬條|貿易金屬條 (Trade Bars)]]：以重量計價的貴金屬錠。
- [[寶石|寶石 (Gemstones)]]：以價值級距決定的隨機寶石表。
- [[藝術品|藝術品 (Art Objects)]]：以價值級距決定的隨機藝術品表。
- [[魔法物品/魔法物品索引|魔法物品索引 (Magic Items Index)]]：已建立的魔法物品條目與分類導覽。
- [[魔法物品/隨機魔法物品|隨機魔法物品 (Random Magic Items)]]：依寶藏主題與稀有度選擇魔法物品的程序。

### 隨機庫藏寶藏

「隨機庫藏寶藏表」的第三列金幣為 `8d8 × 1,000 GP`；原列的 `8d8 × 10,000 GP` 已由勘誤更正。（來源：DMG 2024 Errata v1.0，p. 1）
