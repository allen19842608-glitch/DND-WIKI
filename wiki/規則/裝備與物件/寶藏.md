# 寶藏 (Treasure)

## ⚙️ 規則條文 (Rule Text)

### 寶藏主題 (Treasure Themes)

怪物的寶藏偏好可用下列主題決定。此表協助選擇寶庫中的非魔法貴重物品與魔法物品類型；隨機魔法物品則使用本章的隨機表。

| 主題 | 對應寶藏 |
| :--- | :--- |
| 奧秘 | 寶石，以及超自然或充盈魔能的魔法物品 |
| 武備 | 錢幣或貿易金屬條，以及適合戰鬥的魔法物品 |
| 器具 | 錢幣、貿易金屬條或貿易貨品，以及偏重實用性的魔法物品 |
| 聖物 | 藝術品，以及具有宗教起源或歸宿的魔法物品 |

### 寶藏類型

- [[服務與錢幣|錢幣 (Currency)]]：使用玩家手冊的錢幣換算與重量規則。
- [[貿易貨品|貿易貨品 (Trade Goods)]]：可直接以物易物的常見貨物。
- [[wiki/規則/裝備與物件/貿易金屬條|貿易金屬條 (Trade Bars)]]：以重量計價的貴金屬錠。
- [[wiki/規則/裝備與物件/寶石|寶石 (Gemstones)]]：以價值級距決定的隨機寶石表。
- [[wiki/規則/裝備與物件/藝術品|藝術品 (Art Objects)]]：以價值級距決定的隨機藝術品表。
- [[魔法物品/魔法物品索引|魔法物品索引 (Magic Items Index)]]：已建立的魔法物品條目與分類導覽。
- [[wiki/魔法物品/隨機魔法物品|隨機魔法物品 (Random Magic Items)]]：依寶藏主題與稀有度選擇魔法物品的程序。

### 個體寶藏 (Individual Treasure)

個體寶藏用於單一怪物攜帶、私藏，或由其受害者遺留的小量財物。依怪物的挑戰等級（CR）擲骰，或直接採用括號內的平均值；若是一組相同生物，將一次結果乘以生物數量。

| CR | 個體寶藏 |
| :--- | :--- |
| 0–4 | `3d6`（平均 10）GP |
| 5–10 | `2d8 × 10`（平均 90）GP |
| 11–16 | `2d10 × 10`（平均 110）PP |
| 17 以上 | `2d8 × 100`（平均 900）PP |

### 隨機庫藏寶藏 (Random Treasure Hoard)

庫藏寶藏用於一群生物累積的財富，或強大生物囤積的大筆寶藏。單一怪物使用其 CR；一群生物使用首領的 CR。可擲骰或採用表列平均值；特別熱衷囤積寶藏的生物（例如龍）可擲兩倍骰子或將結果加倍。角色通常約每次遊戲會獲得一次庫藏寶藏；其中的魔法物品數量依表決定，並以 [[wiki/魔法物品/隨機魔法物品|隨機魔法物品 (Random Magic Items)]] 決定具體物品。

| CR | 寶藏量 | 魔法物品數量 |
| :--- | :--- | :--- |
| 0–4 | `2d4 × 100`（平均 500）GP | `1d4 − 1` |
| 5–10 | `8d10 × 100`（平均 4,400）GP | `1d3` |
| 11–16 | `8d8 × 1,000`（平均 36,000）GP | `1d4` |
| 17 以上 | `6d10 × 10,000`（平均 330,000）GP | `1d6` |

「隨機庫藏寶藏表」的第三列金幣為 `8d8 × 1,000 GP`；原列的 `8d8 × 10,000 GP` 已由勘誤更正。（來源：DMG 2024 Errata v1.0，p. 1）

### 任務獎勵 (Quest Rewards)

角色完成任務時，可擲一次隨機庫藏寶藏表作為報酬；以角色等級取代該表原本使用的 CR。

### 怪物寶藏類別 (Monster Treasure Preferences)

怪物資料中的寶藏類別決定適用的生成程序：

| 類別 | 使用方式 |
| :--- | :--- |
| 任意 | 擲隨機庫藏寶藏表；金錢獎勵可為錢幣、貿易金屬條、貿易貨品、寶石或藝術品，魔法物品可使用任一寶藏主題與類別。 |
| 個體 | 不具有庫藏寶藏；改擲隨機個體寶藏表，結果可為錢幣、貿易金屬條、貿易貨品、寶石或藝術品。 |
| 奧秘、武備、器具或聖物 | 擲隨機庫藏寶藏表決定規模；若包含魔法物品，依指定的 [[wiki/魔法物品/隨機魔法物品\|寶藏主題表]] 決定物品。 |
