# 裝備與物件索引

2024 玩家手冊的裝備章節包含下列資料類別；本頁是「裝備與物件」分類的唯一導覽入口。

| 類別 | 內容 |
| :--- | :--- |
| 護甲 | 輕甲、中甲、重甲、盾牌、護甲特性與 AC 計算 |
| 武器 | 簡易／軍用武器、近戰／遠程武器、傷害、射程、特性、精通詞條與價格 |
| 冒險裝備 | 燃料、容器、繩索、工具、照明、服裝與探索用品 |
| 工具 | 工匠工具、遊戲工具、樂器、套組與專業用途 |
| 坐騎與載具 | 坐騎、船隻、車輛與相關速度／容量 |
| 服務 | 住宿、交通、施法與其他雇用服務的價格 |
| 錢幣 | CP、SP、EP、GP、PP 的換算與使用 |
| 寶藏 | 寶藏主題、貿易貨品、貿易金屬條、寶石與藝術品 |
| 魔法物品 | 魔法物品的類別、同調與使用規則 |
