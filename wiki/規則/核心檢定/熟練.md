# 熟練 (Proficiency)

## ⚙️ 規則條文 (Rule Text)

- 生物的熟練加值反映訓練；角色依等級、怪物依挑戰等級決定。等級或 CR 4 以下為 +2，5-8 為 +3，9-12 為 +4，13-16 為 +5，17-20 為 +6；更高 CR 依 SRD 表格繼續增加至 +9。
- 當 D20 檢定使用你熟練的技能、豁免檢定或裝備時，加入熟練加值；同一個擲骰或數值不能加入同一熟練加值超過一次。
- 具有工具熟練且同時具有與該檢定相關的技能熟練時，該屬性檢定具有優勢。（來源：SRD 5.2.1，pp. 8-9）

### 技能與常用屬性

| 技能 | 常用屬性 | 典型用途 |
| :--- | :--- | :--- |
| 特技 | 敏捷 | 保持平衡或表演特技 |
| 馴獸 | 感知 | 安撫、訓練或指揮動物 |
| 奧秘 | 智力 | 回想法術、魔法物品與位面知識 |
| 運動 | 力量 | 跳躍、游泳或破壞物件 |
| 欺瞞 | 魅力 | 說謊或偽裝 |
| 歷史 | 智力 | 回想歷史事件、人物與文化 |
| 洞悉 | 感知 | 判讀情緒與意圖 |
| 威嚇 | 魅力 | 以威勢或威脅影響他人 |
| 調查 | 智力 | 尋找隱晦資訊或推理運作方式 |
| 醫藥 | 感知 | 診斷疾病或判斷死因 |
| 自然 | 智力 | 回想地形、植物、動物與天候知識 |
| 察覺 | 感知 | 透過感官注意容易錯過的事物 |
| 表演 | 魅力 | 演戲、說故事、演奏或舞蹈 |
| 說服 | 魅力 | 真誠而得體地說服他人 |
| 宗教 | 智力 | 回想神祇、儀式與聖徽知識 |
| 巧手 | 敏捷 | 扒竊、藏物或表演手上技法 |
| 隱匿 | 敏捷 | 安靜移動或藉遮蔽物避開注意 |
| 求生 | 感知 | 追蹤、覓食、找路或避開自然危害 |

技能表所列的是最常搭配的屬性；若情境合理，地下城主可要求以其他屬性進行該技能檢定。（來源：SRD 5.2.1，p. 9）

## 💡 實戰應用與裁量 (DM Ruling)

- 同時擁有兩個相關技能熟練不會使熟練加值加兩次；特定規則明示倍增或減半時才依其處理。
