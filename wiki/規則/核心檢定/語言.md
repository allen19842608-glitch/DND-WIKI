# 語言 (Languages)

## ⚙️ 規則條文 (Rule Text)
- 語言知識代表角色能以該語言溝通、閱讀與書寫。角色至少知道通用語及從標準語言表擲骰或選擇的兩種語言；職業、背景與其他特性可能額外提供語言。（來源：玩家手冊 2024；SRD 5.2.1 對照，Character Creation p. 20）

### 稀有語言

稀有語言通常較秘密，或因源自其他存在位面而在物質位面較不為人知；某些特性能讓角色習得稀有語言。

| 語言 | 起源 |
| :--- | :--- |
| 深淵語 (Abyssal) | 深淵的惡魔 (Demons) |
| 天界語 (Celestial) | 天族 |
| 深潛語 (Deep Speech) | 異怪 |
| 德魯伊語 (Druidic) | 德魯伊結社 |
| 煉獄語 (Infernal) | 九獄的魔鬼 (Devils) |
| 原初語 (Primordial) | 元素 |
| 木族語 (Sylvan) | 妖精荒野 |
| 盜賊黑話 (Thieves’ Cant) | 各種犯罪公會 |
| 地底通用語 (Undercommon) | 幽暗地域 (The Underdark) |

原初語包括水族語 (Aquan)、氣族語 (Auran)、火族語 (Ignan) 與土族語 (Terran) 方言；懂得其中一種方言的生物可以和懂得另一種方言的生物交流。（來源：DND 2024 中文翻譯，角色建立；SRD 5.2.1，Character Creation p. 20）
