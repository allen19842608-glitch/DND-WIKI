# D&D 冒險者聯盟 5 級起始角色 (Starting Play at 5th Level)

## ⚙️ 規則條文 (Rule Text)

- 角色可直接從 5 級開始，取得職業與背景的標準起始裝備、500 GP、40 天休整期，並選擇或隨機決定一件起始魔法物品。（來源：玩家指南 v2026.4，p. 1）

| 起始魔法物品 |
| :--- |
| +1 萬能工具 (All-Purpose Tool, +1) |
| +1 虔信護符 (Amulet of the Devout, +1) |
| +1 奧法秘典 (Arcane Grimoire, +1) |
| 次元袋 (Bag of Holding) |
| +1 血源瓶 (Bloodwell Vial, +1) |
| +1 龍皮腰帶 (Dragonhide Belt, +1) |
| +1 月鐮 (Moon Sickle, +1) |
| +1 調律者之鼓 (Rhythm-Maker’s Drum, +1) |
| +1 契約掌控者之杖 (Rod of the Pact Keeper, +1) |
| +1 盾牌 (Shield, +1) |
| +1 戰法師魔杖 (Wand of the War Mage, +1) |
| +1 武器 (Weapon, +1) |
| +1 徒手技藝綁帶 (Wraps of Unarmed Power, +1) |

## 💡 實戰應用與裁量 (DM Ruling)

- 這是建立角色時的一次性選擇；不能以同稀有度任意替換清單外物品。
