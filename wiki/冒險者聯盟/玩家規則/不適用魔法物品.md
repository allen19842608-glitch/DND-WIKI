# D&D 冒險者聯盟不適用魔法物品 (Unavailable Magic Items)

## ⚙️ 規則條文 (Rule Text)

符合下列任一標準的魔法物品不適用於 AL；附錄 B 明列的例外仍可使用。（來源：玩家指南 v2026.4，p. 11）

| 標準           | 判定摘要                            |
| :----------- | :------------------------------ |
| 第三方魔法物品      | 非對應 CR 戰役的合作產品物品                |
| 神器           | 神器類物品                           |
| 邪惡           | 具有邪惡陣營、使角色邪惡或要求邪惡行為             |
| 傷害玩家角色       | 強迫傷害、懲罰或奪取其他玩家角色自主權             |
| 愛情護咒         | 強迫形成愛情或類似關係                     |
| 機制效果         | 永久機制或屬性值效果；附錄列出的卷冊、手冊等例外除外      |
| 印刷錯誤品        | 明顯或已被勘誤、設計師、AL 管理員確認的錯誤物品       |
| 未指定的 DM 選擇效果 | 卡牌、符文、法術、技能或其他效果未由文字明確指定        |
| 未指定的魔咒物品     | 魔咒護甲、法杖或武器未指定所附法術               |
| 抹除           | 非卷軸物品且會抹消物質                     |
| 一件物品的一部分     | 不完整或破損物品                        |
| 劇情裝置         | 與特定 NPC、地點、願望、劇情生物或事件綁定         |
| 施法者          | 具有智能且能施法的物品                     |
| 載具           | 冒險授予的魔法航行工具或大於龍骨船的載具；玩家製作者依例外處理 |
| 其他具破壞性的情況    | 會顯著破壞公開遊戲或跨桌一致性的其他物品            |

## 💡 實戰應用與裁量 (DM Ruling)

- 先檢查附錄 B 標準，再檢查「適用的例外」；不能只看物品名稱或稀有度。
