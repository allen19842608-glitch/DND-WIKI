# D&D 冒險者聯盟不適用魔法物品 (Unavailable Magic Items)

## ⚙️ 規則條文 (Rule Text)

符合下列任一標準的魔法物品不適用於 AL；附錄 B 明列的例外仍可使用。（來源：《冒險者聯盟玩家指南 v2026.4》）

| 標準 | 判定摘要 | 範例（節錄） | 適用的例外 |
| :--- | :--- | :--- | :--- |
| 第三方魔法物品 | 非對應 CR 戰役的合作產品物品 | 非 CR 戰役中的 CR 物品。 | — |
| 神器 | 神器類物品 | 維克那之眼。 | — |
| 邪惡 | 具有邪惡陣營、使角色邪惡或要求邪惡行為 | 蔚藍之鋒、黑杖、書籤、阿格哈榮的龍之法杖、哈茲瑞恩、地獄鞍羈、奧庫斯雕像、凜冬之戒、開闢者。 | — |
| 傷害玩家角色 | 強迫傷害、懲罰或奪取其他玩家角色自主權 | 萬象無常牌。 | — |
| 愛情護咒 | 強迫形成愛情或類似關係 | 迷情媚藥。 | — |
| 機制效果 | 永久機制或屬性值效果 | 萬事萬象無常牌、奇蹟牌組、阿祖瑪的虛空卷軸。 | 魔豆之袋、人情、卷冊、手冊、《地下城主指南》的次要性質或怪癖、超自然贈禮。 |
| 印刷錯誤品 | 明顯或已被勘誤、設計師、AL 管理員確認的錯誤物品 | +1 秘銀條板甲。 | — |
| 未指定的 DM 選擇效果 | 卡牌、符文、法術、技能或其他效果未由文字明確指定 | 未指定的幻象牌組、助手水晶、月刃、動力裝甲、夸爾羽符、雜貨法袍、吸收權杖。 | 文字明確指定的選擇，例如夸爾羽符（天鵝船），且不符合本表其他標準或故事物品標準，或獎勵 GP 或永久魔法物品者。DM 可選擇護甲類型、傷害類型、抗性、對特定生物類型的傷害、樂器、位面及武器。 |
| 未指定的魔咒物品 | 魔咒護甲、法杖或武器未指定所附法術 | 未指定魔咒盔甲、魔咒法杖、魔咒武器。 | — |
| 抹除 | 非卷軸物品且會抹消物質 | 煙塵桶、湮滅法球、黃玉殲滅者。 | — |
| 一件物品的一部分 | 不完整或破損物品 | 精靈之靴中的一隻靴子、破損物品。 | — |
| 劇情裝置 | 與特定 NPC、地點、願望、劇情生物或事件綁定 | 傳送海螺、毀滅法球、水溺、諸界吊床、鴉族聖徽。 | 命令植物護咒、被詛咒的幸運石、靈能水晶。 |
| 施法者 | 具有智能且能施法的物品 | 特魯萊。 | — |
| 載具 | 冒險授予的魔法航行工具或大於龍骨船的載具 | 魔法船舵、魔法船、克羅諾權杖、導航球。 | 角色製作的物品。 |
| 其他具破壞性的情況 | 會顯著破壞公開遊戲或跨桌一致性的其他物品 | 黎明使者、千象無常牌、龍槍、火巨靈囚瓶。 | — |

## 💡 實戰應用與裁量 (DM Ruling)

- 先檢查附錄 B 標準，再檢查「適用的例外」；不能只看物品名稱或稀有度。
