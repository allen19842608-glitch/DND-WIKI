# 復仇之劍 (Sword of Vengeance)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀或短劍） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法武器加值**：
  - **效果**：你用此魔法武器進行的攻擊檢定和傷害擲骰獲得 +1 加值。

### 詛咒

與此物品同調會使你受到詛咒。

- **詛咒效果**：寄宿在武器內、渴望復仇的魂靈使你總是把劍帶在身上且不願分開；同調持續期間，你使用其他武器的攻擊檢定和傷害擲骰具有劣勢。攜帶此劍時，若你在戰鬥中受其他生物傷害，必須通過 DC 15 感知豁免；失敗時，你必須持續攻擊該生物，直到你或它的生命值降至 0，或你無法追上它以發動近戰攻擊。
- **解除方式**：可用通常方式解除詛咒；對劍施展放逐術也可驅逐其中的復仇魂靈。解除後，此劍成為不具其他詞條的 +1 武器。
