# 觸月劍 (Moon-Touched Sword)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀、短劍） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **月光刃鋒**：
  - **啟用／觸發**：在黑暗中將劍出鞘時。
  - **效果**：刃鋒洩出月光，創造半徑 15 呎的明亮光照及其外 15 呎的微光光照。

## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：此光照只在黑暗中且武器出鞘時產生。
