# 防禦者 (Defender)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意近戰武器） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此武器攻擊時。
  - **效果**：此魔法武器的攻擊檢定與傷害擲骰獲得 +3 加值。

- **防禦轉移**：
  - **啟用／觸發**：持握並同調期間；你每個回合第一次以此武器攻擊時。
  - **效果**：你可將此武器 +3 加值的全部或部分，從攻擊檢定與傷害擲骰轉移至你的 AC。例如，你可將武器加值降至 +1，並使 AC 獲得 +2 加值。
  - **限制與恢復**：此調整持續至你的下個回合開始；你必須持握此武器才能獲得其 AC 加值。
