# 斬首劍 (Vorpal Sword)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍或彎刀） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此武器攻擊時。
  - **效果**：此魔法武器的攻擊檢定與傷害擲骰獲得 +3 加值，並無視揮砍傷害抗性。

- **斬首**：
  - **啟用／觸發**：持握並同調期間；此武器的攻擊檢定 d20 擲出 20，且目標至少有一個頭部時。
  - **效果**：你斬下目標的一顆頭。若目標無法失去該頭部後存活，它立即**死亡**。若目標免疫揮砍傷害、沒有頭部或不需要頭部，或 DM 判定其頭部過大而無法斬下，則改為在該次命中額外受到 30 點揮砍傷害。具有傳奇抗性的目標可消耗其一次使用次數避免被斬首，但仍受到額外傷害。
