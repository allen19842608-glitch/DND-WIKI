# 狂戰斧 (Berserker Axe)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（戰斧，巨斧或戟） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法武器加值**：
  - **效果**：你使用此魔法武器進行的攻擊檢定和傷害擲骰獲得 +1 加值；同調期間，你的生命值上限增加等同等級的數值。

### 詛咒

與此物品同調會使你受到詛咒。

- **詛咒效果**：你總會把斧頭放在觸手可及處且不願分開，使用此斧以外武器的攻擊檢定具有劣勢。持有此斧時，若其他生物對你造成傷害，須進行 DC 15 感知豁免；失敗則陷入**狂怒**，直到你的回合開始時周圍 60 呎內沒有你能看見或聽見的生物。狂怒期間，你將最近、可看見或聽見的生物視為敵人；若有多名生物同樣最近，隨機選擇其中一名。你在每回合盡可能靠近該生物，並以攻擊動作攻擊它；若無法接近以此斧攻擊，耗盡移動力即結束回合。目標死亡或不再可看見或聽見時，改以符合條件的下一名最近生物為目標。
- **解除方式**：依詛咒物品共通規則，須先打破詛咒才能結束同調，例如使用移除詛咒法術。
