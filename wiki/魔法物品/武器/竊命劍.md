# 竊命劍 (Sword of Life Stealing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀或短劍） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **臨時生命值**：
  - **啟用／觸發**：持用期間。
  - **效果**：當你用這把魔法武器攻擊一個生物並在攻擊檢定的 d20中骰出20時，若目標並非構裝或亡靈，則其額外受到15點暗蝕傷害，且你獲得等於目標所受的暗蝕傷害值的臨時生命值。
