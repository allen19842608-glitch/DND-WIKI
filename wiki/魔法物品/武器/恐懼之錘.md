# 恐懼之錘 (Mace of Terror)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（硬頭錘） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **恐懼波動**：
  - **啟用／觸發**：持握武器期間，以一個**魔法**動作消耗 1 充能。
  - **效果**：武器釋放恐懼波動。距你 30 呎內由你選擇的每個生物須通過 DC 15 感知豁免，否則陷入**恐慌**狀態，持續 1 分鐘。以此方式恐慌的生物在其回合內必須盡可能遠離你，不能發動**借機攻擊**；其動作只能用來**疾走**或嘗試擺脫阻止其移動的效果。若無處可逃，它可以執行**閃避**動作。
  - **限制與恢復**：該生物在每個自己回合結束時可重複豁免，成功則提前結束此效果。

### 使用、充能與恢復

- **充能總量與恢復**：武器具有 3 充能，每日黎明重獲 1d3 已消耗的充能。
