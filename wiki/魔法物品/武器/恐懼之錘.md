# 恐懼之錘 (Mace of Terror)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（硬頭錘） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：持用期間。
  - **效果**：這把魔法武器具有3 充能，並在每日黎明時重獲1d3已消耗的充能。持握這把武器期間，你可以使用一個**魔法**動作並消耗1 充能，來從該武器中釋放出一股恐懼波動。30 呎內每個你所選擇的生物都必須成功通過一次 DC 15的感知豁免，否則將陷入**恐慌**狀態，持續1分鐘。以這種方式陷入**恐慌**的生物在其回合內必須儘可能的向遠離你的方向移動，並且它不能發動**藉機攻擊**。它只能選擇進行**疾走**動作，或嘗試擺脫一個阻止其移動的效應。如果無處可逃，則它可以執行**迴避** 動作。該生物在每個自己的回合結束時可以再次進行此豁免，豁免成功則其身上的該效應提前結束。
  - **限制與恢復**：這把魔法武器具有3 充能，並在每日黎明時重獲1d3已消耗的充能。30 呎內每個你所選擇的生物都必須成功通過一次 DC 15的感知豁免，否則將陷入**恐慌**狀態，持續1分鐘。
