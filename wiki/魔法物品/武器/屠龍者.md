# 屠龍者 (Dragon Slayer)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易武器或軍用武器） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法武器加值**：
  - **效果**：你用此魔法武器發動的攻擊檢定和傷害擲骰獲得 +1 加值。

- **屠龍傷害**：
  - **啟用／觸發**：此武器對龍類目標造成傷害時。
  - **效果**：額外造成 3d6 點與武器相同類型的傷害。
