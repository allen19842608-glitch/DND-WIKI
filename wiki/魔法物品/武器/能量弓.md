# 能量弓 (Energy Bow)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長弓或短弓） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **附加詞條**：
  - **啟用／觸發**：持用期間。
  - **效果**：這把魔法武器具有以下額外詞條。

- **束縛之箭**：
  - **啟用／觸發**：持用期間。
  - **效果**：**束縛之箭 Arrow of Restraint**。當你使用這把武器朝一個生物進行一次遠程攻擊時，你可以試圖束縛該生物而非造成傷害。若箭命中了目標，則其必須成功於一次 DC 15的力量豁免，否則陷入**束縛 Restrained**狀態，持續1分鐘。以一個動作，被一根箭束縛的生物可以進行一次 DC 20的力量（運動）檢定以掙脫束縛，若檢定成功，則其身上的此效應結束。
  - **限制與恢復**：若箭命中了目標，則其必須成功於一次 DC 15的力量豁免，否則陷入**束縛 Restrained**狀態，持續1分鐘。

- **轉移之箭**：
  - **啟用／觸發**：持用期間。
  - **效果**：**轉移之箭 Arrow of Transport**。以一個**魔法**動作，你可以向位於你60 呎內一個你可見的目標射出一根能量箭。目標可以是一名自願的中型或更小的生物，也可以是一個未被著裝或攜帶的，小到足以塞入一個5 呎立方的物件。箭將目標轉移至位於你10 呎內一處你可見的未佔空間中。

- **能量梯子**：
  - **啟用／觸發**：持用期間。
  - **效果**：**能量梯子 Energy Ladder**。以一個**魔法**動作，你可以對著一面位於你60 呎內的牆壁從此武器中射出一連串箭，箭會成為突出牆面的發光梯級，在牆上形成一架至多60 呎長的魔法梯子。梯子在消失前會持續存在1分鐘。
  - **限制與恢復**：梯子在消失前會持續存在1分鐘。
