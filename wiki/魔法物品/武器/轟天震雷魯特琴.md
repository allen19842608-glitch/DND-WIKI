# 轟天震雷魯特琴 (Lute of Thunderous Thumping)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（短棒） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法短棒與雷鳴傷害**：
  - **啟用／觸發**：將加固的魯特琴作為魔法短棒持用並命中時。
  - **效果**：該次命中額外造成 2d8 雷鳴傷害。

- **音律聯擊**：
  - **啟用／觸發**：你是吟遊詩人，且一邊哼歌或唱曲，一邊用此魯特琴進行近戰攻擊檢定時。
  - **效果**：你可以使用魅力調整值代替力量調整值。
