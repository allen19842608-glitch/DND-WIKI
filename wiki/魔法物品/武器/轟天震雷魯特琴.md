# 轟天震雷魯特琴 (Lute of Thunderous Thumping)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（短棒） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **音律聯擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：**音律聯擊 Sing and Swing**。若你是一位吟遊詩人，你可以在用該魯特琴發動近戰攻擊檢定時，使用魅力調整值來代替力量調整值，但此時你必須哼歌或唱曲。
