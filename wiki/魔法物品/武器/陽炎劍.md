# 陽炎劍 (Sun Blade)

## 📖 物品描述

這件物品看起來像一把劍柄。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長劍） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **耀光劍刃**：
  - **啟用／觸發**：持握劍柄時，以一個**附贈動作**展開或收起劍刃。
  - **效果**：**耀光劍刃 Blade of Radiance**。持握劍柄時，你可以用一個**附贈動作**將這把劍純粹由光芒構成的劍刃展開或是解除。展開劍刃的陽炎劍視為一把具有靈巧詞條的魔法長劍。如果你擁有長劍或短劍的熟練，則你也擁有對陽炎劍的熟練。

- **攻擊與傷害加值**：
  - **啟用／觸發**：劍刃存在時，以此武器發動攻擊或命中亡靈。
  - **效果**：你用該武器發動的攻擊檢定和傷害擲骰獲得+2加值，但它造成光耀傷害而非揮砍傷害。被這把劍命中的亡靈將額外受到1d8點光耀傷害。

- **耀陽**：
  - **啟用／觸發**：劍刃存在時發光；以一個**魔法**動作調整光照範圍。
  - **效果**：**耀陽 Sunlight** 。陽炎劍閃耀的劍刃會散發出15 呎的明亮光照和額外15 呎微光光照。這一光照視為日光。劍刃展開期間，你能夠以一個**魔法**動作 使明亮與微光光照半徑各擴大或縮小5 呎。光照範圍上限為明亮和微光區域各30 呎，下限為各10 呎。
