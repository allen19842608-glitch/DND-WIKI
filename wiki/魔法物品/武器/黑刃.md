# 黑刃 (Blackrazor)

## 📖 物品描述

黑刃藏於白羽山中，其黑色劍鞘由黑曜石製成；劍身則呈漆黑色，帶有如羽毛般的白色紋理。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（巨劍） |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此武器命中不死生物時。
  - **效果**：此魔法武器的攻擊檢定與傷害擲骰獲得 +3 加值。你以此武器命中不死生物時，你受到 1d10 點暗蝕傷害，且該目標恢復 1d10 點生命值；若此傷害使你的生命值降至 0，黑刃可以吞噬你的靈魂。

- **持握增益**：
  - **啟用／觸發**：持握並同調期間。
  - **效果**：你免疫魅惑與恐慌狀態，並具有 30 呎盲視。

- **吞噬靈魂**：
  - **啟用／觸發**：你以黑刃使非不死生物、非構裝生物的生物生命值降至 0 時。
  - **效果**：該生物死亡，且黑刃吞噬其靈魂；該生物只能藉由*祈願術 Wish*復活。若黑刃吞噬的不是你的靈魂，你獲得等同於該生物生命值上限的暫時生命值。

- **加速術**：
  - **啟用／觸發**：黑刃決定時；每個黎明一次。
  - **效果**：黑刃能對你施展*加速術 Haste*，無須專注，持續 1 分鐘。此法術會在黑刃決定時提早結束；黑刃能在你任何回合結束時使其結束。

### 智慧物品

- **心智與感官**：黑刃是絕對中立的智慧武器，智力 17、感知 10、魅力 19。它具有 120 呎聽覺與黑暗視覺，能說通用語，並以心靈感應溝通；與你同調時，它知曉你會的所有語言。

- **個性與目標**：黑刃高傲、自負，語氣輕蔑。它渴望吞噬靈魂，尤其是強大生物的靈魂；它也想與波濤和征服重聚。

- **靈魂飢渴**：若黑刃連續 3 日或更久沒有吞噬靈魂，它會在下一個黃昏時嘗試反抗其持用者。

### 摧毀方式

黑刃必須在機械境的巨大齒輪間被摧毀，或在奇點的樂曲中被摧毀。
