# 神聖復仇者 (Holy Avenger)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易或軍用） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要（聖騎士） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此武器攻擊時。
  - **效果**：此魔法武器的攻擊檢定與傷害擲骰獲得 +3 加值。你以此武器命中邪魔或亡靈時，該目標額外受到 2d10 點光耀傷害。

- **抗魔光環**：
  - **啟用／觸發**：持握並同調期間；武器出鞘時。
  - **效果**：武器產生源自你的 10 呎光環。你與光環內的友好生物對抗法術及其他魔法效應的豁免檢定具有優勢。若你的聖騎士等級至少為 17，光環半徑增加至 30 呎。
