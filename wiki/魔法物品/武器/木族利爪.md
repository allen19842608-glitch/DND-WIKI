# 木族利爪 (Sylvan Talon)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（匕首、刺劍、彎刀、短劍、鐮刀或矛） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **妖精交流**：
  - **啟用／觸發**：攜帶此武器於身上期間。
  - **效果**：攜帶這把武器於身上期間，你可以理解所有妖精的非書面交流方式，而妖精們同樣能理解你的非書面交流方式。

- **秘信術**：
  - **啟用／觸發**：以一個魔法動作使用此武器時。
  - **效果**：你可以使用該武器施展[[法術/戲法/傳訊術|傳訊術 (Message)]]。
  - **限制與恢復**：這項詞條一經使用，直至下個黎明前你都無法再次使用。

## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：理解妖精的非書面交流與施展傳訊術是兩項獨立效果；後者每日只能使用一次。
