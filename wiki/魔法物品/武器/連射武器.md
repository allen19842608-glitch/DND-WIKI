# 連射武器 (Repeating Shot)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **連射武器**：
  - **啟用／觸發**：持握期間。
  - **效果**：以此武器進行遠程攻擊時，攻擊檢定與傷害擲骰有 +1 加值，並無視裝填詞條；若武器沒有彈藥，攻擊時會創造一發魔法彈藥，命中或失手後消失。
