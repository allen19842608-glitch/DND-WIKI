# 魔咒武器 (Enspelled Weapon)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易或軍用） |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持用期間。
  - **效果**：這把武器中銘刻了一道八環或更低環階的法術。這道法術必須是一道屬於**咒法**、**預言**、**塑能**、**死靈**或**變化**學派的法術，在製造此武器的時候決定。此武器具有6 充能，且在每日黎明時重獲1d6已消耗的充能。持握此武器期間，你可以消耗1 充能以施展該法術。
  - **限制與恢復**：此武器具有6 充能，且在每日黎明時重獲1d6已消耗的充能。

- **法術豁免 DC 與攻擊加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：武器中銘刻的法術其環階決定了這道法術的豁免 DC 和攻擊加值，還有這把武器的稀有度（見下表）。
