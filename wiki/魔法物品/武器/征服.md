# 征服 (Whelm)

## 物品描述

征服是矮人鍛造的強大戰錘，遺失於白羽山地下城。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（戰錘） |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要（矮人，或與矮人腰帶維持同調的生物） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持用期間。
  - **效果**：以此武器進行的攻擊檢定與傷害擲骰獲得 +3 加值。

- **勁力猛投**：
  - **啟用／觸發**：以征服進行遠程攻擊命中時。
  - **效果**：征服具有投擲（射程 60/180 呎）詞條。命中時，目標額外受到 1d8 力場傷害；若目標是構裝、元素或巨人，則改為 4d8 力場傷害。無論是否命中，武器立即飛回你手中。

- **震盪波**：
  - **啟用／觸發**：以一個**魔法**動作用征服重擊地面時。
  - **效果**：你選擇的 60 呎內生物必須進行 DC 20 體質豁免；失敗時陷入震懾狀態 1 分鐘，並可在其每個回合結束時重複豁免，成功則結束效應。
  - **限制與恢復**：使用後，直至下個黎明無法再次使用。

- **超然警覺**：
  - **啟用／觸發**：持握期間。
  - **效果**：你知曉 30 呎內密門或隱藏門的位置，並可從征服施展*偵測善惡*或*物件定位術*。
  - **限制與恢復**：施展任一法術後，直至下個黎明無法再從征服施展法術。

### 特殊規則

- **智能與個性**：征服是守序中立智能武器（智力 15、感知 12、魅力 15），具有 120 呎聽覺與黑暗視覺，能以心靈感應與持用者交流，並說矮人語、巨人語與地精語。它渴望回到丹吉爾或強錘矮人氏族、保護矮人；持用者若不認同此目標，征服會反噬。
- **摧毀征服**：可用剛被殺死的遠古黑龍酸性膽汁熔化，或由強錘矮人氏族的合法領袖在鍛造廠熔化。
