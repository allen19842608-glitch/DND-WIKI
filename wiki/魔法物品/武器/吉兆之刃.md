# 吉兆之刃 (Luck Blade)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀、鐮刀或短劍） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此武器攻擊時。
  - **效果**：此魔法武器的攻擊檢定與傷害擲骰獲得 +1 加值。攜帶此武器期間，你的豁免檢定也獲得 +1 加值。

- **幸運**：
  - **啟用／觸發**：攜帶並同調期間；你未陷入**失能 Incapacitated**狀態且 D20 檢定失敗時；無須動作；每個黎明一次。
  - **效果**：你可重擲該次失敗的 D20 檢定，但必須使用新結果。
  - **限制與恢復**：使用後，直到下個黎明前無法再次使用。

- **可施展法術**：
  - **啟用／觸發**：持握並同調期間；消耗 1 充能；每個黎明一次。
  - **效果**：此武器具有 1d3 充能。你可從中施展*祈願術 Wish*。
  - **限制與恢復**：使用後，直到下個黎明前無法再次使用。充能耗盡時，此武器失去此能力。
