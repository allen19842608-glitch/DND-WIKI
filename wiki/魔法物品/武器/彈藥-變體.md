# 彈藥（+1、+2、+3） (Ammunition，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意彈藥） |
| 稀有度 (Rarity) | 多種稀有度（見變體） |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；命中後失去魔法效果 |
| 常見包裝與價值 | 通常以 10 或 20 枚為一組；10 枚的價值等同一瓶相同稀有度的藥水。 |

### 變體

| 變體 | 攻擊檢定與傷害擲骰加值 | 稀有度 |
| :--- | :--- | :--- |
| +1 彈藥 | +1 | 非普通 |
| +2 彈藥 | +2 | 珍稀 |
| +3 彈藥 | +3 | 極珍稀 |

### 物品效果

- **魔法加值**：
  - **啟用／觸發**：使用此彈藥進行攻擊時。
  - **效果**：你使用此魔法彈藥進行的攻擊檢定和傷害擲骰，獲得該變體所列的加值。此彈藥一旦擊中目標即不再具有魔法效果。
