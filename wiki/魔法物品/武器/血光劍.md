# 血光劍 (Sword of Wounding)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀或短劍） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **阻礙生命恢復**：
  - **啟用／觸發**：以此武器命中一個生物時。
  - **效果**：目標額外受到 2d6 暗蝕傷害，並須進行 DC 15 體質豁免。豁免失敗時，目標在 1 小時內無法恢復生命值；其可在每個回合結束時重做此豁免，成功則結束此效應。（來源：城主指南2024，魔法物品詳述，武器／珍稀，L68）
