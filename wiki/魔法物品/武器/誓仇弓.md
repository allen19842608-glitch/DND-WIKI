# 誓仇弓 (Oathbow)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長弓或短弓） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **指定仇敵**：
  - **啟用／觸發**：持握並同調期間；以此弓進行遠程攻擊時，說出命令詞「負我者死」。
  - **效果**：攻擊目標成為你的仇敵，直到死亡或第七日後的黎明。你同時只能指定一名仇敵；仇敵死亡後，可在下個黎明後重新選擇。你彎弓搭箭時，誓仇弓會以精靈語低語「速殲敵」。

- **仇敵獵殺**：
  - **啟用／觸發**：持握並同調期間；以此弓對你的仇敵進行遠程攻擊時。
  - **效果**：你的攻擊檢定具有優勢；目標不受半身或四分之三掩護的益處，你不因超出常規射程而具有劣勢。命中時，仇敵額外受到 3d6 點穿刺傷害。

- **仇敵執念**：
  - **啟用／觸發**：你的仇敵仍存活時。
  - **效果**：你使用其他武器進行的攻擊檢定具有劣勢。
