# 屠殺彈藥 (Ammunition of Slaying)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意彈藥） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；造成下述額外傷害後變為非魔法彈藥 |

### 物品效果

- **針對特定生物的額外傷害**：
  - **啟用／觸發**：指定類型的生物受到此魔法彈藥的傷害時。
  - **效果**：此彈藥針對一種由 DM 選擇，或依下表隨機決定的生物類型。觸發時，該生物須進行 DC 17 體質豁免；失敗時額外受到 6d10 力場傷害，成功時額外受到一半傷害。
  - **限制與恢復**：彈藥對生物造成上述額外傷害後，變為非魔法彈藥。
