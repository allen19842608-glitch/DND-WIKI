# 應答之劍 (Sword of Answering)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長劍） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持握並同調期間；以此劍攻擊時。
  - **效果**：此魔法長劍的攻擊檢定與傷害擲骰獲得 +3 加值。

- **應答反擊**：
  - **啟用／觸發**：持握並同調期間；觸及內的生物對你造成傷害時；使用一個**反應**。
  - **效果**：你使用此劍對該生物進行一次近戰攻擊。此攻擊檢定具有優勢，且該次特殊攻擊造成的傷害忽略目標對該傷害的免疫與抗性。
