# 銳鋒之劍 (Sword of Sharpness)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、或彎刀） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **命中效果**：
  - **啟用／觸發**：持用期間。
  - **效果**：當你用這把魔法武器命中一個物件時，該武器的武器傷害骰取滿。

- **重擊效果**：
  - **啟用／觸發**：持用期間。
  - **效果**：用這把武器攻擊生物並在攻擊檢定的 d20中投出20時，該目標額外受到14點揮砍傷害並獲得1級**力竭**。
