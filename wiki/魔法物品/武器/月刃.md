# 月刃 (Moonblade)

## 📖 物品描述

月刃是精靈製造、最珍貴且受嚴密守護的魔法物品之一。遠古時期幾乎每個精靈貴族家族都擁有一把；隨著家族血脈消亡與持有者失蹤，如今僅存少數。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（巨劍、長劍、刺劍、彎刀或短劍） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要（由武器選擇的生物） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **同調選擇**：
  - **啟用／觸發**：生物嘗試與月刃同調時。
  - **效果**：月刃尋求秉性相合、目標相同的持用者。若月刃接受你，你立即成功同調，並有一枚新符文出現在武器上；同調持續至你**死亡**或月刃被摧毀。除月刃持有者外，其他人持用它時，它如同同類非魔法武器。
  - **限制與恢復**：若月刃拒絕你，它拒絕同調並使你的 D20 檢定具有劣勢，持續 24 小時；此效應可由*移除詛咒 Remove Curse*或類似魔法提前結束。

- **符文武器**：
  - **啟用／觸發**：持握並同調期間；以此武器攻擊時。
  - **效果**：月刃通常具有 1d6 + 1 枚符文，每多一名它自願侍奉的持有者便多一枚。第一枚符文使其成為 +1 魔法武器；第二枚及以後的符文各賦予一項月刃詞條，由 DM 選擇或依下表隨機決定。

- **次級詞條**：
  - **啟用／觸發**：持握並同調期間。
  - **效果**：除符文詞條外，每把月刃另具有一項次級詞條，依本章的魔法物品次級詞條表隨機決定。

### 月刃詞條

| d100 | 詞條 |
| :--- | :--- |
| 01–60 | 此武器攻擊檢定與傷害擲骰的加值增加 1，最多 +3；若已為 +3，重新擲骰。 |
| 61–75 | 以月刃命中時額外造成 1d6 點力場傷害。每再次獲得此詞條，額外傷害增加 1d6，最多 3d6；若已為 3d6，重新擲骰。 |
| 76–80 | 月刃獲得投擲（20/60 呎）詞條；你投擲它攻擊後，它回到你的手中。 |

### 智慧物品

- **心智與感官**：月刃是智慧魔法武器，智力 12、感知 10、魅力 12，具有 120 呎聽覺與 120 呎黑暗視覺，陣營與創造者相同。

- **溝通與個性**：月刃以情緒溝通，想傳達感知時會讓持用者的手感到刺痛；持用者出神或睡眠時，它可藉由夢境或幻象溝通。它的個性與創造者相似；一旦認定主人，即使主人的陣營或目標後來改變，它仍相信只有該人能揮舞它。
