# 處刑者之斧 (Executioner's Axe)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（戰斧、巨斧、戟或手斧） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用該魔法武器發動的攻擊檢定和傷害擲骰獲得+1加值。

- **類人斬擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用該武器命中的任何類人都額外受到2d6揮砍傷害，且你獲得等於造成的該額外傷害的臨時生命值。
