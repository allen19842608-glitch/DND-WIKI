# 衝擊彈 (Walloping Ammunition)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意彈藥） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **衝擊**：
  - **啟用／觸發**：此彈藥命中生物時。
  - **效果**：任何被這枚彈藥命中的生物都必須成功通過一次 DC 10的力量豁免，豁免失敗則會陷入**伏地 Prone**狀態。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：只有彈藥命中時才觸發；未命中時不會要求目標進行豁免。
