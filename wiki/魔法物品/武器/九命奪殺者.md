# 九命奪殺者 (Nine Lives Stealer)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易武器或軍用武器） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用該魔法武器發動的攻擊檢定和傷害擲骰獲得+2加值。

- **奪命殺**：
  - **啟用／觸發**：持用期間。
  - **效果**：**奪命殺 Life Stealing** 。該武器有1d8+1 充能。當你用該武器攻擊一名生命值不足100的生物且在攻擊檢定中擲出20時，該生物必須成功通過一次 DC 15的體質豁免否則立刻因生命力被該武器吸乾而死（亡靈與構裝自動成功於此豁免）。如果該生物因此被殺死，九命奪殺者將失去1 充能。該武器會在充能耗盡後失去這一詞條。
  - **限制與恢復**：該武器會在充能耗盡後失去這一詞條。
