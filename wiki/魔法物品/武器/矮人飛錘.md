# 矮人飛錘 (Dwarven Thrower)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（戰錘） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要；矮人，或已與[[魔法物品/奇物/矮人腰帶\|矮人腰帶]]同調的生物 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊加值與投擲**：
  - **效果**：你用此魔法武器進行的攻擊檢定與傷害擲骰獲得 +3 加值。它具有投擲屬性，常規射程為 20 呎，最大射程為 60 呎。

- **遠程命中與返回**：
  - **啟用／觸發**：你以此武器進行遠程攻擊時。
  - **效果**：命中時額外造成 1d8 力場傷害；若目標是巨人，改為額外造成 2d8 力場傷害。遠程攻擊命中或未命中後，武器立即飛回你的手中。

### 來源文字差異

中文來源 L28 僅寫「需矮人同調」；同版英文原文 `/item/651 reqAttune` 寫「矮人，或已與矮人腰帶同調的生物」。依英文原文，表格列出完整條件；L29 與英文 `entries[0]` 的返回時機則以「命中或未命中後」明確表述。
