# 矮人飛錘 (Dwarven Thrower)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（戰錘） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **飛錘**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用該魔法武器發動的攻擊檢定和傷害擲骰獲得+3加值。它具有投擲屬性，常規射程為20 呎，最大射程為60 呎。當你用此武器發動遠程攻擊命中時，它將造成1d8的額外力場傷害。如果命中的目標是一個生物類型為巨人的生物，則額外傷害提升為2d8。攻擊後，此武器將立即飛回你的手中。
