# 雜技長棍 (Quarterstaff of the Acrobat)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長棍） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔化武器**：
  - **啟用／觸發**：持用期間。
  - **效果**：你以此魔法武器進行的攻擊檢定和傷害擲骰具有+2加值。

- **微光照明**：
  - **啟用／觸發**：持用期間。
  - **效果**：持握此武器期間，你可以在骰先攻後令該長棍散發出10 呎微光光照。你也可以用一個**附贈動作**使其散發出同樣的光照，或使該光照熄滅。

- **變形**：
  - **啟用／觸發**：持用期間。
  - **效果**：持握此武器期間，你可以用一個**附贈動作**轉化其形態，將其變為一根6寸短杆（為便於儲存）或一根10 呎長杆，又或者將其恢復至一根長棍。此武器至多隻能伸長至其周圍空間所允許的長度。

- **形態詞條**：
  - **啟用／觸發**：持用期間。
  - **效果**：在相應形態下，此武器具有以下額外詞條：

- **援助特技**：
  - **啟用／觸發**：持用期間。
  - **效果**：**援助特技 Acrobatics Assist（僅限長棍和10 呎長杆形態）。**持握此武器期間，你在敏捷（特技）檢定上具有優勢。

- **偏斜攻擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：**偏斜攻擊 Attack Deflection（僅限長棍形態）。**若你在持握此武器期間被一次攻擊命中，你可以用一個**反應**讓武器盤繞於己身，使你針對觸發此反應的攻擊中護甲等級+5，這可能導致該攻擊變為未命中。該詞條在你完成一次短休或長休前無法再次使用。
  - **限制與恢復**：該詞條在你完成一次短休或長休前無法再次使用。

- **遠程武器**：
  - **啟用／觸發**：持用期間。
  - **效果**：**遠程武器 Ranged Weapon（僅限長棍形態）。**此武器具有投擲（30/120）詞條。你以此武器進行一次遠程攻擊之後，它會立即飛回你的手中。
