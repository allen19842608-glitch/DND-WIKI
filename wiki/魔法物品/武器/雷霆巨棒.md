# 雷霆巨棒 (Thunderous Greatclub)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（巨棒） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **附加詞條**：
  - **啟用／觸發**：持用期間。
  - **效果**：這把武器具有以下附加詞條:

- **雷霆霹靂**：
  - **啟用／觸發**：持用期間。
  - **效果**：**雷霆霹靂 Clap of Thunder** 。以一個**魔法**動作，你可以使用這把武器擊打一處堅硬表面，製造出在300 呎內都能聽見的雷鳴般巨響。並且，你製造出一個30 呎錐狀的雷霆能量區域。錐狀區域內的每個生物都必須成功通過一次 DC 15的力量豁免，豁免失敗則其陷入**伏地 Prone** 狀態。錐狀區域內未被穿著或攜帶的非魔法物件會受到3d8雷鳴傷害。

- **地震術**：
  - **啟用／觸發**：持用期間。
  - **效果**：**地震術 Earthquake**。以一個**魔法**動作，你可以使用這把武器敲擊地面，在以敲擊點為中心，半徑50 呎的範圍內引起一陣強烈的地震擾動。該區域內與地面接觸的建築物會受到50點鈍擊傷害，並且該區域地面上的每個生物都必須成功通過一次 DC 20的敏捷豁免，豁免失敗則其陷入**伏地 Prone**狀態。若該生物同時正在維持專注，則其必須成功通過一次 DC 20的體質豁免，豁免失敗則其專注被打斷。此外，你可以在該區域內任意一處的地面上打開一道30 呎深，10 尺寬的裂縫。任何位於裂縫開口位置的生物都必須進行一次 DC 20的敏捷豁免，豁免失敗則其落入裂縫中，豁免成功則其會隨著裂縫邊緣移動。任何位於裂縫開口位置的建築物都會坍塌落入裂縫中。這項詞條一經使用，則其直至下個黎明前都無法再次使用。
  - **限制與恢復**：這項詞條一經使用，則其直至下個黎明前都無法再次使用。
