# 淬毒匕首 (Dagger of Venom)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（匕首） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：以此魔法武器發動攻擊時。
  - **效果**：你以此魔法武器進行的攻擊檢定和傷害擲骰獲得+1加值。

- **塗毒攻擊**：
  - **啟用／觸發**：以一個**附贈動作**，用魔法使刀刃覆上毒液。
  - **效果**：毒液持續 1 分鐘，或直到你以此武器攻擊命中一名生物為止。該生物須通過 DC 15 體質豁免，否則受到 2d10 毒素傷害，並陷入**中毒**狀態 1 分鐘。
  - **限制與恢復**：此武器的塗毒能力直到下個黎明前無法再次使用。
