# 淬毒匕首 (Dagger of Venom)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（匕首） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：你以此魔法武器進行的攻擊檢定和傷害擲骰獲得+1加值。

- **塗毒攻擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：你可以用**附贈動作**為匕首覆上毒液，持續1分鐘。用這把武器發動的一次攻擊成功命中生物後毒液也會消失。此時，被命中的生物必須成功通過一次 DC 15的體質豁免否則受到2d10毒素傷害並陷入**中毒**狀態1分鐘。直至下個黎明前，該附贈動作都無法被再次使用。
  - **限制與恢復**：你可以用**附贈動作**為匕首覆上毒液，持續1分鐘。用這把武器發動的一次攻擊成功命中生物後毒液也會消失。直至下個黎明前，該附贈動作都無法被再次使用。
