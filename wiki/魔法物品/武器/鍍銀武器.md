# 鍍銀武器 (Silvered Weapon)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易或軍用） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **鍍銀重擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：這件魔法武器使用鍊金工藝鍍上了一層銀。當你用該武器對一個變形的生物造成一次重擊時，該武器令該次傷害在計算時額外擲一顆骰子。
