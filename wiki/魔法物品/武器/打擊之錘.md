# 打擊之錘 (Mace of Smiting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（硬頭錘） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **構裝毀壞**：
  - **啟用／觸發**：持用期間。
  - **效果**：當你使用這把武器進行一次攻擊檢定並擲出20時，目標會額外受到7鈍擊傷害。如果目標為構裝生物，則其受到的額外鈍擊傷害為14。如果一個構裝生物因受到該傷害而生命值被降至25及以下，則該生物被摧毀。
