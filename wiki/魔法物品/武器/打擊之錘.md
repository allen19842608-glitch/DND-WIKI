# 打擊之錘 (Mace of Smiting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（硬頭錘） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法武器加值**：
  - **效果**：你使用此魔法武器進行的攻擊檢定和傷害擲骰獲得 +1 加值；以它攻擊構裝生物時，該加值提升為 +3。

- **構裝毀壞**：
  - **啟用／觸發**：以此武器進行攻擊檢定並擲出 20 時。
  - **效果**：目標額外受到 7 點鈍擊傷害；若為構裝生物，則改為額外受到 14 點鈍擊傷害。若構裝生物在受到此傷害後只剩 25 點或更少生命值，該生物被摧毀。
