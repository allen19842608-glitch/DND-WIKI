# 閃電標槍 (Javelin of Lightning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（標槍） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **命中時變更傷害類型**：
  - **啟用／觸發**：以此魔法武器發動的攻擊檢定命中時。
  - **效果**：你可以選擇讓該次攻擊造成閃電傷害，取代穿刺傷害。

- **閃電束**：
  - **啟用／觸發**：向距離你至多 120 呎的一個目標投擲此武器時，可放棄遠程攻擊檢定，改使武器化為閃電束。
  - **效果**：閃電束在你與目標之間形成一條寬 5 呎的線。目標與線內其他每個生物（你除外）須進行 DC 13 敏捷豁免；失敗受到 4d6 閃電傷害，成功則受一半傷害。造成傷害後，武器立即回到你手中。
  - **限制與恢復**：此效果直到下個黎明前無法再次使用。
