# 閃電標槍 (Javelin of Lightning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（標槍） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **閃電束**：
  - **啟用／觸發**：持用期間。
  - **效果**：**閃電束 Lightning Bolt**。當你向至多120 呎內的一個目標投擲該武器時，你可以選擇不進行遠程攻擊檢定，而是改為將該武器變為一道閃電束。該閃電束會在你和目標之間形成一個5 呎線狀區域，目標及該區域內的每個生物（除你之外）都必須進行一次 DC 13的敏捷豁免，豁免失敗者受到4d6閃電傷害，豁免成功則傷害減半。該武器會在造成該傷害後立即回到你的手中。直到下個黎明前，該詞條都無法再使用。
