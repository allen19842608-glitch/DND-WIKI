# 惡毒武器 (Vicious Weapon)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易武器或軍用武器） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **惡毒傷害**：
  - **啟用／觸發**：此魔法武器命中生物時。
  - **效果**：目標額外受到 2d6 傷害，傷害類型與武器通常造成的傷害類型相同。
