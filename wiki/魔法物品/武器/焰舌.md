# 焰舌 (Flame Tongue)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意近戰武器） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **烈焰刀鋒**：
  - **啟用／觸發**：持握並同調期間；以一個**附贈動作**說出命令語時。
  - **效果**：武器用來造成傷害的部分會被烈焰包覆，散發出40 呎範圍的明亮光照，以及額外40 呎的微光光照。武器燃燒期間，命中的目標額外受到2d6點火焰傷害。
  - **限制與恢復**：火焰持續燃燒到你丟下武器、將它收起或入鞘，或以一個**附贈動作**再次說出命令語為止。
