# 巨人屠殺者 (Giant Slayer)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易武器或軍用武器） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用此魔法武器發動的攻擊檢定和傷害擲骰獲得+1加值。

- **擊倒巨人**：
  - **啟用／觸發**：持用期間。
  - **效果**：你用此武器命中一名巨人時，該巨人額外受到與武器傷害類型相同的2d6點傷害，且必須成功通過一次 DC 15的力量豁免否則陷入**伏地 Prone**狀態。
