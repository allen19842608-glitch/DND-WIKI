# 霜銘 (Frost Brand)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（長柄刀、巨劍、長劍、刺劍、彎刀或短劍） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：持握期間。
  - **效果**：當你用此魔法武器以一次攻擊檢定命中目標時，目標將受額外受到1d6寒冷傷害。此外，持握此武器期間你對火焰傷害具有抗性。

- **光照**：
  - **啟用／觸發**：持握期間。
  - **效果**：在嚴寒環境中，此武器將會發出10 呎明亮光照以及其外10 呎的微光光照。

- **使用限制**：
  - **啟用／觸發**：持握期間；拔出武器時。
  - **效果**：拔出此武器時，你可以選擇讓周圍30 呎內的所有非魔法火焰熄滅。該詞條一經使用，直到1小時之後才可再次使用。
