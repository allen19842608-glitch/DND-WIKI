# 警戒武器 (Weapon of Warning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意簡易武器或軍用武器） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

完成同調後，只要武器位於你的觸及範圍內，你和你 30 呎內的盟友便是下列效果的受益者。

- **警報術**：
  - **啟用／觸發**：戰鬥開始時，受益者處於自然睡眠。
  - **效果**：武器會魔法性地喚醒受益者；無法喚醒因魔法導致睡眠的受益者。

- **超然備戰**：
  - **啟用／觸發**：受益者擲先攻時。
  - **效果**：受益者的先攻擲骰具有優勢。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：武器只需在你觸及範圍內，無須持用；但必須先完成同調，且盟友必須位於你 30 呎內。
