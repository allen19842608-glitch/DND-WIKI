# 飛行藥水 (Potion of Flying)

## 📖 物品描述

透明藥液漂浮在容器頂部，內有些許雲霧狀白色雜質飄蕩。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飛行與懸浮**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得等同於自身速度的飛行速度，並且可以懸浮，持續 1 小時。
  - **限制與恢復**：藥水效應結束時，若你仍在空中且沒有其他方式維持飛行，就會墜落。
