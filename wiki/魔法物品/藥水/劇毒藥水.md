# 劇毒藥水 (Potion of Poison)
## 📖 物品描述

這瓶混合物的外觀、氣味與味道都像[[魔法物品/藥水/治療藥水|治療藥水]]或其他有益藥水。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **幻術偽裝**：
  - **效果**：這實際上是一瓶用幻術魔法偽裝的毒藥；[[法術/1環/鑑定術|鑑定術]]（Identify）可以揭露其本質。

- **劇毒**：
  - **啟用／觸發**：飲下此藥水時。
  - **效果**：你受到 4d6 毒素傷害，並須通過 DC 13 體質豁免，否則陷入[[規則/狀態/中毒|中毒]]狀態 1 小時。
