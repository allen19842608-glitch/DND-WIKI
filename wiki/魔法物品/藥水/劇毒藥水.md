# 劇毒藥水 (Potion of Poison)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **偽裝毒藥**：
  - **啟用／觸發**：使用時。
  - **效果**：然而，這實際上是一瓶用**幻術**魔法偽裝的毒藥。_鑑定術 Identify_可以揭露其本質。

- **劇毒**：
  - **啟用／觸發**：使用時。
  - **效果**：如果你飲下這瓶藥水，你受到4d6毒素傷害並必須通過 DC 13的體質豁免否則陷入**中毒**狀態，持續1小時。
