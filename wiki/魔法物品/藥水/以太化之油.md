# 以太化之油 (Oil of Etherealness)

## 物品描述

這種渾濁的灰色油在容器外形成油珠，並迅速蒸發。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；塗抹時耗用所需瓶數 |

### 物品效果

- **塗抹以太化之油**：
  - **啟用／觸發**：將油塗抹在一名生物身上；塗抹需花費 10 分鐘。
  - **效果**：一瓶可覆蓋一名中型或更小的生物，以及其穿戴與攜帶的裝備；體型每比中型大一級，須額外使用一瓶。受影響生物獲得[[法術/7環/以太化|以太化 (Etherealness)]]法術的效果，持續 1 小時。
