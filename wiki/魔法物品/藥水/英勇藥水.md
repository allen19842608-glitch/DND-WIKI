# 英勇藥水 (Potion of Heroism)

## 📖 物品描述

這瓶藍色藥液如同沸騰般冒出氣泡與蒸氣。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得 10 點暫時生命值，持續 1 小時；同一時間內，你受到*祝福術 Bless*效應影響，無須專注。
