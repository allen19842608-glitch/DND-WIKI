# 隱身藥水 (Potion of Invisibility)

## 物品描述

容器看上去像是空的，但拿起來能感到裡面裝著藥液。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **隱形**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得**隱形**狀態，持續至多 1 小時。
  - **限制與恢復**：若你進行攻擊檢定、造成傷害或施展法術，效應提前結束。
