# 重拳藥水 (Potion of Pugilism)

## 📖 物品描述

瓶中裝著嚐起來像菠菜的濃稠綠色流體。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **重拳**：
  - **啟用／觸發**：使用時。
  - **效果**：飲下這瓶藥水後，你的每次徒手打擊命中時都會額外造成1d6力場傷害。
  - **限制與恢復**：效應持續10分鐘。
