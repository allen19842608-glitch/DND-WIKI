# 攀爬藥水 (Potion of Climbing)

## 📖 物品描述

這瓶藥水分離成如岩層般的褐、銀、灰三層顏色；搖晃也無法混合顏色。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得等同於自身速度的攀爬速度，持續 1 小時；在此期間，為攀爬進行的力量（運動）檢定具有優勢。
