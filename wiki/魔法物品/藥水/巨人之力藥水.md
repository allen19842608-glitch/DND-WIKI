# 巨人之力藥水 (Potion of Giant Strength)

## 📖 物品描述

透明藥液中漂浮著一小片對應巨人的指甲。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **巨人之力**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你的力量屬性值變為下表中對應巨人的數值，持續 1 小時。如果你原本的力量屬性值等於或高於該數值，藥水對你無效。

### 巨人種類與數值

| 藥水變體 | 力量 | 稀有度 |
| :--- | :---: | :---: |
| 山丘巨人之力藥水 | 21 | 非普通 |
| 霜巨人之力藥水 | 23 | 珍稀 |
| 石巨人之力藥水 | 23 | 珍稀 |
| 火巨人之力藥水 | 25 | 珍稀 |
| 雲巨人之力藥水 | 27 | 極珍稀 |
| 風暴巨人之力藥水 | 29 | 傳說 |
