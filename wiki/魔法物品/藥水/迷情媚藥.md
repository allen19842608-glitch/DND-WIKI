# 迷情媚藥 (Philter of Love)

## 📖 物品描述

玫瑰色氣泡藥液中含有一個容易忽略的心形氣泡。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **迷情魅惑**：
  - **啟用／觸發**：飲下藥水後的 10 分鐘內，下一次看見一個生物時。
  - **效果**：你被該生物魅惑，陷入[[規則/狀態/魅惑|魅惑]]狀態，持續 1 小時。
