# 水下呼吸藥水 (Potion of Water Breathing)

## 📖 物品描述

這瓶渾濁綠色液體聞起來像海水，其中漂浮一個水母形狀的氣泡。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你可在水下呼吸，持續 24 小時。
