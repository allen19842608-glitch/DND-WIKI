# 讀心藥水 (Potion of Mind Reading)

## 📖 物品描述

黏稠紫色藥液中漂浮著一團粉色卵形雲霧。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **偵測思想效應**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得[[法術/2環/偵測思想|偵測思想]]法術的效應，豁免 DC 為 13，持續 10 分鐘，無須專注。
