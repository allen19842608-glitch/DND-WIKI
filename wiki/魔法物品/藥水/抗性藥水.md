# 抗性藥水 (Potion of Resistance)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你對一種傷害類型具有抗性，持續 1 小時。該類型由 DM 指定，或擲下表的 d10 決定。
