# 化獸為友藥水 (Potion of Animal Friendship)

## 📖 物品描述

攪動渾濁藥液時可見細碎殘渣：魚鱗、蜂鳥羽毛、貓爪或松鼠毛髮。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時，你可以施展三環版本的_化獸為友 Animal Friendship_ 法術（豁免 DC 13）。
