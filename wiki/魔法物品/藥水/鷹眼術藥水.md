# 鷹眼術藥水 (Potion of Clairvoyance)

## 📖 物品描述

一顆眼球在泛黃藥液中沉浮，但在容器打開期間會消失。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得[[法術/3環/鷹眼術|鷹眼術]]法術的效應，無須專注。
