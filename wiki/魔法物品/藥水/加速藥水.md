# 加速藥水 (Potion of Speed)

## 📖 物品描述

黃黑相間的藥液自行旋轉成漩渦狀。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **法術效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得[[法術/3環/加速術|加速術]]法術的效應，持續 1 分鐘，無須專注；效應結束時不會承受該法術通常造成的倦怠。
