# 加速藥水 (Potion of Speed)

## 📖 物品描述

黃黑相間的藥液自行旋轉成漩渦狀。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **法術效果**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時，你獲得法術_加速術 Haste_的效應，持續1分鐘（無需專注），並且不會遭受通常在效應結束時泛起倦意的影響。
