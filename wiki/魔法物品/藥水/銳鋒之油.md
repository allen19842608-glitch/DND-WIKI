# 銳鋒之油 (Oil of Sharpness)

## 📖 物品描述

透明凝膠狀油膏中摻雜極纖細、微小的銀色碎片。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **銳鋒塗層**：
  - **啟用／觸發**：花費 1 分鐘，將一扁瓶油塗在一把近戰武器或 20 發彈藥上。
  - **效果**：只有非魔法且造成揮砍或穿刺傷害的近戰武器與彈藥會受影響。油隨後魔法性地滲入塗抹處，使該武器成為 +3 武器，或使該批彈藥成為 +3 彈藥。
