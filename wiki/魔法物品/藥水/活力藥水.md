# 活力藥水 (Potion of Vitality)

## 📖 物品描述

深紅藥液發出有節奏的微光，令人聯想到心跳。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **半位面休養**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時，它將移除你具有的任何**力竭**等級，並結束你的**中毒**狀態。在接下來的24小時內，你消耗生命骰來恢復生命時將直接取用最大值。
