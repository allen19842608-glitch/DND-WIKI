# 活力藥水 (Potion of Vitality)

## 📖 物品描述

深紅藥液發出有節奏的微光，令人聯想到心跳。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **恢復活力**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你現有的所有**力竭**等級都被移除，且你的**中毒**狀態結束。接下來 24 小時內，每當你消耗生命骰恢復生命值，均恢復該生命骰可提供的最大值。
