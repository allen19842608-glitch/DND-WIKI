# 氣化形體藥水 (Potion of Gaseous Form)

## 📖 物品描述

容器看似裝著流動、傾瀉如水的霧氣。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **氣化形體效應**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得[[法術/3環/氣化形體|氣化形體]]法術的效應，無須專注。
  - **限制與恢復**：效應持續至多 1 小時；你可以用一個**附贈動作**提前結束。
