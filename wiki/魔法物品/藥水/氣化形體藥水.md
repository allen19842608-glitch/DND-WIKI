# 氣化形體藥水 (Potion of Gaseous Form)

## 📖 物品描述

容器看似裝著流動、傾瀉如水的霧氣。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **當你飲下這瓶藥水時，你獲得法術氣化形體**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時，你獲得法術_氣化形體 Gaseous Form_的效應，持續1小時（無需專注）或你以**附贈動作** 結束這個效應為止。
