# 高等隱身藥水 (Potion of Greater Invisibility)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **隱形**：
  - **啟用／觸發**：使用時。
  - **效果**：這瓶藥水的容器看上去像是空的，但感覺上像是裝著藥液。當你飲下這瓶藥水時，你獲得**隱形**狀態，持續1小時。
  - **限制與恢復**：當你飲下這瓶藥水時，你獲得**隱形**狀態，持續1小時。
