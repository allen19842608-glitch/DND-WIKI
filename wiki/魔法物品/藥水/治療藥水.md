# 治療藥水 (Potions of Healing)

## 📖 物品描述

無論藥效如何，紅色藥液在搖晃時都會閃爍。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時將恢復生命值。生命值的恢復量取決於藥水的稀有度，如下表所述。

### 隨機表

| **藥水** | **恢復生命值** | **稀有度** |
| --- | --- | --- |
| 治療藥水 | 2d4+2 | 普通 |
| 治療藥水（高等） | 4d4+4 | 非普通 |
| 治療藥水（強效） | 8d4+8 | 珍稀 |
| 治療藥水（極效） | 10d4+20 | 極珍稀 |
