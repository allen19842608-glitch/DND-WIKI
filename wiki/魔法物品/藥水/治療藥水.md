# 治療藥水 (Potions of Healing)

## 📖 物品描述

無論藥效如何，紅色藥液在搖晃時都會閃爍。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：以一個**附贈動作**飲用，或依共通藥水規則將其施用於另一生物。普通治療藥水另明定可施用於你 5 呎內的生物。
  - **效果**：飲用或受施用的生物恢復下表所列的生命值。

### 藥水變體與恢復量

| **藥水** | **恢復生命值** | **稀有度** |
| --- | --- | --- |
| 治療藥水 | 2d4+2 | 普通 |
| 良效治療藥水 | 4d4+4 | 非普通 |
| 強效治療藥水 | 8d4+8 | 珍稀 |
| 極效治療藥水 | 10d4+20 | 極珍稀 |
