# 通曉藥水 (Potion of Comprehension)

## 📖 物品描述

藥液是透明調配物，鹽粒與煙塵在其中旋轉。

| 項目 | 內容 |

| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **當你飲下這瓶藥水時，你獲得法術通曉語言**：
  - **啟用／觸發**：使用時。
  - **效果**：當你飲下這瓶藥水時，你獲得法術_通曉語言 Comprehend Languages_的效應，持續1小時。
