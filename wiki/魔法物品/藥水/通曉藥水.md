# 通曉藥水 (Potion of Comprehension)

## 📖 物品描述

藥液是透明調配物，鹽粒與煙塵在其中旋轉。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **通曉語言效應**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得[[法術/1環/通曉語言|通曉語言]]法術的效應，持續 1 小時。
