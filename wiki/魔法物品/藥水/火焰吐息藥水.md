# 火焰吐息藥水 (Potion of Fire Breath)

## 📖 物品描述

橙色藥液不停閃爍，容器頂部充滿煙霧，開啟時會飄散而出。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **火焰吐息**：
  - **啟用／觸發**：飲用此藥水後，以一個**附贈動作**向 30 呎內的一名目標噴吐火焰。
  - **效果**：目標須進行 DC 13 敏捷豁免，失敗受到 4d6 點火焰傷害，成功傷害減半。
  - **限制與恢復**：此效應在你第三次噴吐火焰後，或飲用藥水後經過 1 小時時結束。
