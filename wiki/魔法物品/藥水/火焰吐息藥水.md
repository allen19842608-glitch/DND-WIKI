# 火焰吐息藥水 (Potion of Fire Breath)

## 📖 物品描述

橙色藥液不停閃爍，容器頂部充滿煙霧，開啟時會飄散而出。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **火焰吐息**：
  - **啟用／觸發**：使用時。
  - **效果**：在你飲下這瓶藥水後，你可以執行**附贈動作**，向位於你30 呎內的一名目標噴吐出火焰。目標必須通過 DC 13的敏捷豁免，豁免失敗則受到4d6火焰傷害，豁免成功則傷害減半。效應將在你噴吐三次火焰或經過一小時後結束。
