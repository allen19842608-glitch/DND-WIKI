# 成長藥水 (Potion of Growth)

## 📖 物品描述

藥液中的紅色部分會由小球膨脹後再收縮，將周圍清澈藥液染紅；搖晃藥水不會打斷此過程。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得*變巨術／縮小術 Enlarge/Reduce*的變巨效應，持續 10 分鐘，無須專注。
