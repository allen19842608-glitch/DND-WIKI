# 延壽藥水 (Potion of Longevity)

## 📖 物品描述

一顆違反常理般跳動的微型心臟懸浮於琥珀色藥液中；藥水打開時，這些成分會消失。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

  - **限制與恢復**：這些成分將在藥水被打開時消失。
