# 延壽藥水 (Potion of Longevity)

## 📖 物品描述

一顆違反常理般跳動的微型心臟懸浮於琥珀色藥液中；藥水打開時，這些成分會消失。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **改變生理年齡**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你的生理年齡減少 1d6 + 6 年，最低降至 13 歲。此後每次再次飲用延壽藥水，都有累計 10% 的機率使你的生理年齡改為增加 1d6 + 6 年，而非減少。
