# 衰減藥水 (Potion of Diminution)

## 📖 物品描述

藥液中的紅色部分不斷收縮成小球，再度膨脹並將周圍清澈藥液染紅；搖晃藥瓶不會打斷此過程。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你獲得*變巨術／縮小術 Enlarge/Reduce*的縮小效應，持續 1d4 小時，無須專注。
