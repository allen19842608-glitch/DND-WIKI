# 健康靈藥 (Elixir of Health)

## 📖 物品描述

這瓶清澈紅色液體中漂浮著發光的微小氣泡。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **飲用效果**：
  - **啟用／觸發**：飲用此藥水時。
  - **效果**：你身上所有魔法性疫病被治癒，且你的目盲、耳聾、麻痺與中毒狀態結束。
