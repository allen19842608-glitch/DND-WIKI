# 魔法物品獨特特性 (Magic Item Special Features)

## ⚙️ 規則條文 (Rule Text)

- 為魔法物品設定製作者、預設使用者、過往歷史、次級詞條或影響，可使其具有辨識度；擲出不合理結果時，DM 可重擲、選擇其他結果或自行創作。除非物品另有明定，這些特性不取代其既有規則。（來源：DMG 2024，第七章「魔法物品的獨特特性」）
- 在「次級詞條」及「影響」表中，「你」均指該物品的持用者。

### 製作者或預設使用者

| d20 | 結果與可用特徵 |
| :--- | :--- |
| 1 | **異怪**：年代久遠，外觀彷彿覆有黏液。 |
| 2 | **天界**：重量減半，刻有羽翼、日月星辰；邪魔厭惡它。 |
| 3 | **羅絲信徒**：重量減半，刻有蜘蛛與蛛網。 |
| 4 | **巨龍**：飾有龍巢寶物；120 呎內有龍類時會發熱。 |
| 5–6 | **矮人**：堅固、帶矮人符文，可能被氏族追索。 |
| 7 | **氣元素**：重量減半、似空心；絲織部分可如薄紗半透明。 |
| 8 | **土元素**：可能由石頭製成，皮革或布料鑲有磨圓小石。 |
| 9 | **火元素**：觸感溫暖，金屬為黑鐵，覆有火焰圖樣。 |
| 10 | **水元素**：皮革或布料改為魚鱗；金屬部分改為貝殼與珊瑚。 |
| 11–12 | **精靈**：重量減半，飾以自然標記。 |
| 13 | **妖精**：精巧、散發 5 呎微光；金屬部分為銀或秘銀。 |
| 14 | **邪魔**：鐵或角製；帶邪魔皮革、褻瀆符文；天族厭惡它。 |
| 15 | **巨人**：尺寸較大，原為巨人製給小型盟友。 |
| 16 | **侏儒**：看似尋常但好用，附有非必要的齒輪與機械。 |
| 17–19 | **人類**：來自失落王國或傳奇人物，可帶失傳文字或標記。 |
| 20 | **亡靈**：飾以骨骸或死亡標記，可能含屍體材料，觸感冰冷。 |

### 過往歷史

| d8 | 歷史 |
| :--- | :--- |
| 1 | **神秘**：為古代施法者團體製作，帶其標誌。 |
| 2 | **災禍術**：為對抗特定生物類型而製。 |
| 3 | **英雄**：大英雄曾持有，新主人被期待延續其功業。 |
| 4 | **裝飾**：為紀念特殊事件而製，飾有貴金屬、寶石或鑲邊。 |
| 5 | **預言**：是預言的一部分，持有者將在未來事件扮演要角。 |
| 6 | **宗教**：曾用於敬奉特定神祇的儀式，帶宗教標誌。 |
| 7 | **不祥**：與強大惡物的暴行有關，可能具有名字或惡名。 |
| 8 | **權力象徵**：曾是皇權或高位身分的象徵。 |

### 次級詞條

| d20 | 詞條 |
| :--- | :--- |
| 1–2 | **燈火**：附贈動作開關 10 呎明亮光及額外 10 呎微光。 |
| 3 | **羅盤**：魔法動作得知磁北；無磁北處無效。 |
| 4 | **深掘者**：地下時知曉所在深度及最近上行通道方位。 |
| 5–6 | **守護者**：未失能時，先攻檢定 +2。 |
| 7–8 | **調諧**：同調僅需 1 分鐘。 |
| 9 | **鎖鑰**：可用來解鎖一件容器、房間、金庫或門。 |
| 10 | **密令**：藏有訊息，可能僅在特定時間、地點或月光下顯現。 |
| 11–12 | **哨兵**：DM 選一種生物；其進入 120 呎內時物品發微光。 |
| 13 | **作曲**：敲擊物品或以其命中敵人時，聽見古歌片段。 |
| 14–15 | **奇材怪料**：由不合用途的奇特材料製成，但耐久性不受影響。 |
| 16 | **令人暖心**：在華氏 0 度以下或 100 度以上仍安然無恙。 |
| 17 | **堅不可摧**：無法被破壞，除非使用特殊手段。 |
| 18 | **戰爭領袖**：魔法動作，聲音或信號可清晰傳至 600 呎內，至下回合結束。 |
| 19 | **水上漂**：漂浮於水或其他液體；游泳的力量（運動）檢定具優勢。 |
| 20 | 再擲兩次；若再擲出 20，重擲該次結果。 |

### 影響

| d8 | 影響 |
| :--- | :--- |
| 1 | **幸福**：使你感到富足、有希望；蝴蝶等無害生物可能在旁逗留。 |
| 2 | **自信**：使你感到自信滿滿。 |
| 3 | **貪婪**：使你沉迷於物質財富。 |
| 4 | **易碎**：持用、穿戴或啟用時出現碎屑、磨損、缺口或裂紋，但不影響詞條。 |
| 5 | **喧鬧**：使用時發出巨響，例如叮噹、叫喊或迴音鐘聲。 |
| 6 | **變形**：外觀週期性出現細微變化；你無法控制，但不妨礙使用。 |
| 7 | **疼痛**：使用時感受短暫、無害的疼痛。 |
| 8 | **嫌惡**：互動時反胃；持有期間持續感到不適。 |
