# 法術反轉戒指 (Ring of Spell Turning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **法術豁免與無效化**：
  - **啟用／觸發**：佩戴戒指期間，對抗法術進行豁免時。
  - **效果**：該豁免具有優勢。若你成功豁免不高於七環的法術，該法術對你不產生任何效果。

- **法術反彈**：
  - **啟用／觸發**：佩戴戒指期間，成功豁免一道不高於七環、只以你為目標且不創造區域效應的法術時，可以執行反應。
  - **效果**：將該法術反彈給原施法者；原施法者須以自己的法術豁免 DC，對該法術進行豁免。
