# 法術反轉戒指 (Ring of Spell Turning)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **法術反轉**：
  - **啟用／觸發**：佩戴並同調期間；你對抗法術進行豁免時。
  - **效果**：你對抗法術的豁免檢定具有優勢。若你成功豁免不高於七環的法術，該法術不對你產生效應；若該法術只以你為目標且不創造區域效應，你可使用一個**反應**將其反彈給施法者。原施法者必須以其自己的法術豁免 DC，對該法術進行豁免。
