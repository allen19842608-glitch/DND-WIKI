# 反射閃避戒指 (Ring of Evasion)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **反射閃避**：
  - **啟用／觸發**：佩戴戒指期間，當你敏捷豁免失敗時，可以執行反應並消耗 1 充能。
  - **效果**：使該次豁免改為成功。
  - **限制與恢復**：戒指具有 3 充能，並在每日黎明重獲 1d3 點已消耗的充能。
