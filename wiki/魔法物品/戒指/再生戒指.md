# 再生戒指 (Ring of Regeneration)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：佩戴戒指且生命值至少為 1 時。
  - **效果**：每 10 分鐘恢復 1d6 點生命值。

- **肢體再生**：
  - **啟用／觸發**：佩戴戒指期間失去一部分肢體，且在接下來的 1d6 + 1 天內生命值始終至少為 1。
  - **效果**：失去的部位再生，並在該段時間後恢復完整功能。
