# 再生戒指 (Ring of Regeneration)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此戒指期間，如果你至少擁有 1 生命值，則你每 10 分鐘恢復 1d6 生命值。如果你失去了一部分肢體，這枚戒指會使你失去的部位自行再生。只要你在 1d6+1 天的時間裡全程保有至少 1 生命值，該部位就會在這段時間後恢復原有的功能。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
