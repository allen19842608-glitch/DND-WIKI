# 三願戒指 (Ring of Three Wishes)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：佩戴期間；消耗 1 充能。
  - **效果**：你可從戒指施展[[法術/9環/祈願術|祈願術 (Wish)]]。
  - **限制與恢復**：戒指共有 3 充能；使用最後一點充能後，戒指變為非魔法物品。
