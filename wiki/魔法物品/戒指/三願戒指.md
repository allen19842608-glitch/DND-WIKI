# 三願戒指 (Ring of Three Wishes)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：佩戴期間；消耗 1 充能。
  - **效果**：此戒指具有 3 充能。你可從中施展*祈願術 Wish*。
  - **限制與恢復**：充能耗盡時，此戒指變為非魔法物品。
