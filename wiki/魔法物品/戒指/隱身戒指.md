# 隱身戒指 (Ring of Invisibility)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **隱形**：
  - **啟用／觸發**：佩戴並同調期間；使用一個**魔法**動作。
  - **效果**：你獲得**隱形 Invisible**狀態。
  - **限制與恢復**：隱形持續至你摘下戒指，或使用一個**附贈動作**使自己顯形。
