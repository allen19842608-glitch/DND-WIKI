# 影響動物戒指 (Ring of Animal Influence)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：佩戴戒指期間，消耗 1 充能。
  - **效果**：從戒指施展下列法術之一；法術豁免 DC 為 13：
    - [[法術/1環/化獸為友|化獸為友 (Animal Friendship)]]
    - [[法術/3環/恐懼術|恐懼術 (Fear)]]；此法術只影響野獸。
    - [[法術/1環/動物交談|動物交談 (Speak with Animals)]]
  - **限制與恢復**：戒指具有 3 充能，每日黎明重獲 1d3 點已消耗的充能。
