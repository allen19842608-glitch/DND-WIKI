# 影響動物戒指 (Ring of Animal Influence)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：這枚戒指具有 3 充能，並在每日黎明時重獲 1d3 已消耗的充能。著裝此戒指期間，你可以消耗 1 充能，從中施展以下法術之一（豁免 DC 13）：
    * *化獸為友 Animal Friendship*
    * *恐懼術 Fear*（只影響野獸）
    * *動物交談 Speak with Animals*
  - **限制與恢復**：這枚戒指具有 3 充能，並在每日黎明時重獲 1d3 已消耗的充能。
