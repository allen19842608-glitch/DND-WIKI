# X射線戒指 (Ring of X-Ray Vision)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **X 射線視覺**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：著裝此戒指期間，你可以執行**魔法**動作以獲得範圍 30 呎的 X 射線視覺，持續 1 分鐘。對你來說，半徑內的固態物件變為透明，並且不會阻礙光線通過。這種視覺可以穿透 1 呎厚的石頭，1 吋厚的常見金屬或最多 3 呎厚的木頭或泥土。更厚的物質或一張薄鉛片會阻擋這種視覺。
  - **限制與恢復**：著裝此戒指期間，你可以執行**魔法**動作以獲得範圍 30 呎的 X 射線視覺，持續 1 分鐘。這種視覺可以穿透 1 呎厚的石頭，1 吋厚的常見金屬或最多 3 呎厚的木頭或泥土。

- **過度使用風險**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：每當你在完成一次長休前再次使用這枚戒指時，你必須成功通過一次 DC 15 的體質豁免，否則獲得 1 級**力竭**。
