# X射線戒指 (Ring of X-Ray Vision)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **X 射線視覺**：
  - **啟用／觸發**：佩戴戒指期間，執行一個魔法動作。
  - **效果**：你獲得範圍 30 呎的 X 射線視覺，持續 1 分鐘。對你來說，此範圍內的固態物件變為透明，且不會阻擋光線。視覺可穿透 1 呎厚的石頭、1 吋厚的常見金屬，或至多 3 呎厚的木頭或泥土；更厚的物質或一張薄鉛片會阻擋這種視覺。

- **過度使用風險**：
  - **啟用／觸發**：完成一次長休前，再次使用戒指時。
  - **效果**：進行一次 DC 15 體質豁免；失敗時獲得 1 級**力竭**。
