# 自由行動戒指 (Ring of Free Action)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **自由行動**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：著裝此戒指期間，你不會因困難地形而損耗額外的移動力。此外，魔法不能減少你的任何速度，也不能使你陷入**麻痺**或**束縛**狀態。
