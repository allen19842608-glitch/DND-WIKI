# 心靈護盾戒指 (Ring of Mind Shielding)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **心靈防護**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此戒指期間，你免疫能讓其他生物閱讀你的思想、辨別你在說謊、知曉你陣營或生物類型的魔法。只有在你允許時，生物才能與你進行心靈感應交流。

- **隱匿戒指**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：你可以執行**魔法**動作來讓戒指變的無法被察覺，持續至你脫下戒指、**死亡**或執行另一個**魔法**動作使其可被察覺為止。
  - **限制與恢復**：你可以執行**魔法**動作來讓戒指變的無法被察覺，持續至你脫下戒指、**死亡**或執行另一個**魔法**動作使其可被察覺為止。

- **靈魂寄宿**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：如果你在著裝戒指期間**死亡**，你的靈魂將進入戒指中，除非其內已寄宿著其他靈魂。你可以留在戒指內或奔向來世。只要你的靈魂處在戒指中，你就可以與著裝它的任何生物進行心靈感應交流。著裝者無法阻止這種心靈感應交流。
  - **限制與恢復**：如果你在著裝戒指期間**死亡**，你的靈魂將進入戒指中，除非其內已寄宿著其他靈魂。
