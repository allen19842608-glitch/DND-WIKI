# 心靈護盾戒指 (Ring of Mind Shielding)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **心靈防護**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：你免疫能讓其他生物閱讀你的思想、辨別你在說謊、知曉你陣營或生物類型的魔法。只有在你允許時，生物才能與你進行心靈感應交流。

- **隱匿戒指**：
  - **啟用／觸發**：執行一個魔法動作。
  - **效果**：戒指變得無法被察覺，直到你脫下戒指、死亡，或執行另一個魔法動作使其重新可被察覺。

- **靈魂寄宿**：
  - **啟用／觸發**：你佩戴戒指期間死亡，且戒指內尚未寄宿其他靈魂。
  - **效果**：你的靈魂進入戒指，可以留在其中或前往來世。靈魂留在戒指內期間，你可以與任何佩戴者進行心靈感應交流；佩戴者無法阻止這種交流。
