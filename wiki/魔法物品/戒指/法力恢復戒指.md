# 法力恢復戒指 (Spell-Refueling Ring)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要（施法者） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **恢復法術位**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：著裝期間，以一個附贈動作恢復一枚已消耗、至多三環的法術位。
  - **限制與恢復**：使用後直到下個黎明無法再次使用。
