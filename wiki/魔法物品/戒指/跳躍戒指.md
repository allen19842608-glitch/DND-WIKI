# 跳躍戒指 (Ring of Jumping)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展跳躍術**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：著裝此戒指期間，你可以從中施展*跳躍術 Jump*，但只能以自身為目標。
