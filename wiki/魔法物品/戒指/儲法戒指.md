# 儲法戒指 (Ring of Spell Storing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **儲法**：
  - **效果**：戒指會儲存施展於其上的法術，供同調的佩戴者使用；可容納的法術環階總和最多為5環，發現時由 DM 決定其中已存有共 1d6−1 環的法術。任一生物施展一至五環法術時可觸碰戒指將其儲入；法術不會直接生效，若戒指無法容納，法術仍被消耗。佩戴者可施展任何已儲存法術，並使用原施法者的環階、法術豁免 DC、法術攻擊加值與施法屬性；施展後該法術消失並釋放空間。
