# 儲法戒指 (Ring of Spell Storing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：這枚戒指會儲存向其中施展的法術，將它們儲存起來，直至同調的著裝者使用。這枚戒指同時可以儲存環階總和最多為 5 的法術。被發現時，戒指中已儲存了由 DM 選擇的共 1d6-1 環階的法術。
  - **限制與恢復**：這枚戒指會儲存向其中施展的法術，將它們儲存起來，直至同調的著裝者使用。

- **施展法術**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：任何生物都可以向戒指內存入一至五環的法術，這需要施法者在施法的同時觸碰該戒指。此時法術會被儲存進戒指，不產生任何其他效果。如果戒指無法承載這道法術，則法術會被消耗並不產生任何效果。施展法術時使用的法術位決定其佔用戒指中的多少空間。

- **施展法術**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此戒指期間，你可以施展任何其中儲存的法術。這道法術使用原施法者的環階，法術豁免 DC，法術攻擊加值與施法屬性，但其他方面將如同你施展了法術一般處理。戒指中的法術一經施展即消失，釋放它原本佔用的空間。
  - **限制與恢復**：戒指中的法術一經施展即消失，釋放它原本佔用的空間。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
