# 儲法戒指 (Ring of Spell Storing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

這枚戒指最多可儲存環階總和為 5 的法術。被發現時，戒指已儲存由 DM 選定、環階總和為 1d6 − 1 的法術。

- **存入法術**：
  - **啟用／觸發**：任一生物施展一至五環法術時觸碰戒指。
  - **效果**：法術儲入戒指，不產生其他效果；所用法術位的環階決定占用多少儲存空間。
  - **限制與恢復**：若戒指無法容納該法術，法術仍被消耗，但不產生效果，也不儲入戒指。

- **施展儲存法術**：
  - **啟用／觸發**：完成同調並佩戴戒指期間，施展戒指內儲存的法術。
  - **效果**：法術沿用原施法者的法術位環階、法術豁免 DC、法術攻擊加值與施法屬性；其他方面視為由你施展。施展後，法術從戒指中消失並釋放其占用的空間。
