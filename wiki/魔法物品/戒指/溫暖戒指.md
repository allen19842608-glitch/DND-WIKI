# 溫暖戒指 (Ring of Warmth)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **寒冷傷害減免**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：著裝此戒指期間，當你受到寒冷傷害時，戒指將你所受的傷害減少 2d8。

- **低溫防護**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：此外，著裝此戒指期間，你以及你著裝和攜帶的任何東西都不會被 0 華氏度及以下的溫度所傷害。
