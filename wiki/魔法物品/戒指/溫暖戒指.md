# 溫暖戒指 (Ring of Warmth)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **寒冷傷害減免**：
  - **啟用／觸發**：佩戴戒指期間受到寒冷傷害時。
  - **效果**：該次傷害減少 2d8。

- **低溫防護**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：你及你穿戴或攜帶的物品不會受到 0 華氏度（含）以下溫度的傷害。
