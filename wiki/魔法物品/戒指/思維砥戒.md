# 思維砥戒 (Mind Sharpener)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **維持專注**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：此戒指有 4 充能。當你維持專注的體質豁免失敗時，可用反應消耗 1 充能使其成功。
  - **限制與恢復**：每日黎明恢復 1d4 已消耗的充能。
