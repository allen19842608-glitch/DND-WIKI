# 命令元素戒指 (Ring of Element Command)

## 📖 物品描述

每枚戒指都連接四個元素位面之一；DM 選擇或隨機決定其連接位面。例如，命令元素戒指（氣）連接氣元素位面。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |

| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **元素災厄**：
  - **啟用／觸發**：佩戴並同調期間；你或元素進行攻擊檢定時。
  - **效果**：你對元素的攻擊檢定具有優勢，元素對你的攻擊檢定具有劣勢。

- **元素強令**：
  - **啟用／觸發**：佩戴並同調期間；使用一個**魔法**動作指定你可見、60 呎內的元素。
  - **效果**：目標進行 DC 18 感知豁免。豁免失敗時，它直到你的下個回合開始前陷入**魅惑 Charmed**狀態，且你決定它下個回合如何使用移動與動作。

- **元素集中**：
  - **啟用／觸發**：佩戴並同調期間。
  - **效果**：你依戒指所連接的元素位面，獲得下列對應增益：
    - **氣**：你知曉氣族語、對閃電傷害具有抗性，並獲得等同速度的飛行速度，且可懸浮。
    - **土**：你知曉土族語、對強酸傷害具有抗性，無視碎石、岩石或泥土造成的困難地形；你可穿過固態土地或岩石，如同它們是困難地形，且不會擾動穿過的物質。若你在其中結束回合，會被推至先前所在的最近未佔據空間。
    - **火**：你知曉火族語，並免疫火焰傷害。
    - **水**：你知曉水族語、獲得 60 呎游泳速度，且可在水下呼吸。

- **可施展法術**：
  - **啟用／觸發**：佩戴並同調期間；依各法術的充能消耗施展。
  - **效果**：此戒指具有 5 充能，並在每日黎明重獲 1d4 + 1 點已消耗的充能。你依戒指所連接的元素位面施展下表中的法術；法術豁免 DC 為 18。

#### 可施展法術列表

| 位面 | 法術（充能） |
| :--- | :--- |

| 土 | *塑石術 Stone Shape*（2）、*石膚術 Stoneskin*（3）、*石牆術 Wall of Stone*（3）、*地震術 Earthquake*（5） |
| 火 | *燃燒之手 Burning Hands*（1）、*火球術 Fireball*（2）、*火牆術 Wall of Fire*（3）、*火焰風暴 Firestorm*（4） |
| 水 | *造水術／枯水術 Create or Destroy Water*（1）、*冰風暴 Ice Storm*（2）、*水上行走 Water Walk*（2）、*冰牆術 Wall of Ice*（3）、*海嘯術 Tsunami*（5） |
