# 公羊戒指 (Ring of the Ram)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **靈體公羊衝擊**：
  - **啟用／觸發**：佩戴戒指期間，以一個魔法動作消耗 1 至 3 充能，指定你可見的 60 呎內一名生物。
  - **效果**：戒指創造靈體公羊頭，對目標進行具有 +7 加值的遠程法術攻擊。命中時，每消耗 1 充能，目標受到 2d10 點力場傷害，並被推離你 5 呎。

- **破壞物件**：
  - **啟用／觸發**：佩戴戒指期間，以一個魔法動作消耗 1 至 3 充能，指定你可見的 60 呎內一件未被穿戴或攜帶的非魔法物件。
  - **效果**：戒指嘗試破壞該物件，進行力量檢定；每消耗 1 充能，檢定獲得 +5 加值。

### 使用、充能與恢復

- **充能／使用次數**：戒指具有 3 充能，兩種用法每次均可消耗 1 至 3 充能。
- **恢復**：每日黎明重獲 1d3 點已消耗的充能。
