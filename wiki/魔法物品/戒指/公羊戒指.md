# 公羊戒指 (Ring of the Ram)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：這枚戒指具有 3 充能，且在每日黎明時重獲 1d3 已消耗的充能。著裝此戒指期間，你可以執行**魔法**動作並消耗 1 至 3 充能，對 60 呎內的一個可見生物進行一次遠程法術攻擊。戒指創造出一個靈體公羊腦袋並進行具有 +7 加值的攻擊檢定。命中時，你每消耗 1 充能，目標就會受到 2d10 點力場傷害並且從你的方向被推離 5 呎。
  - **限制與恢復**：這枚戒指具有 3 充能，且在每日黎明時重獲 1d3 已消耗的充能。

- **充能效果**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：作為另一種用法，你可以執行**魔法**動作並消耗 1 至 3 充能，以嘗試破壞一件 60 呎內你可見且未被著裝或攜帶的非魔法性的物體。戒指將進行力量檢定，你每消耗 1 充能，此檢定便具有 +5 加值。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
