# 易傷護甲 (Armor of Vulnerability)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此護甲期間，你具有以下三種傷害類型之一的抗性：鈍擊、穿刺、或揮砍。具體傷害類型由 DM 選擇，或由 DM 隨機選定。

- **詛咒**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：**詛咒 Curse。**這是一件被詛咒的護甲，這一點只有在你同調此護甲或對它使用*鑑定術 identify*時才會揭曉。同調此護甲將會使你被詛咒，卸除該護甲不會終止詛咒，只有對你施展法術 *移除詛咒 remove curse*或以類似的魔法才能將其移除。此詛咒使你具有上述三種傷害類型中除護甲提供抗性的類型之外的兩種傷害的易傷。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
