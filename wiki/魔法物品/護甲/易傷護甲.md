# 易傷護甲 (Armor of Vulnerability)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：穿著期間。
  - **效果**：著裝此護甲期間，你具有以下三種傷害類型之一的抗性：鈍擊、穿刺、或揮砍。具體傷害類型由 DM 選擇，或由 DM 隨機選定。

### 詛咒

與此物品同調會使你受到詛咒；此事只有同調此護甲或對它施展鑑定術時才會揭曉。

- **詛咒效果**：你具有鈍擊、穿刺、揮砍三種傷害類型中，護甲未提供抗性的另外兩種傷害易傷；卸下護甲不會結束詛咒。
- **解除方式**：你成為移除詛咒或類似魔法的目標時，詛咒結束。
