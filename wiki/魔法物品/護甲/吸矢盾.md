# 吸矢盾 (Arrow-Catching Shield)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：持握此盾牌期間，你對抗遠程攻擊的 AC 具有 +2 加值。該加值將加在盾牌通常提供的 AC 加值上。

- **吸矢**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：此外，當一個攻擊者對你周圍 5 呎內的目標發動遠程攻擊時，你可以執行**反應**以替代該目標成為此次攻擊的目標。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
