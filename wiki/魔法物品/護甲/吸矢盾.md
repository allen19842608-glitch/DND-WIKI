# 吸矢盾 (Arrow-Catching Shield)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：持用期間。
  - **效果**：持握此盾牌期間，你對抗遠程攻擊的 AC 具有 +2 加值。該加值將加在盾牌通常提供的 AC 加值上。

- **吸矢**：
  - **啟用／觸發**：當攻擊者以遠程攻擊檢定攻擊你 5 呎內的目標時。
  - **效果**：你可以執行**反應**，改由自己成為該次攻擊的目標。
