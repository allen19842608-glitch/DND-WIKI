# 火巨靈鏈甲 (Efreeti Chain)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鏈甲或鏈甲衫） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **火巨靈庇護**：
  - **啟用／觸發**：穿戴並同調期間。
  - **效果**：你的 AC 獲得 +3 加值；你免疫火焰傷害、知曉原初語，並可如履平地般行走於熔岩上。
