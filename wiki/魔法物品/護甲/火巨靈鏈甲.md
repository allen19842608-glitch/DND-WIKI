# 火巨靈鏈甲 (Efreeti Chain)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鏈甲或鏈甲衫） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此護甲期間，你的 AC 獲得 +3 加值，具有對火焰傷害的免疫，且懂得原初語。此外，你還可以如行走在堅實地面上一般行走於熔岩之上。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
