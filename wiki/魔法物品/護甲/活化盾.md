# 活化盾 (Animated Shield)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **活化**：
  - **啟用／觸發**：持用期間。
  - **效果**：持握此盾牌期間，你可以用**附贈動作**使其活化。盾牌將飛到空中並懸浮在你所佔據的空間中保護你，如同你正持用著它一般，且同時解放你的雙手。盾牌保持活化 1 分鐘，如果你陷入**失能 Incapacitated**、**死亡**、或用**附贈動作**終止其效應時，活化會提前結束。如果活化結束時你有空閒的手空著，盾牌將落回你手裡；否則它會掉落在地上。
