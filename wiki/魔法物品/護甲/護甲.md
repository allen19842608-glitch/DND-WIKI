# 護甲 (Armor，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲），珍稀（+1）/極珍稀（+2）/ |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：著裝此護甲期間，你的 AC 具有加值。加值的數值取決於護甲的稀有度。
