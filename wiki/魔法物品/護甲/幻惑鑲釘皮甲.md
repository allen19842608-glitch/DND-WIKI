# 幻惑鑲釘皮甲 (Glamoured Studded Leather)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鑲釘皮甲） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：穿著這件護甲期間，你的 AC 獲得 +1 加值。你還可以用一個**附贈動作**使這件護甲的外觀幻化為任何非金屬的衣物或其他種類的護甲。幻化後的外觀由你決定——包括顏色、樣式和配飾——但其體積和重量不變。幻化外觀的效應持續到你脫掉此護甲或再次改變護甲外觀。
