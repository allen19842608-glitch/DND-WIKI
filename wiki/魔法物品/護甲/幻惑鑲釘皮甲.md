# 幻惑鑲釘皮甲 (Glamoured Studded Leather)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鑲釘皮甲） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：你的 AC 獲得 +1 加值。
- **幻化外觀**：
  - **啟用／觸發**：穿著護甲時，你可以用一個**附贈動作**改變其外觀。
  - **效果**：護甲可呈現一般衣物或其他種類護甲的外觀。你決定顏色、樣式與配飾，但護甲原本的體積和重量不變。此幻象外觀持續到你再次使用這項能力，或脫下護甲為止。

### 來源文字差異

中文來源 L36 寫「非金屬的衣物」，同版英文 `/item/853` 寫一般衣物（normal set of clothing），沒有材質限制；上方依英文原文，不加入「非金屬」條件。
