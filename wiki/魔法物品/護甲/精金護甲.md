# 精金護甲 (Adamantine Armor)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意中甲或重甲，獸皮甲除外） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **重擊防護**：
  - **啟用／觸發**：著裝期間；依效果所列時機。
  - **效果與數值**：這套護甲使用了現存最堅硬的物質之一——精金加以強化。著裝該護甲期間，任何對你的<u>重擊命中</u>都會變為普通命中。
