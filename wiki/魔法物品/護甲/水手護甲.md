# 水手護甲 (Mariner's Armor)
## 物品描述

這套護甲飾有魚群和貝殼的紋樣。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **游泳速度**：
  - **啟用／觸發**：穿著期間。
  - **效果**：著裝這套護甲期間，你獲得等同於你速度的游泳速度。此外，當你在水下以 0 生命值開始你的回合時，你立即恢復 1d4 生命值。直至下個黎明前，該護甲無法再治療任何人。
  - **限制與恢復**：直至下個黎明前，該護甲無法再治療任何人。
