# 魔咒護甲 (Enspelled Armor)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲或重甲） |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：穿著期間。
  - **效果**：這套護甲中銘刻了一道八環或更低環階的法術。這道法術必須是一道屬於防護或幻術學派的法術，在製造此護甲的時候決定。著裝此護甲期間，你可以消耗 1 充能以施展該法術。
  - **限制與恢復**：此護甲具有 6 充能，且在每日黎明時重獲 1d6 已消耗的充能。

- **法術豁免 DC 與攻擊加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：護甲中銘刻的法術其環階決定了這道法術的豁免 DC 和攻擊加值，還有這套護甲的稀有度（見下表）。
