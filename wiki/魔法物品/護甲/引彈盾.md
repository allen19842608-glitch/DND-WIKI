# 引彈盾 (Shield of Missile Attraction)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：持握這面盾牌期間，你對使用遠程武器進行的攻擊所造成的傷害具有抗性。

- **詛咒**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：**詛咒 Curse。**這面盾牌被詛咒了。與之同調會使你也被詛咒，直至你成為法術*移除詛咒 Remove Curse*或類似魔法的目標。每當使用遠程武器進行的攻擊以你 10 呎內一個生物為目標時，詛咒會使你代替該生物成為目標。
  - **限制與恢復**：與之同調會使你也被詛咒，直至你成為法術*移除詛咒 Remove Curse*或類似魔法的目標。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
