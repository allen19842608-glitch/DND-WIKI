# 燜燃護甲 (Smoldering Armor)
## 物品描述

這件護甲被著裝期間，一縷縷無害無味的煙霧會不斷從護甲中升起。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意重甲，中甲或輕甲） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **無害煙霧**：
  - **啟用／觸發**：穿著護甲期間。
  - **效果**：一縷縷無害、無味的煙霧持續從護甲升起。
