# 以太化板甲 (Plate Armor of Etherealness)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（半身板甲或板甲） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：穿戴並同調期間；說出命令語並使用一個**魔法**動作；每個黎明一次。
  - **效果**：你獲得*以太化 Etherealness*的效應。若你脫下護甲，或再次使用一個**魔法**動作說出命令語，該效應立即結束。
  - **限制與恢復**：使用後，直到下個黎明前無法再次使用。
