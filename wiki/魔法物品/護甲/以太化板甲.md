# 以太化板甲 (Plate Armor of Etherealness)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（半身板甲或板甲） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **快速脫甲**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此護甲期間，你能夠以一個**魔法**動作說出其命令語以獲得法術*以太化 etherealness*的效應。若你脫下此護甲或以**魔法**動作再次說出命令語，則法術立即結束。此詞條一經使用，直至下個黎明你都無法再次使用。
  - **限制與恢復**：此詞條一經使用，直至下個黎明你都無法再次使用。

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
