# 斥力之盾 (Repulsion Shield)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **斥力反擊**：
  - **啟用／觸發**：持用期間。
  - **效果**：持用時 AC 有 +1 加值。此盾牌有 4 充能；體型不超過大型的生物在 5 呎內以近戰攻擊命中你時，可用反應消耗 1 充能將其直線推離至多 15 呎。
  - **限制與恢復**：每日黎明恢復 1d4 已消耗的充能。
