# 精靈鏈甲 (Elven Chain)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鏈甲或鏈甲衫） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：著裝期間；依效果所列時機。
  - **效果與數值**：穿著這件護甲期間，你的 AC 獲得 +1 加值。即使沒有受訓於中型護甲或重型護甲，你依然視為受訓於該護甲。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
