# 精靈鏈甲 (Elven Chain)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（鏈甲或鏈甲衫） |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：穿著這件護甲期間，你的 AC 獲得 +1 加值。即使沒有受訓於中型護甲或重型護甲，你依然視為受訓於該護甲。
