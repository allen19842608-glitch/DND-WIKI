# 盾牌 (Shield，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌），非普通（+1）/珍稀（+2）/ |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：著裝期間；依效果所列時機。
  - **效果與數值**：持握這面盾牌期間，除了盾牌原本提供的 AC 加值外，你還會獲得額外的護甲等級加值，加值大小取決於盾牌的稀有度。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
