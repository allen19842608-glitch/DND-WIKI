# 堅不可摧護甲 (Armor of Invulnerability)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（板甲） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝此護甲期間，你具有對鈍擊、穿刺和揮砍傷害的抗性。

- **金屬外殼**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：**金屬外殼 Metal Shell。**你能夠以一個**魔法**動作令你具有對鈍擊、穿刺和揮砍傷害的免疫，持續 10 分鐘或在你不再著裝該此護甲時提前結束。該詞條一經使用，直至下個黎明你都無法再次使用。
  - **限制與恢復**：**你能夠以一個**魔法**動作令你具有對鈍擊、穿刺和揮砍傷害的免疫，持續 10 分鐘或在你不再著裝該此護甲時提前結束。該詞條一經使用，直至下個黎明你都無法再次使用。

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
