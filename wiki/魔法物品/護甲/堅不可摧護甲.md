# 堅不可摧護甲 (Armor of Invulnerability)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（板甲） |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **傷害抗性**：
  - **啟用／觸發**：穿戴並同調期間。
  - **效果**：你對鈍擊、穿刺與揮砍傷害具有抗性。

- **金屬外殼**：
  - **啟用／觸發**：穿戴並同調期間；使用一個**魔法**動作；每個黎明一次。
  - **效果**：你免疫鈍擊、穿刺與揮砍傷害，持續 10 分鐘，或在你不再穿戴此護甲時提前結束。
  - **限制與恢復**：使用後，直到下個黎明前無法再次使用。
