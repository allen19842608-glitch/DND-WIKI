# 矮人板甲 (Dwarven Plate)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（半身板甲或板甲） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：你的 AC 獲得 +2 加值。
- **抵抗強制移動**：當某種效應將要違背你的意願使你沿地面移動時，你可以用反應使這次位移距離減少至多 10 呎。
