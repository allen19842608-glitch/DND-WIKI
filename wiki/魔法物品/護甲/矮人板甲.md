# 矮人板甲 (Dwarven Plate)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（半身板甲或板甲） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：著裝該護甲期間，你的 AC 獲得 +2 加值。此外，當某種效應將要在違背你意願的情況下使你沿地面移動時，你可以用反應來減少你被移動的距離，至多減少 10 呎。
