# 表情盾 (Shield of Expression)
## 物品描述

這面盾牌的正面呈現出一張臉的形狀。攜帶這面盾牌期間，你可以使用一個**附贈動作**來改變這張臉的表情。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **改變表情**：
  - **啟用／觸發**：攜帶盾牌期間，以一個**附贈動作**啟用。
  - **效果**：改變盾牌正面那張臉的表情。
