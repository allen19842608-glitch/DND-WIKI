# 秘銀甲 (Mithral Armor)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意中甲或重甲，獸皮甲除外） |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **秘銀輕量化**：
  - **啟用／觸發**：穿著期間。
  - **效果**：秘銀是一種輕盈且柔韌的金屬。秘銀鍊甲衫或胸甲可以穿在普通衣物裡面。如果這套護甲本來會使著裝者的敏捷（隱匿）檢定具有劣勢，或是對著裝者的力量屬性具有要求，則它的秘銀版本將不會具有這些限制。
