# 惡魔護甲 (Demon Armor)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 充能 (Charges) | 依效果說明 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：著裝該護甲期間，你的 AC 具有 +1 加值，且你理解深淵語。此外，護甲如利爪般的護腕會令你的徒手打擊造成 1d8 點揮砍傷害，代替徒手打擊原本的鈍擊傷害，你徒手打擊的攻擊檢定與傷害擲骰獲得 +1 加值。

- **詛咒**：
  - **啟用／觸發**：著裝並同調期間；依效果所列時機。
  - **效果與數值**：**詛咒 Curse。**著裝這件被詛咒的護甲後，除非你被施予法術*移除詛咒 remove curse*或類似的魔法效應，否則你無法將其卸下。著裝該護甲期間，你對惡魔進行的攻擊檢定具有劣勢，且你對抗惡魔的法術與特殊能力進行的豁免檢定同樣具有劣勢。
## 💡 實戰應用與裁量 (DM Ruling)

- **常見誤區**：啟用、充能與限制均依各效果的來源描述。
