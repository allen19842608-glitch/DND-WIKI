# 惡魔護甲 (Demon Armor)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲、或重甲） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：穿著期間。
  - **效果**：著裝該護甲期間，你的 AC 具有 +1 加值，且你理解深淵語。此外，護甲如利爪般的護腕會令你的徒手打擊造成 1d8 點揮砍傷害，代替徒手打擊原本的鈍擊傷害，你徒手打擊的攻擊檢定與傷害擲骰獲得 +1 加值。

### 詛咒

這是一件詛咒護甲；穿上後，除非受到下述魔法影響，否則無法脫下。

- **詛咒效果**：穿著期間，你對惡魔的攻擊檢定，以及對抗惡魔法術與特殊能力的豁免檢定，都具有劣勢。
- **解除方式**：你成為[[法術/3環/移除詛咒|移除詛咒]]或類似魔法的目標後，可以脫下護甲。物品原文未說護甲本身的詛咒因此消失。
