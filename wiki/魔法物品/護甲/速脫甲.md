# 速脫甲 (Cast-Off Armor)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（任意輕甲、中甲或重甲） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **快速脫甲**：
  - **啟用／觸發**：穿著期間。
  - **效果**：你只用一個**魔法**動作便可脫下這套護甲。
