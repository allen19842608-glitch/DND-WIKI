# 無盡煙壺 (Eversmoking Bottle)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **放出煙雲**：
  - **啟用／觸發**：使用一個**魔法**動作打開瓶子。
  - **效果**：濃重煙霧自瓶中湧出，形成以瓶子為中心、半徑 60 呎的濃厚煙雲；該區域處於重度遮蔽。瓶子保持開啟時，煙雲每分鐘半徑增加 10 呎，最大半徑 120 呎。
  - **限制與恢復**：使用一個**魔法**動作關閉瓶子時，煙雲固定在原處，10 分鐘後消散。強風（例如*造風術 Gust of Wind*）可在 1 分鐘後將其吹散。
