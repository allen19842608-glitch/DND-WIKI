# 西風馬蹄鐵 (Horseshoes of a Zephyr)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **懸浮坐騎**：
  - **效果**：四個馬蹄鐵同時附著在一匹馬或類似的生物身上期間，它將懸浮在離地面4寸的高度，並可以如常移動。這使得該生物可以穿過或站在非固態或非穩定的平面上，例如水面或岩漿。它無視困難地形並且不會留下足跡。此外，該生物每天最多可以旅行12個小時，並且不會因為長時間旅行而獲得力竭等級。
  - **限制與恢復**：此外，該生物每天最多可以旅行12個小時，並且不會因為長時間旅行而獲得力竭等級。
