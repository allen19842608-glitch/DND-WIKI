# 西風馬蹄鐵 (Horseshoes of a Zephyr)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **附著與移除馬蹄鐵**：
  - **啟用／觸發**：以一個**魔法**動作將其中一個馬蹄鐵接觸馬或類似生物的蹄子；移除一個馬蹄鐵也需要一個**魔法**動作。
  - **效果**：馬蹄鐵四個為一套；接觸蹄子後，該馬蹄鐵便附著在蹄子上。

- **懸浮坐騎**：
  - **啟用／觸發**：四個馬蹄鐵同時附著在一匹馬或類似生物的蹄上期間。
  - **效果**：該生物離地 1/3 呎懸浮並照常移動，可穿過或站在水面、岩漿等非固態或不穩定表面；它無視困難地形，也不留下足跡。
  - **限制與恢復**：該生物每天最多可旅行 12 小時，而不會因長途旅行獲得力竭等級。
