# 機巧奇具 (Mechanical Wonders)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 依型態而定 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **上弦啟動**：未啟動時為休眠物件。以專屬手持鑰匙花 1 分鐘上發條，且期間每回合執行操作動作；啟動後維持各型態指定的時間。
- **家用型與飛空型**：啟動後是你與盟友的盟友，使用你的先攻並在你回合後行動，遵從口頭命令；沒有命令時迴避並遠離危險。家用型的物品規則見 [[魔法物品/奇物/家用型奇具|家用型奇具]]；飛空型資料見原始資料段落。
- **旋翼型**：珍稀的巨型飛行載具；啟動 8 小時、需要飛行員、可載重至 2,000 磅，超重即停用。
- **移動型**：普通型態；啟動 24 小時後成為個人移動裝置，使你的速度變為 30 呎，且其他生物不能在未經你允許下移走它。
