# 靜報號角 (Horn of Silent Alarm)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 來源未註明 |

### 物品效果

- **指定聽者的號角聲**：
  - **啟用／觸發**：以魔法動作消耗 1 充能並吹響號角。
  - **效果**：距離號角 600 呎內，由你選擇的一名生物能聽到號角聲；其他生物都聽不到。
  - **限制與恢復**：號角共有 4 充能，每日黎明時恢復 1d4 點已消耗的充能。
