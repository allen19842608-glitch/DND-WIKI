# 噴嚏粉 (Dust of Sneezing and Choking)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **噴嚏粉塵**：
  - **啟用／觸發**：執行操作動作將粉末灑向空中時。
  - **效果**：這種粉末通常裝在小盒子裡，分量僅足以使用一次，且看起來像無蹤粉；對它施展鑑定術也會得到相同結果。你和你周圍30 呎內的生物必須進行 DC 15 體質豁免；構裝、元素、泥怪、植物與亡靈自動成功。豁免失敗者不停打噴嚏，陷入**失能**並窒息；其每回合結束時可重複豁免，成功即結束自身效應。次級復原術也能結束一名生物身上的效應。
