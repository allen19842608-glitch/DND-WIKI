# 讀心水晶球 (Crystal Ball of Mind Reading)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 重量 (Weight) | 3 磅 |

### 物品效果

- **施展探知術**：
  - **啟用／觸發**：接觸水晶球期間。
  - **效果**：你可以透過它施展[[法術/5環/探知術|探知術 (Scrying)]]，法術豁免 DC 為 17。

- **施展偵測思想**：
  - **啟用／觸發**：透過探知術的傳感器看見目標生物，且該生物位於傳感器 30 呎內時。
  - **效果**：你可以對該生物施展[[法術/2環/偵測思想|偵測思想 (Detect Thoughts)]]，法術豁免 DC 為 17。
  - **限制與恢復**：以此法施展的偵測思想在持續時間內無須專注；探知術結束時，此法術也隨之結束。
