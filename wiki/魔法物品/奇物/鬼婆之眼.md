# 鬼婆之眼 (Hag Eye)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **集會傳感器**：
  - **效果**：**集會傳感器 Coven Sensor**。鬼婆之眼通常會被託付給鬼婆的僕從以對其進行保護與轉移。隸屬於創造該鬼婆之眼集會的鬼婆若與鬼婆之眼處於同一存在位面上，則其可以用一個**魔法**動作透過鬼婆之眼視物。只要該鬼婆維持專注，則該效應將會一直持續。同一集會中的多個鬼婆可以同時透過該鬼婆之眼視物。

- **創造鬼婆之眼**：
  - **效果**：**創造鬼婆之眼 Creating a Hag Eye**。只有鬼婆集會才能夠製造此物品，其成品由裹在清漆中的真實眼球製成，並通常鑲在吊墜或其他可佩戴的物品之上。一個鬼婆集會在同一時間只能擁有一顆鬼婆之眼，製作一個新的則需全部三位集會成員進行一場特殊儀式。這場儀式耗時1小時，且若一名或多名鬼婆陷入**失能**狀態，則儀式無法進行。若鬼婆們在儀式期間執行任何其他動作，則儀式失敗並終止。
