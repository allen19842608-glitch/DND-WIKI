# 霍華德香料包 (Heward's Handy Spice Pouch)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **取用調味料**：
  - **啟用／觸發**：持握香料包期間，以一個**魔法**動作消耗 1 充能並說出一種非魔法食物調味料名稱。
  - **效果**：從香料包取出一撮所指定的調味料，足以調味一份單人食物。

### 使用、充能與恢復

- **充能／使用次數**：10 充能；每次使用此效果消耗 1 充能。
- **恢復**：每日黎明時重獲 1d6 + 4 已消耗的充能。
