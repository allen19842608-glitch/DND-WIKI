# 命令氣元素香爐 (Censer of Controlling Air Elementals)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |

| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **當你輕輕揮動這件香爐期間，你可以用一個魔法動作來召喚一隻氣元素**：
  - **效果**：當你輕輕揮動這件香爐期間，你可以用一個**魔法**動作來召喚一隻[[wiki/怪物/元素/氣元素|氣元素 (Air Elemental)]]。氣元素會出現在距離香爐最近的未佔據空間、理解你所說的語言、服從你的命令、使用你的先攻值並在你之後立即執行其回合。氣元素會在1小時後、或它死亡時、或你用一個**附贈動作**解消時消失。直到下個黎明前，香爐都無法再以該方式進行使用。
  - **限制與恢復**：氣元素會在1小時後、或它死亡時、或你用一個**附贈動作**解消時消失。
