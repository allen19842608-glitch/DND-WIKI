# 江湖騙子披風 (Cape of the Mountebank)

## 物品描述

這件披風帶有淡淡的硫磺味。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：穿著披風期間，以魔法動作施展[[法術/4環/任意門|任意門 (Dimension Door)]]。
  - **效果**：以此法術傳送時，你留下一團煙霧，使你離開的空間處於輕度遮蔽，直到你下一個回合結束。
  - **限制與恢復**：這項施法能力使用後，直到下一個黎明才能再次使用。
