# 角之王冠 (Crown of Horns)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **不死尖錐**：以魔法動作在 60 呎錐狀區域造成 DC 18 體質豁免的 4d8 暗蝕傷害（成功減半）；被殺死的類人生物會成為服從命令的惡靈。
- **死亡權能**：你免疫暗蝕傷害；可用附贈動作開關 60 呎恐懼靈光；並可每日一次以王冠施展律令死亡（DC 18），被其殺死的類人生物會成為邪靈。
- **傳送與詞條**：你可施展傳送術；每次使用後 7 天內不能再使用。王冠有一項次要增益、次要減益及主要減益的隨機詞條，且為可心靈感應交流的智能神器。

### 詛咒

與王冠同調會受詛咒：你不願與它分離、陣營變為中立邪惡，並在 365 天內逐步轉化為由 DM 控制的巫妖；使用不死尖錐或米爾寇之手會使立即完成轉化的累積機率增加 10%。只有祈願術或米爾寇的意志可移除此詛咒。

- **詛咒效果**：你無法自願結束同調，陣營變為中立邪惡，並會逐步轉化為巫妖。
- **解除方式**：祈願術或米爾寇的意志。
