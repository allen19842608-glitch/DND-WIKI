# 適應項鍊 (Necklace of Adaptation)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **抗毒豁免**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴此項鍊期間，你能在任何環境中正常呼吸，並且你在為避免或結束**中毒**狀態的豁免中具有優勢。
