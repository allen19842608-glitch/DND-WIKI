# 命令水元素水缽 (Bowl of Commanding Water Elementals)

## 物品描述

水缽直徑約 1 呎、深約半呎，可盛約 3 加侖水。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **召喚水元素**：
  - **啟用／觸發**：水缽盛滿水，且你位於水缽 5 呎內時，以魔法動作啟用。
  - **效果**：在最靠近水缽的未佔據空間召喚一隻[[怪物/元素/水元素|水元素 (Water Elemental)]]。它理解你會的語言、服從你的命令，並在你的同一先攻值上緊接著你行動。
  - **限制與恢復**：水元素在 1 小時後、死亡時，或你以附贈動作解消時消失。水缽直到下一個黎明前都不能再次以此方式使用。
