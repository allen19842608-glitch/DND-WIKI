# 蛛行便鞋 (Slippers of Spider Climbing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攀爬速度**：
  - **效果**：著裝這雙便鞋期間，你無需藉助雙手即可上下移動，以及穿過垂直表面和沿著天花板移動。你獲得等同於你速度的攀爬速度。不過，你無法以此法在滑溜的表面上移動，例如被冰或油覆蓋的表面。
