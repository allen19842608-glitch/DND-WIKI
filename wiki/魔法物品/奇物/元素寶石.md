# 元素寶石 (Elemental Gem)
## 📖 物品描述

這枚寶石蘊含一道元素能量的微塵。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；打破後寶石失去魔法 |

### 物品效果

- **召喚生物**：
  - **啟用／觸發**：以**使用物件**動作打破寶石。
  - **效果**：寶石失去魔法，並依種類召喚下表所示的元素。元素出現在最靠近碎裂寶石的未佔據空間，理解你說的語言、服從你的命令，並在你的先攻值上緊接著你行動。
  - **限制與恢復**：元素在 1 小時後、死亡時，或你以**附贈動作**解消時消失。
