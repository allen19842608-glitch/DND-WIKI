# 召喚魔方 (Cube of Summoning)

## 物品描述

這個小立方體形似玩偶盒。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **召喚生物**：
  - **啟用／觸發**：以魔法動作轉動魔方曲柄時。
  - **效果**：盒蓋伴隨歡快曲調彈開，在最接近盒子的未佔據空間出現一名生物，隨後盒蓋關閉，且不能以其他方式打開。擲召喚法術表決定魔方施展的法術；該法術以五環法術位施展，法術豁免 DC 為 17、法術攻擊加值為 +9，且不需要專注。除上述事項外，視為由你施展該法術。
  - **限制與恢復**：召喚一名生物後，直到下個黎明前不能再次召喚。
