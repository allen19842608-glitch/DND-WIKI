# 次元鐐銬 (Dimensional Shackles)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **束縛與封鎖移動**：
  - **啟用／觸發**：以一個操作動作，將鐐銬戴在陷入[[失能|失能 (Incapacitated)]]狀態的生物身上。
  - **效果**：鐐銬會自行調整，以適合小型至大型的生物。被鐐銬束縛的生物無法使用任何異次元移動方式，包括傳送或前往其他存在位面；鐐銬不阻止該生物穿過跨位面的傳送門。

- **解除與釋放**：
  - **啟用／觸發**：你或你在使用鐐銬時指定的生物，以一個操作動作解除鐐銬。
  - **效果**：被束縛的生物每隔 30 日可以進行一次 DC 30 的力量（運動）檢定；成功時掙脫並摧毀鐐銬。
