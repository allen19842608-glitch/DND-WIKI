| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **解除與釋放**：
  - **效果**：你和你使用鐐銬時指定的生物可以用操作動作直接解除此鐐銬。每隔30日，被約束的生物可以進行一次 DC 30的力量（運動）檢定，成功則破壞鐐銬重獲自由。
