# 保健護符 (Periapt of Health)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴此吊墜期間，你可以執行**魔法**動作來恢復2d4+2生命值。一經使用，則其直至下個黎明前都無法再次使用。
  - **限制與恢復**：一經使用，則其直至下個黎明前都無法再次使用。

- **抗毒豁免**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：此外，佩戴著此吊墜期間，你在為避免或結束**中毒**狀態的豁免中具有優勢。
