# 自然斗篷 (Nature's Mantle)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要；德魯伊或遊俠 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **環境變色與施法法器**：
  - **啟用／觸發**：穿著斗篷期間。
  - **效果**：斗篷的顏色與質地會變化，與周圍地形融合；你可以將其作為施展德魯伊和遊俠法術的施法法器。

- **自然匿蹤**：
  - **效果**：身處輕度遮蔽的區域時，你可以用一個**附贈動作** 來執行躲藏動作，即便你能被直接觀察到。
