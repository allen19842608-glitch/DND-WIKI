# 喚鼠樂笙 (Pipes of the Sewers)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **生物態度**：
  - **啟用／觸發**：攜帶期間。
  - **效果**：在你隨身攜帶這隻樂笙期間，普通鼠和巨鼠對你的態度為冷漠。除非你威脅或傷害它們，否則它們不會主動攻擊你。

- **充能效果**：
  - **啟用／觸發**：使用時。
  - **效果**：喚鼠樂笙具有3 充能，並在每日黎明時重獲1d3已消耗的充能。你可以使用一個**魔法**動作演奏該樂笙，並使用一個**附贈動作**消耗1~3 充能。如果你周圍半里內有足夠可供召喚的老鼠（由 DM 決定），那麼每消耗1 充能就能召喚1組[[wiki/怪物/野獸/鼠集群|鼠集群 (Swarm of Rats)]]。如果範圍內鼠的數量不足以形成集群，則該次充能被浪費。被召喚的集群會沿著最短的可用路線向音樂移動，但除此之外不受你的控制。
  - **限制與恢復**：喚鼠樂笙具有3 充能，並在每日黎明時重獲1d3已消耗的充能。

- **鼠群魅惑**：
  - **啟用／觸發**：使用時。
  - **效果**：在你演奏樂笙期間，每當一個未被其他生物控制的鼠群進入到你周邊30 呎範圍內時，該鼠群就必須進行一次 DC 15的感知豁免。如果豁免成功，該鼠群就會像平常一樣行動，並在接下來的24小時內不再受到樂笙音樂的影響。如果豁免失敗，鼠群就會受到樂笙音樂的影響，並且只要你每輪繼續使用一個**魔法**動作演奏樂笙，鼠群就會對你和你的盟友保持友好態度。一個友好的鼠群會遵從你的命令。當你沒對一個友好的鼠群下達命令時，它們會盡力保護自己，但不會執行其他動作。如果一個友好的鼠群在距離你30 呎以外的地方開始其回合，則你對該鼠群的控制就會終止，鼠群會像平常一樣行動，並在接下來的24小時內不再受到樂笙音樂的影響。
