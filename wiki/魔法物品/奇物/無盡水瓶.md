# 無盡水瓶 (Decanter of Endless Water)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **出水命令**：
  - **效果**：你可以用一個**魔法**動作拔出瓶塞並說出其三個命令語之一，使瓶中湧出淡水或鹹水（由你選擇）。水將在你的下一回合開始時停止湧出。從下列命令語中進行選擇：

- **水花**：
  - **效果**：**水花 Splash**。此瓶產生1加侖的水。

- **落泉**：
  - **效果**：**落泉 Fountain**。此瓶產生5加侖的水。

- **井噴**：
  - **效果**：**井噴 Geyser**。此瓶產生30加侖的水，以一道長30 呎，寬1 呎的線狀水柱的形式噴湧而出。如果你正握持著此瓶，那麼你可以將瓶口對準一處地方（無需動作）。你選擇該線狀範圍內你的一名生物，該生物必須成功通過一次 DC 13的力量豁免，否則受到1d4點鈍擊傷害並陷入**倒地**狀態。除瞄準生物以外，你也可以用瓶口瞄準線狀範圍內一個不超過200 磅，且未被著裝或攜帶的物件。該物件將被水柱打翻。
