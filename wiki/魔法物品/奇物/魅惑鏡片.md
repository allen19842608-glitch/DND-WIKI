# 魅惑鏡片 (Eyes of Charming)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：這副水晶鏡片適合戴在眼前，具有 3 充能。佩戴時，你可消耗 1 至 3 充能施展[[法術/1環/魅惑類人|魅惑類人 (Charm Person)]]（豁免 DC 13）：消耗 1 充能時為一環版本，每多消耗 1 充能，法術環階提高一環。
  - **限制與恢復**：鏡片每天黎明恢復所有已消耗的充能。
