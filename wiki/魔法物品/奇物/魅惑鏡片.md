# 魅惑鏡片 (Eyes of Charming)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：這副水晶鏡片適合戴在眼前。它具有3 充能。佩戴著這副鏡片期間，你可以消耗至少1 充能來施展_魅惑類人 Charm Person_（豁免 DC 13）。若消耗1發充能，你可以施展一環版本的該法術。每多消耗一發充能，該法術的環階就提升一環。鏡片消耗掉的充能將在每天黎明時恢復。
  - **限制與恢復**：鏡片消耗掉的充能將在每天黎明時恢復。
