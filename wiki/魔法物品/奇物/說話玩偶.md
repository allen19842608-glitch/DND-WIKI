# 說話玩偶 (Talking Doll)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **預設短語**：
  - **效果**：這個玩偶在你周邊5 呎範圍內期間，你可以花費一次短休教會它說至多六段短語，並設定玩偶說出每段短語的條件，每段短語的長度都不能超過六個單詞。你也可以使用新短語替換舊短語。設定的條件必須在玩偶周邊5 呎範圍內發生，這樣玩偶才會說話。例如，當有人撿起這個玩偶時，它可能會說一句“我想要一塊糖”。當你與玩偶的同調結束時，玩偶的短語會消失。
  - **限制與恢復**：這個玩偶在你周邊5 呎範圍內期間，你可以花費一次短休教會它說至多六段短語，並設定玩偶說出每段短語的條件，每段短語的長度都不能超過六個單詞。當你與玩偶的同調結束時，玩偶的短語會消失。
