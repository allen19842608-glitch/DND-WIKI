# 飛翼之靴 (Winged Boots)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **飛行速度**：
  - **啟用／觸發**：穿著期間，以一個**魔法**動作消耗 1 充能。
  - **效果**：獲得 30 呎飛行速度。
  - **限制與恢復**：效果持續 1 小時；若持續時間結束時你仍在飛行，便以每輪 30 呎的速度下降，直到著陸。

### 使用、充能與恢復

- **充能／使用次數**：4 充能；每次使用此效果消耗 1 充能。
- **恢復**：每日黎明時重獲 1d4 已消耗的充能。
