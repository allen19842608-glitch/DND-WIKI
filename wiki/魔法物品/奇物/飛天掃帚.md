# 飛天掃帚 (Broom of Flying)

## 📖 物品描述

這把掃帚平時如同普通掃帚。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **騎乘飛行**：
  - **啟用／觸發**：騎乘並同調期間；使用一個**魔法**動作。
  - **效果**：掃帚懸浮在你身下並載你飛行。它飛行速度為 50 呎，最多可載重 400 磅；載重超過 200 磅時，飛行速度降為 30 呎。
  - **限制與恢復**：你著陸或不再騎乘時，掃帚停止懸浮。

- **自主飛行**：
  - **啟用／觸發**：使用一個**魔法**動作，指定你熟悉、1 英里內的地點；或掃帚在你 1 英里內時。
  - **效果**：掃帚自行飛往指定地點；或自行回到你身邊。
