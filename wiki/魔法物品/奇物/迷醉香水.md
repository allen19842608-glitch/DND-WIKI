# 迷醉香水 (Perfume of Bewitching)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **社交魅惑**：
  - **啟用／觸發**：使用時。
  - **效果**：這個小瓶內裝有足夠單次使用的魔法香水。你可以使用一個**魔法**動作將香水噴灑或塗抹在自己身上，其效應會持續1小時。在持續時間內，你對試圖影響一個位於你周邊5 呎範圍內的生物而進行的所有魅力（欺瞞和遊說）檢定都具有優勢。
  - **限制與恢復**：你可以使用一個**魔法**動作將香水噴灑或塗抹在自己身上，其效應會持續1小時。
