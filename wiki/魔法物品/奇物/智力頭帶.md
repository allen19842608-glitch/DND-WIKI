# 智力頭帶 (Headband of Intellect)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **智力設定**：
  - **效果**：你著裝此帽期間智力值變為19。若你未著裝此物品時智力已為19或更高，則此魔法物品對你不產生效應。
