# 淨水珠 (Bead of Refreshment)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **淨化飲水**：
  - **效果**：這個沒有味道的凝膠珠子在液體中溶解時，它會把液體轉化成一品脫新鮮且冰冷的飲用水。這顆珠子對魔法液體或者毒藥之類的有害物質無效。
