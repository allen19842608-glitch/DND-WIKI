# 淨水珠 (Bead of Refreshment)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；珠子在液體中溶解後耗用 |

### 物品效果

- **淨化飲水**：
  - **效果**：這個沒有味道的凝膠珠子在液體中溶解時，它會把**至多一品脫**液體轉化成新鮮且冰冷的飲用水。這顆珠子對魔法液體或者毒藥之類的有害物質無效。

### 來源文字差異

中文來源 L11 寫「一品脫」，同版英文來源 `/item/179` 寫「至多一品脫」（up to a pint）。依英文原文，上方採「至多一品脫」；中文來源的數量上限譯法保留於此供追溯。
