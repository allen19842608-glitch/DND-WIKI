# 健體手冊 (Manual of Gainful Exercise)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **力量鍛鍊**：
  - **啟用／觸發**：在不超過 6 日的期間內，花費 48 小時研讀本書並實踐其中方針。
  - **效果**：你的力量提升 2，最高提升至 30。
  - **限制與恢復**：完成後，手冊失去魔力，直到一個世紀後才恢復。
