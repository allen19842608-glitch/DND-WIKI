# 幻象樂器 (Instrument of Illusions)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **視覺幻象**：
  - **啟用／觸發**：演奏期間，以一個**魔法**動作啟用。
  - **效果**：在源自樂器的 5 呎光環內創造無害的幻象視覺效應，例如發光音符、虛幻舞者、舞動蝴蝶或飄雪。若你是吟遊詩人，光環半徑為 15 呎。效應沒有觸感與聲音，且明顯是幻象。
  - **限制與恢復**：你停止演奏時，效應結束。
