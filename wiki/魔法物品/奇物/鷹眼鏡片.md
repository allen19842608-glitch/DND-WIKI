# 鷹眼鏡片 (Eyes of the Eagle)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **警戒優勢**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：這副水晶鏡片適合戴在眼前。佩戴著這副鏡片期間，你依賴視力進行的感知（察覺）檢定具有優勢。另外，在視野清晰的情況下，你可以在距離極遠之處看清小至2 呎的生物與物件的細節。
