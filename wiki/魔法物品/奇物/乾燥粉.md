# 乾燥粉 (Dust of Dryness)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **解除與釋放**：
  - **效果**：這個小包裡共裝著1d6+4把粉末。你可以用一個**操作**動作將一把粉末灑到水面上。粉末將把15 呎立方區域的水變成一個彈珠大小的小球，漂浮或停止在粉末被灑下的位置附近。小球的重量可以忽略不計。 生物可以用**操作** 動作將小球摔在某個結實表面，以令小球破碎並釋放其中的水分。這樣做會摧毀小球並使其失去其魔力。

- **元素脫水**：
  - **效果**：你可以用操作動作將一把粉末灑在5 呎內一個身體大部分由水組成的元素生物（例如**水元素 Water Elemental**或**水詭 Water Weird** ）身上。此時該生物須進行一次 DC 13的體質豁免，豁免失敗者受到10d6點暗蝕傷害，豁免成功則傷害減半。
