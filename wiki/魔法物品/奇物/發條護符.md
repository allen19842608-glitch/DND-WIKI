# 發條護符 (Clockwork Amulet)

## 物品描述

這枚銅製護符內有相互咬合的微小齒輪，由機械境的魔法驅動；護符會發出微弱的滴答與呼呼聲。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **固定攻擊骰值**：
  - **啟用／觸發**：佩戴護符期間，當你進行攻擊擲骰時。
  - **效果**：你可以不擲 d20，直接將該骰的結果視為 10。
  - **限制與恢復**：此效果使用後，直到下一個黎明前都無法再次使用。
