# 發條護符 (Clockwork Amulet)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **位面移動**：
  - **效果**：這枚銅製的護符內有數個互相咬合的微小齒輪，其以機械境——一個秩序至極，萬物皆可被機械預測的位面——的魔法所驅動。模糊的滴答聲與呼呼的噪音從中傳出。

- **固定攻擊骰值**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴該護符期間，當你進行一次攻擊檢定時，你可以放棄擲骰並在 d20的骰值上取10。該詞條一經使用，直至下個黎明前都無法再次使用。
  - **限制與恢復**：該詞條一經使用，直至下個黎明前都無法再次使用。
