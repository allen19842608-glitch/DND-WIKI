# 垂釣之杆 (Pole of Angling)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **釣竿變形**：
  - **啟用／觸發**：持握期間，以一個**魔法**動作啟用。
  - **效果**：將物品轉變為附帶魚鉤、魚線與捲線盤的釣魚竿，或將釣魚竿恢復為一根長桿。
