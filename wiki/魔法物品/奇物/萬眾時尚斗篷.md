# 萬眾時尚斗篷 (Cloak of Many Fashions)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **變換樣式**：
  - **啟用／觸發**：穿著斗篷期間，以附贈動作啟用。
  - **效果**：改變斗篷的樣式、顏色及看起來的品質，也可模仿其他魔法斗篷的外觀。
  - **限制與恢復**：斗篷重量不變，無論外觀如何仍只是一件斗篷，也不會獲得所模仿斗篷的魔法屬性。
