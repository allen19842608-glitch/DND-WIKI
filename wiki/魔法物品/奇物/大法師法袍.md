# 大法師法袍 (Robe of the Archmagi)

## 📖 物品描述

這件典雅的長袍由精美布料製成，並以符文裝飾。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要（術士、契術師或法師） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲**：
  - **啟用／觸發**：著裝並同調期間；未著裝護甲時。
  - **效果**：你的基礎護甲等級為 15 + 你的敏捷調整值。

- **魔法抗性**：
  - **啟用／觸發**：著裝並同調期間；對抗法術或其他魔法效應進行豁免時。
  - **效果**：你的豁免檢定具有優勢。

- **戰爭法師**：
  - **啟用／觸發**：著裝並同調期間。
  - **效果**：你的法術豁免 DC 與法術攻擊加值各提升 2。
