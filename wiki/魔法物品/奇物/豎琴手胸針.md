# 豎琴手胸針 (Harper Pin)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（銀質）或珍稀（金質） |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **豎琴手偽裝**：完成同調時選擇一個豎琴手偽裝（包含陣營與生物類型）。佩戴期間，偵測你的生物類型、陣營或位置的魔法會將你視為該偽裝。
- **銀質胸針**：完成同調時可預設一段不超過 25 個詞的概略思想。佩戴期間，讀心者偵測到的是該思想；使用研究動作讀心者須成功通過 DC 13 智力（調查）檢定，才會知道這是預設思想。
- **金質胸針**：佩戴期間可對自己施展回避偵測；效果持續至關閉效果、取下胸針或結束同調。
