# 營養珠 (Bead of Nourishment)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；珠子在舌頭上溶解後耗用 |

### 物品效果

- **一天份營養**：
  - **啟用／觸發**：凝膠珠在你的舌頭上溶解時。
  - **效果**：提供等同一天份口糧的營養。
