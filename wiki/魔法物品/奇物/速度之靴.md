# 速度之靴 (Boots of Speed)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **加速步伐**：
  - **啟用／觸發**：穿著靴子期間，以附贈動作互擊靴子的腳跟。
  - **效果**：靴子使你的速度加倍；任何生物對你進行藉機攻擊時，該攻擊擲骰具有劣勢。再次互擊腳跟時，這項效果結束。
  - **限制與恢復**：累計使用這項效果達 10 分鐘後，靴子的魔法對你失效，直到你完成一次長休。
