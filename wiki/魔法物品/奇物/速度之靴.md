# 速度之靴 (Boots of Speed)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **加速步伐**：
  - **效果**：著裝這雙靴子期間，你可以使用一個**附贈動作**來互擊腳後跟。若如此做，你的移動速度將加倍，且任何生物對你發動藉機攻擊時都具有劣勢。若再次互擊腳後跟則該效應終止。

- **加速限制**：
  - **效果**：在你使用該靴子的詞條共計10分鐘後，其魔法效應將不再對你生效，直至你完成一次長休。
