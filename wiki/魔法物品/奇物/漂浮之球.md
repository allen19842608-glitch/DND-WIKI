# 漂浮之球 (Driftglobe)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |
| 重量 (Weight) | 1 磅 |

### 物品效果

- **發光命令**：
  - **啟用／觸發**：你在球體 60 呎內說出命令語時。
  - **效果**：球體發出相當於[[法術/戲法/光亮術|光亮術 (Light)]]或[[法術/3環/晝明術|晝明術 (Daylight)]]的光芒，由你選擇。
  - **限制與恢復**：使用晝明術效應後，直到下一個黎明前都無法再次使用該效應。

- **漂浮**：
  - **啟用／觸發**：以一個魔法動作說出另一個命令語，使正在發光的球體升空。
  - **效果**：球體懸浮於離地不超過 5 呎處，直到你或另一生物抓住它。若你離開球體 60 呎範圍，它會循最短路徑跟隨你，直到與你相距不超過 60 呎。
  - **限制與恢復**：如果球體的移動受阻，它會緩緩落地、停止運作，光芒也隨之熄滅。
