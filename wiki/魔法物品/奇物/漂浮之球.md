# 漂浮之球 (Driftglobe)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **漂浮**：
  - **效果**：你可以用**魔法**動作來說出另一個命令語，以讓發光球體飛到空中，漂浮在離地面不超過5 呎的地方。球體將持續漂浮在空中，直到你或另一生物將它抓住。如果你離開球體周圍60 呎範圍，則它將沿最短路徑跟隨你移動直到距離你60 呎為止。如果它的移動遭到妨礙，它將閃爍著落回地面並回到啟動前的狀態，其發出的光芒也會熄滅。
