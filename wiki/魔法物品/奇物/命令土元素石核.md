# 命令土元素石核 (Stone of Controlling Earth Elementals)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **召喚土元素**：
  - **啟用／觸發**：以這塊重 5 磅的石核接觸地面時，使用一個**魔法**動作。
  - **效果**：在你 30 呎內一處未佔據空間召喚一隻土元素（Earth Elemental）。它理解你所說的語言、服從你的命令、使用你的先攻值，並在你之後立即行動。
  - **限制與恢復**：土元素在 1 小時後、死亡時，或你以一個**附贈動作**將其解消時消失；使用後，石核直到下個黎明才能再次用於此效果。
