# 怪物菸斗 (Pipe of Smoke Monsters)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **煙霧怪物**：
  - **啟用／觸發**：使用時。
  - **效果**：用這個菸斗抽菸期間，你可以使用一個**魔法**動作呼出一股煙霧並使其變成一個生物的形狀，例如一條龍、一隻呋嚕、或者一隻史拉蟾。該形狀必須小到足以容納進1 呎立方，並且其會在數秒後失去其形狀，變回一股普通的煙霧。
