# 攀爬繩 (Rope of Climbing)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 來源未註明；生命值降至 0 時會被摧毀 |

### 物品效果

- **活化與攀爬**：
  - **啟用／觸發**：持握這根 60 呎長繩索的一端時，以魔法動作命令另一端活化，前往距離你不超過繩索長度的指定目的地。
  - **效果**：繩索可承受最多 3,000 磅。首次命令時，另一端在你的回合移動 10 呎，此後在你的每個回合開始時移動 10 呎，直到抵達目的地或你命令它停止。你也可命令繩索牢固繫在物件上或鬆開、打結或解結，以及盤卷以便攜帶。打結時每隔 1 呎出現一個大結，繩索縮短為 50 呎；使用它攀爬所進行的屬性檢定具有優勢。

- **繩索耐久**：
  - **效果**：繩索 AC 20、生命值 20，免疫毒素及心靈傷害。只要尚有至少 1 點生命值，每 5 分鐘恢復 1 點生命值；生命值降至 0 時被摧毀。
