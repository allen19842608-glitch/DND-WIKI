# 命令火元素火盆 (Brazier of Commanding Fire Elementals)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **當你位於這座火盆5 呎內期間，你能夠以一個魔法動作來召喚一隻火元素**：
  - **效果**：當你位於這座火盆5 呎內期間，你能夠以一個**魔法**動作來召喚一隻**火元素 Fire Elemental** 。火元素會出現在距離火盆最近的未佔據空間、理解你所說的語言、服從你的命令、使用你的先攻值並在你之後立即執行其回合。火元素會在1小時後，或它死亡時，或你以一個**附贈動作**解消時消失。直到下個黎明前，火盆都無法再以該方式進行使用。
  - **限制與恢復**：火元素會在1小時後，或它死亡時，或你以一個**附贈動作**解消時消失。
