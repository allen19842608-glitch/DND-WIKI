# 命令火元素火盆 (Brazier of Commanding Fire Elementals)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **召喚火元素**：
  - **啟用／觸發**：你位於火盆 5 呎內時，以魔法動作啟用。
  - **效果**：在最靠近火盆的未佔據空間召喚一隻[[怪物/元素/火元素|火元素 (Fire Elemental)]]。它理解你會的語言、服從你的命令，並在你的同一先攻值上緊接著你行動。
  - **限制與恢復**：火元素在 1 小時後、死亡時，或你以附贈動作解消時消失。火盆直到下一個黎明前都不能再次以此方式使用。
