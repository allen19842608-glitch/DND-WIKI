# 冒險者之戒 (Adventurer's Ring)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **無熱火焰**：
  - **啟用／觸發**：戒指蓋子開啟期間。
  - **效果**：產生一簇不具熱量、不消耗燃料的火焰，提供半徑 20 呎明亮光照及額外 20 呎微光。
  - **限制與恢復**：你可以用附贈動作開啟或蓋上蓋子，分別點燃或熄滅火焰。
