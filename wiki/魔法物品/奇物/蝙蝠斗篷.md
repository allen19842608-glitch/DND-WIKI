# 蝙蝠斗篷 (Cloak of the Bat)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **飛行**：
  - **效果**：著裝此斗篷期間，你的敏捷（隱匿）檢定具有優勢。在微光或黑暗的環境中，你可以抓住斗篷的邊沿，利用它以獲得40 呎的飛行速度。如果你在以此法飛行時不再抓住斗篷邊沿或不再處於微光或黑暗環境中，則你失去此飛行速度。

- **施展法術**：
  - **效果**：著裝此斗篷且身處微光或黑暗環境期間，你可以用一個**動作**對自己施展法術 _變形術 Polymorph_，並以此變成一隻**蝙蝠 bat**。你在變成蝙蝠時保留自身的智力、感知和魅力屬性。該詞條一經使用，直至下個黎明前都無法再次使用。
  - **限制與恢復**：該詞條一經使用，直至下個黎明前都無法再次使用。
