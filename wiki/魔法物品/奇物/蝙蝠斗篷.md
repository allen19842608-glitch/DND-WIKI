# 蝙蝠斗篷 (Cloak of the Bat)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **隱匿優勢**：
  - **啟用／觸發**：穿著斗篷期間。
  - **效果**：你的敏捷（隱匿）檢定具有優勢。

- **飛行**：
  - **啟用／觸發**：穿著斗篷，在微光或黑暗中抓住斗篷邊緣。
  - **效果**：你獲得 40 呎飛行速度。
  - **限制與恢復**：以此方式飛行時，若不再抓住斗篷邊緣，或離開微光與黑暗環境，便失去此飛行速度。

- **可施展法術**：
  - **啟用／觸發**：穿著斗篷且身處微光或黑暗環境時。
  - **效果**：你可以對自己施展[[法術/4環/變形術|變形術 (Polymorph)]]，變成一隻[[怪物/野獸/蝙蝠|蝙蝠 (Bat)]]；變形期間保留原有的智力、感知及魅力值。
  - **限制與恢復**：使用後，直到下一個黎明前都不能再次以此方式施法。
