# 雜貨法袍 (Robe of Useful Items)

## 物品描述

這件長袍上有各種顏色與形狀的布製補丁。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 補丁用後移除；全部移除後長袍成為普通衣物 |

### 物品效果

- **取下補丁**：
  - **啟用／觸發**：穿著長袍時，以魔法動作拆下其中一塊補丁。
  - **效果**：補丁成為它所代表的物件或生物。最後一塊補丁被取下後，長袍成為普通衣物。
  - **限制與恢復**：長袍起初含下列補丁各兩塊：裝滿燃料且點燃的牛眼提燈、匕首、鏡子、長桿、盤繞的繩索、麻袋。另有 4d4 塊其他補丁；由 DM 選擇，或擲下表決定。
