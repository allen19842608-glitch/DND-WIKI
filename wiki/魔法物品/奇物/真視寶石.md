# 真視寶石 (Gem of Seeing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **透過寶石觀察**：
  - **啟用／觸發**：以一個**魔法**動作消耗 1 充能。
  - **效果**：接下來 10 分鐘，透過寶石觀察時，你具有 120 呎範圍的[[規則/移動與探索/真實視覺|真實視覺 (Truesight)]]。
  - **限制與恢復**：寶石共有 3 充能，每日黎明恢復 1d3 已消耗的充能。
