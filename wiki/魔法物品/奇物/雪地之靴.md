# 雪地之靴 (Boots of the Winterlands)

## 物品描述

這雙加絨靴子溫暖且舒適。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

> **共同適用條件**：穿著這雙靴子期間。

- **寒冷抗性**：
  - **效果**：你對寒冷傷害具有抗性，並且無須額外保護也能忍受華氏 0 度或更低的溫度。

- **冬行者**：
  - **效果**：你無視冰或雪造成的困難地形。
