# 神威綁帶 (Wraps of Unarmed Power)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物，非普通（+1）/珍稀（+2）/ |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **徒手打擊加值**：
  - **啟用／觸發**：裹著綁帶期間。
  - **效果**：你的徒手打擊攻擊檢定與傷害擲骰獲得依稀有度而定的加值；你可以令徒手打擊造成力場傷害，而非原本的傷害類型。
