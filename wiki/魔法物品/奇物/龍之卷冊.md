# 龍之卷冊 (Tome of the Dragon)

## 物品描述

此厚重卷冊記載將活龍或死龍轉化為龍巫妖的儀式。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **龍巫妖儀式**：使用者須是具至少兩個 5 環法術位的施法者或龍類；符合相同條件的助手可協助。持續接觸成年或遠古龍的活體或遺體，並準備價值 80,000 GP 的物資後，舉行持續 `180 ÷ 參與者人數` 天的儀式；每天休息不得超過 8 小時。龍類使用者的成本與時間減半。
- **完成結果**：卷冊爆炸，對使用者與助手各造成 12d6 暗蝕傷害；生命值降至 0 者死亡後立即成為由 DM 控制的喪屍。目標轉化為龍巫妖；活龍死亡後其精魄進入儀式寶石，遺體則復甦並由外層位面邪惡巨龍精魄占據。
