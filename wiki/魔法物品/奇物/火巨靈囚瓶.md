# 火巨靈囚瓶 (Efreeti Bottle)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；依首次擲骰結果，失去魔力前最多可開啟四次 |

### 物品效果

- **釋放火巨靈**：
  - **啟用／觸發**：以一個**魔法**動作打開彩繪黃銅瓶的瓶塞。
  - **效果**：一團濃煙從瓶內溢出；在你的回合結束時，煙霧伴隨無害火焰消失，一名[[怪物/元素/火巨靈|火巨靈 (Efreeti)]]出現在你周邊 30 呎內一處未佔據空間。

- **隨機結果**：
  - **效果**：瓶子第一次被打開時，DM 按下面的表格擲骰，以此來決定會發生什麼。
### 隨機表

| **d10** | **發生事件** |
| --- | --- |
| 1 | 火巨靈攻擊你。戰鬥進行5輪後，火巨靈將消失，同時瓶子將失去魔力。 |
| 2-9 | 在接下來的1小時內，火巨靈理解你的語言並遵循你的命令。在這之後它會重新回到瓶中，而一個新的瓶塞將顯現並再次將其封印，且新瓶塞在24小時內都無法被拔出。下兩次打開瓶子時會產生同樣的效應。當瓶子第四次被打開時，火巨靈將逃走並消失，同時瓶子將失去魔力。 |
| 10 | 火巨靈理解你的語言並能為你施展一次[[法術/9環/祈願術\|祈願術 (Wish)]]。它將在 1 小時後或施放完祈願術時消失，同時瓶子將失去魔力。 |
