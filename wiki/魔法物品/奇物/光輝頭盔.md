# 光輝頭盔 (Helm of Brilliance)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **持用增益**：
  - **效果**：你著裝頭盔時獲得以下增益。

- **鑽石輝光**：
  - **效果**：**鑽石輝光 Diamond Light**。只要頭盔上至少有一顆鑽石，其便會散發出30 呎光環區域。至少有一名亡靈位於此區域中時，光環區域便會充滿微光光照。任何在此區域中開始其回合的亡靈受到1d6光耀傷害。

- **火歐泊烈焰**：
  - **效果**：**火歐泊烈焰 Fire Opal Flames**。只要頭盔上至少有一顆火歐泊，你便可以用一個**魔法**動作令烈焰包裹在你持握的一把武器上。烈焰散發出10 呎明亮光照與其外10 呎微光光照。烈焰對你和武器是無害的。當你使用此武器進行的攻擊檢定命中時，目標額外受到1d6火焰傷害。烈焰持續至你用一個附贈動作熄滅烈焰，你丟下武器或收起武器。

- **紅寶石抗性**：
  - **效果**：**紅寶石抗性 Ruby Resistance**。只要頭盔上至少有一顆紅寶石，你便具有對火焰傷害的抗性。

- **法術**：
  - **效果**：**法術 Spells**。你可以施展以下法術之一（豁免 DC 18），使用頭盔上其中一顆特定種類的寶石作為法術成分：_晝明術 Daylight_（歐泊）、_火球術 Fireball_（火歐泊）、_虹光噴射 Prismatic Spray_（鑽石）、_火牆術 WallofFire_（紅寶石）。施展法術時，寶石將被摧毀並從頭盔上消失。
  - **限制與恢復**：施展法術時，寶石將被摧毀並從頭盔上消失。

- **沐於火中**：
  - **效果**：**沐於火中 TakeFireDamage**。若你著裝著頭盔且因失敗於某一法術的豁免而受到了火焰傷害，骰1d20。若骰值為1，則頭盔上剩餘的寶石將迸射出光束，隨後頭盔被摧毀。每名位於以你為原點的60 呎光環區域內的生物必須成功於一次 DC 17的敏捷豁免檢定，否則被光束擊中並受到等同於頭盔上剩餘寶石數量的光耀傷害。
