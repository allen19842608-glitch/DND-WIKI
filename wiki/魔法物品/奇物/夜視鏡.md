# 夜視鏡 (Goggles of Night)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **黑暗視覺**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴著這副暗色鏡片期間，你具有60 呎範圍的黑暗視覺。如果你本就擁有黑暗視覺，則其在佩戴著這副夜視鏡期間範圍再擴大60 呎。
