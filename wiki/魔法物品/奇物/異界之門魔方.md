# 異界之門魔方 (Cubic Gate)

## 📖 物品描述

這個邊長 3 吋的立方體散發明顯的魔法能量。它的六個面各連接一個不同的存在位面：其中一面連接物質位面，其餘各面所連接的位面由 DM 決定。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展異界之門**：
  - **啟用／觸發**：以一個魔法動作消耗 1 充能，按壓魔方其中一面一次。
  - **效果**：你透過魔方施展[[法術/9環/異界之門|異界之門 (Gate)]]，開啟通往該面所連接位面的傳送門。

- **施展位面轉移**：
  - **啟用／觸發**：以一個魔法動作消耗 1 充能，按壓魔方其中一面兩次。
  - **效果**：你透過魔方施展[[法術/7環/位面轉移|位面轉移 (Plane Shift)]]，將目標傳送至該面所連接的位面。

### 使用、充能與恢復

- **充能／使用次數**：魔方共有 3 充能；每次以上述任一方式施法時消耗 1 充能。
- **恢復**：每日黎明重獲 1d3 點已消耗的充能。
