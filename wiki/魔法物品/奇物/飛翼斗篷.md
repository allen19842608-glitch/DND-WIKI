# 飛翼斗篷 (Wings of Flying)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **翅膀變形**：
  - **啟用／觸發**：穿著期間，以一個**魔法**動作啟用。
  - **效果**：將斗篷轉變為背上的一對翅膀，並獲得 60 呎飛行速度。
  - **限制與恢復**：翅膀持續 1 小時，或你以一個**魔法**動作提前結束效果；翅膀消失時若你仍在空中便會墜落。翅膀消失後，1d12 小時內不能再次使用。
