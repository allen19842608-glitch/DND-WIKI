# 卡林曼農水晶 (Calimemnon Crystal)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **水晶詞條**：可作奧術法器；獲得 30 呎飛行速度與懸浮；能以 DC 18 施展造水術／枯水術、變巨術／縮小術、僅對自身的隱形術及高級幻影。
- **寒冷靈光**：以魔法動作開關 20 呎光環。生物進入、光環進入其空間或在其中結束回合時受 2d6 寒冷傷害（每回合最多一次）；同調者不受影響。
- **治癒／傷害射線**：持握時以魔法動作向 60 呎內一個或多個目標射出六道射線；每道可造成 DC 18 敏捷豁免的 6d6 + 6 光耀傷害（成功減半），或治療 2d6 + 2 生命值。使用治癒射線後至下個黎明前不能再用。
- **隨機詞條與摧毀**：具有一項次要增益、主要增益、次要減益與主要減益詞條。只有同調者以祈願術祈願摧毀它時才會毀壞，並釋放其中巨靈。
