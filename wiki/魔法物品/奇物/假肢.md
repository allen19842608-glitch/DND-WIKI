# 假肢 (Prosthetic Limb)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **肢體替代**：
  - **效果**：這件魔法物品能替代一處缺失的肢體——一隻手，一條手臂，一條腿，或是類似的身體部位。在假肢已完成安裝期間，它能像被代替的肢體一樣正常工作。

- **安裝與移除**：
  - **效果**：你可以用一個魔法動作將其裝好或者卸除，且只要你活著，它就不能在你非自願的情況下被移除。
