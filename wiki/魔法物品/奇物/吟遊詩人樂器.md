# 吟遊詩人樂器 (Instrument of the Bards)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 依七種樂器變體而定；見下表 |
| 同調 (Attunement) | 需要；僅限吟遊詩人 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **未同調演奏風險**：未與樂器同調的生物若嘗試演奏，必須通過 DC 15 感知豁免，否則受到 2d4 心靈傷害。
- **施展法術**：演奏樂器時，你可以透過它施展下表所列的其中一道法術。每種樂器都有「所有樂器」列的四道法術，以及其專屬列的法術。法術使用你的施法屬性與法術豁免 DC。某件樂器施展一道法術後，直到下個黎明前都不能再透過**該件樂器**施展**該道法術**。

## 來源差異與不確定性

中文來源 L84 將麥克-弗瑞米西特琴的英文拼成 `Mac-Fuimidh cittern`；同版英文紀錄 `/item/1079` 為 `Mac-Fuirmidh Cittern`。英文名稱依同版原文記錄，中文名稱沿用來源譯名；兩者所指的樂器及法術列相同。
