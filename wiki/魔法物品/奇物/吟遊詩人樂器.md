# 吟遊詩人樂器 (Instrument of the Bards)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **未同調演奏風險**：
  - **效果**：吟遊詩人樂器在各方面都優於普通樂器。吟遊詩人樂器共有七種，每種都以一所吟遊詩人學院的名字命名。吟遊詩人樂器列表中列出了所有樂器的通用法術，以及每種樂器的獨有法術和其稀有度。在未與樂器完成同調的情況下，嘗試演奏樂器的生物必須進行一次 DC 15的感知豁免，豁免失敗則會受到2d4心靈傷害。

- **施展法術**：
  - **效果**：你可以通過演奏樂器來施展它的一個法術。一旦該樂器被用來施展了某一個法術，則其直至下個黎明前都無法再被用來施展該法術。這些法術使用你的施法屬性和法術豁免 DC。
  - **限制與恢復**：一旦該樂器被用來施展了某一個法術，則其直至下個黎明前都無法再被用來施展該法術。
