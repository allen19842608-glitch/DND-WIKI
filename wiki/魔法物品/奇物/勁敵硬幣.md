# 勁敵硬幣 (Rival Coin)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：使用時。
  - **效果**：這枚硬幣具有1 充能，並在每日黎明時重獲已消耗的充能。你可以使用一個**魔法**動作拋擲這枚硬幣，並消耗其充能。擲一枚任意骰子來確定硬幣是正面朝上（若結果為偶數）還是反面朝上（若結果為奇數）。此結果決定了硬幣產生的效應：
  - **限制與恢復**：這枚硬幣具有1 充能，並在每日黎明時重獲已消耗的充能。

- **正面**：
  - **效果**：**正面 Heads**。以位於你60 呎內一個你可見的生物為目標。目標進行一次 DC 13 的感知豁免：如果豁免失敗，目標會受到2d4心靈傷害，並在其下一回合結束前進行的下一次攻擊檢定中具有劣勢；豁免成功則目標僅受半傷。

- **反面**：
  - **效果**：**反面 Tails**。你受到1d4心靈傷害。
