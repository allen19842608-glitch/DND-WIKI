# 移位斗篷 (Cloak of Displacement)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **移位幻影**：
  - **效果**：著裝此斗篷期間，它將魔法性地投射出你的幻影，使你看起來像是站在一個和你實際位置稍有偏差的地方。任何生物對你的攻擊檢定都將具有劣勢。你受到傷害時斗篷會暫時失效，直至你的下一回合開始恢復效應。當你的速度為0時，該詞條將被壓制。
  - **限制與恢復**：你受到傷害時斗篷會暫時失效，直至你的下一回合開始恢復效應。
