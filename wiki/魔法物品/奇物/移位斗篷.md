# 移位斗篷 (Cloak of Displacement)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **移位幻影**：
  - **啟用／觸發**：穿著斗篷期間。
  - **效果**：斗篷投射你的幻影，令你看起來站在實際位置附近的另一處，使任何生物對你的攻擊擲骰具有劣勢。
  - **限制與恢復**：你受到傷害時，這項效果停止運作，直到你下一個回合開始；你的速度為 0 時，這項效果受到壓制。
