# 比拉羅的鐵索 (Iron Bands of Bilarro)

## 物品描述

這顆鏽跡斑斑的鐵球直徑 1/4 呎，重 1 磅。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **投擲與束縛**：
  - **啟用／觸發**：以一個**魔法**動作，將鐵球擲向你可見、位於 60 呎內的巨型或更小體型生物。
  - **效果**：鐵球在空中展開成鐵索。進行一次遠程攻擊檢定，攻擊加值等於你的敏捷調整值加熟練加值。命中時，目標陷入**束縛**狀態，直到你以一個**附贈動作**下令釋放；未命中或下令釋放時，鐵索收縮回鐵球。
  - **限制與恢復**：使用後直到下一次黎明前不能再次使用。

- **打破鐵索**：
  - **啟用／觸發**：能觸及鐵索的生物（包括被束縛的生物）可用一個動作，進行 DC 20 的力量（運動）檢定。
  - **效果**：成功時，鐵索被摧毀，被束縛的生物獲釋。
  - **限制與恢復**：失敗時，該生物在接下來 24 小時內的後續嘗試均自動失敗。
