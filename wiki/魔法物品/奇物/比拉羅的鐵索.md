# 比拉羅的鐵索 (Iron Bands of Bilarro)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **命中效果**：
  - **效果**：進行一次遠程攻擊檢定，將你的熟練加值和敏捷調整值加到這次攻擊檢定中。如果攻擊命中，目標會陷入**束縛**狀態，直至你使用一個**附贈動作**下令釋放它。如果攻擊未命中，或是你下達了釋放命令，鐵索會重新收縮為鐵球。
  - **限制與恢復**：如果攻擊命中，目標會陷入**束縛**狀態，直至你使用一個**附贈動作**下令釋放它。

- **一個能觸及到鐵索的生物（包括被鐵索束縛的生物）可以使用一個動作進行一次**：
  - **效果**：一個能觸及到鐵索的生物（包括被鐵索束縛的生物）可以使用一個動作進行一次 DC 20的力量（運動）檢定來嘗試打破鐵索。如果檢定成功，此物品將被摧毀，被束縛的生物將被釋放。如果檢定失敗，進行此次檢定的生物在隨後的24小時內進行的任何進一步嘗試都會自動失敗。

- **使用限制**：
  - **效果**：此鐵索一經使用，直至下個黎明前它都無法再次被使用。
