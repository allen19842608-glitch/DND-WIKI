# 水下呼吸帽 (Cap of Water Breathing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **水下呼吸**：
  - **啟用／觸發**：戴著帽子並位於水下時，以魔法動作啟用。
  - **效果**：帽子在你的頭部周圍創造一個空氣泡，讓你能在水下正常呼吸。
  - **限制與恢復**：氣泡持續隨著你，直到你取下帽子或不再處於水下。
