# 伊格薇爾伏惡魔志 (Demonomicon of Iggwilv)

## 物品描述

此書由伊格薇爾伏撰寫，記錄無底深淵各層與居民，是詳盡且褻瀆的惡魔學著作。其內藏有一塊神秘的深淵位面碎片，因此即使書頁遭撕除，內容仍會持續更新。

### 物品效果

- **深淵學識**：
  - **效果**：進行與惡魔資訊相關的智力檢定，或與深淵相關的感知（求生）檢定時，你可參考惡魔志並在該檢定具有優勢。

- **封印**：
  - **啟用／觸發**：持握期間；以一個**魔法**動作指定一名你可見、被困於防護法陣的邪魔時。
  - **效果**：目標必須進行 DC 20 魅力豁免；失敗時被困於惡魔志的一張空白頁中，頁面會記錄其廣為人知的名字與墮落事蹟。此書被發現時，通常已記錄 1d4 名邪魔。
  - **限制與恢復**：此效果使用後，直至下個黎明無法再次使用。

- **被封印邪魔的附身**：
  - **啟用／觸發**：你完成長休時，且你與惡魔志位於同一位面。
  - **效果**：書中一名被困生物可嘗試附身你；你必須進行 DC 20 魅力豁免。失敗時，該生物如操控傀儡般控制你，並可用一個**魔法**動作釋放你，於距你最近的未佔據空間顯現。
  - **限制與恢復**：豁免成功時，該邪魔在 7 天內不能再次嘗試附身你；其他被困邪魔仍可嘗試。

- **迷惑**：
  - **啟用／觸發**：攜帶期間；你施展僅針對邪魔的*防護法陣*，或對邪魔施展*異界誓縛*時。
  - **效果**：無論使用的法術位環階，該法術均以九環版本施展，且邪魔對抗該法術的豁免檢定具有劣勢。

- **鞭笞邪魔**：
  - **啟用／觸發**：攜帶期間；你對邪魔施展的法術進行傷害擲骰時。
  - **效果**：傷害擲骰取可能的最大值，不須擲骰。

- **隨機詞條**：
  - **效果**：惡魔志具有 2 項次要增益詞條、1 項次要減益詞條與 1 項主要減益詞條（見本章「神器」）。

### 可施展法術

- **啟用／觸發**：持握期間；以一個**魔法**動作施展。
- **效果**：此書的法術豁免 DC 為 20。

| 法術 | 充能消耗 |
| :--- | :---: |
| *塔莎狂笑術 Tasha's Hideous Laughter* | 0 |
| *防護法陣 Magic Circle* | 1 |
| *異界誓縛 Planar Binding* | 2 |
| *魔魂壺 Magic Jar* | 3 |
| *異界誓盟 Planar Ally* | 3 |
| *位面轉移 Plane Shift*（僅限無底深淵） | 3 |
| *邪魔召喚術 Summon Fiend* | 3 |

- **限制與恢復**：此書具有 8 充能，並在每日黎明重獲 1d8 已消耗的充能。

### 特殊規則

- **摧毀惡魔志**：六位不同惡魔領主必須各撕下六分之一書頁。書頁在 24 小時內恢復；在所有書頁皆被撕下並恢復前，打開殘餘裝訂部分者會被傳送至書中隱藏的新生深淵層級。若將其中的弗拉茲-厄魯之杖帶離口袋位面，惡魔志會立刻變成《反序古典》的普通過時抄本，且弗拉茲-厄魯立刻知曉法杖已現世。
