# 防護聖甲蟲 (Scarab of Protection)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **防禦**：
  - **啟用／觸發**：攜帶並同調期間。
  - **效果**：你的護甲等級獲得 +1 加值。

- **保護**：
  - **啟用／觸發**：攜帶並同調期間；你對死靈系法術或亡靈造成的有害效應豁免失敗時；使用一個**反應**並消耗 1 充能。
  - **效果**：此聖甲蟲具有 12 充能。你令該次豁免改為成功。
  - **限制與恢復**：充能耗盡時，聖甲蟲被摧毀並化為灰燼。

- **法術抗性**：
  - **啟用／觸發**：攜帶並同調期間；對抗法術進行豁免時。
  - **效果**：你的豁免檢定具有優勢。
