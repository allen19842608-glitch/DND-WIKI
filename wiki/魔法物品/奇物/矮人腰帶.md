# 矮人腰帶 (Belt of Dwarvenkind)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

> **共同適用條件**：穿戴並同調期間。

- **矮人語**：
  - **效果**：你理解矮人語。

- **矮人之友**：
  - **效果**：你進行與矮人及灰矮人互動的魅力（遊說）檢定時具有優勢。

- **剛毅**：
  - **效果**：你的體質增加 2，最高為 20。

- **鬍鬚生長**：
  - **啟用／觸發**：每個黎明。
  - **效果**：若你能長出鬍鬚，有 50% 機率長出濃密鬍鬚；已有鬍鬚時，鬍鬚明顯變得更濃密。

- **黑暗視覺**：
  - **啟用／觸發**：你不是矮人或灰矮人時。
  - **效果**：你獲得 60 呎黑暗視覺。

- **體魄**：
  - **啟用／觸發**：你不是矮人或灰矮人時。
  - **效果**：你獲得對毒素傷害的抗性，並對避免或結束**中毒 Poisoned**狀態的豁免檢定具有優勢。
