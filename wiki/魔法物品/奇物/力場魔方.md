# 力場魔方 (Cube of Force)

## 物品描述

這個立方體稜長約 1 寸，每一面都有不同標記。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：按下魔方的一面，並消耗該面對應的充能時。
  - **效果**：你施展下表中對應的法術，法術豁免 DC 為 17。
  - **限制與恢復**：魔方共有 10 充能，每日黎明恢復 1d6 點已消耗的充能；每次施法消耗表列點數。
