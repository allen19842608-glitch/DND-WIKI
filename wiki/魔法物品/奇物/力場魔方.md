# 力場魔方 (Cube of Force)

## 物品描述

這個立方體稜長約 1 寸，每一面都有不同標記。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：按下魔方的一面並消耗對應充能時。
  - **效果**：你施展力場魔方各面效果表中對應的法術，法術豁免 DC 為 17。

### 使用、充能與恢復

- **充能／使用次數**：共有 10 充能；施展法術時消耗表中所列充能。
- **恢復**：每日黎明時重獲 1d6 已消耗的充能。
