# 戴恩的摺疊要塞 (Daern's Instant Fortress)

## 📖 物品描述

此物是一尊高 1 吋的精金小雕像。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **展開要塞**：
  - **啟用／觸發**：使用一個**魔法**動作，將雕像置於地面並說出命令語。
  - **效果**：雕像迅速展開為方形精金高塔。若塔內空間未被佔據，再次說出命令語可使其恢復雕像形態。高塔出現時，其佔據空間內的生物被推至塔外未佔據空間，該區域內未穿戴或未攜帶的物件也被推出。

- **要塞構造**：
  - **啟用／觸發**：高塔展開期間。
  - **效果**：高塔長、寬各 20 呎，高 30 呎，牆上有箭孔，頂端設城垛。內部有兩層，由你選擇的梯子、樓梯或斜坡連通，並通往頂層活板門。展開時底層面向你的牆面出現一扇門；只有你使用一個**附贈動作**向門傳令時才會開啟，且此門免疫*敲擊術 Knock*與類似魔法。

- **要塞耐久**：
  - **啟用／觸發**：高塔展開期間。
  - **效果**：魔法使高塔無法被推倒。塔頂、門與每面牆各有 AC 20、HP 100，免疫非攻城器械造成的揮砍、鈍擊與穿刺傷害，並對其他所有傷害具有抗性。
  - **限制與恢復**：將塔變回雕像不會修復傷害。只有*祈願術 Wish*能修復要塞（視為複製不高於八環的法術）；每次施展可使高塔恢復所有生命值。
