# 時間法球 (Orb of Time)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **位面移動**：
  - **啟用／觸發**：持握期間。
  - **效果**：持握這顆法球期間，你可以使用一個**魔法**動作 來確認現在是上午、下午、傍晚還是夜晚。這項屬性僅在物質位面中有效。
