# 爆裂頭飾 (Circlet of Blasting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：佩戴頭飾期間。
  - **效果**：你可以用頭飾施展[[法術/2環/灼熱射線|灼熱射線 (Scorching Ray)]]，法術攻擊命中加值為 +5。
  - **限制與恢復**：使用後，頭飾直到下一個黎明前都不能再次施展此法術。
