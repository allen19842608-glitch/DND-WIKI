# 巨人之力腰帶 (Belt of Giant Strength)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **巨人之力**：
  - **啟用／觸發**：穿戴期間。
  - **效果**：你的力量值變為腰帶賦予的數值。若你未穿戴腰帶時的力量值已大於或等於該數值，此物品不生效。

### 稀有度與力量

| 腰帶類型 | 力量 | 稀有度 |
| :--- | :--- | :--- |
| 山丘巨人 | 21 | 珍稀 |
| 霜巨人或石巨人 | 23 | 極珍稀 |
| 火巨人 | 25 | 極珍稀 |
| 雲巨人 | 27 | 傳說 |
| 風暴巨人 | 29 | 傳說 |
