# 魔術袋 (Bag of Tricks)

## 📖 物品描述

這種布袋有灰色、鐵鏽色與棕褐色三種版本。布袋看似空無一物，但把手伸入時會摸到小小的毛絨物件。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果


- **取出動物**：
  - **啟用／觸發**：使用一個**魔法**動作取出毛絨物件，並將其扔至多 20 呎遠。
  - **效果**：物件落地時，依布袋顏色對應的表格擲骰，決定其變成的生物；相關生物資料見《怪物圖鑑》。該生物在下個黎明或生命值降至 0 時消失。

- **命令生物**：
  - **效果**：扔出的生物對你和你的盟友態度**友好 Friendly**，且會在你的回合結束後行動。你能夠以一個**附贈動作**命令該生物在其下一回合執行特定的移動方式，做特定的動作，例如攻擊你的敵人。沒接到命令時，該生物按自己天性行動。

- **使用限制**：
  - **效果**：一旦袋子抽出三件毛絨物件後，直至下個黎明才可再次使用。
