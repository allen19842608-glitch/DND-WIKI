# 害獸帽 (Hat of Vermin)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：持握期間。
  - **效果**：這頂帽子有3 充能。持握此帽期間，你可以用一個**魔法**動作消耗1 充能，召喚你選擇的下述三種生物之一：一隻[[wiki/怪物/野獸/蝙蝠|蝙蝠 (Bat)]]、一隻青蛙（Frog）或一隻[[wiki/怪物/野獸/鼠|鼠 (Rat)]]。召喚出的生物魔法性地出現在帽子中，並且會試圖儘快遠離你。此生物對你和其他生物的態度是冷漠，且不在你的控制之下。它會如其種類的普通生物一般行動，且會在1小時或者生命值降至0點時消失。此帽在每日黎明時恢復所有已消耗的充能。
  - **限制與恢復**：它會如其種類的普通生物一般行動，且會在1小時或者生命值降至0點時消失。此帽在每日黎明時恢復所有已消耗的充能。
