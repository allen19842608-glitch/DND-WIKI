# 光彩奪目寶石 (Gem of Brightness)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **第一命令語**：
  - **效果**：**第一命令語 First Command Word**。寶石發出亮光，提供30 呎的明亮光照和其外30 呎的微光光照。該效應不會消耗充能。此效應將持續到你用一個**附贈動作**再次說出該命令語，或你使用寶石的另一能力為止。

- **第二命令語**：
  - **效果**：**第二命令語 Second Command Word**。你消耗1發充能，令寶石向60 呎內你能看見的一個生物發出一道耀眼的光束。該生物必須成功通過一次 DC 15的體質豁免否則陷入**目盲**狀態1分鐘。該生物在其每個回合結束時可以重複此豁免，豁免成功則結束其身上的此效應。

- **第三命令語**：
  - **效果**：**第三命令語 Third Command Word**。你消耗5發充能，令寶石以自身為原點對30 呎錐狀區域放出刺眼的光芒。區域內的每個生物必須進行豁免，如同它們被以第二命令語創造的射線擊中一般。

- **充能效果**：
  - **效果**：耗盡充能後，此寶石變為價值50gp 的非魔法寶石。
