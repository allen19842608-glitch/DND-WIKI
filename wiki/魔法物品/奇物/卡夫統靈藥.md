# 卡夫統靈藥 (Keoghtom's Ointment)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **生命恢復**：
  - **效果**：以一個**操作**動作，你可以自己吞下一劑軟膏，或將一劑軟膏塗在你5 呎內的一個生物身上。軟膏將為受用者恢復2d8+2點生命值，並解除其中毒狀態。
