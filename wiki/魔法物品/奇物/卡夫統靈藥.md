# 卡夫統靈藥 (Keoghtom's Ointment)
## 📖 物品描述

直徑 1/4 呎的玻璃瓶內有 1d4＋1 劑略帶蘆薈氣味的軟膏；瓶子與內容物共重 1/2 磅。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；每次使用消耗一劑 |

### 物品效果

- **生命恢復**：
  - **啟用／觸發**：以**使用物件**動作吞下一劑軟膏，或將一劑塗在你 5 呎內的一名生物身上。
  - **效果**：受用生物恢復 2d8＋2 點生命值，並解除其中毒狀態。
  - **限制與恢復**：每次消耗一劑；一瓶共有 1d4＋1 劑。
