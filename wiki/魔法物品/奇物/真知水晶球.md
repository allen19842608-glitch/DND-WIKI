# 真知水晶球 (Crystal Ball of True Seeing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |
| 重量 (Weight) | 3 磅 |

### 物品效果

- **施展探知術**：
  - **啟用／觸發**：接觸水晶球期間。
  - **效果**：你可以透過它施展[[法術/5環/探知術|探知術 (Scrying)]]，法術豁免 DC 為 17。

- **真實視覺**：
  - **啟用／觸發**：你正以此水晶球施展探知術時。
  - **效果**：你獲得以該法術傳感器為中心、半徑 120 呎的真實視覺。
