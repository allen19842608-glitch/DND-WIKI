# 辟矢奪箭手套 (Gloves of Missile Snaring)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **偏轉飛射物**：
  - **效果**：在你穿戴該手套期間被遠程或投擲武器造成的攻擊檢定命中時，若你至少空著一隻手，則你可以用**反應**來減少1d10+你的敏捷調整值的傷害。如果你把傷害減少到0，則你可以選擇抓住擊中你的拋擲物（前提是它的尺寸足夠讓你用手抓住）。
