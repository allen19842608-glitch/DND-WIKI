# 塞爾法術刺青 (Thayan Spell Tattoo)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **準備法術**：
  - **啟用／觸發**：刺青紋在你身上且與之同調期間。
  - **效果**：刺青蘊含創造者選定的一道 1 至 3 環法術；你始終準備該法術，並可用適當環階法術位施展它。若有施法或契約魔法特性，使用自身施法屬性；否則，需要豁免或攻擊檢定時，法術豁免 DC 為 13、攻擊加值為 +5。
- **無消耗施法**：
  - **啟用／觸發**：你施展刺青中的法術時。
  - **效果**：可不消耗法術位或法術成分施展一次該法術。
  - **限制與恢復**：以此方式施展後，刺青消失；結束同調時也會消失。

### 使用、充能與恢復

- **啟用方式**：刺青紋於身上並完成同調。
- **充能／使用次數**：無消耗施法僅能使用 1 次。

### 製作限制

塞爾法術刺青不能依一般魔法物品製作規則製作。要學習繪製，必須在紅袍巫師中擁有 50 聲望、具有奧秘技能與書法工具熟練，且在每日抄錄期間始終準備對應法術；時間與金錢等同抄錄相同環階的法術卷軸，並提供且消耗該法術所需的材料成分。
