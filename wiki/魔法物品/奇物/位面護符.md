# 位面護符 (Amulet of the planes)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **位面移動**：
  - **啟用／觸發**：佩戴此護符期間，以一個**魔法**動作指名另一存在位面中你熟悉的地點。
  - **效果**：進行一次 DC 15 的智力（奧秘）檢定。成功時，你施展[[法術/7環/位面轉移|位面轉移 (Plane Shift)]]；失敗時，你與你周圍 15 呎內的每個生物和物件被傳送至擲 1d100 並查下表決定的隨機目的地。
### 隨機表

| **d100** | **目的地** |
| --- | --- |
| 01-60 | 與你指名地點同一位面的隨機地點。 |
| 61-70 | 投擲1d6決定某內層位面中的隨機地點：1氣之位面；2土之位面；3火之位面；4水之位面；5妖精荒野；6墮影冥界。 |
| 71-80 | 投擲1d8決定某外層位面中的隨機地點：1奔放之野；2世外桃源；3萬獸鄉；4雙生天堂；5極樂境；6機械境；7天堂山；8伊斯加德。 |
| 81-90 | 投擲1d8決定某外層位面中的隨機地點：1無底深淵；2修羅場；3卡瑟利；4焦炎火獄；5哈迪斯；6混沌海；7九層地獄；8喧癲空隧。 |
| 91-00 | 星界位面中的隨機地點。 |
