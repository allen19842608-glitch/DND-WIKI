# 健康護符 (Amulet of Health)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |

| 消耗品 (Consumable) | 否 |

### 物品效果

- **體質設定**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴此護符期間，你的體質變為19。如果你的體質在未佩戴護符時已經大於或等於19，則護符不會起效。
