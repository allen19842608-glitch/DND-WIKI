# 短訊石 (Sending Stones)

## 📖 物品描述

短訊石兩顆一對，彼此經雕刻而相互匹配，配對關係很容易辨認。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：觸摸其中一顆短訊石時；每對石頭每個黎明一次。
  - **效果**：你從此石施展*短訊術 Sending*，目標為另一顆石頭的攜帶者。若另一顆石頭未被生物攜帶，你得知此事，且短訊術不會被施展。
  - **限制與恢復**：任一顆石頭施展短訊術後，兩顆石頭皆在下個黎明前無法再次使用。若其中一顆被摧毀，另一顆失去魔法。
