# 啟蒙花盆 (Pot of Awakening)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **啟蒙灌木**：
  - **啟用／觸發**：在花盆中種植一株普通灌木並使其生長 30 日。
  - **效果**：灌木以魔法轉化為一株啟蒙灌木（Awakened Shrub）；其根系會打碎並摧毀花盆。啟蒙灌木對你友好並服從你的命令；沒有命令時不會採取行動。
