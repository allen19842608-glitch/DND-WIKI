# 微視鏡片 (Eyes of Minute Seeing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **黑暗視覺**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：這副水晶鏡片適合戴在眼前。佩戴著這副鏡片期間，你觀察周邊1 呎距離內的事物時的視力顯著提高，這將給予你此範圍內的黑暗視覺，並使你為檢視某物而進行的智力（調查）檢定具有優勢。
