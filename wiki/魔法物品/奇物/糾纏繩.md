# 糾纏繩 (Rope of Entanglement)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 來源未註明；生命值降至 0 時會被摧毀 |

### 物品效果

- **纏住生物**：
  - **啟用／觸發**：持握這根 30 呎長繩索的一端時，以魔法動作命令另一端纏住你能看見且距離你 20 呎內的一名生物。
  - **效果**：目標須通過 DC 15 敏捷豁免，否則陷入[[規則/狀態/束縛|束縛]]狀態。你可鬆開手中的繩端，使繩索盤繞並落在目標的空間，或以附贈動作再次命令繩索，使它盤繞並回到你手中；兩種方式都會釋放目標。
  - **限制與恢復**：受繩索束縛的目標可用動作進行 DC 15 力量（運動）或敏捷（特技）檢定，成功則解除此束縛。若目標逃脫時你仍持握繩索，可用反應命令它盤繞並回到手中；否則繩索盤繞並落在目標的空間。

- **繩索耐久**：
  - **效果**：繩索 AC 20、生命值 20，免疫毒素及心靈傷害。只要尚有至少 1 點生命值，每 5 分鐘恢復 1 點生命值；生命值降至 0 時被摧毀。
