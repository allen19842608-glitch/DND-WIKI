# 加速馬蹄鐵 (Horseshoes of Speed)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **附著與移除馬蹄鐵**：
  - **啟用／觸發**：以一個**魔法**動作將其中一個馬蹄鐵接觸馬或類似生物的蹄子；移除一個馬蹄鐵也需要一個**魔法**動作。
  - **效果**：馬蹄鐵四個為一套；接觸蹄子後，該馬蹄鐵便附著在蹄子上。

- **速度調整**：
  - **效果**：當四個馬蹄鐵都附著在同一生物身上期間，其速度增加 30 呎。
