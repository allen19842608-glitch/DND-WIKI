# 次元袋 (Bag of Holding)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **位面移動**：
  - **效果**：如果次元袋超載，或是袋子被戳破、撕裂，它將因此被摧毀，它所裝載的東西將散落到星界位面各處。如果袋子被內外翻轉，則它所裝載的東西將完好無損地掉落出來，但再次使用袋子之前必須將它恢復原狀。次元袋內所容納的空氣量可供其內生物呼吸的分鐘數為10除以袋內正在呼吸的生物數量，此後袋內的生物便開始窒息。

- **把次元袋放入霍華德便利袋**：
  - **效果**：把次元袋放入_霍華德便利袋 Heward's handy haversack_ 、_次元洞 portable hole_ 或其他類似物品內時，將會立即同時摧毀兩件物品並打開一扇通往星界位面的傳送門扉。門扉產生於放入另一物品的第一件物品的所在地。任何在門扉周邊10 呎球狀區域內的生物將被吸入門內，並送往星界位面中的隨機地點。然後門扉即時關閉，門的通道是單向的且無法被再次打開。
