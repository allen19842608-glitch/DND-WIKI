# 萬溶劑 (Universal Solvent)

## 📖 物品描述

這管乳白色液體散發濃烈酒精氣味；被發現時，管中裝有 1d6 + 1 盎司萬溶劑。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **溶解黏著劑**：
  - **啟用／觸發**：使用一個**操作**動作，將 1 盎司或更多液體倒在觸及內的表面上。
  - **效果**：每盎司萬溶劑立刻溶解其接觸到、至多 1 立方呎的黏著劑，包括*至尊膠 Sovereign Glue*。
