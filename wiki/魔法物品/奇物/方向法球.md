# 方向法球 (Orb of Direction)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **辨識北方**：
  - **啟用／觸發**：持握期間。
  - **效果**：持握這顆法球期間，你可以使用一個**魔法**動作 來確認地磁北方的方位。如果在一個沒有地磁北方的地方使用這顆法球，則不會發生任何事情。
