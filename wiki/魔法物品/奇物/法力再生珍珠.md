# 法力再生珍珠 (Pearl of Power)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **恢復法術位**：
  - **啟用／觸發**：隨身攜帶期間，以一個**魔法**動作啟用。
  - **效果**：恢復一枚已消耗的 3 環或更低環階法術位。
  - **限制與恢復**：使用後，直到下個黎明才能再次使用。
