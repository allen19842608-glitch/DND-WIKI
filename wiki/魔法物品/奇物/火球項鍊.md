## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **強化火球**：
  - **效果**：你可以同時把多枚珠子，甚至把整條項鍊一起投擲出去。這麼做時，每有一顆額外投擲出的珠子，火球術的傷害就增加1d6點（最大12d6）。
