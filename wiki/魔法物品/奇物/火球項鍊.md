# 火球項鍊 (Necklace of Fireballs)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；使用時投擲珠子，珠子於落點引爆 |

### 物品效果

- **投擲火球珠**：
  - **啟用／觸發**：以一個**魔法**動作從項鍊取下一顆珠子，將它投擲至最遠 60 呎處。
  - **效果**：項鍊共有 1d6＋3 顆珠子。珠子在投擲路徑末端引爆，效果等同三環[[法術/3環/火球術|火球術 (Fireball)]]（豁免 DC 15）。

- **同時投擲多顆珠子**：
  - **效果**：你可以一次投擲多顆珠子，甚至整條項鍊；第一顆以外，每多投擲一顆，火球術傷害增加 1d6，最高為 12d6。
