# 跳跑之靴 (Boots of Striding and Springing)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **變形**：
  - **效果**：著裝這雙靴子期間，你的速度變為30 呎，除非你原本的速度更快。且你的速度不會因為攜帶物品超重或者著裝重甲而降低。

- **強化跳躍**：
  - **效果**：你的每個回合限一次，你可以只消耗10 呎移動力來跳躍至多30 呎。
