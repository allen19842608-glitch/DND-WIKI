# 老兵手杖 (Veteran's Cane)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **變形**：
  - **效果**：你能夠以一個**附贈動作**將這根手杖變為一把普普通通的長劍，或者將長劍變回手杖。你必須持握該物品才能完成以上兩種變形。
