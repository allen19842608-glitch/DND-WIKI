# 無蹤粉 (Dust of Disappearance)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；粉末發揮魔法時消耗 |

### 物品效果

- **散布無蹤粉**：
  - **啟用／觸發**：以**使用物件**動作把粉末灑向空中。
  - **效果**：你與源自你的 10 呎光環內每個生物及物件都變為**隱形**狀態，持續 2d4 分鐘；各目標的持續時間相同。
  - **限制與恢復**：這份細沙狀粉末只夠使用一次，其魔法生效時即被消耗。受影響生物進行攻擊檢定、造成傷害或施展法術後，隱形狀態立即對該生物終止。

### 來源文字差異

中文來源 L102 只列發動攻擊或施展法術會終止隱形；同版英文原文 `/item/643` 列出攻擊檢定、造成傷害或施法後立即終止。依英文原文，規則採三種觸發條件。
