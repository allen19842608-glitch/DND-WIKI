# 無蹤粉 (Dust of Disappearance)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **效果**：這些粉末形同細沙，其分量足夠使用一次。你可以用**操作**動作將粉末灑向空中，讓你和源自你的10 呎光環區域內的每個生物和物件變為**隱形**狀態2d4分鐘。每個目標的隱形時長相同，一旦粉末的魔法生效，其即被消耗。如果一名受影響的生物發動攻擊或者施展法術，則該生物的**隱形**效應也隨之終止。
