# 食人魔力量護手 (Gauntlets of Ogre Power)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **力量設定**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：戴著這雙護手期間，你的力量值變為19。如果未著裝該護手時你的力量值已經大於或等於19，則該護手無效。
