# 黑暗碎片護符 (Dark Shard Amulet)

## 📖 物品描述

這個護符由來自異界的彈性材料碎片製成。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要；契術師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

> **共同適用條件**：佩戴護符期間。

- **施法法器 (Spellcasting Focus)**：你可以將護符作為施展魔契師法術的施法法器。
- **未知法術 (Unknown Spell)**：
  - **啟用／觸發**：以一個魔法動作，選擇一道你未知、列於魔契師法術列表且施法時間為一個動作的戲法。
  - **效果**：進行 DC 10 智力（奧秘）檢定；成功便施展該戲法，失敗則施法失敗且此動作被浪費。
  - **限制與恢復**：不論檢定成敗，直到完成一次長休前都不能再次使用此屬性。
