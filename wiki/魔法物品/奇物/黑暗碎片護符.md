# 黑暗碎片護符 (Dark Shard Amulet)

## 📖 物品描述

這個護符由來自異界的彈性材料碎片製成。
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護符增益**：
  - **啟用／觸發**：佩戴期間。
  - **效果**：佩戴此護符期間，你獲得以下增益。

- **施法**：
  - **效果**：**施法 Spellcasting Focus** 。你可以把護符當作你施展魔契師法術時的法器使用。

- **未知法術**：
  - **效果**：**未知法術 Uknown Spell** 。作為一個**魔法**動作 ，你可以嘗試施展一道你未知的戲法。該戲法必須在魔契師法術列表之內且施法時間為1動作。隨後你進行一次 DC 10的智力（奧秘）檢定，檢定通過則你施展該法術，檢定失敗則法術失效，且你施法所用的動作將被浪費。無論發生哪種情況，那之後直至你完成長休前都無法再次使用該詞條。
  - **限制與恢復**：無論發生哪種情況，那之後直至你完成長休前都無法再次使用該詞條。
