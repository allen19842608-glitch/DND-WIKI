# 造風之扇 (Wind Fan)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **造風術**：
  - **效果**：持握這把扇子時，你可以用它施展_造風術 Gust of Wind_ （豁免 DC 13）。在下個黎明之前，隨後每再次使用這把扇子都會累積20%的幾率失效；如果扇子失效，則其會被撕裂成無用的非魔法碎紙。
