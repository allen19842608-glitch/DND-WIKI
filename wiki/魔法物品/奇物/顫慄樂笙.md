# 顫慄樂笙 (Pipes of Haunting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：使用時。
  - **效果**：顫慄樂笙具有3 充能，並在每日黎明時重獲1d3已消耗的充能。你可以使用一個**魔法**動作演奏該樂笙，並消耗其1 充能來創作一首怪誕且令人著迷的曲調。你周邊30 呎範圍內每個你選擇的生物都必須成功通過一次 DC 15的感知豁免，豁免失敗者會陷入**恐慌**狀態，持續1分鐘。豁免失敗的生物可以在其每個回合結束時重複該豁免，豁免成功則結束對自身的影響。豁免成功的生物將在24小時內免疫該樂笙的效應。
  - **限制與恢復**：顫慄樂笙具有3 充能，並在每日黎明時重獲1d3已消耗的充能。你周邊30 呎範圍內每個你選擇的生物都必須成功通過一次 DC 15的感知豁免，豁免失敗者會陷入**恐慌**狀態，持續1分鐘。
