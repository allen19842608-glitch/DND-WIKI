# 戰法紅石 (Ruby of the War Mage)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **武器法器**：
  - **啟用／觸發**：將紅寶石按壓在一把簡易或軍用武器上至少 10 分鐘。
  - **效果**：附著紅寶石的武器可作為你施展法術的法器。
  - **限制與恢復**：紅寶石會保持附著，直到你以一個**魔法**動作將其取下、武器被摧毀，或你與紅寶石的同調結束。
