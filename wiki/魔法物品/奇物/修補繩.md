# 修補繩 (Rope of Mending)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **重新接合**：
  - **啟用／觸發**：以一個**魔法**動作啟用。
  - **效果**：讓所有彼此接觸且未被使用的繩段重新接合。這根長 50 呎的繩索被切成任意數量小段後可自行修復。
  - **限制與恢復**：若任一繩段遺失或被摧毀，繩索的長度永久縮短。
