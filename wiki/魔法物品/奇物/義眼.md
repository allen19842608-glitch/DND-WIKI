# 義眼 (Ersatz Eye)

## 📖 物品描述

這隻魔法義眼可替代失去或被移除的真眼。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **安裝與移除**：
  - **啟用／觸發**：使用一個**魔法**動作植入或移除該義眼。
  - **效果**：義眼植入眼窩期間，你可以透過這顆微型小球視物，如同使用天生眼睛。
  - **限制**：在你活著的時候，義眼無法違背你的意願被移除。
