# 鐵騎馬鞍 (Saddle of the Cavalier)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **持用增益**：
  - **效果**：在你騎乘配有這副鞍座的坐騎，並跨坐於此鞍座上期間，此鞍座會提供以下增益：

- **坐騎保護**：
  - **效果**：**坐騎保護 Protected Mount** 。對坐騎進行的攻擊檢定具有劣勢。

- **穩固騎手**：
  - **效果**：**穩固騎手 Secure Rider**。你不會在非自願的情況下解除騎乘。此詞條在你處於失能狀態期間失效。
