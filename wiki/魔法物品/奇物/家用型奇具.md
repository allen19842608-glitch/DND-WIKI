# 家用型奇具 (Domestic Wonder)

## 物品描述

這具雙足奇具是用於協助日常家務的半自動物件，其外形模仿創造者選定的某個種族。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **家務盟友**：
  - **啟用／觸發**：奇具被啟動期間。
  - **效果**：使用[[怪物/構裝/家用型奇具|家用型奇具 (Domestic Wonder)]]數據卡。它是你與盟友的盟友；使用你的先攻、在你回合結束後立刻行動，並遵從你的口頭指令（無需動作）。未獲指令時，它執行迴避動作並移向遠離危險的位置；HP 降至 0 時被摧毀。

### 使用、充能與恢復

- **啟用方式**：另一名生物使用專用鑰匙為其上發條，需花費 1 分鐘。
- **充能／使用次數**：上發條後運作 10 天；持鑰匙的生物可用操作動作觸碰它以停用。
