# 讀心勳章 (Medallion of Thoughts)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：佩戴期間，消耗 1 充能。
  - **效果**：你可以從勳章施展法術*偵測思想 Detect Thoughts*（豁免 DC 13）。

### 使用、充能與恢復

- **充能／使用次數**：5 充能；每次施展消耗 1 充能。
- **恢復**：每日黎明時重獲 1d4 已消耗的充能。
