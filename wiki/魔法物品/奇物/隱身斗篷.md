# 隱身斗篷 (Cloak of Invisibility)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **隱形**：
  - **啟用／觸發**：著裝並同調期間；拉上兜帽、消耗 1 充能並使用一個**魔法**動作。
  - **效果**：此斗篷具有 3 充能。你進入**隱形 Invisible**狀態，持續 1 小時。
  - **限制與恢復**：斗篷在每日黎明重獲 1d3 點已消耗的充能。你褪下兜帽（無須動作）或不再著裝斗篷時，隱形提前結束。
