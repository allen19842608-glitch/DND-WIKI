# 巫術帽 (Hat of Wizardry)
## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **持用增益**：
  - **效果**：這頂錐形帽上點綴著星月。你著裝此帽期間，你獲得下述增益。

- **施法**：
  - **效果**：**施法 Spellcasting Focus**。你可以將其作為你施展法師法術的施法法器。

- **未知法術**：
  - **效果**：**未知法術 Unknown Spell**。你可以用一個**魔法**動作嘗試施展一道你並未已知的戲法。所選戲法必須位於法師法表中，並且其施法時間必須為動作。你進行一次 DC 10的智力（奧秘）檢定。檢定成功，則你施展那道法術。檢定失敗，則你施法失敗，用於施法的動作被浪費。無論檢定成功與否，此詞條一經使用，直到你完成一次長休之前不能再次使用。
  - **限制與恢復**：無論檢定成功與否，此詞條一經使用，直到你完成一次長休之前不能再次使用。
