# 萬法無常帽 (Hat of Many Spells)
## 物品描述

這頂尖頂帽具有尖頂外形。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |

| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要（法師） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施法法器**：
  - **啟用／觸發**：持握並同調期間；以此帽施展法師法術時。
  - **效果**：你可以將此帽作為施展法師法術的施法法器。任何透過此帽施展的法術均具有特殊的姿勢成分：你必須將手伸入帽中，將法術從中「拽」出來。

- **嘗試未知法術**：
  - **啟用／觸發**：持握並同調期間；選擇施展一道你尚未知曉的一環或更高環法術時。
  - **效果**：所選法術必須位於法師法表中，其環階必須是你能施展的環階，且材料成分不得超過 1,000 GP。你必須消耗一個對應環階的法術位，然後進行智力（奧秘）檢定（DC＝10＋法術環階）。成功時，你以該法術的正常施法時間施展它；失敗時，該法術施展失敗，並在下表擲骰決定隨機效應。你透過此帽施展的所有法術均使用自己的法術豁免 DC 與法術攻擊加值。
  - **限制與恢復**：檢定成功後，直到完成一次短休或長休前，你無法再次使用此詞條。
