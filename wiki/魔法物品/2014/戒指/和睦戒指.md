# 和睦戒指 (Ring of Amity，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 戒指 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這枚用赤鐵礦雕刻而成的戒指，其戒面上刻印著友誼符文。 當你首次同調這枚戒指時，你可以觸碰一個自願生物，在你與它之間塑造一條魔法聯結。聯結存在期間，每當你受益於恢復生命值的法術或魔法效應時，受聯結的生物也將獲得那個法術或魔法效應相同的好處。 你可以在長休結束時觸碰另一名自願生物，以此聯結一名新的生物。 一個生物同一時間只能受益於一枚 **和睦戒指 Ring of Amity** 的聯結，而已有的聯結也會在生物離開當前位面、你在長休結束時與另一生物進行聯結、或你以一個附贈動作主動結束聯結時結束。
- **激活符文 Invoking the Rune**：當另一聯結生物以一次攻擊檢定擊中了一個目標時，如果你此時與聯結生物之間的距離不超過60 呎，你就可以用你的反應去激活戒指上的符文，使聯結生物的那次攻擊形成一次重擊。 此符文被激活後，直到下個黎明為止都無法被再度激活。
