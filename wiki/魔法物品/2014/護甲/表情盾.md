# 表情盾 (Shield of Expression，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲（盾牌） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **表情盾**：
  - **效果**：這面盾牌的正面被塑成了一張臉的模樣。持握這面盾牌期間，你可以用一個附贈動作改變盾牌上的這張臉的表情。
