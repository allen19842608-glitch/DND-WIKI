# 西風護甲 (Zephyr Armor，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **_護甲（輕甲），珍稀（需同調）_**：這套完整的白色與銀色相間的護甲，其胸甲上承載著疾風符文。 穿著此護甲期間，柔和的風會強化你的行動能力。你進行的敏捷（特技）檢定與任何敏捷豁免具有優勢。
- **激活符文 Invoking the Rune**：以一個動作，你可以激活護甲上的符文以用其施展法術 _風牆術 wind wall_ （豁免 DC15）。此符文被激活後，直到下個黎明為止都無法被再度激活。
