# 安防護甲 (Armor of Safeguarding，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 護甲 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：鑲嵌在這套護甲正中央的，是一顆刻印著盾牌符文的黃水晶。 穿著這套護甲期間，你的生命值上限獲得提升，其數額等同於 10+你的等級 點。
- **激活符文 Invoking the Rune**：以一個動作，你可以激活護甲上的符文以用其施展法術 _希望信標 beacon of hope_ ；此法術不需要專注，且其持續時間改為1 分鐘。此符文被激活後，直到下個黎明為止都無法被再度激活。
