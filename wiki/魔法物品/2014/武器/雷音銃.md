# 雷音銃 (Thunderbuss，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（手銃） |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法手銃**：
  - **效果**：這把喇叭形手銃的槍管刻有風暴符文。以此武器進行的攻擊檢定與傷害擲骰獲得 +1 加值；它不需彈藥、沒有裝填屬性，造成雷鳴傷害而非穿刺傷害。
- **激活符文 (Invoking the Rune)**：
  - **啟用／觸發**：以附贈動作，向自身 30 呎內一處可見地點發射能量彈。
  - **效果**：能量彈在該點爆發；以該點為中心、半徑 10 呎球狀區域內的每個生物須進行 DC 14 體質豁免。失敗時受到 3d6 雷鳴傷害，且直到你的下回合結束前無法執行反應；成功時只受到一半傷害。
  - **限制與恢復**：符文激活後，直到下個黎明前不能再次激活。
