# 雷音銃 (Thunderbuss，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

| :--- | :--- |

| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這把魔法遠程武器是一中喇叭形的手銃，它的槍管上雕刻著風暴符文。你使用這把武器發起的攻擊檢定與其傷害擲骰具有+1加值。它不需要彈藥，也沒有 裝填 Loading 屬性，其傷害類型也是雷鳴而非穿刺。
- **激活符文 Invoking the Rune**：以一個附贈動作，你可以激活這把武器的符文以向著你周圍30 呎範圍內的一個你可見的點，發射一枚能量彈。能量彈將在那點爆發出湍流颶風與雷鳴電閃。以該點為中心10 呎半徑球狀區域內的每個生物都必須通過一次 DC14的體質豁免。豁免失敗時，生物將受到3d6點雷鳴傷害，且直到你的下個回合結束前無法執行反應。豁免成功時只受半數的傷害。此符文被激活後，直到下個黎明為止都無法被再度激活。
