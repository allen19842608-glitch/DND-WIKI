# 耀閃滅擊銃 (Lucent Destroyer，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這把魔法武器是一根三管青銅火銃。你使用它發動的攻擊檢定與其傷害擲骰具有+1加值。它不需要彈藥，也沒有 裝填 Loading 屬性，其傷害類型也是光耀而非穿刺。這把槍的槍托上有印著光明符文的紋章裝飾。 此外，與這把槍同調期間，你可以隨意用這把槍施展戲法 _舞光術 dancing lights_ 。
- **激活符文 Invoking the Rune**：以一個動作，你可以激活武器上的符文以用其施展法術 _陽炎射線 sunbeam_ （豁免 DC17）。此符文被激活後，直到下個黎明為止都無法被再度激活。
