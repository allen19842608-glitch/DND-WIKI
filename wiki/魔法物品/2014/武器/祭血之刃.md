# 祭血之刃 (Bloodshed Blade，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這把劍的握柄上，鑲嵌著一枚刻印著鮮血符文的紅瑪瑙。 你可以將你的體質調整值（至少+1）加入到你用這把武器發動的攻擊的傷害擲骰中。
- **激活符文 Invoking the Rune**：當你用這把劍向一個生物發動攻擊時，你可以激活這把劍的符文，使它散發出緋紅色的光芒，併為你渴望鮮血的刀刃中注入致命的精準。你可以消耗並投擲一枚你未消耗的生命骰，並將其骰出數值加入到你的攻擊檢定中。你可以在投擲 d20後再選擇是否激活這一符文。 如果那次攻擊成功命中，你還可以消耗並投擲任意數量的你未消耗的生命骰，並將他們的投擲結果合起來，加入到武器的傷害中。 此符文被激活後，直到下個黎明為止都無法被再度激活。
