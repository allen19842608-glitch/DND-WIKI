# 龍怒武器 (Dragon's Wrath Weapon，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這種武器裝飾有龍頭，爪子，翅膀，鱗片，或龍語文字。它進入巨龍寶庫後會吸收龍的吐息武器的能量，並用它的特性造成這種類型的傷害。 _**沉睡(非普通)。**_當你使用此武器進行攻擊檢定擲出20時，目標5英尺內每個你選擇的生物都受到和龍的吐息武器相同類型的5傷害。 _**激活(珍稀)。**_激活的武器具有沉睡狀態的特性。此外，你使用該武器的攻擊檢定和傷害擲骰獲得+1，每次攻擊命中時該武器造成與龍息武器相同類型的額外1d6傷害。 _**覺醒(極珍稀)。**_覺醒的武器具有沉睡狀態的特性，並且在覺醒狀態的特性上有所提升。攻擊檢定和傷害擲骰的加值增加到+2，武器造成的額外傷害增加到2d6。 以一個動作，你可以從武器中釋放出 30 呎錐形的毀滅性能量。該區域內的每個生物必須進行一次 DC 16的敏捷豁免，豁免失敗時受到龍息武器造成的8d6傷害，豁免成功時受到的傷害減半。一旦這個動作被使用，直到下一個黎明前它不能再次使用。 _**神化(傳奇)。**_神化的武器擁有沉睡狀態的特性，並在激活和覺醒狀態的特性上有所提升。攻擊檢定和傷害擲骰的加值增加到+3，武器造成的額外傷害增加到3d6。武器的錐形毀滅性能量增加到60 呎，豁免 DC 增加到18。傷害增加到12d6。
