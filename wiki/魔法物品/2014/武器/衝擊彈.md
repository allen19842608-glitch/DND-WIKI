# 衝擊彈 (Walloping Ammunition，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（任意彈藥） |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **衝擊彈**：
  - **效果**：這枚彈藥中被包入了一陣衝擊。任何被這發彈藥擊中的生物都必須透過一次 DC10的力量豁免，若豁免失敗將會應擊倒地。
