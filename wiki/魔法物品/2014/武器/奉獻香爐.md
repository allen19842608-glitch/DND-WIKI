# 奉獻香爐 (Devotee's Censer，2014 Legacy)

| :--- | :--- |

| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：這把鏈枷的圓形頭部開有一些小孔，成徽記或圖紋狀排列。你可以將這把鏈枷視為聖徽。當你使用這把鏈枷進行攻擊命中時，目標受到額外1d8光耀傷害。 作為一個附贈動作，你可以說出命令語並使鏈枷散發出半徑10 呎的微弱薰香雲，持續1 分鐘。在你的每個回合開始時，你和其他在薰香中的生物恢復1d4生命值。直到下次黎明前，此屬性都不能再使用。
