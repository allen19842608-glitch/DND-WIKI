# 安南之錛 (Adze of Annam，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這把沉重的扁斧傳說是由 萬物之父安南 All-Father Annam 揮舞的一件神兵，萬古以來，它不僅僅是武器，更是塑造萬千世界之物質位面的工具。
- **隨機屬性 Random Properties**：扁斧具有以下的隨機屬性，你需要根據《城主指南》所記述的相關表格進行擲骰來決定它們的具體內容： 2項弱效增益屬性 1項強效增益屬性 2項弱效減益屬性
- **魔化武器 Magic Weapon**：當一個生物與扁斧同調後，神器會魔法性的變化自己的尺寸使生物可以將其作為一把巨斧持用。扁斧是一把在攻擊檢定與其傷害擲骰上具有+3加值的魔法物品，且在擊中時會額外造成3d12點力場傷害。此外，它對物件和建築物造成的傷害翻倍。
- **神聖之鋤 Divine Mattock**：以一個動作，你可以呼喚萬物之父的神力以施展法術 _地動術 move earth_ 或 _鬼斧神工 fabricate_ 。此能力一旦被使用，直到下個黎明前都無法被再次使用。
