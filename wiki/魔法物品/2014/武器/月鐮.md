# 月鐮 (Moon Sickle，2014 Legacy)

## 📖 物品描述

這把銀刃鐮刀散發柔和的月光。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器（鐮刀） |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（德魯伊或遊俠） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **武器與法術加值**：持握這把魔法鐮刀時，以它進行的攻擊檢定與傷害擲骰，以及你的德魯伊或遊俠法術攻擊檢定與法術豁免 DC，均獲得對應變體的加值。
- **施法法器**：持握鐮刀時，你可以將它作為施展德魯伊或遊俠法術的施法法器。
- **治療增益**：持握鐮刀並施展一道恢復生命值的法術時，可以擲 1d4，將結果加至恢復的生命值。

### 加值變體

| 變體 | 稀有度 | 武器攻擊與傷害加值 | 德魯伊或遊俠法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: | :---: |
| +1 月鐮 | 非普通 | +1 | +1 |
| +2 月鐮 | 珍稀 | +2 | +2 |
| +3 月鐮 | 極珍稀 | +3 | +3 |
