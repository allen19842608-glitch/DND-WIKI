# 水晶刀鋒 (Crystal Blade，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 武器 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這把劍的劍刃由一隻水晶龍的角或者脊骨製成。當你用這把劍進行的攻擊檢定命中時，目標受到額外 1d8光耀傷害。 這把劍有 3發充能，並在每日黎明時恢復1d3發充能。當你用這把劍擊中一個生物時，你可以消耗1發充能恢復自己等同於這把劍造成的額外光耀傷害數值的 HP。 當你握著這把劍的時候，你可以用一個附贈動作使其發出 30 呎明亮光照和30 呎微弱光照，發出10 呎微弱光照，或者熄滅光照。
