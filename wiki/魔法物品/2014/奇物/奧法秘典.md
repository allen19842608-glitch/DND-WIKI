# 奧法秘典 (Arcane Grimoire，2014 Legacy)

## 📖 物品描述

這是一本皮革封面的書。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（法師） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **法師施法法器與加值**：持握此書時，你可以將它作為施展法師法術的施法法器；你的法師法術攻擊檢定與法術豁免 DC 獲得對應變體的加值。
- **法術書**：你可以將這本書當作法術書使用。
- **奧術回想增益**：使用奧術回想特性時，你可恢復的法術位環階總和增加 1。

### 加值變體

| 變體 | 稀有度 | 法師法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: |
| +1 奧法秘典 | 非普通 | +1 |
| +2 奧法秘典 | 珍稀 | +2 |
| +3 奧法秘典 | 極珍稀 | +3 |
