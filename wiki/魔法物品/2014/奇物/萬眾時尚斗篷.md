# 萬眾時尚斗篷 (Cloak of Many Fashions，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **萬眾時尚斗篷**：
  - **效果**：只要穿著這件斗篷，你就可以用一個附贈動作改變它的樣式、顏色、及外表品質。這件斗篷的重量不會因此改變，且不論它的外觀如何，這件斗篷永遠只能是一件斗篷而不是別的東西。當然，這件斗篷可以用於複製其他魔法斗篷的外觀，但它不會因此具有任何其他魔法斗篷的魔法能力。
