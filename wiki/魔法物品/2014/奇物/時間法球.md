# 時間法球 (Orb of Time，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **時間法球**：
  - **效果**：只要你持握著這顆法球，你就可以用一個動作得知外面的時間是早上、中午、傍晚、還是夜晚。不過這一能力只在物質位面中有效。
