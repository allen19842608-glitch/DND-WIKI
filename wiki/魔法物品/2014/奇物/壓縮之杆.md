# 壓縮之杆 (Pole of Collapsing，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **壓縮之杆**：
  - **效果**：持握這根10 呎長杆期間，你可以用一個動作念出它的命令詞使其壓縮為一根便於儲藏的1 呎魔棒。你可以用一個動作念出另一段不同的命令語使這根魔棒展開變回長杆——不過魔棒最多隻能展開到其周遭空間允許的大小。
