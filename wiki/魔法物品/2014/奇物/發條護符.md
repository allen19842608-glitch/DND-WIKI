# 發條護符 (Clockwork Amulet，2014 Legacy)

| :--- | :--- |

| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **發條護符**：
  - **效果**：這枚銅製的護符內有數個互相咬合的微小齒輪，其以機械境——一個秩序至極，萬物皆可被機械預測的位面——的魔法所驅動。把耳朵放在護符上的生物可以聽到護身符內的模糊的滴答聲與呼呼的噪音。佩戴著這個護身符期間，當你進行一次攻擊檢定時，你可以放棄擲骰並在 d20的骰值上取10。使用後，直到下一個黎明前此物品的此能力無法被再次使用。
