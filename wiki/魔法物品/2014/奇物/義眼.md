# 義眼 (Ersatz Eye，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **義眼**：
  - **效果**：這隻人造的眼球會替代你失去或被移除的一隻真眼。只要義眼仍植入在你的眼眶內，它便不能被除你以外的任何人移除。這隻小球將如同一隻正常的眼睛一般，允許你用其去視物。
