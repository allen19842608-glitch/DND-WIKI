# 建築里拉琴 (Lyre of Building，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：當持握這把里拉琴時，你可以用一個動作施展_修復術 Mending_。當一個距離你300 呎內的物件或建築受到傷害時，你也可以用一個反應彈奏這把里拉琴，使其免疫該此次傷害以及其他同型別傷害，直到你的下個回合開始。 此外，你可以用一個動作彈奏這把里拉琴，施展_鬼斧神工 Fabricate_、_地動術 Move Earth_、_穿牆術 Passwall_或_構裝召喚術 Summon Construct_（在本書出現），直到下次黎明前，該法術不能再以此法施展。
