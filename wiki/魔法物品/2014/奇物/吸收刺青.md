### 物品效果

- **主要魔法效果**：
  - **效果**：該魔法刺青用一根特殊的針製作，且其圖案特別突出了一種顏色。 **_刺青同調_**。同調此物品時，你需要將針持握，並抵在你想要讓刺 青出現 的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。 若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。 **_傷害抗性_** 。當刺青在你的皮膚上時，你擁有與刺青顏色相聯絡的一種傷害抗性，如下方表格所示。DM 可以自己選擇或隨機決定刺青顏色。 **_傷害吸收_**。當你受到與刺青所選傷害種類一致的傷害時，你可以用你的反應獲得對該次傷害的免疫，而後你回覆等同於你原先要受到傷害數值一半的生命值。使用後，直到下次黎明前，這個反應不能再次使用。 | **d10** | **傷害型別** | **顏色** | | --- | --- | --- | | **1** | 強酸 | 綠色 | | **2** | 寒冷 | 藍色 | | **3** | 火焰 | 紅色 | | **4** | 力場 | 白色 | | **5** | 閃電 | 黃色 | | **6** | 暗蝕 | 黑色 | | **7** | 毒素 | 紫羅蘭色 | | **8** | 心靈 | 銀色 | | **9** | 光耀 | 金色 | | **10** | 雷鳴 | 橙色 |
