# 吸收刺青 (Absorbing Tattoo，2014 Legacy)

### 物品效果

- **主要魔法效果**：
  - **效果**：刺青的同調、傷害抗性與傷害吸收效果如下。
    - **刺青同調**：同調時，持握刺青針並將其抵在你希望刺青出現的皮膚上；同調完成時，針頭化為墨水並成為刺青。若同調結束，刺青消失，針頭重新出現在你的位置。
    - **傷害抗性**：刺青在你皮膚上時，獲得與其顏色對應的一種傷害抗性。DM 可選擇或擲骰決定顏色與傷害類型。

    | d10 | 傷害類型 | 顏色 |
    | :---: | :--- | :--- |
    | 1 | 強酸 | 綠色 |
    | 2 | 寒冷 | 藍色 |
    | 3 | 火焰 | 紅色 |
    | 4 | 力場 | 白色 |
    | 5 | 閃電 | 黃色 |
    | 6 | 暗蝕 | 黑色 |
    | 7 | 毒素 | 紫羅蘭色 |
    | 8 | 心靈 | 銀色 |
    | 9 | 光耀 | 金色 |
    | 10 | 雷鳴 | 橙色 |

    - **傷害吸收**：受到與刺青所選傷害類型一致的傷害時，可用反應獲得該次傷害的免疫，並恢復等同於原本將受到之傷害一半的生命值。使用後，直到下次黎明前不能再次使用此反應。
