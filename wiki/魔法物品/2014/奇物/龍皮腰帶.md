# 龍皮腰帶 (Dragonhide Belt，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要；武僧 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這條精緻的腰帶用龍皮製成。裝備著它時你在氣的 DC 上獲得加值。加值由腰帶的稀有度決定。 除此之外，你可以用一個動作恢復氣，數值等同於一個你的武藝骰。直到下次黎明之前你不能再使用這個動作。
