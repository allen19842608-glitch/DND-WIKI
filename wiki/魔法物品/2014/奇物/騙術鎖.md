# 騙術鎖 (Lock of Trickery，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **騙術鎖**：
  - **效果**：這把鎖看上去就像是一把普通的鎖（同《玩家手冊》第五章描述的那樣），通常會配備有一把一對一的鑰匙。這把鎖裡的鎖齒會魔法性的拒斥那些撬鎖的竊賊。任何為撬開這把鎖所進行的敏捷檢定都將具有劣勢。
