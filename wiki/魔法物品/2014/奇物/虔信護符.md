# 虔信護符 (Amulet of the Devout，2014 Legacy)

## 📖 物品描述

護符上鑲有以珍稀石料或金屬製成的神祇聖徽。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（牧師或聖騎士） |
| 消耗品 (Consumable) | 否 |

### 物品效果

> **共同適用條件**：佩戴護符期間。

- **法術加值**：你的法術攻擊檢定與法術豁免 DC 獲得對應變體的加值。
- **引導神力**：可以使用一次你的引導神力特性，且不消耗該特性的使用次數。此屬性使用後，直到下次黎明前不能再次使用。

### 加值變體

| 變體 | 稀有度 | 法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: |
| +1 虔信護符 | 非普通 | +1 |
| +2 虔信護符 | 珍稀 | +2 |
| +3 虔信護符 | 極珍稀 | +3 |
