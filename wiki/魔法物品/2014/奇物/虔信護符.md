# 虔信護符 (Amulet of the Devout，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：這件護符載有一位神的聖徽，由珍稀石料或金屬雕刻。當佩戴這枚護符時，你在你法術的法術攻擊骰和法術豁免 DC 上獲得加值，加值取決於護符的稀有度。（原文沒有說是牧師/聖騎士法術限定，但我覺得是他漏了。） 當你穿戴這枚護符時，你可以使用一次你的引導神力特性而不消耗特性的使用次數。此屬性使用後，直到下次黎明前，不能再次使用。
