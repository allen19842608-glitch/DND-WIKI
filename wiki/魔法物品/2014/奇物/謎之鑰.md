# 謎之鑰 (Mystery Key，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **謎之鑰**：
  - **效果**：這把鑰匙的末端添有一個問號樣式的裝飾。這把鑰匙有5%的機率解開任何一個其插入的鎖。一旦這把鑰匙成功解鎖了什麼東西，它就會消失。
