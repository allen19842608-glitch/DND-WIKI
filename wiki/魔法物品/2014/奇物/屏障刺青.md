# 屏障刺青 (Barrier Tattoo，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：刺青的同調與防護效果如下。
    - **刺青同調**：同調時，持握刺青針並將其抵在你希望刺青出現的皮膚上；同調完成時，針頭化為墨水並成為刺青。若同調結束，刺青消失，針頭重新出現在你的位置。
    - **防護**：未著裝護甲時，依刺青的稀有度獲得下表 AC；即使裝備盾牌，仍可獲得此增益。

    | 稀有度 | AC |
    | :--- | :--- |
    | 非普通 | `12 + 敏捷調整值` |
    | 珍稀 | `15 + 敏捷調整值`（敏捷調整值最多 +2） |
    | 極珍稀 | 18 |
