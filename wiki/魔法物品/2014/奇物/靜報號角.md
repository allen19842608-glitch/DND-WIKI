# 靜報號角 (Horn of Silent Alarm，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **靜報號角**：
  - **效果**：這個號角具有4發充能。當你使用一個動作並消耗一發充能吹響它時，一個600 呎範圍內由你選擇的生物將能聽到其嘟嘟聲，前提是這個生物未處於耳聾狀態。而除此之外的任何其他生物都無法聽見這個號角的聲音。每日黎明時分，這個號角會恢復1d4發已消耗的充能。
