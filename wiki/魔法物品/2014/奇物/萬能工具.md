# 萬能工具 (All-Purpose Tool，2014 Legacy)

## 📖 物品描述

這件物品原本是一把簡單的螺絲刀。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（奇械師） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **變換工匠工具**：
  - **啟用／觸發**：以一個動作觸碰此物品。
  - **效果**：將它變為你選擇的任一種工匠工具；無論變為何種工具，你都具有該工具的熟練。
- **奇械師法術加值**：持握此工具時，你的奇械師法術攻擊檢定與法術豁免 DC 獲得對應變體的加值。
- **習得暫時戲法**：
  - **啟用／觸發**：以一個動作凝神於此工具，選擇任一職業法術列表中一道你未知的戲法。
  - **效果**：接下來 8 小時內，你可以施展該戲法；對你而言，它視為奇械師戲法。
  - **限制與恢復**：此屬性使用後，直到下次黎明前不能再次使用。

### 加值變體

| 變體 | 稀有度 | 奇械師法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: |
| +1 萬能工具 | 非普通 | +1 |
| +2 萬能工具 | 珍稀 | +2 |
| +3 萬能工具 | 極珍稀 | +3 |
