# 害獸帽 (Hat of Vermin，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **害獸帽**：
  - **效果**：這頂帽子有三發充能。佩戴這頂帽子期間，你可以以一個動作消耗其一發充能並說出命令語來召喚出一隻蝙蝠、青蛙、或鼠（由你選擇，其資料見《玩家手冊》或者《怪物圖鑑》）。召喚出來的生物魔法般出現在帽子中，並儘可能的嘗試遠離你。這種生物對你既不友好也不敵對，且不受你的控制。它們表現的像是個普通生物一樣，但會在一小時後或生命值歸零時消失。每日黎明，這頂帽子將重獲全部已被消耗的充能。
