# 迷醉香水 (Perfume of Bewitching，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **迷醉香水**：
  - **效果**：這個小瓶裡裝有足夠一人用的魔法香水。你可以用一個動作將香水噴灑或塗抹在自己身上。香水將生效1 小時，持續時間內你對挑戰等級為1或更低的類人生物進行的任何魅力檢定都將具有優勢，而這些生物也不會注意到他們被香水的魔法所影響了。
