# 說話玩偶 (Talking Doll，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

當這個毛絨玩偶位於你 5 呎內時，你可以花一次短休教它說出至多六個句子，**每句至多六個詞**，並為每句設定一個可觀察的觸發條件。你也可以用新句子取代舊句子。觸發條件須發生在玩偶 5 呎內，該句子才會說出。例如，有人拿起玩偶時，它可以說「我想要一顆糖果」。你與玩偶的同調結束時，這些句子會消失。
