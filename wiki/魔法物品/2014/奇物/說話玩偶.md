# 說話玩偶 (Talking Doll，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **說話玩偶**：
  - **效果**：只要這個毛絨玩偶在你周圍5 呎範圍內，你就可以利用一次短休的時間去教會它說六個短句，每個短句由至多六個片語成，且你可以分別為每個短句設定一條觸發條件，但這一條件必須是可以被觀察到的現象，且只有發生在玩偶周圍5 呎範圍內時它才會被觸發。舉例來說，你可以設定當有人拾起這個玩偶時它會說“我-想-要-一-顆-糖-果”。當你和玩偶的同調斷開時，玩偶設定的短句也將會消失。再次短休時，你可以用新的短句去替換舊的短句。
