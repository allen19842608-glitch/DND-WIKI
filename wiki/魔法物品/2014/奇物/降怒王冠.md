# 降怒王冠 (Crown of the Wrath Bringer，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這根鋸齒狀的鐵質頭冠上有一枚刻印著仇敵符文的寶石。佩戴後，王冠將散發出蒼白的光芒，它自佩戴者的怒火中汲取力量，轉以惡怖懲戒佩戴者的對手。 佩戴這頂王冠期間，當你向一個生物發起一次攻擊檢定，併成功命中時，你可以消耗並投擲一枚你未消耗的生命骰。生物將受到等同於你骰出數值點的心靈傷害。
- **激活符文 Invoking the Rune**：以一個動作，你可以激活王冠上的符文以用其施展法術 _恐懼術 fear_ （豁免 DC15） ；此法術不需要專注，且其持續時間改為1 分鐘。此符文被激活後，直到下個黎明為止都無法被再度激活。
