# 魔網紅寶石 (Ruby Weave Gem，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要；施法者 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：當你持握這塊寶石時，你可以用它作為你施法的法器。 這塊寶石有 3發充能並且在每天黎明時恢復所有已消耗的充能。當你在持握這塊寶石施法時，你可以消耗至多3發充能來忽視標註有價格法術材料成分，每發充能至多500 GP。 當你完成一次長休之後，從任何職業的法術列表中選擇一個法術。這個法術必須是你當前能夠施展的法術環階。你將這個法術視為已知並且可以用你的適合環階的法術位來施展這個法術，直到你下次長休為止
