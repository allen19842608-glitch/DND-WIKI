# 戰法紅石 (Ruby of the War Mage，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要；施法者 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **戰法紅石**：
  - **效果**：這個直徑1寸、被魔能符文蝕刻的紅寶石可以被附著於一把簡易武器或軍用武器上，以將那把武器作為你施展法術的法器使用。想使這一能力得以運作，你必須將紅寶石保持按壓在武器上至少十分鐘。附著後，除非你以一個動作將其分離或武器被摧毀，否則這顆紅寶石將無法被從武器上移除，即使是連 _反魔法場 antimagic field_ 也無法使其掉落。當然，與紅寶石解除同調後，它也會從武器上掉下來。
