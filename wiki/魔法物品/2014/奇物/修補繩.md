# 修補繩 (Rope of Mending，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **修補繩**：
  - **效果**：不論這根50 呎長的麻繩被切成了多少量的小段，你都可以用一個動作念出命令語讓這些小段重新結合回一體。不過結合時，這些小段必須互相接觸在一起且不得另作他用。如果其中有任何一段被摧毀或匿失，則這根修補繩會永遠短上同樣長度的一截。
