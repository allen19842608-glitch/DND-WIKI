# 清醒杯 (Tankard of Sobriety，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **清醒杯**：
  - **效果**：這個大酒杯上的一側雕刻著一張堅毅的臉。只要用這個酒杯，不論你喝麥芽酒、葡萄酒、還是其他任何非魔法的酒精飲料你都不會醉。這個酒杯對魔法液體或毒藥之類的有害物質不會產生影響。
