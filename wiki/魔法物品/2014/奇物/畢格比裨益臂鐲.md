# 畢格比裨益臂鐲 (Bigby's Beneficent Bracelet，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 神器 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這件華麗的珠寶飾品由法師 畢格比 Bigby 為他自己打造由四枚黃金戒指和一個鑲嵌藍寶石和鑽石的臂環組成，手背上分別有精緻的金鍊條連接著臂環與四枚戒指上。
- **隨機屬性 Random Properties**：手鐲有 1 項弱效增益、1 項強效增益與 1 項弱效減益屬性，各依《城主指南 2014》第七章的[[規則/2014/地下城主工具箱/地下城主指南/神器隨機屬性表|神器隨機屬性表]]擲 d100 決定。
- **靈活手指 Dexterous Fingers**：佩戴這件手鐲期間，你可以施展 _法師之手 Mage Hand_ 。
- **力場雕塑 Force Sculpture**：使用1 分鐘時間專注並引導手鐲的魔力，你可以創造一個大型或以下非魔法物件的靈體複製品。複製品會出現在你周圍10 呎範圍內的未佔據空間中，且它必須出現在一個能支撐他的表面上或液體中。靈體複製品用堅硬、但透明的力場製造，會模仿被複制物件的尺寸、重量、以及其他屬性。生物可以如正常非魔法物體一般觸碰複製體，或與複製體交互。 複製體免疫於所有傷害，亦無法被解除，但一次法術 _解離術 disintegrate_ 可以立刻摧毀它。此外，複製體將在8 小時，或在你主動用一個動作解散它時消失。 手鐲可以創造至多三次複製體，每日黎明，手鐲將恢復全部已被消耗的創造次數。
- **有助之手 Helpful Hand**：以一個動作，你可以用手鐲施展9環版本的法術 _畢格比之手 Bigby's hand_ （法術攻擊加值+13）。當你以此施展這個法術時，它不需要你的專注。此能力一旦被使用，直到下個黎明前都無法被再次使用。
