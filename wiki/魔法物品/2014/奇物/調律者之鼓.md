# 調律者之鼓 (Rhythm-Maker's Drum，2014 Legacy)

| 項目 | 內容 |
| :--- | :--- |

| 稀有度 (Rarity) | 非普通 |

| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：當持握這張鼓時，你在你吟遊詩人法術的法術攻擊骰和法術豁免 DC 上獲得加值。加值取決於鼓的稀有度。 作為一個動作，你可以演奏這張鼓以恢復一次你詩人激勵特性的使用次數。鼓的此項屬性，直到下次黎明前，不能再次使用。
