# 調律者之鼓 (Rhythm-Maker's Drum，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（吟遊詩人） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **吟遊詩人法術加值**：持握鼓時，你的吟遊詩人法術攻擊檢定與法術豁免 DC 獲得對應變體的加值。
- **恢復詩人激勵**：以一個動作演奏此鼓，可以恢復一次詩人激勵特性的使用次數。此屬性使用後，直到下次黎明前不能再次使用。

### 加值變體

| 變體 | 稀有度 | 吟遊詩人法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: |
| +1 調律者之鼓 | 非普通 | +1 |
| +2 調律者之鼓 | 珍稀 | +2 |
| +3 調律者之鼓 | 極珍稀 | +3 |
