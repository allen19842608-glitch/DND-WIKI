# 幻象樂器 (Instrument of Illusions，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **幻象樂器**：
  - **效果**：在你使用這把樂器進行演奏的期間，你可以在以樂器為中心的5 呎半徑球狀區域內創造出無害的、幻象般的視覺效應。如果你是一名吟遊詩人，那麼這個效應的半徑將提高到15 呎。簡單的視覺效應包括了幻光的音符、靈體的舞者、舞動的蝴蝶、飄散的雪花。這種魔法效應既無觸感亦無聲音，且他們顯然是幻象。此效應在你終止演奏的同時也會結束。
