# 撰寫樂器 (Instrument of Scribing，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **撰寫樂器**：
  - **效果**：這把樂器有三發充能。在你使用這把樂器進行演奏的期間，你可以以一個動作消耗這其1發充能，以此在周圍30 呎內你可見的非魔法物體或表面上撰寫一段魔法資訊。這段資訊以你熟知的語言書寫，且其最長六個詞。如果你是一名吟遊詩人，你的詞彙上限增加七個詞，並可以選擇令文字發出淡淡的光芒，令它在非魔法黑暗中同樣可以被看見。這些文字將在24 小時後消失，對資訊施展法術 解除魔法 dispel magic 也能將其擦掉。這個號角在每日黎明時分會恢復全部已消耗的充能數。
