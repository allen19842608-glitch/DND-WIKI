# 撰寫樂器 (Instrument of Scribing，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

這把樂器有 **3 發充能**。演奏時，你可以用一個動作消耗 1 發充能，在 30 呎內你可見的非魔法物件或表面寫下魔法訊息。訊息以你知道的語言書寫，至多六個詞；若你是吟遊詩人，可多寫七個詞，並可選擇讓文字微微發光，使其在非魔法黑暗中可見。對訊息施展[[法術/2014/3環/解除魔法|解除魔法]]會將其抹除；否則訊息會在 24 小時後消失。樂器每日黎明恢復所有已消耗的充能。
