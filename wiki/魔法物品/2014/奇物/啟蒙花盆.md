# 啟蒙花盆 (Pot of Awakening，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **啟蒙花盆**：
  - **效果**：你可以在這個10 磅重的黏土花盆裡種植普通的灌木。待其生長三十天後，這株灌木會魔法性的轉化為一株 **啟蒙灌木 Awakened Shrub** （其資料見《怪物圖鑑》）。當灌木被啟蒙時，它的根會打碎花盆並導致花盆被摧毀。這株植物對你友善，且若沒有得到你的命令，它什麼都不會幹。
