# 噴流式奧能臂 (Arcane Propulsion Arm，2014 Legacy)

## 物品描述

坎尼斯家族的奇械師研發了這種義肢。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要；限缺失手或臂的生物，須將義肢裝在手腕、手肘或肩膀的殘端 |
| 消耗品 (Consumable) | 來源未註明 |

### 物品效果

- **義肢連接**：
  - **啟用／觸發**：將義肢裝在殘端完成同調時。
  - **效果**：義肢以魔法形成所取代肢體的形態。連接期間，它是你身體中功能完備的一部分。你可以用動作將它移除；同調結束時它也會自行脫離，且不能違背你的意願被移除。

- **投擲義肢**：
  - **啟用／觸發**：義肢連接期間，以它作為武器攻擊。
  - **效果**：義肢是你具有熟練的魔法近戰武器，命中造成 1d8 力場傷害，並具有投擲詞條，常規射程 20 呎、最大射程 60 呎。投擲時，它脫離殘端飛向攻擊目標，隨後立即返回並重新連接。
