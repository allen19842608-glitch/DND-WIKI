# 蘊能木法器 (Imbued Wood Focus，2014 Legacy)

## 物品描述

蘊能木法器由汲取異位面能量的樹木製成，可以是權杖、法杖或魔杖。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通；八種木材變體皆相同 |
| 同調 (Attunement) | 需要；八種木材變體皆相同 |
| 消耗品 (Consumable) | 來源未註明 |

### 物品效果

- **施法法器**：
  - **啟用／觸發**：你是施法者時。
  - **效果**：你可以將此物品作為施法法器使用。

- **對應傷害加值**：
  - **啟用／觸發**：你使用此物品作為施法法器，施展一道造成傷害的法術時。
  - **效果**：若該法術造成與木材變體相對應的傷害類型，該法術的一次該類型傷害擲骰獲得 +1 加值。八種變體的對應如下：

| 木材變體 | 對應傷害類型 |
| :--- | :--- |
| 費尼亞梣木 (Fernian Ash) | 火焰 |
| 伊瑞安玫瑰木 (Irian Rosewood) | 光耀 |
| 奇斯瑞毒番石榴木 (Kythrian Manchineel) | 強酸或毒素 |
| 拉曼尼亞橡木 (Lamannian Oak) | 閃電或雷鳴 |
| 瑪巴爾烏木 (Mabaran Ebony) | 暗蝕 |
| 瑞西亞松木 (Risian Pine) | 寒冷 |
| 沙瓦拉斯樺木 (Shavarran Birch) | 力場 |
| 宙瑞亞特雞翅木 (Xorian Wenge) | 心靈 |
