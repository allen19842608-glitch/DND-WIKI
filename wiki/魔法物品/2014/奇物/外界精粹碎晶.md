# 外界精粹碎晶 (Outer Essence Shard，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要術士同調 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：可用動作將碎晶附到一件微型物件（例如武器或珠寶）或將其取下；同調結束時碎晶會掉落。持握或穿戴碎晶時，可將其作為法器。擲 `d4` 決定精粹類型；持握或穿戴碎晶並對法術套用一個超魔法選項時，可套用下表對應屬性。

| d4 | 屬性 |
| :---: | :--- |
| 1 | **守序**：可終止正影響你或 30 呎內一個可見生物的下列一種狀態：魅惑、目盲、耳聾、恐慌、中毒或震懾。 |
| 2 | **混亂**：選擇一個受到該法術傷害的生物；其攻擊檢定與屬性檢定直到你的下一回合開始前具有劣勢。 |
| 3 | **善良**：你或一個由你選擇、30 呎內可見的生物獲得 `3d6` 臨時生命值。 |
| 4 | **邪惡**：選擇一個受到該法術傷害的生物；其額外受到 `3d6` 暗蝕傷害。 |
