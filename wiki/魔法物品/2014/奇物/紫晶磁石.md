# 紫晶磁石 (Amethyst Lodestone，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這塊拳頭大小的紫水晶被注入了紫晶龍扭曲引力的能力。當你持用這塊磁石時，你在力量豁免上具有優勢。 磁石有 6發充能，當你持用這塊磁石時可以消耗充能使用以下特性。磁石在每日黎明時恢復1d6發充能。
- **飛行**：以一個附贈動作，你可以消耗1發充能在十分鐘內獲得飛行的能力。在此期間你獲得等同於你的步行速度的飛行速度，並且可以懸浮。
- **引力猛推**：以一個動作，你可以消耗一發充能將引力集中在60 呎內一個你能看到的生物周圍，目標必須通過一個 DC18的力量豁免，否則朝你選擇的方向被推出20 呎。
- **反轉重力**：以一個動作，你可以消耗3發充能通過磁石施展一道法術_反轉重力_（豁免 DC18）。
