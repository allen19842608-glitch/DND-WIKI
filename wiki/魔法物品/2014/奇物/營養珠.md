# 營養珠 (Bead of Nourishment，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是；珠子在舌頭上溶解後耗用 |

### 物品效果

- **營養珠**：
  - **效果**：這個無味海綿狀凝膠珠子在你的舌頭上溶解時，它會為你提供一天份的食物營養。
