# 血源瓶 (Bloodwell Vial，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：同調此物品時，你需要將你的一些鮮血滴入其中。直到你與它的同調結束前，小瓶無法再次被開啟。若你與小瓶的同調結束，瓶中之血將化為灰燼。你可以在持握或穿戴這個小瓶時將作為法器，同時你在你術士法術的法術攻擊骰和法術豁免 DC 上獲得加值。加值取決於小瓶的稀有度。此外，當你使用任意數量的生命骰以恢復生命值時，你可以恢復5點術法點。該特性直到下次黎明前，無法再次被使用。
