# 血源瓶 (Bloodwell Vial，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 非普通（+1）／珍稀（+2）／極珍稀（+3） |
| 同調 (Attunement) | 需要（術士） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **同調與封存**：與小瓶同調時，必須滴入幾滴自己的血。同調持續期間，小瓶無法打開；同調結束時，瓶內血液化為灰燼。
- **術士施法法器與加值**：持握或佩戴小瓶時，你可以將它作為施法法器；你的術士法術攻擊檢定與法術豁免 DC 獲得對應變體的加值。
- **恢復術法點**：攜帶小瓶並擲出一枚或多枚生命骰以恢復生命值時，你可以恢復 5 點術法點。此屬性使用後，直到下次黎明前不能再次使用。

### 加值變體

| 變體 | 稀有度 | 術士法術攻擊與豁免 DC 加值 |
| :--- | :--- | :---: |
| +1 血源瓶 | 非普通 | +1 |
| +2 血源瓶 | 珍稀 | +2 |
| +3 血源瓶 | 極珍稀 | +3 |
