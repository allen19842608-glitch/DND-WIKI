# 霍華德香料包 (Heward's Handy Spice Pouch，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **霍華德香料包**：
  - **效果**：這個細繩緊繫的小包具有十發充能，發現它時其內部是空的。你可以手持這個小包，以一個動作消耗其1發充能，並說出任何一種非魔法的食物調味料的名字（例如鹽、胡椒、番紅花、或香菜）。此時，小包內就能倒出一些你想要的事物調味料，其量足以調味單人份的食物。這個小包於每日黎明時分恢復1d6+4發已消耗的充能。
