# 龍觸法器 (Dragon-Touched Focus，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 需要；施法者 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這個奇物可以是法杖、法球、護符、水晶或其他的精製物件。它通常包含有龍的翅膀、爪子、牙齒或鱗片的象形。 _**沉睡(非普通)。**_你的先攻檢定具有優勢。當你持握這件法器時，它可以作為你施展所有法術的法器。 _**激活(珍稀)。**_激活法器具有沉睡狀態的特性，它還獲得了另一個特性，由激活它的寶庫的主龍的族裔決定：
- **色彩**：每當你使用法術位施展一道造成強酸、寒冷、火焰、閃電或毒素傷害的法術時。投擲一個 d6，你在這個法術的其中一個傷害擲骰上增加擲出的值。
- **寶石**：當你使用法術位施放一道法術時，你可以立即傳送到距離你15 呎內一處你能看見且未佔據空間。
- **金屬**：當一個你能看到的生物在你30英尺內進行豁免檢定時，你可以使用你的反應使該生物在這次豁免檢定上獲得優勢。 _**覺醒(極珍稀)。**_覺醒的法器有沉睡和激活狀態的特性，當你持握覺醒法器時，你可以使用它來施放特定的法術。一旦該物品被用來施放一道這個特性贈送的法術，直到下一個黎明之前它就不能再次被用於施展該法術。這些法術由使其覺醒的寶庫主龍的族裔決定。星號表示本章前面出現的新法術。
- **彩色**：定身怪物，霧凇霜縛\*
- **寶石**：拉瑞心靈鏈接，勞洛希姆心靈長槍\*
- **金屬**：。費資本鉑金盾\*，通曉傳奇
- **_神化(傳奇)。_**：神化法器具有沉睡、激活和覺醒狀態的特性。此外，當你持握這個法器施展一道1環或更高環階的法術時，你可以將其視為使用9環法術位施放的法術。一旦這項特性被使用，直到下一個黎明之前它不能被再次使用。
