# 聖所護符 (Sanctum Amulet，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這枚黑色蛋白石掛墜懸掛在一條珍珠項鍊的下方。神聖符文銘刻在這枚掛墜的背面。 佩戴這件物品期間，你獲得暗蝕傷害的抗性。此外，你可以用動作或附贈動作（由你選擇）來施展戲法 _維生術 spare the dying_ 。
- **激活符文 Invoking the Rune**：當你周圍60 呎範圍內你可見的一名生物生命值因受到傷害而生命值降至0時，你可以用你的反應去激活這件物品上的符文，讓掛墜散發出一陣暗淡的光，他們將改為生命值降至1點，而非0點。 此符文被激活後，直到下個黎明為止都無法被再度激活。
