# 旅人之靴 (Wayfarer's Boots，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **特殊能力**：這雙靴子使用堅固耐用的布料製成，金色的絲線在兩隻靴子的腳後跟上各縫紉著旅途符文。穿著這對靴子期間，你的步行速度增加10 呎，且你進行的感知（求生）檢定具有優勢。
- **激活符文 Invoking the Rune**：以一個附贈動作，你可以激活這對靴子上的符文以用其施展法術 _腳底抹油 expeditious retreat_ 。此符文被激活後，直到下個黎明為止都無法被再度激活。 （譯者注：旅途符文同時也是神迪安卡斯特拉的聖徽）
