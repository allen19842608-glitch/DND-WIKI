# 巫術帽 (Hat of Wizardry，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 需要；法師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **巫術帽**：
  - **效果**：這個老舊的、圓錐形的帽子被以金色的新月和星星裝飾。佩戴這頂帽子期間，你獲得下列增益： 你可以用這頂帽子作為你施展法師法術的法器使用。 你可以嘗試施展你不知曉的戲法，但其必須位於法師法術列表，且你必須透過一次 DC10的智力（奧秘）檢定。若檢定成功則你如常施展那個法術。若檢定失敗，則法術施展失敗，並且用於施法的動作將被浪費。使用後，不論檢定結果如何，直到你完成一次長休前你都不能再次使用這個能力。
