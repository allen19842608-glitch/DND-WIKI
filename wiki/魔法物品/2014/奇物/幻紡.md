# 幻紡 (Glamerweave，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物（衣物） |
| 稀有度 (Rarity) | 普通或非普通；依版本 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **普通幻紡**：
  - **啟用／觸發**：穿戴期間；使用一個附贈動作。
  - **效果**：在衣料內創造流動的無害幻象圖案。

- **非普通幻紡**：
  - **啟用／觸發**：穿戴期間；使用一個附贈動作。
  - **效果**：在衣料內創造流動的無害幻象圖案，也可以讓圖案從衣料上升起。
  - **額外效果**：穿戴期間進行魅力（表演）或魅力（遊說）檢定時，可以擲一顆 d4，將結果加到檢定。此額外效果用過後，直到下個黎明才可再次使用。
