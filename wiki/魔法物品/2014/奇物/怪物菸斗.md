# 怪物菸斗 (Pipe of Smoke Monsters，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **怪物菸斗**：
  - **效果**：用這個菸斗抽菸期間，你可以以一個動作，撥出一團膨脹的煙雲並另其變成某一生物的形狀，例如一條龍、一隻呋嚕怪、或者一之沼喉怪。不過這個形狀將被縮到1 呎立方的大小，並其會在數秒之後失去其形態，變回普通的煙。
