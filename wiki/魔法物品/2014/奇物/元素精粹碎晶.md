# 元素精粹碎晶 (Elemental Essence Shard，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 奇物 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要術士同調 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **主要魔法效果**：
  - **效果**：可用動作將碎晶附到一件微型物件（例如武器或珠寶）或將其取下；同調結束時碎晶會掉落。持握或穿戴碎晶時，可將其作為法器。擲 `d4` 決定精粹類型；持握或穿戴碎晶並對法術套用一個超魔法選項時，可套用下表對應屬性。

| d4 | 屬性 |
| :---: | :--- |
| 1 | **氣**：立即飛行移動 60 呎，且不會引發藉機攻擊。 |
| 2 | **土**：獲得你所選一種傷害類型的抗性，直到你的下一回合開始。 |
| 3 | **火**：你可見的一個法術目標立刻著火；該目標在其下一回合開始時受到 `2d10` 火焰傷害，之後火焰消失。 |
| 4 | **水**：以你為源點爆發半徑 10 呎水流。區域內每個由你選擇且可見的目標受到 `2d6` 寒冷傷害，並進行力量豁免對抗你的法術豁免 DC；失敗時被推離 10 呎並陷入伏地狀態。 |
