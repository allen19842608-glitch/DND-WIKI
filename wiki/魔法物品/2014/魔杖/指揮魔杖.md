# 指揮魔杖 (Wand of Conducting，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **指揮魔杖**：
  - **效果**：這根魔杖具有3發充能。持握這把魔杖期間，你可以用一個動作揮舞它，消耗其1發充能創造一段管絃樂。這段音樂在60 呎範圍內被聽到，並會在你停止揮舞之後消失。這根魔杖在每日黎明時會恢復全部已消耗的充能數。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將伴隨著演奏出一陣哀慟的低音兼次中音大號聲音，碎裂成灰燼，並被摧毀。
