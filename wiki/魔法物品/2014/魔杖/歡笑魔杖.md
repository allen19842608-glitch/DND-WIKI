# 歡笑魔杖 (Wand of Smiles，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **歡笑魔杖**：
  - **效果**：這根魔杖具有3發充能。持握這把魔杖期間，你可以用一個動作，消耗其一發充能，以指定周圍30 呎範圍內的一個類人生物作為目標。目標必須透過一個 DC10的魅力豁免檢定否則被強制喜笑顏開一分鐘。這根魔杖在每日黎明時會恢復全部已消耗的充能數。當充能數耗盡時，骰一次 d20。如果骰值為1，這根魔杖會變成一根愁苦魔杖。
