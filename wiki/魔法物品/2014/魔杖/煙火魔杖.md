# 煙火魔杖 (Wand of Pyrotechnics，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **煙火魔杖**：
  - **效果**：這根魔杖具有7發充能。持握這把魔杖期間，你可以用一個動作，消耗一發充能創造一束無害且多彩的光亮，令其以60 呎內你可見的一點為中心爆發。這段光亮迸發時會伴隨著一陣300 呎範圍內都能聽見的響亮爆裂聲。這發光亮如火把之光一般，卻只存一瞬。這根魔杖每天黎明恢復1d6+1發已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，這根魔杖會迸發出一陣無害的煙火表演，並被摧毀。
