# 龍威藥水 (Potion of Dragon's Majesty，2014 Legacy)

> [!WARNING]
> 本條目為 2014 Legacy 魔法物品；不取代同名的 2024 條目。

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 藥水 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **特殊能力**：這個藥水看起來像是液態的黃金，有一片色彩，寶石或金屬龍的鱗片懸浮在其中。你喝下藥劑之後，你變成一隻 成年龍，類型作為和鱗片來源的龍種類相同。變形持續一小時。任何你裝備或持用的裝備融入新形態或者散落在周圍。在其期間內，你使用成年龍的遊戲數據來代替你的遊戲數據，但你保有你原本的語言，個性和記憶。你不能使用龍的變形能力，傳說動作或巢穴動作。
