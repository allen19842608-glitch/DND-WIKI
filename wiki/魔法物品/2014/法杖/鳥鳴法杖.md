# 鳥鳴法杖 (Staff of Birdcalls，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **鳥鳴法杖**：
  - **效果**：這根木質法杖以鳥的雕像為飾。它具有10發充能。持握這把法杖期間，你可以用一個動作消耗其1發充能，以創造一陣可以在周圍60 呎範圍內被聽到的下列聲音之一：麻雀啾啾、烏鴉報喪、鴨子嘎嘎、家雞打鳴、大鵝咳咳、潛鳥啁啁、火雞咯咯、海鷗啼哭、夜梟呵斥、或老鷹長嘯。這根法杖每日黎明時分恢復1d6+4發已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將在一陣無害的鳥形雲霧中爆炸並且永遠消失。
