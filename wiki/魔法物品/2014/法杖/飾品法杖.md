# 飾品法杖 (Staff of Adornment，2014 Legacy)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **飾品法杖**：
  - **效果**：持握這根法杖期間，你可以將至重1 磅的物件（例如水晶碎片、雞蛋、或是石頭）在法杖的頂端，這個物品會在法杖頂端周圍相距一寸的位置漂浮著，直到其被移除或者法杖不再為你所控為止。一根法杖同一時間最多有三件物品漂浮於其頂端周圍。持握法杖時，你可以選擇令一個物品緩慢旋轉起來，或令其停止旋轉。
