# 復生權杖 (Rod of Resurrection)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：持握並同調期間；依各法術的充能消耗施展。
  - **效果**：此權杖具有 5 充能。你可從中施展下列法術：
    - *醫療術 Heal*（1 充能）
    - *復生術 Resurrection*（5 充能）
  - **限制與恢復**：權杖在每日黎明重獲 1 點已消耗的充能。充能耗盡時擲 1d20；若結果為 1，權杖在無害光芒中消失。
