# 庇護權杖 (Rod of Security)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **庇護半位面**：
  - **啟用／觸發**：持握期間；執行魔法動作啟動時。
  - **效果**：當持握這根權杖時，你可以執行**魔法**動作來激活它。權杖會立刻將你和你可見的至多 199名自願生物傳送入一個半位面。你選擇半位面所呈現的形式。它可以是寧靜的花園、熱鬧的酒館、宏偉的宮殿、熱帶島嶼、夢幻般的嘉年華，或者任何你能想像的場景。無論性質如何，這個半位面有足夠的食物和水供訪客享用，並且半位面的任何環境都無法傷害到其中的居住者們。此處一切可交互的事物都只能存在於該半位面中。例如，把半位面中花園裡摘的花帶出半位面時，該花將消失。
  - **限制與恢復**：例如，把半位面中花園裡摘的花帶出半位面時，該花將消失。

- **半位面休養**：
  - **啟用／觸發**：半位面啟動並停留期間。
  - **效果**：在半位面裡每度過一個小時，訪客們都能如同花費了1個生命骰一般地恢復生命值。並且儘管半位面中時間將正常流動，但其中的生物不會變老。訪客們可以在此停留最多 200除以生物數量的天數（向下取整）。
  - **限制與恢復**：訪客們可以在此停留最多 200除以生物數量的天數（向下取整）。

- **返回原處**：
  - **啟用／觸發**：停留時間耗盡，或執行魔法動作結束效應時。
  - **效果**：當停留時間耗盡或你執行**魔法**動作以結束該效應時，所有訪客都會重新出現在權杖激活前的位置或該位置最近的未佔據的空間裡。該詞條被使用後，直至過去10天時間才能再次使用。
  - **限制與恢復**：該詞條被使用後，直至過去10天時間才能再次使用。
