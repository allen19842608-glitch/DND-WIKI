# 不動權杖 (Immovable rod)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **固定權杖**：
  - **啟用／觸發**：以一個**操作**動作按下鐵質權杖一端的按鈕。
  - **效果**：權杖魔法性地固定在原處，即使違反重力也不移動；你或另一生物以一個**操作**動作再次按下按鈕時解除固定。
  - **限制**：權杖最多承受 8,000 磅；更重的負載使其失效並掉落。生物可以用一個**操作**動作進行 DC 30 力量（運動）檢定，成功時可將固定的權杖移動最多 10 呎。
