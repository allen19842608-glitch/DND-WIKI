# 不動權杖 (Immovable rod)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **固定權杖**：
  - **啟用／觸發**：執行操作動作按下按鈕時。
  - **效果**：這根鐵質權杖的一端具有一枚按鈕。你可以執行**操作動作**按下按鈕，讓這根權杖魔法性地固定在原處。直到你或另一生物執行**操作動作**再次按下按鈕前，即使違反了重力定律，權杖也不會移動。權杖最多能負載8000 磅的重量。更重的負載則會讓權杖的效應失效並掉落在地。一個生物可以執行操作動作來進行一次DC 30的力量（運動）檢定，成功則可以將固定住的權杖移動最多 10 呎。
  - **限制與恢復**：一個生物可以執行操作動作來進行一次DC 30的力量（運動）檢定，成功則可以將固定住的權杖移動最多 10 呎。
