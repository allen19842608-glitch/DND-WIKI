# 統御權杖 (Rod of Rulership)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **統御命令**：
  - **啟用／觸發**：執行魔法動作展示權杖時。
  - **效果**：你可命令你可見、你 120 呎內任意數量由你指定的生物服從。每名目標須通過 DC 15 感知豁免，否則陷入**魅惑**狀態 8 小時，並視你為值得信賴的領袖。若你或盟友傷害目標，或命令其做違反天性的事，該目標的魅惑便結束。
  - **限制與恢復**：使用後，直到下個黎明前無法再次使用。
