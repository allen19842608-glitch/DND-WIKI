# 統御權杖 (Rod of Rulership)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **統御命令**：
  - **啟用／觸發**：執行魔法動作展示權杖時。
  - **效果**：你可以執行**魔法**動作來展示這根權杖，並向你可見的，周身120 呎內你所指定的每個生物下令服從於你。每個目標必須通過一次DC 15的感知豁免，否則陷入**魅惑**狀態8 小時。在以這種方式被**魅惑**期間，生物將視你為值得託付信賴的領袖。如果你或你的盟友傷害了目標，或命令目標去做違反其天性的行為時，以此法造成的**魅惑**將終止。該詞條一經使用，直至下個黎明前你都無法再次使用。
  - **限制與恢復**：該詞條一經使用，直至下個黎明前你都無法再次使用。
