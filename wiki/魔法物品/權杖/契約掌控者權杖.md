# 契約掌控者權杖 (Rod of the Pact Keeper，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔契法術加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：當持握這根權杖時，你的契術師法術的法術攻擊檢定和豁免DC獲得加值。加值大小取決於權杖的稀有度。

- **恢復法術位**：
  - **啟用／觸發**：持握期間；執行魔法動作時。
  - **效果**：此外，持握這根權杖期間，你能夠以一個**魔法**動作恢復一個法術位。該詞條一經使用，你在完成一次長休後都無法再次使用。
  - **限制與恢復**：該詞條一經使用，你在完成一次長休後都無法再次使用。
