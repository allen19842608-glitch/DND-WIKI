# 契約掌控者權杖 (Rod of the Pact Keeper，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 多種稀有度（見變體） |
| 同調 (Attunement) | 需要（契術師） |
| 消耗品 (Consumable) | 否 |

### 變體

| 變體 | 法術攻擊與豁免 DC 加值 | 稀有度 |
| :--- | :--- | :--- |
| +1 契約掌控者權杖 | +1 | 非普通 |
| +2 契約掌控者權杖 | +2 | 珍稀 |
| +3 契約掌控者權杖 | +3 | 極珍稀 |

### 物品效果

- **魔契法術加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：當持握這根權杖時，你的契術師法術的法術攻擊檢定和豁免 DC 獲得該變體所列的加值。

- **恢復法術位**：
  - **啟用／觸發**：持握期間；執行魔法動作時。
  - **效果**：恢復一個法術位。
  - **限制與恢復**：使用後，直到完成一次長休前無法再次使用。
