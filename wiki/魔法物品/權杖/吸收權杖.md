# 吸收權杖 (Rod of Absorption)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 權杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **吸收法術**：
  - **啟用／觸發**：持握期間；你成為符合條件法術的唯一目標時。
  - **效果**：持握這根權杖期間，你可以執行**反應**來吸收一道僅以你為目標且不會創造範圍效應的法術。被吸收的法術將被解除，且法術的能量（而非法術本身）將被儲存進權杖中。這些能量與該法術施展時的環階相同。被解除的法術消散且無效，而施展法術時使用的任何資源都將浪費掉。這根權杖在其被製造出來後最多能吸收並儲存共計50環的能量。當權杖已經吸收了50環的能量後，它將無法再吸收法術。如果你被一道權杖無法儲存的法術所選為目標，那麼權杖將不會對其產生影響。

- **儲能資訊**：
  - **啟用／觸發**：完成同調時。
  - **效果**：當你與權杖同調時，你會知曉權杖已經吸收過多少環的能量，以及它當前儲存了多少環的法術能量。

- **轉化法術能量**：
  - **啟用／觸發**：持握期間；施展已準備或已知法術時。
  - **效果**：持握此權杖期間，如果你是一名施法者，則你可以將權杖中儲存的能量轉化為法術位並用其施展你已準備的法術或已知的法術。此法可轉化出的法術位其環階不超過你擁有的最高法術位環階，且最高為五環。你需要如常施展該法術，只是你消耗的是權杖儲存的法術能量而非自己的法術位。例如，你可以將權杖儲存的3環能量作為一個3環法術位使用。

- **初始能量與耗盡**：
  - **效果**：新發現的吸收權杖通常已經儲存了 1d10 環法術能量；無法再吸收法術且沒有剩餘能量時，權杖變為非魔法物品。
