# 隨機魔法物品 (Random Magic Items)

隨機魔法物品表先按寶藏主題分類，再按物品稀有度分類。先選擇符合寶藏主題的表，再擲該稀有度的 d100 表。

## ⚙️ 規則條文 (Rule Text)

若物品不特別適合任一主題，擲 1d4 決定使用的主題表：

| d4 | 主題表 |
| :---: | :--- |
| 1 | 奧秘 |
| 2 | 武備 |
| 3 | 器具 |
| 4 | 聖物 |

選擇表格時可參閱 [[規則/裝備與物件/寶藏|寶藏主題 (Treasure Themes)]]。

### 主題表

- [[奧秘隨機表|奧秘隨機表 (Arcana Tables)]]：完整收錄普通、非普通、珍稀、極珍稀與傳說的奧秘 d100 結果。
- [[武備隨機表|武備隨機表 (Armaments Tables)]]：完整收錄普通、非普通、珍稀、極珍稀與傳說的武備 d100 結果。
- [[器具隨機表|器具隨機表 (Implements Tables)]]：完整收錄普通、非普通、珍稀、極珍稀與傳說的器具 d100 結果。
- [[聖物隨機表|聖物隨機表 (Relics Tables)]]：完整收錄普通、非普通、珍稀、極珍稀與傳說的聖物 d100 結果。
