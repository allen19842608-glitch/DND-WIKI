# 冰霜法杖 (Staff of Frost)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：**法術 Spells**。這根法杖具有10 充能。持握此法杖期間，你可以從法杖中施展以下表格中的一道法術，使用你自己的法術豁免 DC。施展相應法術所需消耗的充能數如下表所示。

### 使用、充能與恢復

- **恢復與耗盡**：**重獲充能 Regaining Charges**。這根法杖在每日黎明時重獲1d6+4已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將融化為水並被摧毀。
