# 魔咒法杖 (Enspelled Staff)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：這柄法杖中銘刻了一道八環或更低環階的法術。這道法術可以是任意學派的一道法術，在製造此法杖的時候決定。此法杖具有6 充能，且在每日黎明時重獲1d6已消耗的充能。持握此法杖期間，你可以消耗1 充能以施展該法術。若你消耗了法杖最後一充能，則擲一次 d20，若結果為1，則法杖失去其詞條並變為一把非魔法長棍。
  - **限制與恢復**：此法杖具有6 充能，且在每日黎明時重獲1d6已消耗的充能。

- **法術豁免 DC 與攻擊加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：法杖中銘刻的法術環其階決定了這道法術的豁免 DC 和攻擊加值，還有這柄法杖的稀有度（見下表）。
