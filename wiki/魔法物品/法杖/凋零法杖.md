# 凋零法杖 (Staff of Withering)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要；牧師、德魯伊或契術師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖具有3 充能，並在每日黎明時重獲1d3已消耗的充能。

- **凋零打擊**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖可被用作一根魔法長棍。命中時，其造成普通長棍的傷害，然後你可以消耗1 充能來對目標造成額外2d10暗蝕傷害，並強迫目標進行一次 DC 15的體質豁免。豁免失敗時，目標在1小時內進行的基於力量或體質的屬性檢定與豁免都具有劣勢。

### 來源差異

中文來源僅寫「需同調」；同版英文原文指定牧師、德魯伊或契術師。上方依英文原文列出職業限制。
