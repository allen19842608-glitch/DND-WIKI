# 巨蟒法杖 (Staff of The Python)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **命令生物**：
  - **啟用／觸發**：持握期間。
  - **效果**：在你的回合內，只要蛇在你身邊60 呎範圍內且你未陷入**失能**狀態，你便可以用精神給他下達命令（無需動作）。你將決定巨蟒在這一輪中執行什麼動作以及如何移動，或者你可以下達一個寬泛的指令，例如攻擊你的敵人或保護某個地點。如果你沒有下達命令，蛇將保護自己。

- **生命恢復**：
  - **啟用／觸發**：持握期間。
  - **效果**：以一個**附贈動作**，你可以命令蛇在當前的空間還原回法杖形態，之後你無法在1小時內再次使用法杖的詞條。如果蛇的生命值被降為0，它將**死亡**並還原回法杖形態，隨後法杖破碎並被摧毀。如果蛇在失去全部生命值之前還原回法杖形態，它會恢復所有失去的生命值。
  - **限制與恢復**：如果蛇的生命值被降為0，它將**死亡**並還原回法杖形態，隨後法杖破碎並被摧毀。
