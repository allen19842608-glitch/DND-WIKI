# 蟲群法杖 (Staff of Swarming Insects)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要；吟遊詩人、牧師、德魯伊、術士、契術師或法師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **蟲雲**：
  - **啟用／觸發**：持握期間。
  - **效果**：**蟲雲 Insect Cloud**。持握這根法杖期間，你可以執行**魔法**動作並消耗1 充能，使一群無害的飛蟲佈滿源自你的30 呎光環內的空間。這些昆蟲持續存在10分鐘，並讓這片區域被除你以外的生物視為重度遮蔽。一陣強風（例如_造風術 Gust of Wind_ 所創造的）可以驅散蟲群並結束其效應。

- **法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：持握這根法杖期間，你可以從法杖中施展以下表格中的一道法術，使用你自己的法術豁免 DC 與法術攻擊調整值。施展相應法術所需消耗的充能數如下表所示。

### 使用、充能與恢復

- **充能總量**：這根法杖具有 10 充能。

- **恢復與耗盡**：**重獲充能 Regaining Charges**。這根法杖在每日黎明時恢復1d6+4發已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，蟲群將蠶食法杖，並在將其摧毀後消散。
