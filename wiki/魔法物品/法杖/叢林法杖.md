# 叢林法杖 (Staff of The Woodlands)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要；德魯伊 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖具有6 充能並可被用作一根魔法長棍（用這根長棍發動的攻擊檢定和傷害擲骰獲得+2加值）。持握此法杖期間，你在法術攻擊檢定上獲得+2加值。

- **法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：**法術 Spells**。持握這根法杖期間，你可以從法杖中施展以下表格中的一道法術，使用你自己的法術豁免 DC。表格中將顯示你施展法術所需消耗的充能數。

- **樹木形態**：
  - **啟用／觸發**：持握期間。
  - **效果**：**樹木形態**。你可以執行**魔法**動作來將法杖的一端插入一處未佔據空間的土地上，並消耗1 充能將其轉變為一棵健壯的樹。這棵樹高60 呎，樹幹直徑5 呎，頂端的樹冠以20 呎半徑向外延伸。這棵樹外觀與普通的樹無異，但_偵測魔法 Detect Magic_能辨別出樹上散發出的微弱**變化**系魔法靈光。你可以在觸碰這棵樹時執行**魔法**動作 將其變回原本的法杖形態。當樹還原回法杖時，任何在樹上的生物都會掉下來。

### 使用、充能與恢復

- **恢復與耗盡**：**重獲充能 Regaining Charges。**這根法杖在每日黎明時重獲1d6已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖失去其所有詞條並將變為一根非魔法性的長棍。
