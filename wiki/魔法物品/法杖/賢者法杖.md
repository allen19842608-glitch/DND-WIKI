# 賢者法杖 (Staff of The Magi)

## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 需要（術士、契術師或法師） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **魔法長棍**：
  - **啟用／觸發**：持握並同調期間；以法杖作為長棍攻擊時。
  - **效果**：此法杖具有 50 充能，可作為魔法長棍使用；其攻擊檢定與傷害擲骰獲得 +2 加值。持握期間，你的法術攻擊檢定也獲得 +2 加值。

- **法術吸收**：
  - **啟用／觸發**：持握並同調期間；其他生物施展僅以你為目標的法術時；使用一個**反應**。
  - **效果**：你對抗法術的豁免檢定具有優勢。你可令法杖吸收該法術，使其效果消失，並獲得等同於該法術環階的充能。
  - **限制與恢復**：若吸收後充能超過 50，法杖如同啟用「復仇打擊」般爆炸。

- **可施展法術**：
  - **啟用／觸發**：持握並同調期間；依各法術的充能消耗施展。
  - **效果**：你可從法杖施展下列法術，使用自己的法術豁免 DC：

    | 法術 | 充能消耗 |
    | :--- | :--- |
    | *秘法鎖 Arcane Lock* | 0 |
    | *偵測魔法 Detect Magic* | 0 |
    | *變巨術／縮小術 Enlarge/Reduce* | 0 |
    | *光亮術 Light* | 0 |
    | *法師之手 Mage Hand* | 0 |
    | *防護善惡 Protection from Evil and Good* | 0 |
    | *熾焰法球 Flaming Sphere* | 2 |
    | *隱形術 Invisibility* | 2 |
    | *敲擊術 Knock* | 2 |
    | *蛛網術 Web* | 2 |
    | *解除魔法 Dispel Magic* | 3 |
    | *冰風暴 Ice Storm* | 4 |
    | *火牆術 Wall of Fire* | 4 |
    | *穿牆術 Passwall* | 5 |
    | *心靈遙控 Telekinesis* | 5 |
    | *咒喚元素 Conjure Elemental* | 7 |
    | *火球術 Fireball*（七環版本） | 7 |
    | *閃電束 Lightning Bolt*（七環版本） | 7 |
    | *位面轉移 Plane Shift* | 7 |
  - **限制與恢復**：每日黎明重獲 4d6 + 2 點已消耗的充能。充能耗盡時擲 1d20；若結果為 20，重獲 1d12 + 1 點已消耗的充能。

- **復仇打擊**：
  - **啟用／觸發**：使用一個**魔法**動作，在自己的膝蓋或堅固表面上折斷法杖。
  - **效果**：法杖被摧毀並爆炸，影響以法杖為中心的 30 呎光環。你有 50% 機率被立即傳送至隨機存在位面以避開爆炸；未避開時，你受到等於 16 × 法杖充能的力場傷害。區域內其他生物必須進行 DC 17 敏捷豁免；失敗受到等於 6 × 法杖充能的力場傷害，成功則傷害減半。
