# 飾品法杖 (Staff of Adornment)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **漂浮**：
  - **啟用／觸發**：持握期間。
  - **效果**：持握這根法杖期間，如果你將一個重量不超過 1 磅的微型物件（例如一塊水晶碎片、一顆雞蛋、一塊石子）放於法杖的尖端，這個物件將會在尖端旁 1 寸的位置漂浮，直到該物件被移除或法杖不再由你持有。這根法杖同一時間至多可以讓三個這樣的物件在尖端漂浮。持握此法杖期間，你可以讓這些物件中的一個或多個緩慢地繞著法杖旋轉或原地自轉。

### 來源差異

中文來源將停止條件寫為法杖「不在你手裡」；同版英文原文為「不再由你持有」。上方依英文原文表述。
