# 威力法杖 (Staff of Power)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要；術士、契術師或法師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **護甲等級加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖具有20 充能並可被用作一根魔法長棍（用這根長棍發動的攻擊檢定和傷害擲骰獲得+2加值）。持握此法杖期間，你在護甲等級、豁免和法術攻擊檢定上獲得+2加值。

- **法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：**法術 Spells**。持握這根法杖期間，你可以從法杖中施展以下表格中的一道法術，使用你自己的法術豁免 DC。施展相應法術所需消耗的充能數如下表所示。

### 使用、充能與恢復

- **恢復與耗盡**：**重獲充能 Regaining Charges**。這根法杖在每日黎明時重獲2d8+4已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將失去除了攻擊檢定與傷害擲骰獲得+2加值以外的其他所有詞條。如果骰值為20，法杖恢復1d8+2 充能。

- **復仇打擊**：
  - **啟用／觸發**：以魔法動作將法杖折斷在膝蓋上或堅硬表面上。
  - **效果**：法杖被摧毀並釋放魔力，在以法杖為源點、半徑 30 呎的光環區域內爆炸。你有 50% 機率立即前往隨機存在位面，避開爆炸；若未避開，你受到等於法杖剩餘充能數 16 倍的力場傷害。區域內其他每名生物須進行 DC 17 敏捷豁免；失敗受到等於法杖剩餘充能數 4 倍的力場傷害，成功則受一半傷害。
