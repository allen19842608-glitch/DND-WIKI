# 魅惑法杖 (Staff of Charming)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：**施展法術 Cast Spell**。你可以消耗1 充能，從法杖中施展_魅惑類人 Charm Person_、_命令術 Command_、或_通曉語言 Comprehend Language_ ，該法術使用你自己的法術豁免 DC。

- **惑控反射**：
  - **啟用／觸發**：持握期間。
  - **效果**：**惑控反射 Reflect Enchantment**。如果一道惑控學派法術僅以你為目標，而你豁免成功時，你可以執行**反應**並消耗1 充能，將法術反射給原施法者，如同你施展了這道法術一般。

- **惑控抵抗**：
  - **啟用／觸發**：持握期間。
  - **效果**：**惑控抵抗 Resist Enchantment**。如果一道惑控學派法術僅以你為目標，而你豁免失敗時，你可以將失敗的豁免改為成功。法杖的這項詞條一經使用，其直至下個黎明前都無法再次使用。
  - **限制與恢復**：法杖的這項詞條一經使用，其直至下個黎明前都無法再次使用。

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges**。這根法杖在每日黎明時重獲1d8+2已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將崩解為塵土，並被摧毀。
  - **限制與恢復**：這根法杖在每日黎明時重獲1d8+2已消耗的充能。
