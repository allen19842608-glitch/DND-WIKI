# 魅惑法杖 (Staff of Charming)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要；吟遊詩人、牧師、德魯伊、術士、契術師或法師 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：消耗 1 充能，從法杖施展[[wiki/法術/1環/魅惑類人|魅惑類人]]、[[wiki/法術/1環/命令術|命令術]]或[[法術/1環/通曉語言|通曉語言]]（Comprehend Languages），使用你自己的法術豁免 DC。

- **惑控反射**：
  - **啟用／觸發**：持握期間。
  - **效果**：**惑控反射 Reflect Enchantment**。如果一道惑控學派法術僅以你為目標，而你豁免成功時，你可以執行**反應**並消耗1 充能，將法術反射給原施法者，如同你施展了這道法術一般。

- **惑控抵抗**：
  - **啟用／觸發**：持握期間。
  - **效果**：如果一道惑控學派法術僅以你為目標，而你豁免失敗時，你可以將失敗的豁免改為成功。
  - **限制與恢復**：此能力使用後，直到下個黎明前無法再次使用。

### 使用、充能與恢復

- **充能總量**：法杖具有 10 充能。

- **恢復與耗盡**：**重獲充能 Regaining Charges**。這根法杖在每日黎明時重獲1d8+2已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將崩解為塵土，並被摧毀。
