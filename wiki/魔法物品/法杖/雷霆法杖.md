# 雷霆法杖 (Staff of Thunder and Lightning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **電閃**：
  - **啟用／觸發**：持握期間。
  - **效果**：**電閃 Lightning**。當你用法杖發動近戰攻擊並命中時，你可以對目標造成額外2d6點閃電傷害（無需動作）。

- **雷鳴**：
  - **啟用／觸發**：持握期間。
  - **效果**：**雷鳴 Thunder**。當你用法杖發動近戰攻擊並命中時，你可以讓法杖爆發出距你300 呎內都能聽見的雷霆巨響（無需動作）。被你擊中的目標必須通過一次 DC 17的體質豁免，否則陷入**震懾**狀態，持續至你的下個回合結束。

- **雷霆**：
  - **啟用／觸發**：持握期間。
  - **效果**：**雷霆 Lightning and Thunder**。當你用法杖發動近戰攻擊並命中時，你可以立刻執行附贈動作來同時使用電閃和雷鳴詞條（見上文）。這樣做只會消耗雷霆詞條的使用次數，而不會消耗電閃或雷鳴的使用次數。

- **閃電打擊**：
  - **啟用／觸發**：持握期間。
  - **效果**：**閃電打擊 Lightning Strike**。你可以執行**魔法**動作，讓法杖從尖端射出一道覆蓋寬5 呎，長120 呎線狀區域的閃電束。所有在該線狀區域內的生物都需要進行 DC 17的敏捷豁免，豁免失敗則其受到9d6閃電傷害，豁免成功則傷害減半。

- **鳴雷破**：
  - **啟用／觸發**：持握期間。
  - **效果**：**鳴雷破 Thunderclap**。你可以執行**魔法**動作，讓法杖製造一記在你600 呎內都能聽見的驚雷聲響。源自你的60 呎光環區域內的所有生物都需要進行 DC 17的體質豁免。豁免失敗則其受到2d6雷鳴傷害並陷入**耳聾**狀態，持續1分鐘；豁免成功則僅受半傷。
  - **限制與恢復**：豁免失敗則其受到2d6雷鳴傷害並陷入**耳聾**狀態，持續1分鐘；豁免成功則僅受半傷。
