# 蝰蛇法杖 (Staff of The Adder)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **命中效果**：
  - **啟用／觸發**：持握期間。
  - **效果**：以一個**附贈動作**，你可以將法杖的頭部變為一條會動的毒蛇，持續一分鐘，或直至你執行**附贈動作**將法杖還原為非活化形態。

- **攻擊檢定加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：當你執行攻擊動作時，你可以使用觸及5 呎的活化蛇頭來發動其中一次攻擊檢定。這次攻擊檢定使用你的熟練加值與感知調整值。命中時，目標將受到1d6穿刺傷害與3d6毒素傷害。

- **生命恢復**：
  - **啟用／觸發**：持握期間。
  - **效果**：蛇頭在活化期間可以被攻擊。它具有 AC15，HP20，免疫毒素與心靈傷害。蛇頭的生命值降為0時法杖將被摧毀。只要法杖未被摧毀，它就會在還原為非活化形態時恢復所有失去的生命值。
