# 鮮花法杖 (Staff of Flowers)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根木製法杖具有10 充能。持握此法杖期間，你可以執行**魔法**動作並消耗1 充能，使你周身5 呎內的一小塊地面、土壤或從法杖裡綻放出一朵鮮花。如果你未指定花朵的品種，法杖則會創造出帶有清香的雛菊。花朵是無害且非魔法性的，並且會如常生長或枯萎。

### 使用、充能與恢復

- **恢復與耗盡**：**重獲充能 Regaining Charges** 。這根法杖在每日黎明時重獲1d6+4已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將化為花瓣並且永久消失。
