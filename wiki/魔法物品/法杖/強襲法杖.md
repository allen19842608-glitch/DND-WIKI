# 強襲法杖 (Staff of Striking)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 法杖 |
| 稀有度 (Rarity) | 極珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **攻擊與傷害加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖可被用作一根魔法長棍（用這根長棍發動的攻擊檢定和傷害擲骰獲得+3加值）。

- **充能效果**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根法杖具有10 充能。當你用其發動近戰攻擊並命中時，你可以消耗至多3 充能。每消耗1 充能都將額外造成1d6力場傷害。

### 使用、充能與恢復

- **恢復與耗盡**：**重獲充能 Regaining Charges** 。這根法杖在每日黎明時重獲1d6+4已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，法杖將變為一根非魔法性的長棍。
