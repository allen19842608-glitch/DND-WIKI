# 召喚泰坦卷軸 (Scroll of Titan Summoning)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 卷軸 |
| 稀有度 (Rarity) | 傳說 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **召喚泰坦**：
  - **啟用／觸發**：使用一個**魔法**動作閱讀此卷軸。
  - **效果**：卷軸指定的泰坦出現在你 1 里內、地面或水中的未佔據空間。DM 選擇合適的泰坦，或依下表隨機決定。泰坦對其他所有生物態度敵對，並在生命值降至 0 時消失。
  - **限制與恢復**：若召喚空間不足以容納該泰坦，召喚失敗且卷軸被浪費。
