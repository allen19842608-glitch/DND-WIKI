# 法術卷軸 (Spell Scroll)

| 項目 | 內容 |
| :--- | :--- |

| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：閱讀時。
  - **效果**：如果這道法術在你的法術列表中，但其環階高於你當前能施展的水平，則你必須使用你的施法屬性進行一次屬性檢定，以決定是否可以施展這道法術，DC 等於10+這道法術的環階。如果檢定失敗，則卷軸上記載的法術會消失，並且不會產生任何效果。
  - **限制與恢復**：如果檢定失敗，則卷軸上記載的法術會消失，並且不會產生任何效果。

- **法術豁免 DC 與攻擊加值**：
  - **啟用／觸發**：閱讀時。
  - **效果**：卷軸所記載法術的法術環階決定了這道法術的豁免 DC 和攻擊加值，以及卷軸的稀有度，如下表所示：

- **將卷軸抄錄入法術書**：
  - **啟用／觸發**：閱讀時。
  - **效果**：**將卷軸抄錄入法術書 Copying a Scroll into a Spellbook** 。法術卷軸上的法師法術可以被抄錄入法術書中。以此方式抄錄法術時，抄錄者必須進行一次 DC 等於10+這道法術環階的智力（奧秘）檢定。檢定成功時便能完成法術的抄錄。無論檢定成功與否，該法術卷軸都會被摧毀。
