# 法術卷軸 (Spell Scroll)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 卷軸 |
| 稀有度 (Rarity) | 多種稀有度 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **閱讀與施展卷軸法術**：
  - **啟用／觸發**：卷軸所記法術在你的法術列表中，且你閱讀卷軸施展該法術時。
  - **效果**：卷軸以神秘暗語記載一道法術。符合上述條件時，你可施展該法術，無須提供材料成分；施法仍使用該法術的正常施法時間。不在你的法術列表中的卷軸無法理解。若該法術環階高於你通常能施展的環階，須以你的施法屬性進行一次 DC 等於 10＋法術環階的屬性檢定，決定是否成功施展。
  - **限制與恢復**：法術施展後卷軸化為塵土。若施法中斷，卷軸不會消失；若上述檢定失敗，卷軸上的法術消失且不產生效果。

- **法術豁免 DC 與攻擊加值**：
  - **效果**：卷軸所記載法術的環階決定其稀有度、法術豁免 DC 與攻擊加值，如下表所示。

- **將卷軸抄錄入法術書**：
  - **啟用／觸發**：將卷軸上的一環或更高環階法師法術抄錄入法術書時；須符合[[職業/法師|法師]]抄錄法術的準備條件。
  - **效果**：抄錄者須通過 DC 等於 10＋法術環階的智力（奧秘）檢定；成功時完成抄錄。無論檢定成功與否，卷軸都會被摧毀。
