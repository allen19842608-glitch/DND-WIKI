# 守護卷軸 (Scroll of Protection)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 卷軸 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 是 |

### 物品效果

- **守護光環**：
  - **啟用／觸發**：用一個魔法動作閱讀此卷軸時。
  - **效果**：每張卷軸只針對一種生物類型；由 DM 指定或擲下表決定。你創造一個源自你的 5 呎光環，持續 5 分鐘。指定類型的生物無法進入此區域或影響區域內任何事物。若你的移動使這類生物進入光環，效應結束。光環外 5 呎內的該類生物可用一個魔法動作進行 DC 15 魅力豁免；成功則不再受該光環影響。（來源：城主指南2024，魔法物品詳述，卷軸／珍稀，L6–L22）
