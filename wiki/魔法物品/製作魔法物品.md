# 製作魔法物品 (Crafting Magic Items)

## ⚙️ 規則條文 (Rule Text)

- 製作魔法物品時，製作者與每名助手都必須具有奧秘技能熟練，以及物品類別指定工具的熟練。
- 若物品可讓使用者施展法術，製作者必須在每個製作日準備所有這些法術。
- 每個製作日工作 8 小時，工作日可不連續。一般可由一名助手協助；製作時間除以參與製作的角色數量，DM 可允許更多助手。
- 原料可用性由 DM 決定：城市中有 75% 機率可取得，其他聚居地為 25%；失敗後至少等候 7 日才能再次確認。若物品含有有價格的基底物品，還須支付其完整價格或自行製作該基底。

| 類別 | 所需工具 |
| :--- | :--- |
| 護甲 | 依基底選擇皮匠、鐵匠或織布工具 |
| 藥水 | 煉金工具或草藥工具 |
| 戒指 | 珠寶匠工具 |
| 權杖、法杖或魔杖 | 木雕工具 |
| 卷軸 | 書法工具 |
| 武器 | 依基底選擇皮匠、鐵匠或木雕工具 |
| 奇物 | 修補工具，或基底物品的製作工具 |

| 稀有度 | 時間 | 原料成本 |
| :--- | :--- | :--- |
| 普通 | 5 日 | 50 GP |
| 非普通 | 10 日 | 200 GP |
| 珍稀 | 50 日 | 2,000 GP |
| 極珍稀 | 125 日 | 20,000 GP |
| 傳說 | 250 日 | 100,000 GP |

- 除法術卷軸外，消耗品的時間與成本減半；法術卷軸改用 [[規則/裝備與物件/製作裝備|製作裝備 (Crafting Equipment)]] 的規則。
