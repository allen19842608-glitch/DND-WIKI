# 魔法物品規則 (Magic Item Rules)

## ⚙️ 規則條文 (Rule Text)

- 魔法物品具有其描述列出的魔法效果；除非物品另有規定，啟動物品需要其描述指定的動作、附贈動作或反應。
- 鑑定術可迅速揭示魔法物品的詞條；也可在短休中專注於一件並持續接觸，於短休結束時得知其詞條與使用方式，但不會得知詛咒。這次短休不能同時用於與該物品同調。
- 需要同調的物品須在一次不被中斷的短休中，專注於該物品並持續接觸才會完成同調；一個生物最多同調三件魔法物品，且不能同調多件同一魔法物品。
- 不再符合先決條件、物品位於 100 呎外至少 24 小時、死亡，或另一生物與物品同調時，同調立即結束。除詛咒物品外，亦可在短休中主動結束同調。
- 魔法物品依稀有度分類為普通、非普通、珍稀、極珍稀與傳說；稀有度不等同於角色等級需求，除非物品描述另有規定。（來源：2024 玩家手冊，魔法物品）

### 啟動、充能與消耗品

- 啟動魔法物品通常需要魔法動作；個別物品可能要求命令語、特定使用方式或其他條件。
- 命令語通常是一個字或一句短語，必須能被聽見；在所有聲音都受壓制的區域內，不能以說話方式啟動命令語。
- 若物品讓使用者施展法術，該法術以其最低可用環級或施法者等級施展，不消耗使用者的法術位或成分，除非物品另有規定；需要專注時仍由使用者維持專注。
- 若物品要求使用者的施法屬性，使用者自行選擇其任一施法屬性；沒有施法屬性時，該物品使用其施法屬性調整值 +0，且使用者的熟練加值仍適用。
- 具有充能的物品會依描述消耗與恢復充能。同調者可知悉物品的充能及恢復量；若「下個黎明」在所在世界或位面不會發生，恢復時機由 DM 決定。
- 消耗品啟動後會耗盡或失去魔力。詛咒通常無法以鑑定術等一般鑑定方式察覺；與詛咒物品的同調須先解除詛咒才能結束。

### 稀有度與價格

稀有度大致衡量魔法物品相對的力量，也可作為戰役中買賣的定價參考；賣家仍可能要求服務而非錢幣。若物品含有具購買價格的非魔法基底（如武器或護甲），將基底價格加到魔法物品價格。除法術卷軸外，消耗品價格減半；法術卷軸價格為其抄寫成本的兩倍。

| 稀有度 | 價格 |
| :--- | ---: |
| 普通 | 100 GP |
| 非普通 | 400 GP |
| 珍稀 | 4,000 GP |
| 極珍稀 | 40,000 GP |
| 傳說 | 200,000 GP |
| 神器 | 無價 |

### 耐久性

- 魔法物品至少與同類非魔法物品一樣堅韌。
- 除藥水與卷軸外，絕大多數魔法物品具有全部傷害類型的抗性。
- 神器不受傷害，只有其描述指定的特殊方法可將其摧毀；發現該方法通常需要研究或探索。

### 類別與使用限制

- 魔法物品分為護甲、藥水、戒指、權杖、卷軸、法杖、魔杖、武器與奇物九類。著裝類物品通常必須正確著裝；物品描述可規定例外。
- 護甲與武器可指定其非魔法基底；未指定時由 DM 選擇或隨機決定。魔法武器發射的彈藥，視為魔法性彈藥。
- 物品可設定職業或施法者等同調先決條件；能以自身特性或能力施展至少一道法術的生物，符合「施法者」先決條件。

### 藥水的使用與混合

- 藥水是消耗品。飲用藥水，或將藥水施用於另一名生物，均需要一個**附贈動作**。塗抹油狀藥水可能需要其物品描述指定的更長時間。使用後藥水立即生效並耗盡。
- 將兩種藥水混在一起時擲 d100，依下表決定結果；每多加入一種藥水，再擲一次。除非效果立即可見，否則等到效果顯現才揭示結果。（來源：2024《地下城主指南》，魔法物品的類別，L25–43。）

| d100 | 混合結果 |
| :---: | :--- |
| 01 | 兩種藥水都失效，混合物在自身周圍 5 呎半徑爆炸；區域內每個生物受到 4d10 點力場傷害。 |
| 02–08 | 兩種藥水都失效，混合物變成由 DM 選擇的一種服用型毒藥。 |
| 09–15 | 兩種藥水都失效。 |
| 16–25 | 其中一種藥水失效。 |
| 26–35 | 兩種藥水均生效，其數值效果與持續時間減半；若某種藥水既無數值效果、也無持續時間，則該藥水失效。 |
| 36–90 | 兩種藥水均正常生效。 |
| 91–99 | 兩種藥水均生效，其數值效果與持續時間加倍；若兩者都沒有可加倍之處，則正常生效。 |
| 00 | 只有一種藥水生效，但其效果成為永久；DM 選擇適合永久化的效果。DM 可裁定[[法術/3環/解除魔法\|解除魔法]]或類似法術終止持續中的效果。 |
