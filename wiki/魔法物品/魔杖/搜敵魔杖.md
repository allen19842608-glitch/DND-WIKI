# 搜敵魔杖 (Wand of Enemy Detection)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **隱形**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根魔杖具有7 充能。持握它時，你可以執行**魔法**動作並消耗1 充能。在一分鐘內，你可以知道位於你60 呎內離你最近的敵對生物所在的方向，但不知道距離。魔杖可以感知肉眼可見的敵對生物，也可以感知到**隱形**、以太化、偽裝、躲藏的敵對生物。效應在你不再持握這根魔杖時終止。

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges**。這根魔杖在每日黎明時重獲1d6+1已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將化作飛灰並被摧毀。
  - **限制與恢復**：這根魔杖在每日黎明時重獲1d6+1已消耗的充能。
