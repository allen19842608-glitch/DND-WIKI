# 搜敵魔杖 (Wand of Enemy Detection)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **偵測敵人**：
  - **啟用／觸發**：持握期間；以一個**魔法**動作消耗 1 充能。
  - **效果**：持續 1 分鐘，你知道 60 呎內離你最近的敵對生物所在方向，但不知道距離。魔杖可感知可見、**隱形**、以太化、偽裝或躲藏的敵對生物；不再持握魔杖時，效果結束。

### 使用、充能與恢復

- **充能／使用次數**：7 充能；每次偵測消耗 1 充能。
- **恢復**：每日黎明時重獲 1d6 + 1 已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖化為飛灰並被摧毀。
