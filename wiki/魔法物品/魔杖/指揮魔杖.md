# 指揮魔杖 (Wand of Conducting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **管絃樂**：
  - **啟用／觸發**：持握期間；以一個**魔法**動作消耗 1 充能並揮舞魔杖。
  - **效果**：創造可在 120 呎內聽見的管絃樂；停止揮舞魔杖時，音樂結束。

### 使用、充能與恢復

- **充能／使用次數**：3 充能；每次創造管絃樂消耗 1 充能。
- **恢復**：每日黎明時重獲所有已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖在悲傷的低音號聲中化為飛灰並被摧毀。
