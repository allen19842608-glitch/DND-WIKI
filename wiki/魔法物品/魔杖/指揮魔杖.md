# 指揮魔杖 (Wand of Conducting)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges** 。這根魔杖在每日黎明時重獲所有已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將在悲傷的低音號聲中化作飛灰並被摧毀。
  - **限制與恢復**：這根魔杖在每日黎明時重獲所有已消耗的充能。
