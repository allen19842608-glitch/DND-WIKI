# 探秘魔杖 (Wand of Secrets)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **偵測密門與陷阱**：
  - **啟用／觸發**：持握期間，以一個**魔法**動作消耗 1 充能。
  - **效果**：若你 60 呎內有密門或陷阱，魔杖跳動並指向離你最近的一個。

### 使用、充能與恢復

- **充能／使用次數**：3 充能；每次使用此效果消耗 1 充能。
- **恢復**：每日黎明時重獲 1d3 已消耗的充能。
