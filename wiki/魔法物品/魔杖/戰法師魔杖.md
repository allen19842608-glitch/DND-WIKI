# 戰法師魔杖 (Wand of The War Mage，+1、+2、+3)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 非普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **法術攻擊加值**：
  - **啟用／觸發**：持握期間。
  - **效果**：持握這根魔杖時，你的法術攻擊檢定獲得加值，加值大小取決於魔杖的稀有度。此外，你在進行法術攻擊檢定時無視半身掩護。
