# 恐懼魔杖 (Wand of Fear)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：你可以從此杖施展下列法術（法術豁免 DC 15）。

#### 可施展法術與充能

| 法術 | 充能消耗 |
| :--- | ---: |
| [[法術/1環/命令術\|命令術 (Command)]]（僅能命令走開或趴下） | 1 |
| [[法術/3環/恐懼術\|恐懼術 (Fear)]]（範圍改為 60 呎錐形） | 3 |

### 使用、充能與恢復

- **充能／使用次數**：7 充能；依上表消耗充能。
- **恢復**：每日黎明時重獲 1d6 + 1 已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖化為飛灰並被摧毀。
