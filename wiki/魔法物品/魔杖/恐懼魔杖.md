# 恐懼魔杖 (Wand of Fear)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **充能效果**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根魔杖具有7 充能。

- **法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：**法術 Spells**。持握這根魔杖時，你可以從中施展下列表格中的一道法術（豁免 DC 15）。施展對應法術所需消耗的充能數如表格所示。

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges**。這根魔杖在每日黎明時重獲1d6+1已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將化作飛灰並被摧毀。
  - **限制與恢復**：這根魔杖在每日黎明時重獲1d6+1已消耗的充能。
