# 閃電束魔杖 (Wand of Lightning Bolts)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要（施法者） |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **可施展法術**：
  - **啟用／觸發**：持握期間；消耗 1 至 3 充能施展。
  - **效果**：你可以從此杖施展[[wiki/法術/3環/閃電束|閃電束 (Lightning Bolt)]]（法術豁免 DC 15）。消耗 1 充能時以三環版本施展；每額外消耗 1 充能，法術環階提高一環。

### 使用、充能與恢復

- **充能／使用次數**：7 充能；每次施展消耗 1 至 3 充能。
- **恢復**：每日黎明時重獲 1d6 + 1 已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖化為飛灰並被摧毀。
