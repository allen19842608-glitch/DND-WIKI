# 閃電束魔杖 (Wand of Lightning Bolts)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根魔杖具有7 充能。持握它時，你可以消耗最多3 充能從中施展_閃電束 Lighting Blot_ （豁免 DC 15）。你可以用1 充能施展3環版本的法術；每多消耗1 充能，法術的環位就將提升1環。
  - **限制與恢復**：持握它時，你可以消耗最多3 充能從中施展_閃電束 Lighting Blot_ （豁免 DC 15）。

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges**。這根魔杖在每日黎明時重獲1d6+1已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將化作飛灰並被摧毀。
  - **限制與恢復**：這根魔杖在每日黎明時重獲1d6+1已消耗的充能。
