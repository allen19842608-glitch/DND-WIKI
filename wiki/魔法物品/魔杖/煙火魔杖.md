# 煙火魔杖 (Wand of Pyrotechnics)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 普通 |
| 同調 (Attunement) | 不需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **煙火**：
  - **啟用／觸發**：持握期間；以一個**魔法**動作消耗 1 充能。
  - **效果**：在你 120 呎內一處你可見的位置創造一束無害的多彩亮光。亮光迸發時伴隨可在 300 呎內聽見的響亮爆鳴聲；亮度如火把，但僅持續 1 秒。

### 使用、充能與恢復

- **充能／使用次數**：7 充能；每次創造煙火消耗 1 充能。
- **恢復**：每日黎明時重獲 1d6 + 1 已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖化為飛灰並被摧毀。
