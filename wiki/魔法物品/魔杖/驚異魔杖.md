# 驚異魔杖 (Wand of Wonder)

| :--- | :--- |

| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **施展法術**：
  - **啟用／觸發**：持握期間。
  - **效果**：這根魔杖具有7 充能。持握它時，你可以執行**魔法**動作並消耗1 充能，並選擇位於你120 呎內的一點。那個位置變為由驚異魔杖效應表中骰出的法術或其他魔法效應的源點。從魔杖中施展的法術的豁免 DC 為15。如果一個法術的最大射程在正常情況下不足120 呎，則當被魔杖釋放時其射程變為120 呎。若一種效應有多個可選目標，則 DM 隨機決定其中哪個目標將被效應影響。

- **重獲充能**：
  - **啟用／觸發**：持握期間。
  - **效果**：**重獲充能 Regaining Charges**。這根魔杖在每日黎明時重獲1d6+1已消耗的充能。當充能數耗盡時，骰一次 d20。如果骰值為1，魔杖將化作飛灰並被摧毀。
  - **限制與恢復**：這根魔杖在每日黎明時重獲1d6+1已消耗的充能。
