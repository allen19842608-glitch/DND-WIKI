# 驚異魔杖 (Wand of Wonder)
## ⚙️ 規則條文 (Rule Text)

### 物品資料

| 項目 | 內容 |
| :--- | :--- |
| 類別 (Category) | 魔杖 |
| 稀有度 (Rarity) | 珍稀 |
| 同調 (Attunement) | 需要 |
| 消耗品 (Consumable) | 否 |

### 物品效果

- **驚異效應**：
  - **啟用／觸發**：持握期間；以一個**魔法**動作消耗 1 充能，並選擇 120 呎內一點。
  - **效果**：選定位置成為擲出之驚異魔杖效應的源點。其法術豁免 DC 為 15；由魔杖施展且通常最大射程不足 120 呎的法術，射程改為 120 呎。若效應有多個可選目標，由 DM 隨機決定受影響目標。

### 使用、充能與恢復

- **充能／使用次數**：7 充能；每次產生驚異效應消耗 1 充能。
- **恢復**：每日黎明時重獲 1d6 + 1 已消耗的充能。
- **耗盡與風險**：充能耗盡時擲 d20；若擲出 1，魔杖化為飛灰並被摧毀。
