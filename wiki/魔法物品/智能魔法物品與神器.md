# 智能魔法物品與神器 (Sentient Magic Items and Artifacts)

## ⚙️ 規則條文 (Rule Text)

### 智能魔法物品

- 智能物品具有智力、感知與魅力、陣營、溝通方式、感官與特殊目標；一次性物品不能是智能物品。
- 智能物品與其啟動特性由 DM 控制。持有者與物品關係不佳或違背其特殊目標時，可能引發反噬。

### 神器

- 神器是獨一無二、極其稀有且具歷史意義的強大魔法物品，通常作為戰役或冒險的劇情核心，而不是一般戰利品。
- 除自身描述外，神器最多可有 4 項次要與 2 項主要增益詞條，也最多可有 4 項次要與 2 項主要減益詞條；重新現世時，這些詞條通常會改變。

### 神器隨機詞條表（2024）

下列四表適用於引用 2024《地下城主指南》第七章神器詞條的物品。擲 d100 時，表中的「00」代表 100；實際詞條數量依各物品描述決定。（來源：`原始資料/地下城主指南2024/第七章_寶藏/魔法物品/神器.md` L9–76。）

#### 次要增益詞條 Minor Beneficial Properties

| **1D100 骰值** | **詞條** |
| --- | --- |
| 01-20 | 在與該神器同調期間，你獲得一項由 DM 所選擇的技能熟練。 |
| 21-30 | 在與該神器同調期間，你具有對中毒狀態的免疫。 |
| 31-40 | 在與該神器同調期間，你具有對魅惑狀態與恐慌狀態的免疫。 |
| 41-50 | 在與該神器同調期間，你具有對由 DM 所選擇的一項傷害類型的抗性。 |
| 51-60 | 在與該神器同調期間，你可以從該神器中施展一道戲法（戲法由 DM 選擇）。 |
| 61-70 | 在與該神器同調期間，你可以從該神器中施展一道1環法術（法術由 DM 選擇）。在你施展該法術後，擲1d6。若結果為1-5，則直至下個黎明，你無法再次以此法施展該法術。 |
| 71-80 | 如61-70一行所述，除了把法術環階改為2環。 |
| 81-90 | 如61-70一行所述，除了把法術環階改為3環。 |
| 91-00 | 在與該神器同調期間，你的護甲等級獲得+1加值。 |

#### 主要增益詞條 Major Beneficial Properties

| **1D100 骰值** | **詞條** |

| 01-20 | 在與該神器同調期間，你的一項屬性值（由 DM 選擇）提升2，最多為24。 |
| 21-30 | 在與該神器同調期間，若你具有至少1點生命值，則你在你的每個回合開始時，恢復1d6生命值。 |
| 31-40 | 在與該神器同調期間，當你的攻擊檢定命中時，目標將額外受到1d6力場傷害。 |
| 41-50 | 在與該神器同調期間，你的速度提升10尺。 |
| 51-60 | 在與該神器同調期間，你可以從該神器中施展一道4環法術（法術由 DM 選擇）。在你施展該法術後，擲1d6。若結果為1-5，則直至下個黎明你無法再次以此法施展該法術。 |
| 61-70 | 如51-60一行所述，除了把法術環階改為5環。 |
| 71-80 | 如51-60一行所述，除了把法術環階改為6環。 |
| 81-90 | 如51-60一行所述，除了把法術環階改為7環。 |
| 91-00 | 在與該神器同調期間，你具有對目盲、耳聾、石化以及震懾狀態的免疫。 |

| **1D100 骰值** | **詞條** |
