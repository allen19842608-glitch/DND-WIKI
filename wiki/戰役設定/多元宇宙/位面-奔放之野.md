# 奔放之野

## ⚙️ 設定資料


### 位面特徵

- **激情自然**：奔放之野有壯闊山林、峽谷、果園與田野；精魂棲息各處，風暴與樂聲同樣突然而強烈。
- **情感本質**：善良居民以坦率、強烈的情緒生活，喜悅、愛、憤怒與戰意都可迅速高漲。

### 三個位層

| 位層 | 設定摘要 |
| --- | --- |
| 繁林野阿梵多 | 巨木、野花、作物與果實構成豐饒樂土。 |
| 永浪野阿誇羅 | 海神河與永恆汪洋孕育海洋生物及強風暴。 |
| 銀沙野米薩迪爾 | 神祇曾駐足的無垠白沙荒漠。 |

### 冒險主題

- **真實情感與渴望**：讓角色面對無法掩飾的情緒、離去後的思鄉，以及銀沙野遺留的神祇祕密。
