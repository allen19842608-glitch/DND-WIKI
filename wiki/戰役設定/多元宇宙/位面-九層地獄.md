# 九層地獄

## ⚙️ 設定資料


### 位面特徵

- **秩序的邪惡**：九層地獄是魔鬼的領域，由九個向下遞降的位層構成。其社會以契約、階級與懲罰維繫，血戰的軍團亦由此出征。
- **腐化與交易**：地獄以誘惑、交易與服從為主題；位面的惡意會成為訪客的長期風險。

### 九重位層

| 位層 | 設定摘要 |
| --- | --- |
| 禽絕地獄阿弗納斯 | 血戰前線與墜毀戰爭機器遍布的荒原。 |
| 焱鐵地獄迪斯 | 焱鐵大公統治的鐵城與陰謀中心。 |
| 腐沼地獄彌瑙洛斯 | 酸雨、泥沼與財富囤積之地。 |
| 赫炎地獄弗萊格索斯 | 火焰、酷刑與欲望的領域。 |
| 悲憎地獄斯泰吉亞 | 凍海、背叛與冰封祕密。 |
| 崩縛地獄瑪爾伯吉 | 滑落巨石與被壓迫靈魂的山體。 |
| 墮律地獄瑪拉多米尼 | 毀壞城市、廢墟與官僚統治。 |
| 霜秘地獄卡尼亞 | 極寒、奧術祕密與野心。 |
| 無間地獄奈瑟斯 | 地獄最深層，阿斯摩蒂爾斯的權力核心。 |

### 階級與冒險主題

- **地獄階級**：魔鬼以嚴密階層運作，契約與恩惠往往同時是誘惑與枷鎖。
- **冒險主題**：角色可在血戰、救援墮落靈魂、破解魔鬼契約或地獄權力鬥爭中行動；任何交易都應清楚呈現其代價。
