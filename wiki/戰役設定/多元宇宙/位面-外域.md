# 外域

## ⚙️ 設定資料


### 位面特徵

- **中立圓盤**：外域位於外層位面中央，呈巨大圓盤，兼容多樣地貌並象徵彼此拉扯的平衡。
- **十六門鎮**：圓盤邊緣的每座門鎮都圍繞一座通向外層位面的傳送門，並帶有其目的地的性質；各位面使者在此頻繁往來。

### 門鎮目的地

| 門鎮 | 連接位面 |
| --- | --- |
| 自動鎮、瘋人院、詛咒獄、喜樂界 | 機械境、喧癲空隧、卡瑟利、極樂境 |
| 精益城、百獸鄉、堅定園、榮光灣 | 天堂山、萬獸園、世外桃源、伊斯加德 |
| 絕望坑、瘟疫沼、肋骨籠、悍鬥堡 | 哈迪斯、無底深淵、九層地獄、修羅場 |
| 林野苑、烽炬山、商貿門、混沌渦 | 奔放之野、焦炎火獄、雙生天堂、混沌海 |

### 冒險主題

- **位面衝突的交會點**：外域適合讓各陣營在同一地點競爭、交易或交涉，也適合以維持自然與宇宙平衡為目標。
