# 焦炎火獄

## ⚙️ 設定資料


### 位面特徵

- **火山斜坡**：焦炎火獄每層都是巨大火山，幾乎所有地面至少有 45° 坡度；陡崖、峽谷、毒氣與火焰裂縫令旅行格外危險。
- **尤格羅斯魔家園**：貪婪自私的尤格羅斯魔在此大量活動，位面的主題是猜忌、交易與背叛。

### 四個位層

| 位層 | 設定摘要 |
| --- | --- |
| 巖熔峰卡拉斯 | 冥河旁的熔岩、火山灰與蒸汽。 |
| 烈塵峰查瑪達 | 灰燼雨下，尤格羅斯魔鐵製飛艇穿行熔岩。 |
| 酸雪峰蒙戈斯 | 酸性火山灰與降雪同落。 |
| 火寂峰克蘭戈斯 | 寂靜黑暗中的巨大火山，藏有巫妖。 |

### 冒險主題

- **誰都不能信任**：淚滴宮的危險交易、奧法魔塔的祕密與偽裝求助者，都可迫使隊伍在猜忌中做出選擇。
