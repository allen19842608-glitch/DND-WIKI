# 諸位面

## ⚙️ 設定資料

### 分類

| 類別 | 構成與角色 |
| --- | --- |
| 物質界域 | 物質位面及其兩個迴響：妖精荒野、墮影冥界。 |
| 中轉位面 | 以太位面與星光位面，是跨位面旅行的廣闊通路。 |
| 內層位面 | 氣、土、火、水四元素位面與四個次生元素位面。 |
| 外層位面 | 十七個以道德、哲學與思想為本質的位面。 |
| 正負位面 | 包裹宇宙的生命與死亡原始力量。 |

### 巨輪與其他結構

- **巨輪**：將物質界域置於中心，內層位面、以太位面與外層位面依序環繞，外域連接外層位面。這是有用的模型，而不是可以由凡人直接觀察的宇宙地圖。
- **替代模型**：DM 可採用世界樹、星光／元素上下分層、精簡位面組合，或讓位面繞物質位面運轉的模型。

### 物質界域與內層位面

- **平行迴響**：妖精荒野與墮影冥界和物質位面重疊，地貌相似但分別更奇幻或更陰鬱；偶然穿越可能發生。
- **元素邊緣與外側**：元素位面近物質位面的區域較像尋常世界；遠離後則成為近乎純粹、惡劣的元素領域。最外側為元素混沌。

### 外層位面與位層

- **思想成形**：外層位面是天族、邪魔與神祇的居所，也是善惡、秩序與混沌的實體化。不同陣營的訪客可能感受與位面不協調。
- **位層不是一般地圖**：多層位面可被描述為階梯、山峰、球體或其他比喻；距離與範圍會隨位面意志或強大存在而改變。外來傳送門通常抵達第一層。

### 位面失諧

- 天族在下層位面、邪魔在上層位面完成長休後，須作 DC 10 體質豁免。失敗時 D20 檢定減少 1d4；重複失敗會累加。回到不違反其天性的位面完成長休後，效應結束。
- 長期停留在外層位面的生物也可能逐漸認同該處道德觀念；這是由 DM 建議、交由玩家扮演的敘事影響。
