# 修羅場

## ⚙️ 設定資料


### 位面特徵

- **漂浮鐵塊**：巨大鐵塊飄浮於虛空，偶爾猛烈相撞並粉碎夾在其中的一切；其四層由下而上，鐵塊逐漸巨大。
- **戰爭衝動**：位面本質會喚起訪客的嗜血慾望。

### 四個位層

| 位層 | 設定摘要 |
| --- | --- |
| 戰魂墟阿瓦拉斯 | 靈體士兵在殘骸遍地的戰場進行無盡戰爭。 |
| 遺械墟圖爾達寧 | 空心立方體收藏大量廢棄戰爭機器。 |
| 冥憶墟丁提布魯斯 | 黑暗中翻滾的鋸齒巨塊封存被冥河奪去的記憶。 |
| 寒淵墟奧坎瑟斯 | 黑冰沼澤上方盤旋著鋒利碎片。 |

### 冒險主題

- **軍令與同化**：修羅場以無止盡的衝突呈現強制秩序；可用於探問角色為何而戰。
- **冒險鉤子**：阻止反派回收戰爭殘骸，或從冥憶墟取回被封存的思維與記憶。
