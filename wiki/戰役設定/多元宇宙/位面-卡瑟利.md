# 卡瑟利

## ⚙️ 設定資料


### 位面特徵

- **隔離與絕望**：卡瑟利是背叛者與陰謀家的監獄位面，六層地貌由沼澤、密林、沙漠、山脈、酸洋至黑冰凍原遞變。
- **難以逃離**：除祈願術外，以法術離開的嘗試失敗；傳送門與通道只可單向進入。傳聞中的逃路受到機關與怪物守護，冥河航段亦極危險。

### 六個位層

| 位層 | 設定摘要 |
| --- | --- |
| 沙沼獄奧瑟瑞斯 | 冥河穿越無邊沼澤與流沙。 |
| 朽瘴獄卡瑟瑞斯 | 猩紅平原與腐臭密林瀰漫腐敗氣息。 |
| 嵐漠獄米奈瑟斯 | 沙暴掩埋古老流沙城遺址。 |
| 刃淵獄科洛瑟斯 | 深淵與山巒交錯，行進困難。 |
| 蝕瀛獄波法提斯 | 黑雪落入冰冷酸洋。 |
| 黯冰獄艾嘉西斯 | 帶血紅紋痕的黑冰覆蓋全境。 |

### 冒險主題

- **囚禁與救贖**：營救蒙冤靈魂、流放神祇或尋找逃路；冒險的核心阻力是絕望、背叛與難以合作。
