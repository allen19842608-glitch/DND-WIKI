# 無底深淵

## ⚙️ 設定資料


### 位面特徵

- **無窮混亂與腐化**：無底深淵由近乎無窮的位層向下螺旋，每層皆更詭異險惡。其腐化本質會影響訪客，相關效果見詛咒與魔法疾病規則。
- **位層編號**：編號來自印記城探險者的發現與編目，不代表深淵位層存在有序結構。

### 知名位層

| 位層 | 設定摘要 |
| --- | --- |
| 萬淵平原（第 1 層） | 佈滿通往其他層與其他位面的傳送門，是深入或逃離深淵的門戶。 |
| 墮域阿茲格拉特（第 45–47 層） | 格拉茲特的三重領域，以奢華、操弄與陷阱聞名。 |
| 蜘蛛魔網（第 66 層） | 羅絲的魔法蛛網捕獲物件與文明碎片，隱藏跨位面傳送門。 |
| 裂淵巨口（第 88 層） | 狄摩高根統治的叢林、海洋與雙塔堡壘。 |
| 冥歿荒土塔納托斯（第 113 層） | 奧喀斯的亡靈荒原與巨大墓場。 |
| 軟泥深坑（第 222 層） | 朱庇萊克斯與祖格莫伊支配的泥怪、真菌與腐敗之地。 |
| 死亡谷地、無盡迷宮 | 分別是耶諾古的荒原與巴弗滅的迷城獵場。 |

### 冒險主題

- **混亂的代價**：深淵冒險適合面對惡魔領主、腐化與無序；每個位層都應以自己的危險環境和支配者塑造不同任務。
