# 次生元素位面

## ⚙️ 設定資料


### 位面特徵

- **元素交界**：四個次生元素位面位於元素位面的邊界，呈現兩種元素相互融合或相互衝突的極端環境。

### 四個次生位面

| 位面 | 相鄰元素與設定摘要 |
| --- | --- |
| 灰燼位面 | 氣與火交界的火焰、煙塵與灰燼風暴；漂浮灰燼島是逃亡者的少數棲身處。 |
| 寒冰位面 | 氣與水交界的永恆冰川與暴風雪，冰窟中棲息寒帶怪物。 |
| 熔岩位面 | 土與火交界的連綿火山；火矮人、火巨人與紅龍在此活動。 |
| 軟泥位面 | 水與土交界的腐沼。傳說投入沼中的物品百年內無法尋回，吸引尋寶者與藏匿神器者。 |

### 冒險主題

- **元素互動**：次生位面將元素的共性、對立與變化具體化；環境本身可成為探索、求生與尋寶的主要挑戰。
