# 極樂境

## ⚙️ 設定資料


### 位面特徵

- **自在善意**：極樂境是自由善良靈魂與尋求庇護者的田園樂土，生命與美景在此格外旺盛。
- **海神河**：河流由最深處的英靈境發源，貫穿各層後流向萬獸園；穿越位層的感受如逆流激湍，仍可順暢航行。

### 四個位層

| 位層 | 設定摘要 |
| --- | --- |
| 惠原境艾默瑞亞 | 河岸小鎮與繁茂草原相伴。 |
| 靜泉境貝爾利安 | 河水環繞的森林聖域。 |
| 翠峙境歐羅伯洛斯 | 多彩山峰與夢幻雲霧。 |
| 英靈境塔拉西亞 | 海神河源頭的寧靜水域。 |

### 冒險主題

- **庇護與行動**：此地可讓角色從戰亂中尋求安全，但真正的善意仍可能要求他們離開樂土、援助他者。
