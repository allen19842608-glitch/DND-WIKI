# 半龍

## 設定資料

**半龍 Half Dragons**

正如龍的繁殖不一定是一個簡單的生物學問題一樣，半龍也可能是通過各種方式產生的。下面的半龍起源表為你提供了一些例子。

龍出於各種原因創造了半龍後代。有些龍創造半龍是為了獲得可靠的手下。其他龍則在他們的巢穴周圍創造半龍子嗣，以使該地區對入侵者更加危險。更多的時候則是，半龍只是自發出現，或者是龍之魔力及影響的額外結果。

在某些世界中，這些現象也可以用來解釋龍裔、狗頭人以及第二章中描述的龍族贈禮的來源。

**半龍起源**

| **D6** | **起源** |
| --- | --- |
| **1** | **區域效應 Regional。**龍之巢穴的魔法影響令半龍自發地出現在該地區的其他生物中。 |
| **2** | **龍之禁果 Forbidden** **Fruit。**龍可以使一棵樹結出神奇的果實。當被能夠生育的生物吃掉果實時，這個生物就將誕下一隻半龍。 |
| **3** | **真愛之禮 True** **Love‘s** **Gift。**愛情偶爾會在龍和其他種類的生物之間萌發，這種生命的連結會產生半龍的子嗣。大多數因愛而生的半龍都是以這種方式來到這個世界的。 |
| **4** | **龍血轉化 Blood** **Transformation。**沐浴龍血中或飲用龍血的生物有時會變成半龍。一條龍可能會自願提供一些血液來滿足這一條件，而當一個屠龍者被濺上龍血時，這種轉變同樣可能產生。 |
| **5** | **龍類賜福 Cradle** **Favor。**龍可以將龍的力量賜予新生兒或未出生的孩子，作為祝福或詛咒。 |
| **6** | **寶庫竊賊 Hoard** **Thieves。**一條老龍的寶藏充滿了龍的力量。而當這種力量滲入染指古龍寶庫的竊賊身上時，這個小偷可能就會變成半龍。 |
