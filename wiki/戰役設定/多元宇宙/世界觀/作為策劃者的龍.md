# 作為策劃者的龍

> [!warning] 劇透警告
> 本頁含有冒險劇情、祕密身分或結局資訊。

## 設定資料

**作為策劃者的龍 Dragon as Schemer**

本書中的大多數冒險引子都涉及到龍在漫長的一生中可能實施的計劃，可能利用追隨者作為世界上的代理人。在實踐中，許多策劃龍的目標可能與上方那些過於危險的龍的目標相同：獲取食物、確保巢穴、增加寶藏。但其他的陰謀可能圍繞著獲取爪牙、推進龍族派系的事業、建立龍的威望、為整個龍族的福祉而努力，或者改變世界的性質和魔法。

當龍的計劃與人物的生活發生交集時，它們就會成為冒險的基礎。最直接的是，人物可能被要求幫助龍的計劃或反對它們。**交鋒理由**表提供了靈感，幫助你把與龍有關的冒險引子變成影響遊戲中人物的冒險。

**交鋒理由**

| **d6** | **龍的計劃......** |
| --- | --- |
| **1** | ...直接針對一個或多個角色。當龍或龍的爪牙與角色對峙時，冒險開始。 |
| **2** | ...威脅到一個角色的牽絆或對一個或多個角色很重要的 NPC。 |
| **3** | ...挑戰一個角色的理想或利用一個缺陷。角色可能會聽到關於龍的活動的傳聞，刺激他們採取行動。 |
| **4** | ....把人物困在衝突的勢力之間。 |
| **5** | ...為人物追求個人目標創造機會。 |
| **6** | ...造成威脅人物的事故或災難。 |

一個以龍的陰謀為主題的冒險通常最適合作為**基於事件的冒險 Event-Based Adventures**，如**_城主指南_**中所述。無論龍是反派、贊助者還是感興趣的旁觀者，都可以利用本章和第五章的表格和建議來充實龍的個性、目標和其他特徵。龍的巢穴可能是冒險的關鍵地點（可以參考或使用第五章的地圖），但龍的計劃也可以把人物帶到任何地方——甚至是其他世界和星球。
