# 生命歷程

> [!warning] 劇透警告
> 本頁含有冒險劇情、祕密身分或結局資訊。

## 設定資料

**生命歷程 Life Span**

_當一條龍將你視為無關緊要的人時，儘量不要感到不快。記住，你面對的可能是三個時代前孵化出來的個體，而並不是每條龍都有智慧看到孤膽英雄如何扭轉歷史的進程。_

_——費資本_

龍的壽命可達一千多年，超過單個國家，甚至是整個文明的興衰。龍對時間流逝的看法自然與更短命的生物有很大不同。但是，就像人物隨著等級的提高而擴大他們的優先事項和視角一樣，龍也會隨著年齡的增長而擴大。

本節中的表格提出了可能的目標，反映了龍在不同年齡段的優先事項。當然，龍的目標是由許多其他因素形成的，包括盟友、理想、紐帶和缺陷。因此，請將下列的內容作為一個起點或框架，在你對龍的個性有了完整的瞭解後再充實每個龍的目標。

**雛龍 Wyrmlings**

與 T1（即1至4級）冒險者一樣，龍在其生命的頭五年裡仍在探索自己的能力極限和自身在這個世界上的位置。因此，雛龍通常依賴成年龍或其他夥伴生物來保證安全。

雛龍最常考慮的是自己領地的規模——不超過幾個農莊或村莊可能覆蓋的區域。如果成年龍正在養育一窩小龍，龍仔們通常會與自己的父母分享領地。因此，雖然雛龍可能只有幾平方英里的領地，但雛龍的存在足以表明其的兄弟姊妹們可能就在附近。另一方面，沒有成年龍看護的雛龍可能會成為其他種類生物的盟友或是俘虜。這樣的雛龍更有可能從它們的同窩手足中分散出去。

**雛龍目標 Wyrmling** **Goals**

| **D6** | **目標** |
| --- | --- |
| **1** | 確立自己獨立於成年龍（或其他強大的生物）的地位。 |
| **2** | 獲得一個有價值的魔法物品或藝術品，以建立一個自己的寶庫。 |
| **3** | 獲得能帶來食物和財寶的奴僕 |
| **4** | 建立對同窩龍仔中其他小龍的統治地位 |
| **5** | 確保與更強大的生物建立夥伴關係，以確保安全 |
| **6** | 為第一個獨立的巢穴找到一個好地方 |

**青年龍 Young** **Dragons**

青年龍步入了其生命中的第一個世紀，在許多方面與 T2（即5至10級）的冒險者相似，他們開始邁入了主物質位面最強大生物的行列。

這個階段是大多數龍首次建立自己的領地和巢穴的時候。一條青年龍的領地可以覆蓋大約50英里的範圍。這個時期，龍也會開始形成將龍與其寶庫及巢穴周圍的地區連結在一起的魔法聯繫。

巡狩中的龍通常會在一天內沿著近似環形的路線飛到其領地的一個邊緣，然後再返回，總共飛行約75英里。青年龍還利用它們的巡狩飛行來視察其領地內發生的事情，並敏銳地觀察那些與它們的領地相鄰或重疊的其他生物。青年龍可以通過公開的暴力與威脅，或是微妙的滲透與操縱來成為一個城市或王國的重大威脅。

**青年龍目標 Young** **Dragon** **Goals**

| **D6** | **目標** |
| --- | --- |
| **1** | 建立一個巢穴，並開發其周圍的土地，以最大限度地保證安全和充足的獵物。 |
| **2** | 收集儘可能多的財寶 |
| **3** | 獲得魔法物品以幫助保護巢穴 |
| **4** | 破壞其他青年龍在當地建立巢穴的努力。 |
| **5** | 通過展示力量贏得住在巢穴附近的其他生物的恐懼和尊重 |
| **6** | 確保忠誠和強大的僕從的效忠 |

**成年龍 Adult** **Dragon**

度過了生命中第一個世紀的成年龍是強大的存在，類似於 T3角色（即11至16級）。成年龍的影響力甚至可以延伸到整個地區乃至大陸。

大多數成年龍會建立其他的巢穴來擴大它們的領地。這些巢穴通常相隔50至75英里，所以龍可以在一天的時間內從一個巢穴飛到另一個巢穴。成年龍通常會在一個巢穴周圍停留狩獵一個月或更長時間，然後再轉移到另一個巢穴。龍與巢穴的魔法聯繫甚至可以改變周圍的自然環境，這一點由區域效應來體現。

**成年龍目標**

| **D6** | **目標** |
| --- | --- |
| **1** | 尋找一處適合建立額外巢穴的地點 |
| **2** | 將一件神器或強大的魔法物品納入庫藏 |
| **3** | 通過養育後代來建立血系王朝 |
| **4** | 淘汰那些長大後可能成為競爭對手或威脅的青年龍。 |
| **5** | 將一個更廣袤的區域改造成龍喜歡並且適合巢穴的環境。 |
| **6** | 發展龍視 dragonsight，在多個世界追求目標 |

**遠古龍 Ancient** **Dragon**

龍一旦達到八百歲就被認為是遠古龍，而他們還能繼續活上幾個世紀。遠古龍是多元宇宙中最強大的生物之一，就像 T4角色（17至20級）一樣，它們強大到足以改變世界的命運，打破整個位面的力量平衡。

一條遠古龍通常有幾個巢穴，每個巢穴都充斥著強大的魔法。而圍繞著古龍巢穴的區域效應甚至可以影響周邊數百公里的自然環境。除了這些魔法效應外，龍的持續存在也會對該地區的生態系統、人口和政治產生深遠影響。

**太古龍 Greatwyrms****。**最古老的遠古龍有時會轉變為有著如神般偉力的神話生物。第6章中描述的這些太古龍是龍類本質近乎完美的化身 avatars，他們洋溢著物質位面的魔力，幾乎是不朽的。許多太古龍都是因遠古龍通過儀式將自身的多個迴響融合為單一的實質性存在而產生，例如傳說中的**阿莎德隆 Ashardalon**和**庫若尼普斯 Chronepsis**。大多數太古龍已然跨越了一千二百個春秋，其寶庫價值數百萬金幣，但在其他方面，他們的目標和觀點與其他古龍相似。

**遠古龍目標**

| **D6** | **目標** |
| --- | --- |
| **1** | 通過成為亡靈或找到足以平替的魔法來避免衰老。 |
| **2** | 通過融合多個世界的迴響或在另一個位面上建立巢穴來超越單一世界物理存在的限制。 |
| **3** | 獲得一個特定的神器，也許是為了完成一套神器（邪惡之神的三個部分，維克那之眼和維克那之手，等等）。 |
| **4** | 收集一套完整的藝術珍品，如某位大師的所有畫作，某位著名作家的全部作品的手稿，或某位工匠大師製作的每件珠寶。 |
| **5** | 將整個世界轉變為適合作為巢穴的極端環境——火山熔岩、凍土苔原、沙漠荒地，或類似的地形。 |
| **6** | 摧毀一個或多個神靈，作為報復或使自己登神的條件。 |

**龍的領地 Dragons and Territory**
隨著龍的年齡增長，它們對領地的認識也在不斷擴大，龍在它們稱之為家的地區建立了多個巢穴。一條龍的領地越大，它就越有可能與另一條龍的領地靠攏或重疊。成年龍或遠古龍的領地常常包括了較為年輕的龍的領地，只要較老的龍不將年輕的龍視為威脅。
落實到一場戰役發生的地區，一個大約50英里寬的區域，如一個男爵的封地或一個小森林，可能包括一個青年龍或更老的龍的領地。
一個橫跨300英里的區域——一個王國或類似大小的地區——可以包含兩到三打龍的領地，只要它們中的大多數是青年龍。然而，同樣大小的土地只能容納三或四條成年龍或遠古龍。一條成年龍可能會允許多達六或八條青年龍（可能包括這條成年龍自己的後代）與自己分享領地，但成年龍通常只允許那些作為自己配偶或作為特殊聯盟或組織的成年龍和自己分享領地。
若是放寬到整個大陸，橫跨約3000英里，也許包括數百條青年龍和幾十條成年龍，但遠古龍只有相當少數。
