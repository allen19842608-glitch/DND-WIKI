# 跨越世界的迴響

> [!warning] 劇透警告
> 本頁含有冒險劇情、祕密身分或結局資訊。

## 設定資料

**跨越世界的迴響 Echos Across the World**

_不需要費什麼力氣就能成就無限。如同蜘蛛依靠眾多眼睛視物，龍就是存在於世，無論是一還是眾。_

_——費資本_

龍與物質位面的魔法和第一世界歷史的獨特聯繫，使其與物質位面無數世界的其他龍有著神秘的聯結。理論上說，每一條曾經存在過的色彩龍、金屬龍和寶石龍在物質位面的每一個世界都有一個獨特的迴響。其中有些迴響彼此非常相似，但有些迴響則有更大的差異。

你可以使用龍之迴響的特徵表來幫助你決定龍的回聲在哪些方面與你所知道的龍相似，哪些方面不同。然後你就可以利用本章中的其他表格（包括**龍類外表**、**龍類舉止**、**龍類牽絆**、**龍類缺陷和秘密**表），以及第五章中的**個性**和**理念**，來幫助你決定一條龍和其迴響間的差異。

**龍之迴響的特性**

| **d8** | **回聲特徵** |
| --- | --- |
| **1** | 相同的龍種和年齡，只在外形上有差異 |
| **2** | 相同的龍種和年齡，只是在行為舉止上有差異 |
| **3** | 相同的龍種和年齡，但在性格、理想或陣營方面有明顯的差異 |
| **4** | 相同的龍種，大體上相似，但在年齡上要更大或更小。 |
| **5** | 相同的年齡，同一龍種中的不同種類（色彩、寶石或金屬），並且在外觀和性格上相似 |
| **6** | 相同的年齡，不同龍種中的不同種類（有相似的吐息武器或棲息地），有類似的外觀，但有非常不同的理想或羈絆 |
| **7** | 在幾乎所有可以想像的方面都有根本性的不同，但仍然被跨越世界的命運所連結 |
| **8** | 重骰。此外，迴響是龍類亡靈（**龍巫妖**、**空骸龍**、**幽魂龍**或**龍靈碎晶**）或幽影龍。 |
