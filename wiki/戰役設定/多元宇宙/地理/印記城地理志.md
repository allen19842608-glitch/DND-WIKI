# 印記城地理志

> [!warning] 劇透警告
> 本頁含有冒險劇情、祕密身分或結局資訊。

## 設定資料

眾門之城被劃分為數個城區，其風貌如其居民般多樣。從官僚體系森嚴的職員區高塔林立的樓宇，到底層印記城黴氣沖天的無政府街巷。每個城區至少擁有一個派系的總部——那是印記城哲學家們聚集、劃分城市職責的大型建築。這些派系總部周邊的場所，往往會呈現出該派系的性格。比如說，市民歡樂堂周圍的商店就滿足感覺團的享樂主義傾向——你會看到酒館、音樂廳，以及販售一次性新奇玩意的小販攤位。
下方的印記城城區表概覽了每個城區以及總部在對應城區的掌權派系，該表也標註了六個次要派系，這些次要派系被星號（\*）標記。

**印記城城區**

| **城區 Ward** | **主要派系 Prominent Factions** |
| --- | --- |
| 職員區 | 定命盟，咒法會\*，感覺團 |
| 巢穴區 | 無望黨，禍亂之手，灰燼先驅 |
| 女士區 | 末日守衛，秩序廳，和諧營，屠憫會 |
| 下層區 | 神明非神會，送戒人\*，心靈之眼 |
| 市場區 | 自由聯合會\*，超然社 |
| 底層印記城 | 蛋糕社\*，革命聯盟\*，無分會\*（詳見本章節後文“底層印記城”部分） |

接下來的章節將逐一介紹每個區域的細節，遵循以下格式：

**區域遭遇 Ward Encounters。** 介紹冒險者在該區域內可能遭遇的事件或互動。

**派系 Factions。**說明設於該區的派系與其職能運作。

**地點 Locations。**列出該區著名地點，包括派系總部在內。所提及的地點在印記城海報地圖中皆有標示。

**巨型建築 Megastructures。** 多數區域會附上一座印記城巨型建築的地圖。這些巨型建築常是派系總部，也能容納無數冒險。地圖僅為建築內重要區域之概覽，不代表其全貌。為配合冒險需要，這些地點的細節與比例皆可依需求進行調整。
