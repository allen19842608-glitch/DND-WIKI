# 冒險主題 (Adventure Themes)

## 冒險設計

一群冒險者離開了那座陰暗潮溼的城市，將充滿罪惡的街巷拋諸身後。他們登上一艘環繞火焰的飛艇，開啟橫越大陸的旅程，卻在中途被騎著飛龍的匪徒突襲。在飛艇朝著地面疾速墜落時，他們不得不為生存而殊死搏鬥！
他們憑藉著急智與勇氣在墜機中倖存，卻發現自己被困於哀傷故地的死灰迷霧之中。為了找到返回起點的道路，他們不得不面對這片飽受戰火蹂躪的土地所潛藏的重重危機。而他們即將面對的最大恐懼，或許正是潛伏在自己內心深處的陰影。
正如本書引言所述，在艾伯倫，通俗冒險和黑色陰謀是兩大交織的主題。將這些主題巧妙地融合，或是單獨深入探索其中之一，都能賦予艾伯倫故事一種獨特的魅力。這些主題的冒險有助於強化地域感，讓玩家（以及你）沉浸在一個被百年戰火所困擾、由現代理念和美學所塑造、並被一道魔法屏障與其他《龍與地下城》多元宇宙隔絕開來的世界。
本節介紹這些主題旨在幫助你講述完美契合艾伯倫的故事。它將探討塑造引人入勝的宿仇和保持冒險動力的技巧，討論如何將終末戰爭作為冒險的主題和背景，並將哀傷故地作為一個冒險地點進行詳細闡述。隨後，本節還將描述在途中——包括在飛艇上、在閃電列車上、在沿途的休息站裡——可能發生的冒險與遭遇戰。最後，本節將討論那些通常被定義為“怪物”的生物在科瓦雷所扮演的角色，並深入探索艾伯倫的宇宙觀。

### 宿仇 Recurring Villains

最能牽動人心的反派，莫過於那些一再現身、反覆折磨他們那些偉光正宿仇的反派。當英雄們挫敗了邪惡主謀的陰謀後，這個狡猾的惡棍總能逃出生天，為日後的交鋒留下伏筆。一個刻畫豐滿的宿仇能夠讓潛伏在黑暗中的陰險密謀具象化，從而極大地增強玩家的世界沉浸感。
你可以通過在反派的背景中加入一些道德模糊感——或許是通過影射他們在終末戰爭中的經歷——讓你的戰役中的宿仇變得更加引人入勝。

### **怎麼讓反派活下來 How to Keep Villains Alive**
設計宿仇的首要任務是確保反派能在與冒險者的初次交鋒中倖存，以便捲土重來，接著折磨他們。以下是一些能確保你的反派不會在第一時間白給的策略——即便面對再足智多謀的英雄也是如此。
**交給手下代勞 Have Lackeys Do the Work。** 反派只需派出嘍囉去消耗隊伍的力量便可以輕易地推遲與冒險者的首次當面衝突。同時，你得確保冒險者知道這些嘍囉為誰工作——藉此抬高反派的逼格。
**竭盡全部資源 Use All Available Resources。** 一個聰明的反派，尤其是那些擁有魔法資源的反派，可以在冒險小隊面前設置大量的障礙。機械和魔法陷阱、反預言結界、以及防護性魔法物品，都只是足智多謀的反派可以使用的安全措施的冰山一角。請記住，那些倖存嘍囉的報告，以及從其他渠道得來的關於冒險者的消息，都能為反派提供足夠的信息，以便準備適當的反制措施。
**擬定逃跑計劃 Have an Escape Plan。** 秘密通道、隱形或傳送法術、飛行坐騎、以及成群爪牙，都能幫助反派在與冒險者的衝突陷入劣勢時成功逃脫。任何稱職的反派都至少會有一個後備方案。
**劫持一些人質 Take Hostages。** 如果冒險者擔心一旦他們拔劍攻擊，反派的嘍囉就會立即屠殺無辜的俘虜，那麼大多數冒險者都不會輕易動手。
**從死亡中歸來 Returning from Death。**死亡對於玩家角色而言當然並非終點……對於反派來說也同樣如此。在冒險者擊殺了他們的宿敵後，下一次遭遇時，這個反派可能已被複活，或以亡靈的形態出現。可以想像，死亡可能會讓反派變得更加強大，並且對這些多管閒事的冒險者更加憤怒。另外，角色們可能只是誤以為反派已死——比如墜入瀑布、被困火場，或被巨型紫蟲吞噬——直到後來才發現，反派不僅倖存了下來，而且心中充滿了復仇的烈火。

**強化反派 Improving Villains**
隨著時間的推移，冒險者會變得越來越強大，因此，如果一個反派想要持續成為一個有分量的威脅，他也必須同步提升自身實力。你可以通過以下三種方式來處理這個問題：
**增強數值 Mechanical Improvement。** 你可以參考《城主指南》第九章為反派增加職業等級或生命骰，並提升其挑戰等級，使其能夠與更高等級的角色相匹敵。
**非玩家角色數據卡 NPC Stat Blocks。**《怪物圖鑑》中的某些數據卡可以反映同一角色在不同階段的實力。例如，冒險者可能初次遇到一個使用**魔法師 Mage**（9級法師）數據卡的反派，而他日後則以**大法師 Archmage**（18級法師）的身份迴歸。你也可以利用其他資料中的數據卡來擴充序列，讓角色們最初遇到這位有抱負的反派時，他可能只是一位**學徒法師 Apprentice Wizard**，而後來則晉升為**塑能學者 Evoker** （兩者均收錄於《瓦羅的怪物指南》）
**反派組織 Organizations as Villains。**與其將個體設定為反覆出現的宿敵，不如將目光投向反派所隸屬或代表的組織。舉例來說，低等級的冒險者可能會與翡翠利爪教團的低級特工交戰，並逐漸開始厭恨他們的爪形徽記和綠色斗篷。隨著角色等級的提高，他們將面對更加強大的教團成員。

**邪惡之灰影 Shades of Evil**
道德上的模稜兩可是黑色風格的一大特色，它可以為艾伯倫的冒險增添豐富與複雜的層次。在這個世界，紅龍未必邪惡（青銅龍也未必善良），而你永遠無法確知誰值得信任。即便是所謂的反派，其行為也可能無法被簡單地歸入非黑即白的善惡定義之中。
許多冒險中的惡人，其驅動力更多來自人性的動機，而非宏大的宇宙善惡觀。人們有時會出於好的理由而做出邪惡的事情。
在設計故事並探索這些黑色主題時，需要謹慎一些。對某些玩家群體來說，在冒險中處理道德難題會很有樂趣，但並非所有玩家都樂在其中。當困境沒有好的解決辦法時尤其如此——如果角色們別無選擇，只能採取他們厭惡的行動，一些玩家可能會感到不快。
灰色的反派表為你提供了一些可以添加到本章反派身上的反轉，讓他們作惡的理由或多或少帶有一絲善意。

**熟悉的反派 The Villain You Know**
並非每一個反派都是在幕後策劃陰謀的操縱者，或者企圖毀滅世界的恐怖存在。有時，最具分量的惡人恰恰是那些角色們日日相見的人——他們在社會上公開活動，卻將自身的惡行隱藏得滴水不漏。
那些試圖將反派繩之以法的執法者和冒險者，會在每一步都遭遇阻礙，始終無法找到任何確鑿的犯罪證據。如果玩家們終於開始對反派深惡痛絕，那麼反派的塑造就成功了。
你可以使用熟悉的反派表，為那些頻繁困擾角色的反派行動和動機增加深度和細節。

**熟悉的反派 Villain You Know**

**神秘的反派 The Mysterious Villain**
與那些日常生活中的反派不同，異界反派不僅身份隱秘，而且其本質也充滿謎團。問題不僅僅在於“反派是誰”，更在於“反派是什麼”，以及需要採取何種非凡措施才能阻止他們的惡行。舉例來說，即便冒險者發現他們的長期宿敵是蒙啟者之一，他們仍需深入學習蒙啟者及其夢靈主人的秘密，才能找到對付這種威脅的方法。
有時，神秘感本身就足以讓這樣的反派引人入勝，好奇心會驅使冒險者們不斷挖掘對手的秘密。時機成熟時，你可以將一個神秘的反派轉變成一個令人不安的熟悉反派——例如，一個夢靈精魂會樂於通過多個不同的蒙啟者軀體開口說話，嘲諷冒險者們無法觸及其精魂本體。此時，憎恨就會與好奇心交織，驅動冒險者們進行更深入的探索。當角色們深入挖掘世界的奧秘時，他們對設定的沉浸感和依戀度也會隨之加深，你的戰役自然會從中受益。
**終極邪惡 Ultimate Evil。** 有些神秘反派掌握著足以威脅整個世界的力量，這力量可能來自巨大的蠻力、高超的魔法、驚異的智慧，或是絕倒的魅力（其力量通常來自這些因素的結合）。這些反派通常潛伏在陰影之中，遙控著手下和夥伴，鮮少親自現身。這類惡棍尤其難以根除，即便他們被放逐或囚禁也是如此——他們的魔法和僕從網絡能確保其影響力遠遠超出其肉體存在範圍。
**驅動勢力 Driving Forces。**這類反派大多歸屬於本章稍後描述的驅動勢力之中。你可以從費解的反派表中選擇其中一個勢力，然後查閱相應章節中的冒險種子和反派設想。

### 行動！Action!

通俗冒險風格的戰役，往往以一聲巨響拉開序幕，隨後以極快的速度推進，最終在高速載具上驚心動魄的遭遇戰中，或在戲劇性場所的宏大混戰中達到高潮。行動不一定意味著戰鬥，但確保世界在玩家角色周圍不斷運轉，是保持他們高昂興趣的絕佳方式。

**拉開序幕 Kicking Off the Action**
當你以一聲巨響開始冒險時，你會立刻將角色們捲入行動之中，抓住他們的注意力，並讓他們踏上一段狂野的旅程。故事開場表提供了一些充滿行動感的開場方式，來讓故事動起來。

**故事開場 Story Kickoff**

| **d6** | **事件** |
| --- | --- |
| 1 | 在一個安靜的夜晚，酒館大門被猛地撞開，一群士兵直呼其中一位隊員的名字。 |
| 2 | 某處市場發生爆炸，周圍物品四處橫飛。 |
| 3 | 一輛載具在隊伍附近墜毀。有人受傷需要救助，而造成墜毀的元兇仍然隱藏在附近。 |

| 6 | 一位酒館顧客突然暴起，盲目狂怒地抓撓、撕咬其中一名冒險者。 |

**急轉直下 Keeping the Action Going**
“如果你不知道接下來寫什麼，就讓一個人拿著槍破門而入。”硬漢小說作家雷蒙德·錢德勒提供的這條建議，同樣適用於行動驅動型的冒險。每當故事節奏出現滯緩時，再來上一點興奮劑就能讓事態持續推進。
場景中新登場的人物可以是對核心情節不可或缺的一部分，也可以是獨立的突發事件。全新發展表中展示了一些點子。

### 陰謀 Intrigue

遵循黑色電影敘事的故事往往以緩慢的節奏開始，隨著謎團不斷加深、愈發複雜，故事張力也逐漸積聚，直到最終在一次決定性的衝突中爆發。與通俗冒險中那種令人心跳加速的行動相比，黑色電影通常依靠陰謀——無論怎麼解釋這個詞都行——來讓主角們在故事的層層深入中保持參與感。

**佈設舞臺 Setting the Stage**
在冒險伊始就將一個謎團擺在角色面前，能夠為接下來的故事定下基調，並迅速將他們引入劇情。故事開場表提供了一些將角色們拉入這場陰謀之中的方法。

**故事開端 Story Opening**

| **d6** | **事件** |
| --- | --- |
| 1 | 隊伍從一位街頭算命先生那裡得到了詳盡的占卜解讀，勾勒出了冒險的起點。 |
| 2 | 一名信使護送隊伍登上元素飛艇，一位富有的主顧在飛艇上交代了他們的任務。 |
| 3 | 在一場奢華的化裝舞會上，一位戴著面具的客人請求隊伍提供幫助。 |
| 4 | 一位喬裝打扮的龍紋家族後裔帶著一項提議在城鎮的破舊角落接近了角色們。 |
| 5 | 一名人造生命體送來了一封匿名信，信中提供了一份工作，但未透露寄信人的身份。 |
| 6 | 一位莫格雷夫大學教授聯繫了隊伍中他以前的學生，求他幫一個大忙。 |

**撲朔迷離 The Plot Thickens**
大多數陰謀類冒險的關鍵點在於重大的情節轉折。當你規劃線索、事件和互動軌跡時，不妨考慮一個可以用撲朔迷離表中的轉折來徹底動搖局勢的關鍵節點。

**撲朔迷離 The Plot Thickens**

| **d8** | **事件** |
| --- | --- |
| 1 | 看起來顯然是受害者的那位其實才是反派。 |
| 2 | 某個號稱價值連城的物件其實根本一文不值（反之亦然）。 |
| 3 | 某件貴重物品其實不屬於聲稱自己是物主的那個人。 |
| 4 | 真正有價值的其實不是藝術品本身，而是藏在上面（例如雕像內部、畫框背面）的地圖或別的情報。 |
| 5 | 某人其實愛慕著隊伍中的某位成員，或者愛慕著反派。 |
| 6 | 某人其實是隊伍中某位成員的親戚。 |
| 7 | 一位老朋友或前盟友其實正在和反派聯手合作。 |
| 8 | 最初的陰謀其實只是為了將人們的注意力從真正的計劃上引開。 |
