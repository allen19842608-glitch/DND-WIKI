# 黑色陰謀 (Noir Intrigue)

遺憾、債務、灰色地帶與可失之物的黑色電影風格。

艾伯倫深受黑色電影與硬派小說的啟發。這是一個充滿灰色地帶的世界，故事未必總有美好的結局，每個問題也並非都能找到完美的解決方案。在艾伯倫中設定角色或構思故事時，不妨參考以下理念。

## 每個人都有遺憾 Everyone Has Regrets

玩家角色固然非凡，但絕非完美無瑕。當你為角色設定缺陷時，不妨帶點硬派風格，回顧角色的過往：你是否曾犯下無法挽回的悲劇性錯誤？是否傷害過某人，以致對方現在懷著復仇的怒火？遺憾表中展現了一些可能糾纏角色的失誤：

**遺憾 Regrets**

| **d10** | **遺憾** |
| --- | --- |
| 1 | 在終末戰爭中，你被迫遺棄了一名負傷的戰友。你至今不知道他們是否存活。 |
| 2 | 你曾信任一位戀人，但對方背叛了你。從此，你不敢輕易相信他人。 |
| 3 | 你謀殺了一位競爭對手。儘管你的行為可能有理可循，他的面龐卻仍在你腦中揮之不去。 |
| 4 | 你曾對孩子或愛人許下承諾，卻未能實現。 |
| 5 | 你散盡家財，令家道中落，祖上蒙羞。 |
| 6 | 你與某個異界實體達成交易，而如今嗟悔無及。 |
| 7 | 你為了追求冒險生活拋棄了家庭。你的村莊在戰爭中被摧毀，家人至今下落不明。 |
| 8 | 你曾作為間諜或士兵為國家執行秘密任務，在此期間做了不可饒恕的事。 |
| 9 | 你曾得到某人全心信任，但你卻為私利背叛了對方。即便如今後悔萬分，破鏡已難重圓。 |
| 10 | 你自願參與神秘實驗，雖然這可能是你職業能力的來源，但你卻飽受副作用的折磨。 |

## 你為什麼需要 200 金幣 Why Do You Need 200 Gold Pieces?

過去的遺憾塑造了角色當下故事中的性格，但眼前的問題同樣至關重要。另一種定義角色缺陷的方式，是為其設定一個急需解決的債務。債務不僅增加了角色的深度，還為冒險提供了更直接的動機。
為什麼選擇讓角色揹負債務？因為這能增加角色的深度，亦能增添緊迫的冒險動機——你可不是為了變成富哥來冒險的，你賺快錢是為了消掉你頭上的賞金。這也是為角色設定其推進動機的大好機會。例如，為了從當鋪取回魔法物品，你大可聲稱這件物品曾是角色的重要遺產、心血之作，或是導師贈與的禮物——你只不過是暫時把它弄丟了。若你在為加入某個秘密組織籌資，這也暗示了該組織可能在故事中扮演重要角色。
設定債務需要玩家和 DM 的共同協作。雙方可以一起完善細節：是誰在敲詐你？你想加入的秘密組織是什麼？你典當的魔法物品有什麼背景故事，又是什麼類型的物品？你可以提出點子，但 DM 擁有最終決定權。

**債務 Debts**

| **d10** | **債務** |
| --- | --- |
| 1 | 你在終末戰爭中犯下了罪行，現在被掌握證據的人勒索。雖然你可以為自己的行為辯護，但法律並不關心理由。 |
| 2 | 你嗜賭成性。如果無法還清達斯克（見第三章）的欠款，他們很快就會讓你和蛇雞獸玩一把鬼抓人。 |
| 3 | 你擁有一件非普通魔法物品，但不得已將其典當。如果你無法在一個月內將其贖回，當鋪就會賣掉它。 |
| 4 | 你曾為波羅馬氏族（見第3張）運送貨物，但不幸把貨物弄丟了。 |
| 5 | 你本以為你的兄弟姊妹或愛人於哀傷日失蹤，但有人知道他們的下落。然而，這條信息的價格高得離譜。 |
| 6 | 你患有無法用常規手段治療的退行性疾病，如果不能儘快獲得次級復原術的治療，症狀將逐漸開始顯現。 |
| 7 | 你的家庭在終末戰爭中失去了一切。有了這200gp，你就能為他們在一家新客棧、農場或者驛車隊裡入個股。 |
| 8 | 你身上掛著懸賞，除非與撒剌釋克家族和解，否則賞金獵人隨時可能找到你。 |
| 9 | 你有機會加入一個有影響力的秘密組織，但前提是必須在一個月內籌到會費。 |
| 10 | 再擲一次。這筆債務並不是你的，而是你愛人的問題。你能在他們面對後果前替他們解決債務嗎？ |

## 個人動機 Personal Motives

並非所有衝突都關乎光明與黑暗的較量。多數人只被簡單的慾望驅動：貪婪、恐懼、驕傲或野心。有人只想多賺點金幣，有人想取悅情人，而某些領袖則出於對鄰國的恐懼與對統一大陸的執念而將其國家拖入戰爭。
儘管原初力量可能威脅艾伯倫的存亡，但角色更常面對的是迷途的愛國者、極端的宗教狂熱者、盤剝科瓦雷的龍紋家族、為了國家利益不擇手段的間諜，或是試圖建立犯罪帝國的卑鄙罪犯。艾伯倫的世界既有無私的英雄，也容得下徹底的反派，而更多人則位於兩者之間。

## 灰色地帶 Shades of Gray

在艾伯倫，英雄與反派之間的界限往往模糊不清。善良的人可能做出可怕的事情，而冷酷的人也可能服務於更大的利益。一名宗教裁判官為了剿滅黃泉巨龍邪教，拷打了無辜者。如果她被阻止，異教可能會壯大。一群獸人定期襲擊人類定居點，因為這些村落建在獸人的聖地上，並破壞了封印邪惡的結界。英雄們在墓穴中找到一把強大的魔法武器，卻發現它是古代大地精將軍的遺物，其後代希望將其歸還。並非所有問題都有簡單的答案。
有些時候行動果決至關重要——比如，必須阻止翡翠利爪邪教徒引爆足以毀滅半個薩恩的暗蝕共鳴儀。但在一個精彩的艾伯倫故事中，最簡單的解決方式未必是最好的。

## 可失之物 Something to Lose

在黑色故事中，結局未必美滿。冒險總是伴隨著死亡或失敗的風險，但除此之外，角色還可能承擔怎樣的風險呢？他們應有一些除了生命值以外的可失之物：名譽受損的恐懼、好友愛人受到的威脅、心愛產業的毀滅或收購。角色間的關係需要玩家沉浸於劇情，而 DM 和玩家共同完善背景細節（第一章中的團隊贊助者即提供了填入這些細節的框架）則是最佳選擇。
DM 可以在故事中引入與玩家角色一同服役的老戰友，描述對方後，請玩家定義他們的聯繫。例如“玩家甲，斯米蒂怎麼在戰爭中救的你？玩家乙，你和斯米蒂曾被關押在同一個戰俘營，又是如何從中逃脫的？”對這些問題的回答為故事提供了更多細節，也讓玩家在其中投入更多感情。這也使得翡翠利爪教團將斯米蒂列為刺殺目標這一點對玩家來說更為重要！
