# 科瓦雷的信仰

## 設定資料

在艾伯倫世界中，宗教扮演著重要角色。諸神不會以實體形式顯現，但虔誠的信徒們深信神聖力量塑造著日常生活。共同的信仰能夠團結社群，並在艱難時刻提供希望。
大多數科瓦雷人都承認天命諸神及其惡意陰影——黑暗六神這一神系。天命諸神是伽利法王國的主流信仰，並在科瓦雷大部分地區擁有影響力——唯獨瑟雷恩除外，該地更傾向於銀焰教會。其他宗教則與特定的文化或社群相聯繫。例如，離夢人信奉光明之道，而不朽議庭則指引著艾倫諾的精靈。
宗教對於聖武士、牧師和德魯伊尤為重要，但任何角色都可以信仰更高層級的力量。遵循宗教信仰是讓你的角色與世界建立更深聯繫，並與社群其他成員建立紐帶的方式。信仰根基表可以為你的信仰來源提供一些思路。
反之，缺乏信仰也可以成為你故事中有意義的一部分。如果你不相信任何神聖力量，那麼這種疑慮因何而起？信仰拒斥表可以提供有助於塑造你故事的靈感。

**信仰根基 Foundation of Faith**

| **d6** | **根基** |
| --- | --- |
| 1 | 你是在濃厚的宗教氛圍中被撫養長大的。你的宗教是你家系和社群的重要組成部分。 |
| 2 | 你所珍視的某人——導師、朋友、愛人——推薦你入教。 |
| 3 | 你是在另一種宗教氛圍中長大的，但後來被你當前信仰的理想和信念所吸引。 |
| 4 | 你從未認真對待你的信仰。隨後，你在終末戰爭期間立下誓言，如果災難得以避免，你會將全身心投入信仰之中……而你真的避開了那場災難。 |
| 5 | 你對你的宗教很虔誠，但從未接受過正式的教義教育。你遵循自己個人的理解來信奉這一宗教。 |
| 6 | 你經歷了一次超然體驗，並相信自己肩負著需要完成的神聖使命。 |

**信仰拒斥 Rejection of Faith**

| **d6** | **拒斥** |
| --- | --- |
| 1 | 你認為牧師和聖武士的魔法並非源自神祇，而是來自施法者內在的力量或信念。 |
| 2 | 你來自秉持不可知論的社群，很少思考精神層面的事務。 |
| 3 | 你曾是一位極度虔誠的信徒，但終末戰爭中的一場悲劇使你開始質疑你的信仰。 |
| 4 | 一次個人損失或背叛動搖了你的信仰。 |
| 5 | 你在與邪魔或異怪的遭遇中受到了精神創傷。 |
| 6 | 你創造了屬於自己的個人宗教，並認為所有既定的信仰都有缺陷。 |
