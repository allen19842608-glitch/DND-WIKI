# 龍紋陰謀冒險

## 設定資料

《艾伯倫：自終末戰爭中崛起》中包含了圍繞一個龍紋家族創作冒險的建議，但最有趣的冒險則應當涉及多個龍紋家族之間的互動。請使用家族陰謀表作為靈感來創作涉及兩個或多個家族的情節。

**家族陰謀 House Intrigue**

| **1d6** | **冒險目標** |
| --- | --- |
| 1 | 龍紋家族爭奪對一位傑出人物（可能是玩家角色中的一個）的影響力。 |
| 2 | 龍紋家族爭奪一個關鍵地點的控制權。 |
| 3 | 兩個龍紋家族之間的關係日益緊張，可能爆發出致命的爭鬥。 |
| 4 | 來自兩個或更多龍紋家族的反派組成了一個危險的聯盟。 |
| 5 | 一個反派試圖破壞兩個或多個龍紋家族之間的聯盟。 |
| 6 | 來自兩個龍紋家族的分裂者試圖組成一個新的龍紋家族。 |
