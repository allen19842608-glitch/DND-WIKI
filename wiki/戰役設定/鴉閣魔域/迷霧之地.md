# 迷霧之地

迷霧之地是鴉閣魔域中各個恐懼領域與其迷霧的統稱。本頁的旅行、死亡與魔法限制只適用於鴉閣魔域，並不取代多元宇宙的通用規則。（來源：前言／迷霧之地）

## ⚙️ 鴉閣共通設定

### 迷霧

- 迷霧中的區域為重度遮蔽，且任何風都無法將迷霧吹散。
- 迷霧受黑暗力量支配；它可從其他世界攫取生物或地區、隔絕領域，並作為領域間的穿行媒介。

### 迷霧護符

迷霧護符是與特定領域共鳴的非魔法物件。手持或佩戴護符並專注於其關聯領域的生物，在迷霧中跋涉 `1d6` 小時後抵達目標領域；跟隨其周圍 30 呎內的生物也會抵達同一處。若目標領域邊界已封鎖，護符不能使持有者進入或離開。（來源：前言／迷霧之地／迷霧護符）

### 漂泊於迷霧中

未攜帶迷霧護符的生物踏入環繞領域的迷霧後，會在跋涉 `1d6` 小時後於別處出現。DM 可擲 `1d100` 或依冒險需求選擇結果。

| `1d100` | 去向或遭遇 |
| :--: | :--- |
| 01–20 | DM 選擇的一個領域。 |
| 21–40 | 再漂泊 `1d6` 小時後重擲。 |
| 41–65 | 原進入位置 `1d100` 呎外。 |
| 66–75 | 原進入位置 1 英里外，時間為次日午夜。 |
| 76–85 | 原領域內一處建築。 |
| 86–95 | 遭遇生物後重擲；偶數為平民，奇數為驚怖迷霧。 |
| 96–99 | 回到進入位置，但領域已發生改變。 |
| 100 | 暫至物質位面；`1d6` 小時後迷霧將生物拉回原試圖離開的領域。 |

### 領域與黑暗領主

- 恐懼領域是位於墮影冥界、彼此隔絕的有限半位面；每一個領域都囚禁一名黑暗領主。
- 黑暗領主不能離開自己的領域；領域會以與其罪行、失敗或野心相關的方式折磨該領主。
- 黑暗領主可封鎖領域邊界。邊界封鎖時，迷霧變得致命，任何嘗試離開的生物最終都會回到原領域。

### 死亡與重生

在鴉閣魔域或迷霧中死亡的靈魂無法前往死後世界。死亡超過 24 小時後再被魔法復活者，會得知自己仍受困於迷霧；未被復活的靈魂可能被黑暗力量留在領域內，並可能在日後轉世。（來源：前言／迷霧之地／死亡與重生）

### 迷霧中的魔法

下列為鴉閣中的地域性例外；未列出的魔法依通常規則運作。

| 類別 | 鴉閣中的處理 |
| :--- | :--- |
| 放逐與異界旅行 | 放逐的異界生物會出現在隨機其他恐懼領域；沒有法術可使生物逃離鴉閣。星界投影、位面轉移等位面旅行法術在領域中失效；異界之門不能用於逃離。 |
| 以太與異次元空間 | 進入邊界以太後離開時，生物會回到進入時的領域；異次元空間可正常運作，但其中施法仍受領域限制。 |
| 異界聯絡與位面邊界 | 黑暗領主能察覺跨位面聯絡魔法，且可冒充被聯絡者；每個領域對跨位面效應視為獨立位面。 |
| 召喚 | 召喚魔法可正常運作，但被召喚的生物或物件本質上是黑暗力量的造物。 |

## 💡 DM 使用提醒

- 迷霧旅行表是供 DM 決定或擲骰使用的冒險工具；不是角色可自行選擇出現位置的玩家程序。
- 迷霧中的魔法例外僅適用於鴉閣魔域；離開鴉閣後，法術回復其通常處理。
