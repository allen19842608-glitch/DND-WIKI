# 結束冒險 (Bring It to an End)

高潮應兌現冒險先前建立的承諾，並受角色先前的成功與失敗影響。可在早期以線索或敵人的言行為高潮埋下伏筆。

## 冒險高潮表 (Adventure Climax)

| d10 | 高潮方向 |
| :---: | :--- |
| 1 | 與主要反派及其爪牙最終決戰。 |
| 2 | 追逐反派、克服阻礙，並在其基地決戰。 |
| 3 | 角色或反派引發災難，角色必須逃離。 |
| 4 | 與時間競賽，在反派計畫完成前趕到關鍵地點。 |
| 5 | 反派與副手分頭進行儀式，角色必須逐一破壞。 |
| 6 | 盟友背叛角色；此手法應謹慎使用。 |
| 7 | 異位面傳送門開啟，角色須在應付湧出的生物時關閉它。 |
| 8 | 地下城坍塌，反派試圖趁亂逃走。 |
| 9 | 角色必須在追捕逃跑反派與拯救重要 NPC 或無辜者之間抉擇。 |
| 10 | 看似已被擊敗的主要威脅轉化為更強的形態或怪物。 |

## 收尾 (Denouement)

高潮之後可安排收尾，串起先前的情節與線索、處理寶藏、授勳或悼念等結果，並留下能引向下一場冒險的新線索。
