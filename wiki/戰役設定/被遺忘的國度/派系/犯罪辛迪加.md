# 犯罪辛迪加 (Criminal Syndicates)

費倫的地下勢力從短命地痞到能脅迫貴族的跨地域組織皆有。它們是冒險者可對抗、滲透或被迫合作的勢力。

| 組織 | 根據地與特徵 |
| :--- | :--- |
| 焰匕 (Fire Knives) | 西門；由貴族出身的刺客與間諜構成，以毒刃、偽裝與上流社交接近目標。 |
| 九金劍幫 (Nine Golden Swords) | 塞斯克與黃金之路；從事攔路搶劫、恐嚇與黑市事業，首領稱為黃金王座。 |
| 影賊公會 (Shadow Thieves) | 安姆；以陰影議會、陰影宗祖與披風大師構成嚴密階層，操控市場與政治。 |
| 珊娜薩公會 (Xanathar Guild) | 深水城；入會前須犯下嚴重罪行，內部以殘酷競爭決定晉升。 |
