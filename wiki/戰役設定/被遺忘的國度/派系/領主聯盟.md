# 領主聯盟 (Lords' Alliance)

領主聯盟是西費倫定居點的統治者與貴族組成的協會，透過共享威脅情報、雇用冒險者與防衛邊境，維護北地城鎮的安全與繁榮。各成員在領主議會中擁有代表，並定期舉行領主集會。

## 成員定居點

安菲爾、博德之門、匕首灘、長鞍鎮、米拉巴、秘銀廳、無冬城、銀月城、深水城與雅塔皆為本書列舉的成員；代表通常是當地統治者或其代理人。

## 聲望獎勵

| 聲望 | 獎勵 |
| :--- | :--- |
| 3+、15+、30+ | 不同等級的聯盟定居點貴族對你預設友好。 |
| 5+ | 可向軍需官以九折購買藥水與至多 3 環的法術卷軸。 |
| 10、40 | 首次達成時，分別獲得隨機非普通、珍稀魔法物品。 |
| 25+ | 可免費請施法者對聯盟代表施展[[法術/3環/短訊術\|短訊術 (Sending)]]。 |
| 50+ | 可請求會見任何代表，並可申請最多三名騎士護送一次任務。 |

## 成員與據點

- 成員在自己代表的定居點享富裕生活方式，在其他聯盟定居點享舒適生活方式；另獲一匹價值至多 75 GP 的坐騎與乘用鞍座。
- **領主聯盟貴族住所**是 9 級、龐大、1 名僱員的招募設施，先決條件為聯盟成員。在其中完成長休後獲得英雄激勵。
- 招募時 14 天內不能使用住所休息；擲骰為偶數則指定定居點的一名貴族在 7 天後抵達、停留 7 天，並告知其家鄉 50 英里內、未被魔法隱藏的已知生物位置及近 7 日行蹤。
