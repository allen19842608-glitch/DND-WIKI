# 費倫其他組織 (Other Organizations)

| 組織 | 設定與角色切入點 |
| :--- | :--- |
| 奧術兄弟會 | 路斯坎奧術主塔的祕密法師集會；成員競爭魔法造詣，並守護主塔的圖書館。 |
| 奧蘿拉百貨 | 費倫各地的商品目錄與門店網絡；奶酪袋每袋 1 GP、每日每人限購 1 袋，隨機決定產地。 |
| 元素教派 | 氣、土、火、水四個崇拜邪惡元素的預言者教派，各自以破壞與災害追求目標。 |
| 焰拳 | 博德之門的傭兵團與實際治安力量，亦駐守偏遠前哨。 |
| 海妖會 | 活躍於劍灣與無痕海的情報與暴力組織，為神祕海中存在服務。 |
| 掘地教團 | 探索與測繪洞穴、天然隧道及幽暗地域上層的公會；成員可獲裝備折扣、探索資訊分享與搜救服務。 |
| 法術守衛 | 銀月城的軍事化施法者騎士團，守護城市並派遣精英執行遠方任務。 |
| 水鍾公會 | 無冬城的奇械師、地脈術士與工匠組織；水鍾復興正尋回失落發明以重建公會。 |
