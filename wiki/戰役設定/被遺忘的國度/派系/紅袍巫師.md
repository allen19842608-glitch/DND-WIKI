# 紅袍巫師 (Red Wizards)

紅袍巫師是源自塞爾、追求奧術力量與長生的施法者派系。八位首席各主宰一所魔法學派，薩扎斯・坦則是其中最可怖的亡靈統治者；紅袍巫師也會離開塞爾，蒐集祕辛並經營魔法物品貿易。

## 組織與塞爾飛地

- 紅袍巫師慣穿深紅長袍、剃頭並紋奧術刺青；在費倫旅行時常以幻術隱藏身分。
- 非正式頭銜為學徒、導師與賢人；塞爾飛地是由紅袍巫師、保鏢與魔法物品市場構成、租約上適用塞爾法律的社區。
- 成員獲得會在每日黎明自行縫補、清洗的紅袍；典型角色為法師，也有術士、契術師及塞爾騎士。

## 聲望獎勵

| 聲望 | 獎勵 |
| :--- | :--- |
| 3+ | 知曉所有塞爾飛地位置，可在其中免費採舒適生活方式。 |
| 5+ | 以半價購買奧術法器、書寫用品、治療藥水與戲法／1 環卷軸。 |
| 10、30、50 | 首次達成時，分別獲得隨機非普通、珍稀、極珍稀法杖、魔杖或權杖。 |
| 15+ | 買賣魔法物品或施法服務的議價屬性檢定具有優勢。 |
| 25+ | 認識可繪製[[魔法物品/奇物/塞爾法術刺青\|塞爾法術刺青 (Thayan Spell Tattoo)]]的刺青師。 |
| 40+ | 在城鎮或更大聚落準備結陣法術時，可免費招募 1d4 名法師協助；其於 1d10 天內抵達，至聲望提高前不能重用。 |

## 紅袍巫師大墓地

**紅袍巫師大墓地**是 5 級、寬敞、1 名僱員的招募設施，先決條件為紅袍巫師成員且能使用施法法器。它可容納最多八名據點衛兵。每次招募指令可創造至多四名亡靈衛兵；被摧毀的亡靈於 14 天後回歸，前提是設施未關閉且尚有空位。
