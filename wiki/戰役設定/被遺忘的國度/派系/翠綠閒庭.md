# 翠綠閒庭 (Emerald Enclave)

翠綠閒庭由生存主義者與自然崇拜者組成，成員稱為庇護者；其使命是維繫文明與荒野的平衡、守護自然聖地，並清除威脅自然秩序的非自然力量。

## 組織與儀式

- 成員分屬結社：大氣、遠古、巨像、大地、月亮與野火結社。三長老是傳奇德魯伊領袖，居於橡樹之廳。
- 滿月用於接納新庇護者，新月用於審判；煤紋聖杉、蒼藍巨柱與銀淚是著名聖地。
- 成員享有含食物、水與庇護的儉樸生活方式；常見角色為野蠻人、德魯伊與遊俠。

## 聲望獎勵

| 聲望 | 獎勵 |
| :--- | :--- |
| 3+ | 以半價僱用翠綠閒庭僱員。 |
| 5+ | 可請一名斥候隨行協助導航、覓食與搜索一次，至聲望提高前不能重用。 |
| 10 | 首次達成時學會德魯伊語。 |
| 15+ | 可購買普通與非普通藥水、法術卷軸。 |
| 25+ | 距閒庭據點 10 里內斷炊時，獲得食物與水。 |
| 30 | 首次達成時獲得 1d4 瓶強效治療藥水。 |
| 40+ | 人馬、樹人、獨角獸與野獸預設友好。 |
| 50+ | 成員公開分享情報，並可求見三長老一次。 |

## 翠綠閒庭林居

**翠綠閒庭林居**為 9 級、龐大、2 名僱員的招募設施，先決條件為翠綠閒庭成員；可容納一隻巨型或兩隻大型生物。下達招募時，骰值為偶數則一隻自然生靈於 7 天後入住，可作為據點衛兵；可選擇讓其依天性活動而不參與防衛。
