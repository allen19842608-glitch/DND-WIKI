# 豎琴手 (Harpers)

豎琴手以間諜、偵探與吟遊詩人的方式對抗壓迫，主張權力、財富與知識不應由少數人獨占。他們沒有中央指揮部，主要以小隊、獨立特工與要塞形成鬆散網絡。

## 組織與加入

- 準則強調自由、公正與平衡；格言可作為口令與身分驗證。
- 候選人必須在不知情下通過品格考驗，受邀後向資深成員宣誓。背叛者通常遭逐出，甚至面臨嚴厲報復。
- 至高豎琴手負責長期計畫與重大戰役，但極少公開聚會。

## 聲望獎勵

| 聲望 | 獎勵 |
| :--- | :--- |
| 3+ | 可於豎琴手要塞留宿，獲得簡樸生活方式。 |
| 5+ | 可購買普通藥水與卷軸。 |
| 10 | 習得一個豎琴手偽裝身分。 |
| 15+ | 要塞內藥水、卷軸與冒險裝備享 15% 折扣。 |
| 25、40 | 分別獲得銀／金豎琴手徽章與額外偽裝身分。 |
| 30+ | 初抵定居地時，當地豎琴手分享值得注意的傳言與情報。 |
| 50+ | 可與一名至高豎琴手單獨會面一次。 |

## 成員與據點

- 新成員獲得一件樂器與一套易容工具；常見成員包括吟遊詩人、遊蕩者、遊俠、術士與法師。
- **豎琴手藏身處**是 5 級、寬敞、1 名僱員的增強設施，先決條件為豎琴手成員。它以不超過四分之一里長的隧道連接據點，並受[[法術/1環/警報術|警報術 (Alarm)]]保護。
- 9 級時可改以魔法門連接並放在據點周圍 100 里內；13 級可置於費倫任意地點；17 級的門可跨位面。增強時，若擲骰為偶數，一名特工到訪 7 天；角色每天花至少 8 小時訓練，可在欺瞞、調查或表演中取得一項熟練 7 天。
