# 散塔林會 (Zhentarim)

散塔林會（暗黑情報網）是商人、傭兵與不法之徒組成的鬆散網絡。它以財富與個人野心驅動，擅長護運、情報、武力與不受法律歡迎的生意；主要根據地是黑暗堡，但在費倫各地設有前哨。

## 組織與成員

- 成員彼此以「家族」相稱，但正式階級從爪牙、惡狼、蝰蛇、強龍到魔王；最高首腦是神祕的派裡高斯特。
- 組織與班恩、希瑞克有歷史關聯，部分成員也追隨九層地獄的魔王。
- 成員可在任務開始時借用一件價值不超過 50 GP 的武器或護甲；任務結束必須歸還，否則支付兩倍價格。身處聚落時，成員總能找到傭兵工作。

## 聲望獎勵

| 聲望 | 獎勵 |
| :--- | :--- |
| 3+ | 取得「爪牙」頭銜，可在控制區的安全屋與旅店以窮困開支住宿。 |
| 5+ | 可在各類聚落穩定銷贓。 |
| 10 | 首次達成時獲得隨機非普通魔法物品。 |
| 15+、25+ | 取得「惡狼」、「蝰蛇」頭銜；在控制市場購買武器、護甲與冒險裝備享 10% 折扣，並在控制聚落的魅力（威嚇）檢定具有優勢。 |
| 30+ | 可派遣至多六名間諜執行一次不妨礙會務的任務，並取得一枚散塔林會徽的憑證。 |
| 40 | 取得「強龍」頭銜與建立據點的權限、資金；可請一隻眼魔協助單次任務。 |
| 50+ | 取得「魔王」頭銜；首次達成時，特工免費對你施展[[法術/8環/克隆術\|克隆術 (Clone)]]。 |

## 散塔林驛站

**散塔林驛站**是 5 級、龐大、2 名僱員的探索設施，先決條件為散塔林會成員。它可暫置四隻大型生物（兩隻中型生物等同一隻大型生物）。

- 在據點完成長休後，隊伍的最高旅行步調提高一級。
- 下達探索指令後，僱員花 7 天偵察；下一段旅行中，隊伍為覓食或導航進行的感知（求生）檢定具有優勢。
