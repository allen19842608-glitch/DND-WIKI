# 侏儒神系

## 概覽

《劍灣冒險者指南》將下列神祇列為侏儒神系成員。（來源：《劍灣冒險者指南》，p. 24）

| 神祇 | 陣營 | 領域 | 聖徽 |
| :--- | :--- | :--- | :--- |
| 貝爾凡・野遊者（林地之神） | NG | 自然 | 浣熊的臉 |
| 巴瑞瓦・影斗篷（幻術與欺瞞之神） | NG | 奧秘、詭術 | 一件掛起的披風前抵著匕首 |
| 卡勒杜蘭・滑手（採礦與刻石之神） | N | 知識、自然 | 帶六芒星的金色璽戒 |
| 弗蘭達・鋼皮（金工之神） | NG | 知識 | 燃燒之錘 |
| 蓋爾達爾・鐵手（保護之神） | LG | 戰爭 | 鐵箍 |
| 加爾・閃金（詭計與寶石之神） | LG | 詭術 | 金塊 |
| 奈貝倫（發明與幸運之神） | CG | 知識、詭術 | 風箱與蜥蜴尾巴 |
| 沙苟貞・大地喚者（土與死者之神） | NG | 光明 | 發光的寶石 |
| 厄爾德連（貪婪與謀殺之神） | CE | 死亡、戰爭 | 從土中現身的白色鼴鼠 |

## 歷史與現況

- 本來源提供神系名錄，未另敘述其歷史演變。（來源：《劍灣冒險者指南》，p. 24）

## 重要關係

無。

## 來源差異與不確定性

- 無。既有 Wiki 曾誤植獸人神系表；中文譯文原檔與英文原文均為侏儒神系表，已據此更正。
