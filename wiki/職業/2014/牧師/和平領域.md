# 和平領域 (Peace Domain，2014 Legacy)

> [!WARNING] 本條目為 2014 舊版規則。

**子職定位**：這些和平的牧師們難道就沒有想過，他們其實在違背一條最為深刻的道理嗎？這道理便是：自作，自受。 在每個健康的社群，友好的諸國，以及善良的靈魂心中，永遠存在著對和平的嚮往。和平之神們激勵著所有人平息衝突，並對試圖打破和平的力量奮起反抗。和平神祇表格中包含了一部分擁有該領域的神明。 和平領域的牧師會主持條約的簽訂儀式，同時還常常被請求秉公裁斷，解決爭端。這些牧師的祝福讓人們眾志成城，同舟共濟。而這些牧師的魔法對於那些為和平而戰之人則如同雪中送炭。 **和平神祇 Peace Deities** | **神祇範例** | **神系** | | --- | --- | | 安格芮絲 Angharradh | 精靈 | | 蓓倫妮真銀 Berronar Truesilver | 矮人 | | 博得雷 Boldrei | 艾伯倫 | | 希勞拉妮 Cyrrollalee | 半身人 | | 埃達絲 Eldath | 被遺忘的國度 | | 蓋爾達爾鐵手 Gaerdal Ironhand | 侏儒 | | 帕拉丁 Paladine | 龍槍 | | 拉奧 Rao | 灰鷹 | **領域法術 Domain Spells** **_第1級和平領域特性_** 當你獲得和平領域法術表中所對應的牧師等級時，你將同時習得這些法術。檢視玩家手冊中的神聖領域職業特性來瞭解什麼是領域法術。 **和平領域法術 Peace Domain Spells** | **牧師等級** | **法術** | | --- | --- | | 1st | _英雄氣概 heroism，庇護術 sanctuary_ | | 3rd |

### 子職特性詳解

#### 1 級：和平執行 (Implement of Peace)

- **效果**：你獲得洞悉、表演、或遊說技能的熟練項（由你選擇）。

#### 1 級：勇氣聯結 (Emboldening Bond)

- **效果**：你創造出一條力量的聯結，聯絡彼此之間和平相處的人。以一個動作，你可以選擇你周圍30 呎範圍內等同於你熟練加值數量的自願生物（可以包括你自己）。你在他們之間創造出一條持續10 分鐘的魔法聯結。當任一聯結生物的30 呎範圍記憶體在另一個或多個被聯結的生物時，在他進行的攻擊檢定、屬性檢定、或豁免檢定時，可以額外擲一枚 d4並加入那次檢定中。每個生物每回合只能因此加一次 d4。若你再次使用此特性，上一條魔法聯結就會立刻終止。
你可以使用此特性的次數等同於你的熟練加值，當你完成一次長休時恢復所有使用次數。

#### 2 級：引導神力：引導神力 Channel Divinity:Balm of (Peace)

- **效果**：你可以用引導神力來減輕痛苦，慰籍心靈。以一個動作，你可以移動等同於你速度的距離，此次移動不會引發藉機攻擊。當你在此動作期間移動到了任意其他生物周遭5 呎範圍內時，你都可以為其恢復2d6+你的感知調整值的生命值（最低1點生命值）。每次你使用這個引導神力時，每個生物只能從其中獲得一次治療。

#### 6 級：保護聯結 (Protective Bond)

- **效果**：你創造的聯結幫助人們同甘共苦。當一個受到你勇氣聯結影響的生物即將受到傷害時，30 呎內的另一個聯結生物可以用它的反應來傳送到第一個生物周圍5 呎的一處未佔據空間內，並代替那個生物承受所有傷害。

#### 8 級：強力施法 (Potent Spellcasting)

- **效果**：你施展牧師戲法造成傷害時，可以再加上你的感知調整值。

#### 17 級：增強聯結 (Expansive Bond)

- **效果**：_你的勇氣聯結和保護聯結的現在能在兩個聯結生物之間距離不超過60 呎時被應用。此外，當一個生物使用保護聯結來為其他人承受傷害時，還能被視為具有對那次傷害的抗性。_
