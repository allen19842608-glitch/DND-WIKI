# 妖精漫遊者 (Fey Wanderer，2014 Legacy)

> [!WARNING] 本條目為 2014 舊版規則。2024 新版請參閱 [[職業/遊俠/妖精漫遊者|妖精漫遊者 (Fey Wanderer)]]。

**子職定位**：你說，妖精漫遊的浪漫是不是離不開蘇格蘭短裙這個要素？什麼，你說沒有這回事？別胡說八道！ 或來自一位至高妖精的恩惠，或是來自你食用的一枚從能言之樹上取下的閃亮果實，或是來自你曾浸遊於中的魔法清泉，或是來自其他妙事，你的身側因那次奇遇而有妖精的魔力纏繞。 無論你是怎麼得到你來自妖精的魔法的，你現在是一名代表了凡間與妖精國度雙方的遊俠妖精漫遊者。你漫步於多元宇宙之時，你輕快的笑聲為受壓迫者們帶來欣喜的希望，你英勇的技藝直擊你敵人的恐懼，你所就的偉績乃是妖精的喜悅，你散步的恐懼乃是妖精的憤怒。

### 子職特性詳解

#### 3 級：哀懼打擊 (Dreadful Strikes)

- **效果**：_你能夠使用來自妖精荒野中黑暗空洞的攝心魔法以強化你的武器攻擊。當你用一把武器擊中一個生物時，你可以對目標造成額外的1d4點心靈傷害。每個生物在每個回合只能夠受到這一額外傷害一次。_
你的遊俠等級達到11級時，這一額外傷害變為1d6。
（校對注：按照原文的 which can take 來看，其“一回合一次”的主語是“每個生物受到一次傷害”，而非與其他遊俠一樣是“造成一次傷害”。
意味著5級之後攻擊兩個不同目標時，兩個目標都能受到額外1d4點心靈傷害。.
此外，這裡的條件是“用武器”，而不是“武器攻擊”。簡而言之就是能夠享受某些特定增益或效果的，與其他同類文字不同的文字。謹慎甄別。 ）

#### 3 級：妖精漫遊者魔法 (Fey Wanderer Magic)

- **效果**：你在達到特定等級時，你會額外習得一個下方妖精漫遊者法術列表中列出的法術。這些法術對你而言視作遊俠法術，且不計入你的遊俠已知法術數量中。
**妖精漫遊者法術 Fey Wanderer Spells**
| **遊俠等級** | **法術** |
| --- | --- |
| 3rd | 魅惑類人 charm person |
| 5th | _迷蹤步 misty step_ |
| 9th | _解除魔法 dispel magic_ |
| 13th | _任意門 dimension door_ |
| 17th | _假象術 mislead_ |
你還獲得了來自一位妖精盟友或一處妖精神力的神奇祝福。你可以在下方妖精荒原之賜表格中選擇你的祝福，或者隨機決定它。
**精野之賜 Feywild Gifts**
| **D6** | **贈禮** |

| 3 | 你身上有淡淡的肉桂、薰衣草或肉豆蔻，或另一種令人舒適的藥草或香料的香味。 |

#### 3 級：異界魅力 (Otherworldly Glamour)

- **效果**：_你的妖精本質給予了你超脫凡俗的魅惑力。因此，每當你進行一次魅力檢定時，你都可以在那次檢定中獲得等同於你的感知調整值的加值（至少+1）。_
另外，你獲得下列技能之一的熟練項（由你選擇）：欺瞞、表演、或遊說。

#### 7 級：扭轉迷惑 (Beguiling Twist)

- **效果**：妖精荒原的魔法護衛著你的心靈。你在對抗陷入魅惑或恐懼的豁免檢定上具有優勢。
此外，當你或周圍120 呎內你可見的一個生物成功透過了一次對抗魅惑或恐懼的豁免檢定時，你可以用你的反應迫使120 呎內的另一個你可見的不同生物透過一次感知豁免，豁免 DC 等同於你的法術豁免 DC。若其豁免失敗，則目標被你魅惑，或對你恐懼（由你選擇），持續 一分鐘。目標能夠在他的每回合結束時重複這次豁免，豁免成功時效果提前終止。

#### 11 級：精類增援 (Fey Reinforcements)

- **效果**：妖精荒原的皇庭賜予你獲得妖精援助的祝福：你習得法術 _妖精召喚術 summon fey_（一個出自第三章的法術)。它不計入你的已知遊俠法術，且你施展它時無需材料成分。你可以免費施展這個法術一次而不需要消耗法術位，在你完成一次長休後，你重獲免費施展該法術的能力。
每當你施展 _妖精召喚術 summon fey_ 前，你都可以微調這一法術使其本次施展與維持無需你保持專注。以無需專注的方式施展時，該法術的持續時間將變為一分鐘。

#### 15 級：迷霧漫遊 (Misty Wanderer)

- **效果**：你可以在眨眼之間穿梭妖精荒原以進行移動：你可以免費施展 _迷蹤步 misty step_而不需要消耗法術位，次數等同於你的感知調整值次（至少一次），在完成一次長休後，你重獲所有的已消耗的次數。
另外，每當你施展 _迷蹤步 misty step_時，你可以攜帶一個五呎以內你可見的自願生物與你一同傳送。那個生物會被傳送到由你選擇的，位於你的目標位置周圍五呎範圍內的一處未佔據空間內。
