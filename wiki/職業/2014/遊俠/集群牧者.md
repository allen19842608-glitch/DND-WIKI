# 集群牧者 (Swarmkeeper，2014 Legacy)

> [!WARNING] 本條目為 2014 舊版規則。

**子職定位**：我愛昆蟲——這些成群結隊、無所畏懼、專攻一事的小傢伙們。但，請用你自己的單細胞腦瓜子，來糾正一下這些昆蟲的單細胞腦瓜子：好看，但給我滾出我的實驗室！ 有的遊俠感受到了與周身自然之間的緊密聯絡，他們透過自己與世界之間的魔法聯絡向自然的本源伸出雙手，並透過一片自然精魂的叢集與自然本身羈連。叢集隨後化作戰鬥中的強力幫手，或遊俠的一位得力助手。有的遊俠是被放逐者或是隱士他們更在意修行自我而非與他人打交道並找不快。而其他的叢集牧者則樂意創造服務於所有被他們視為自然叢集的一部分者集體利益的美麗社會。 （校注：該職業在萬智牌中被譯作“叢集守衛”，曾沿用）

### 子職特性詳解

#### 3 級：蜂聚叢集 (Gathered Swarm)

- **效果**：無形自然精魂形成的叢集與你形影不離並會在戰鬥中對你施以援手。直到你死亡為止，叢集會存在於你的空間中，在你身上爬行或在你周身的空間裡飛舞或竄動。你自行決定叢集的外觀，或者你投擲叢集外觀表格來決定其外觀。
**叢集外觀 Swarm Appearance**
| **D4** | **外觀** |
| --- | --- |
| 1 | 群聚的昆蟲 |
| 2 | 微小的枯枝怪 |
| 3 | 飛舞的群鳥 |
| 4 | 好動的皮克精 |
每個你的回合一次，當你的攻擊命中一個生物後，你能立刻讓叢集以以下一種方式助你一臂之力：
-   叢集對這次攻擊的目標造成1d6點穿刺傷害。
-   這次攻擊的目標必須成功透過對抗你法術豁免 DC 的力量豁免檢定，豁免失敗將被叢集水平移動最多15 呎，方向由你選擇。
-   你被叢集水平移動5 呎，方向由你選擇。
#### 3 級：叢集牧者魔法 (Swarmkeeper Magic)
若你之前還未習得 _法師之手 mage hand_ 這個戲法，你習得之。當你施展法師之手時，那隻手會以你的叢集自然精魂形態出現。
此外，當你到達指定遊俠等級時，你會習得一個額外的1環或更高環階的法術，如叢集牧者法術列表所示。這些法術對你視為遊俠法術，且不計入你的已知法術總數中。
**叢集牧者法術 Swarmkeeper Spells**
| **遊俠等級** | **法術** |
| --- | --- |
| 3rd | _妖火 faerie fire_ |
| 3rd | _法師之手 mage hand_ |
| 5th | _蛛網術 web_ |
| 9th | _氣化形體 gaseous form_ |
| 13th | _秘法眼 arcane eye_ |
| 17th | _疫病蟲群 insect plague_ |
#### 7 級：翻騰浪湧 (Writhing Tide)
你能將你的叢集的一部分凝聚成一股集中的力量，來將你托起。以一個附贈動作，你獲得10 呎飛行速度，且能懸浮。該效應持續1 分鐘。若你陷入失能狀態，它會提前結束。
你能使用該特性的次數等於你的熟練加值次，在完成一次長休後你重獲全部消耗的次數。

#### 11 級：壯大叢集 (Mighty Swarm)

- **效果**：你的蜂聚叢集透過以下方式變得更加強大：
-   蜂聚叢集造成的傷害提升至1d8。
-   如果一個生物在對抗被蜂聚叢集移動的豁免中失敗，你還能驅使叢集將該生物擊倒在地（陷入倒地）。
-   當你被蜂聚叢集移動後，它會使你獲得半身掩護，直至你下個回合開始前。
#### 15 級：群逸逃散 (Swarming Dispersal)
你能將自己散入叢集來躲避危險。當你受到傷害時，你能使用你的反應讓自己獲得對該次傷害的抗性。你會消失在自己的叢集之中，然後傳送至30 呎內一個未被佔據的可見空間中，你的叢集使你重新出現在那裡。
你能使用該特性的次數等於你的熟練加值次，在完成一次長休後你重獲全部消耗的次數。
> [!info] 補充資訊
> **它是你的叢集 It's Your Swarm
> **一位叢集牧者的叢集和法術反應了角色與自然精魂的聯絡。在遊戲中，多抓住機會來描述你自己的叢集和遊俠法術。比方說，當你的遊俠施展氣化形體 gaseous form 時，施法物件可能會消失在他自己的叢集中，而非變為一團霧氣，而秘法眼 arcane eye 則可以創造出一部分分離的叢集為你進行偵查。這樣的描述不會改變法術的效應，但它們能讓透過特性描述自己的角色更加引人入勝。需要更多個性化法術的指導，請見第一章中的“定製法術”一節。
> 同樣，記住你得叢集外表能由你自己定製，別侷限於單一的造型。也許精魂的外表會隨著遊俠的情緒而千變萬化，或者隨著季節而呈現出不同的形象。這一切都由你自己選擇。
