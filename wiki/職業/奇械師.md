# 奇械師 (Artificer)

## ⚙️ 規則條文 (Rule Text)

### 奇械師核心特質 (Core Artificer Traits)

| 項目     | 內容                        |
| :----- | :------------------------ |
| 主要屬性   | 智力                        |
| 生命骰    | 每奇械師等級 d8                 |
| 豁免檢定熟練 | 體質、智力                     |
| 技能熟練   | 任選兩項：奧秘、歷史、調查、醫藥、自然、察覺或巧手 |
| 武器熟練   | 簡易武器                      |
| 護甲訓練   | 輕甲、中甲、盾牌                  |
| 工具熟練   | 盜賊工具、修補工具及一種工匠工具          |

### 成為一名奇械師 (Becoming an Artificer)

#### 作為 1 級角色

- 獲得核心特質、施法與工藝魔法。（來源：EFA 2025，奇械師章節）

#### 作為多職角色

- 獲得生命骰、修補工具熟練、一項奇械師技能熟練，以及輕甲、中甲與盾牌訓練；施法者等級計算時加入奇械師等級的一半（向上取整）。（來源：EFA 2025，奇械師章節）

### 🛡️ 職業特性詳解 (Class Features Description)

#### 1 級：施法 (Spellcasting)

- 以工具作為施法法器，施法屬性為智力；準備的奇械師法術可在長休後更換。（來源：EFA 2025，奇械師章節）

#### 1 級：工藝魔法 (Tinker's Magic)

- 學會修復術，並可在持握修補工具時創造指定的普通物品；使用次數等於智力調整值（最低一次），長休後恢復。（來源：EFA 2025，奇械師章節）

#### 2 級：仿製魔法物品 (Replicate Magic Item)

- 學習魔法物品方案，並於長休結束時依已知方案創造暫時性魔法物品。（來源：EFA 2025，奇械師章節）

#### 20 級：奇械之魂 (Soul of Artifice)

- 詳細效果待依來源段落增量編譯。

## 💡 實戰應用與裁量 (DM Ruling)

- 奇械師的工具需求與魔法物品數量，應在長休結束時一併確認。
