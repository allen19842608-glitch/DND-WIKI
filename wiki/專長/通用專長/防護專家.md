# 防護專家 (Abjuration Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/護盾術\|護盾術 (Shield)]] |
| 2 | [[wiki/法術/2環/次等復原術\|次等復原術 (Lesser Restoration)]] |
| 3 | [[wiki/法術/3環/防護能量\|防護能量 (Protection from Energy)]] |
| 4 | [[wiki/法術/4環/放逐術\|放逐術 (Banishment)]] |
| 5 | [[wiki/法術/5環/群體療傷術\|群體療傷術 (Mass Cure Wounds)]] |

- **守護結界 (Protective Ward)**：使用法術位施展防護學派法術時，自己或 30 呎內一名可見生物獲得等於所用法術位環階兩倍的臨時生命值。（來源：第一章，p. 28）
