# 通用專長索引 (General Feats Index)

> 本索引彙整本分類已建立的條目，依頁面現有分組與名稱排序。

## 規則條文

除非另有說明，2024 通用專長的先決條件為等級 4 以上；多數專長同時提供一項屬性值提升（最高 20）。以下為中文翻譯資料中的完整索引，個別專長將依序建立獨立條目。

| 英文 | 中文 | 核心效果摘要 |
| :--- | :--- | :--- |
| Ability Score Improvement | 屬性值提升 | 提升一項屬性 2，或兩項各 1（最高 20） |
| Actor | 演員 | 魅力提升；偽裝與擬聲 |
| Athlete | 運動健將 | 力量／敏捷提升；攀爬、迅速起身、跳躍 |
| Charger | 衝鋒手 | 強化衝刺；移動 10 呎後攻擊可追加傷害或推撞 |
| Chef | 廚師 | 廚師炊具；短休額外治療；臨時生命值零食 |
| Crossbow Expert | 強弩專家 | 無視裝填；近戰弩攻擊不劣勢；輕型弩額外攻擊 |
| Crusher | 粉碎者 | 鈍擊推移；鈍擊重擊後攻擊優勢 |
| Defensive Duelist | 防禦式決鬥 | 靈巧武器反應加熟練值至 AC |
| Dual Wielder | 雙持客 | 強化雙持與快速拔收 |
| Durable | 堅韌不屈 | 體質提升；死亡豁免優勢；附贈動作消耗生命骰恢復 |
| Elemental Adept | 元素行家 | 法術忽略所選元素抗性，傷害骰 1 視為 2 |
| Fey-Touched | 精類之觸 | 獲得預言／惑控一環法術與迷蹤步 |
| Grappler | 擒抱者 | 徒手打擊兼擒抱；擒抱目標攻擊優勢 |
| Great Weapon Master | 巨武器大師 | 重型武器額外傷害；重擊或擊倒後附贈攻擊 |
| Heavily Armored | 重甲運用 | 力量／體質提升；取得重甲訓練 |
| Heavy Armor Master | 重甲大師 | 力量／體質提升；重甲減少鈍擊、穿刺、揮砍傷害 |
| Inspiring Leader | 激勵領袖 | 短休／長休後最多六名盟友取得臨時生命值 |
| Keen Mind | 敏銳心智 | 智力提升；知識技能熟練或專精；附贈動作研究 |
| Lightly Armored | 輕甲運用 | 力量／敏捷提升；取得輕甲與盾牌訓練 |
| Mage Slayer | 法師殺手 | 使專注豁免劣勢；智力、感知或魅力豁免失敗可改成功 |
| Martial Weapon Training | 軍武訓練 | 力量／敏捷提升；取得軍用武器熟練 |
| Moderately Armored | 中甲運用 | 力量／敏捷提升；取得中甲訓練 |
| Medium Armor Master | 中甲大師 | 中甲且敏捷 16 以上時 AC 敏捷上限提高至 3 |
| Mounted Combatant | 騎乘戰鬥 | 騎乘攻擊優勢；坐騎閃避；可替坐騎承受攻擊 |
| Observant | 敏銳觀察 | 智力／感知提升；洞悉、調查或察覺熟練／專精；附贈動作搜索 |
| Piercer | 穿刺者 | 穿刺傷害重骰；穿刺重擊額外傷害骰 |
| Poisoner | 製毒師 | 毒素忽略抗性；製作與施用毒藥 |
| Polearm Master | 長柄大師 | 長柄武器附贈攻擊；敵人進入觸及範圍可反應攻擊 |
| Resilient | 適應力 | 提升一項未具熟練的屬性並取得其豁免熟練 |
| Ritual Caster | 儀式施法者 | 準備儀式法術；可快速儀式施法（長休恢復） |
| Sentinel | 哨兵 | 盟友附近敵人觸發藉機攻擊；命中後速度歸零 |
| Shadow-Touched | 陰影之觸 | 獲得幻術／死靈一環法術與隱形術 |
| Sharpshooter | 神射手 | 遠程攻擊無視掩護、近戰劣勢與遠射程劣勢 |
| Shield Master | 盾牌大師 | 盾牌衝撞；敏捷豁免成功可用反應免傷 |
| Skill Expert | 技能專家 | 任選屬性提升、技能熟練與一項技能專精 |
| Skulker | 潛行者 | 10 呎盲視；戰鬥躲藏優勢；未命中不暴露位置 |
| Slasher | 劈砍者 | 揮砍降低速度；揮砍重擊使攻擊劣勢 |
| Speedy | 迅捷 | 速度 +10 呎；衝刺忽略困難地形；藉機攻擊劣勢 |
| Spell Sniper | 法術射手 | 法術攻擊無視掩護、近戰劣勢；遠程增加 60 呎 |
| Telekinetic | 心靈致動者 | 法師之手強化；附贈動作推拉 30 呎內生物 |
| Telepathic | 心靈感應者 | 60 呎心靈傳語；免費施放偵測思想（長休恢復） |
| War Caster | 戰鬥施法者 | 專注豁免優勢；藉機攻擊可改施法；持武器仍可施法 |
| Weapon Master | 武器大師 | 力量／敏捷提升；取得一種武器精通並可長休更換 |

（來源：DND 2024 中文翻譯，pp. 19-37）
