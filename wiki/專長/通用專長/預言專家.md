# 預言專家 (Divination Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/偵測善惡\|偵測善惡 (Detect Evil and Good)]] |
| 2 | [[wiki/法術/2環/心靈尖刺\|心靈尖刺 (Mind Spike)]] |
| 3 | [[wiki/法術/3環/鷹眼術\|鷹眼術 (Clairvoyance)]] |
| 4 | [[wiki/法術/4環/預言術\|預言術 (Divination)]] |
| 5 | [[wiki/法術/5環/探知術\|探知術 (Scrying)]] |

- **先見干預 (Prescient Intervention)**：60 呎內可見生物進行 D20 檢定時，可用反應給予此次擲骰優勢或劣勢；長休後恢復使用，也可在使用法術位施展預言學派法術時恢復使用。（來源：第一章，p. 29）
