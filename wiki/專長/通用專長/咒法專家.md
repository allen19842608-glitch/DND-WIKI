# 咒法專家 (Conjuration Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/糾纏術\|糾纏術 (Entangle)]] |
| 2 | [[wiki/法術/2環/迷蹤步\|迷蹤步 (Misty Step)]] |
| 3 | [[wiki/法術/3環/咒喚獸群\|咒喚獸群 (Conjure Animals)]] |
| 4 | [[wiki/法術/4環/任意門\|任意門 (Dimension Door)]] |
| 5 | [[wiki/法術/5環/咒喚元素\|咒喚元素 (Conjure Elemental)]] |

- **恆久咒法 (Persistent Conjuration)**：維持咒法學派法術專注的體質豁免，加上本專長提升屬性的調整值。（來源：第一章，p. 28）
