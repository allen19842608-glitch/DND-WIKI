# 惑控專家 (Enchantment Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/不諧低語\|不諧低語 (Dissonant Whispers)]] |
| 2 | [[wiki/法術/2環/注目術\|注目術 (Enthrall)]] |
| 3 | [[wiki/法術/2環/定身類人\|定身類人 (Hold Person)]] |
| 4 | [[wiki/法術/4環/支配野獸\|支配野獸 (Dominate Beast)]] |
| 5 | [[wiki/法術/5環/篡改記憶\|篡改記憶 (Modify Memory)]] |

- **精妙惑控 (Subtle Enchantments)**：使用法術位施展惑控學派法術時，可省略言語、姿勢及材料成分；有指定成本或會消耗的材料仍須提供。（來源：第一章，p. 30）
