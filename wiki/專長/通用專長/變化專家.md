# 變化專家 (Transmutation Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/跳躍術\|跳躍術 (Jump)]] |
| 2 | [[wiki/法術/2環/蛛行術\|蛛行術 (Spider Climb)]] |
| 3 | [[wiki/法術/3環/緩慢術\|緩慢術 (Slow)]] |
| 4 | [[wiki/法術/4環/變形術\|變形術 (Polymorph)]] |
| 5 | [[wiki/法術/5環/活化物件\|活化物件 (Animate Objects)]] |

- **魔法增幅 (Magical Augmentation)**：在自己回合使用法術位施展變化學派法術時，速度增加所用法術位環階 × 5 呎，至該回合結束。（來源：第一章，p. 32）
