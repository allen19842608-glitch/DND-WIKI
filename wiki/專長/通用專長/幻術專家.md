# 幻術專家 (Illusion Adept)

- **前置條件 (Prerequisite)**：4 級以上；施法或契約魔法特性
- **屬性提升 (Ability Score Increase)**：從智力、感知、魅力選一項增加 1，上限 20。

## 🌟 專長效果描述

- **額外準備法術**：具備表列環階的法術位後，始終準備該環階及以下的表列法術。

| 法術位環階 | 法術 |
| :---: | :--- |
| 1 | [[wiki/法術/1環/無聲幻影\|無聲幻影 (Silent Image)]] |
| 2 | [[wiki/法術/2環/魅影之力\|魅影之力 (Phantasmal Force)]] |
| 3 | [[wiki/法術/3環/高級幻影\|高級幻影 (Major Image)]] |
| 4 | [[wiki/法術/4環/幻景\|幻景 (Hallucinatory Terrain)]] |
| 5 | [[wiki/法術/5環/偽裝術\|偽裝術 (Seeming)]] |

- **幻象宗師 (Masterful Illusions)**：使用法術位施展幻術學派法術時，可省略言語、姿勢及材料成分；有指定成本或會消耗的材料仍須提供。（來源：第一章，p. 30）
- **幻象宗師 (Masterful Illusions)**：生物以智力（調查）識破你的法術幻象時，檢定具有劣勢。（來源：第一章，p. 30）
