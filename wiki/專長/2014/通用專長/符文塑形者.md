# 符文塑形者 (Rune Shaper，2014 Legacy)

- **前置條件 (Prerequisite)**：施法特性或符文雕刻者背景

## 🌟 專長效果描述

- **通曉語言 (Comprehend Languages)**：你習得通曉語言。每次長休之間可不消耗法術位施展此法術一次；你也可以用自己擁有的法術位施展它。

- **符文魔法 (Rune Magic)**：你知曉的符文數量等同於熟練加值的一半（向下取整），從下表選擇。每次完成長休時，可將每個已知符文刻印在一件你觸碰的非魔法武器、護甲、一套衣物或其他物件上；直到下一次長休前，你暫時習得各刻印符文對應的 1 環法術，並可用自己擁有的法術位施展。
  - 當你攜帶或穿著刻印符文的物件時，可不消耗法術位且不需材料成分，施展該符文對應的法術一次；施展任一個這樣的法術後，直到完成長休前不能再次使用此能力。
  - 選擇此專長時，選擇智力、感知或魅力作為本專長的施法屬性；每當你升級時，可用下表中不同的符文替換一個已知符文。

| 符文 | 對應法術 |
| :--- | :--- |
| 雲霧 (Cloud) | 雲霧術 (Fog Cloud) |
| 死亡 (Death) | 致傷術 (Inflict Wounds) |
| 騰龍 (Dragon) | 繁彩球 (Chromatic Orb) |
| 仇敵 (Enemy) | 易容術 (Disguise Self) |
| 火焰 (Fire) | 燃燒之手 (Burning Hands) |
| 友誼 (Friend) | 動物交談 (Speak with Animals) |
| 寒霜 (Frost) | 黯冰獄鎧 (Armor of Agathys) |
| 山丘 (Hill) | 神莓術 (Goodberry) |
| 旅途 (Journey) | 大步奔行 (Longstrider) |
| 君王 (King) | 命令術 (Command) |
| 山脈 (Mountain) | 糾纏術 (Entangle) |
| 岩石 (Stone) | 庇護術 (Sanctuary) |
| 風暴 (Storm) | 雷鳴波 (Thunderwave) |
