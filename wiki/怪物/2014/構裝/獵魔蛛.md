# 獵魔蛛 (Retriever)

## ⚙️ 規則條文 (Rule Text)

*大型構裝，普遍守序邪惡*

**AC** 19（天生護甲）

**HP** 210（20d10+100）

**速度** 40 呎、攀爬40 呎

**技能** 察覺+5、隱匿+8

**感官** 盲視30 呎，黑暗視覺60 呎，被動察覺15

**語言** 理解深淵語、精靈語、及地底通用語，但不能說

**傷害抗性／免疫** 暗蝕、毒素、心靈；非魔法且非精金攻擊的鈍擊、穿刺、揮砍

**狀態免疫** 魅惑、力竭、恐慌、麻痺、中毒

**CR** 14（11,500 XP） 熟練加值+5

### 動作 (Actions)

- **多重攻擊（Multiattack）**：獵魔蛛發動兩次前肢攻擊，然後使用力場射線或麻痺射線（若可用）。
- **前肢（Foreleg）**：近戰武器攻擊：命中+11，觸及10 呎，單一目標。命中：15（2d8+6）點揮砍傷害，
- **力場射線（Force Beam）**：獵魔蛛指定周圍60 呎範圍內的一個可見生物為目標。迫使目標通過一次 DC16的敏捷豁免，豁免失敗將受到27（5d10）點力場傷害，豁免成功則只受半數傷害。
- **麻痺射線（Paralyzing Beam（充能5~6））**：獵魔蛛指定周圍60 呎範圍內的一個可見生物為目標。迫使目標通過一次 DC18的體質豁免，豁免失敗將陷入 麻痺 Paralyzed 狀態，持續1分鐘。因此被麻痺的目標可以在每個其自己回合結束時重複此豁免，豁免成功則它身上的此麻痺效應提前結束。 如果被麻痺的生物體型不超過中型，獵魔蛛可以將其撿起（作為移動的一部分），並且保持全速移動或者攀爬。
- **施法（Spellcasting）**：獵魔蛛施展以下法術之一，無需任何材料成分，且以感知為其施法屬性（法術豁免 DC 13）： 每項3/日：位面轉移 plane shift（僅限自身和至多一個失能生物（該生物被法術視為“自願生物”）），蛛網術 web
