# 邪教徒介紹 (Cultists)

## 📖 怪物介紹

末日崇拜者與邪教狂信徒

**棲息地：** 任意；**寶藏：**個體，聖物

邪教徒使用魔法以及其他極端手段來傳播其激進的信仰。一些邪教團是追求玄奧隱秘的密教團體，而另一些則是活躍於暗面的陰謀集團，意圖實現某種怖人的大業。邪教徒們通常遵循著晦澀的密教習俗行事，或是醉心於解讀古老的預言。它們還可能將其信仰獻上給超自然的宗主——神靈、異界的生物、擅於操弄凡人的異質心靈、甚至是其他更加詭異的力量。擲一次邪教大業表或從中選擇一個結果，以此啟發一夥邪教徒們會意欲達成什麼樣的目標。

**邪教大業**

| **1d6** | **這一邪教團致力於……** |
| --- | --- |
| 1 | 終結一個政權、一個時代、甚至是整個世界。 |
| 2 | 燃盡世間那些欺騙著凡人的美好，揭露其下的殘酷現實。 |
| 3 | 通過洗腦和壓迫來擴張其的信仰。 |
| 4 | 改變整個世界，例如令大地悉數沉沒、令萬千火山噴發。 |
| 5 | 大規模地重新塑造生命的形態，改變其他生物的肉體或精神。 |
| 6 | 將其“神靈”召喚入現世，至少也要召喚其神靈的令使、武器、甚至是“神國”。 |

### 密教聖印 Occult Symbols

邪教徒通常依靠聖印來分辨教團的成員。這些聖印通常印在邪教的標誌性物品上，亦可能印在衣物上、甚至可能直接刻在邪教徒的身體上。聖印的意義可能很容易理解，亦可能只有教團成員才能分辨。擲一次邪教聖印表或從中選擇一個結果，以此啟發邪教團會使用什麼作為自己的標誌。

**邪教聖印**

| **1d10** | **聖印是……** | **被描繪為……** |
| --- | --- | --- |
| 1 | 一枚鍊金學符印 | 一份萬年曆或地圖 |
| 2 | 一種動物 | 一份羽飾或某種紋章 |
| 3 | 一顆天體 | 一份複雜的圖樣 |
| 4 | 一尊神靈的徽記 | 一張暗示性的圖畫 |
| 5 | 一種元素 | 一個神秘存在 |
| 6 | 一顆眼睛 | 某份公式的一部分 |
| 7 | 一個幾何圖形 | 一張重複的圖案 |
| 8 | 一個字母或是一個數字 | 一系列抓痕 |
| 9 | 怪物的一部分 | 一個簡單的象形字畫 |
| 10 | 一顆顱骨 | 一把武器或工具 |
