# 祭司介紹 (Priests)

## 📖 怪物介紹

聖旨與凡塵的裁量者

**棲息地：** 任意；**寶藏：**個體，聖物

牧師駕馭信仰之力，於塵世中行施奇蹟。這些宗教信徒的類型和其所信仰的對象那般多樣。一些祭司服從於其所信仰的神祇及其僕從，而另一些祭司則踐行著古老的信條。信仰引領著祭司們的行動，為它們的魔法之力指引方向，讓祭司們依照自己所屬的意識形態塑造這個世界。
擲一次祭司身份表或從中選擇一個結果，以此啟發這名牧師屬於什麼樣的類型。

**祭司身份**

| **1d10** | **這名祭司是……** |
| --- | --- |
| 1 | 一名將邪惡精魂拒於體外的苦修士。 |
| 2 | 一名能代表死者發言的老者。 |
| 3 | 一名獵殺邪惡精魂的驅魔師。 |
| 4 | 某尊從未聽說過的神祇的追隨者。 |
| 5 | 一名以傳統手段行事的調停者與導師。 |
| 6 | 一位專注於某一概念、多元宇宙觀、或是存在位面的哲學家。 |
| 7 | 某位古老的信仰領袖的轉生體。 |
| 8 | 一位使用酊劑和表演來與神靈溝通的儀式師。 |
| 9 | 一位薩滿，能夠使用藥物減緩病患的痛苦。 |
| 10 | 渴望著一場以神指明發起的聖戰的一名狂熱信徒。 |

“輝耀之主啊，求禰照亮我的時日” “以聖靈之火燃起我的靈魂，以神聖之思啟迪我的作為” “求禰驅散我途中的陰翳，容我步履堅定，行在禰永恆不滅的榮光之中”

——獻給培羅的晨間禱告
