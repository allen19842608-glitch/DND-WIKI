# 匪徒介紹 (Bandits)

## 📖 怪物介紹

惡名遠揚的法外狂徒

**棲息地：** 任意；**寶藏：**個體

匪徒們蠻取豪奪。幫派成員、亡命之徒、非法傭兵等各類罪犯都可算作匪徒。然而，並不是所有匪徒都是出於貪婪而犯罪。有些匪徒是因為不公的法律、深陷絕望、甚至是受人脅迫才不得已踏入罪惡之道。
擲一次匪徒動機表，或從中選擇一個結果，以此啟發並決定是什麼驅使匪徒們不斷犯下罪行。

**匪徒動機**

| **1d6** | **這一匪徒……** |
| --- | --- |
| 1 | 為反抗暴政而戰。 |
| 2 | 是一位被拋棄的士兵，現在它要親自奪回國家許諾給它的事物。 |
| 3 | 屬於一支將其他所有人都視作敵人的黑幫。 |
| 4 | 是一位邪惡領袖的死忠。 |
| 5 | 是某個政府或當地統治者的黑手套，目的是製造混亂。 |
| 6 | 為生存而強奪必要資源。 |
