# 至高天介紹 (Empyreans)

## 📖 怪物介紹

諸神之子嗣

**棲息地：** 任意；**寶藏：**聖物

至高天是神靈的後代。祂們並非真正的神祇，卻也繼承了來自其神性親代的神性影響與威能。一些至高天類似半神，駕馭著難以想像的偉力，以及重塑凡人之能力；另一些至高天卻不過是神性存在之思想或某道關注力的具現化。無論一個至高天是具體化的完美生物，還是某份神力的片影，其外表都受其創造者的影響。擲一次至高天特徵表或從中選擇一個結果，以此啟發一位至高天繼承的神力在其外表上以何種形式具現。

**至高天特徵**

| **1d6** | **這位至高天具有的特徵是……** |
| --- | --- |
| 1 | 均衡的、自然的或是彷彿注視著他人的眼瞳。 |
| 2 | 外形色澤豐富、色調陰暗或是在不同的觀者眼中有不同的相貌。 |
| 3 | 造型溫柔且令人安心或是能令觀者回想起美好的回憶。 |
| 4 | 其軀體是不接合的碎塊、思維以可見的形似顯現或是有著畸化的外形。 |
| 5 | 如機械般規律、如磐石般堅韌、外形極端對稱或是如同審判者一般。 |
| 6 | 外形病態、危險、怖人或是如同觀者心中之恐懼的具現。 |

終有一日，吾將登臨風暴之神位——照看無可計數的信徒，回應每一道祈禱，賦予世界以變革——但在那之前，我想做什麼就做什麼。

——寇鐸哈，風暴之神子
