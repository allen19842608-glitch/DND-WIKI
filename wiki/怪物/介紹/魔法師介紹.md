# 魔法師介紹 (Mages)

## 📖 怪物介紹

魔法研學者與法術施展者

**棲息地：** 任意；**寶藏：**奧秘，個體

魔法師們是行使魔法，創造奇蹟之人，從擁有施法能力的霸主到隱世研學的女巫，都可以被稱為魔法師。它們研究玄奧的隱秘，研習怪物、傳說、預兆、以及其他學識。魔法師們經常召集盟友或僱傭助手來助其進行研究，或是獲得強大的魔法力量。
擲一次魔法師身份表或從中選擇一個結果，以此啟發這是一名什麼類型的魔法師。

**魔法師身份**

| **1d10** | **這名魔法師是一位……** |
| --- | --- |
| 1 | 自群星之中汲取魔法的觀星師。 |
| 2 | 書寫著禁忌隱秘的作家。 |
| 3 | 製造奇物的魔法工程師。 |
| 4 | 解讀預兆的先知。 |
| 5 | 繼承了奇異的魔法遺產的天才。 |
| 6 | 靈能使，其天賦威能以法術的形式展現。 |
| 7 | 調查遠古學識的學者。 |
| 8 | 為統治者提供建議的占卜家。 |
| 9 | 在戰場上支援士兵的戰爭法師。 |
| 10 | 分享秘密睿識的女巫。 |

你有親自凝視過‘混沌符文’嗎？你有用顫抖的手握著‘亡月法球’、穿過‘吞世之門’、踏過‘俱滅之路’、或是坐在薩扎斯坦的左手邊親眼目睹‘二重燒卻秘儀’的現場嗎？沒有？那你最好別跟我談法師、也別跟我談塞爾。

——那瑟爾，塞爾難民
