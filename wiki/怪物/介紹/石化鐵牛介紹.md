# 石化鐵牛介紹 (Gorgon)

## 📖 怪物介紹

呼出石化氣體的牛形衛士

**棲息地：** 森林，草原，丘陵；**寶藏：**任意

石化鐵牛形似身披鐵鎧的強壯公牛，是如活物一般的構裝生物。它們會摧毀所有踏入其領地的生物。除了用致命的牛角頂撞，用鐵蹄踐踏之外，石化鐵牛還能呼出劇毒的氣體
石化鐵牛是施法者創造的衛士。製造石化鐵牛的過程勞神費力且危險，其中一種辦法需要將公牛的骨架、美杜莎的血和雞蛇的大腦組裝到施了魔法的鋼鐵框架之中。如果這一過程失敗，石化氣體會從材料中溢出，產生一種魔法威脅，會充滿建築物內部並經年不散。
當施法者創造石化鐵牛時，他們通常會用魔法讓其能忽視那些在它們面前提供了特別的秘鑰（通常是密碼或特別的信號）的人。一旦石化鐵牛被設置為守衛一個區域，它就會進攻進入的一切闖入者，直到敵人逃跑或被毀滅。而闖入者如果提供了秘鑰，只要仍在它的視線範圍內，石化鐵牛便會無視其存在。但如果闖入者膽敢離開視線再返回卻沒有出示秘鑰，石化鐵牛便會發起進攻。身處石化鐵牛領地的時候必須時刻小心，掌握這怪物的具體位置，否則便有可能被原以為已經不再構成威脅的石化鐵牛攻擊。
創造石化鐵牛的人會讓秘鑰難以發覺。在石化鐵牛創造者的記錄或石化鐵牛保護的區域中，可能會找到關於秘鑰的提示——可能是闖入者生命的最後潦草寫下的。
擲一次石化鐵牛秘鑰表或從中選擇一個結果，以此啟發什麼樣的口令或者信號才能暫時解除石化鐵牛的威脅。

**石化鐵牛秘鑰**

| **1d6** | **要讓石化鐵牛不攻擊，你得……** |
| --- | --- |
| 1 | 當著石化鐵牛的面施展一個特定的法術。 |
| 2 | 背對石化鐵牛，或表現得像沒有看到它一樣。 |
| 3 | 給它一杯血、水或酒。 |
| 4 | 背誦一首特定的押韻詩或唱一首特定的歌。 |
| 5 | 把創造者的名字倒過來唸。 |
| 6 | 帶上一個面具，也許是公牛的形狀，也許是某個對其創造者有特別意義的動物。 |
