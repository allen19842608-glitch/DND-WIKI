# 驚怖迷霧

## ⚙️ 規則條文 (Rule Text)

*大型亡靈，混亂邪惡*

**AC** 13　**先攻** +2（12）

**HP** 45（7d10+7）

**速度** 25 呎，飛行25 呎（懸浮）

**感官** 盲視120 呎；被動察覺11

**語言** 無

**傷害抗性／免疫** 鈍擊，穿刺，揮砍；毒素；魅惑，力竭，恐慌，受擒，麻痺，石化，中毒，倒地，束縛，昏迷

**CR** 3（XP700；PB+2）

### 特性 (Traits)

- **空氣形態（Air Form）**：驚怖迷霧可以進入並停留在一名敵人所處的空間。其可以移動穿過最窄1寸寬的空間而無需消耗額外的移動力。
- **融入迷霧（One with the Mists）**：若驚怖迷霧身處霧氣或迷霧中，其處於隱形狀態。若驚怖迷霧身處霧氣或迷霧區域之外，其陷入失能狀態。

### 動作 (Actions)

- **多重攻擊（Multiattack）**：驚怖迷霧發動兩次撕裂心智攻擊。其可以將其中一次攻擊替換為使用施法來施展命令術 Command（若可用）。
- **撕裂心智（Mind Rend）**：近戰攻擊檢定：+5，觸及5 呎。命中：8（1d10+3）心靈傷害。
- **施法（Spellcasting）**：驚怖迷霧施展以下一道法術，無需法術成分並使用魅力作為施法屬性（法術豁免 DC13）：
- **隨意：**：雲霧術 Fog Cloud
- **1/日：**：命令術 Command

### 附贈動作 (Bonus Actions)

- **滴注恐懼（Instill Dread（充能4~6））**：感知豁免檢定：DC13，位於該驚怖迷霧所處空間內的每個生物。失敗：目標陷入恐慌狀態，直至驚怖迷霧的下一回合開始。
