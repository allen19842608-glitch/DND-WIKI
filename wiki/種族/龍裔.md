# 龍裔 (Dragonborn)

## ⚙️ 規則條文 (Rule Text)

> [!IMPORTANT]
> 龍裔的龍族血統決定吐息武器與傷害抗性，並在 5 級取得短暫飛行。

| 生物類型 | 體型 | 速度 |
| :--- | :--- | :--- |
| 類人生物 | 中型 | 30 呎 |

- **龍族血統 (Draconic Ancestry)**：選擇下表一種龍族血統；其傷害類型決定你的吐息武器與傷害抗性。

| 龍族血統 | 傷害類型 |
| :--- | :--- |
| 黑龍 | 強酸 |
| 藍龍 | 閃電 |
| 綠龍 | 毒素 |
| 紅龍 | 火焰 |
| 白龍 | 寒冷 |
| 黃銅龍 | 火焰 |
| 青銅龍 | 閃電 |
| 赤銅龍 | 強酸 |
| 金龍 | 火焰 |
| 銀龍 | 寒冷 |
- **吐息武器 (Breath Weapon)**：在你的攻擊動作中，以一次攻擊替換為 15 呎錐形或 30 呎長、5 呎寬直線。範圍內生物進行敏捷豁免（DC 8 + 體質調整值 + 熟練加值）；失敗承受 1d10 對應傷害，成功減半。5、11、17 級時提升為 2d10、3d10、4d10；每長休恢復等同熟練加值的使用次數。
- **傷害抗性 (Damage Resistance)**：對龍族血統對應的傷害類型具有抗性。
- **黑暗視覺 (Darkvision)**：範圍 60 呎。
- **龍族飛行 (Draconic Flight)**：5 級起，以附贈動作展開幽光雙翼，獲得等同速度的飛行速度，持續 10 分鐘、收起雙翼或陷入失能時結束；長休後才能再次使用。

## 💡 實戰應用與裁量 (DM Ruling)

- 吐息武器是攻擊動作中的一次攻擊替換，不是額外動作；多重攻擊時仍可使用其餘攻擊。

## 🌍 被遺忘的國度設定

費倫許多龍裔家庭是在奧法瘟疫期間、阿貝爾與托瑞爾短暫融合時來到此地；但龍裔這個族群與托瑞爾同樣古老。泰曼瑟的龍裔社會曾結合泰曼迦巴的習俗與恩瑟重視榮譽、傳統和家庭的價值觀；第二次大陸分離後，許多龍裔帶著這些生活方式散居費倫。

今日的龍裔遍及費倫，也常見於古帝國與泰曼瑟難民建立的聚落；部分生活於卡林姆沙漠的巨靈城市。這些段落屬戰役設定，不改變本頁的 2024 種族特質。（來源：《被遺忘的國度：費倫英雄》，〈角色種族／龍裔〉）
