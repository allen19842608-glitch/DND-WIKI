# 色彩龍裔 (Chromatic Dragonborn，2014 Legacy)

> [!WARNING]
> 本條目為 2014 舊版規則；2024 新版請參閱 [[種族/龍裔|龍裔 (Dragonborn)]]。

## ⚙️ 規則條文 (Rule Text)

> [!IMPORTANT]
> **種族摘要**：具有特定龍族血脈的龍裔變體；建立角色時依《費資本的巨龍寶庫》採用自訂起源的屬性值提升與語言規則。

### 基本資料

| 生物類型 | 體型 | 速度 | 其他速度 |
| :--- | :--- | :--- | :--- |
| 類人 | 中型 | 30 呎 | 無 |

### 種族特質 (Species Traits)

#### 龍族起源 (Draconic Ancestry)

- **效果**：從下表選擇血脈；它決定吐息武器與龍族抗性的傷害類型。

| 血脈 | 傷害類型 |
| :--- | :--- |
| 黑 | 強酸 |
| 藍 | 閃電 |
| 綠 | 毒素 |
| 紅 | 火焰 |
| 白 | 寒冷 |

#### 吐息武器 (Breath Weapon)

- **取得／觸發**：執行攻擊動作時，可用一次攻擊替換。
- **效果**：在 30 呎長、5 呎寬直線 呼出魔法能量；範圍內生物進行 DC 8 + 體質調整值 + 熟練加值的敏捷豁免，失敗受血脈傷害、成功半傷。傷害為 1d10，於角色 5、11、17 級分別增為 2d10、3d10、4d10。
- **限制**：使用次數等同熟練加值，完成長休恢復。

#### 龍族抗性 (Draconic Resistance)

- **效果**：對所選血脈的傷害類型具有抗性。

#### 繁彩防護 (Chromatic Warding)

- **取得／觸發**：5 級起，以一個動作啟用。
- **效果**：1 分鐘內免疫所選血脈的傷害類型。
- **限制**：每次長休後可再使用。
