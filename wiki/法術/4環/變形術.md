# 變形術 (Polymorph)

- **環階**：4 環
- **學派**：變化
- **施法時間 (Casting Time)**：動作
- **施法距離 (Range)**：60 呎
- **目標 (Target)**：施法距離內一名可見的生物
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：一枚毛毛蟲繭；未標示成本／不消耗
- **持續時間 (Duration)**：專注，至多 1 小時
- **專注 (Concentration)**：是
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/吟遊詩人|吟遊詩人 (Bard)]][[職業/德魯伊|德魯伊 (Druid)]][[職業/術士|術士 (Sorcerer)]][[職業/法師|法師 (Wizard)]]

## 🔮 法術效果描述

- **效果**：你嘗試把施法距離內一名可見生物變成野獸。目標感知豁免失敗時，在法術持續期間變成你選擇的野獸形態。該野獸的挑戰等級不得超過目標的挑戰等級；若目標沒有挑戰等級，改以其等級為上限。（來源：《玩家手冊 2024》，p. 306，Polymorph）
- **豁免／法術攻擊**：感知豁免；此法術不要求法術攻擊。
- **資料替換**：目標的遊戲資料由所選野獸的資料卡取代，但保留原本的陣營、性格、生物類型、生命值及生命值骰。
- **臨時生命值與結束**：目標獲得等於野獸形態生命值的臨時生命值。目標不再有剩餘臨時生命值時，法術對它提前結束；法術結束時，任何剩餘的這些臨時生命值也消失。（來源：《玩家手冊 2024》，p. 306，Polymorph；PHB-2024 v1.0 勘誤，p. 1）
- **動作與裝備限制**：目標只能執行新形態生理構造容許的動作，不能說話或施法。裝備融入新形態，目標不能使用裝備，也不能以其他方式從裝備獲益。

來源：《玩家手冊 2024》，p. 306，Polymorph，資料替換、臨時生命值、動作與裝備條文。

## 2014 版差異對比

| 版本 | 主要規則差異 |
| :--- | :--- |
| 2014 Legacy | 使用野獸形態的生命值；形態生命值降至 0 而恢復原形時，溢出傷害由原形承受。只保留陣營與性格，非自願目標才要求豁免，並明列不影響變形生物或生命值為 0 的生物。 |
| 2024 Core | 保留目標原本的生命值、生命值骰與生物類型，改獲野獸形態生命值等量的臨時生命值；臨時生命值不再剩餘時提前結束，結束時剩餘值也消失。條文要求目標感知豁免，未保留舊版的非自願限定及上述兩項目標排除敘述。 |

來源：《玩家手冊 2014》，法術詳述／4 環，L388–400 標題：變形術｜Polymorph；《玩家手冊 2024》，p. 306，Polymorph。

## 💡 實戰應用與裁量 (DM Ruling)

> [!NOTE] 非官方使用建議
> 下列戰術建議不另增法術的官方效果或限制。

- 這不是隨便變成任何怪物，受野獸與等級限制。
- 適合移除麻煩敵人、救援同伴，或暫時把目標變成小動物。
