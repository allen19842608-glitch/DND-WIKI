# 魔鄧肯私人密室 (Mordenkainen's Private Sanctum)

- **環階**：4 環
- **學派**：防護
- **施法時間 (Casting Time)**：10 分鐘
- **施法距離 (Range)**：120 呎
- **效應區域 (Area)**：施法距離內、邊長 5 至 100 呎的立方區域
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：一片薄鉛；未標示成本／不消耗
- **持續時間 (Duration)**：24 小時
- **專注 (Concentration)**：否
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/法師|法師 (Wizard)]][[職業/奇械師|奇械師 (Artificer)]]

## 🔮 法術效果描述

- **效果**：你保護施法距離內一個立方區域，其邊長可從 5 呎至 100 呎。施法時，從下列防護選項中任選一項或多項，於法術持續期間生效。（來源：《玩家手冊 2024》，p. 301，Mordenkainen's Private Sanctum）
- **持續施展**：每天在同一位置施展，連續 365 天後，法術持續至被解除。
- **升環施法 (At Higher Levels)**：使用的法術位每比 4 環高 1 環，可以將立方區域的邊長增加 100 呎。

| 防護選項 | 效果 |
| :--- | :--- |
| 聲音 | 聲音不能穿過區域邊界的屏障。 |
| 視覺 | 屏障顯得黑暗且霧濛濛，視覺（包括黑暗視覺）不能看穿。 |
| 預言感測 | 預言法術創造的感測器不能出現在區域內，也不能穿過邊界屏障。 |
| 預言目標 | 區域內的生物不能成為預言法術的目標。 |
| 傳送 | 任何事物均不能傳送進出區域。 |
| 位面旅行 | 區域內的位面旅行受到阻擋。 |

來源：《玩家手冊 2024》，p. 301，Mordenkainen's Private Sanctum，防護選項、365 天條件與升環條文。

## 2014 版差異對比

| 版本 | 主要規則差異 |
| :--- | :--- |
| 2014 Legacy | 持續 24 小時，或施法者以動作主動解除；每天同地施法一年後成為永久效果。 |
| 2024 Core | 現行條文未保留施法者以動作主動解除的敘述；每天同地施法連續 365 天後，持續至被解除。 |

來源：《玩家手冊 2014》，法術詳述／4 環，L340–365 標題：魔鄧肯私人密室｜Mordenkainen's Private Sanctum；《玩家手冊 2024》，p. 301，Mordenkainen's Private Sanctum。
