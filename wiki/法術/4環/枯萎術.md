# 枯萎術 (Blight)

- **環階**：4 環
- **學派**：死靈
- **施法時間 (Casting Time)**：動作
- **施法距離 (Range)**：30 呎
- **目標 (Target)**：施法距離內一名可見生物，或非生物的非魔法植物
- **法術成分 (Components)**：V、S
- **持續時間 (Duration)**：立即
- **專注 (Concentration)**：否
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/德魯伊|德魯伊 (Druid)]]、[[職業/術士|術士 (Sorcerer)]]、[[職業/契術師|契術師 (Warlock)]]、[[職業/法師|法師 (Wizard)]]

- **取得來源**：[[wiki/專長/通用專長/死靈專家|死靈專家 (Necromancy Adept)]]

## 🔮 法術效果描述

- **效果**：選擇施法距離內一名可見生物，使其進行體質豁免；失敗受到 8d8 暗蝕傷害，成功傷害減半。植物生物自動豁免失敗。（來源：《玩家手冊 2024》，p. 247，Blight）
- **非生物植物**：你也可改以一株並非生物的非魔法植物為目標，例如樹木或灌木；該植物不進行豁免，直接枯萎死亡。（來源：《玩家手冊 2024》，p. 247，Blight）
- **豁免／法術攻擊**：體質豁免；植物的例外如下表
- **升環施法 (At Higher Levels)**：法術位每高於四環 1 環，傷害增加 1d8。（來源：《玩家手冊 2024》，p. 247，Using a Higher-Level Spell Slot）

| 目標 | 豁免與效果 |
| :--- | :--- |
| 植物以外的生物 | 體質豁免；失敗 8d8 暗蝕傷害，成功傷害減半 |
| 植物生物 | 自動豁免失敗，受到 8d8 暗蝕傷害 |
| 非生物的非魔法植物 | 不進行豁免，直接枯萎死亡 |


## 2014 版差異對比

| 版本 | 本頁需要區分的主要規則 |
| :--- | :--- |
| 2014 Legacy | 對構裝及亡靈無效；植物生物或魔法植物的豁免具有劣勢，且傷害取最大值。 |
| 2024 Core | 植物生物改為自動豁免失敗，依正常傷害骰結算；2024 條文不再列出構裝與亡靈無效的限制。 |

2014 列依《玩家手冊 2014》，法術詳述／4環，「枯萎術」；2024 列依本頁《玩家手冊 2024》的法術實體引用。兩版各自適用，不把舊版選項加入本頁的現行效果。
