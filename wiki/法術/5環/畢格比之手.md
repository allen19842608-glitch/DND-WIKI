# 畢格比之手 (Bigby's Hand)

- **環階**：五環
- **學派**：塑能
- **施法時間 (Casting Time)**：動作
- **施法距離 (Range)**：120 呎
- **目標 (Target)**：施法距離內一處可見的未佔據空間
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：一個蛋殼與一隻分指手套；未標示成本／不消耗
- **持續時間 (Duration)**：專注，至多 1 分鐘
- **專注 (Concentration)**：是
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/術士|術士 (Sorcerer)]]、[[職業/法師|法師 (Wizard)]]、[[職業/奇械師|奇械師 (Artificer)]]

## 🔮 法術效果描述

- **效果**：你在施法距離內一處可見的未佔據空間創造大型魔法手掌，於法術持續期間模仿你的手掌動作並依命令移動。它是 AC 20、生命值等於你生命值上限的物件；生命值降至 0 時法術結束。手掌不佔據其所在空間。（來源：《玩家手冊 2024》，p. 246，Bigby's Hand）
- **操控**：施法時，以及你後續回合使用附贈動作時，可以讓手掌移動至多 60 呎，再選擇下表一種效果。
- **豁免／法術攻擊**：打擊使用近戰法術攻擊；推動要求力量豁免；擒抱要求敏捷豁免。
- **升環施法 (At Higher Levels)**：使用的法術位每比 5 環高 1 環，打擊的力場傷害增加 2d8，擒抱後擠壓的鈍擊傷害增加 2d6。

| 效果摘要 | 目標與完整效果 |
| :--- | :--- |
| 近戰打擊 | 打擊手掌 5 呎內一個目標；進行近戰法術攻擊，命中造成 5d8 力場傷害。 |
| 推動生物 | 手掌 5 呎內一名巨型或更小的生物進行力量豁免；失敗則被推動至多「5 + 5 × 你的施法屬性調整值」呎。手掌隨目標一起移動，保持在其 5 呎內。 |
| 擒抱與擠壓 | 手掌 5 呎內一名巨型或更小的生物進行敏捷豁免；失敗則陷入受擒狀態，逃脫 DC 等於你的法術豁免 DC。手掌擒抱目標期間，你可以使用附贈動作讓手掌擠壓它，造成 4d6 + 你的施法屬性調整值的鈍擊傷害。 |
| 提供掩護 | 對源自手掌所在空間或穿過該空間的攻擊與其他效果，你獲得半身掩護；該空間對你的敵人也是困難地形。 |

來源：《玩家手冊 2024》，p. 246，Bigby's Hand，四種手掌效果與升環條文。

## 2014 版差異對比

| 版本 | 主要規則差異 |
| :--- | :--- |
| 2014 Legacy | 以近戰法術攻擊造成 4d8 力場傷害；推動使用手掌的力量對抗目標力量（運動），擒抱使用手掌的力量，擠壓造成 2d6 + 施法屬性調整值的鈍擊傷害。掩護以選定生物為對象，並依雙方力量決定能否穿越。 |
| 2024 Core | 打擊增為 5d8；推動改為目標力量豁免，擒抱改為目標敏捷豁免，擠壓增為 4d6 + 施法屬性調整值。掩護改依攻擊或效果是否源自或穿過手掌空間判定，該空間對你的敵人為困難地形。 |

來源：《玩家手冊 2014》，法術詳述／5 環，L57–77 標題：畢格比之手｜Bigby's Hand；《玩家手冊 2024》，p. 246，Bigby's Hand。

## 💡 實戰應用與裁量 (DM Ruling)

> [!NOTE] 非官方使用建議
> 下列戰術建議不另增法術的官方效果或限制。

- 玩家常見的規則誤區：魔法手掌不佔據空間，但仍有獨立 AC 與生命值。
- 戰鬥或探索中的搭配：依目標與場地選擇控制、傷害或阻擋效果。
