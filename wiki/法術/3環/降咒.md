# 降咒 (Bestow Curse)

- **環階**：三環
- **學派**：死靈
- **施法時間 (Casting Time)**：動作
- **施法距離 (Range)**：觸碰
- **目標 (Target)**：你觸碰的一名生物
- **法術成分 (Components)**：V、S
- **持續時間 (Duration)**：專注，至多 1 分鐘
- **專注 (Concentration)**：是
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/吟遊詩人|吟遊詩人 (Bard)]]、[[職業/牧師|牧師 (Cleric)]]、[[職業/法師|法師 (Wizard)]]

## 🔮 法術效果描述

- **效果**：你觸碰一名生物。目標感知豁免失敗時，在法術持續期間受到詛咒；你從下表選擇一種效果。（來源：《玩家手冊 2024》，p. 246，Bestow Curse）
- **豁免／法術攻擊**：感知豁免；第三種效果另在戰鬥中的每回合開始時要求感知豁免。
- **升環施法 (At Higher Levels)**：使用更高環階法術位時，專注需求與持續時間如下表。

| 可選效果 | 規則 |
| :--- | :--- |
| 影響一項屬性 | 選擇一項屬性；目標使用該屬性的屬性檢定及豁免具有劣勢。 |
| 影響對你的攻擊 | 目標對你發動的攻擊檢定具有劣勢。 |
| 強迫閃避 | 戰鬥中，目標在每回合開始時進行感知豁免；失敗則該回合被迫執行閃避動作。 |
| 額外傷害 | 你以攻擊檢定或法術對目標造成傷害時，目標額外受到 1d8 暗蝕傷害。 |

| 使用法術位 | 持續時間 | 需要專注 |
| :--- | :--- | :--- |
| 3 環 | 至多 1 分鐘 | 是 |
| 4 環 | 至多 10 分鐘 | 是 |
| 5–6 環 | 8 小時 | 否 |
| 7–8 環 | 24 小時 | 否 |
| 9 環 | 直到被解除 | 否 |

來源：《玩家手冊 2024》，p. 246，Bestow Curse，四種詛咒效果與升環條文。

## 2014 版差異對比

| 版本 | 主要規則差異 |
| :--- | :--- |
| 2014 Legacy | 每回合開始豁免失敗時，目標浪費該回合的動作；條文另允許 DM 裁定其他不更強的詛咒選項。 |
| 2024 Core | 每回合開始豁免失敗時，目標被迫執行閃避動作；現行條文列出四種選項，未保留舊版自訂詛咒選項的授權敘述。 |

來源：《玩家手冊 2014》，法術詳述／3 環，L33–53 標題：降咒｜Bestow Curse；《玩家手冊 2024》，p. 246，Bestow Curse。
