# 法術反制 (Counterspell)

- **環階**：3 環
- **學派**：防護
- **施法時間 (Casting Time)**：反應，當你看見 60 呎內一名生物施展一道具有言語、姿勢或材料成分的法術時使用
- **施法距離 (Range)**：60 呎
- **目標 (Target)**：施法距離內一名正在施法的生物
- **法術成分 (Components)**：S
- **持續時間 (Duration)**：立即
- **專注 (Concentration)**：否
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/術士|術士 (Sorcerer)]][[職業/契術師|契術師 (Warlock)]][[職業/法師|法師 (Wizard)]]

## 🔮 法術效果描述

- **效果**：你嘗試打斷正在施法的生物。目標進行體質豁免；失敗時，被反制的法術消散且不產生效果，用來施法的動作、附贈動作或反應也隨之浪費。如果該法術使用法術位施展，被反制者的那個法術位不消耗。（來源：《玩家手冊 2024》，p. 258，Counterspell）
- **豁免／法術攻擊**：目標進行體質豁免；此法術不要求法術攻擊。
- **觸發限制**：你必須看見 60 呎內的生物正在施展具有言語、姿勢或材料成分的法術，才能使用這個反應。（來源：《玩家手冊 2024》，p. 258，Counterspell，施法時間）

## 2014 版差異對比

| 版本 | 主要規則差異 |
| :--- | :--- |
| 2014 Legacy | 3 環或更低的法術直接被打斷；更高環階要求反制者以施法屬性進行 DC 為 10 + 目標法術環階的屬性檢定。升環可提高直接打斷的法術環階。 |
| 2024 Core | 改由正在施法的生物進行體質豁免，不依目標法術環階直接成功，也沒有升環強化條文。失敗時施法所用的動作、附贈動作或反應浪費；若使用法術位施法，那個法術位不消耗。 |

來源：《玩家手冊 2014》，法術詳述／3 環，L130–139 標題：法術反制｜Counterspell；《玩家手冊 2024》，p. 258，Counterspell。
