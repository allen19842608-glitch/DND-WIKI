# 酸液飛濺 (Acid Splash)

- **環階**：戲法
- **學派**：塑能
- **施法時間 (Casting Time)**：動作
- **施法距離 (Range)**：60 呎
- **目標 (Target)**：施法距離內一點
- **效應區域 (Area)**：以該點為中心的 5 呎半徑球狀區域
- **法術成分 (Components)**：V、S
- **持續時間 (Duration)**：立即
- **專注 (Concentration)**：否
- **儀式 (Ritual)**：否
- **施法職業**：[[職業/術士|術士 (Sorcerer)]]、[[職業/法師|法師 (Wizard)]]、[[職業/奇械師|奇械師 (Artificer)]]

## 🔮 法術效果描述

- **效果**：你在施法距離內一點創造酸液泡，於該點爆發成 5 呎半徑的球狀區域。區域內每名生物必須通過敏捷豁免，否則受到 1d6 強酸傷害。（來源：《玩家手冊 2024》，p. 239，Acid Splash）
- **豁免／法術攻擊**：敏捷豁免
- **戲法強化**：傷害隨你的角色等級增加，如下表。（來源：《玩家手冊 2024》，p. 239，Cantrip Upgrade）

| 角色等級 | 傷害 |
| :--- | :--- |
| 1–4 級 | 1d6 |
| 5–10 級 | 2d6 |
| 11–16 級 | 3d6 |
| 17 級以上 | 4d6 |


## 2014 版差異對比

| 版本 | 本頁需要區分的主要規則 |
| :--- | :--- |
| 2014 Legacy | 指定一名可見生物，或兩名相距不超過 5 呎的可見生物。 |
| 2024 Core | 改為選擇距離內一點，影響該點周圍 5 呎半徑球狀區域內的每名生物。 |

2014 列依《玩家手冊 2014》，法術詳述／戲法，「酸液飛濺」；2024 列依本頁《玩家手冊 2024》的法術實體引用。兩版各自適用，不把舊版選項加入本頁的現行效果。
