# 操控天氣 (Control Weather)

- **環階**：八環
- **學派**：變化
- **施法時間 (Casting Time)**：10 分鐘
- **施法距離 (Range)**：自身
- **效應區域 (Area)**：以自身為原點的 5 里半徑區域
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：點燃的焚香和一點混有泥土和木屑的水；未標示成本／不消耗
- **持續時間 (Duration)**：專注，至多 8 小時
- **專注 (Concentration)**：是
- **儀式 (Ritual)**：否
- **施法職業**：牧師、德魯伊、法師

## 🔮 法術效果描述

- **效果**：你在法術持續時間內控制自身 5 裡範圍內的天氣狀況。施展該法術時你必須身處戶外，而一旦移動到無法直接看到天空的地點時，法術也會隨即終止。 本來由 DM 基於季節和氣候所決定的天氣狀況，在你施展此法術時可以由你隨意操控。你可以改變降水、氣溫以及風勢等狀況。新的天氣狀況生效需要經過1d4×10分鐘的時間才能完成。狀況改變完成後，你可以再次對當前對天氣狀況作改變。法術終止時，天氣將漸漸恢復成平常狀態。 改變天氣狀況時，你可以從以下表格查明與目前對應的等級，再選擇同一表格中高一級或低一級的狀況作為其改變結果。改變風勢時，你還可以同時改變其風向。 | **降水 Precipitation** | | **氣溫 Temperature** | | **風勢 Wind** | | | | | --- | --- | --- | --- | --- | --- | --- | --- | | **等級** | **狀況** | | **等級** | **狀況** | | **等級** | **狀況** | | 1 | 天晴 clear | | 1 | 酷熱 unbearable heat | | 1 | 無風 calm | | 2 | 薄雲 light clouds | | 2 | 炎熱 hot | | 2 | 和風 moderate wind | | 3 | 多雲 overcast，有霧 ground fog | | 3 | 暖和 warm | | 3 | 強風 strong wind | | 4 | 有雨 rain，冰雹 hail，有雪 snow | | 4 | 清涼 cool | | 4 | 狂風 gale | | 5 | 暴雨 torrential rain，冰暴 driving hail，暴雪 blizzard | | 5 | 寒冷 cold | | 5 | 暴風 storm | | | | | 6 | 極寒 arctic cold | | | |（來源：玩家手冊 2014，法術詳述，#Control_Weather）
