# 轉生術 (Reincarnate)

- **環階**：五環
- **學派**：變化
- **施法時間 (Casting Time)**：1 小時
- **施法距離 (Range)**：觸碰
- **目標 (Target)**：你觸碰的一個類人生物的遺體或遺體的一部分
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：價值至少 1000gp 的稀有油和軟膏，作為該法術的耗材；未標示成本／不消耗
- **持續時間 (Duration)**：立即
- **專注 (Concentration)**：否
- **儀式 (Ritual)**：否
- **施法職業**：德魯伊

## 🔮 法術效果描述

- **效果**：你觸碰一個類人生物的遺體或遺體的一部分，以此創造出一具新的成年身體，並呼喚該生物的靈魂進入此新身軀。該生物死亡時間必須不超過 10 日。此外，如果目標生物的靈魂此時不能或者不願意完成該過程，則法術失敗。 該法術要為目標生物創造出一具新的身體，因此很可能導致該生物的種族發生變動。DM 可以投一個 d100 來判定該生物以何種形態復生，也可以直接由 DM 選擇一種形態。 ?? | **d100** | **種族** | | **d100** | **種族** | | --- | --- | --- | --- | --- | | 01~04 | 龍裔 | | 47~52 | 巖侏儒 | | 05~13 | 丘陵矮人 | | 53~56 | 半精靈 | | 14~21 | 山地矮人 | | 57~60 | 半獸人 | | 22~25 | 黑暗精靈 | | 61~68 | 輕足半身人 | | 26~34 | 高等精靈 | | 69~76 | 強魄半身人 | | 35~42 | 木精靈 | | 77~96 | 人類 | | 43~46 | 林侏儒 | | 97~00 | 提夫林 | 轉生後的生物保留其前生記憶和經驗。受術者保留原形的一切能力，不過其種族特質將以新種族的相應特性做更替。（來源：玩家手冊 2014，法術詳述，#Reincarnate）
