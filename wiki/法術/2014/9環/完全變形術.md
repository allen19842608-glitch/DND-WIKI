# 完全變形術 (True Polymorph)

- **環階**：九環
- **學派**：變化
- **施法時間 (Casting Time)**：1 動作
- **施法距離 (Range)**：30 尺
- **目標 (Target)**：施法距離內你能看見的一個生物或物件
- **法術成分 (Components)**：V、S、M
- **材料成本與消耗**：一滴水銀，一團阿拉伯膠以及一縷煙；未標示成本／不消耗
- **持續時間 (Duration)**：專注，至多 1 小時
- **專注 (Concentration)**：是
- **儀式 (Ritual)**：否
- **施法職業**：吟遊詩人、契術師、法師

## 🔮 法術效果描述

- **效果**：你指定施法距離內一個你能看見的生物或物件並使其變形。該法術無法對 0 生命值目標生效。你可以將目標生物變成另一個不同的生物，或將目標生物變成一個非魔法物件，又或者將目標物件變成一個生物（該物件必須沒有被任何生物著裝或攜帶）。變形效應持續到法術持續時間結束，或直至目標生命值降至 0 或目標死亡。如果你在法術持續時間內一直保持該法術的專注，則該變形將一直持續到被解除。 該法術對變形生物以及生命值為 0 的目標無效。而不願被變形的生物可以進行一次感知豁免，豁免成功則不受該法術影響。 生物變生物。如果你將一個生物變形成另一種生物，則它的新形態可以是你選擇的挑戰等級等於或低於受術者挑戰等級（如果受術者沒有挑戰等級則按其角色等級）的任意物種。受術者的遊戲資料（包括各精神屬性值）將被新形態的數據取代，而其陣營和性格則保持不變。 目標將使用新形態的生命值。而當其變回通常形態時，該目標的生命值也恢復為變形前的數值。如果目標是因為生命值降至 0 而變回通常形態，則由通常形態承受溢出的傷害。只要溢出傷害不足以將通常形態生命值降至 0，他就不會因此而昏迷。 該生物所能實施的行為因其新形態的特徵而受限，除非其新形態的身體特徵允許，否則該生物不能說話，施法或者執行任何需要手和言語的動作。 目標的裝備融入其新形態，而且不能激活或持用裝備，也無法以其他任何方式從其裝備上獲益。 > **物件變生物。**你可以將一個物件變成任何一種符合下列要求的生物：生物的體積不能大於原物件，且生物的挑戰等級必須低於等於 9。變形出的生物對你和你的同伴保持友善。而戰鬥中它將會在你的回合內，由你決定其如何行動。該生物的數據由 DM 掌控，並由 DM 來判定其行動結果如何。 > 如果該法術變成永久有效，則你將不再控制該生物。此後，該生物將根據你對待他的方式決定是否對你保持友善。 > > **生物變物件。**如果你將一個生物變形成一個物件，則它連同其穿著攜帶物一起變成新的形態。變成物件的體型不能比原生物大。受術者的數據變成和該物件一樣，在法術終止而受術者變回原形後，它將不會記得在變成物件時所發生的任何事情。（來源：玩家手冊 2014，法術詳述，#True_Polymorph）
