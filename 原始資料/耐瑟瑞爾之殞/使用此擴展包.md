# 使用此擴展包

本擴展包包含了你在古代耐瑟瑞爾——被遺忘的國度世設中一個早已隕落的帝國——開展《龍與地下城》冒險所需的全部工具。文中引用的怪物數據均出自《怪物圖鑑》或附錄 B。
這段引言概述了古代耐瑟瑞爾及其歷史。雖然本引言適合所有玩家閱讀，但本擴展的其餘內容僅供地下城主使用。
本擴展包含以下內容：
第一章提供了關於在古代耐瑟瑞爾中展開冒險的資訊，包括浮空城伊萊納 Eileanar 及螺灣城 Conch 的詳細介紹。同時也包含設定在這些城市中的地圖與冒險工具。
第二章闡述了古代耐瑟瑞爾因魔法濫用與開採而常見的環境效應與災害。
第三章詳述了當代的時光之門，角色可藉此前往古代耐瑟瑞爾，並附上了相關地圖與設定在這些地點附近的冒險。
第四章提供了設定在古代耐瑟瑞爾中的地圖與冒險。
附錄 A 收錄了角色可能在冒險中獲得的耐瑟瑞爾魔法物品。
附錄 B 提供了古代耐瑟瑞爾中可見生物的怪物圖鑑。

### 確保所有人玩得開心 Ensuring Fun for All

本擴展涉及的主題中，有些可能會讓部分玩家感到敏感或不適。在你將本擴展納入遊戲之前，請仔細閱讀其中內容，回顧《城主指南》中"確保所有人玩得開心"一節，並務必按照"硬底線與軟底線"一節中的說明，與所有玩家進行溝通。
