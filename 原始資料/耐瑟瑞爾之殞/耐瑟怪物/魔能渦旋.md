# 魔能渦旋

失控狂暴的魔法旋風

**棲息地：** 城市；**寶藏：**無

當魔法能量變得極度不穩定時，有時會形成魔能渦旋——一種不受控制的塑能魔力旋風，噼啪作響著迸射出火焰和閃電。魔能渦旋通常出現在那些頻繁且無節制地使用魔法的地方，比如一個著魔的法師的密室附近、大量製造魔法物品的工坊旁邊或是那些由技藝不精的抄寫員研習_法術卷軸 Spell Scrolls_ 的圖書館週圍。在古耐瑟瑞爾，魔能渦旋經常出現在那些著名法師的宅邸與工作場所附近。
魔能渦旋肆虐時只有一個目的：儘可能地摧毀沿途出現的一切事物。在魔能渦旋現形之前，會有一些明顯的跡象預示著它的到來。擲一次渦旋現形徵兆表或從中選擇一個結果，以此啟發並決定魔能渦旋現形前發生了什麼。

**渦旋現形徵兆**

| **1d6** | **在渦旋出現之前......** |
| --- | --- |
| 1 | 五彩斑斕的火花在空中飛舞，就像煙花一樣。 |
| 2 | 尖叫的巫師或恐怖巨獸的幻象在旋風中盤旋。 |
| 3 | 電光閃爍，火焰躥起，空氣中瀰漫著刺鼻的氣味。 |
| 4 | 紫色的煙霧翻滾著匯聚成漩渦。 |
| 5 | 一道五彩斑斕的光柱從地面噴湧而出，直射向天空。 |
| 6 | 空氣泛起了微光，令人不安的狂笑聲從四面八方傳來。 |

### 特性 Traits

**魔法抗性 Magic Resistance。**魔能渦旋對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**魔能渦旋使用灼燒橫掃或奧法箭發動共計2次攻擊。

**灼燒橫掃 Searing Swipe。**_近戰攻擊檢定：_+6，觸及10尺。_命中：_13（3d6+3）火焰或閃電傷害，傷害類型由渦旋選擇。

**奧法箭 Arcane Bolt。**_遠程攻擊檢定：_+6，射程120尺。_命中：_14（2d10+3）力場傷害。

### 反應 Reactions

**魔能過載 Eldritch Overload。**_觸發：_魔能渦旋受到傷害時。_響應：__力量豁免檢定：_DC14，源自渦旋的5尺光環區域內每個由渦旋選擇的生物。豁免_失敗：_7（2d6）力場傷害，目標陷入倒地狀態。
