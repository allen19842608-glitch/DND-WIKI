# 龍巫教 Cult of the Dragon

龍巫教是一個擁有數個世紀曆史的陰謀集團，成員由邪惡巫師，末日預言者和拜龍者組成。龍巫教的成員對於那些以龍為中心的預言深信不疑。在這些預言中，巨龍是無可違逆的滅世者（或小部分人認為是拯救者）。為了加速終焉的到來，教徒們舉行了一場場精心策劃的儀式來強化或召喚邪惡巨龍。

### 目標與活動 Goals And Activities

龍巫教的陰謀雖然隱秘，但是其存在卻並非默默無聞。大多費倫的民眾都曾對這個邪教有所耳聞，但是瞭解也僅限於邪教的成員崇拜邪惡巨龍。邪教會從各大城市招募新鮮血液，許多邪教成員也在大城市中做合法營生，或是被分配到一般的學術研究崗位上。只有少部分邪教徒作為盜賊，刺客或特工行動。
龍巫教在成立之初主要致力於創造並崇拜龍巫妖——這是一種威力無匹的亡靈巨龍。根據_龍之卷冊 Tome of the Dragon_所記載的儀式，邪教徒們相信這些不死巨龍終將統治費倫。然而，近來邪教分裂，許多教徒轉而侍奉邪龍女王提亞瑪特。這個分裂出來的派系將提亞瑪特尊為神上神，並且期盼著巨龍女王的歸來，堅信她（而非龍巫妖）將摧毀文明，開啟巨龍們的輝煌王朝，並恩賜那些幫助巨龍建立統治的追隨者。
龍巫教徒的套裝遍佈巨龍主題的象徵物或是圖騰：裁成龍翼的斗篷，代表穿戴者所鍾愛的巨龍種類的服飾，珠寶和龍形配飾，面具，尤其是巨龍面具在邪教徒的聚會中十分普遍，並且許多教徒都會自己製作面具。
龍巫教徒會避免在公共場合穿戴套裝，不過專心留意者總能在人群中揪出偽裝的龍巫教徒。最醒目的特徵就是提亞瑪特的標誌手勢，崇拜巨龍女王的邪教徒會用這個手勢互相問候：右手伸展，掌心朝前，五指伸開，代表提亞瑪特的五頭。

### 領導與組織 Leadership And Organization

龍巫教的階級結構簡單明瞭，新人教徒組成了最底層階級，上面是四個位階的邪教徒，而最高位階則是紫衫——它們是各個地區的邪教領袖與宗師。邪教由一群叫做龍語者的神秘紫衫統治，因其與巨龍建立了強有力的超自然牽絆而得此尊稱。
邪教中的位階取決於教徒的功績和狂熱程度。新入教的教徒沒有任何位階，必須服從上級的命令。只有證明了自身價值的新人才能獲得晉升。紫衫可以以龍爪（第一位階）、龍翼（第二位階）、龍牙（第三位階）、龍魂（第四位階）的順序提拔新人。
龍巫教的行動組織規模各異，有的只是幾個低階教徒的自發行動，而有的則有數百名位階各異的教徒，在多位紫衫的指揮下統一行動。具體規模取決於教徒所執行的任務。

**基層組織 Cells**

**龍巫教由遍佈費倫的無數基層組織構成。每個組織都由一名或多名紫衫領導，通常以魔法傳訊的方式向龍語者直接彙報工作，。基層組織有各自的安排，但必須遵循龍語者的教義，否則會被逐出教團。**

**招募 Recruitment**
龍巫教一直在尋求擴充位階成員。新人教徒會被鼓勵把信得過的家人和朋友帶來入教。第二常見的招募形式則是屢試不爽的綁架——然後再洗腦。邪教徒有時候也會招募亡靈，精類和其他怪物。
龍巫教領袖並不反對在某些工作中或人丁稀少時招募僱傭兵。邪教會通過招募板上模稜兩可的告示和陰暗酒館中的黑道掮客來廣撒網；之後高級邪教徒再從中挑選最有前途（也就是最好控制）的人選。通過這種方式，無數的僱傭兵，尋常暴徒，甚至經驗豐富的冒險者渾然不覺地落入了邪教的圈套，為其執行任務。有的人即使在完成任務後都渾然不覺自己被邪教算計；有些人則在任務中途識破陷阱，及時抽身。還有極少數心術不正的人識破了工作的本質，利用這個機會申請加入邪教。

**紫衫 Wearers of Purple**
紫衫處於龍巫教階級中的頂點，並且他們的話對於其手下城市、堡壘和巢穴中的邪教徒而言就是法律。在龍巫教中，只有紫衫才有資格穿戴紫色服飾，他們大多數以這身色彩為傲。紫衫在與巨龍交流談判時頗具親和力——這是龍語者的天賦。 整個龍巫教中有數十名紫衫，都能隨意調動邪教的資源。
只有邪教的內環 inner circle 成員可以將龍魂晉升至紫衫，並賦予其一個行動基地與資金支持。作為權力根基的一部分，許多新晉的紫衫已經與巨龍或龍巫妖發展出了良好的工作關係。沒能維持此關係的紫衫有時會被降職。近日來，已有數位提亞瑪特的祭司被晉升為紫衫，並且正在費倫建立公開崇拜邪龍女王的神廟。

**龍語者 Wyrmspeakers。**五位紫衫執掌著整個龍巫教最為深遠的計劃。這個內環中的成員均帶著不同顏色的巨龍面具，隱藏起真實身份。他們自稱龍語者，而邪教成員都恐懼著他們駕馭巨龍的力量。每個龍語者都與某一種色彩龍聯繫密切。他們與對應的色彩龍交涉，招募更多巨龍入夥，並策劃推進著邪教的陰謀。

**脫離邪教 Leaving the Cult**
從加入龍巫教開始，教徒的生命就歸屬龍巫教了。逃離邪教之人會惶惶不可終日，對餘生中的每一片暗影和每一個陌生人都疑神疑鬼——因為龍巫教從不寬恕逃兵。
在極少數情況下，邪教徒可能會被除名，但仍留有小命。但這份仁慈絕不廉價——被驅逐的教徒必須被抹除記憶的魔法清除所有記憶，或是辦幾件不可告人的勾當，作為日後勒索的把柄。

### 聲望獎勵 Renown Rewards

角色可以通過為巨龍工作或完成邪教的任務來獲取龍巫教聲望。在他們提升聲望值時，角色也會獲得各種額外福利，見龍巫教聲望表。如果你的戰役不使用聲望規則，那麼由你的 DM 來決定角色是否以及何時獲得這些福利。

**龍巫教聲望**

| **聲望等級** | **獎勵** |
| --- | --- |
| 3+ | 龍巫教會為你在藏身處免費提供窮困等級的日常生活開銷。 |
| 5+ | 你可以以平常一半的價格僱傭龍巫教僱工。 |
| 10 | 你榮升龍爪位階。當你第一次達到10聲望值時，邪教會隨機獎勵你一件非普通魔法物品。 |
| 15+ | 你榮升龍翼位階。你可以指派一支由6名**邪教徒 Cultist**組成的小隊去執行任何不直接與龍巫教教義相悖的任務。當你使用此獎勵後，你只有在聲望值提升後才能再次使用。 |
| 25+ | 你榮升龍牙位階。你可以在任務中增派一名**邪教狂信者 Cultist Fanatic** 。當你使用此獎勵後，你只有在聲望值提升後才能再次使用。 |

| 50+ | 你榮升紫衫位階。所有的教徒都會遵循你的指示，並主動和你彙報消息。此外，僅限一次，你可以請求覲見龍巫教的內環。 |

### 龍巫教角色 Cult of the Dragon Characters

龍巫教吸引了來自三教九流的各色人士：無論是士兵，施法者還是地痞無賴，都會有對教派有用的技能。
任何角色都有可能與龍巫教有牽連，即便並非邪惡角色。在絕望之中，天性善良之人也有可能請求邪教的幫助。邪教徒經常會勒索無辜者為教派效力——甚至包括自己的家人。角色可能會在不知情的情況下協助龍巫教的活動（即便玩家本人知道真相）。

**成員福利 Member Benefits**
若你成為龍巫教的成員，你擁有以下福利：

**什一奉獻 Tithing。**每月你應向所處的基層組織領導捐獻100GP 或當月收入的10%，取其中較低者。

**飾品 Trinket。**在龍巫教飾品表中進行擲骰，以決定你在龍巫教生涯中獲得的飾品。

**法衣 Vestments。**作為入會流程的一部分，你會收到一套長袍和一具邪惡的龍類面具。有你來選擇法衣的顏色是黑色、藍色、綠色、紅色還是白色。

### 龍之印記 Marked By the Dragon

龍巫教通過獻祭儀式來推進他們那深不可測的目標。不過並非所有的邪教祭品都會在這折磨中喪命。極少數人從儀式中逃脫了出來，但他們也被永久改變了。據說這些倖存者都"被巨龍烙上了印記"，有人稱他們為"龍瘢"。不同的基層組織對待這些龍瘢的態度各不相同。有些會將他們看作怪物，並將它們驅逐出教派的領地。也有的基層組織會善待龍瘢，將這些人攫升為教派高層。如果你的角色在獻祭儀式中倖存，你可以在龍瘢祝福表中進行擲骰，以隨機決定你的角色歷經折磨後獲得的身體特徵。這些特徵只是表象，沒有實際效用。

**龍瘢祝福**

| **1d8** | **身體特徵** |
| --- | --- |
| 1 | 你的臉上留有一道龍形傷疤。 |
| 2 | 你長著殘缺的龍角、龍翼或尾巴。 |
| 3 | 你的雙眼瞳孔細長，長有色彩鮮豔的虹膜。。 |
| 4 | 你的部分皮膚覆蓋著爬行動物的鱗片 |
| 5 | 你的血液寒冷如冰。 |

| 7 | 你開始對一些你所屬物種一般無法食用的食物如飢似渴，並且能夠將其消化，比如整顆雞蛋、生禽肉、泥土或骨頭。 |
| 8 | 你的頭髮直衝天空，其上還有靜電噼啪作響。 |

### 特色設施 Special Facility

龍巫教的成員可以在其據點中添加如下特色設施。

**龍巫教檔案館 Cult of the Dragon Archive**

**_13級據點設施**
_**先決：**龍巫教成員_

**空間：**寬敞

**僱員：**1

**指令：**探索

龍巫教檔案館中收錄了涵蓋許多特定主題的詳實資料，包括關於龍類的內容。

**探索：有益學識 Helpful Lore。**當你對此設施下達探索指令時，你委託設施僱員針對傳說檔案進行研究。這項工作需要7天時間。僱員會如同施展了法術_通曉傳奇 Legend Lore_一般獲得這些知識，並且會在下一次交談時與你分享。

**參考書 Reference Books。**你的龍巫教檔案館收錄了大量的龍類傳說。當你在據點內時，你在因回憶有關龍類的傳說而執行研究動作時所進行的智力（自然或宗教）檢定中具有優勢。

**擴大設施 Enlarging the Facility。** 你可以花費2000GP，將龍巫教檔案館擴大為龐大設施。這樣做後，你會獲得兩本在《城主指南》第八章檔案館設施中列出的兩本參考書。
