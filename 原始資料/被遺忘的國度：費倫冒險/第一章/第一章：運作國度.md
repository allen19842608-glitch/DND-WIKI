# 第一章：運作國度

主持被遺忘的國度戰役的 DM 將面臨獨特的挑戰。本章將助你應對這些挑戰，為你和你的玩家們打造既充滿樂趣又富含個人成就的冒險旅程。內容包括：
**創作奇幻****史詩 Creating Epic Fantasy。** 本節將指導你如何構建並運作那些展現費倫世界中超凡英雄、生死博弈與強大反派的冒險故事。
**史詩天命 Epic Destinies。** 國度中的角色鮮少只是尋常冒險者。本節將提供建議，幫助你塑造與宏大設定相匹配的角色。
**國度傳說 Realms Lore。** 數十年來，無數創作者、玩家與粉絲們共同將費倫打造成了最為詳盡的奇幻設定之一。本節提供了助你在遊戲中運用這些龐大背景的建議。
**冒險 Adventures。**本章收錄了受費倫的神祇、派系、魔法與地理區域所啟發的冒險實例，為你的戰役提供豐富靈感。
