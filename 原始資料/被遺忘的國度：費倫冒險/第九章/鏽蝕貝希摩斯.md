# 鏽蝕貝希摩斯

被鏽蝕咒腐蝕的巨人堪稱可怕的猛獸，它們在無意識的狂怒中撕扯樹木、掀翻山丘。它們那堅硬的鐵鏽皮膚能彈開刀劍與箭矢，同時迸濺出有毒的橙色粉塵。這些鏽蝕貝希摩斯熱衷於破壞荒野。

### 動作 Actions

**多重攻擊 Multiattack。**鏽蝕貝希摩斯使用猛擊或鏽球投擲發動共計三次攻擊。

**猛擊 Slam。**_近戰攻擊檢定：_+10，觸及10尺。_命中：_20 （4d6 + 6） 鈍擊傷害。

**鏽球投擲 Rusted Shot Put。**_遠程攻擊檢定：_+10，射程60/240尺。_命中：_15 （2d8 + 6） 鈍擊傷害，目標陷入中毒狀態直至其下個回合結束。

### 反應 Reactions

**鏽蝕表皮 Rust-Riddled Hide。** _觸發：_鏽蝕者被一次造成鈍擊、穿刺或揮砍傷害的攻擊檢定命中。 _響應：__體質豁免檢定：_DC16，以鏽蝕者為中心5尺光環範圍內由其選擇的所有生物。_失敗：_目標在下一回合結束前中毒。
