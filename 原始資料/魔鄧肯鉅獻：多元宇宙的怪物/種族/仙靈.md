# 仙靈

妖精荒野是許多奇幻種族的家園，其中包括仙靈。仙靈是一種微小的種族，但還不及他們的皮克精 pixie 和小仙靈 sprite 朋友們。最初的精靈講著精靈語、地精語或木族語，和人類訪客的相遇也促使了許多仙靈學習了通用語。
仙靈們受到妖精荒野魔法的影響，大多仙靈看上去像是帶著昆蟲翅膀的精靈，但每個仙靈都有一種獨特的身體特徵，使得他們與其他仙靈不同。在妖精特徵表格中選擇或骰出一項作為你的仙靈的特徵。
如果下列建議都不符合你的角色，你也可以自由創作出你自己的特點。

**妖精特徵 Fey Characteristics**

| **d8** | **特徵** |
| --- | --- |
| 1 | 你的翅膀如同鳥類的翅膀。 |
| 2 | 你的皮膚閃閃發光，五彩繽紛。 |
| 3 | 你有著特別大的耳朵。 |
| 4 | 一層閃閃發光的霧一直環繞著你。 |
| 5 | 你的額頭上有一根靈體角，就像小型的獨角獸角。 |
| 6 | 你有著昆蟲的腿。 |
| 7 | 你聞起來像是剛出爐的布朗尼。 |
| 8 | 一種明顯的、無害的寒意環繞著你。 |

**仙靈特質 Fairy Traits**
作為一位仙靈，你擁有以下角色特質：

**生物類型 Creature Type。**你是妖精生物。

**體型 Size。**你的體型為小型。

**速度 Speed。**你的步行速度為30尺。

**仙靈魔法 Fairy Magic。**你知曉_德魯伊伎倆 Druidcraft_。
從3級開始，你能用該特質施展_妖火 Faerie_。從5級開始，你能使用該特質施展_變巨術/縮小術 Enlarge/Reduce_。一旦你使用了該特質施展了妖火或變巨術/縮小術，直到完成一次長休前，你不能再次使用該特質施展那個法術。你也能用你擁有的相應法術環階的法術位來施展這些法術。
當你使用該特質施展這些法術時，智力，感知或魅力是你的施法屬性（當你選擇該種族時進行決定）。

**飛行 Flight。**因為你的翅膀，你擁有等於你步行速度的飛行速度。如果你穿戴中甲和重甲，則你不能使用此飛行速度。
