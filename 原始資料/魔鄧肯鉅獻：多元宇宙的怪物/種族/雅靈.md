# 雅靈

雅靈是來自妖精荒野的精靈，那是一個充滿危險的美麗和無邊的魔法的世界。以那種魔法，雅靈可以在眨眼之間從一處傳送到另一處，而且每個雅靈都以季節的形式，與妖精荒野捕獲的情感產生共鳴這樣的親和力影響了雅靈的情緒與外觀。一個雅靈的季節能夠改變，但是一些雅靈永遠留在一個季節。從雅靈季節表格中選擇或骰出你的季節。你的出神特質能讓你轉換季節。
如同其他精靈，雅靈的壽命在750年以上。

**雅靈季節 Eladrin Seasons**

| **d4** | **季節** |
| --- | --- |
| 1 | **秋：**平和與友善，夏天的收穫分享給大家之時。 |
| 2 | **冬：**沉思與悲傷，世界中的活力沉睡之時。 |
| 3 | **春：**快樂與慶祝，象徵著冬天的悲傷過去時的歡樂和希望。 |
| 4 | **夏：**大膽與好鬥，一段象徵無羈能量和號召行動的時光。 |

**雅靈特質 Eladrin Traits**
作為一位雅靈，你擁有以下角色特質：

**生物類型 Creature Type。**你是類人生物。對於任何需要你是精靈的先決條件或效果而言，你也被視作一個精靈。

**體型 Size。**你的體型為中型。

**速度 Speed。**你的步行速度為30尺。

**黑暗視覺 Darkvision。**在微光光照下，你身邊60尺內可以視為等同於明亮光照。而在黑暗中，該範圍內可視為等同於微光光照。你無法在黑暗中分辨顏色，只能看到有灰度的黑白畫面。

**精類血統 Fey Ancestry。**你在為自己避免或結束魅惑狀態的豁免檢定時具有優勢。

**妖精步 Fey Step。**用一個附贈動作，你可以魔法地傳送到一處30尺內且未被佔據的可見空間。你可以使用該特質的次數等於你的熟練加值，當你完成一次長休後，你重新獲得所有消耗的次數。
當你到達3級時，你的妖精步會根據你的季節獲得額外的效果；如果該效果需要進行一次豁免，該 DC 等於8+你的熟練加值+你的智力，感知或魅力調整值（當你選擇該種族時進行決定）：

-   **秋 Autumn。**在你使用妖精步後，立即選擇至多兩個10尺內的可見生物，這些生物必須進行一次感知豁免，如果豁免失敗則被你魅惑1分鐘，或者直到你或你的同伴對他做出傷害行為為止。
    
-   **冬 Winter。**在你使用妖精步時，選擇傳送前位於你5尺內的一個可見生物，這個生物必須進行一次感知豁免，如果失敗則對你陷入恐慌，該效應持續至你的下一回合結束。
    
-   **春 Spring。**在你使用妖精步時，你碰觸5尺內的一個自願的生物。這個生物代替你進行傳送，出現在你選擇的一處在你30尺範圍內且未被佔據的可見空間。
    
-   **夏 Summer。**在你使用妖精步後，立即選擇的5尺範圍內的每個可見生物，它們將受到等同於你熟練加值的火焰傷害。
    

**敏銳感官 Keen Senses。**你擁有察覺技能的熟練項。

**冥想 Trance。**你不需要睡眠，並且不會因魔法效應而陷入睡眠。你能夠以4小時的時間完成長休，前提是如果你將這些時間花在一次出神冥想中，在此期間你保留意識。
每當你結束冥想時，你可以改變你的季節，並能夠獲得兩項你未擁有的熟練，其中每一項都是你從《玩家手冊》中選擇的一個武器或是工具。你通過抽取精靈共有記憶來神秘的獲得這些熟練項，並且你保留他們直到你完成下次長休。
