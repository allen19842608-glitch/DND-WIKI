# 預言法師

**預言法師 Diviner Wizard**

預言師可以窺探未來，深知知識就是力量。他們可能表現得冷漠而神秘，暗示著預兆和秘密，也可能是萬事通，為了提高自己的地位而洩露真知灼見。

## 預言法師 Diviner Wizard

_中型類人，任意陣營_

**護甲等級**：12（使用法師護甲時15）

**生命值**：90（20d8）

**速度**：30尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 9 | -1 |
| 敏捷 | 14 | +2 |
| 體質 | 11 | +0 |
| 智力 | 18 | +4 |
| 感知 | 12 | +1 |
| 魅力 | 11 | +0 |

**豁免**：智力+7，感知+4

**技能**：奧秘+7，歷史+7

**感官**：被動察覺11

**語言**：任意四門語言

**挑戰等級**：8（3,900XP） 熟練加值+3

### 動作 Actions
多重攻擊 Multiattack。**預言師進行三次奧能爆發攻擊。

**奧能爆發 Arcane Burst。**近戰或遠程法術攻擊：命中+7，距離5尺或120尺，單一目標。命中：20 （3d10+4）點光耀傷害。

**天啟將至 Overwhelming Revelation（充能5~6）。**預言師魔法地在距其120尺內選擇一點為中心，半徑10尺的球體內製造出一束光。該區域內的每個生物都必須進行一次 dc15的感知豁免。豁免失敗時，生物受到45 （10d8）的心靈傷害，並被震懾至預言師的下一回合結束。豁免成功時，，該生物受到的傷害減半，並且不會被震懾。

**施法 Spellcasting。**預言師施展下列的一個法術，其施法屬性為智力（法術豁免 DC15）：
_隨意：法師之手 mage hand, 傳訊術 message, 魔法伎倆 prestidigitation_
每項2/日：秘法眼 arcane eye, 偵測魔法 detect magic,偵測思想 detect thoughts,
飛行術 fly, 閃電束 lightning bolt, 物品定位術 locate object, 法師護甲 mage armor, 拉瑞心靈聯結 Rary's telepathic bond
1/日：真知術 true seeing_
### 反應 Reactions

**預兆 Portent（3/日）。** 當預言師或一個它所能看見的生物進行一次攻擊檢定、豁免檢定、或屬性檢定時，預言師可以骰一顆 d20並選擇使用該骰替換掉其攻擊檢定、豁免檢定、或屬性檢定的擲骰結果。
