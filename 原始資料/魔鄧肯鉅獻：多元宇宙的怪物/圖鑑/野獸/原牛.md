# 原牛

**原牛 Aurochs**

原牛是一種巨大凶猛，有突出尖銳彎角的牛類。在許多國家，成群的原牛自由遊蕩，而在其他地方，獸人和人類從很小的時候就訓練它們作為坐騎進入戰鬥。

## 原牛 Aurochs

_大型野獸（牛類），無陣營_

**護甲等級**：11（天生護甲）

**生命值**：38（4d10+16）

### 動作 Actions

**角抵 Gore。**近戰武器攻擊：命中+7，觸及5尺，單一目標。命中：14（2d8+5）穿刺傷害。如果原牛先向目標直線移動至少 20 尺，然後在同一回合裡以抵撞攻擊命中該目標。此時該目標將受到額外 9（2d8）鈍擊傷害。若目標是生物，則該目標必須通過 DC15的力量豁免檢定，否則將被撞擊倒地。
