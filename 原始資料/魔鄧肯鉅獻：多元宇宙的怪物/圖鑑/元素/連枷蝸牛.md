# 鏈枷蝸牛

**鏈枷蝸牛 Flail Snail**

鏈枷蝸牛是一種由元素之土構成的生物，以它那多彩而又正規的外殼而著稱。它看似無害，實則它們會在足夠大的威脅生物靠近時，閃耀出刺眼的光芒，並用錘子一般的觸手發起攻擊。
在沒有干擾的情況下，鏈枷蝸牛會沿著地面緩緩移動著。它會食用著表面上的一切東西，包括岩石、沙子、與土壤，也會停下來仔細品味水晶簇和其他大型礦產。它會走過的地方殘留下一道閃閃發光的殘留物。殘留物會迅速凝固成一層薄薄的，近乎透明的，對蝸牛來說不可食用的玻璃狀物質。這種殘留物可以被收集，切割成各樣的窗玻璃，也可以被加熱並紡成其他玻璃製品——因此，有些居民會嘗試尾隨鏈枷蝸牛，收集殘留物謀生。

**使用鏈枷蝸牛殼 Using the Shell of a Flail Snail**
一枚鏈枷蝸牛的殼重250磅，且有許多用處。一塊完整的殼可以被以5000gp 的價格賣出。
許多獵人為了蝸殼的反魔法能力而尋找它。一個專業的護甲師可以用一枚蝸殼做三面盾牌，每面盾牌都可以基於給持用者鏈枷蝸牛的 **反魔法蝸殼 Antimagic Shell** 特性。盾牌的魔力可以持續一個月，魔力消失後，留下的獨特盾牌也是用於製作 _抗法盾 Spellguard Shield_ 的完美素材。
鏈枷蝸牛殼也可以用於製作 _虹光法袍 Robe of Scintillating_。在用於製作法袍時，需要將一枚蝸殼碾成粉末，一部分添加到染料中，一部分作為給法袍附魔的儀式的材料成分。

## 鏈枷蝸牛 Flail Snail

_大型元素生物，無陣營_

**護甲等級**：16（天生護甲）

**生命值**：52（5d10+25）

**速度**：10尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 17 | +3 |
| 敏捷 | 5 | -3 |
| 體質 | 20 | +5 |
| 智力 | 3 | -4 |
| 感知 | 10 | +0 |
| 魅力 | 5 | -3 |

**傷害免疫**：火焰，毒素

**狀態免疫**：中毒

**感官**：黑暗視覺60尺，震顫感知60尺，被動察覺10

**語言**：——

**挑戰等級**：3（700 XP） 熟練加值+2

**反魔法蝸殼 Antimagic Shell。**蝸牛在對抗法術時所進行的豁免具有優勢；任何生物對蝸牛發動法術攻擊時，其攻擊檢定將具有劣勢。
當蝸牛對抗法術的豁免成功時，或當一次來自法術的攻擊以蝸牛為目標但是沒有命中它時，如果那次法術的環階為1環或更高，則蝸牛的外殼將部分來襲的法術能量轉換為一陣破壞性的力量。此時，所有處於蝸牛周圍30尺範圍內的每個生物都必須通過一次 DC15的體質豁免，豁免失敗將受到該法術環階每環3（1d6）點力場傷害，豁免成功則只受半數傷害。
### 動作 Actions

**多重攻擊 Multiattack。**鏈枷蝸牛發動五次鏈枷觸手攻擊。

**鏈枷觸手 Flail Tentacle。**近戰武器攻擊：命中+5，觸及10尺，單一目標。命中：5（1d4+3）點鈍擊傷害。

**閃耀之殼 Scintillating Shell（短休或長休後充能）。**蝸牛的外殼發出耀眼的彩光。外殼將散發出半徑30尺的明亮光照，與之外的30尺的微光光照。任何處於此明亮光照範圍內，且能看到蝸牛的生物，必須通過一次 DC15的感知豁免，豁免失敗將陷入 **震懾 Stunned** ，持續直到光照消失。光照將一直持續到蝸牛的下一回合結束為止。此外，光照存在期間，任何可以看見蝸牛的生物對蝸牛發動的攻擊檢定具有劣勢。

**殼體防禦 Shell Defense。**鏈枷蝸牛縮回它的殼中。直到它出殼為止，其 AC 獲得+4加值並陷入 **束縛 Restrained** 狀態。它能在它的回合中以一個附贈動作重新出殼。
