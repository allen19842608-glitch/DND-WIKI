# 食人魔攻城錘

**食人魔攻城錘 Ogre battering ram**

攜帶巨棒的食人魔攻城錘主要用於把門砸成柴火，但也適用於粉碎敵人。這些食人魔只執行兩個簡單的任務：衝上去粉碎敵人的防禦工事，和用他們的武器讓前進的敵人停下。

## 食人魔攻城錘 Ogre battering ram

*大型巨人，普遍混亂邪惡*

**護甲等級**：11（獸皮甲）

**生命值**：76（9d10+27）

**速度**：40尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 19 | +4 |
| 敏捷 | 8 | -1 |
| 體質 | 16 | +3 |
| 智力 | 5 | -3 |
| 感知 | 7 | -2 |
| 魅力 | 7 | -2 |

**感官**：黑暗視覺60尺，被動察覺8

**語言**：通用語，巨人語

**挑戰等級**：4（1,100 XP） 熟練加值+2

**攻城怪物 Siege Monster。**食人魔攻城錘對物件和建築物造成雙倍傷害。
### 動作 Actions

**多重攻擊 Multiattack。**食人魔攻城錘發動兩次痛擊。

**痛擊 Bash。**近戰武器攻擊：命中+6，觸及5尺，單一 目標。命中：15（2d10+4）的鈍擊傷害，並且食人魔攻城錘可以將目標推離五尺，如果其為巨型體型或者更小。
### 反應 Reactions

**攔路虎 Block the Path。**當一個生物進入食人魔5尺攻擊範圍內的空間時，食人魔對該生物進行一次痛擊。如果攻擊命中，目標的速度將降低到0，直到食人魔下一回合開始。
