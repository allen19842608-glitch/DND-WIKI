# 毒液巨魔

**毒液巨魔 Venom Troll**
從大量毒素中倖存下來巨魔可能會變異成毒液巨魔。殘留的毒液滲透進它的血液和組織，毒液從毛孔中漏出，覆蓋在它的毒牙和爪子上。這些生物在近身戰鬥中額外的危險，因為毒液會從它們肉體中滴下，並且在它們受到的每一個傷口中噴濺而出。

## 毒液巨魔 Venom Troll

_大型巨人，通常混亂邪惡_

**護甲等級**：15（天生護甲）

**生命值**：94(9d10+45)

**速度**：30尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 18 | +4 |
| 敏捷 | 13 | +1 |
| 體質 | 20 | +5 |
| 智力 | 7 | -2 |
| 感知 | 9 | -1 |
| 魅力 | 7 | -2 |

**技能**：察覺+5

**傷害免疫**：毒素

**狀態免疫**：中毒

**感官**：黑暗視覺60尺，被動察覺15

**語言**：巨人語

**挑戰等級**：7（2900XP）熟練加值+3

**毒液飛濺 Poison Splash。**當巨魔受到任何除了心靈以外的傷害時，在巨魔周圍5尺的每個生物受到9（2d8）的毒素傷害。

**再生 Regeneration。** 巨魔在它的回合開始時回覆10 點生命值。如果巨魔受到強酸或者火焰傷害，則該特質在它的下一回合裡無法生效。如果巨魔以0 生命值開始其自己回合且無法使用再生，則巨魔死亡。
### 動作 Actions

**多重攻擊 Multiattack。**巨魔發動三次攻擊：一次啃咬和兩次爪擊

**啃咬 Bite。**近戰武器攻擊：命中+7，觸及5 尺，單一目標。命中：7 （1d6+4）的穿刺傷害，外加4（1d8）毒素傷害。該生物陷入中毒直到巨魔的下一個回合開始。

**爪擊 Claw。**近戰武器攻擊：命中+7，觸及5 尺，單一目標。命中：11 （2d6+4）的揮砍傷害，外加4（1d8）毒素傷害。

**毒氣噴湧 Venom Spray（充能6）。**巨魔用爪子撕開自己的身體，向15尺立方範圍噴出毒霧。巨魔受到7（2d6）的揮砍傷害（此傷害不能被任何方法減少），該範圍內的每個生物都必須進行一次 DC16的體質豁免，豁免失敗者受到18（4d8）的毒素傷害並中毒一分鐘，豁免成功則傷害減半且不會中毒。一個已中毒的生物可以在每個其自己回合結束時再進行一次該豁免，豁免成功則結束其身上的效應。
