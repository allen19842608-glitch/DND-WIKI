# 雲巨人歡笑者

**雲巨人歡笑者 Cloud Giant Smiling One**

歡笑者是視尊崇和效仿曼諾的詭計與欺騙高於一切的雲巨人。他們是最高明的騙子，極盡花招、欺騙、誤導和魔法之能事追求財富。他們的天性難以預料，還有著缺德的幽默感。歡笑者的行為僭越了禮節的所有界限，以至低俗的無賴都會認為他們的所作所為有失體面。
“歡笑者”這個名字來源於他們佩戴的古怪雙面面具。雙面面具的其中一半是笑臉，看起來往往更像是假笑或得意洋洋的譏笑，而非宜人的笑臉。另一半雙面面具皺著眉，表明歡笑者對它們處於風暴巨人之後的第二序位位置的不滿。雙面面具象徵著雲巨人歡笑者的信仰，與此同時歡笑者面部的真實表情也隱藏在面具之下。

### 動作 Actions

**多重攻擊 Multiattack。**巨人進行兩次猛擊或兩次念力打擊。

**猛擊 Slam。**近戰武器攻擊：命中+12，觸及10尺，單一目標。命中：21（3d8+8）鈍擊傷害加上5（1d10）心靈傷害。

**念力打擊 Telekinetic Strike。**遠程武器攻擊：命中+7，射程240尺，單一目標。命中：25（4d10+3）力場傷害。

**變化形體 Change Shape。**巨人如魔法般變形成它看到的野獸或者類人生物，或者回到他的真實形態。巨人穿著或攜帶的任何裝備都會被新形態吸收。他的數據，除了它的體形外，在每種形態下都是相同的。如果他死了，它變回其真實形態。

**施法 Spellcasting。**巨人施展以下法術之一，無需材料成分，且以魅力為其施法屬性（法術豁免 DC15）：
_隨意：偵測魔法，雲霧術，光亮術，次級幻象_
每項3/日：隱形術，無聲幻影，暗示術，羽落術，巧言術
每項1/日：氣化形體，高級幻影_
### 附贈動作 Bonus Actions

**騰雲步 Cloud Step（充能4~6）。**巨人和他攜帶、穿著的所有裝備傳送到至多60尺內一個他能看見且未被佔據的位置。
