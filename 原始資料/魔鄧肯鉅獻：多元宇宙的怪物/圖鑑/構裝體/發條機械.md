# 發條機械

**發條機械 Clockworks**

侏儒們在魔法和機械裝置上工藝製造出了許多失敗的構裝生物，但也同樣帶來了真正的進步，比如發條機械。製造這些發條機械的方法已經在侏儒社區之間流傳了數代。

**個性化設計 Individual Designs**
侏儒工匠們更看重一臺個性化的發條機械，而不是為了造出一臺功能完美的發條機械，而盲目過照搬另一個作品的做法。發條機械可以通過在其數據中添加以下增強功能之一和一個潛在的故障來實現個性化。你可以隨機選擇，也可以選擇一對適合其設計者風格的改造方案。

| ****1d10**** | ****發條機械增強**** |
| --- | --- |
| 1 | **偽裝。**如果發條機械還沒有敏捷（隱匿）熟練項，它會獲得該技能。當它靜止不動時，與停止的機器沒有什麼區別。 |
| 2 | **傳感器。**發條機械的黑暗視覺範圍增加60尺。此外，如果原本沒有，它可以獲得感知（察覺）熟練。 |
| 3 | **提高護甲。**發條機械的 AC 增加2。 |
| 4 | **增加速度。**發條機械的速度增加10尺。 |
| 5 | **強化結構。**這種發條機械具有力場、閃電和雷鳴傷害的抗性。 |
| 6 | **自我修復。**如果發條機械在其回合開始時至少有1點生命值，它將恢復5點生命值。如果它受到閃電傷害，這個能力在其下一個回合開始時不會生效。 |
| 7 | **堅固構造。**發條機械的生命值上限增加等於它的生命骰數。 |
| 8 | **吸附。**發條機械獲得30英尺的攀爬速度。 |
| 9 | **發聲諧振器。**發條機械獲得講基礎的通用語或侏儒語（由創造者選擇）的能力。 |
| 10 | **渦輪推進。**發條機械獲得30尺的游泳速度。 |

| ****1d8**** | ****發條裝置故障**** |
| --- | --- |
| 1 | **傳感器失靈。**在發條機械的回合開始時投擲 d6。如果骰出1，發條機械直到它回合結束為止處於目盲。 |
| 2 | **定位儀缺陷。** 在發條機械的回合開始時投擲 d6。如果骰出1，發條機械的攻擊骰具有劣勢直到其回合結束。 |
| 3 | **接地故障。**發條機械具有閃電傷害易傷。 |
| 4 | **底層循環。**在發條機械的回合開始時投擲 d6。如果骰出1，發條機械會將一個它能看到的30英尺內的生物誤認為其創造者。發條機械在一分鐘內不會傷害該生物，直到該生物攻擊它或對它造成傷害為止。 |
| 5 | **轉彎卡死。**發條機械必須沿直線運動。它可以在運動前和運動中點轉向90度。如果其在該回閤中沒有移動，它可以改為自由轉向。 |
| 6 | **優先自保。**如果發條機械在戰鬥中開始其回合時只有一半或更少的生命值，投擲 d6。如果骰出1，它將從戰鬥中撤退。如果撤退是不可能的，它會繼續戰鬥。 |
| 7 | **過熱。**在發條機械的回合開始時投擲 d6。如果骰出1，發條機械陷入失能，直到它的回合結束。 |
| 8 | **齒輪生鏽。**發條機械在先攻檢定上有劣勢，它的速度會下降10尺。 |
