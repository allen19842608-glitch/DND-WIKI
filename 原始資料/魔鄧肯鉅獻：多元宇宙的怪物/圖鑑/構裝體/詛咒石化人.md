# 詛咒石化人

**詛咒石化人 Stone Cursed**

在一個被轉變為石頭的原類人生物身上舉行一場邪惡的鍊金儀式，一名詛咒石化人就此誕生。這次儀式需要用到 石化蜥蜴 Basilisk 的鮮血與 蛇雞 Cockatrice 的羽毛灰燼（將它們混合得到混合物），而儀式將喚醒被石化者殘存的魂魄殘響，活化這尊“雕像”，讓其成為新的、能夠發揮作用的守護者。
詛咒石化人有著屠戮生靈的惡意，但它們會完全忠實於完成儀式活化它們之人，也會盡最大可能的服從那人的命令。在戰鬥中，它們會伸出岩石質的爪子攻擊敵人，利用爪子上的那一層厚實的、不斷滴落的鍊金灰色汙泥將被爪子劃傷之人化為一尊新的“雕像”。
作為製造詛咒石化人儀式效應的一部分，它們的軀幹內會形成一顆拳頭大小的黑曜石制頭顱。雖然在詛咒石化人活動期間從外面是看不見這顆頭顱的，但是一旦詛咒石化人被擊殺，“雕像”破碎，這顆頭顱就會落在地上。這顆頭顱正是這種邪惡鍊金儀式創造此種恐怖造物的中樞，因此頭箍棕會有著最初被活化、被石化前的受害者記憶，迴盪、迴響於其中。一名熟練的魔法使也許可以從這枚黑曜石頭顱中提取記憶，以此瞭解受害者的過往經歷，以及也許被雪藏的失落學識。

**詭秘的低語 Cryptic Whispers**
事實上被轉化為詛咒石化人的生物早已死去了，但即使如此它們記憶之中的數段低語將繼續存活在詛咒石化人體內，那顆黑曜石頭顱中。每當完成一次短休時，角色可以嘗試通過一次 DC20的智力（奧秘）檢定來嘗試提取出頭顱中的記憶......其形式如同角色口頭對其提出一段問題，之後頭顱給出的回答。一旦進行了這一檢定，不論檢定是否成功，頭顱都無法再次被以這種途徑使用了。

## 詛咒石化人 Stone Cursed

_中型構裝，普遍守序邪惡_

**護甲等級**：17（天生護甲）

**生命值**：19（3d8+6）

**速度**：10尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 16 | +3 |
| 敏捷 | 5 | -3 |
| 體質 | 14 | +2 |
| 智力 | 5 | -3 |
| 感知 | 8 | -1 |
| 魅力 | 7 | -2 |

**傷害易傷**：鈍擊

**傷害免疫**：毒素

**狀態免疫**：魅惑、力竭、恐慌、石化、中毒

**感官**：被動察覺9

**語言**：生前所知曉的語言

**挑戰等級**：1（200XP） 熟練加值+2

**詭詐藉機 Cunning Opportunist。**詛咒石化人為藉機攻擊所做的攻擊檢定具有優勢。

**擬形 False Appearance。**當詛咒石化人在戰鬥開始時保持靜止，它進行的先攻檢定具有優勢。不僅如此，如果一個生物未曾觀察過這隻詛咒石化人移動或行動，生物必須得通過一次 DC18的智力（調查）檢定才能發覺這是一隻詛咒石化人，而不是一尊雕像。

**非凡本質 Unusual Nature。**詛咒石化人不需要呼吸、吃、喝、以及睡眠。
### 動作 Actions

**石化爪擊 Petrifying Claws。**近戰武器攻擊：命中+5，觸及5尺，單一目標。命中：12（2d8+3）點揮砍傷害。若目標為生物，其還需要通過一次 DC12的體質豁免，若豁免失敗該生物將開始逐漸轉變為石頭並陷入 **束縛 Restrained** 狀態，持續直至它的下一回合結束......此時，其必須重複這一豁免。豁免成功則終止此效應對它的影響；豁免失敗則陷入 **石化 Petrified** 狀態，持續24小時。
