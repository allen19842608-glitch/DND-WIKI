# 沼喉怪

**沼喉怪 Froghemoth**

沼喉怪是一種像大象一樣大的兩棲捕食者。它棲息在沼澤中，有四條觸手，厚實的膠質皮膚，帶著一條能抓物的舌頭的充滿尖牙的口器，及一根可伸展的肉莖上朝向不同方向運動的三個眼球。
沼喉怪是不屬於這個世界的生物。一本據說是很久以前由法師 盧姆 Lum 寫的日記裡，描述了埋藏在地下的奇怪柱形金屬房間。沼喉怪從那裡出現，但是沒有關於這些地方位置的可靠報告。
每隔幾年，一頭沼喉怪就可以在不交配的情況下產下一顆受精卵。沼喉怪不關心它的卵，也可能把它吃掉。一頭年幼的沼喉怪的生存通常是建立在它的父母在冷漠中離棄了它。一頭新生的沼喉怪通過不加選擇的捕食它沼澤領地裡的其他生物在一個月時間裡成長為完全的大小。他學會了把它巨大的軀體隱藏在渾濁的水塘裡，只把它的眼睛露在水面上以觀察路過的生物。當食物觸手可及時，沼喉怪就會從它的水塘裡射出觸鬚和舌鞭。它可以同時攫取多個目標，使它們陷入絕境，在它用舌頭捲起另一個目標並把它拉過來吞下時。
如果一個啵靈蛙部落遇到了一頭沼喉怪，啵靈蛙會把沼喉怪當做神明看待，竭盡所能把這怪物哄誘進他們的巢穴。啵靈蛙通過提供食物來（勉強）馴服這些沼喉怪，且可以與它進行基本的溝通。所以絕大部分的這種生物往往很少捕食這些啵靈蛙。啵靈蛙收集食物作為給它的貢品，為它提供一個舒適的巢穴，狂熱的保護它免受傷害，並努力確保任何年幼的沼喉怪都能發育成熟。

### 動作 Actions

**多重攻擊 Multiattack。** 沼喉怪發動一次啃咬攻擊和兩次觸鬚攻擊。它還使用舌卷。

**啃咬 Bite。**近戰武器攻擊：命中+10，觸及5尺，單一目標。命中：22（3d10+6）點穿刺傷害，如果目標是一箇中型或更小的生物則被吞下。一個被吞下的目標陷入**目盲**且被**束縛**，其對於沼喉怪身體外的攻擊或效應視為處於**全身掩護**，並在每次該沼喉怪的回合開始時受到10（3d6）的強酸傷害。沼喉怪的食道一次可以容納兩個生物。
如果沼喉怪在同一回合受到20點或更多來自其體內的傷害，則該沼喉怪在該回合結束時必須成功通過一次 DC20的體質豁免否則將吐出所有被吞下的生物，每個都摔下倒地於沼喉怪周邊10尺範圍內。如果該沼喉怪死亡，則被吞下的生物將不再受**束縛**，且可以消耗10尺移動力逃出，然後在屍體旁現身並陷入**倒地**狀態。

**觸鬚 Tentacle。**近戰武器攻擊：命中+10，觸及20尺，單一目標。命中：19（3d8+6）點鈍擊傷害,如果目標是巨型或更小的生物則被**擒抱**（逃脫 DC 16）。直到擒抱結束，沼喉怪不能對另一個目標使用這條觸手。沼喉怪有四條觸手。

**舌卷 Tongue。**沼喉怪選擇一個20尺內它能看見的中型或更小的生物。目標必須成功通過一次 DC18的力量豁免。豁免失敗則目標被拉至沼喉怪5尺內一處未佔據空間。
