# 咒恨蛇人

**咒恨蛇人 Yuan-Ti Anathema**

憎惡蛇人對神性的追求也許會令其嘗試一種儀式，而一旦成功，它就可以轉變成更為強大的形態——咒恨蛇人。這一儀式需要數以百計的蛇作為祭品，而憎惡蛇人還要沐浴在敵人的鮮血中。儀式帶來的轉變極為迅速，卻也苦痛難耐。
並非所有的蛇人都渴望看到它們中的一員轉變成咒恨蛇人，因為咒恨蛇人殘酷地驅使那些弱小同類，以達成他們自己的邪惡目的。
咒恨蛇人自封為半神，並追求進一步取得更高等的神性。它們要求更弱的蛇人服從，並利用其所擁有的一切資源對其鄰國發起征戰，掠來俘虜與祭品，以及榮耀和財富，而這些皆是為了讓咒恨蛇人們取得它們所認為的，真正的神性所需的代價。
咒恨蛇人不會衰老，故而它們可以恆久地追求自己的目標，直至時間的盡頭。咒恨蛇人中真正的強者可以支配多個蛇人都市，並將整個地區置於蛇人的統治之下。

**魔法抗性 Magic Resistance。**咒恨蛇人為抵抗法術和其他魔法效應而作的豁免檢定具有優勢。

**懼蛇靈光 Ophidiophobia Aura。**任何由咒恨蛇人選擇的生物（除非是一條蛇或一隻蛇人）在咒恨蛇人30尺內開始回合時都必須成功通過一次 DC17的感知豁免，否則將對蛇和蛇人**恐慌**。陷入**恐慌**的目標可以在每次自己回合結束時重複豁免，豁免成功則結束該效應。若目標豁免成功或是該效果結束，則目標在接下來的24小時內免疫該咒恨蛇人的懼蛇靈光。

**六首 Six Heads。** 咒恨蛇人在對抗**目盲、魅惑、耳聾、恐懼、震懾或昏迷**的豁免檢定上有優勢。
### 動作 Actions

**多重攻擊（僅蛇人形態)。**咒恨蛇人發動兩次爪擊和一次疾風連啃攻擊。

**爪擊（僅蛇人形態）。**近戰武器攻擊：命中+10，觸及10尺，單一目標。命中：13（2d6+6）揮砍傷害。

**疾風連啃 Flurry of Bites（僅蛇人形態）。**近戰武器攻擊：命中+10，觸及10尺，單一生物。命中：27（6d6+6）穿刺傷害外加14（4d6）毒素傷害。

**絞纏 Constrict（僅巨蟒形態）。**近戰武器攻擊：命中+10，觸及15尺，單一個大型或更小的生物。命中：16（3d6+6）鈍擊傷害外加7（2D6）強酸傷害，且目標被**擒抱**（逃脫 DC16）。目標還會在被擒抱期間陷入**束縛**狀態，且在其每個回合開始時受到16（3d6+6）鈍擊傷害外加7（2D6）強酸傷害，咒恨蛇人一次只能**擒抱**一個生物。

**施法 Spellcasting（僅蛇人形態）。**咒恨蛇人施展以下一道法術，使用魅力作為施法屬性且無需任何材料成分（法術豁免 DC17）：
_隨意：化獸為友（僅蛇類）_
每項3/日：黑暗術，糾纏術，恐懼術，變形術，暗示術_
### 附贈動作 Bonus Actions

**變形 Change Shape。**咒恨蛇人變為一條巨形蟒蛇，或是變回其真實形態。它的數據在每種形態都是相同的。任何它所攜帶的裝備都不會隨之變形。
