# 食屍魔

**食屍魔 Maurezhi**

當食屍鬼之王多瑞森 Doresain 腐化了一個精靈社群時，他創造出了一種新的惡魔——食屍魔，以此來領導物質位面的食屍鬼和妖鬼（資料均見《怪物圖鑑》）大群。
當食屍魔吃盡一個被其殺死的類人生物的屍體——這一過程大概需要10分鐘時間——它會立刻呈現出該生物活著時候的樣子。這一新外表會在接下來的幾天裡開始腐爛，最終展現出這種惡魔原本的樣子。
食屍魔是疫病傳染的具象化身。其啃咬可以耗盡受害者的自我意識。如果這種苦痛的強度足夠大，受害者會感染上對血肉的不潔飢餓，這飢餓會壓過其原本的人格，將其轉變為一個食屍鬼。

**偽裝形體 Assume Form。**食屍魔可以偽裝成任何被其吃掉的中型類人生物的外表。此偽裝維持1d6天，在此期間會逐漸腐爛，直到效果結束時，此形體自惡魔的身體上剝落。

**魔法抗性 Magic Resistance。**食屍魔對抗法術和其他魔法效應時的豁免骰具有優勢。
### 動作 Actions

**多重攻擊 Multiattack。**食屍魔進行一次啃咬攻擊與一次爪擊攻擊。

**啃咬 Bite。**近戰武器攻擊：命中+6，觸及5尺，單一目標。命中：14（2d10+3）點穿刺傷害。若該目標是一個生物，則其魅力值減少1d4點。此減損持續到該目標完成一次短休或長休。若此目標的魅力值減少到0，則其死亡。因此而死亡的目標會在24小時候重生為一個 **食屍鬼 Ghoul**，除非其在此之前已經被複活，或其屍體被摧毀。

**爪擊 Claws。**近戰武器攻擊：命中+6，觸及5尺，單一目標。命中：12（2d8+3）點揮砍傷害。若該目標是一個非不死生物的生物，則其必須成功通過一次 DC12的體質豁免，否則被麻痺1分鐘。該目標在其每個回合結束時可以重複進行此豁免，豁免成功則終止其所承受的此效應。

**復生食屍鬼 Raise Ghoul****（充能5~6）****。**食屍魔指定30尺內一個其可以看到的死去的 **食屍鬼 Ghoul** 或 **妖鬼 Ghast** 為目標。該目標復生並且擁有滿生命值。
