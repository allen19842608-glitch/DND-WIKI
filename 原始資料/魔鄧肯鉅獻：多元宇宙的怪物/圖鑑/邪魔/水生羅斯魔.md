# 水生羅斯魔

**水生羅斯魔 Hydroloth**

正如他們所棲居的消除人記憶的冥河水一樣，水生羅斯魔攝取攻擊目標的記憶，偷走他們的思想，獻給給他們所侍奉的主人。水生羅斯魔善於尋找丟失之物，特別是淹沒在深處的東西。
兩棲或者水下作戰的情況中，水生羅斯魔在尤格羅斯魔中無人能比。他們有時候會襲擊並擊沉船隻，或者突襲濱海據點。

**水生羅斯魔 Hydroloth**

**_中型邪魔（尤格羅斯魔），普遍中立邪惡_**
護甲等級：15
生命值：135（18d8+54）
速度：20尺，游泳40尺
力量12（+1） 敏捷21（+5） 體質16（+3）
智力19（+4） 感知10（+0） 魅力14（+2）
技能：洞悉+4，察覺+4
傷害易傷：火焰
傷害抗性：寒冷、閃電；非魔法攻擊的鈍擊、穿刺、揮砍傷害
傷害免疫：強酸、毒素
狀態免疫：中毒
感官：盲視60尺，黑暗視覺60尺，被動察覺14
語言：深淵語，煉獄語，心靈感應60尺。
挑戰：9（5,000 XP）熟練加值：+4

**兩棲 Amphibious。**水生羅斯魔可以在水中和空氣中呼吸。

**魔法抗性 Magic Resistance。**水生羅斯魔在對法術和其他魔法效果的豁免檢定上有優勢。

**牢固記憶 Secure Memory。**水生羅斯魔免疫冥河之水以及其他任何能夠竊取或者修改其記憶，以及偵測或閱讀其思想的效應。

**水生優勢 Watery Advantage。**浸沒在水中時，水生羅斯魔的攻擊檢定具有優勢。

**動作 Actions**

**多重攻擊 Multiattack。**水生羅斯魔進行兩次啃咬或爪抓攻擊。其中一次攻擊可以替換為施展一個法術。

**啃咬 Bite。**近戰武器攻擊：+9命中，觸及5尺，單一目標。命中：16(2d10+5)點穿刺傷害，外加9（2d10）點心靈傷害。

**爪擊 Claws。**近戰武器攻擊：+9命中，觸及5尺，單一目標。命中：14(2d8+5)揮砍傷害，外加9（2d10）點心靈傷害。

**施法 Innate Spellcasting 。**水生羅斯魔施展如下法術之一，且不需要材料成分，其施法屬性為智力（法術豁免 DC16)：
_隨意：黑暗術 darkness，偵測魔法 detect magic，解除魔法 dispel magic，隱形術 invisibility (僅自身)_
每項3/日：操控水體 control water，瘋狂冠冕 crown of madness，恐懼術 fear，暗示術 suggestion
_**記憶竊取 Steal Memory (1/日)。**水生羅斯魔以60尺內可以看到的一個生物為目標。目標受到14（4d6）點心靈傷害，並且需要進行一次 DC16的智力豁免。豁免成功則該生物24小時內免疫該水生羅斯魔的記憶竊取。豁免失敗則目標失去所有熟練項；不能施法；不能理解語言；並且如果他的智力和魅力屬性值大於5，則變為5。每當目標完成一次長休便可以重新進行豁免，豁免成功時效應終止。一個施展在目標身上的_高等復原術 greater restoration_或者_移除詛咒 remove curse_可以提前結束效應。_

**傳送術 Teleport。**水生羅斯魔可以攜帶任何穿著或攜帶的物品傳送到60尺內能看見的未佔據空間裡。
