# 魘騎魔

**魘騎魔 Narzugon**

與魔鬼做交易並帶著那扭曲的榮譽感進入來世的聖武士對九獄的大公們格外有價值。這些魘騎魔充當著恐怖墮落版本的遊俠騎士，執行其主子的意願。
魘騎魔手持地獄鍛造、可以將任何被其殺死的生物的靈魂轉移至冥河並重生為劣魔（見《怪物圖鑑》）的騎槍。每一支騎槍上都同時擁有魘騎魔自己和其主人的標記。
每個魘騎魔都擁有一隻夢魘（見《怪物圖鑑》）作為坐騎。這些坐騎被_煉獄鞍轡 infernal tack_ （見下）所綁定，必須回應馬刺穿戴者的召喚與命令。

**煉獄鞍轡 Infernal Tack。** 魘騎魔身上穿戴的馬刺是_煉獄鞍轡 infernal tack_ 的一部分，因此它可以以一個動作召喚其夢魘同伴。

**魔法抗性 Magic Resistance。** 魘騎魔對抗法術和其他魔法效應時的豁免骰具有優勢。
### 動作 Actions

**多重攻擊 Multiattack。**魘騎魔進行三次地獄火騎槍攻擊。然後，它使用煉獄指令或恐怖指令。

**地獄火騎槍 Hellfire Lance。**近戰武器攻擊：命中+10，觸及10尺，單一目標。命中：11（1d12+5）點穿刺傷害，外加16（3d10）點火焰傷害。若此傷害殺死了一個有靈魂的生物，該生物在1d4小時後於阿弗納斯的冥河重生為一個**劣魔 lemure**（見《怪物圖鑑》）。若該生物沒有在此之前被複活，則只有一個_祈願術 wish_法術，或殺死該劣魔並對該生物原本的身體施放_完全復生術 true resurrection_ 才能使其恢復生命。構裝生物與魔鬼免疫此效應。

**煉獄指令 Infernal Command。** 魘騎魔60尺內的所有盟友無法被魅惑或陷入恐慌，直到魘騎魔的下一回合結束。

**恐怖指令 Terrifying Command。** 魘騎魔60尺內的每個非邪魔生物必須成功通過一個 DC17的魅力豁免，否則陷入對魘騎魔的恐慌1分鐘。一個生物可以在其自己的回合結束時重複進行此豁免，成功則結束此效應。一個在豁免擲骰中獲得了成功的生物在接下來的24小時裡免疫此魘騎魔的恐怖指令能力。

**醫療 Healing****（1/日）****。**魘騎魔，或其觸碰的一個生物，恢復100點生命值。

**魔法物品：煉獄鞍轡 Infernal Tack**
_奇物，傳說（需邪惡陣營生物同調）_
一個騎手可以以煉獄鞍轡綁定一隻夢魘為其服務，這套鞍轡包括籠頭、嚼子、韁繩、馬鞍和馬鐙，以及供騎手穿戴的馬刺。一隻裝備了煉獄鞍轡的夢魘必須服從穿戴馬刺的生物，直到其穿戴者死亡或鞍轡被移除。
你可以用一個動作，通過將馬刺互相磕在一起或者用它們刮過鮮血來召喚一隻裝備了煉獄鞍轡的夢魘。該夢魘於你的下一回合開始時出現在你的20尺內。它作為你的盟友行動，並在你的先攻階段進行其回合。它會保持存在1天，直到你或它死去，或直到你用一個動作遣返它。若該夢魘死亡，它會用24個小時在九獄中重構形體，在那之後你可以在此召喚它。
此鞍轡並不會創造出一個夢魘；必須先制服一隻夢魘，使得鞍轡可以被穿戴於其上。沒有夢魘會自願接受這強迫奴役，但其中一些最終會對它們的主人建立了強烈的忠誠，併成為了真正的邪惡夥伴。
