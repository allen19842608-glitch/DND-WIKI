# 臃腫魔

**臃腫魔 Nupperibo**

九獄不會拒絕任何靈魂，但那些真正沒有價值的靈魂——那些活著時所做的惡行主要是由於粗心和懶惰的靈魂——只適合成為臃腫魔。這些可悲的生物在各種地方蹣跚遊蕩著，只有在環繞它們的害蟲之云為它們找到一個可供摧毀的目標，或是更高階的邪魔強行命令它們時才會有目的地行動。
單個的臃腫魔是弱小的，但它們很少獨自出現，而當聚集成群時便非常危險。蜇人的昆蟲、蚊蝠（見《怪物圖鑑》）以及其他害蟲組成的雲團環繞在它們周圍，形成一股折磨任何靠近的非魔鬼生物的可怖的、升騰的外殼。
臃腫魔的唯一念頭就是摧毀一切非邪魔生物。一旦一個臃腫魔的害蟲之雲察覺到一塊可能被吃到的肉食，任何附近的臃腫魔都會不眠不休地追逐這個獵物，直到獵物或者臃腫魔有一方被殺死，或者有其他潛在的受害者擋在這些魔鬼的路上，阻撓了它們。
臃腫魔不假思索地服從任何以心靈感應從其他魔鬼處接收到的命令。這盲目的忠誠讓它們成為了最容易被投入戰鬥中的煉獄士兵，但它們在軍團中的存在對提升軍團將軍的地位可沒什麼幫助。

## 臃腫魔 Nupperibo

_中型邪魔（魔鬼），普遍守序邪惡_

**護甲等級**：13（天生護甲）

**生命值**：11（2d8+2）

**速度**：20尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 16 | +3 |
| 敏捷 | 11 | +0 |
| 體質 | 13 | +1 |
| 智力 | 3 | -4 |
| 感知 | 8 | -1 |
| 魅力 | 1 | -5 |

**技能**：察覺+1

**傷害抗性**：強酸，寒冷

**傷害免疫**：火焰，毒素

**狀態免疫**：目盲，魅惑，恐慌，中毒

**感官**：盲視20尺（超出此範圍則目盲），被動察覺11

**語言**：理解煉獄語但不會說

**挑戰等級**：1/2（100XP） 熟練加值 +2

**害蟲之雲 Cloud of Vermin。**除魔鬼以外，任何生物在一個或更多臃腫魔的20尺內開始其回合時，必須成功通過一個 DC11的體質豁免，否則承受5（2d4）點強酸傷害。在兩個或更多臃腫魔的蟲群區域內的生物在進行此豁免時承受劣勢。

**驅使追蹤 Driven Tracker。**在九獄內，臃腫魔可以毫無誤差地追蹤任何在此前的24小時內曾經因任何臃腫魔的害蟲之雲而承受傷害的生物。
### 動作 Actions

**啃咬 Bite。**近戰武器攻擊：命中+5，觸及5尺，單一目標。命中：6（1d6+3）點穿刺傷害。
