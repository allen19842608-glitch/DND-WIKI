巨龍英豪

**巨龍英豪 Heroes of the Dragon**

　　並非只有從巨龍血脈中獲得魔法的術士，與龍獸同行的遊俠，以及習練巨龍之道的武僧才是傳承了巨龍之力並獲得技能、法術與職業特性的冒險者。任何職業的角色都可以與龍族有密切聯繫。龍類角色紐帶表提供了一些點子，您可以從中找點靈感，為您的角色來點龍味兒。每個條目末尾括號中標註的職業尤其適合於該紐帶，但您也完全可以自由發揮。

**龍類角色紐帶**

| **d10** | **龍類紐帶** |
| --- | --- |
| **1** | 我崇敬，並從龍神處汲取力量最有可能的是巴哈姆特與提亞馬特，但也有可能是薩迪沃或其他具備高度實力的巨龍，如阿絲特萊雅，阿莎德隆或庫若尼普斯。（牧師、聖武士、魔契師） |
| **2** | 我崇敬或被某個龍類精魂所寄宿著，就如同自然或先祖之魂一般。（野蠻人、德魯伊、遊俠） |
| **3** | 我是某個傳承巨龍師祖教誨的教團之一員。（戰士、武僧、聖武士、法師） |
| **4** | 我有一位巨龍導師或宗主。（吟遊詩人、德魯伊、戰士、遊蕩者、術士、魔契師） |
| **5** | 我使用我的職業特性時會表現出某些龍類特徵。（野蠻人、術士） |
| **6** | 我擁有一件龍牙、龍角、龍爪或龍鱗，並用它們作為我的法器（牧師、德魯伊、聖武士、遊俠、術士、魔契師、法師） |
| **7** | 某位巨龍先祖，或給予我先祖的巨龍賦禮，讓我獲得了力量。（野蠻人、戰士、術士） |
| **8** | 我與自然的連結讓我與某條龍建立了奇異的鏈接，因其存在改變了周遭自然環境的結構。（德魯伊、遊俠） |
| **9** | 我最近發現我某位所愛之人或所信之人的真身是頭巨龍。（任意） |
| **10** | 我從巨龍的寶庫中偷得了某件看似平平無奇的玩意兒，但當我把它帶在身上時就會發生不可思議的事情。（任意） |
