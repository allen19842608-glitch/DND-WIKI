# 龍的繁殖

**龍的繁殖 Reproduction**

_龍就像蜥蜴。它們存在於人類存在之前，並將存在於人類消亡之後，它們可以重塑現實的結構，他們超越了自然的__法則！哦等等……不是像蜥蜴。對，對！是像魔法一樣。_

_——費資本_

在諸多物質位面的世界中，龍的繁殖也因世界不同而具有諸多差異，並且甚至會因所涉及的龍的家族、種類或個體性質而產生進一步的不同。長期以來，研究龍的人類學者一直認為它們的生殖方式類似於普通的爬行動物——即，兩條不同性別的龍交配併產生一窩蛋。許多世界中的龍都大多如此，然而龍的繁殖涵蓋了其他更加廣泛的可能性。你可以從使用龍蛋起源表中選擇一種方式用於你的世界中的龍的繁殖，或是作為特定的某窩龍蛋的起源，亦或是介於二者之間。

**龍蛋起源**

| **D10** | **起源** |
| --- | --- |
| **1** | **自發轉世 Spontaneous** **Reincarnation。**當一條成年或更老的龍死亡時，龍逐漸解體的屍骸中會形成一個或更多的蛋。這些蛋可能會如真菌般在屍體腐爛時生長而出，也可能出現在消逝於烈火中的屍體所留下的餘燼中，亦或是需要從已經變成堅石或金屬的龍骸中開採出來。 |
| **2** | **初世之苗 Seedlings of the First World****。**在世界的中心（地下，或遠離文明的原始曠野）矗立著一棵樹，龍蛋像果實一樣在上面生長。每條龍一生中都會有一次壓倒性的衝動，去尋找這棵樹。在找到它之後，龍必須說服聖樹守護者賜予它一個或更多的蛋。 |
| **3** | **吞噬寶物 Consuming** **Treasure。**龍吃掉其寶庫相當重要的一部分，以此令自己產下一窩蛋。 |
| **4** | **秘法傑作 Magical Crafting。**與巴哈姆特和提亞馬特創造龍相似，龍通過複雜而精巧的儀式製出龍蛋，併為其注入生命。 |
| **5** | **龍脈轉化 Draconic** **Transformation。**蒙受啟示的非龍類（大多是類人生物）會在迎接死亡、完全醒悟，或是經歷也許會涉及龍血沐浴或被龍吞噬的儀式之後，就會被轉化為龍蛋。類人生物和龍類都將這種轉變視為向更高級的存在形式的過渡。 |
| **6** | **神造起源 Divine** **Origin。**只有巴哈姆特和提亞馬特能創造龍蛋——每顆龍蛋都是神聖干預的結果。 |
| **7** | **自發形成 Spontaneous** **Forming。**龍蛋會在某些地區自然生成，對於金屬龍和寶石龍來說，通常是在金屬礦或寶石礦的地下礦脈中，對於色彩龍來說則是在極端環境（如火山、凍原、沼澤等）中。龍蛋也許會自行孵化，或者必須先由其他生物挖掘出來，無論是由成年或更老的龍還是某個倒霉的礦工。 |
| **8** | **孤雌生殖 Parthenogenesis。**只要覺得已經做好了飼養雛龍的準備，一個成年或更老的龍就可以自行產下一窩蛋——或是把撫養的責任交給其他龍。 |
| **9** | **龍類誓約 Dragon** **Conclave。**五條不同種類的成年或更老的龍聚集在一起創造一窩龍蛋，參與儀式的每條龍都將獻出一些生命能量。這窩龍蛋將孵化出五條不同種類的龍，這取決於組成誓約的龍。 |
| **10** | **龍類復生 Rejuvenation。**遠古龍自願深入出神直至死亡，並留下一顆龍蛋。 |

龍蛋誕生之後，必須在適宜的環境下才能孵化成雛龍。通常情況下，龍蛋只能在適合對應種族龍類的環境中成長——紅龍或金龍在熔岩中，白龍或銀龍在冰中，黑龍或綠龍在腐殖質中，黃銅龍或藍龍在暴曬中的沙裡，青銅龍或赤銅龍則在海蝕洞穴或荒涼的荒地上。寶石龍蛋通常需要在納入岩石或小型洞穴中孵化。無論是哪種龍蛋，其孵化期可能從六個月到數十年不等，也可能更長。
