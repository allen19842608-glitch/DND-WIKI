# 龍的遭遇

**龍的遭遇 Dragon Encounters**

_通常情況下，一條看起來很生氣的龍實際上只是餓了。雖然對那些觀察的生物而言結果是一樣的，但我認為真的有必要澄清一下動機。_

——費資本

無論你是圍繞著龍來設計整個冒險，還是隻想把一條有趣而且有個性的龍扔到隊伍的路上，你都要在遭遇戰中把龍的作用發揮到最好，首先要回答這四個問題。

**遭遇是一個目標還是一個障礙？**龍（尤其是成年和更老的龍）適合作為冒險中的高潮遭遇，而屠龍正是各類文學作品和神話傳說中老生常談的經典話題。但你也可以把龍作為冒險中眾多遭遇中的一個來克服。

**遭遇的目標是什麼？**並非每次與龍相遇都需要戰鬥，更不用生死搏鬥了。也許角色們正試圖幫助一個負責飼養小龍的狗頭人找回被一幫地精綁架的雛龍（如冒險**暗無天日**中，本篇模組收錄於**《哈欠之門故事集》**中）。在這種情況下，如果龍不願意回來，戰鬥可能是不可避免的，但同樣也不能殺死這個生物。另一種情況則是，角色們嚴重不敵巨龍，它們唯一的目標就是活著逃離這次遭遇。

**遭遇是在龍的巢穴中嗎？**在龍的巢穴中戰鬥更有可能意味著一場生死之戰，因為龍可能不會在這樣的遭遇中逃跑——它們更傾向於與那些在闖入龍巢後逃跑的冒險者決一死戰。這種情況也意味著成年或更老的龍有機會使用巢穴動作。此外，在開闊外界作戰的龍可以更容易地飛離地上敵人的觸及範圍。第四章和第五章提供了幫助你在龍的巢穴及其周圍建立遭遇的信息和地圖。

**獨自一龍還是手下眾多？**依靠傳奇動作，哪怕僅僅是一隻的成年龍和遠古龍也可以成為一次很有挑戰性的遭遇，但即使是那些作為一個單獨敵人的年輕的龍也是很棘手的。另一方面，在龍類遭遇中加入手下可以將角色的注意力從龍身上轉移開來，使戰鬥遭遇更加有趣，也更加危險。關於龍和其手下之間的關係如何影響一場遭遇戰，請參見本章前面的 **"龍的手下 Followers"**。

考慮完這四個問題，你還可以從**龍類遭遇雜項**表中找到一些鬼點子、特殊效果和異常情況，以使任何龍的遭遇更加有趣和刺激。

**龍類遭遇雜項**

| **d20** | **雜項** |
| --- | --- |
| **1** | 龍對戰鬥沒有興趣，並試圖避開角色們，直到他們因明顯的傷害或侮辱激怒了對方。 |
| **2** | 龍認為戰鬥太無聊了，不願意與角色們交手，如果他們離開，甚至還會給他們少量的財寶。 |
| **3** | 龍討厭某種類型的角色（可能是詭詐的遊蕩者、治療者或重甲戰士），每輪至少會對這種角色進行一次攻擊。 |
| **4** | 龍試圖通過情感上的傷害或羞辱來趕走這些角色——威脅他們明顯關心的東西，破壞他們的裝備，侮辱他們，或者顯示他們的攻擊是多麼的無效。 |
| **5** | 龍在巢穴深處有一個緊急呼救裝置；比如一個召喚手下的魔法號角，一個裡面封印著強大惡魔的道具，或者一個通往其迴響之巢穴的傳送門。角色必須阻止龍請求增援，否則將面臨新的威脅。 |
| **6** | 龍正在拼命地保護一個特定的寶物，一個或多個蛋，或者可能是一個爪牙，為保護這個寶物而討價還價，如果它受到傷害就會暴跳如雷。 |
| **7** | 龍的巢穴的前主人留下了一個詛咒、一個陷阱或一個揮之不去的靈魂，聰明的人物可以將其與龍對抗。 |
| **8** | 如果不能使用龍的某些特殊移動方式（通常是飛行，但也可能是掘穴、游泳或攀爬），幾乎不可能在龍的巢穴內自由出入。 |
| **9** | 已經很久沒有人敢於闖入龍的巢穴了，比起對人物造成嚴重傷害，龍更喜歡炫耀它的巢穴和令人印象深刻的巢穴動作。如果角色們逃了出來，並將龍的威名傳開，那就更好了。 |
| **10** | 當龍被激怒時，改變巢穴周圍地形的區域效應每輪都會在龍周圍產生明顯的變化。 |
| **11** | 當人物挑戰龍時，龍的僕從中派系的積怨就會爆發，導致內訌，可能會使戰局向任何一個方向傾斜。 |
| **12** | 龍的巢穴中的一個特徵具有不可預知的魔法效果，也許類似於**驚異魔杖 Wand** **of** **Wonder**、術士的**狂野魔法**，或者**《城主指南》**中描述的地城**唬人把戲 Tricks**。除非戰局不順，龍會傾向於避開這個特徵，然後要麼激活這個特徵，要麼試圖誘使角色這麼做。 |
| **13** | 在龍的巢穴內使用的法術效果和吐息武器會造成戲劇性的破壞，包括裂縫蔓延、天花板坍塌、柱子倒塌，以及其他能對角色和龍造成同樣傷害或阻礙的效果。 |
| **14** | 龍有一個對手，他注意到角色們接近了龍的巢穴，並從暗處觀察著這場戰鬥。這個對手可能會根據情況介入，幫助角色或龍，也可能在角色離開龍的巢穴時伏擊他們。 |
| **15** | 龍非常積極的偽裝成類人生物並聲稱自己是自己的奴僕，當入侵者進入巢穴時，龍會卑躬屈膝的聲稱自己的主龍不在。 |
| **16** | 龍戰鬥的唯一目的是瞭解角色們的某些關鍵信息然後逃跑，但它還有更大的目標。 |
| **17** | 龍喜歡戰鬥，每當人物發動有效的攻擊或華麗的法術時，它就會發出讚賞的吼聲。但如果受到嚴重傷害，龍會迅速投降並要求停火。 |
| **18** | 在與龍的每一輪戰鬥中，角色們都會看到另一個世界的陰森恐怖的一瞥，那裡有龍的一個迴響在活動。 |
| **19** | 龍有一個在受到攻擊時詐死的計劃——諸如是被埋在坍塌的洞穴裡、墜入深淵、淹沒在熔岩中，或者一些類似的戲劇性的假死逃脫手段。在逃脫之後，龍會謀劃復仇。 |
| **20** | 在人物與龍對峙的同時，另一群冒險者正在另一個世界與龍的一個迴響交戰。在戰鬥進行到一半的時候，龍或者角色和其他冒險者就會互換位置。 |
