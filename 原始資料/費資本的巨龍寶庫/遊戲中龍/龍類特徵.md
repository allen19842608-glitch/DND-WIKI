# 龍類特徵

**龍類特徵 Dragon Characters**

《城主指南》一書中含有一系列旨在幫助你製作 NPC 的表格和指南。而本節介紹了這些表格的替代方案，幫助你將一條龍從一張資料卡和簡述轉變為冒險中的一個有血有肉的角色。

在本書的第5章中，你可以找到為各種龍定製的性格特徵與理想的附加表格。

**龍類的外貌**

| **D20** | **外貌** |
| --- | --- |
| **1** | 刻著在位置顯著的鱗片上的龍語單詞或符號 |
| **2** | 巨大的疤痕 |
| **3** | 一隻眼睛缺失或呈乳白色 |
| **4** | 彎曲的牙齒 |
| **5** | 明顯的超重或瘦削 |
| **6** | 修長的、蜿蜒的身體 |
| **7** | 短小、粗壯的身體 |
| **8** | 嵌入鱗片的錢幣或寶石 |
| **9** | 雕刻過的角或爪子 |
| **10** | 鰭或翅膀邊緣穿透著金屬環 |
| **11** | 披著某種形式的衣服，從披肩到長袍。 |
| **12** | 不尋常的顏色（例如橙色、棕色或紫色的紅龍）。 |
| **13** | 低伏下身，像貓一樣的獵食姿態 |
| **14** | 直立的、幾乎兩足步行的姿態 |
| **15** | 鱗片上有僕從、崇拜者或雛龍的爪印圖案 |
| **16** | 用敵人的骨頭、角、爪子或牙齒做成的項鍊 |
| **17** | 額外的角或刺 |
| **18** | 長長的、像獠牙一樣的牙齒，或額外的一排牙齒 |
| **19** | 尖銳的或鋸齒狀的鱗片 |
| **20** | 與龍的吐息武器相對應的元素能量從鱗片之間滲出 |

**龍類習慣**

| **D20** | **習慣** |
| --- | --- |
| **1** | 我在傾聽或說話時，頭部會不斷左右晃動 |
| **2** | 我的尾巴像蛇一樣不斷蠕動 |
| **3** | 我緩慢而持續地扇動翅膀 |
| **4** | 我在說話時慣於俯下身子與小個子種族平視——除非我生氣了。 |
| **5** | 我即使在說其他語言時，也會夾雜一些龍語的詞彙和短語 |
| **6** | 我用獸嘶作為講話的標點——咆哮、吼叫、呼嚕聲、鳴叫或口哨聲 |
| **7** | 我常常擺弄尾巴尖 |
| **8** | 我心不在焉地咀嚼劍、矛、長槍或用它們剔牙 |
| **9** | 我總會迅速忘記其他人名字，並隨意的編造綽號。 |
| **10** | 我在談話中經常引經據典，儘管很多時候完全不相干。 |
| **11** | 我不斷地晃動尾巴——偶爾會撲向它 |
| **12** | 我說一種古老的通用語（相當於文言文），不理解當代的俚語和習語。 |
| **13** | 我常常發出可怕的、陰陽怪氣的聲音，這實際上是笑聲 |
| **14** | 我喜歡模仿類人生物的聲音 |
| **15** | 我將現代文化視為歷史奇觀，並認為它們很快就會崩潰。 |
| **16** | 我難以辨別像類人生物那樣小個子生物的細節 |
| **17** | 我常在身邊的石頭表面上磨利爪子或角 |
| **18** | 我會表現出吐息武器的小跡象，如吐出黑煙，齒間電光閃爍，或吹出酸性飛沫 |
| **19** | 我不停地嘆氣，給人以極度無聊的印象。 |
| **20** | 我疑心極重，把所有遇到的類人生物都視為敵對龍的潛在代理人 |

**龍類牽絆**

| **D****1****0** | **牽絆** |
| --- | --- |
| **1** | 我的寶庫中珍藏著一件特別的事物——那是我所愛的人送給我的禮物，但對方早已去世。 |
| **2** | 我深愛著我的兄弟姐妹，他們的巢穴就在附近。我會不惜一切代價保護它們，或者為它們報仇。 |
| **3** | 附近的某個人用誘人的謎題和奇異的想法吸引著我。 |
| **4** | 我收集關於物質位面中諸多世界的信息，並希望有一天能訪問另一個世界。 |
| **5** | 我獻身於巴哈姆特或提亞馬特，把祂們的利益放在我自己的利益之上。 |
| **6** | 我決心毀滅那些殺害我父母的冒險者——以及所有與它們有關的人。 |
| **7** | 我痴迷於吸引另一條龍的注意。 |
| **8** | 我覺得有義務保護居住在我的領地上的生物（除了好吃的那些）。 |
| **9** | 我正在努力收集一套極其罕見的無價之寶。 |
| **10** | 在我找回從寶庫中被偷走的物品前，我不會休息。 |

**龍類缺陷和秘密**

| **D10** | **缺陷和秘密** |
| --- | --- |
| **1** | 我覺得冒險者很可怕，我感覺有一天我會在他們手中遭遇滅頂之災。 |
| **2** | 我寶庫中一件東西的價值相當於我其他所有寶藏之和，而擔心它失竊的恐懼無時無刻不在侵擾我。 |
| **3** | 只要有機會，我就會一口氣吃到撐，然後陷入漫長的沉眠。 |
| **4** | 比起和入侵者戰鬥，我寧願讓我可怕的名聲嚇跑他們。 |
| **5** | 如果其他龍知道我多麼喜歡那些小個子僕從，他們肯定會嘲笑我。但它們真的太可愛了! |
| **6** | 我很害怕來自外層位面的生物，尤其是**魔冢 modrons**。 |
| **7** | 另一條龍已經發誓要找到並宰了我。 |
| **8** | 人類還沒有準備好去了解我收藏書籍中可怕的宇宙真理。 |
| **9** | 再活幾個世紀的前景讓我筋疲力盡。 |
| **10** | 我確信，在繁多主物質位面中的另一個世界裡，另一個我正謀劃摧毀我並奪走我的寶藏。 |
