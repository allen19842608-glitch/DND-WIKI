# 雕皮之龍

**雕皮之龍 Hidecarved Dragons**

在物質位面中，龍經常會形成一種由三到五條龍組成的小型結社，這被稱為**密約 lauths**。這些龍分享的領地和寶藏，在嚴格的紀律與守則下生活，併為一個共同的目標奉獻自己。它們最顯著的特點是在鱗片上刻下具有保護效果的秘法印記。

**共同目標 Common** **Purpose。**當龍確定了一個共同的目標，而這個目標的完成需要一群不同的龍的持續努力時，它們經常就會形成一個密約集會。密約目標表提供了一些例子。

**密約目標**

| **d6** | **目標** |
| --- | --- |
| **1** | 支持建立一個強大的帝國，以維護密約領土的秩序。 |
| **2** | 使一個強大帝國覆滅 |
| **3** | 結束源自幽暗地域中的異怪的影響 |
| **4** | 尋找並摧毀由某個古老法師製造的數百件被詛咒的魔法物品 |
| **5** | 摧毀一個大惡魔、一個惡魔主君、一個強大的天族或一個至高妖精，他們的影響改變了密約成員們的領地。 |
| **6** | 實現（或阻止）幾百年前由一條遠古龍做出的預言。 |

**多樣的龍 Diverse** **Dragons。**雕皮之龍的密約團體有著共同的目標，但往往沒有什麼其他共同點。設計上，每個成員通常是不同類型的龍，為團體的目標帶來獨特的能力和觀點。同樣地，這樣一個團體往往涵蓋了不同的年齡段的龍，以確保該團體的傳統比其最年長的成員更長久。

**鐫刻護咒 Engraved** **Wards。**雕刻在龍的鱗片上的秘法印記能為它的主人提供一定的保護，它們使龍在執行密約任務時更能抵禦可能面臨的威脅。龍加入密約的時間越長，它們得到的保護就越多。大多數作雕皮之龍都有一個這樣的護咒，每比雛龍高出一個年齡層，即可再加上一個額外的條目。你可以在密約護咒表上擲骰或者按照你的意願決定具體效果。

**密約護咒**

| **d6** | **符文效果** |
| --- | --- |
| **1** | **不變形態 Immutability。**龍免疫任何會改變其形態的法術或魔法效應。 |
| **2** | **精神壁壘 Inscrutability。**龍免疫任何能感知其情感或讀取它的思想的效應。為確定其意圖或辨別言辭真偽的智力（洞悉）檢定具有劣勢。 |
| **3** | **魔法抗性 Magic** **Resistance。**龍在面對法術和其他魔法效果時，有優勢。 |
| **4** | **傷害抗性 Damage** **Resistance。**龍對來自非魔法攻擊的鈍擊、揮砍、穿刺的傷害具有抗性。 |
| **5** | **額外抗性 Additional** **Resistance。**龍對一種類型的傷害有抗性。擲一個 D8，如果你得到一個龍已經具有抗性或免疫的傷害類型，則重新擲。1，強酸；2，寒冷；3，火焰；4，閃電；5，暗蝕：6，心靈；7，光耀；8，雷鳴。 |
| **6** | **防死結界 Death** **Ward。**龍可以對自己施放一次**防死結界 death ward**並在完成一次長休後恢復施放的能力。 |

**神話徽記 Mystic** **Markings。**如同龍巫妖一樣，鐫刻在雕皮之龍鱗片上的符號會對位於其他物質位面中的迴響產生影響。當一條龍加入了一個密約團體，其他世界上的迴響就會從龍的符文徽記中獲得一定程度的魔法保護。一些迴響接受了這一莫名其妙的恩惠，而沒有質疑或是對它產生好奇。而有些則嘗試刨根問底，最終可能會喚醒它們的龍視，發掘影響自身的龍的本質——也許最終會與其他處於類似情況的龍一起建立自己的密約。

**冒險引子 Adventure** **Hooks。**雕皮之龍冒險引子表提供了關於這個龍類組織如何捲入冒險者事務的建議。

**雕皮之龍冒險引子**

| **D6** | **冒險引子** |
| --- | --- |
| **1** | 一條雕皮之龍為了完成密約的目標僱傭了角色們去執行任務。 |
| **2** | 密約認定，為了達成目標，需要消滅角色們。 |
| **3** | 密約給予了角色們意料之外的幫助，因為它們的任務密約的目標相一致。 |
| **4** | 密約處處阻撓角色們的任務，因為它們的任務與密約的目標背道而馳。 |
| **5** | 某地報道有一條危險的龍在附近遊蕩，前去調查的角色們發現這條龍是密約的成員，而其目標值得支援。 |
| **6** | 一條龍要求角色們幫助自己搞清楚自己鱗片為何會突然出現秘法印記。要解決這個難題可能意味著他們不得不前往另一個世界，或者找到一種方法來幫助喚醒龍的龍視。 |
