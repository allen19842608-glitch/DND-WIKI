# 歸一者

**歸一者 Inheritors of the First World**

“歌之以息，巨龍之嗣:汝當繼承龍神的偉業 君臨往昔第一世界——儘管它已是破碎過往。"對某些龍來說，《第一世界的輓歌》的結尾不僅僅是指示他們統治主物質位面，更是對重建龍神的原初世界的呼籲。一個名為"歸一者”的末日教派的龍類成員相信，摧毀了原初造物並造成物質界無數個世界的大災變可以逆轉的。事實上，它們教導說，物質位面諸界必須被摧毀並重新融合，這樣才能使這宏偉造物完成其最終的、光榮的使命。

歸一者們的目標可能看起來遙不可及；至少，實現它幾乎肯定需要巴哈姆特和提亞馬特的干預。但他們會受到無數與主物質位面聯繫緊密的神的反對，而且自從第一世界毀滅之前，這兩條原初之龍就沒有為一個共同的目的合作過。儘管如此，歸一者們對主物質位面的多個世界、各位面間的聯繫以及從一個世界到另一個世界的旅行方法都非常瞭解。

**覺醒龍視 Awakening** **Dragonsight。**歸一者們的主要工作是發展龍視——一種所有龍類都具備的一種潛能。教派的領導人已經完善了多種技術——從鍊金藥劑到精心設計的儀式——以幫助激發龍對其他世界的迴響的模糊感應。他們樂於幫助任何渴望激發這種與生俱來潛能的龍，並會毫不吝惜的實施這些技術，他們相信，即使獲得龍視能力的龍無意加入教派，最終結果也是有助於推動自己的事業。某些決定加入這個組織的龍對自己的多個迴響有了基本的認識，並在加入教派時開始與它們直接交流，其過程類似於清醒夢。

任何能夠熟練使用龍視的龍，尤其是那些歸一者的成員，都可以擁有以下特質，代表它們有能力在整個物質位面調用其回聲所具有的知識。

**龍視啟明 Dragonsight Revelation。** 龍能將其熟練加值的一半（向下取整）加入到任何其進行的沒有熟練的使用技能的屬性檢定中。

**崇敬薩迪沃 Reverence** **for** **Sardior****。**歸一者們的一個核心信條是，復生的薩迪沃最終將促使巴哈姆特和提亞馬特再次聯手，迴歸創世的使命。教團的許多成員都是寶石龍，它們相信薩迪沃破碎的意識潛藏在自己的心智中，並努力培養其他寶石龍的龍視。此外，即使是五色龍和金屬龍中也有不少成員敬拜早已死去的硃紅之龍。薩迪沃是他們曾經的和未來的君主——k 只是暫時離開，但終將回歸，為龍族帶來啟迪、撫慰和拯救。

**冒險引子 Adventure** **Hooks。**歸一者冒險引子表為角色如何參與這個末日教派提供了建議。

**歸一者冒險引子**

| **d6** | **冒險引子** |
| --- | --- |
| **1** | 一個逃跑的敵人消失在一個與諸多主物質位面中另一個世界相連的傳送門。當角色們追擊敵人來到了另一個世界時，他們引起了龍的注意，龍想更多地瞭解他們原來所在的世界。 |
| **2** | 寶石龍的巢穴原來是一個魔法性的節點，包含了與其他幾個世界的龍的迴響巢穴相連的門戶。 |
| **3** | 角色們在幽暗地域深處發現了一顆極為龐巨的紅寶石。當他們的發現被傳開後，這顆寶石成為了不少盜賊的目標，並最終引起了龍的注意，他們認為這是薩迪沃的心臟，是硃紅之龍迴歸的關鍵。 |
| **4** | 一條龍僱傭角色們前往另一個世界，並承諾給他們豐厚的報酬。在那裡，他們必須與龍的迴響取得聯繫，並弄清楚為什麼它們的僱主無法覺醒龍視。 |
| **5** | 巴哈姆特的祭司或龍的僕人派角色們去對抗歸一者，它們擔心這個組織恢復巴哈姆特和提亞馬特原始創造的嘗試會激怒諸神，重新點燃龍和類人生物之間的戰火。 |
| **6** | 龍建立了一個連接物質界兩個世界的永久傳送門。這一奇觀引發了一個令人興奮的地理大發現和貿易時代。但隨著時間流逝，傳送門不斷擴張，變得越來越大，似乎要把兩個世界拉到一起，發生災難性的碰撞。 |
