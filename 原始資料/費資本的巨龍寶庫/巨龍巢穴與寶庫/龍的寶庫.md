龍的寶庫

囤積財寶是龍的天性。這並不是說龍是絕對貪婪的，儘管有些龍就像其他人理解的那樣——確實如此。它們也不是像喜鵲那樣被閃閃發光的物體所吸引。相反，寶庫是龍內在魔法本質的延伸——聚集它們的魔力，並將它們與物質位面的魔力聯繫起來的共鳴器。

**_一條遠古龍巢穴中的寶藏之富饒，足以令王朝興起和傾復_**

**年齡、寶庫和力量**
龍輕敲充盈著物質位面的魔法能量，而這種能量被他們擁有的物質事物放大。實際上，這意味著龍的力量同時與年齡和它們寶庫的大小有關，而聰明的龍以及潛在的屠龍者可以利用這一點。

**雛龍**
雛龍在會飛的時候就開始收集財寶，但它們的行動範圍很小，不太可能收集超過幾百枚金幣價值的財寶和一些魔法物品。如果與其他雛龍或成年龍共享一個巢穴，雛龍會將他們的寶藏藏在巢穴中自己獨有的部分。此外，它們也會把財寶藏在睡覺的地方附近。

**青年龍**
當龍從雛龍變為青年大約是在 5歲左右的時候，他們也開始尋找他們的第一個永久巢穴，並積累更多的財寶，這些財寶的價值會增長到數千枚金幣。青年龍把它們的寶庫藏在睡覺的中心位置。這些龍通常還不能造成區域效應，但這些效應可能會隨著龍與巢穴的聯繫發展而開始顯現。你可以給青年龍添加區域效應，甚至是巢穴動作，特別是那些擁有非凡大寶庫的龍。這些龍可能還沒有大到足以完全達到一條成年龍的力量，但收集出這樣的一個寶庫使它們比其他年齡相近的龍更強大。

**成年龍**
龍的成年期由兩個里程碑來衡量 :一個世紀的生命和價值約1.5萬金幣或更多的寶庫。如此大小的寶藏將龍、巢穴和領地捆綁在一起，形成一體的魔法能量，使龍成為真正的傳奇，賦予龍的傳奇動作和巢穴動作，並以區域效應在整個地區傳播龍的影響力。
隨著龍的年齡和寶庫的增長，他們傾向於建立多個巢穴。這在一定程度上是為了降低風險——如果寶藏分散在多個地點，那麼龍在一次盜竊中失去全部寶藏的幾率就會降低——也在一定程度上是為了將龍的魔法影響力擴展到不斷增長的領地上。儲藏在每個巢穴的寶藏將龍的力量錨定在那裡，即使龍不存在，擴大了區域效應的影響範圍。
龍通常會在它們的寶藏達到15000 金幣的倍數時建立新的藏寶處。在它們成年的歲月裡，每隻龍可以在遍佈大陸大部分地區的多個巢穴中建起6到8個藏寶處。

**遠古龍**
大約 800歲的時候，龍得到了遠古屬性，那時它們通常建起了8到10個藏寶處，總價值至少是20萬金幣。隨著時間的流逝，遠古龍繼續擴大他們的寶庫，藏寶處的數量和每個藏寶處的價值都在增加，直到他們的總價值超過100萬金幣。

**連接寶庫**
分割寶庫的龍通常從連接著的一套物品中分配一份或多份到每個藏寶處中。這種做法加強了分散寶庫之間的魔法聯繫，有助於維持龍對遠離其當前位置的寶庫部分的所有權，並將分散的寶庫統一為一個有效的寶庫。
這種連接可以為角色們增加有趣的目標，即讓角色們在尋找龍的藏寶處寶藏時收集一整套分散的寶藏。寶藏連接物品表提供了龍可能以這種方式使用的物品套裝的建議。理想情況下，玩家應該能夠在找到一個或兩個藏寶處後推斷出物品套裝的總數量，這樣他們就知道還需要收集多少道具。有時候，正確的數量是顯而易見的 (例如，象棋中的棋子數量或牌組中的紙牌數量)，但你可以考慮將最早發現的道具儲存在裝飾盒中，盒子的空白位置就可以表明缺失部分的數量。

**搶劫寶庫**
因為龍的力量與寶藏相連，所以可以通過搶劫龍的巢穴來削弱龍的力量。角色們通過去往寶庫並帶走大部分寶藏來削弱巨龍與巢穴及其相關領地的聯繫。
按照經驗來看，如果龍巢穴裡的寶藏不再具有至少 10000 gp 的價值，則該地點不再被視作一個巢穴。龍不能在那裡使用巢穴動作，巢穴周圍的區域效應也將會消失，如同龍已經死亡一樣。
這暗示了角色在對抗龍時可能會想到一個妙計：找到龍的一個較小的巢穴，洗劫那裡的寶藏，並迅速將其移走。移動寶藏不可避免地會引起巨龍的注意，因為無論是巨龍的部下還是巨龍與寶藏的魔法聯繫都會提醒巨龍注意入侵者。來調查被擾亂的巢穴的龍有反擊盜竊的強烈動機 ——為了防止損失更多寶藏。當龍意識到失去寶藏會讓自己變得脆弱時，可能為時已晚。
理論上來說，可以通過洗劫龍的全部寶庫來剝奪成年龍或者遠古龍的傳奇屬性。要做到這一點，龍必須被魔法束縛住，或者以其他方式阻止其干擾掠奪 ——但這種束縛可能比殺死一隻強大的傳奇龍更容易。

**寶庫異能**
龍的寶庫有與強大魔法物件相似的特徵，掠奪巨龍寶庫的行為會在寶庫主龍死後仍會有長久的影響。任何數量的超自然效應都可以留存在傳奇龍的寶庫中或其周圍，通常集中在一些珍貴的財寶中 ——例如最珍貴的寶石或藝術品，或最稀有的魔法物品。

**區域效應**
與傳奇龍巢穴相關的區域效應是通過巨龍的寶庫被引導到環境中。當寶藏被轉移到其他地方時，這些影響會在不同程度上持續存在，如下所示 :

**改變水質。**寶庫中的一件物品可以汙染或淨化它接觸到的任何水。

**改變天氣。**寶庫中的一件物品能吸引適合龍類的天氣。

**吸引動物。**小動物會不可抗拒地被寶庫中的物品所吸引，並不斷地試圖拿走它。

**巨龍之夢。**睡在巨龍寶藏附近的生物會夢見巨龍。

**個性轉變。**使用來自寶庫的物品的角色會發展出龍的性格特徵。

**尋求迴歸。**來自寶庫的智能物品想要返回龍的巢穴，並導致角色意外地誤入那個方向。

**翠綠干涉。**如果將來自寶庫的硬幣放入土壤中，它們會促進茂盛的植物生長

**作祟寶庫**
龍的寶庫中有一件或幾件物品鬧鬼是很正常的。陰魂不散的精魂可能會糾纏著對他們生命有特殊意義的物品，而偷走這些物品的龍的死亡可能是這些精魂最終找到安息的機會。精魂可以完全以幽 **魂 ghost、鬼魂 specter、邪靈 wrait**h 或類似生物的形式出現，也可以以把作祟物品變成智能魔法物品方式出現出現。
終結精魂最有效的方法就是完成那些讓精魂與塵世相連的未竟事業。在作祟寶庫中，你可以使用未竟的事業表來幫助你決定它可能是什麼。

| **d6** | **未竟的事業** |
| --- | --- |
| **1** | 把作祟物品託付給鬼魂的繼承人 |
| **2** | 把作祟物品和精魂的屍體一同埋葬 |
| **3** | 將作祟物品用於特定目的 |
| **4** | 摧毀作祟物品 |
| **5** | 將作祟物品與其他部件還原成一套 |
| **6** | 消滅殺死精魂的兇手：身為寶庫主龍在另一個世界的迴響的另一條龍 |

**龍的詛咒**
一條龍的暴死有時會使寶庫揹負長久的詛咒。一條垂死的巨龍可能會對任何搶奪巨龍寶藏的人發出的魔法誓言，或者一條活著的巨龍可能會銘刻可怕的警告：掠奪巨龍寶藏的人將會被邪惡的魔法汙染。這種詛咒通常不僅影響那些從寶藏中偷東西的人，也影響任何接觸到寶藏的人。此外，打破詛咒通常是可能的，但是隻有當所有的寶藏重新集中於一處時才行。
使用寶庫詛咒效果表來給龍的長久詛咒的可能效果帶來靈感。

| **d6** | **寶庫詛咒效果** |
| --- | --- |
| **1** | 每個受影響的生物獲得1級力竭，直到詛咒解除後才能移除。 |
| **2** | 每個受影響的生物都會在對龍的吐息武器和駭人威儀的豁免檢定中自動失效。 |
| **3** | 每個受影響的生物獲得對詛咒了寶庫的龍的呼吸武器的傷害類型的易傷。 |
| **4** | 每個受影響生物的速度降低10英尺。 |
| **5** | 受影響的生物不能在短休期間花費生命骰來恢復生命值。 |
| **6** | 受影響的生物死亡時，被殺死的龍的靈魂將他的靈魂囚禁，阻止該生物從死亡中復活 |

一般來說，終止龍的寶藏上的詛咒並不像施展一道法術那麼簡單。然而，魔法可以提供暫時的緩解。對受影響的角色施放法術 _移除詛咒 remove curse_會抑制詛咒效果1小時，而法術_高等復原術 greater restoration_則會將詛咒效果抑制到受影響的角色完成一次長休為止。
將所有寶藏送回龍的巢穴可以終止詛咒，但帶走哪怕一枚硬幣也會再次激活詛咒。除了放棄寶藏這一極端手段以外，將所有寶藏聚集在一起，並進行一些特定的儀式，就可以結束詛咒。這樣的儀式可能包含寶庫詛咒表中建議的任何或所有元素。

**打破寶庫詛咒**

| **d4** | **連接道具** |
| --- | --- |
| **1** | 施展法術聖居 hallow |
| **2** | 參與屠龍者（或那些生物的近親）獻出鮮血 |
| **3** | 用龍血沐浴或灑在寶藏上 |
| **4** | 向巴哈姆特、提亞馬特或同時向兩者獻祭 |

另一種繞過寶庫的巨龍詛咒的方法是讓寶藏成為另一個龍的寶庫的一部分，這樣的話之前的擁有者的詛咒就會失效。聰明的冒險者可能會與友好的龍進行交易，用被詛咒的財寶交換同等數量(但可能更少)的財寶。

**爭奪寶庫**
神秘的邪教、隱居的學者、敵對的冒險者和秘密組織可能會尋找龍的寶藏，要麼試圖從龍那裡得到它，要麼試圖從殺死龍的角色那裡得到它。除了貪婪以外，這類團體還可能有許多尋找龍的寶藏的動機。這類團體一般是利用龍的寶藏的魔法來舉行一些偉大的儀式。寶庫魔法表提供了一些可能性。
