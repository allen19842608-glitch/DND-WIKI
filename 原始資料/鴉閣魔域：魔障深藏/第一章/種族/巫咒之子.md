# 巫咒之子

巫咒之子是因詭異能量或神秘巫術而被注入了妖精魔法的個體。許多巫咒之子是在與強大的鬼婆達成交易後轉化而成，但其他的奇異能量同樣可能導致巫咒之子的誕生。巫咒之子的奇異妖精力量體現在他們的神秘預知能力和魅惑魔法。

**巫咒之子特質 Hexblood Traits**
**生物類型：**妖精
**體型：**中型（約4-7尺高）或小型（約2-4尺高），在選取該種族時選擇
**速度：** 30尺

作為巫咒之子，你擁有以下特殊特質。
**黑暗視覺 Darkvision。** 你具有60尺黑暗視覺。
**神秘信物 Eerie Token。** 你能以附贈動作無害地剪下一縷頭髮，拔下一片指甲或其他方式，來創造一件魔法信物。信物存在期間，你獲得以下增益：

-   **遠程傳信 Distant Message。** 只要你位於信物的10裡內，你能以魔法動作向攜帶或持握該信物的生物傳遞一條不超過二十五個單詞的心靈感應信息。
    
-   **遙遠視野 Remote Viewing。** 若你位於信物的10裡內，你能以魔法動作將感官延伸至信物處，持續1分鐘，或在你解除該狀況（無需動作）或陷入失能狀態時提前結束。此狀況下，你能如同身處信物所在位置一樣看和聽。此狀況結束時，信物被無害地摧毀。
    

除非信物被提前摧毀，否則其存在持續至你完成長休。一旦你以此特性創造一件信物，直至你完成長休都無法再如此做。
**巫咒魔法 Hex Magic。**你始終準備著法術_易容術 Disguise Self_和_脆弱詛咒 Hex_ 。你可以無需法術位地施展每道法術各一次，當你完成長休時，你重獲以此法施展這些法術的能力。你也能夠以你擁有的合適環階的法術位施展這些法術。你的這些法術的施法屬性是感知、智力或魅力（在你選取該種族時選擇）。
