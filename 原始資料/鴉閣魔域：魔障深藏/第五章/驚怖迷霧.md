# 驚怖迷霧

迷霧中的無形追蹤者

**棲息地：** 任意；**寶藏：**無

將各個恐懼領域分隔開來的迷霧絕非安全之地——也絕不空曠。驚怖迷霧是活化的水汽雲團，在迷霧中幾乎無法被察覺。當有生物在場時，這些由蒸汽構成的恐怖存在會化作目擊者心中最深邃的恐懼之形。這種外貌是主觀的，任何看向驚怖迷霧的人，看到的都是最令自己感到膽寒的模樣。一旦離開迷霧，驚怖迷霧便會迅速失去凝聚力，坍縮成一團無害的水汽。

### 特性 Traits

**空氣形態 Air Form。**驚怖迷霧可以進入並停留在一名敵人所處的空間。其可以移動穿過最窄1寸寬的空間而無需消耗額外的移動力。

**融入迷霧 One with the Mists。**若驚怖迷霧身處霧氣或迷霧中，其處於隱形狀態。若驚怖迷霧身處霧氣或迷霧區域之外，其陷入失能狀態。

### 動作 Actions

**多重攻擊 Multiattack。**驚怖迷霧發動兩次撕裂心智攻擊。其可以將其中一次攻擊替換為使用施法來施展_命令術 Command_（若可用）。

**撕裂心智 Mind Rend。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_8（1d10+3）心靈傷害。

**施法 Spellcasting。**驚怖迷霧施展以下一道法術，無需法術成分並使用魅力作為施法屬性（法術豁免 DC13）：

**_隨意：_**_雲霧術 Fog Cloud_

**_1/日：_**_命令術 Command_

### 附贈動作 Bonus Actions

**滴注恐懼 Instill Dread（充能4~6）。**_感知豁免檢定：_DC13，位於該驚怖迷霧所處空間內的每個生物。_失敗：_目標陷入恐慌狀態，直至驚怖迷霧的下一回合開始。
