# 無骨者

殺機暗藏地剝下皮囊

**棲息地：** 任意；**寶藏：**無

無骨者是被活生生壓碎或剝皮的類人生物化作的活體皮囊。它們從那些遭遇剝皮、碾壓或被同類相食等殘忍死法的屍體中甦醒。這些充滿仇恨的皮囊可能會尋求復仇，用它們的彈性身軀緊緊纏勒並悶死受害者。此外，死靈法師也可能創造無骨者來充當隱秘的刺客。
邪惡的施法者可能會命令無骨者像怪誕的旗幟一樣懸掛著，或是將其披掛在骷髏和喪屍身上作為裝飾。當敵人靠近時，無骨者便會從周圍環境或亡靈盟友身上剝落，徑直撲向對手。

### 特性 Traits

**劫持 Abduct。**無骨者移動一名正被其擒抱的生物時無需額外消耗移動力。

**柔韌軀體 Compression。**無骨者可以移動穿過最窄1寸寬的空間而無需消耗額外的移動力。

### 動作 Actions

**卷緊 Smother。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_7（2d4+2）鈍擊傷害。如果目標是中型或更小的生物，則其陷入受擒狀態（逃脫 DC12）。直至擒抱結束，目標陷入目盲和束縛狀態且窒息，並在無骨者的每個回合開始時受到7（2d4+2）鈍擊傷害。無骨者同時能卷緊的生物數上限為一。在擒抱目標期間，無骨者無法再次使用此動作。

### 附贈動作 Bonus Actions

**解體血肉 Unraveling Flesh（1/日）。**_感知豁免檢定：_DC11，30尺範圍內每個能看到該無骨者的生物。_失敗：_目標陷入恐慌狀態。_失敗或_成功：__無骨者移動至多等於其速度的距離，且不會引發藉機攻擊。
