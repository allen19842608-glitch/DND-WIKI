# 無情主宰

無情主宰是龐大而兇殘的屠戮者，永不停歇地追獵其目標。這些碾壓者揮舞著特製的巨刃和鈍石，作為毀滅的利器。

*大型邪魔，中立邪惡*

**AC** 16　**先攻** +1（11）

**HP** 168 （16d10 + 80）

**速度** 30尺

### 特性 Traits

**傳奇抗性 Legendary Resistance（3/日）。**主宰豁免失敗時，可以將其改為豁免成功。

**再生 Regeneration。**主宰在其回合開始時恢復10生命值。若主宰受到光耀或來自重擊的傷害，則該特質在其下一回合開始時無法生效。主宰只有以0生命值開始其回合且無法再生時，才會死亡。

**攻城怪物 Siege Monster。**主宰對物件和建築造成雙倍傷害。

### 動作 Actions

**多重攻擊 Multiattack。**主宰使用處刑巨刃或毀傷之石發動共計兩次攻擊。

**處刑巨刃 Executioner's Blade。**_近戰攻擊檢定：_+10，觸及10尺。_命中：_ 19（3d8 + 6）揮砍傷害，且目標的速度減少10尺，持續至主宰的下一回合結束。

**毀傷之石 Crushing Stone。**_遠程攻擊檢定：_+10，射程60尺。_命中：_ 13（2d6 + 6）鈍擊傷害，且目標陷入失能狀態，持續至主宰的下一回合開始。

### 傳奇動作 Legendary Actions

傳奇動作次數：3。主宰可以在另一生物的回合後立即消耗一次傳奇動作來執行以下一道動作。主宰在其回合開始時回覆所有已消耗的傳奇動作次數。

**無情推進 Implacable Advance。**主宰移動至多等於其速度一半的距離，忽視困難地形。其路徑上的每個生物遭受以下效應。_力量豁免檢定：_DC 18。_失敗：_ 7（2d6）鈍擊傷害，且目標陷入倒地狀態。_失敗或_成功：__主宰直至其下個回合開始都無法再執行此動作。

**掃蕩斬 Sweeping Blade。**_敏捷豁免檢定：_ DC18，15尺錐狀區域內的每名生物。_失敗：_11（1d10 + 6）揮砍傷害，且目標被主宰直線拉近至多10尺。
