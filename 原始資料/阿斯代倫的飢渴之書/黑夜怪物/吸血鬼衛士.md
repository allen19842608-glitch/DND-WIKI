# 吸血鬼衛士

膚若磐石的吸血守衛

**棲息地：**幽暗地域，城市；**寶藏：**任意

吸血鬼需要值得信任的守衛來捍衛其巢穴、僕從及寶藏。不過，血僕一般活不長久，且總是有諂媚或睡眠等無法警惕的時候；而怪物僕從的行動又難以預測，或是根本就不可靠。為了確保巢穴的安全，一些吸血鬼會製造更堅韌的子代，作為監守巢穴的哨衛。這些吸血鬼衛士如大多數吸血鬼一般有著蒼白的外表，它們能憑藉意志力抗下可以打倒其他吸血鬼的打擊。若是遇到可以殺死大多數吸血鬼的情景，吸血鬼衛士便會化為石像，治癒自身，為再度服役做好準備。

啊，這些皮膚像石頭一樣硬的小笨蛋——它們是一群令人難以忍受的血族看門狗。我曾經試著跟家裡的一隻玩玩傳接球，但事情進展的可不順利。

——阿斯代倫銳評吸血鬼衛士

### 特性 Traits

**魔法抗性 Magic Resistance。**吸血鬼對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

**吸血鬼弱點 Vampire Weakness。**吸血鬼擁有以下弱點：

**_禁制術 Forbiddance。_**吸血鬼未得到一位居住者的邀請時無法進入相應的民宅。

**_流水 Running Water。_** 若吸血鬼在流水中結束回合，其受到20強酸傷害。

**_樁刺 Stake to the Heart。_** 吸血鬼位於其休眠地且陷入失能狀態期間，若用一把造成穿刺傷害的武器釘入其心臟，其陷入麻痺狀態直至該武器被移除。

**_日照 Sunlight。_**若吸血鬼在陽光下開始其回合，其受到20光耀傷害。若其身處陽光下，其進行的屬性檢定和攻擊檢定具有劣勢。

**屹立復甦 Immobile Restoration。**若吸血鬼的生命值被降至0時不具有石化狀態，則其變為石像，恢復50生命值並陷入石化狀態1小時。

### 動作 Actions

**多重攻擊 Multiattack。**吸血鬼發動兩次爪擊攻擊並使用啃咬或衛士號令。

**爪擊 Claw。**_近戰攻擊檢定：_+9，觸及5尺。_命中：_14（2d8+5）揮砍傷害外加7（2d6）暗蝕傷害。若目標生物不超過大型，則其被雙手之一擒抱，陷入受擒狀態（逃脫 DC16）。

**啃咬 Bite。**_體質豁免檢定：_DC16，單一5尺內的自願或陷入受擒、失能或束縛狀態的生物。_失敗：_7（1d4+5）穿刺傷害外加7（2d6）暗蝕傷害。目標的生命值上限減少等於其受到暗蝕傷害的數值，且吸血鬼恢復等量生命值。

**衛士號令 Guardian's Command。**吸血鬼施展_強迫術 Compulsion_，無需法術成分並使用魅力作為施法屬性（法術豁免 DC15）。

### 反應 Reactions

**血肉韌化 Resilient Flesh。**_觸發：_吸血鬼被一名其可見的攻擊者以一次近戰攻擊檢定命中。_響應：_吸血鬼令其從該次攻擊中受到的傷害減少11（2d6+4）。
