# 收割魔

奸詐與誘惑之魔鬼

**棲息地：**異界（九層地獄）；**寶藏：**器具

收割魔，顧名思義，是收集靈魂的能手，其名字便暗示了他們在為九層地獄添魂加魄方面的技巧。這些能言善辯的生物外形酷似提夫林，生有短小的尖角和一條能夠表現情緒的尾巴，在九獄階級中也被稱為伐樞魔 Falxugons。它們大多身著華美精緻的服飾，向那些易被腐化的凡人許諾財富或權勢。通常而言，硫磺光芒一閃，他們便會從中瞬間變出一紙契約，藉此完成交易。這份契約會將凡人簽署者的靈魂與九獄綁定。
收割魔的契約篇幅冗長，條款錯綜複雜，但這些魔鬼在交易時急功近利，以至於可能留下可以拯救簽署者靈魂的漏洞。你可以在契約漏洞表上擲骰或選擇一個結果，以決定某位精明讀者可能發現的這個漏洞是什麼。

**契約漏洞**

| **1d6** | **契約會失效的前提是簽署者......** |
| --- | --- |
| 1 | 向墨菲斯托費勒斯獻上其他九十九個靈魂。 |
| 2 | 同時站在滿月與弦月的月光之下。 |
| 3 | 在深淵中宣佈廢除契約。 |
| 4 | 受到另一名邪魔的保護。 |
| 5 | 有一個完全一致的雙胞胎或克隆。 |
| 6 | 誘騙該魔鬼簽署任何其他契約。 |

唉，這些魔鬼打扮得花枝招展，可他們契約的漏洞找起來可遠遠沒有我想像中那麼有意思。

——阿斯代倫銳評收割魔

### 特性 Traits

**魔鬼守禦 Diabolic Ward。**對收割魔發動的攻擊檢定具有劣勢。若其進行一次攻擊檢定，則此特質直到其下個回合開始之前被壓制。

**魔鬼復甦 Diabolical Restoration。**若收割魔於九層地獄之外死去，其身軀會化為硫磺煙霧消失，並立即在九層地獄某處獲得一具新的身體，以滿生命值復活。

**魔法抗性 Magic Resistance。**收割魔對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**收割魔使用獄火利刃或迷惘射線進行總計兩次攻擊。

**獄火利刃 Infernal Blade。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_6（1d6+3）揮砍傷害外加7（2d6）火焰傷害。

**迷惘射線 Confounding Ray。**_遠程攻擊檢定：_+5，射程120尺。_命中：_13（2d12）心靈傷害。若目標是一名生物，則其直到收割魔的下個回合開始前不能發動藉機攻擊。

**強辯契約 Compelling Contract（1/日）。**_魅力豁免檢定：_DC14，單一30尺內收割魔可見的生物。_失敗：_目標陷入魅惑狀態。目標陷入魅惑期間同時陷入震懾狀態，不過其仍能說話。若目標同意了收割魔的契約，則此效應終止。否則，目標在其受到傷害或其每回合結束時可以再進行一次此豁免。豁免成功時其身上的此效應終止。1分鐘後，其自動成功於此豁免。
