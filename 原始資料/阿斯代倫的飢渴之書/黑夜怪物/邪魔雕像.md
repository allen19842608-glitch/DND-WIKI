# 邪魔雕像

地獄魔法驅動的雕像

**棲息地：** 城市；**寶藏：**無

邪魔雕像是一種怪誕、具有智慧的雕像，刻畫的是可怖的邪魔形象。這些生物因邪惡儀式而獲得生命。邪魔雕像能噴出地獄之火來炙烤敵人，而且它們常常偽裝成普通的雕像，直到躍起伏擊入侵者。
擲一次邪魔雕像外觀表或從中選擇一個結果，以此啟發某個特定邪魔雕像的形象。

**邪魔雕像外觀**

| **1d6** | **邪魔雕像被刻畫為……** |
| --- | --- |
| 1 | 一個肌肉發達的邪魔，手持一支點燃的燭臺。 |
| 2 | 一個肚圓體肥的小魔鬼正在舔著一把鋸齒刀。 |
| 3 | 一個身材敦實、身披長袍的身影，一條分叉的尾巴從衣袍下探出。 |
| 4 | 一個長著鋒利獠牙的小天使，伸出一隻手作歡迎狀。 |
| 5 | 六隻烏鴉相互堆疊，形成一個大致人形的輪廓。 |
| 6 | 一個長角邪魔，模樣與某位角色極為相似。 |

唯一比這些醜陋雕像更難看的，就是我和我的兄弟姐妹們，尤其是當僕人們忘了拉上遮光窗簾的時候。

—— 阿斯代倫銳評邪魔雕像

### 特性 Traits

**魔法抗性 Magic Resistance。** 雕像對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**雕像發動兩次猛擊攻擊並使用熾熱爆發。

**猛擊 Slam。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_4（1d4+2）鈍擊傷害。

**熾熱爆發 Fiery Eruption。**_敏捷豁免檢定：_DC 11，位於源自雕像的5尺光環區域內的每名生物。_失敗：_受到7（2d6）火焰傷害。
