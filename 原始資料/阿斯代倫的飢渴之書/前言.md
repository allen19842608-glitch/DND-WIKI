# 前言

## 吸血鬼主宰黑夜！

在電子遊戲《博德之門3》中，精靈初生吸血鬼阿斯代倫·安庫因 Astarion Ancunín 憑藉其個人魅力深受廣大被遺忘的國度愛好者們的喜愛。在遊戲中，阿斯代倫是一位冒險夥伴及潛在的情緣對象，玩家既可以催他棄惡從善，也可縱容他踏上暴君之路。
但在電子遊戲中的大事件發生前，阿斯代倫是一名受害者，被迫淪為了吸血鬼卡扎多爾·扎爾 Cazador Szarr——大魔鬼墨菲斯托費利斯 Mephistopheles 的信徒——的僕從。每到深夜，阿斯代倫就會和卡扎多爾的其他初生吸血鬼為他們的主人獻上受害者，供其享用與殺戮。為了熬過扎爾的折磨以及不死生活的恐怖，阿斯代倫用譏諷、逢場作戲與一種陰冷的幽默感保護著自己。幾十年如一日的夜間狩獵教會了阿斯代倫吸血鬼生活的方方面面，也就是在本書中所呈現的各種秘辛。
對於玩家和地下城主而言，無論是在博德之門還是在龍與地下城的冒險裡，《阿斯代倫的飢渴卷冊》都為那些對吸血鬼感興趣的人提供了新的角色選項與工具。通過使用這些細節，阿斯代倫的粉絲們可以與他們最喜歡的初生吸血鬼一同冒險，而所有玩家都能得以窺見吸血鬼地下世界最骯髒角落裡潛藏著的真相。
