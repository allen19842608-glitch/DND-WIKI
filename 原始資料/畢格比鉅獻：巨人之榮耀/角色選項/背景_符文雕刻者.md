# 符文雕刻者

**符文雕刻者 Rune Carver**

你奉獻你的一生以學習符文工藝。也許你是受一名符文雕刻者的大師教導，亦也許是從古代刻印中鑽研得到的成果，你得到了利用符文之中的超自然能量的能力。
符文工藝的技藝最初是由巨人們創造的，但時過境遷，這一項工藝早已被許多人接納與利用。同樣的，雖然巨人符文也是最常被使用的那一類，但許多符文雕刻者的也會在作品融入他們原生語言中的符號。

**技能熟練項:** 歷史，察覺

**工具熟練項:** 一套工匠工具

**語言:** 巨人語

**裝備:** 一套工匠工具（由你選擇的一套），一把小刀，一塊打磨石，一套普通服裝，以及一個裝有10gp 的小包

**符文風格 Rune Styles**
每個符文雕刻者都有一套專屬於自己的風格與偏好的媒介。你可以投擲 符文風格 Rune Style 表來決定它，決定你是如何製作你的符文的。

**符文風格 Rune Style**

| **d6** | **風格** |
| --- | --- |
| 1 | 你用一根精緻的金屬針在蠟上、或在黏土上銘刻你的符文。 |
| 2 | 你將小塊的木頭切削成木雕以用於承載你的符文。 |
| 3 | 你將符文雕刻在玻璃珠子上，並將他們串成項鍊或是手鐲。 |
| 4 | 你將符文縫在衣物的褶邊上。 |
| 5 | 你在一組動物骨頭上刻下你的符文，並按照不同排列順序投擲。 |
| 6 | 你在蠟燭上繪出符文，再將蠟融化，填平蠟燭上的刻痕。 |

****

**特性：符文塑形者 Feature: Rune Shaper**
你獲得專長 符文塑形者 Rune Shaper（將在本章節稍後記述）。

**創建一個符文雕刻者角色 Building a Rune Carver Character**
學者的追求、古老的神秘、或一次命運的邂逅也許會啟發一個角色去追求屬於符文雕刻者的秘密。

**建議特徵 Suggested Characteristics**
符文雕刻者個性特點表向你提供了一些特點的建議，也許你會為你的角色採用它們。

**符文雕刻者個性特點 Rune Carver Personality Traits**

| **d6** | **個性特點** |
| --- | --- |
| 1 | 學習這種幾乎用不上的古老語言有用麼？沒。但這很有趣是吧？那當然。 |

| 3 | 那些古老的、傳統的符文工藝符號看上去是那麼的無聊，為什麼我不能給我的符文加點時髦的設計呢？ |
| 4 | 在我研習符文期間，我時常在探尋偉大文明衰落的原因，以此預防悲劇再次發生在現在的人，與現在的社會上。 |
| 5 | 生活也許就像一團混沌的狂風亂雨，但當我創造出我的符文後，那一切都無所謂了。 |
