# 邪氣之雲巨人

**邪氣之雲巨人 Cloud Giant of Evil Air**

考慮到他們和氣元素的內在聯繫，背棄序位諸神的雲巨人常常被邪惡氣元素親王延西冰所吸引。這些巨人狡猾而迷人，純粹的肉體力量和魔法能力會讓他們極為適合擔任邪惡元素教派的領導職位。一個以雲巨人為頭領的邪教可能成為一股強大的力量，在世界上散播腐化和毀滅。而彷彿這些還不足以證明自己的能耐一般，雲巨人們常常會帶來鉅額的財富，富足了邪教的金庫，為更深遠的運營提供資金。
一個忠於邪惡大氣的雲巨人身穿一件魔法背心，其上裝著由大鵬羽毛製成的翅膀，上面附著的氣元素魔法讓巨人能夠飛行。這件背心只對穿著它的巨人生效。

**邪氣之雲巨人 Cloud Giant of Evil Air**
_巨型巨人，通常中立邪惡_
AC 14（天生護甲）
HP 200（16d12+96）
速度 40尺，飛行40尺
力量27（+8）敏捷10（+0）體質22（+6）
智力12（+1）感知16（+3）魅力19（+4）
豁免：體質+10，感知+7，魅力+8
技能：洞悉+7，察覺+7，隱匿+4
感官：被動察覺17
語言：氣族語，通用語，巨人語
挑戰等級12（8,400XP）熟練加值+4

**飛掠 Flyby。**巨人飛出敵人的觸及範圍時不會引起藉機攻擊。

**動作 Actions**

**多重攻擊 Multiattack。**巨人進行兩次彎刀攻擊或兩次風暴迴旋鏢攻擊。

**彎刀 Scimitar。**近戰武器攻擊：命中+12，觸及10尺，單一目標。命中：18（3d6+8）揮砍傷害。

**風暴迴旋鏢 Storm Boomrang。**遠程法術攻擊：命中+12，射程60/120尺，單一目標。命中：15（3d4+8）鈍擊傷害，外加7（2d6）雷鳴傷害，並且目標必須成功通過 DC16的體質豁免否則直到自己的下個回合結束陷入震懾狀態。無論命中與否，迴旋鏢都會在攻擊後因魔法自動飛回巨人手中。

**施法 Spellcasting。**巨人施展以下一個法術，不需要任何材料成分且使用魅力作為施法關鍵屬性（法術豁免 DC16）。
隨意：_偵測魔法 detect magic，雲霧術 fog cloud，光亮術 light_
2/日：_心靈遙控 telekinesis_
1/日：_氣化形體 gaseous form_
