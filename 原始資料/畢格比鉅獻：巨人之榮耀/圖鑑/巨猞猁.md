# 巨猞猁

**巨猞猁 Giant Lynx**

在遇到那個正好用石頭把我砸死的霜巨人前不久，魔鄧肯和我看到了一隻巨猞猁。它只是以一種非常貓科動物的方式凝視著什麼都沒有的地方。 魔鄧肯想和它談談，看看它究竟在看什麼，但我成功勸住了他。

畢格比

當你看見一隻巨猞猁在凝視什麼都沒有的地方時，你可以很確信它在看什麼並不在那兒的東西。或者在看一個幽魂。

迪安卡斯特拉

儘管它們常常被誤認為是普通貓兒，但巨猞猁是一種源自妖精荒野白雪皚皚的林地的魔法生物。它們的毛皮外套在冬天顏色更淺，能夠讓它們哪怕是大地銀裝素裹的時候也能在自己最喜歡的棲息地中進行偽裝。
巨猞猁是狡猾的獵人，它們以小團隊的形式合作捕殺獵物，偶爾還能用魔法的天賦來偵查可能的狩獵地點。它們同樣足夠聰明，能夠智勝許多試圖誘捕它們獵取皮毛的獵手，還喜歡破壞在自己領地上發現一切捕獵者的圈套。
霜巨人和雲巨人有時會和巨猞猁交朋友，並把它們當做心愛的寵物。只要猞猁的智慧和獨立自主得到尊重，它們就會樂意和巨人夥伴分享他們的預言魔法。

**巨猞猁 Giant Lynx**
_中型妖精，通常絕對中立_
_AC 14_
HP 22（4d8+4）
速度 30尺，攀爬30尺
力量14（+2）敏捷18（+4）體質13（+1）
智力12（+1）感知14（+2）魅力10（+0）
技能：察覺+6，隱匿+6
傷害抗性：寒冷
感官：真實視覺60尺，被動察覺16
語言：巨人語，木族語
挑戰等級1/2（100XP）熟練加值+2

**猞猁之眼 Lynx's Sight（1/每日）。**猞猁能夠施展_鷹眼術 clairvoyance_，無需任何法術成分，使用感知作為其施法關鍵屬性。

**林地偽裝 Woodland Camouflage。**猞猁在灌木或雪地地下中進行的隱匿檢定具有優勢。

**動作 Actions**

**爪擊 Claw。**近戰武器攻擊：命中+6，觸及5尺，單一目標。命中：8（1d8+4）揮砍傷害。如果巨猞猁在攻擊前向目標直線移動至少20尺然後命中目標，則目標必須進行一次 DC 12的力量豁免，豁免失敗者將應擊倒地。如果目標處於倒地狀態，則該巨猞猁可以用一個附贈動作對目標再發動一次爪擊。
