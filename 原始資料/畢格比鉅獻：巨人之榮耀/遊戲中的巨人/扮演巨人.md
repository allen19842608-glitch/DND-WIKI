# 扮演巨人

**扮演巨人 Roleplaying Giants**

除了體型之外，巨人和人類十分相像也就是說，巨人很難一概而論。在團裡使用巨人的時候，你可以使用《城主指南》中關於設計 NPC 的表格來把你的巨人變成一位與眾不同的角色。有神秘紋身的巨人，愛用雙關的巨人，會玩雜耍的巨人會在玩家想像力的加持下變得格外生動，就和普通類人 NPC 一樣。

在創造巨人角色，或者扮演巨人角色的時候，要記住幾個關鍵點：體型，年齡，音量和驕傲。本節描述了一些可以合併到巨人形象中的特徵和行為，以強調每個元素，並未每個巨人都提供了示例。

**體型 Size**
序位中的巨人非常巨大，從16英尺到26英尺高不等。巨人和人類之間的體型關係就猶如成年人與新生嬰兒一般。巨人可能會覺得類人生物是無助的嬰兒、可愛的寵物（像小狗），噁心的害獸（如老鼠）或玩具兵。
在扮演時候最好考慮一下怎麼體現出巨人的體型。比如說玩家坐著的時候你站著，表現出一種睥睨感，或者描述你的巨人是怎麼睥睨的。巨型行為表格給出了一些習慣和事件的例子，能夠表現出一個巨人的體型很大。

**巨型行為 Huge Behaviors**

| **d8** | **行為** |
| --- | --- |
| 1 | 巨人養著一條寵物（豹，狼或者巨鼬），坐在巨人的腿上或者肩膀上。 |
| 2 | 巨人周圍飛著一大群椋鳥，他嘗試把那群跟蚊子一樣嗡嗡叫的東西打跑。 |
| 3 | 巨人用匕首當牙籤，用巨劍當開信刀，用標槍當縫衣針。 |
| 4 | 巨人把人舉起來的時候會小心翼翼地護著他們的頭，方便觀看和聽他們說話。 |
| 5 | 巨人驚歎於類人生物的盔甲細節和銜接部件是微雕工藝。 |
| 6 | 巨人把類人生物的頭骨當手玩把件。 |
| 7 | 巨人用桶喝水，就像是人類用水袋喝水一般。 |
| 8 | 巨人用一隻手抓著蜜瓜啃。 |

**年齡 Age**

**儘管不能和近神祖先們相比，但與人類相比，巨人也是十分長壽。他們的壽命長短也和他們在序位上的地位掛鉤，山丘巨人能活兩個世紀，風暴巨人是六個世紀。石巨人是個例外，他們能活到八百歲以上，就跟他們名字裡的那個石一樣久經磨洗。壽命表中顯示了每種類巨人的平均壽命（其他巨人類型生物的平均壽命和人類一致）。**

| **巨人類型** | **壽命** |
| --- | --- |
| 山丘巨人 | 200歲 |
| 石巨人 | 800歲 |
| 霜巨人 | 250歲 |
| 火巨人 | 350歲 |
| 雲巨人 | 400歲 |
| 風暴巨人 | 600歲 |

巨人的生活節奏會比小個子們慢很多，和他們的漫長壽命相一致。他們說話的速度也很慢，做決定的時候也不會很倉促。令人忍俊不禁的是，巨人們經常和周邊世界的時代產生脫節，這讓他們在和小族裔的互動中平添了許多困惑，他們對於類人生物國度和民族的知識儲備可能在他們還是小孩子的時候就過時了。古老行為表格提供了一些方法，讓你能夠更好地將巨人的年齡與遭遇結合起來。

**古老行為 Ancient Behaviors**

| **d8** | **行為** |
| --- | --- |
| 1 | 巨人把類人生物們認成是某個前朝的人（放現實就是叫你“巴比倫人”）。 |
| 2 | 巨人們說話的時候會扯到完全不相關的歷史背景。 |
| 3 | 巨人對類人生物的時尚俚語和流行文化的細節非常好奇。 |
| 4 | 巨人拖延症絕症晚期，覺得一切事都可以等未來某天再做。 |
| 5 | 巨人很容易談起某個已經去世了的朋友或家庭成員。 |
| 6 | 巨人不願意接手一切緊迫的問題。 |
| 7 | 巨人決定每天都找點樂子。 |
| 8 | 巨人相信自己的長壽應該被利用起來，在世界上留下印記。 |

**音量 Volume**
巨人很吵。他們數噸重的身體讓腳步聲震天動地，隆隆作響，如木桶般巨大的肺部在呼吸時的吼聲也是震耳欲聾，巨人們製造噪音的方式多種多樣。你不用對著你的玩家們大喊大叫，但也的確可以放大一點音量，輕輕晃動桌子來表現巨人前進時的震撼。強調巨人的音量可以幫助桌上的每個人都意識到自己在跟什麼照面。吵鬧行為表提供了許多建議。

**吵鬧行為 Loud Behaviors**

| **d6** | **行為** |
| --- | --- |
| 1 | 巨人（大聲地）鼓勵小個子們大聲地說話。 |
| 2 | 巨人若有所思，“嗯”了一聲，讓地面和聽眾都震了一下。 |
| 3 | 巨人發出一聲驚歎或者怒喝，讓聽眾都被嚇了一跳。 |
| 4 | 巨人的噴嚏聲，喊聲或嘆息聲都會把窗戶震的嘎嘎作響，讓樹葉飄落到地上。 |
| 5 | 巨人笑起來的時候就會引發一陣地動。 |
| 6 | 巨人的盔甲和武器雷霆作響。 |

**驕傲 Pride**
很多巨人都被教導說，安南誕下了巨人，並希望他們統治物質位面的諸界。雖然他們在以千年記的歷史中吸取了許多慘痛教訓，但他們的故事中仍然充斥著一種自負，讓他們的虛榮心膨脹起來。對於一個16到26英尺高的巨人生物來說，3到7英尺高的類人生物和他們的想法實在不值一提。用驕傲行為表來給你一些關於巨人的驕傲與虛榮之描述。

**驕傲行為 Proud Behaviors**

| **d8** | **這裡加粗寫文本** |
| --- | --- |
| 1 | 巨人無視較小的生物，除非對方表現出了恭敬和奉承。 |
| 2 | 巨人拒絕對著小生物彎腰，坐下以及跪下。 |
| 3 | 巨人無視小生物們的名字，而是用某種通用標籤稱呼（比如人類或晃鎧甲的）。 |
| 4 | 巨人看到小生物們的第一反應是大笑即便是被威脅或者大難臨頭。 |
| 5 | 巨人總是貶低或者藐視小生物，稱之為“小不點”，“雜毛”，“嬰兒”，“鼠輩”，“蟲豸”等。 |
| 6 | 巨人只會說巨人語。 |
| 7 | 巨人對小生物的一切侮辱或不尊重都大發雷霆。 |
| 8 | 巨人對小生物們說話時總是帶有一種優越感，拒絕把他們當一回事。 |
