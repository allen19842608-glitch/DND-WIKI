# 門鎮守衛

_先決條件：異度風景戰役_
你曾在受位面力量影響之地或是通往其他存在位面的傳送門周圍生活了許久，例如外域中的某個門鎮。你早已習慣那些令人聞風喪膽的異界恐怖與引人入勝的異域風光，且對你來說，與那些天族們與邪魔們打交道，就如同跟門鎮裡的小販打交道一樣稀疏平常（雖然有可能那個小販就是天族/邪魔）。

**技能：**遊說，求生

**語言：**自選兩門語言（推薦選擇深淵語、天界語或煉獄語）

**裝備：**一輪不知道對應什麼鎖的鑰匙串，一本空白的書籍，一根墨水筆或羽毛筆，一瓶黑墨水，一套旅行服裝，以及一個裝有10gp 的小包。

### 特性：位面注能 Planar Infusion

居住在門鎮或類似門鎮的地方使你長期浸泡在位面能量之下。你獲得專長外層位面後裔（見本章後文）。此外，你熟知你成長的這座社區裡哪裡能找到免費的、儉樸的飲食與住宿。

### 建議特徵 Suggested Characteristics

外層位面的影響塑造了你的看法，門鎮守衛個性特點表向你建議了一些你可以為你的角色選用的個性特點。

**門鎮守衛個性特點表**

| **d6** | **個性特點** |
| --- | --- |
| 1 | 我對那些稀奇古怪的事件與異界生物見怪不怪。 |
| 2 | 我覺得這才叫交易：一物換一物，空手換空手。 |
| 3 | 我以一種罕見的腔調說話。 |
| 4 | 我說話時總是帶點其他位面的語言的單詞或髒話。 |
| 5 | 我已經見過太多次了，以至於我明白靠臉看人靠不住，所以我會仔細端詳每一個人。 |
| 6 | 我因我成長的門鎮而獲得了一項奇特的習性，像是在緊張的時候我會去摸摸鐵器，或是非要把某些東西排順不然就不舒服之類的。 |

### 創建門鎮守衛角色 Building a Gate Warden Character

這些長期生活在通往另一個位面的永久傳送門附近的人，會吸取到源自傳送門彼端界域的精華。受到同一個位面影響的人，在行為舉止與身體外表上總有著某些共同之處。

**門鎮守衛飾品 Gate Warden Trinkets。**當你創建你的角色時，你可以在門鎮守衛飾品表上進行投擲，而非在《玩家手冊》中的飾品表上進行投擲。
