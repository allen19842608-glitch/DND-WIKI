# 印記城中的冒險

印記城位於外層位面的中心，多元宇宙的任何陰謀或威脅都可能滲入這座“眾門之城”。籠城中居民常懷揣跨越位面的野心，這為這座城市帶來了無數的冒險機會。本節內容旨在為基於印記城獨特地點與居民的冒險提供靈感。

**住在印記城，我們或許見識過一切……但位面的美妙與恐怖之處，在於它總能創造更多。**

**——艾琳·蒙哥馬利，感覺團會長**

### 冒險引子 Adventure Hooks

通過下表生成印記城各處的冒險起點。

| **D10** | **冒險引子** |
| --- | --- |
| 1 | 一個迷途的靈魂請求冒險者們護送其前往神祇居所——但無人知曉這位神祇的存在。 |
| 2 | 一位律師懇求角色們在高等法院的審判中作證，但角色們卻不記得目睹過犯罪行為。 |
| 3 | 一隻掌握重要秘密的**吱語顱鼠 Cranium Rat Squeaker** （見《莫提的位面遊記》）需躲避敵人並尋找城中它的鼠群。 |
| 4 | 難民懇求角色們幫助他們在印記城尋找一個安全的新家園。 |
| 5 | 角色們得知一臺恐怖的戰爭機器正通過印記城進行轉運，這臺戰爭機器用於征服某個物質位面世界。 |
| 6 | 店主或酒館老闆僱傭角色們追討賴賬的主顧——對方可能是**熾天神使 Solar**、**深獄煉魔 Pit Fiend**、**死亡騎士 Death Knight** 或其他強大的存在。。 |
| 7 | 一夥人試圖綁架某位角色，因為該角色是團隊計劃使用的傳送門鑰匙。 |
| 8 | 某個惡棍與某位角色外貌極度相似，導致一個**協約者 Kolyarut**或一個**紫銅卿 Cuprilach Rilmani** （二者均出自《莫特的位面遊記》）將這名角色錯認為是這個惡棍。 |
| 9 | 一位初到印記城的**大法師 Archmage**承諾：若角色們擔任其招攬者與轎伕 S 一日，便贈予角色們魔法物品。 |
| 10 | 一位**監護者 Dabus**（見《莫特的位面遊記》）請求角色們在痛苦女士察覺前，將某人或某地從印記城抹除。 |

### 派系任務 Faction Missions

使用下表中的情節深化角色們與印記城派系之間的聯繫。

| **D6** | **任務** |
| --- | --- |
| 1 | 會長僱傭角色們蒐集敵對派系會長的黑料。 |
| 2 | 角色們需潛入另一個派系總部並竊取無價之寶。 |
| 3 | 派系領袖僱傭角色們在議長大廳的重要城市活動中擔任保鏢。 |
| 4 | 會長懷疑己方陣營有內奸，僱傭角色們將其揪出。 |
| 5 | 一位派系會員秘密地向角色們提供重金懸賞，要求角色們幫監獄的某人越獄。 |
| 6 | 會長與敵對派系公開爭執後便失蹤，其副手僱傭角色們調查真相。 |

### 印記城災難 Sigil Calamities

各類多元宇宙的災難都可能在印記城中爆發。下表提供眾門之城大型冒險的劇情靈感：

| **D8** | **災難** |
| --- | --- |
| 1 | 印記城在峰時和谷時都會劇烈震顫，引發全城恐慌。 |
| 2 | 奧法黑潮席捲全城：魔法物品的效果會被抑制，法術會變得難以預測，傳送門也會停止運作，罪魁禍首是咒法會。 |
| 3 | 痛苦女士毫無預兆地將印記城三分之二市民投入到迷宮中。角色們必須查明原因。 |
| 4 | 城內各個可靠傳送門集體失靈，大批居民被拋向未知位面，混亂在城中爆發。 |
| 5 | 通往血戰前線的傳送門在下層區開啟，戰火蔓延至城內。 |
| 6 | 數十個已消亡的派系在底層印記城集結，向地表發動起義，意圖推翻多個現存派系。 |
| 7 | 痛苦女士突然封鎖籠城，禁止任何生物和任何物體的出入。 |
| 8 | 痛苦女士宣告不再容忍任何派系，所有派系必須解散，否則將承受其怒。三位會長齊聚一堂，僱傭角色們來改變痛苦女士的想法。 |
