# 莫提的位面遊記

**前言：多元宇宙級生物展覽 Introduction: Multiversal Menagerie**

“莫提。一名自稱‘著名’的位面旅行者，常常假扮成一個智顱來……”——智顱對“莫提”詞條的回應。
“喔！嘿嘿嘿！停一停停一停！哎，我可不知道誰塞給你了個有瑕疵的智顱，老大，但沒事，接下來我來告訴你什麼是什麼。“——莫提。

這些_智顱 Mimir_ ，常常被那些位面旅行者視為珍寶。它們利用智顱瞭解事實，躲開死在那些“手”啊、“爪”啊、“牙”啊、“觸手”啊、還有“長鼻子”啊、還有“產卵管”啊、還有數不勝數的其他多元宇宙捕食者（或者別的什麼暴躁居民）的各種各樣稀奇古怪肢體之下的命運。
莫提，呃，其實並不是一個智顱。
那顆漂浮在空中的頭顱，總是自說自話直言不諱，還聲稱自己有著各樣的專業知識。莫提是印記城眾多特色居民之一，也是一名成就斐然的位面探索者。只要給足了金幣或是欠他個人情，莫提很快就會供出他對各種位面的居民的各種建議、各種見解、以及各種評論。
這本書包含了自莫提的故事與隨言中提取出來的有用數據。然而，這些位面是遼闊且時刻變化的，且莫提親身經歷過的那些也不一定與實際情況相符。請讀者注意甄別。
