# 時光龍

**時光龍 Time Dragon**

_”別去找龍挑事，尤其是那些‘曾經’吃過你的。“——莫提_
這些優雅的龍類掌握著能夠操控過去，現在和未來的時光之力。時光龍雛龍有著閃耀的鱗片，其雙角則是初生的小塊。隨著它們逐漸掌握時間的流動，其雙角上便會生出遍佈分支的虹彩脈絡，諭示著時光運轉的軌跡與可能性。
遠古時光龍能創造出與多元宇宙中特定時間和地點相連的時空門。憑藉於此，時光龍與其盟友可以旅行至任何時間的任何地點，以影響決定命運的重要時刻，或是驅逐來自時光之外的威脅。時光龍能在不同的時代之間穿梭，這令它們經常表現得與當前的時間流脫節，並對何為過去，何為當下，何為未來有著很靈活的看法。
時光龍珍視對過去歷史的記錄、反映著失落文化的物品和早已逝去的創造者遺留的秘寶。它們對操縱時間的魔法和已被遺忘的知識非常感興趣。偶然發現時光龍寶庫的人也許會在其中發現關於過往年代的，極為珍貴的歷史信息。

_在庫若尼普斯之陵中，一條遠古時光龍守護著丈量多元宇宙間的龍類之命運的沙漏。_

**時光龍的巢穴 A Time Dragon's Lair**
時光龍通常棲息在古代文明的廢墟或供奉已逝神靈的聖殿之中，並會盡全力保護這些歷史遺蹟。時光龍對知識的永恆渴望意味著它可能有不止一處這樣的巢穴。
當遠古或成年時光龍在巢穴中遭遇時，其挑戰等級會上升1。

**巢穴動作 Lair Actions**
先攻輪到20時（出現等值時視為後手），巨龍可執行一個巢穴動作併產生下列效應其一。遠古龍和成年龍不能在連續兩輪裡重複使用同一種效應：

> **時光逐流 Temporal Fling。**巨龍試圖將一個位於其60尺內的它可見的生物向未來驅逐。目標須成功通過一次 DC18的感知豁免否則受到26（4d12）心靈傷害並向未來穿越1輪。穿越時光的目標在效應持續時間內消失。當效應終止時，目標會重新出現在其離開時的位置，若該位置已被佔據，則它出現在最近的未被佔據的位置上。
> 
> **時光凝滯 Time Lag。**巨龍緩速每個位於其60尺內的生物，直至下一輪先攻輪到20時。受影響的生物在其回合裡只能在**移動**和執行一個**動作**中選擇一種進行。該生物也不能執行**反應**和**附贈動作**。
> 
> **時軸分支 Timeline Divergence。**巨龍在巢穴中選擇一處能夠容納自身大小的空間。直到下一輪先攻值到20時，它同時存在於原地和選擇的空間中。移動和動作時，它能選擇哪一邊進行移動或動作。如果一個效應或攻擊同時以兩處巨龍所在的空間為目標，則龍僅受到一次影響。

**區域效應 Regional Effects**
遠古和成年時光龍巢穴周圍的區域被龍之魔法所改變，創造出以下一項或多項效應：

-   **時間縮放 Time Dilations。**巢穴周圍3英里內的時間出現波動。在此區域內進行短休所需的時間變為10分鐘或2小時（由你選擇）。
    
-   **永恆之境 Timelessness。**巢穴周圍3英里內的野獸，類人生物和植物每度過10年只會消耗1年的壽命。
    

如果巨龍死去，這些效應會在1d10日內逐漸弱化消失。

## 遠古時光龍 Ancient Time Dragon

_超巨型龍類，通常絕對中立_

**護甲等級**：22（天生護甲）

**生命值**：536（29d20+232）

**速度**：40尺，攀爬40尺，飛行80尺

| 屬性 | 數值 | 調整 |
| --- | ---: | ---: |
| 力量 | 28 | +9 |
| 敏捷 | 14 | +2 |
| 體質 | 26 | +8 |
| 智力 | 27 | +8 |
| 感知 | 18 | +4 |
| 魅力 | 23 | +6 |

**豁免**：敏捷+10，體質+16，感知+12，魅力+14

**技能**：奧秘+16，歷史+24，察覺+20，隱匿+18

**感官**：盲視60尺，黑暗視覺120尺，被動察覺30

**語言**：全部

**挑戰等級**：26（90,000XP）熟練加值+8

**重生循環 Cycle of Rebirth。**若巨龍死亡，其靈魂聚合為一顆金屬質地的龍蛋，並傳送至一個隨機的存在位面。龍蛋免疫所有傷害並在1d100年後孵化成為一隻**時光龍雛龍 Time Dragon Wyrmling**。巨龍保留其前世的全部記憶和習得的知識。

**傳奇抗性 Legendary Resistance（5/日）。**若巨龍在一次豁免中失敗，它可以選擇直接成功。
### 動作 Actions

**多重攻擊 Multiattack。**巨龍發動三次撕裂攻擊。

**撕裂 Rend。**近戰武器攻擊：命中+17，觸及15尺，單一目標。命中：22（3d8+9）揮砍傷害外加10（3d6）力場傷害。

**時光吐息 Time Breath（充能5~6）。**巨龍呼出一道閃耀的光流，覆蓋一處90尺錐狀區域。區域內未被攜帶或著裝的非魔法物件及植物都會崩解為灰塵。任何位於區域內的生物都必須進行一次 DC24的體質豁免。豁免失敗者受到52（8d12）力場傷害並因為其時間流發生錯亂而被魔法性地削弱。對此狀態下的生物發動的攻擊檢定具有優勢，且該生物陷入**中毒**狀態，並且，其他生物都對該生物造成的傷害具有抗性。豁免成功者只會受到一半的傷害。一個被削弱的生物可以在其每個回合結束時重複此豁免，並在累計三次豁免成功之後結束此效應。

**時光之門 Time Gate（1/日）。**巨龍在其雙角之間或是一處位於其30尺內的它可見的未佔據空間咒喚一道20尺直徑的環形傳送門。這道傳送門連接著距當前時間——無論向過去還是向未來......有至多8000年時間間隔的、任意存在位面中的一處精確地點。這道傳送門持續24小時或是直到巨龍的專注結束（如同專注於一道法術）。在各位面生成的傳送門都具有前端和後端，只有通過從傳送門的前端才能夠通過這個傳送門，任何穿過這個傳送門的事物都將被瞬間傳送到目的地，出現於距離傳送門最近的未佔據空間。神祇和其他位面統治者可以阻止巨龍所創造出的傳送門打開於祂們所在或掌管領域內的任何場所。
### 反應 Reactions
時光龍每輪都可以執行3個反應，但一回閤中只能執行一次。

**反應撕裂 Reactive Rend。**巨龍使用傳奇抗性或被一次攻擊命中後，巨龍發動一次**撕裂**攻擊。

**時光緩速 Slow Time。**當一個巨龍可見的生物結束回合時，巨龍指定一個位於其90尺內且被其時光吐息削弱的生物。目標的速度降至0，且其速度不能增加，直至其身上的削弱狀態結束。

**時軸穿梭 Time Slip。**巨龍減半它被一次對其發動的攻擊造成的傷害，前提是它能看到攻擊者。巨龍隨後可以連同其攜帶或著裝的裝備傳送到60尺內它能看見的一處未佔據空間。
