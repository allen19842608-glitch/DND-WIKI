# 神器

#### 愛莉莎女王的奇妙夜鶯 Queen Ehlissa's Marvelous Nightingale

奇物，神器（需同調）
愛莉莎女王的奇妙夜鶯得名於其第一任主人——灰鷹世界東法蘭尼斯的一位女王。其起源已不可考，但有傳說稱，這件神器是為了安慰女王失去心愛寵物鳴禽的悲痛而製作的。
這隻機械鳴禽擁有水晶雙眼、金色羽毛，以及背部一枚小巧的發條鑰匙。作為魔法動作。你可以讓這隻鳥鮮活地動起來，持續10 分鐘；在此期間，其會唱出在300 呎範圍內都能聽見的優美旋律；你也可以令其恢復機械形態。當夜鶯變回機械形態後，其在接下來的1 小時內無法再次活化。
**協奏施法Ensemble Casting。** 夜鶯具有6充能，並在每日黎明時恢復1d6+1已消耗的充能。當夜鶯正在歌唱且位於你60 呎內時，你可以使用附贈動作消耗充能從中施展以下表格中的法術之一（豁免DC18）。表格標明瞭施展該法術所需的充能消耗。

| **法術** | **充能消耗** |
| --- | --- |
| *偵測善惡 Detect Evil and Good* | 0 |
| *動物交談 Speak with Animals* | 0 |
| *安定心神 Calm Emotions* | 1 |
| *緩慢術 Slow* | 2 |
| *強迫術 Compulsion* | 3 |
| *高等復原術 Greater Restoration* | 4 |
| *延遲爆裂火球 Delayed Blast Fireball* | 6 |
| *虹光噴射 Prismatic Spray* | 6 |

**誠實靈光Aura of Truth。** 夜鶯歌唱期間，源自該夜鶯的15 呎光環區域內會充滿法術誠實之域Zone of Truth的效應（豁免DC18）。與夜鶯同調期間，你會知曉哪些生物在對抗該效應的豁免檢定中成功或失敗。
**法術反制Counterspell。**夜鶯歌唱期間，你可以執行反應施展*法術反制Counterspell* （豁免DC18），以響應該法術的觸發條件。該詞條一經使用，則直至下一黎明都無法再次使用。
**隨機詞條Random Properties。** 該神器具有以下隨機詞條（見《城主指南》的神器小節）：

- 2項次要增益詞條

- 1項主要增益詞條

- 1項次要減益詞條

**摧毀夜鶯Destroying the Nightingale。** 如果將夜鶯釋放至混沌海的旋風中，其將被摧毀。

#### 萬能仿製匣 Universal Pantograph

*奇物，神器*
這個立方體盒子每邊長2 呎。其看起來由橡木製成，並以銀飾加固，表面雕刻著提線木偶與歡笑孩童的圖案。
當一件非魔法物品被放入盒中併合上蓋子時，該物品的一個完美複製品便會出現在盒子旁邊。
**克隆Clone。** 你可以使用魔法動作令該仿製匣變大，直至足以讓一箇中型生物蜷縮在其中。你可以使用魔法動作令該仿製匣恢復至正常大小，並將任何無法容納於其中的事物無害地轉移至最近的未佔據空間。
當一個生物位於仿製匣內部時，你可以關閉仿製匣的蓋子，並向匣子灑下價值100+GP的鑽石粉末。若你如此做，則鑽石粉末將被消耗，同時你以仿製匣內的生物為目標施展法術*克隆術Clone*。在該法術的施法時間結束後，該生物會被無害地轉移出仿製匣。隨後，仿製匣的蓋子在120天內無法被打開，在此期間，由該法術創造的克隆體會在其內部成長。一旦克隆體成型，其會被無害地轉移出仿製匣，隨後仿製匣恢復至其原始大小。由仿製匣創造的克隆體無需被容納在容器中，並且在未激活的狀態下可以無限期留存。
**摧毀仿製匣Destroying the Pantograph。** 如果仿製匣內沒有容納克隆體，則當其在妖精荒野的泥沼中浸沒999年後，便會被摧毀。
