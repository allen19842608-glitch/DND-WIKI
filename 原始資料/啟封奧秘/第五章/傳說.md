# 傳說

#### 鑽石法杖 Diamond Staff

*法杖，傳說（需術士、魔契師或法師同調）*
這根6 呎長的節杖由一整塊巨大的水晶雕刻而成，頂端是一個完美的透明圓球。該法杖具有20充能。其可以作為一把魔法長棍被持用，並且以其進行的攻擊檢定和傷害擲骰具有+3加值。
**行家裡手Adept。** 持握該法杖期間，你的智力（奧秘）檢定具有優勢。
**炫目強光Dazzling Light。** 持握該法杖期間，你可以消耗1充能並說出命令詞，使法杖綻放光芒。法杖會發出半徑40 呎的明亮光照以及額外40 呎微光光照。1 分鐘後，或當你使用命令詞將其關閉時，法杖會停止發光。
**法術Spells。**持握該法杖期間，你可以使用你的法術豁免DC從中施展以下表格中的法術之一。表格標明瞭施展該法術所需的充能消耗。

| **法術** | **充能消耗** |
| --- | --- |
| *偵測魔法 Detect Magic* | 0 |
| *光亮術 Light* | 0 |
| *巧言術 Tongues*（僅自身） | 0 |
| *鑑定術 Identify* | 1 |
| *敲擊術 Knock* | 2 |
| *真知術 True Seeing* | 3 |
| *通曉傳奇 Legend Lore* | 5 |
| *迷宮術 Maze* | 8 |

**震懾打擊Stunning Hit。** 當你使用該法杖進行近戰攻擊並命中時，你可以消耗2充能，目標必須進行一次DC17的體質豁免，豁免失敗則陷入震懾狀態，直至你的下一回合結束。
**重獲充能Regaining Charges。** 該法杖在每日黎明時恢復1d6+4已消耗的充能。如果你消耗了最後一充能，擲一次d20。若擲出1，該法杖將被摧毀。

#### 墓冢死神 Grave Reaper

*武器（鐮刀），傳說（需同調）*
你使用這把魔法武器進行的攻擊檢定和傷害擲骰獲得+2加值。當你以其命中一個生物時，目標受到額外2d8暗蝕傷害。
**靈魂提燈Soul Lantern。**持握該武器期間，你可以施展法術*魂靈提燈Spirit Lantern* （見第二章）。當你使用該武器施展此法術時，召喚出的提燈至多可容納五個靈魂碎片，並且該法術的豁免DC為17。
一旦使用該武器施展了此法術，則直至下一黎明前，都無法再次使用其來施展。

#### 旅人珍珠 Traveler's Pearl

*奇物，傳說（需同調）*
持握這顆珍珠期間說出命令詞，你就能從中施展法術*傳送術Teleport*。該詞條一經使用，則直至下一黎明前，都無法再次使用。
