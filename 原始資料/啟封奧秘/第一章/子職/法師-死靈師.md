# 法師-死靈師

## 死靈師 Necromancer

死亡與不朽之主宰

你探索生命、死亡與不朽之力。作為一名死靈師，你知曉如何操控驅使生物活動的能量，並從載於法術書的那些禁忌秘密中汲取日益強大的力量。儘管許多人視死靈師為可怖或邪惡之徒，但並非所有死靈師都是邪惡的。

**3級：死靈學者 Necromancy Savant**
從法師法術列表中選擇兩道不高於二環的死靈學派法術，並將其免費加入你的法術書中。
此外，每當你在本職業中獲得一個新環階的法術位時，你都能免費將一道法師法術列表中的死靈學派法術加入你的法術書中。你所選的法術都必須是你當前擁有法術位的環階。

**3級：死靈魔典 Necromancy Spellbook**
記載在你的法術書中的死靈魔法秘儀令你獲得了更多的力量。你獲得以下增益：
**暗蝕抗性Necrotic Resistance。** 你獲得對暗蝕傷害的抗性。
**亡靈魔寵Undead Familiar。**法術*尋獲魔寵Find Familiar*出現在你的法術書中。當你施展該法術時，除了通常的形態選項，你還可以改為選擇下列特殊形態之一：**骷髏Skeleton**或**喪屍Zombie** （魔寵的數據卡見《玩家手冊》附錄B）。當你使用通常的形態選項時，你可以選擇亡靈作為其生物類型。
此外，當你執行攻擊動作時可以放棄自己動作攻擊中的一次攻擊，轉而讓你的魔寵使用其反應發動一次攻擊。
**亡靈生機Undead Vitality。** 當你使用法術位施展一道死靈學派法術時，你可以選擇60 呎範圍內一名亡靈恢復等同於消耗法術環階+你的法師等級的生命值。

**6級：墳冢之力 Grave Power**
你進一步洞悉了死靈術的內核，並將這些內容記錄進了你的法術書。你在持有自己的法術書期間獲得以下增益：
**思墳之韌Grave Resilience。** 當你使用奧術回想時，你的力竭等級（若有）降低1級。
**朽壞之威Overwhelming Necrosis。** 你的法師法術和法師特性造成的暗蝕傷害無視對暗蝕傷害的抗性。

**6級：亡靈僕役 Undead Thralls**
你始終準備著法術*活化死屍Animate Dead* ，並且可以無需消耗法術位地施展該法術一次，但在你再次以此法施展該法術前，你必須完成一次長休。每當你開始施展該法術時，你可以對其進行調整，使該法術的有效環位提升一環。
此外，在你持有自己的法術書期間，你獲得以下增益：

- **不死堅韌Undead Fortitude。** 每當你施展一道會創造或召喚亡靈的死靈法術時，該亡靈的最大生命值和當前生命值增加，數值等同於你的智力調整值+你的法師等級的一半（向下取整）。

- **凋零打擊Withering Strike。** 每當位於你60 呎內由你操控的亡靈以一次攻擊檢定命中一名生物時，該亡靈造成等同於你智力調整值的額外暗蝕傷害（至少1暗蝕傷害）。

對於強大的魔法師而言，生與死不過是可以相互轉換的存在狀態。

——艾拉斯卓

**10級：收割亡靈 Harvest Undead**
你知曉了更多關於生死之異同的秘密。在因受傷進入浴血但並未被降至0生命值後，你可以立即執行一個反應將一個由你控制的可見亡靈降至0生命值，隨後你立即恢復等同於你法師等級的生命值。

**14級：死之尊主 Death's Master**
你法術書中記載的玄奧秘儀令你主宰生死。在持有你的法術書期間，你獲得以下增益：
**亡靈增幅Bolster Undead。** 以一個附贈動作，你指定60 呎範圍內任意數量由你使用死靈學派法術創造或召喚的亡靈。每個亡靈都獲得等同於你法師等級的臨時生命值。此附贈動作一經使用，直至完成長休你都無法再這麼做。
**湮滅亡靈Extinguish Undead。**當一名你可見的亡靈被降至0生命值時，你可以使其在暗蝕能量中爆裂。擲數量等同於該生物未消耗生命骰數量一半的d6（向上取整，至少為1d6），並將結果相加。自該亡靈10 呎光環區域內的每個生物進行一次敏捷豁免檢定。若豁免失敗，目標受到等同於擲骰結果的暗蝕傷害，並在其下個回合開始前無法執行反應。若豁免成功，目標只受到一半傷害。你必須使用反應並消耗一個五環及以上的法術位才能使用此特性令不受你控制的亡靈爆裂。
