# 背景 Backgrounds

本節採用了與《玩家手冊》相同的格式，展示了十個全新的背景。這些背景列在下方的背景表格中。由各個背景賦予的起源專長的詳細描述，可在本章稍後部分找到。
其中九個背景將角色與第四章中介紹的魔法派系聯繫起來。這些背景描述了與特定派系相關的訓練經歷，但它們並非加入該派系或成為其成員的必要條件。
第十個背景，魔寵訓練家，則適用於任何伴隨魔法動物夥伴長大的角色。
