# 讓戰鬥持續推進

**讓戰鬥持續推進 Keeping 戰鬥 Moving**

有時，即使是計劃最周密的戰鬥遭遇也會陷入僵局，雙方無法推進，也無法對對方造成太大的傷害。在這些情況下，你可以使用以下幾種技巧讓戰鬥繼續推進，或讓遭遇迅速結束。

**不要重複遊戲狀態Don't Repeat Game States**
當角色做出足以改變局勢的行為時，不要把戰況扳回原位。例如，如果一個角色執行撤離行動去遠離一群怪物，作為回應，不要讓這些怪物對該角色緊追不捨，而是讓他們把目標移到別處。

**讓怪物死得更快Hasten a Monster's Demise**
如果戰鬥已經持續了夠長的時間，並且角色們的勝利已成定局，那麼你可以直接讓怪物死掉。玩家們絕不需要知道角色處決怪物時它本來應該還剩15點生命值。

**停止敵對態End Hostilities**
大多數怪物都能看出戰鬥是否正按照它們預想的方向發展（或者根本毫無進展）。智能怪物可能會與角色談和以保性命。突然間，怪物和角色進行談判，停止敵對時，戰鬥就變成了一場交涉。非智能怪物可能會裝死，試圖讓角色停止攻擊，但只要有機會就會立刻站起來逃跑。本章後的“戰鬥還是逃跑”部分將給出更多建議。

**添加參戰者Add a Combatant**
為了讓戰鬥更加刺激，你可以考慮添加一名參戰者。也許一個可怕的掠食者遊蕩到了角色與另一敵人交戰的場景中。或者，持續的戰鬥聲吸引了附近地城住民們的注意。新加入的戰鬥人員可能會同時攻擊角色與其敵人，也可能加入其中的任意一方。每當一個或多個新的參戰者加入遭遇時，請為他們投擲先攻並將其列入先攻順序中。

**改變戰場Change the Terrain**
為了讓參戰者們有理由四處移動，你可以考慮改變戰場來引入新的元素。也許一次強勁的攻擊或爆裂的法術會傾覆一根柱子，粉碎一面牆，或崩裂地板。地面上可能因此裂開縫隙，釋放出毒氣、煙霧或熔岩。魔法可以撕開存在位面間的邊界，釋放原初元素或其他位面的能量。又或者，怪物的絕望情緒導致了狂野魔法將現實架構徹底扭曲。你可以使用第三章中的環境效應、危害和陷阱來展示這些效應。

**更改怪物Changing the Monster**
你可以將一個怪物轉化成另一個怪物，讓戰鬥更有趣。也許一隻座狼從中間裂開，而一隻囈語之口自裡面溢了出來。或者一位邪教徒被煉獄的火柱吞噬，隨即一個魔鬼從灰燼中乍現。你還可以在戰鬥中巧妙地臨場改變怪物的數據卡；例如，你可以決定讓一個怪物在浴血時進入狂怒，它在攻擊時會獲得優勢，而角色們攻擊它時也會獲得優勢，從而加速戰鬥直至結束。
