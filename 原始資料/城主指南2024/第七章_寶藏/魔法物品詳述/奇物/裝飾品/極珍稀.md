# 極珍稀

###### 位面護符 Amulet of the planes

_奇物，極珍稀（需同調）_
佩戴此護符期間，你能夠以一個**魔法**動作指名一個位於其他存在位面的你所熟悉的地點。那之後你進行一次 DC15的智力（奧秘）檢定。如檢定通過，你施展_位面轉移 Plane Shift_ 。如檢定失敗，你和位於你15尺內的每個生物與物件將被傳送至一個由投擲 d100並根據下表決定的隨機目的地。

| **d100** | **目的地** |
| --- | --- |
| 01-60 | 與你指名地點同一位面的隨機地點。 |
| 61-70 | 投擲1d6決定某內層位面中的隨機地點：1氣之位面；2土之位面；3火之位面；4水之位面；5妖精荒野；6墮影冥界。 |
| 71-80 | 投擲1d8決定某外層位面中的隨機地點：1奔放之野；2世外桃源；3萬獸鄉；4雙生天堂；5極樂境；6機械境；7天堂山；8伊斯加德。 |
| 81-90 | 投擲1d8決定某外層位面中的隨機地點：1無底深淵；2修羅場；3卡瑟利；4焦炎火獄；5哈迪斯；6混沌海；7九層地獄；8喧癲空隧。 |
| 91-00 | 星界位面中的隨機地點。 |
