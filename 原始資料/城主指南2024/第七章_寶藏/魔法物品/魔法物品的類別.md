# 魔法物品的類別

**魔法物品的類別 Magic Item Categories**

每件魔法物品都隸屬於一個類別。**魔法物品類別**表列出了所有9個類別並給出了範例。這些類別的相關規則將在該表後有所述及。
**魔法物品類別 Magic Item Categories**

| **類別** | **範例** |
| --- | --- |
| 護甲 | +1皮甲，+1盾牌 |
| 藥水 | 治療藥水 |
| 戒指 | 隱形戒指 |
| 權杖 | 不動權杖 |

### 護甲 Armor

護甲類別的物品一般為玩家手冊中所述護甲的魔法版本。除非一件護甲的描述另有說明，否則護甲必須被著裝以發揮其魔法性質。
某些魔法護甲會註明該護甲的類型，例如鍊甲或板甲。若護甲並未標註類型，則你可以自行選擇或隨機決定其類型。

### 藥水 Potions

藥水類別的物品可以是必須飲用生效的魔法釀造物，或者是必須對一名角色或一個物件塗抹生效的油狀物。一般藥水表現為裝在小瓶中的1盎司液體。
**使用藥水 Using a Potion** 。藥水是消耗品。喝下藥水或者將其施用於另一名角色身上都需要一個附贈動作。而施用一件油狀藥水有可能會需要更久，如其描述所示。
一經使用過後，藥水便會立即生效，且該藥劑即被用盡。
**混合藥水 Mixing Potions** 。一名角色可能會在其仍處於一種藥水效應影響之下的時候又喝下另一種藥劑，或者把幾種藥水注入同一容器之中。在製造藥水時所使用的奇怪原料將會導致產生無法預料的化學反應。
當一名角色將兩種藥水混合到一起時，則依據**藥水混合**表進行擲骰。如果混合的藥水多於兩種，則為隨後加入的每一種藥水再進行一次擲骰。除非混合後的效應可以被立即觀察到，否則在效應顯現時，這些效應才會再被揭示出來。
**藥水混合 Potion Miscibility**

| **1D100骰值** | **結果** |
| --- | --- |
| 01 | 兩種藥水均失去其效應，且該混合物將在以其自身為中心5尺半徑的球狀區域內產生一場魔法性爆炸。該區域內的每名生物將受到4d10力場傷害。 |
| 02-08 | 兩種藥水均失去其效應，且該混合物變成一種由你所選擇的服用型毒藥（見第三章“**毒藥**”）。 |
| 09-15 | 兩種藥水均失去其效應。 |
| 16-25 | 其中一種藥水失去其效應。 |
| 26-35 | 兩種藥水均生效，但它們所有以數值表示的效應及其持續時間均減半。若某種藥水沒有任何以數值表示的效應，也沒有持續時間，則該藥水失效。 |
| 36-90 | 兩種藥水均如常生效。 |
| 91-99 | 兩種藥水均生效，但它們所有以數值表示的效應及其持續時間均翻倍。若兩種藥水都沒有任何能夠以該方式翻倍的地方，則兩者如常生效。 |
| 00 | 只有其中一種藥水可以生效，但其效應將變為永久效應。選擇一項最直截了當的或者看上去最能整活的效應，使其變為永久效應。例如，**治療藥水_Potion of Healing_**可能會為飲用者提高2d4+2點生命值上限，又或者**隱身藥水_Potion of Invisibility_**可能會給予飲用者無期限的隱形狀態。依你的裁決，法術**解除魔法_Dispel Magic_**或者類似的法術或許能夠終止該持續中的效應。 |

### 戒指 Rings

除非戒指的描述另有說明，否則戒指類別的物品必須被著裝在手指或者類似的指趾上以發揮其魔法性質。

### 權杖 Rods

權杖類別的物品通常由金屬，木頭或骨頭製成。權杖一般重量為2到5磅。
權杖可以被用作奧術法器，除非其描述另有說明。

### 卷軸 Scrolls

卷軸類別的物品可以是紙卷或羊皮卷，有時還會纏繞於木棒之上，且一般保存於象牙筒、玉筒、皮筒、金屬筒或木筒中。法術卷軸是最常見的一種卷軸，能夠以書寫的形式儲存一道法術。然而某些卷軸，例如**保護卷軸_Scroll of Protection_** ，其中具有的就是一道咒文，而非法術。
**使用卷軸 Using a Scroll** 。卷軸是消耗品。將卷軸中的魔法釋放出來需要使用者對卷軸進行閱讀。當卷軸中的魔法被喚出後，該卷軸便無法再次使用。然後卷軸上的文字將消失或者其本身破碎化為塵埃。
除非卷軸的描述另有說明，任何能夠看懂一門語言之書面文字的生物都能夠閱讀並嘗試激活卷軸。

### 法杖 Staffs

法杖類別的物品具有各種各樣的外觀：一些法杖外表平滑且各處直徑近乎相等，而另外一些則長得又疙瘩又扭曲；一些法杖由木頭製成，而另外一些則由經拋光的金屬或水晶所組成。法杖重量在2到7磅之間，並且也能很好地充當步行杖或者手杖。
法杖可以被用作一根非魔法長棍或者一件奧術法器，除非其描述另有說明。

### 魔杖 Wands

魔杖類別的物品一般12到15寸長，且一般由金屬，木頭或骨頭製成。其頂端一般會用金屬，骨頭，木頭或者其他一些材料進行裝飾。
魔杖可以被用作奧術法器，除非其描述另有說明。

### 武器 Weapons

魔法武器一般為玩家手冊中所述某種武器的魔法版本。某些魔法武器會在其描述中註明該武器的類型，例如長劍或長弓。若武器並未標註類型，則你可以自行選擇或隨機決定其類型。
**彈藥 Ammunition** 。若一件魔法武器具有彈藥詞條，則對於任何意在規範某件武器魔法性與否的規則而言，從該武器中射出的均為魔法性子彈。

### 奇物 Wondrous Items

奇物類別的物品包括但不限於諸如靴子、腰帶、斗篷、護符、徽章、頭飾之類的可著裝物品。背包、毛毯、小型塑像、號角、樂器等物品也都歸於此類。
**魔法物品規則 Magic Item Rules**
魔法物品的鑑定規則，同調規則與使用規則皆已在玩家手冊中列出。額外的規則則如下所述。

-   **同調的先決條件 Attunement Prerequisites** 。若魔法物品具有某項職業的先決條件，則一名生物必須屬於該職業才能與該物品同調。如果一名生物必須是施法者才能與某物品同調，則若該生物能夠通過其特質或特性施展至少一道法術（不能使用魔法物品或類似手段），那麼該生物就具備同調該物品的資格。
    
-   **為特定生物製造的物品 Items Made for Specific Creatures** 。用以著裝的魔法物品一般會魔法般地自動調整其形狀以適配其著裝者。然而，你也可以令魔法物品不再調整自身以適配著裝者。例如，一位特定的盔甲匠製造出來的物品可能只有那些體型和身材都和矮人差不多的傢伙才能使用。
    
-   **罕見的身體構造 Unusual Anatomy** 。你可以自由決定某名生物是否可以著裝某件並非為其身體構造而製造的物品。戒指套在一條觸手上面或許還能生效，但一名長著蛇尾而非雙腿的蛇人便無法著裝魔法靴子。
    
-   **成對的物品 Paired Items** 。雖然規則規定成對的物品兩者都必須被著裝，但你也可以允許一些例外情況。例如，一名只有一條手臂的角色也可以使用單獨一隻辟矢奪箭手套 Grove of Missile Snaring，只要另外一隻手套還在該角色身上。
