# 魔法物品的獨特特性

**魔法物品的獨特特性 Magic Item Special Features**

你可以通過為某件魔法物品考慮背景故事以為該物品增添獨特性。該物品是誰製造的？其構造是否有什麼不平常之處？它是為什麼而被製造出來，而其最初的用途又是什麼？有什麼奇妙的小影響使得該物品有別於同類型的物品？對這些問題的回答可以幫助你將某件平平無奇的魔法物品，例如一把**+1長劍**，變得更耐人尋味。
使用下列表格來為某件魔法物品的過往歷史填補細節。其中某些表格中的條目能夠為特定物品增添有別於其他物品的更多意義。若你擲骰隨機到了某些不合理的結果，則你可以再次擲骰並選擇更合理的條目，或者直接以該結果作為引導自行編寫屬於你自己的獨特特性。
在**魔法物品的次級詞條**表以及**魔法物品的影響**表中，“你”指的是該物品的所有者。

**魔法物品的製作者或預設使用者 Magic Item's Creator or Intended User**

| **d20 骰值** | **製作者或預設使用者** |
| --- | --- |
| 1 | **異怪 Aberration**。該物品年代久遠，乍一看好像是被粘液所覆蓋一般。 |
| 2 | **天界 Celestial**。該物品重量為其通常重量的一半，其上鐫刻著羽翼、太陽與星星的圖案。邪魔將會對該物品感到厭惡。 |
| 3 | **羅絲信徒 Devotees of Lolth** 。該物品重量為其通常重量的一半。其上鐫刻著蜘蛛與蛛網的圖案，意在表達對羅絲的崇敬。 |
| 4 | **巨龍 Dragon** 。該物品鑲嵌了不少來自巨龍寶庫中的名貴金屬與寶石。當該物品位於一名龍類的120尺內時，該物品將會變熱。 |
| 5-6 | **矮人 Dwarf**。該物品堅固耐用，其上的矮人符文亦是其設計的一部分。該物品可能會關聯於某支希望該物品迴歸其宗祠的矮人氏族。 |
| 7 | **氣元素 Elemental Air** 。該物品重量為其同常重量的一半，而且感覺像是空心的一樣。如果該物品由絲織物製成，則其將如輕紗般半透明。 |
| 8 | **土元素 Elemental Earth** 。該物品可能由石頭製成。其上任何布料或皮革部分點綴滿了打磨光滑的小石粒。 |
| 9 | **火元素 Elemental Fire** 。該物品摸上去很暖和，其上任何金屬部分均由黑鐵打造而成。火焰圖樣覆蓋於物品表面。 |
| 10 | **水元素 Elemental Water** 。該物品的任何布料或皮革部分均由色澤光鮮的魚鱗所替代。而該物品的金屬部分均由貝殼和珊瑚（硬度不輸任何金屬）所替代。 |
| 11-12 | **精靈 Elf**。該物品重量為其通常重量的一半。其上以各種象徵大自然的標誌所點綴：樹葉、藤蔓、星星，諸如此類。 |
| 13 | **妖精 Fey** 。該物品是用最好的材料精巧地製造而成，且其周身散發著如月光般的皎白光輝，在半徑5尺區域內投下微光光照。該物品的任何金屬部分均為銀或秘銀打造，而非鐵或鋼。 |
| 14 | **邪魔 Fiend**。該物品由鐵或角製成，且其含有的任何布料或皮革部分均改為用邪魔的皮膚製成。其表面鐫刻著奸笑的臉以及褻瀆的符文。天族將會對該物品感到厭惡。 |
| 15 | **巨人 Giant**。該物品比其通常尺寸要更大，原先是巨人制造給他們更小體型的盟友們用的。 |
| 16 | **地侏 Gnome**。該物品被製造得看似平平無奇實則非常好用。該物品還帶有齒輪與機械結構，即使這些結構並非其功能所必需。 |
| 17-19 | **人類 Human**。該物品在某個失落人類王國的鼎盛時期所打造，又或者該物品與傳說中的某位人類有著緊密聯繫。其上可能帶有用失傳的語言書寫的銘文，或者意義已隨歲月亡軼的標記。 |
| 20 | **亡靈 Undead**。該物品帶有象徵著死亡的標誌，例如骨頭以及骷髏頭，並且該物品還有可能是用屍體的某些部分製造的。該物品摸上去會感到冰涼。 |

**魔法物品的過往歷史 Magic Item's History**

| **d8 骰值** | **過往歷史** |
| --- | --- |
| 1 | **神秘的 Arcane**。該物品是為某個古代施法者團體所製造而成，並且其上還帶有該團體的標誌。 |
| 2 | **災禍術 Bane**。該物品是為對抗某個特定種類的生物所製造的，例如異怪或者龍類。 |
| 3 | **英雄的 Heroic**。某位大英雄曾經持有過該物品。任何瞭解該物品過往的人都期待著它的新主人能夠再續偉業。 |
| 4 | **裝飾的 Ornament**。該物品是為了紀念某個特殊事件。其表面由寶石，黃金或者鉑金點綴，金絲或者銀線鑲邊。 |
| 5 | **預言的 Prophecy**。該物品是某個預言的一部分：其所有者註定要在未來的某事件中扮演關鍵的角色。 |
| 6 | **宗教的 Religious**。該物品曾用於供奉某個特定神明的儀式。該物品上面帶有宗教的標誌。 |
| 7 | **不祥的 Sinister**。該物品與一名強大邪物的所作所為相關，例如某場大屠殺或某件刺殺案。該物品可能會擁有一個名字，或與某個曾使用過該物品的惡人之名緊緊聯繫在一起。 |
| 8 | **權力象徵 Symbol of Power** 。該物品曾經是皇權象徵的一部分，或是身居高位的標誌。 |

**魔法物品的次級詞條 Magic Item's Minor Property**

| **d20 骰值** | **次級詞條** |
| --- | --- |
| 1-2 | **燈火 Beacon**。你可以執行一個附贈動作令該物品散發出半徑10尺的明亮光照以及額外10尺的微光光照，或令該物品散發的光芒熄滅。 |
| 3 | **羅盤 Compass**。你可以執行一個魔法動作以知曉磁北方向所在。若該詞條在沒有磁北的區域中使用，則其不會產生任何效果。 |
| 4 | **深掘者 Delver** 。在地下時，你總是能夠知道該物品所處深度以及距離最近的樓梯，坡道或任何向上延伸的道路所處的方位。 |
| 5-6 | **守護者 Guardian** 。該物品會為你發出警告，只要你未陷入失能狀態，則該物品將為你的先攻檢定提供+2加值。 |
| 7-8 | **調諧 Harmonious**。與該物品同調僅需1分鐘。 |
| 9 | **鎖鑰 Key** 。該物品可以被用來解鎖某件容器、某個房間、某個金庫或某扇大門。 |
| 10 | **密令 Secret Message** 。一條信息被藏於該物品的某處。該信息可能只有在特定時間、特定地點或者某一月相的月光下才會顯現。 |
| 11-12 | **哨兵 Sentinel** 。DM 選定一種生物，例如奪心魔或巨魔。該物品會在所選定生物進入其120尺內時發出微弱的光芒。 |
| 13 | **作曲 Songcraft** 。每當該物品被敲擊或者該物品被用於擊打某名敵人時，你就會聽到某首古代歌曲的其中一小段。 |
| 14-15 | **奇材怪料 Strange Material** 。該物品由一種與其用途不符的奇特材料製成，但這並不影響其耐久性。 |
| 16 | **令人暖心 Temperate** 。你在0度及以下或100度及以上的華氏溫度下皆能安然無恙。（譯註：即-18攝氏度以下，38攝氏度以上。） |
| 17 | **堅不可摧 Unbreakable**。該物品無法被破壞。只有某些特殊手段方可摧毀該物品。 |
| 18 | **戰爭領袖 War Leader** 。你可以執行一個魔法動作以將你的聲音或信號清晰地傳達到至多600尺的範圍之內，直至你的下個回合結束。 |
| 19 | **水上漂 Waterborne**。該物品可以浮在水或其他液體之上。你為游泳進行的力量（運動）檢定具有優勢。 |
| 20 | 再骰兩次，並重骰接下來任何結果為20的骰子。 |

**魔法物品的影響 Magic Item's Quirk**

| **d8 骰值** | **影響** |
| --- | --- |
| 1 | **幸福 Blissful**。你對未來的事情感到富裕且充滿希望。蝴蝶或其他無害的生物可能會在該物品周圍嬉戲逗留。 |
| 2 | **自信 Confident**。該物品使你感到自信滿滿。 |
| 3 | **貪婪 Covetous**。你對物質財富變得痴迷。 |
| 4 | **易碎 Fragile**。當該物品被持用，著裝或激活時，其將產生碎屑、磨損、破塊或開裂。該影響不會對該物品的詞條產生影響。 |
| 5 | **喧鬧 Loud**。該物品在使用時會發出很大的聲響——例如叮噹聲、喊叫聲或者足以產生迴音的鐘聲。 |
| 6 | **變形 Metamorphic**。該物品以微小變化的方式週期性地改變外觀。你無法對這些微小變化進行控制，而這些微小變化亦不妨礙物品的使用。 |
| 7 | **疼痛 Painful**。當使用該物品時，你將經歷一瞬間無害的疼痛。 |
| 8 | **嫌惡 Repulsive**。當你在與該物品互動的時候會感到一陣倒胃口，並且你在擁有該物品期間將一直感到不適。 |
