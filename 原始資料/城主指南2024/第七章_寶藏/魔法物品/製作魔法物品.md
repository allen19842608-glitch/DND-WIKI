# 製作魔法物品

**製作魔法物品 Crafting Magic Items**

玩家手冊內含有關於釀造治療藥水與抄寫法術卷軸的規則。而要製作其他魔法物品，則需遵循下述規則。在這些規則中，“你”指的是正在製作魔法物品的角色。

### 奧秘熟練項 Arcana Proficiency

若要製作魔法物品，則你與你的每位助手都必須具有奧秘技能的熟練。

### 工具 Tools

魔法物品工具表列出了製作每個類別的魔法物品所需的工具。你必須使用所需工具來製作物品且必須具有該工具的熟練。你的每位助手也必須具有該工具的熟練。有關工具的更多信息詳見玩家手冊。

**魔法物品工具 Magic Item Tools**

| **物品種類** | **所需工具** |
| --- | --- |
| 護甲 | 皮匠工具，鐵匠工具，或者織布工具（根據工具描述中所註明的護甲種類進行選擇） |
| 藥劑 | 鍊金工具或者草藥工具 |
| 戒指 | 珠寶匠工具 |
| 權杖 | 木雕工具 |
| 卷軸 | 書法工具 |
| 法杖 | 木雕工具 |
| 魔杖 | 木雕工具 |
| 武器 | 皮匠工具，鐵匠工具，或者木雕工具（根據工具描述中所註明的武器種類進行選擇） |
| 奇物 | 修補工具或者作為魔法物品之基礎的非魔法物品所需求的製作工具 |

### 法術 Spells

若某件魔法物品允許其使用者從該物品中施展任意法術，則你必須在製作該魔法物品的每一天都準備著所有的這些法術。

### 時間與成本 Time and Cost

製作魔法物品所花費的時間與成本均基於該物品的稀有度，如**魔法物品製作時間與成本**表所示。
**每日的工作 Work per Day** 。你必須每日工作8小時以進行製作。如果一件魔法物品需要多日完成，則這些日期不必是連續的。
**助手 Assistants**。角色們可以齊心協力來縮短製作工期。將製作某件魔法物品所需的時間除以參與制作該物品的角色數量。一般來說，只有一名角色可以為你提供幫助，但 DM 可能也會允許更多的助手參與進來。
**原材料 Raw Materials** 。該表內所述成本即代表製作一件魔法物品所需的原材料。由 DM 決定合適的原材料是否可以獲取。在城市中，原材料將有75%的概率可以獲取，而在任何其他聚居區中，該概率為25%。若材料無法獲取，則你必須等待至少7天，然後才能再次勘察該材料的可獲取性。
若某件魔法物品內含一件擁有購買價格的物品（比如一把武器或一套護甲），則你還必須支付該物品的完整費用或者使用玩家手冊中所述的規則以製作魔法物品。例如，要製作一套**+1護甲**（板甲），則你必須花費3500gp，或者花費2000gp 並在一件板甲的基礎上進行製作。

**魔法物品製作時間與成本 Magic Item Crafting Time and Cost**

| **稀有度** | **時間\*** | **成本\*** |
| --- | --- | --- |
| 普通 | 5日 | 50gp |
| 非普通 | 10日 | 200gp |
| 珍稀 | 50日 | 2000gp |
| 極珍稀 | 125日 | 20000gp |
| 傳奇 | 250日 | 100000gp |

\*除**法術卷軸_Spell scroll_** 外，所有消耗品的製作時間與成本均減半。法術卷軸所需的製作時間與成本在玩家手冊中已給出。
