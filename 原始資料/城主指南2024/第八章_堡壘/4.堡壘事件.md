# 堡壘事件

**堡壘事件 Bastion Events**

在一個角色向自己的堡壘下達維護指令後，DM 立刻在堡壘事件 Bastion Events 表格中擲骰以決定在下一個堡壘回合到來之前，這個堡壘中是否有事件、有什麼事件發生了。如果有堡壘事件發生，DM 向控制堡壘的玩家朗讀出所發生的事件（全部事件將在下文表格後詳述）。事件會立刻結算，而事件中需要填補的具體細節由 DM 和玩家共同決定。如果在同一個堡壘回合內，有多個玩家對自己的堡壘下達了維護指令，則為他們分別投擲並獨立結算堡壘事件，無論他們的堡壘是否合併。

堡壘事件只有在堡壘接受維護指令後才會發生，這通常意味著堡壘的主人此時並不在堡壘內。也就是說，擁有堡壘的玩家可以藉此機會代入堡壘僱員的角色，扮演僱員們對這些事件的反應。DM 甚至可以將一次堡壘事件變成一個劇情片段，每個玩家都可以在其中扮演一位僱員（遵循擁有此堡壘的玩家的指導）。

**事件描述 Event Descriptions**

堡壘事件表格中的各類事件，其具體描述在這裡以首字母排序的順序寫明。

**沒什麼大事發生。在下列表格中擲骰以決定具體情況如何，你也可以按自己的喜好增添細節。**

| **d8骰點** | **詳細情況** |
| --- | --- |
| 1 | 事故報告正在減少。 |
| 2 | 天花板上的漏水處被修復了。 |
| 3 | 沒有發現鼠患的痕跡。 |
| 4 | “那傢伙”又把眼鏡弄丟了。 |
| 5 | 你的一位僱員收養了一隻流浪狗。 |
| 6 | 你從收到了朋友寫來的一封令人欣喜的信件。 |
| 7 | 某些愛開玩笑的人一直在往人們的鞋子裡放臭雞蛋。 |

**攻擊 Attack**
**一股敵對勢力襲擊了堡壘，但是被打敗了。**
投擲6d6;每有一個骰子丟出1，便有一位**堡壘衛兵 Bastion Defender**死亡。從你的堡壘衛兵名單中移除死亡的衛兵。如果堡壘內沒有堡壘衛兵，那麼堡壘的一個特色設施（隨機決定）將遭受損害並被迫關閉。
被關閉的特色設施在你的下個堡壘回合中無法使用，之後它會被修復並重新開始運作，這不會花費你任何金錢。

**罪犯僱員 Criminal Hireling**
**你堡壘的一位僱員以前犯下過罪行，但直到執法人員或者賞金獵人帶著他的通緝令出現在堡壘門口時，大家才知道這件事。你可以賄賂他們1d6\*100GP 來保下這位僱員，否則這位僱員會被逮捕。如果這導致你的某個特色設施完全沒有僱員在工作，那麼該特色設施在你的下個堡壘回合中無法使用。之後，新的僱員會來接手工作，這不會花費你任何金錢。**

**機不可失 Extraordinary Opportunity**
**你的堡壘有機會承辦一個重要的節目或慶典、資助一位強大施法者的研究、或者安撫一位蠻橫的貴族。和 DM 一起決定事件的具體細節。**
如果你抓住這次機會，你必須花費500GP 作為成本。作為回報，你的堡壘獲得了廣大的認可或注意，這使得 DM 重新為你投擲一次**堡壘事件 Bastion Event**（再次出現此結果則重骰）。
如果你拒絕這次機會，你無需花費金錢，無事發生。

**友好的來訪者 Friendly Visitors**友好的來訪者造訪了你的堡壘，他們希望借用你堡壘的一個特色設施。他們願意為此支付1d6\*100GP。例如，有一位騎士希望你的鐵匠鋪為他替換一個馬蹄鐵或維修損壞的武器與盔甲；或者有一群智者希望用你的奧術研究室幫助他們解決一個爭論。他們對特色設施的借用不會影響這些設施執行你下達的指令。

**客人 Guest**
**一位友好的客人來暫住在你的堡壘。從下列表格中擲骰決定來的是怎樣的客人，和 DM 一起為這位客人補充細節。**

| **d4骰點** | **客人** |
| --- | --- |
| 1 | 這位客人是一位非常有名的人，他將在這裡暫住7天。暫住結束後，這位客人給予你一封推薦信（見第三章“**名望的標誌**”一節）。 |
| 2 | 客人尋求你的庇護，讓他不會因信仰或犯罪而遭受迫害。他在7天后離開，離開前贈予你1d6\*100GP 作為禮物。 |
| 3 | 客人是一位僱傭兵，這給予你一位額外的堡壘衛兵。這位客人不會佔用設施空間，並且會一直待在這裡，直至被殺或直至你主動送他離開。 |
| 4 | 客人是一個**友好 Friendly**的怪物，例如一條黃銅龍或一位樹人。如果這個怪物在這裡做客時你的堡壘遭受攻擊，怪物會保護你的堡壘，而你不會損失任何堡壘衛兵。怪物會一直呆在這裡，直至他保護一次你的堡壘或直至你主動送他離開 |

**失去僱員 Lost Hirelings**
**你堡壘的其中一個特色設施（隨機決定）失去了它的所有僱員。僱員離開的原因由你決定。該特色設施在你的下個堡壘回合中無法使用。之後，新的僱員會來接手工作，這不會花費你任何金錢。**

**魔法發現 Magical Discovery**
**你的僱員找到或意外創造了一件**非普通 Uncommon**魔法物品。這不會花費你任何金錢。該魔法物品由你選擇，但必須是某種**藥劑 Potion**或**卷軸 Scroll**。**

**難民 Refugees**
**2d4名難民正在逃離怪物攻擊、自然災害、或是其他災難。他們希望在你的堡壘避難。如果你的堡壘沒有足以容納他們的基礎設施，他們會在堡壘外紮營。難民們向你支付1d6\*100GP 作為你接納並保護他們的報酬。他們會一直待在這裡，直至你為他們找到新家，或直至敵對勢力襲擊你的堡壘。**

**請求援助 Request for Aid**
**一位當地領導者號召你的堡壘為他提供助力。這道請求也許是為了找到某個失蹤的人，或者是因為附近有土匪肆虐。如果你選擇幫助他，你必須派出一位或更多堡壘衛兵。你每派出一名堡壘衛兵便投擲1d6。如果擲骰總和大於等於10，則問題被解決了，你獲得1d6\*100GP 作為報酬。如果擲骰總和小於10，那麼雖然問題仍然被解決了，但是你獲得的報酬減半，並且其中一位被派出的堡壘衛兵被殺死了。將該衛兵從你的堡壘衛兵名單中移除。**

**寶藏 Treasure**
**你的堡壘獲得了一件藝術品或一件魔法物品。從下列表格中擲骰決定類別，然後在第七章的相應表格中擲骰決定具體物品。堡壘獲得這件物品的方式由你決定。它可能是從他人那裡繼承而來、來自一位客人或崇拜者的禮物、從別人那裡偷來的、或者撞了大運意外找到的。如果你在堡壘裡，你立刻獲得該物品。反之，該物品會被存放在儲藏室，直至你前來獲取它。**

| 74-75 | 投擲在2500GP 藝術品表格。 |

| 91-98 | 你選擇一張非普通魔法物品表格（奧秘、武具、器具、聖物）並投擲該表。 |
