# 魔法刺青

**魔法刺青****|Magic Tattoo**

魔法刺青作為一種以墨水與針線為紐帶而將魔法與藝術調和的物品，能夠為它的承載者灌輸奇異的力量。魔法刺青在一開始與能夠將魔法調轉至生物體內的魔法針頭聯繫在一起。
只要被刻到一個生物的身體之上，傷害與損壞便無法削弱刺青的功能，即使刺青被破壞。當一個生物接受刺青之時，他可以自定義刺青的外貌。一個魔法刺青可以看起來像個烙印，像個劃痕，像個胎記，像個鱗片的圖案或其他任何面飾的樣子。
一個魔法刺青越稀有，它所佔據一個生物皮膚的空間一般就越大。魔法刺青信息表格給出來關於一個刺青到底有多大的指導。

魔法刺青信息

| **刺青珍稀度** | **覆蓋區域** |
| --- | --- |
| 普通 | 一隻手，一隻腳或者一條肢體的四分之一 |
| 非普通 | 半條肢體或一整塊頭皮 |
| 珍稀 | 一條肢體 |
| 極珍稀 | 兩條肢體，或者胸膛，或者上背部 |
| 傳說 | 兩條肢體與軀幹 |

**解文刺青****|Illuminator's tattoo**
_奇物（刺青）__,_ _普通（需同調）_
該魔法刺青用一根特殊的針製作，呈現為優美書法或者書寫工具的圖案。
_**刺青同調。**_同調此物品時，你需要將針持握，並抵在你想要讓刺青出現的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。
_**魔法書寫。**_ 當 這個刺青在你的皮膚上時，你可以用你的指尖寫字，就如同一支永遠 不會斷墨的墨水筆。
作為一個動作，你可以觸摸一段至多長達一頁的文字，然後說出一個生物的名字。在接下來的 24 小時內，你所觸摸的文字變為對除你和你所說出名字的生物以外所有人隱形。你們中的一個可以通過觸碰文字來解除隱形（無需動作）。
使用後，直到下次黎明前，此動作不能再次使用。

**偽裝刺青****|Masquerade Tattoo**_奇物（刺青）__,_ _普通（需同調）_
該魔法刺青用一根特殊的針製作，顯現為你所想要的樣子。
**_刺青同調。_** 同調此物品時，你需要將針持握，並抵在你想要讓刺 青出現 的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。
**_液態油墨。_**作為一個附贈動作，你可以將刺青變為任意顏色或圖紋，並移動到你皮膚上的任意區域。無論其有著什麼形態，它看起來總是一個刺青。它的尺寸最小可為一枚銅幣，大則可 覆蓋 你的全身。
**_易容自我。_**作為一個動作，你可以使用刺青施展 _易容術_ _Disguise Self_法術（識破 DC13 ）。使用刺青施展這道法術後，直到下次黎明前，不能再次用刺青施展。

**蘊****法刺青** **|** **Spell wrought Tattoo**_奇物（刺青）__,_ _多種稀有度_
該魔法刺青用一根特殊的針製作，包含著一道最高5 環的法術，用魔法針紋在你的身上。為了使用此刺青，你必須持針抵住你的皮膚，並說出命令語。針會變為墨水，化為刺青，在你的皮膚上顯現為你喜歡的樣子。刺青在你身上時，你可以施展那道法術而不需要材料成分。在你施展這道法術時，刺青會在法術的持續時間內發出微光。法術結束時，刺青會從你的皮膚上消失。

**纏爪刺****青****|Coiling Grasp Tattoo**_奇物（刺青）__,_ _非普通（需同調）_
該魔法刺青用一根特殊的針製作，繪有錯雜盤虯的圖案。
刺青同調。同調此物品時，你需要將針持握，並抵在你想要讓刺青出現的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。
纏握觸鬚。當刺青在你的皮膚上時，你可以用一個動作讓刺青伸縮出一團能夠觸及一個15尺內你可見生物的墨黑色觸鬚。目標生物需要進行一次 DC14的力量豁免，豁免失敗則受到3d6力場傷害並被你 _擒抱__Grappled_。作為一個動作，被擒抱的生物可以通過 DC14的力量（運動）或敏捷（特技）檢定以擺脫擒抱。在你使觸手停止（無需動作），或生物與你相距15尺以上或你對另一個生物使用此刺青時，擒抱也會結束。
**魔能爪****刺青****|Eldritch Claw Tattoo**_奇物（刺青）__,_ _非普通（需同調）_
這個繪有爪型或其他鋸齒型圖案的刺青需要用一根特殊的針製作。
**_刺青同調。_**同調此物品時，你需要將針持握，並抵在你想要讓刺青出現的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。
**_魔法打擊。_**只要該刺青在你的皮膚上，攻擊對非魔法攻擊具有抗性或免疫的目標時，你的徒手打擊視為魔法攻擊，並且你以徒手打擊發動的攻擊檢定和傷害擲骰獲得+1加值。
**_魔能巨_****_錘。_**作為一個附贈動作，你可以增強刺青1分鐘。持續時間內，你每次以武器或徒手打擊發動近戰攻擊時，墨水觸鬚會朝著對方噴射而去，使你可以觸及距離你最遠15尺的目標。此外，你的近戰攻擊命中時會造成額外1d6力場傷害。使用後，直到下次黎明前，此附贈動作不能再次使用。

**鬼步刺****青****|Ghost Step Tattoo**_奇物（刺青）__,_ _極珍稀（需同調）_
該魔法刺青用一根特殊的針製作，圖案於你身上各處閃爍、模糊不清。_**刺青同調。**_ 同調此物品時，你需要將針持握，並抵在你想要讓刺青出現的那處皮膚上。當同調完成時，針頭會化為墨水再變成刺青。若你與刺青的同調結束，刺青會消失，針頭會再次出現在你的位置中。
_**鬼靈形態**_ _**。**_刺 青具有 3 發充能，且每天黎明時恢復所有已消耗的充能。刺青在你的皮膚上時，作為一個附贈動作，你可以消耗 1發刺青的充能變為虛體，直到你的下個回合開始。在持續時間內，你獲得以下增益：

1. 你獲得對非魔法武器的鈍擊、穿刺 和揮砍抗性。

2. 你不會被 _擒抱_ _Grappled_ 或 _束縛_ _Restrained_

3. 你可以像穿過困難地形那樣穿過其他生物或物件。如果你在回合結束時處於固體物件內則受到1d10 力場傷害。如果效果結束時你處於固體物件內，你會被排出到最近一處未佔據空間，並且每移動 5尺就受到 1d10力場傷害。
