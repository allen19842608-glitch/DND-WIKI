# 祝福之輝

**祝福之輝 Blessed Radiance**

上層位面的光輝賜福於這一區域。當以下區域中發生以下情況時，可以考慮根據祝福之輝效應表擲骰決定發生的效應。
·一個生物成功通過一次由邪魔或亡靈能力引起的豁免檢定。
·一個生物成為三環及以上牧師或聖武士法術的目標。
·一個生物在對邪魔或亡靈投出了重擊。
·一個生物在為正義事業服務或對抗邪惡力量時經歷了一場頓悟或鼓舞人心的勝利。
**祝福之輝效應 Blessed Radiance Effect**

| **d100** | **效應** |
| --- | --- |
| 01-06 | 以一個角色為中心，20尺半徑、高40尺的柱狀區域內溢滿金色的光芒，然後逐漸消失。該角色和其柱狀區域內的盟友在1消失內獲得_神恩 divine flavor_法術的效果。 |
| 07-12 | 以一個區域內隨機生物為中心，爆發出半徑10尺球狀區域閃耀能量。每個在範圍內的非亡靈恢復3d6生命值。每個範圍內的亡靈受到3d6光耀傷害。 |
| 13-18 | 區域內的異怪、邪魔和亡靈在接下來24小時內的攻擊檢定和屬性檢定具有劣勢。 |
| 19-24 | 區域內每位帶著來自非邪惡位面神靈聖徽的生物在接下來24小時內豁免檢定具有優勢。 |
| 25-30 | 每位區域內的角色都被浸於天界的力量之中。一分鐘內，角色的近戰攻擊在命中時造成額外2d6光耀傷害。 |
| 31-36 | 一件被在區域內的角色攜帶的非魔法簡易或軍用武器在24小時中獲得_瓦解之錘 mace of disruption_的特性。 |
| 37-42 | 一柄自行飛舞、閃爍光芒的利劍（使用怪物圖鑑中的**凌空劍 flying sword**）出現在一隻異怪，邪魔或亡靈的30尺內，並將它們作為攻擊目標。飛劍造成光耀傷害而非揮砍傷害，並總是知曉目標在區域內時的準確位置。當它自身或目標的生命值降低為0時，飛劍會消失。 |
| 43-48 | 一位區域內的角色聽到來自天界的低語或神聖讚歌的詠唱。角色們能夠像使用_通神術 commune_ 對那些聲音提出一個問題。 |
| 49-54 | 區域內的異怪，邪魔和亡靈散發出深紅色的光芒。該生物周圍10尺內為微光，只要攻擊者能看到它們，對它們進行的攻擊檢定便具有優勢，並且該生物無法從隱形狀態中獲益。 |
| 55-60 | 以一個異怪、邪魔或亡靈為中心，天界之力爆發為30尺半徑球狀區域的神聖輝光。每個區域內的生物必須通過 DC15的體質豁免。失敗的情況下，生物受到4d6光耀傷害並陷入目盲。成功的情況下，生物受到一半傷害並不會陷入目盲。 |
| 61-66 | 一位區域內的角色感受到崇高的使命感，並在一分鐘內獲得_祝福術 bless_ 的好處。它也能選擇能看見的另外兩個生物獲得這個法術的好處。 |
| 67-72 | 天界語的隆隆雷音響徹整個區域。每個區域內的生物必須進行 DC15的體質豁免，成功的情況下，生物獲得2d10臨時生命。豁免失敗則在一分鐘內陷入耳聾狀態。 |
| 73-78 | 在1小時中，一個區域內的角色獲得治癒疾病的能力。以一個動作，他們能施展_次等復原術 less restoration_或_高等復原術 greater restoration_而無需任何材料成分。 |
| 79-84 | 整個區域在24小時內具有_聖居 hollow_的效應，並具有一項額外效應（具體由 DM 選擇） |
| 85-90 | 一個天使般的嗓音在這片區域響起。每個生物必須通過 DC15的感知豁免則受到_命令術 command_的趴下效果影響。 |
| 91-95 | 一個區域內的角色永久獲得暗蝕傷害的抗性。如果你已經投出過這一效應，則重新擲骰。 |
| 96-00 | 一個區域內的角色獲得使用牧師的神聖干預特性的能力，且該特性必定成功。角色只能使用該能力一次，並必須在7日之內使用。如果你已經投出過這一效應，則重新擲骰。 |
