# 魔法泉

**魔法泉 Enchanted Springs**

魔法泉裡滿是奇蹟般的泉水，無論它們自地底下隱藏的魔法源頭湧出，還是被魔法存在所祝福。找到這些神秘地點的人們可能在泉中沐浴，或飲用泉水，並獲得泉水魔法的一部分。各類保護泉水或覬覦財富的守護者都有可能在泉的附近潛藏著，驅散走侵入者或為泉水的使用權要價。雖然很多魔法泉有野外神明或妖精的祝福，有些可能被汙染了。這些泉水可能是在很久之前被邪惡存在的膿水所汙染的水源。與潔淨的魔法泉一樣，人們也會去尋找這類被玷汙的地點，為了淨化或奪取它們可怕的力量。無論這樣的泉水是乾淨的還是被汙染的，泉水可能需要被生物飲用，觸碰，或在其中沐浴才能產生效果。用魔法泉的水裝瓶會消除它的魔法效果，除非它是特製的，被一開始賦予泉水魔法的那個存在祝福過的瓶子。

**魔法泉效果**

| **D12** | **效果** |
| --- | --- |
| 1 | 任何觸摸或飲用泉水的生物感到自己被祝福了。該生物獲得祝福術的效果，時長1小時。 |
| 2 | 在水中沐浴的生物會被一層發光的羽毛覆蓋。如果該生物未著裝護甲，羽毛會給它+1的 AC 加值。在1d4天后羽毛會消失。 |
| 3 | 一個觸碰或飲用泉水的生物突然感到一股強烈的要唱歌的衝動。這個生物在接下來24小時中說出的每句話都像歌曲般美妙，並給它的所有魅力檢定提供優勢。 |
| 4 | 在泉水中沐浴能給一個生物帶來高等復原術的益處。作為副作用，該生物的皮膚、頭髮、眼睛皆變成閃閃發光的金色。 |
| 5 | 在泉水中沐浴能給一個生物帶來蛛行術的益處，持續24小時。 |
| 6 | 觸碰或飲用這個泉水的生物長出一根它最喜歡動物的尾巴。尾巴不受該生物的控制，它會按照主人的情緒來移動或作出反應。尾巴在24小時後會消失。 |
| 7 | 任何智力大於等於6的生物在觸碰或飲用這泉水時將獲得感知（洞悉）檢定上的優勢，並能夠施放一次探測思想，無需施法材料。在法術被施放或是24小時過去後，以最先者為準，泉水的效果會逝去。 |
| 8 | 在泉水中沐浴會令1d10株花叢該生物的頭上長出來。花朵聞起來令人喜愛，而且每天這些花的生命力與香氣都會被恢復。花朵會在7天后消失。 |
| 9 | 觸碰或飲用這個泉水的生物長出1d4根眼柄。這些眼柄能讓該生物看清全方面的事物，並給它提供視覺上的感知（察覺）檢定優勢。眼柄在1d4天后消失。 |
| 10 | 在泉水中沐浴的生物會令自己的嗓音變得可怕。接下來的24小時裡，該生物的嗓音會給它帶來魅力（威嚇）檢定上的優勢和魅力（欺瞞）以及魅力（遊說）檢定上的劣勢。 |
| 11 | 觸碰或飲用泉水的生物將會長出一對驢耳朵。這對耳朵將給生物提供聽力上的感知（察覺）檢定優勢。耳朵在1d4天后消失。 |
| 12 | 在泉水裡沐浴會讓一個生物在額頭上長出第三隻眼睛。這顆眼睛給該生物提供60尺的.真實視覺。眼睛在24小時過後會消失。 |
