# 鏡像區

**鏡像區 Mirror Zone**

鏡像區出現在位面和魔法力量交匯之處，會創造出一片反射區域區域。生物，物件和能量在這裡會產生反射、折射、複製或傳送到其他地方。這樣的區域誕生的原因通常是理論存在的鏡像位面入侵了物質位面，或者涉及變化、防護或預言的魔法產生了意想不到的效應。
當區域中出現以下情況時，可以按照鏡像區效應表格擲骰決定出現的效應。
·一個生物打碎了一面鏡子。
·一個生物使用了傳送魔法。
·一個幻象出現。
·一個生物冒充另一個生物。
**鏡像區效應 Mirror Zone Effect**

| **d100** | **效應** |
| --- | --- |
| 01-06 | 區域中的生物開始表現出並非自己的特點。在接下來24小時中，被影響的生物在偽裝自身的時候進行的魅力（欺瞞）檢定具有優勢。 |
| 07-12 | _海市蜃樓 hallucinatory terrain_法術（豁免 DC15）影響了區域中的自然地貌，將它們變成了不同的地形（由 DM 選擇）。 |
| 13-18 | 一個區域中的隨機生物在一分鐘內獲得_閃現術 blink_的法術增益，其身上閃爍著層層疊疊的破碎反光。 |
| 19-24 | 區域內的生物不會形成倒影。對這些生物進行的感知（洞悉）檢定具有劣勢，並且該生物對注意到這一點的對象進行的魅力（遊說）檢定具有劣勢。當他們離開該區域時，他們會重新獲得自己的倒影，該效應將結束。 |
| 25-34 | 區域中1d4個生物的倒影走出鏡子併發起攻擊。倒影是二維的，其形象和映出他們的生物無二。使用**幽影 shadow**作為其數據，但倒影是妖精而非亡靈，它們對鈍擊傷害而非光耀傷害易傷。 |
| 35-40 | 一位區域內的角色獲得_鏡影術 mirrow image_的法術效應。創造出的鏡影有時可能會自行動作或發表自己的看法。 |
| 41-46 | 在接下來24小時內，區域內的傷口會引來玻璃的碎片，造成額外的傷害。任何非不死和構裝的生物在被一次造成穿刺或揮砍傷害的攻擊命中之後都會血流不止，每回合損失1d4生命值。如果流血的生物被另一次這樣的攻擊命中，則流血失去的生命值增加1d4。任何生物都能以一個動作通過 DC10感知（醫藥）檢定來包紮傷口。流血效應也會在生物受到魔法治療後停止。 |
| 47-52 | 區域內的鏡子和其他反光面能作為魔法通道使用。一個觸碰未佩戴的物品中自己影像的生物能夠施展_迷蹤步 misty step_法術，而無須任何法術成分。 |
| 53-58 | 一位角色在接下來24小時內能夠施展一次_探知術 scrying_，他能夠使用鏡子或其他光滑的表面而無須其他任何法術成分。 |
| 59-64 | 在接下來24小時內，一個隨機生物的皮膚變為銀色並閃閃發光。在此期間，該生物對法術進行的豁免檢定具有優勢，對該生物進行的法術攻擊檢定具有劣勢。 |
| 65-70 | 一把劍刃由鏡子碎片做成的長劍或短劍出現在一個隨機生物的60尺內。該武器是一把_血光劍 sword of wounding_（見《城主指南》）。如果使用該武器在一次攻擊中擲出了1或20，則這把武器會碎裂並在本次攻擊之後破壞。 |
| 71-76 | 在接下來24小時內，當區域內的任何人以一次攻擊動作命中一個生物並投擲傷害時，攻擊者必須成功通過 DC13的魅力豁免否則受到自己造成傷害的一半傷害。 |
| 77-82 | 兩個反光的直立圓盤出現在區域內未佔據空間並持續存在一分鐘。每個圓盤直徑6尺，浮在地面以上1尺高度。其中一個出現在隊伍30尺範圍內未佔據空間內。任何通過一個圓盤的生物會立即出現另一個圓盤旁未被佔據的5尺內。 |
| 83-88 | 下一次隊伍中的某個角色照鏡子時，他們的倒影會獲得生命並開口說話。如同施展_預言術 divination_倒影會提供一個問題的答案 |
| 89-94 | 懸浮的鏡子碎片在區域中旋轉，映照出並不實際存在的生物和地點的倒影。在先攻輪到20時（同先攻值最後），碎片會對區域中一個隨機生物進行一次遠程武器攻擊（命中+6）。命中後，該目標受到10（3d6）揮砍傷害。 |
| 95-00 | 一個隨機生物的鏡像出現在其30尺內未佔據空間內。鏡像的外表，遊戲數據和裝備都與該生物相同，並希望殺死自己的原型。如果鏡像死去，它和它所有的裝備都會破碎成鏡子碎片。如果鏡像在1小時內未能殺死該生物，它便會消失。 |
