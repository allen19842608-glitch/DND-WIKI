# 使用本書

**使用本書 Using This Book**

《塔莎的萬事坩堝》提供了一系列的 Dungeons & Dragons 新選項，我們的旅途將跟隨法師塔莎的筆記來探索這些選項。塔莎，即著名法術 _塔莎狂笑術 Tasha's hideous laughter_ 的作者，她的一生在 DND 多元宇宙中被記載為了無數的故事。她被 芭芭雅嘎 Baba Yaga，巫師之母 本人親手養大，並在 灰鷹 Greyhawk 世界各地與其他著名冒險者們結交朋友...外加有時結交死敵——比如魔鄧肯。時過境遷，她成為了巫後，自更名為 伊格薇爾伏 Iggwilv ——一個人們耳熟能詳、敬畏和崇拜的傳奇人物。

本書專為玩家與地下城主所寫，提供了在任何 DND 世界中可用於角色與戰役上的選項，不論你是在灰鷹、在其他官方世設、還是在自創世界觀下都可以使用的選項。
