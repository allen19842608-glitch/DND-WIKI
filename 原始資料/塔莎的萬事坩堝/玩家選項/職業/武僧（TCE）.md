# 武僧（TCE）

**武僧 Monk**
武僧在這一章節中將擁有新的特性和子職。
**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為武僧的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。這些特性能夠被一個一個單獨選走，這意味著你可以使用其中一些、全部或不使用它們。
**專用武器 Dedicated Weapon**
_第2級武僧特性_
_你訓練自己使用各種武器作為武僧武器，而不僅僅是簡易近戰武器和短劍。每當你完成短休或長休時，可以碰觸一件武器，將氣集中在它之中，然後該武器就視為武僧武器，直到你再次使用這個能力。_
所選武器必須符合以下標準：
武器必須是簡易武器或軍用武器。
你必須擁有其熟練項。
不能擁有重型或特殊屬性。

**馭氣以擊 Ki-Fueled Attack**
_第3級武僧特性_
如果你在你的回合中執行動作時花費了1點或更多的氣，則你可以在回合結束前用一個附贈動作以徒手打擊或武僧武器進行一次攻擊。

**加速癒合 Quickened Healing**
**_第4級武僧特性_**
以一個動作，你能消耗2點氣並且投擲一粒武藝骰，你恢復等同於擲骰結果加上你的熟練加值的生命值。

**凝神聚氣 Focused Aim**
_第5級武僧特性_
當你攻擊檢定未命中時，你可以花費1到3點氣來使該次攻擊檢定獲得加值，每點氣的消耗能獲得+2加值，這可能會使原本的未命中改為命中
