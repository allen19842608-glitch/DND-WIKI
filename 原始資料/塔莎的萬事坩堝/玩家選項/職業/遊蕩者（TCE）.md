# 遊蕩者（TCE）

**遊蕩者 Rogue**
在這一節裡，遊蕩者獲得了新的特性和子職業。

**可選職業特性 Optional Class Features**
你可以在達到特定等級時獲得玩家手冊中描述的職業特性。這一部分提供了一些你作為遊蕩者的額外特性。與玩家手冊中的特性不同的是，你不會自動獲得這些特性。在你達到該部分描述的職業特性的需求等級且決定獲得這些特性時，與你的 DM 先商量商量。
**穩定瞄準 Steady Aim**
_第3級遊蕩者特性_
作為一個附贈動作，你在當前回合為你的下一次攻擊提供優勢。你只能在你本回合還沒有移動的時候使用這個附贈動作，而且在你使用這個附贈動作後，你的速度在當前回合裡歸0.
