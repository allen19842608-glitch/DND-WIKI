# 角色選項

**角色選項 Character Options**

當你製作你的 DND 角色時，你在《玩家手冊》中會有一系列的選項可供你打造你希望的那種角色。這一章添加了這些選項，使角色概念具體化成為可能。如果你將這些選項與在《珊娜薩的萬事指南》中的選項混合使用，你創造角色將會獲得巨大的可能性。

這是本章的所記述的可選項：

-   一種依靠修改種族特質來自定義你角色出身的方式。
    
-   關於更換你的子職業的事宜
    
-   奇械師，一個魔法造物的專家
    
-   每個《玩家手冊》中的職業都有的新職業特性與子職業
    
-   為使用專長可選規則的人使用的新專長
