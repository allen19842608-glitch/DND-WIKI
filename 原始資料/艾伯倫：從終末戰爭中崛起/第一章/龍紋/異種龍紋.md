# 異種龍紋（舊版）

## 異種龍紋 Aberrant Dragonmarks

**你的龍紋司掌創生，坎尼斯之子。而我的龍紋可蘊含著毀滅之力。**

**——腐爛巴爾，塔卡南打手**

十二龍紋的力量是可預測的，而其能力大多是創造性的。然而，還有另一種龍紋，它對承載者和周圍的人同樣危險。這種被稱為異種龍紋的紋樣，通常出現在不同龍紋家族的後代身上，因此十二學會嚴令禁止這種結合。但異種龍紋的出現毫無規律可循，它可以出現在任何種族、任何年齡的人身上，與血脈無關。沒有兩個異種龍紋是完全相同的——即便它們擁有相似的力量，表現形式也可能截然不同。
一個角色往往需要很長時間才能學會控制異種龍紋，在此期間，身邊的人很可能會因此受傷。這一事實導致了一種普遍的迷信，即人們認為異種龍紋的擁有者是危險的迷信。
異種龍紋的出現還引發了人們內心深處的另一種恐懼。很久以前，異種龍紋更為常見，其中一些龍紋擁有強大的力量。異種龍紋的領袖哈拉斯·塔卡南能用強大的地震摧毀整座城市；而瘟疫女士則能操縱疾病，指揮蟲群。這使得龍紋家族聯合起來，發動了一場名為龍紋戰爭的大清洗。有人說這是在迫害無辜者，但大多數人因恐懼異種龍紋而選擇袖手旁觀，任由龍紋家族將他們趕盡殺絕。龍紋戰爭之後，異種龍紋的數量銳減，力量也相對較弱。然而，自哀傷日以來，異種龍紋持有者的數量便一直以驚人的速度增加著。

### 專長：異種龍紋 Aberrant Dragonmark

_先決：沒有其他龍紋_
你顯現了異種龍紋。請設定它的外觀和與之相關的缺陷。你獲得下述增益：

-   你的體質屬性值加1，上限20。
    
-   你從術士法術列表中習得一道戲法。然後，從術士法術列表中選擇一道一環法術。你習得該法術，並能通過龍紋施展它。你以此法施展過一次該法術後，必須完成一次短休或長休才能再次通過龍紋施展。對你而言，這些法術的施法屬性是體質。
    
-   當你通過龍紋施展一環法術時，你可以消耗並投擲一顆生命骰。若骰值是偶數，你將獲得等於骰值的臨時生命值。若骰值是奇數，則位於你30尺內的一名隨機生物（不包括你）受到等於骰值的力場傷害。若範圍內沒有其他生物，則你會受到該傷害。
    

同時，你根據異種龍紋缺陷表獲得一個隨機缺陷。

**異種龍紋缺陷 Aberrant Dragonmark Flaws**

| **d8** | **異象** |
| --- | --- |
| 1 | 你的龍紋給你帶來生理上的持續疼痛。 |
| 2 | 你的龍紋會對你低語，但你可能不知道它想對你說什麼。 |
| 3 | 你的龍紋會在你緊張時發出可以聽見的嘶嘶聲。 |
| 4 | 你龍紋周圍的皮膚變得焦黑、覆鱗或萎縮。 |
| 5 | 你周圍的動物感到不安。 |
| 6 | 你使用龍紋時，情緒會劇烈波動。 |
| 7 | 每當你使用龍紋時，你的外觀就會發生細微的變化。 |
| 8 | 你使用龍紋後會做可怕的噩夢。 |

**可選：高等異種之力 Greater Aberrant Powers**
若 DM 允許，擁有異種龍紋專長的角色有機會展現更大的力量。當該角色達到10級時，其有10%的幾率從《城主指南》第七章的選項中獲得一個傳奇恩惠。若角色沒有得到傳奇恩惠，他在下次升級時仍有10%的機會獲得之。
若角色得到了一個傳奇恩惠，隨機或由 DM 決定恩惠的種類。該角色同時永久失去一枚生命骰，其生命值上限相應地減少等於該生命骰骰值加其體質調整值之和（減值至少為1）的值。該減值無法以任何方式恢復。
