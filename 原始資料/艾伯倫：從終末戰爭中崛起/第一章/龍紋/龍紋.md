# 龍紋

一名半身人醫師觸摸一名垂死的人，她額頭上的紋路閃耀著藍色的火光的同時，瀕死者身上的傷口也隨之癒合和消失。一名半獸人賞金獵人引出紋路的力量以探尋他的獵物。一名人類奇械師觸摸創生鍛爐，隨著她手上的紋路發出光芒，這個超凡奇械轟隆隆地運轉起來。上述幾人的身上都有龍紋——一種出現在皮膚上的紋樣，有著任何紋身都無法比擬的鮮豔色彩。
這個紋樣有著神秘的力量，能夠增強持有者執行某些任務的能力。創造龍紋能夠指引鐵匠的手，而陰影龍紋能夠幫助持有者躲開敵人。龍紋的力量也能以一種更激烈的方式表現出來。暴風龍紋的繼承者能夠用一陣風驅散敵人，而有些陰影龍紋的持有者能夠創造幻象。
龍紋不能靠金錢買來，也絕非隨隨便便就能顯現。每個龍紋都與一條特定的血脈聯繫在一起。龍紋一般會在青春期前後浮現，但不是所有的家族後裔都能擁有龍紋。
在很久以前，龍紋持有者們聚集在一起，組成了龍紋家族。數百年以來，這些家族利用他們的天賦建立起了強大的壟斷。例如：只有持有暴風龍紋的李蘭德家族後裔才能駕駛飛艇。這種對於重要行業的控制使得龍紋家族擁有巨大的權力。
在過去，龍紋家族被伽利法聯合王國所壓制。但是在終末戰爭之後，人們對於哪個國家還能夠將自己的意志強加於龍紋家族這一點持懷疑態度。

### 關於家族的一切 All about the Houses

每個家族都有自己的傳統、陰暗面和秘密。下面是一些適用於大多數家族的事實：
**飛地 Enclaves。**大多數家族都在主要城市中有飛地。這些飛地是家族的業務樞紐和據點。在一座城市中，可能會有很多由龍紋家族經營的實業（例如伽蘭達旅館、坎尼斯鐵匠鋪、西維斯通訊站）不過這些實業僅僅提供服務，和家族領導層沒有直接聯繫。
**姓名與頭銜 Names and Ranks。**任何擁有龍紋的家族後裔都能夠在姓上添加“德”前綴，例如梅里克斯·德坎尼斯 Merrix d'Cannith。儘管《寇斯敕令》禁止龍紋家族成員持有貴族頭銜，但家族的地區性領導者仍被稱為男爵。大多數龍紋家族由族長或女族長領導，但也有些由議會領導。
**家徽 Emblems。**每個龍紋家族都有一個家徽——一個會出現在他們的紋章、官方印章、出品貨物，以及任何需要展示官方認證地方的特殊標誌。家族的家徽會出現在下文介紹每個家族的相應頁面。
**十二學會 The Twelve。**十二學會是旨在促進龍紋家族間溝通與合作的組織。
**剝皮者 Excoriates。**剝皮者是被逐出家族的龍紋後裔。
**棄兒 Foundling。**棄兒是浮現出龍紋的非家族成員。
**西伯瑞斯測驗 Test of Siberys。**龍紋會在青春期前後顯現。每個龍紋家族都會對後裔進行一項名為西伯瑞斯測驗的試練。每個家族的試練內容都不盡相同，但也有一個共通之處，那就是這些試練都會把受測驗者放到可能會使龍紋顯現的環境下。龍紋家族的血脈中大約有一半能夠顯現龍紋。
**《寇斯敕令》Korth Edicts。**《寇斯敕令》禁止龍紋家族擁有土地、擁有貴族頭銜或維持軍事力量（鄧內斯家族除外）。這份法令是在很久以前，五國仍然團結的時候制訂的。許多龍紋家族認為，這份法令在終末戰爭已經結束的現代顯得十分過時。

### 創建龍紋角色 Creating a Dragonmarked Character

龍紋只會顯現在特定種族的少數個體身上，這在遊戲數據上被表現為變體種族或亞種。

-   對於人類和半獸人來說，龍紋是一種取代通常種族特質的變體種族。
-   對於半精靈來說，龍紋是一種取代了部分半精靈特性的變體種族。
-   對於矮人、精靈、侏儒和半身人來說，龍紋取代了你的亞種。

也就是說，如果你要車一張精靈，你可以不當木精靈或高等精靈，而是選擇陰影龍紋。
如果你們桌開了專長，本章還有一個與龍紋相關的選項：通過異種龍紋專長（見下）來獲得有限但危險的魔法能力。異種龍紋不會和龍紋家族綁定，任何種族的角色都能夠使用。

龍紋與背景 Dragonmarks and Backgrounds

龍紋與某些特殊的血統綁定在一起，你在選擇龍紋的同時，就表示你的角色與其中一個龍紋家族有血血緣關係。不過，你能夠自己設定你與家族之間的關係。你是在家族中長大的？還是獨立於家族？這最好通過你的背景來表現，請參考以下的選項。
**代理人 Agent。**你和你的家族一直保持著親密的關係。如果你積極地為家族工作，選擇代理人背景會是不錯的選擇。或者，你也能通過貴族背景來表現你與家族領袖之間的血緣關係。
**獨立後裔 Independent Scion。** 你在家族中長大，或受到了家族的訓練，但是你一直與家族保持距離。這意味著你沒有很多特權，但同時也不會受到責任的束縛。公會工匠背景是用來表現你所受家族訓練的好選擇，但也有很多其他選擇，像是陰影龍紋藝人、暴風龍紋水手、哨戒龍紋士兵、抄錄龍紋賢者等等。
**剝皮者 Excoriate。**當龍紋後裔反抗家族時，他們可能會被逐出家門。在過去，你會遭受把顯現龍紋的皮膚從身上剝除的肉刑。雖然現在這種肉刑已經不再實行，但這些被流放者依然被稱為“剝皮者”。如果你是一名剝皮者，請考慮下你是做了什麼才會受到這種刑罰。你是罪犯？騙子？還是從事禁忌研究的賢者？
**棄兒 Foundling。**你的祖先很久以前就已經脫離家族。你和家族沒有任何關係，甚至可能在顯現龍紋之前都不知道自己和家族有血緣關係。作為一名化外之民或流浪兒，你也許對家族一無所知。你能夠成為一名侍僧或隱士，把自己的信仰置於世間紅塵之上，選擇不去尋求和家族之間的聯繫。不過，無論你的選擇是什麼，這都是一個和 DM 談談你的家族在戰役中所扮演角色的機會。你是想讓家族成為你的敵人？完全避免家族帶來的影響？還是雖然身為外來者，依然想通過自己的努力在家族中獲得權勢？

### 龍紋之力 The Powers of the Mark

龍紋賦予持有者一系列與其內在力量相符的能力。你所屬的龍紋種族為你提供一套源自龍紋魔法的特質。如果你是施法者，你的龍紋還能為你的某些法術提供能量或作為施法媒介。每個龍紋的描述中都包含龍紋法術列表，這些法術都源於龍紋的魔法。如果你扮演的角色擁有施法或契約魔法職業特性，你的龍紋法術將被添加到你所有施法職業的法術列表中，從而擴展你的法術選擇。
你也可以將你的龍紋視為你所有法術或職業特性的來源。例如，作為一名擁有醫療龍紋的牧師，你可以說你施展的所有治療和輔助法術都完全來自你的龍紋，抑或你的魔法是龍紋力量與你對神的信仰的結合。作為一名魔契師，你的異種龍紋可能就是你的邪魔宗主，是你所有魔法的來源。這些設定為你的角色增色，但除了增加將龍紋法術添加到你的法術列表外，並不會改變你的角色能力。
在過去幾百年裡，各大龍紋家族開發出了能夠增強和引導龍紋力量的工具，而正是這些物品（其中部分在第五章出現）貢獻了家族經濟強權的絕大部分。

### 龍紋外觀 Dragonmark Appearance

龍紋是一種顯現在皮膚上的紋路，共有十二種已知的龍紋，每一種的紋路和力量都不同。龍紋可以出現在身體的任何部位。一名半精靈的偵測龍紋可能覆蓋在一隻眼睛上，而另一名則出現在手掌心。龍紋通常呈現出鮮明的藍色和紫色，微微發光，甚至會慢慢移動。當龍紋之力被使用時，龍紋會變得溫暖，有時還會發光（但光線不足以照明）。龍紋無法被移除——即使帶有龍紋的肢體被切除，它最終也會在持有者的另一部分身體上重新顯現。所有的龍紋在最初都擁有相似的外觀，但隨著角色的等級提升，並用它施展更強大的魔法時，龍紋的尺寸和複雜性也會隨之增長。
儘管龍紋大體上擁有相同的外觀，但你的龍紋可能具有一些獨特的異象。你可以參考龍紋異象表來尋找靈感。
