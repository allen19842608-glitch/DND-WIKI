# 背景

家族代理人背景非常適合那些和龍紋家族聯繫緊密的角色。

### 家族代理人 House Agent

你已向一個龍紋家族宣誓效忠。如果你擁有龍紋，你很可能來自家族中的某個顯赫家系；若不然，你則是一個渴望通過家族力量謀求前途的外來者。你的主要任務是充當家族的耳目，但隨時可能受召為家族執行任務。這類任務往往充滿危險，但回報也十分豐厚。
**技能熟練：**調查、遊說
**工具熟練：**家族工具熟練表中的兩種工具
**裝備：**一套高檔服裝，一枚家徽璽戒，身份證明和一個裝有20gp 的錢包。

**特性：家族人脈 House Connections**
作為家族的代理人，你總能在家族的飛地獲得食宿，你同行的夥伴們也能受益。當家族給你指派任務時，通常會提供必要的物資和交通工具。除此之外，你在家族中還有許多舊友、導師和競爭對手。當你與家族的業務打交道時，可能會遇到他們中的某位。他們是否願意提供幫助，取決於你目前在家族中的地位。
