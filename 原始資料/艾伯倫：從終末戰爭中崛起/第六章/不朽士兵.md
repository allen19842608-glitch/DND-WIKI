# 不朽士兵

不朽士兵組成了艾倫諾亡者之城的軍隊。他們守衛著不朽議庭的神廟與各貴族家系的府邸，艾倫諾的大使也常有這些亡靈護衛隨行。不朽士兵身披傳家重鎧，手持華麗兵刃。

*中型亡靈，中立善良*

**護甲等級** 17（胸甲、盾牌）

**生命值** 26（4d8+8）

**速度** 30尺

力量　敏捷　體質　智力　感知　魅力

16(+3)　12(+1)　14(+2)　11(+0)　13(+1)　14(+2)

**技能** 運動+5、歷史+4、察覺+3、宗教+4

**傷害易傷** 暗蝕

**傷害抗性** 光耀；非鍍銀武器非魔法攻擊的鈍擊，穿刺，揮砍

**傷害免疫** 毒素

**狀態免疫** 力竭、中毒

**感官** 黑暗視覺60尺，被動察覺13

**語言** 通用語、精靈語

**CR** 2（450XP）

### 動作 Actions

**多重攻擊 Multiattack。**士兵發動兩次矛攻擊。

**矛 Spear。**_近戰或遠程武器攻擊：_命中+5，觸及5尺或射程20/60尺，單一目標。_命中：_6（1d6+3）穿刺傷害，或雙手使用發動近戰攻擊時7（1d8+3）穿刺傷害，若目標是邪魔或亡靈則外加9（2d8）光耀傷害。
