# 瓦倫納動物

瓦倫納精靈相傳，在其祖先與希恩德瑞克的巨人交戰時，精靈德魯伊曾化身野獸馳騁沙場。殘暴而強大的巨人皇帝庫希爾對這些德魯伊施下了詛咒，將其永遠困在了野獸形態中。正如瓦倫納的祖靈會指引麾下武士戰鬥一樣，這些德魯伊的英靈也能喚醒野獸體內的潛能，造就足以匹配英雄的夥伴。
瓦倫納動物受祖靈感召，獲得了超越凡獸的智慧與力量。傳統上，它們會選擇瓦倫納精靈作為夥伴，映射出精靈先祖與獸形先祖間的深厚羈絆。能被瓦倫納動物選中是極高的榮譽，獲得此殊榮的精靈會備受族人尊崇。然而，即便在極少數情況下，動物選擇了非精靈血統的冒險者作為夥伴，這一結果也會被世人普遍認可。
此處列出的瓦倫納動物——飛隼、獵犬與駿馬僅為範例，事實上祖靈可以寄託於多種多樣的野獸形態之中。

### 變體：先祖特質 Ancestral Traits

每隻瓦倫納動物都可用先祖贈禮進行定製，這是一種由其祖靈授予的超自然特質。在先祖特質表中選擇一個特質或在表上擲骰以為每名瓦倫納動物選擇特質。

**先祖特質 Ancestral Traits**

| **d8** | **特質** |
| --- | --- |
| 1 | **轉運 Bestow Luck（1/日）。** 以一個附贈動作，動物選擇一名位於30尺內的可見生物。目標在接下來的一小時內進行的下一次屬性檢定，攻擊檢定或豁免檢定具有優勢。 |
| 2 | **突進 Burst of Speed（充能6）。** 動物可以用一個附贈動作執行疾走動作。 |
| 3 | **偽裝 Camouflage。**動物位於室外期間進行的敏捷（隱匿）檢定具有優勢。 |
| 4 | **測謊 Lie Detector。** 動物能夠察覺位於其15尺內任何生物說的謊。 |
| 5 | **精類血統 Fey Ancestry。** 動物在進行對抗魅惑或恐慌的豁免上具有優勢，且魔法不能使其入睡。 |
| 6 | **妖精步 Fey Step（1/日）。** 動物與其著裝和攜帶的物品一同傳送至多30尺到一處其可見的未被佔據空間。 |
| 7 | **迅捷 Quickness（充能6）。**動物可以用一個附贈動作執行閃避動作。 |
| 8 | **遮影步 Shrouded Step。** 除非通過魔法方式，否則動物無法被追蹤；且其行進不會留下任何足跡或痕跡。 |
