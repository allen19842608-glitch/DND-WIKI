# 日常魔法物品

得益於龍晶的存在，各種普通魔法物品——包括《珊娜薩的萬事指南》中所列出的那些——在科瓦雷大陸上隨處可見。

### 購買普通魔法物品 Buying a Common Magic item

普通魔法物品在艾伯倫的大多數聚落均有售賣。DM 決定現有的庫存，DM 也可以讓購物者進行一次群體智力（調查）檢定，以尋找擁有目標物品存貨的店鋪或攤販。該檢定的 DC 在城市中為10，鄉鎮中為15，村莊中則為20。若檢定失敗，則至少需經過24小時後方可在該聚落再次尋找同一件物品。
普通魔法物品的價格由 DM 設定，或通過隨機擲骰決定：2d4×10gp，若為藥水或卷軸等消耗品則價格減半。   

### 創造普通魔法物品 Creating Common Magic Items

通常情況下，在艾伯倫創造魔法物品需遵循《城主指南》或《珊娜薩的萬事指南》中的製作規則。但如果你擁有一塊龍晶，便能更輕鬆地製作出一件普通魔法物品。
要利用龍晶製作此類物品，角色必須擁有製作該物品非魔法版本所需的工具熟練項，或擁有奧秘技能的熟練。例如，擁有草藥工具熟練的角色可以製作治療藥水。熟練於奧秘技能的施法者可以為其已知的法術抄錄一份法術卷軸，且必須提供該法術所需的所有材料成分。抄錄在卷軸上的戲法如同施法者是1級施法者一般運作。
創造普通魔法物品表列出了利用龍晶製作此類物品所需花費的時間與成本，龍晶在製作過程中會被消耗。製作時長可以分攤到多個工作日中，且不必連續。

**創造普通魔法物品 Creating Common Magic Items**
****

| **普通魔法物品** | **時間** | **成本** |
| --- | --- | --- |
| _法術卷軸 Spell Scroll_（戲法） | 8小時 | 15gp |
| _治療藥水 Potion of Healing_ | 8小時 | 25gp |
| 任何其他普通魔法物品 | 32小時\* | 50gp\* |

\*對於藥水或卷軸這樣的消耗品而言減半。

### 製作難題 Crafting Complications

對於不是普通稀有度的物品而言，若 DM 使用了《珊娜薩的萬事指南》中的製作規則，那麼製作過程可能會出現難題。每投入五個工作周（25日）進行物品製作，就有10%的幾率出現難題。《珊娜薩的萬事指南》給出了若干種可能的難題，或者你也可以使用下方的艾伯倫製作難題表。

**艾伯倫製作難題 Eberron Crafting Complications**

| **d6** | **難題** |
| --- | --- |
| 1 | 坎尼斯家族或其他龍紋家族對你的工作產生了興趣。他們是把你視為威脅，還是被你的技藝所折服？ |
| 2 | 一場意外創造了一個臨時的顯能區（關於顯能區的信息見第四章“存在位面”）。 |
| 3 | 你需要獲取額外的稀有組件來完成工作。該去冒險了！ |
| 4 | 位面之間變幻的平衡干擾了你的工作；你必須等待當前的位面交匯狀態發生改變。這會使你的工作進度延遲2d6天。 |
| 5 | 你的行為引起了金權會、密閣、翡翠利爪或塵主的注意。 |
| 6 | 你的物品變成了智能物品（關於智能物品的規則見《城主指南》第七章）。 |
