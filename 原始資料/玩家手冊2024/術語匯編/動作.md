### 動作 Action
在你的回合，你可以執行一項動作。你可以選用下列的這些動作項來執行，你也可以選用某些特性為你提供特殊動作項來執行。另見第一章（“**動作**”）。這些動作在術語彙編的其他條目中皆有釋義：

| | | | |
| :---: | :---: | :---: | :---: |
| 攻擊 | 疾走 | 撤離 | 迴避 |
| 協助 | 躲藏 | 魔法 | 影響 |
| 搜索 | 研究 | 預備 | 操作 |

### 攻擊 Attack【動作】
當你執行攻擊動作時，你可以用你的武器或徒手打擊進行一次攻擊檢定。
**裝備武器與卸下武器 Equipping and Unequipping Weapons。**作為攻擊動作的一部分，每當你發動一次攻擊時，你都可以裝備或卸下一把武器。你可以在此次攻擊之前或之後裝備/卸下武器。如果你在發動一次攻擊前裝備一把武器，你不需要以這把武器發動這次攻擊。裝備武器的行為包括從鞘（或類似的收納物）中拔出你的武器以及撿起一把武器。卸下武器的行為包括把武器收入鞘（或類似的收納物）中、收起來以及丟下它。
**攻擊間移動 Moving between Attacks。**你的回合中，如果你具有某些可以使你在攻擊動作中發動複數次攻擊的特性（例如**額外攻擊 Extra Attack**），你可以使用一部分或全部移動力，在這幾次攻擊之間進行移動。

### 疾走 Dash【動作】
當你執行疾走動作時，你可以獲得供當前回合使用的一些額外移動力。額外移動力的量等於你的速度（在一切調整值計算完後）。舉個例子，如果你有 30 尺速度，而你執行了疾走動作，那麼當前回合你就可以移動至多 60 尺距離。如果你的速度被從 30 尺降至 15 尺，那麼在你執行了疾走動作的回合中你只能移動至多 30 尺。
如果你擁有特殊速度（例如飛行速度或游泳速度），你可以使用該速度代替你的速度來執行疾走動作。每次你執行疾走動作時你都需要選擇具體使用哪個速度。另見“**速度 Speed**”。

### 撤離 Disengage【動作】
執行撤離動作後，當前回合的剩餘時間內，你的移動不會引發借機攻擊。

### 迴避 Dodge【動作】
執行迴避動作時，你將獲得以下增益：直至你的下個回合開始，任何以你為目標的攻擊檢定具有劣勢，除非你看不到攻擊者，且你進行的敏捷豁免檢定具有優勢。
如果你陷入**失能**或你的速度降至了 0，你會失去這些增益。

### 協助 Help【動作】
當你執行協助動作時，你可以做到以下兩種效果之一。
**輔助一次屬性檢定 Assist an Ability Check。**選擇一項你的技能熟練或工具熟練，並選擇一個與你之間距離不遠，至少你足以口頭/物理上輔助的盟友。那個盟友下一次使用你所選擇的技能/工具進行的屬性檢定具有優勢。在你的下個回合開始前，若該盟友仍未使用掉這一輔助效果，輔助效果會消失。DM擁有你是否可以輔助的最終解釋權。
**輔助一次攻擊檢定 Assist an Attack Roll。**你迅速地虛晃位於你 5 尺內的一個敵人，令下一次由你的某名盟友對該敵人進行的攻擊檢定具有優勢。這一輔助效果會在你的下個回合開始時消失。

### 躲藏 Hide【動作】
執行躲藏動作時，你嘗試將自己隱蔽起來。為了執行躲藏，你必須成功通過一次 DC 15 的敏捷（隱匿）檢定，你只有身處重度遮蔽之中或者處於四分之三掩護或全身掩護之後，還不在任何敵人的視野內（如果你能看到一個生物，你就可以判斷它是否能夠看見你），才能這麼做。
若檢定成功，躲藏期間你處於隱形狀態。記下你的檢定結果總值，這將成為其他生物通過一個感知（察覺）檢定來找到你的 DC。
發生以下情況時，你結束躲藏：你發出了高於低語的響聲；敵人找到了你；你進行一次攻擊檢定；你施展了一個帶有言語成分的法術。

### 魔法 Magic【動作】
當你執行魔法動作時，你施展某個施法時間為動作的法術、使用某個需要使用魔法動作的特性或是使用一個“需要魔法動作來激活”的魔法物品。
若你需要施展一道施法時間為 1 分鐘以上的法術，你必須在施展該法術期間的每個回合中都執行魔法動作，且你必須為其保持專注。若你的專注被打斷，法術將施展失敗，但你不會因此消耗法術位。另見“**專注**”。

### 影響 Influence【動作】
藉由影響動作，你嘗試要求一個怪物去做些什麼事。請描述或扮演岀你與怪物之間是如何交流的。你是在欺騙它？恐嚇它？取悅它？還是和藹地說服它？然後，根據你與怪物的互動，由 DM 來決定這怪物願意、不願意還是猶豫不決，這三種情況將決定你是否需要進行屬性檢定，具體如下所述。
**願意 Willing。**如果你要求的方向與該怪物的欲求一致，那麼你不需要進行屬性檢定，而怪物會以它偏好的方式去完成你的要求。
**不願意 Unwilling。**如果你的要求對於怪物來說是無法接受的，或者有悖於其陣營，那麼你也不需要進行屬性檢定，因為它不會同意的。
**猶豫不決 Hesitant。**如果怪物對於你要求去做的事情有些猶豫，你必須進行一次屬性檢定。此次檢定會受到怪物的態度（冷漠、友好、敵對）影響，這些態度均在術語彙編中有定義。**影響檢定**表上基於你與怪物的互動方式，建議了所需進行的屬性檢定，但具體的檢定類型由 DM 來選擇。檢定的 DC 默認為 15 或怪物的智力屬性值，兩者取高者。檢定成功時，怪物會按你要求的去做。檢定失敗時，你必須等待 24 小時（或者 DM 設定的一段時間）後才能再次以影響動作向它要求。

**影響檢定 Influence Checks**
| 屬性檢定 | 互動方式 |
| :---: | :--- |
| 魅力（欺瞞） | 欺騙一個可以理解你的怪物 |
| 魅力（威嚇） | 恐嚇一個怪物 |
| 魅力（表演） | 取悅一個怪物 |
| 魅力（遊說） | 說服一個可以理解你的怪物 |
| 感知（馴獸） | 和藹地勸誘隻野獸或怪獸 |

### 搜索 Search【動作】
當你執行搜索動作，你進行一次感知檢定來搜索某個“並不顯眼”的東西。根據你嘗試搜索的具體內容，**搜索**表提供了你在執行此動作時可用技能的建議。

**搜索 Search**
| 技能 | 要搜索的東西 |
| :---: | :--- |
| 洞悉 | 生物的心理狀態 |
| 醫藥 | 生物的傷勢，或是死因 |
| 察覺 | 被藏匿的生物/物件 |
| 求生 | 蹤跡，或是食物 |

### 研究 Study【動作】
當你執行研究動作時，你進行一次智力檢定來研究你的記憶、一本書、一條線索或是其他來源的知識，並回想起有關這一事物的重要信息。
知識範圍表基於智力檢定相關的知識範圍，給予了適用何種技能的建議。

**知識範圍 Area of Knowledge**
| 技能 | 範圍 |
| :---: | :--- |
| 奧秘 | 法術、魔法物品、魔能符號、魔法傳承、存在位面、特定生物（異怪、構裝、元素、妖精、怪獸） |
| 歷史 | 歷史事件和歷史人物、古文明、戰爭、特定生物（巨人、類人） |
| 調查 | 陷阱、密文、謎語、設備 |
| 自然 | 地形、植物、天氣、特定生物（野獸、龍類、泥怪、植物） |
| 宗教 | 神祇、宗教層級和儀式、聖徽、教團、特定生物（天族、邪魔、亡靈） |

### 預備 Ready【動作】
你可以執行預備動作來等待某個特定事件到來，再進行你的行動。為此，你需要在自己回合中執行預備動作，使可以在自己的下個回合開始前執行一項反應。
首先，你需要設定“何種可感知的事件能觸發你的反應”。然後，作為你對該事件的響應，你選擇你當時要執行的動作或是選擇移動等於你速度的距離。舉個例子，你可以設定“當那個邪教徒踩上了活板門時，我就拉下打開活板門的拉桿”或是“當那個喪屍走到我身旁時，我就跑開”。
當觸發事件發生時，你可以選擇在觸發事件發生後緊跟著執行你設定的響應動作或是選擇無視該觸發事件。
當你預備一道法術時，你需要如常施展它（消耗如常施展它所需的各種資源）來維持其能量，並在觸發事件發生時用你的反應去釋放它。為預備一道法術，這道法術的施法時間必須是動作，且你在維持法術魔法能量期間必須為其保持專注（此專注至多持續至你的下個回合開始時）。如果你的專注被打斷，法術將消散，且不會產生任何效應。

### 操作 Utilize【動作】
通常，你會在做其他事的同時與一件物品進行交互，例如作為攻擊動作的一部分來拔出一把劍。當一個物件需要一個動作才能使用時，你需要為其執行操作動作。
