# 你需要什麼

下文列出了你與一些朋友玩 DND 時所需要的東西（標準的一桌冒險按五個人來計）：
**地下城主 Dungeon Master 。**一名玩家擔任**地下城主**（DM）的角色，他是遊戲中的主要敘事者與裁判。DM 為玩家的角色們創造冒險，而角色們在其中闖險境，尋前路。DM 也要敘述角色們的經歷歷程，以及扮演一路上遇到的敵友。即使 DM 會讓角色們面臨挑戰，地下城主也始終會盡力讓大家感到開心。
**玩家們 Players。**每個玩家都創建一名冒險者，與其他玩家的冒險者結成小隊。小隊可能會通力合作探索黑暗的地下城、城市廢墟、鬧鬼的城堡、失落的廟宇、被熔岩覆蓋的山峰或是其他 DM 及述的地方。冒險者也會解決謎題、與其他角色交談、與奇妙怪物戰鬥以及發現魔法物品或是別的財寶——所有一切都能為彼此提供樂趣。

你同樣還需要實體形式或 DndBeyond.com 網站中的電子版資源：
**《玩家手冊 Player's handbook****》** **。**這本書是遊戲規則的必要參考，也會指導你創造你的冒險者。
**《城主指南 Dungeon Master's Guide》和《怪物圖鑑****Monster Manual** **》。**前者能在 DM 創造與運行冒險時提供指導，後者則提供了上百種怪物來充實這些冒險。
**骰子 Dice。**你需要一套多面骰（詳見第一章）。你可以從桌遊玩具店和網店找到這樣的骰子。也可以使用擲骰子的應用程序。
**角色卡 Character Sheet 。**為了記錄你的角色的重要信息，你需要一張角色卡，它既可以是你寫筆記的簡單紙片，也可以是功能豐富的電子記錄。

DM 可能也會找到這些有用的配件：
**城主帷幕 DM Screen 。**很多 DM 喜歡使用帷幕擋住玩家，不讓玩家看他們的筆記和擲骰。偷看帷幕之後是很失禮的！
**微縮模型和格子戰鬥地圖 Miniatures and Battle Grid 。** 一些地下城主使用格子戰鬥地圖和微縮模型來運行戰鬥遭遇，因為它們讓所有人的行動直觀化。無論是用完即換的紙製地圖還是可擦寫的海報紙地圖，只要上邊標出了1英寸見方的格子，都可以是格子戰鬥地圖。微縮模型從簡單的小指示物到充滿細節的雕塑都可以。也可以使用線上地圖與微縮模型，比如 DndBeyond.com 網站中就有。

**旁觀學習 Learn by Watching**
看看別人怎麼玩是學習 DND 基礎規則的良好方式。網上有 DND 的視頻可看，它們展示了這個遊戲所能提供的諸多可能性。觀看時，你應當留意玩家用什麼方式讓隊伍裡的所有人都感到有趣。在遊玩 DND 時，你需要取悅的觀眾只有你自己和你的隊伍。
