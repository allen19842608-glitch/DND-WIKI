# 六項屬性

所有的生物——無論玩家角色還是怪物——都有六項屬性用於衡量其身體和精神特徵，如**屬性描述**表所示。

**屬性描述 Ability Descriptions**

| **屬性** | **數值衡量……** |
| --- | --- |
| **力量 Strength** | 力氣 |
| **敏捷 Dexterity** | 靈活性、反應能力和平衡感 |
| **體質 Constitution** | 健康程度和耐力 |
| **智力 Intelligence** | 推理能力和記憶力 |
| **感知 Wisdom** | 洞察力和精神堅韌程度 |
| **魅力 Charisma** | 自信、儀態以及吸引力 |

### 屬性值 Ability Scores

每項屬性都有從1到20的數值，不過有些怪物的數值最高能達到30。這個數值代表屬性的強弱，**屬性值**表概述了這些數值的含義。

**屬性值 Ability Scores**

| **數值** | **含義** |
| --- | --- |
| 1 | 這是通常情況下屬性數值可以降到的最低值。如果一個效應將數值降低到0，那麼這種效應自身就會解釋發生了什麼。 |
| 2-9 | 這代表能力較弱。 |
| 10-11 | 這代表人類的平均值。 |
| 12-19 | 這代表能力較強。 |
| 20 | 除非某特性另有說明，否則這已經是冒險者的屬性數值所能達到的最高值。 |
| 21-29 | 這代表才能非凡 |
| 30 | 這是屬性數值能達到的極限 |

### 屬性調整值 Ability Modifiers

每當你使用某項屬性進行**D20檢定**時，你都需要應用該屬性對應的調整值(詳見“**D20檢定**”)。屬性調整值由屬性自身的數值決定，具體詳見下方**屬性調整值**表。

**屬性調整值 Ability Modifiers**

| **數值** | **調整值** | **數值** | **調整值** |
| --- | --- | --- | --- |
| 1 | \-5 | 16-17 | +3 |
| 2-3 | \-4 | 18-19 | +4 |
| 4-5 | \-3 | 20-21 | +5 |
| 6-7 | \-2 | 22-23 | +6 |
| 8-9 | \-1 | 24-25 | +7 |
| 10-11 | 0 | 26-27 | +8 |
| 12-13 | +1 | 28-29 | +9 |
| 14-15 | +2 | 30 | +10 |
