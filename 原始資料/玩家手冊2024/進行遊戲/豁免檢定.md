# 豁免檢定

豁免檢定——也簡稱豁免——代表試圖去規避或抵抗危險的行為，比如烈焰爆裂、有毒氣體的氣浪或是試圖擾亂你思維的法術。通常情況下，你無法主動選擇進行豁免，而是因為你的角色或是怪物（當你作為 DM）處於危險之中時才不得不進行豁免。豁免的結果會在導致該豁免的效應中詳寫。

如果你不想抵抗某效應，你可以選擇不擲骰來直接判定為失敗。

**屬性調整值 Ability Modifier**
**豁免檢定根據其使用的屬性調整值命名：**體質**豁免檢定、**感知**豁免檢定等等。不同的豁免檢定應用於不同類型的影響，如**豁免檢定示例**表所示。**

**豁免檢定示例 Saving Throw Examples**

| **屬性** | **進行豁免用來……** |
| --- | --- |
| **力量** | 承擔對身體的直觀衝擊 |
| **敏捷** | 躲開有害效應 |
| **體質** | 承受毒性的危害 |
| **智力** | 識別虛假的幻象 |
| **感知** | 抵抗精神攻擊 |
| **魅力** | 維持你的存在 |

**熟練加值 Proficiency Bonus**
**如果你擁有某個豁免的熟練，你則需要將**熟練加值**加到你的豁免檢定中。見本章後面的“**熟練**”。**

**難度等級 Difficulty Class**
**豁免的難度等級取決於導致該豁免的效應或是 DM。例如，如果一個法術迫使你進行豁免，其豁免的 DC 由施法者的施法屬性和**熟練加值**決定。怪物令你進行豁免的能力則會標明其 DC。**
