# 動作

當你進行除移動或交流以外的行動時，你通常需要執行一個動作。下方的**動作**表列出了遊戲中主要的動作選項，其具體定義詳見術語彙編。

**動作 Action**

| **動作** | **概述** |
| --- | --- |
| **攻擊** | 使用武器發動攻擊或發動**徒手打擊** |
| **疾走** | 在回合餘下的時間裡，給予自己等同於自身**速度**的額外移動力。 |
| **撤離** | 在回合餘下的時間裡，你的移動不會引發**藉機攻擊**。 |
| **迴避** | 直至你的下個回合開始，對你進行的攻擊檢定具有**劣勢**，並且你進行的敏捷豁免檢定具有**優勢**。你會在陷入**失能**狀態或速度為0時失去這些增益。 |
| **協助** | 協助另一個生物進行屬性或攻擊檢定，或進行急救。 |
| **躲藏** | 進行一次**敏捷**（**隱匿**）檢定。 |
| **影響** | 通過 **魅力**（**欺瞞**、**威嚇**、**表演**或**遊說**）檢定，或是**感知**（**馴獸**）檢定來改變一個生物的態度。 |
| **魔法** | 施展一道法術、使用一個魔法物品或是使用一個魔法特性。 |
| **預備** | 做好執行某個動作的準備，該動作的觸發時機或情況由你決定。 |
| **搜索** | 進行一次**感知**（**洞悉**、**醫藥**、**察覺**或**求生**）檢定。 |
| **研究** | 進行一次**智力**（**奧秘**、**歷史**、**調查**、**自然**或**宗教**）檢定。 |
| **操作** | 使用一個非魔法物件。 |

玩家角色和怪物也可以進行除這些動作以外的事情。有很多職業特性和其他能力都會提供額外的動作選項，此外你也可以即興做其他動作。當你描述一項規則中沒有的動作時，**地下城主**會告訴你這個動作是否可行，以及你是否需要進行某種**D20檢定**。

### 一次一件事 One Thing at a Time

這個遊戲通過動作來衡量你同一時間內能做多少事情。你一次只能執行一個動作。這條準則在戰鬥中尤為重要，在本章後面的“**戰鬥**”部分有所描述。
當然，動作也會發生在除戰鬥以外的情況，例如：交涉時，你可以嘗試**影響**一個生物，或是通過**搜索**動作來判斷生物的肢體語言，但你不能同時進行這兩個行為。或是當你探索地城時，你也不能同時一邊使用**搜索**動作來尋找陷阱，一邊使用**協助**動作來幫助另一個正在（執行**操作**動作來）嘗試打開卡住的門的角色。

**你的角色會做什麼？ What Would Your Character Do?**
在你遊玩的過程中，不妨問問自己：“我的角色應該做些什麼？”扮演一個角色需要設身處地地代入角色、理解角色各個行為背後的驅動力以及搞清這些角色動機該如何轉化為行動。在 DND 中，一切都發生在僅存於幻象中的奇幻世界，試想一下你的角色在面對這些情況時，又會做出怎樣的反應？關於這條建議，有一個重點你需要注意：避免讓角色做出會摧毀其他玩家與 DM 的樂趣的決定。踐行那些能夠令你和你的朋友感到愉快的抉擇吧。
