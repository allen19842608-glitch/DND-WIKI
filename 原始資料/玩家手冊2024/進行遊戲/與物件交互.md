# 與物件交互

與物件交互通常很好判定。玩家只需要告訴 DM 角色打算做什麼——例如拉動拉桿、開門，接著 DM 來描述會發生什麼。但有時，物品的使用方式也需要遵循規則的規定，具體細則如下。

**什麼是物件？ What Is an Object？**
**僅從規則的角度來說，**物件 object**是無生命的、獨立的物品，例如門、窗、劍、書、桌、椅或石頭。建築或載具等存在無法算作物件，因為它們由多個物件複合而成。**

**短時物件交互 Time-Limited Object Interactions**
**在時間緊迫的情況下與物件進行交互時，例如在戰鬥中，與物件的交互將受到限制：生物每回合只能無需動作地交互一次。這次交互必須發生在生物移動或動作的途中。任何額外的交互都需要玩家執行**操作**動作，在本章後面的“**戰鬥**”有所描述。**

**尋找隱藏物件 Finding Hidden Objects**
**當你的角色嘗試尋找隱藏起來的物件時，比如某扇密門或某個陷阱時，DM 一般會要求你進行一次感知（**察覺**）檢定，前提是你有描述你的角色在隱藏物件的周邊進行搜索。成功則你尋得該物件或其他一些重要的細節信息，又或者是兩者皆有。**
若在你的描述中，你的角色正搜尋的位置不在那個隱藏物件周圍，那麼不管檢定結果如何，這次感知（**察覺**）檢定都無法使你找到該物件。

**攜帶物件 Carrying Objects**
**通常情況下，你不需要擔心自己到底能攜帶多沉的裝備和寶物。但如果你打算攜帶異常沉重的物件或過多較輕的物件時，DM 可能會要求你遵循術語彙編中的**載重**規則。**

**破壞物件 Breaking Objects**
**以一個動作，你能隨意打破甚至摧毀一個脆弱的非魔法物件，例如一盞玻璃容器或一張紙。如果你試圖對更堅韌的東西造成傷害，DM 可能會採用術語彙編中的**破壞物件**規則。**
