# 獲得法術

## 獲得法術 Gaining Spells

要想施展一道法術，你必須在自己的意識裡準備了它，或是使用一件能令你使出該法術的魔法物品（如*<u>法術卷軸Spell Scroll</u>*）。如果你能施法，那麼你的特性會列出你能使用哪些法術、你是否始終準備著某些特定法術、以及你是否可以更改你準備的法術列表。

**準備法術 Preparing Spells**  
如果你具有由一環或更高環階的法術組成的準備法術列表，你的施法特性會列出你能在何時更改這份列表，以及更改法術列表時能更改的法術數量，如職業的準備法術表所示：

**職業的準備法術**

| **職業** | **何時可更改** | **單次更換數量** |
| --- | --- | --- |
| 吟遊詩人 | 升級時 | 一個 |
| 牧師 | 完成一次長休時 | 任意 |
| 德魯伊 | 完成一次長休時 | 任意 |
| 聖騎士 | 完成一次長休時 | 一個 |
| 遊俠 | 完成一次長休時 | 一個 |
| 術士 | 升級時 | 一個 |
| 魔契師 | 升級時 | 一個 |
| 法師 | 完成一次長休時 | 任意 |

大多數可施展法術的怪物無法更改其準備法術列表，但dm可以自行更改。

**始終準備的法術 Always-Prepared Spells**  
某些特性會給予你某道你始終準備的法術。如果你擁有一個可供更改的準備法術列表，那麼你始終準備的法術將不會計入該列表中存在的法術數目。

著甲施法 Casting in
Armor  
當你在著裝護甲期間施展法術時，你必須具備該種護甲的受訓，否則你將因護甲的妨礙而無法施展法術。
