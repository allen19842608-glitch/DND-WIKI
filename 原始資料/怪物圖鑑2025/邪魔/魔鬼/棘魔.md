# 棘魔 Spined Devil

擾亂與懷疑之魔鬼

**棲息地：** 異界（九層地獄）；**寶藏：**無

棘魔又被稱為**斯皮納魔 Spinagons**；它們隱匿在下層位面的陰影之中，為它們的地獄主子搜尋秘密。棘魔偏好於從空中發起攻擊，與敵人保持距離，向敵人拋擲惡毒的尖刺。棘魔收集信息，用這些秘密來控制凡人，或是引誘更強大的魔鬼。擲一次棘魔情報表，或從中選擇一個結果，以此啟發棘魔正在尋找或已經獲取了怎樣的信息。

**棘魔情報**

| **1d6** | **棘魔正尋求關於……的信息** |
| --- | --- |
| 1 | 神器，神器的位置以及神器的持有者 |
| 2 | 其他魔鬼或是地獄的同盟者的背叛 |
| 3 | 具有影響力的領導人所犯下的罪行或欺瞞 |
| 4 | 隱姓埋名者的真實身份 |
| 5 | 跨位面軍隊的動向 |
| 6 | 由神明隱藏起來的預言或秘密 |

### 特性 Traits

**飛掠 Flyby。**棘魔飛行離開敵人的觸及範圍時不會引發藉機攻擊。

**魔法抗性 Magic Resistance。**棘魔對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**棘魔使用地獄叉刺或尾刺發動共計兩次攻擊。

**灼熱叉刺 Searing Folk。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_5（1d6+2）穿刺傷害外加3（1d6）火焰傷害。

**地獄尾刺 Tail Spine。**_遠程攻擊檢定：_+4，射程20/80尺。_命中：_4（1d4+2）穿刺傷害外加3（1d6）火焰傷害。
