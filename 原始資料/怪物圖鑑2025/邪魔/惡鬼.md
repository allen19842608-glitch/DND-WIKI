# 惡鬼 Oni

折磨惡人的惡人

**棲息地：**森林，城市；**寶藏：**任意

惡鬼是居住在黑暗森林與各類荒野中的難以捉摸的實體。惡鬼能變形成無辜的人，還能隱去身形移動，惡鬼會以此侵擾周遭的社區，佔據孤僻的道路。惡鬼非常喜歡去騷擾那些有信仰的傢伙，它會考驗這群傢伙對其信仰的虔誠度；惡鬼還喜歡折磨那些自私自利的傢伙，讓惡人為自己的惡行付出代價。聰明的社區往往會設立守護神像、舉辦一年一度的各種儀式、或是流傳一些風俗迷信來阻止惡鬼的侵擾。雖然這種情況很少見，但確實，有些惡鬼會漸漸在社區的這些行為下成為他們的“朋友”，並守護著這片社區未來的世世代代免遭其他威脅。
對於那些不尊重惡鬼或不尊重其他超自然力量的村莊，惡鬼會以自己的方式懲戒他們。擲一次惡鬼之禍表或從中選擇一個結果，以此啟發惡鬼在這些社區裡如何作孽。

**惡鬼之禍**

| **1d4** | **惡鬼在此作的孽有……** |
| --- | --- |
| 1 | 魅惑人心，讓其演繹下流的把戲。 |
| 2 | 霸佔某座橋、某扇大門、某個神龕、或是某條小徑，並意圖吃掉所有膽敢接近之人。 |
| 3 | 蠱惑周遭的怪物，令它們襲擊居住地。 |
| 4 | 持續不斷的打鼓，讓所有人無法入睡。 |

### 特性 Traits

**再生 Regeneration。**若惡鬼至少擁有1生命值，則其在自己回合開始時回覆10生命值。

### 動作 Actions

**多重攻擊 Multiattack。**惡鬼發動兩次爪擊或噩夢射線攻擊。其可以將其中一次攻擊替換為使用施法。

**爪擊 Claw。**_近戰攻擊檢定：_+7，觸及10尺。_命中：_10（1d12+4）揮砍傷害，外加9（2d8）點暗蝕傷害。

**噩夢射線 Nightmare Ray。**_遠程攻擊檢定：_+5，射程60尺。_命中：_9（2d6+2）心靈傷害，且目標陷入恐慌狀態，直至惡鬼的下個回合開始。

**變形 Shape-Shift。**惡鬼變形為小型或中型的類人生物或大型的巨人生物，或變回其真實形態。除體型以外，其各形態下游戲數據均相同。惡鬼著裝或攜帶的任何裝備都不會隨之變化。

**施法 Spellcasting。**惡鬼施展以下一道法術，無需材料成分且使用魅力作為施法屬性（法術豁免 DC13）：

**_每項1/日：_** _魅惑類人 Charm Person_（二環版本）、 _黑暗 Darkness、氣化形體 Gaseous Form、睡眠術 Sleep_

### 附贈動作 Bonus Actions

**隱形術 Invisibility。**惡鬼對自身施展_隱形術 Invisibility_，無需法術成分並使用與施法動作相同的施法屬性。
