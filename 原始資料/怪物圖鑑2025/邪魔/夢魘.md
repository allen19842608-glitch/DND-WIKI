# 夢魘 Nightmare

下層位面的恐怖坐騎

**棲息地：** 異界（下層位面）；**寶藏：**任意

夢魘形似擁有烈焰鬃毛、燃火馬蹄和陰燃雙目的馬匹。它們恐嚇弱小的生物，並常與下層位面的住民結盟以實施惡行。這些超自然的馬匹天生能夠在以太位面和物質位面之間穿行，且許多個體都知曉前往下層位面、墮影冥界和其他險惡領域的傳送門位置。
夢魘的速度、耐久力以及在存在位面間馳騁的能力令其成為了惡徒們垂涎的坐騎。擲一次夢魘騎手錶或從中選擇一個結果，以此來為什麼存在可能僱傭一隻夢魘坐騎提供靈感。

**夢魘騎手**

| **1d** | **夢魘承載著……** |
| --- | --- |
| 1 | 某個邪惡神明的勇士或信使。 |
| 2 | 一群偷乘坐騎的**小魔鬼 imps**或**小惡魔 quasits**。 |
| 3 | 一個被困於狂野邪魔之身的無辜靈魂。 |
| 4 | 一個追尋知識的**魔法師 mage**，**邪教徒 cultist**或**巫妖 lich**。 |
| 5 | 一個在位面間放牧**幼蟲魔 larvae**的**夜鬼婆 night hag** 。 |
| 6 | 一位邪惡的騎士，例如一個**死亡騎士 death knight**，一個**罪魔 erinyes**，一個**夢魔 incubus**或一個**吸血鬼 vampire** 。 |

## 夢魘 Nightmare

*大型邪魔，中立邪惡*

**HP** 68（8d10+24）

**速度** 60尺，飛行90尺（懸浮）

### 特質 Traits

**賦予火焰抗性 Confer Fire Resistance。**騎乘夢魘期間，夢魘可以賦予一名騎手對火焰傷害的抗性。

**照明 Illumination。**夢魘散發出半徑10尺的明亮光照以及額外10尺的微光光照。

### 動作 Actions

**蹄擊 Hooves。**_近戰攻擊檢定：_+6，觸及5尺。_命中：_13（2d8+4）鈍擊傷害外加10（3d6）火焰傷害。

**以太折躍 Ethereal Stride。**夢魘和其5尺內至多三名自願的生物一起從物質位面傳送至以太位面，或反之。
