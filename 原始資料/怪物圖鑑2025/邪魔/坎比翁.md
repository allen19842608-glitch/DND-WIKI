# 坎比翁 Cambion

被注入邪魔力量的凡人

**棲息地：** 任意；**寶藏：**聖物

坎比翁曾是凡人，但他們遭到了邪魔力量的腐化或被一個詭譎存在所附身。與具有少量邪魔血統的自由意志個體——提夫林相比，坎比翁則從本源上與下層位面的邪惡魔法相綁定，或受其重塑。
許多坎比翁為作為其力量來源的邪惡勢力效力。另一些坎比翁則試圖篡奪其創造者的力量，或獲得屬於它們自己的異界力量。在此類坎比翁之中最臭名昭著的就是埃烏茲，這位成為了邪惡半神的反派掌控著的邪惡國度正威脅著奧斯世界的自由都市灰鷹。
坎比翁以許多不同的方式誕生。擲一次坎比翁起源表或從中選擇一個結果，以此啟發其邪魔力量的來源。

**坎比翁起源**

| **1d6** | **坎比翁在……後獲得了其力量** |
| --- | --- |
| 1 | 被一個邪魔存在附身 |
| 2 | 被一個邪惡魔法的使用者復活 |
| 3 | 長期暴露於下層位面 |
| 4 | 與一個邪魔進行交易 |
| 5 | 受到一位神明的詛咒 |
| 6 | 參與了邪魔儀式 |

看來什麼事我都得親力親為，畢竟我的僕從全都是白痴。顯然，失望肯定就是神性的代價。

——“惡魔”埃烏茲，坎比翁半神

### 動作 Actions

**多重攻擊 Multiattack。**坎比翁使用爪擊或火焰射線發動共計兩次攻擊。

**爪擊 Claw。**_近戰攻擊檢定：_+7，觸及5尺。_命中：_8（1d8+4）揮砍傷害，外加7（2d6）火焰傷害。

**火焰射線 Fire Ray。**_遠程攻擊檢定：_+7，射程120尺。_命中：_13（3d6+3）火焰傷害。

**施法 Spellcasting。**坎比翁施展以下一道法術，無需材料成分並使用魅力作為施法屬性（法術豁免 DC14）：

**_每項2/日：_** _變身術 Alter Self，命令術 Command_（三環版本）， _偵測魔法 Detect Magic_

**_每項1/日：_** _支配類人 Dominate Person_（八環版本）， _位面轉移 Plane Shift_（僅自身）
