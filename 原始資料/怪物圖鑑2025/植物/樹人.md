# 樹人 Treant

智慧而強大的生命之樹

**棲息地：** 森林；**寶藏：**無

作為森林的古老住民，樹人是佈滿皺紋的巨型活化樹木。這些古老生靈大多存活了數百年，它們通曉自然界的秘密。樹人通常避免捲入短命種族的紛爭，但會堅持守護自己的森林家園。若被激怒，樹人能活化樹木作為援軍。樹人守護著森林的秘密，同時也被這些秘密所影響。擲一次樹人秘密表或從中選擇一個結果，以此啟發樹人守護的秘密之事。

**樹人秘密**

| **1d6** | **這個樹人……** |
| --- | --- |
| 1 | 曾被神明祝福，能結出魔法果實。 |
| 2 | 生長在地城入口或通往妖精荒野的傳送門之上。 |
| 3 | 是**皮克精 Pixie**或小**仙靈 Sprite**族群的家園。 |
| 4 | 是失落的德魯伊知識最後的守護者。 |
| 5 | 紮根於一位英雄的墓冢，能夠活化樹木，使其形似追尋使命的騎士。 |
| 6 | 曾被火焰灼傷，它的樹洞中藏著縱火者的遺骸。 |

### 特質 Traits

**攻城怪物 Siege Monster。**樹人對物件和建築物造成雙倍傷害。

### 動作 Actions

**多重攻擊 Multiattack。**樹人發動兩次猛擊攻擊。

**猛擊 Slam。**
_近戰攻擊檢定：_命中+10，觸及5尺。_命中：_16 （3d6 + 6）鈍擊傷害。

**碎木飛刺 Hail of Bark。** _遠程攻擊檢定：_+10，射程180尺。 _命中：_ 28 （4d10 + 6）穿刺傷害。

**活化樹木 Animate Trees（1/日）。**樹人用魔法活化60尺內其可見的至多兩棵樹木。每顆被活化的樹木均使用**樹人 Treant**的數據卡，但有以下區別：樹木的智力和魅力值為1且無法說話，並缺少活化樹木動作。樹木服從樹人的命令，使用與樹人一樣的先攻並在其回合結束後立即執行回合。樹木的活化持續1日，或在以下情況提前結束：其死亡時、該樹人死亡時或其與該樹人之間的距離超過120尺時。解除活化後，若可用，樹木重新紮根。
