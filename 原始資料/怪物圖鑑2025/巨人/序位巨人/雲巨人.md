# 雲巨人 Cloud Giant

至高巔峰之巨人

**棲息地：** 山地；**寶藏：**奧秘

雲巨人利用天空的力量觀察並巧妙地影響世界。這些巨人形似人類，擁有藍色或銀色的頭髮，皮膚呈現出雲朵般的暮色或者純白色。他們的上顎長著彎曲的獠牙，獠牙延伸至下唇之外。在戰鬥中，雲巨人揮舞著被風暴雲環繞的武器，並投擲咆哮的雷雲。
大多數雲巨人居住在山脈之巔的堡壘或漂浮於雲間的魔法宮殿中，許多雲巨人認為自己擁有高山一般崇高的地位或使命。有些雲巨人視自己為神明一般的存在，可以肆意操控並掠奪地面生物而不受懲罰；另一些則聲稱漫長的壽命和雲端的居所賦予了他們獨特的視角，他們會記錄地面世界的所見所聞，卻並不干涉世界。無論是哪種情況，雲巨人通常擁有驚人的魔法寶物——這些寶物可能從世界各地奪取而來，也可能是巨人為自己打造（並適配其巨型體型）的珍寶。

### 動作 Actions

**多重攻擊 Multiattack。**雲巨人使用雷鳴重錘或雷雲發動共計兩次攻擊。其可以將其中一次攻擊替換為使用施法施展_雲霧術 Fog Cloud。
_**雷鳴重錘 Thunderous Mace。**_近戰攻擊檢定：_+12，觸及10尺。_命中：_21（3d8 + 8）鈍擊傷害外加7（2d6）雷鳴傷害。_

**雷雲 Thundercloud。**_遠程攻擊檢定：_+12，射程240尺。_命中：_18（3d6 + 8）雷鳴傷害，且目標陷入失能狀態直至其下個回合結束。

**施法 Spellcasting。**雲巨人施展以下一道法術，無需材料成分並使用魅力作為施法屬性（法術豁免 DC15）：

**_隨意：_** _偵測魔法 Detect Magic_，_雲霧術 Fog Cloud_，_光亮術 Light_
_**1/日：**__操控天氣 Control Weather_，_氣化形體 Gaseous Form_，_心靈遙控 Telekinesis_

### 附贈動作 Bonus Actions

**迷蹤步 Misty Step。**雲巨人施展_迷蹤步 Misty Step_，使用與施法動作相同的施法屬性。
