# 石像鬼 Gargoyle

隱於眾目之下的石像哨衛

**棲息地：** 幽暗地域，城市；**寶藏：**任意

石像鬼是一種寄宿著元素之靈的石像。雙翼與魔法為這種沉重石像賦予了飛行能力，而它們亦常常棲居於可以“混入其中“的華美建築之上、岩層之間、甚至是一堆普通雕像之中。石像鬼通常會為那些將其咒喚於石像載體之上的魔法使服務，不過一旦放任它們自生自滅，石像鬼們也許就會搞出一些殘忍的惡作劇，甚至偷取寶藏，藏在它們那高聳華麗的巢穴之中。
石像鬼有著許多造型。擲一次石像鬼造型表或從中選擇一個結果，以此啟發某隻石像鬼具體有著什麼樣的外觀。

**石像鬼造型**

| **1d6** | **這隻石像鬼被雕刻為……** |
| --- | --- |
| 1 | 永遠微笑著的小天使。 |
| 2 | 隨便鑿刻出來的造型，或是自然形成的造型。 |
| 3 | 受損的模樣，或是嵌著造型並不匹配的零件。 |
| 4 | 巨龍般的造型，甚至有著精緻的石質鱗片。 |
| 5 | 長著角與尾的哥特風格邪魔。 |
| 6 | “實用”的造型，例如華麗的演講臺或是柱子。 |

## 石像鬼伏擊 Gargoyle Ambushes

石像鬼會試圖伏擊敵人以及侵入其領地生物。石像鬼沒有尋常生物的生理需求，更有著超自然的耐心，故而可以保持長達數月地靜止，只在最適合出手攻擊的情況才會揭露自身。它們往往潛伏於那些出現一尊雕像也不違和的地點，或是潛伏在足以掩蓋其軀體輪廓與顏色的地方。擲一次石像鬼迷彩表或從中選擇一個結果，以此啟發某隻石像鬼如何隱藏自己等待伏擊。

**石像鬼迷彩**

| **1d8** | **這隻石像鬼會裝成……** |
| --- | --- |
| 1 | 一顆巨樹的樹瘤或樹皮。 |
| 2 | 墓地或紀念館中的紀念碑。 |
| 3 | 懸崖或岩層上的突出部。 |
| 4 | 被石化蜥蜴或美杜莎石化的受害者。 |
| 5 | 刻在門或牆上的浮雕。 |
| 6 | 廢墟或垃圾場裡的瓦礫。 |
| 7 | 洞頂的鐘乳石或冰錐。 |
| 8 | 城堡、豪宅或是神廟上的雕像。 |

邪惡之物在土元素位面中橫行，所到之處山崩地裂。惡意雖已逝於諸元素之靈，然於幽邃深暗之中，惡徒終將其重塑為噩夢之形

——提姆，研究元素位面的學者
