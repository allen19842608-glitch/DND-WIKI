# 守秘納迦 Guardian Naga

亙古長存的護識蛇靈

**棲息地：** 荒漠，森林，異界（上層位面）；**寶藏：**聖物

守秘納迦是不朽的蛇形學者，享有著完美的記憶力。它們收集著來自與其一同生活的族群的歷史與秘聞，並看護著不同文化的故事再將其準確無誤地傳遞給新生代的後裔們。一些比共生文明更為長存的守秘納迦仍在殘垣斷壁之間徘徊，銘記著已逝文明的故事，讓其亡佚的子民在傳承中延續下去。
擲一次守秘納迦秘聞表或從中選擇一個結果，以此啟發該納迦的所見所聞。

**守秘納迦秘聞**

| **1d8** | **守秘納迦追憶著……** |
| --- | --- |
| 1 | 一段古代賢者或領袖人物的遺言。 |
| 2 | 一座隱秘城市或一片大陸的位置。 |
| 3 | 一句咒語，密碼，或謎語的答案。 |
| 4 | 每位曾向它講述故事之人的姓名。 |
| 5 | 一項本該被遺忘的儀式或法術。 |
| 6 | 多份使用了本土原料的配方。 |
| 7 | 諸多個講述被遺忘的神祇與土著精魂的故事。 |
| 8 | 一隻傳奇怪物的致命弱點。 |

### 特性 Traits

**天界復甦 Celestial Restoration。**若納迦死亡，則除非其遺骸被施展_驅逐善惡 Dispel Evil and Good_ ，其在1d6天后重獲生命並恢復全部生命值。

### 動作 Actions

**多重攻擊 Multiattack。**該納迦發動兩次啃咬攻擊。其可以將其中一次攻擊替換為使用劇毒蛇涎。

**啃咬 Bite。**_近戰攻擊檢定：_+8，觸及10尺。_命中：_17（2d12+4）穿刺傷害加22（4d10）毒素傷害。

**劇毒蛇涎 Poisonous Spittle。**_體質豁免檢定：_DC16，單一60尺內納迦可見的生物。_失敗：_31（7d8）毒素傷害，且目標陷入目盲狀態直至納迦的下個回合開始。_成功：_僅半傷。

**施法 Spellcasting。**該納迦施展以下一道法術，無需姿勢或材料成分並使感知作為施法屬性（法術豁免 DC16）：

**_隨意：_**_奇術 Thaumaturgy_

**_每項1/日：_** _鷹眼術 Clairvoyance，療傷術 Cure Wounds_（六環版本）， _焰擊術 Flame Strike_（六環版本）， _指使術 Geas，真知術 True Seeing_
