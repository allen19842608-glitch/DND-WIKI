# 變形怪 Doppelganger

易形滲透者

**棲息地：** 幽暗地域，城市；**寶藏：**個體

變形怪是超自然的生靈，它們能變形為一切類似人類的模樣。其讀心能力能幫助它們創造出近乎完美的偽裝，並從毫無防護的頭腦中挖掘出秘密。偶爾，變形怪也會用更公開的方式使用它們的變形能力，變為令人不安的形態來嚇唬敵人。
變形怪的行動可能和它的神秘魔法起源或更多是時候，它被僱來達成的目標有關。擲一次變形怪陰謀表或從中選擇一個結果，以此啟發設計一個變形怪的陰謀。

**變形怪陰謀**

| **1d** | **變形怪在暗中策劃著……** |
| --- | --- |
| 1 | 在那位詛咒它不得以真實形態生活的神祇的神殿中製造混亂。 |
| 2 | 隱藏一個巨大陰謀的證據。 |
| 3 | 假扮成一個傳說中的妖怪，通過恐懼來操縱一個聚居地。 |
| 4 | 取代一位貴族，享受窮奢極欲的生活。 |
| 5 | 窺伺一位法師，以學習如何完成自己拙劣的魔法造物。 |
| 6 | 擔任有影響力的職位，充當一場變形怪入侵計劃的潛伏特工。 |

和“自己”見一面是認識到自己並沒有想像的那麼迷人的最可靠的方式。

——自稱是悚聲堡的洛西林的某人

### 動作 Actions

**多重攻擊 Multiattack。**變形怪使用兩次猛擊攻擊，並使用詭異面容（若可用）。

**猛擊 Slam。**_近戰攻擊檢定：_+6（在每場戰鬥的第一輪中具有優勢），觸及5尺。_命中：_11（2d6+4）鈍擊傷害。

**讀心 Ready Thoughts。**變形怪施展_偵測思想 Detect Thoughts_ ，無需法術成分並使用魅力作為施法屬性（法術豁免 DC12）。

**詭異面容 Unsettling Visage（充能6）。**_感知豁免檢定：_DC12，源自變形怪的15尺光環區域內的每名能看見變形怪的生物。_失敗：_目標陷入恐慌狀態，並在其每個回合結束時重複豁免，成功則終止其身上的此效應。1分鐘後，其豁免自動成功。

### 附贈動作 Bonus Actions

**變形 Shape-Shift。**變形怪變形為小型或中型的類人生物，或變回其真實形態。除體型以外，其各形態下游戲數據均相同。變形怪著裝或攜帶的任何裝備都不會隨之變化。
