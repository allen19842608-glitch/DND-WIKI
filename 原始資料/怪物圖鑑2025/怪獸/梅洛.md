# 梅洛 Merrow

如食人魔般的海底掠奪者

**棲息地：** 海岸，水下；**寶藏：**任意

梅洛是兇狠的水域獵手，兼具食人魔與原始掠食性魚類的特徵。梅洛潛伏在沿海水域，坑害毫無戒備的獵物，它們猛然從水中躍起，抓住目標，或用致命的魚叉將獵物刺穿。隨後，被捕獲的陸地住民會被拖入陰暗的海底巢穴。梅洛常常將囚徒關押在儲藏室中，以作為未來的美餐。
它們還會襲擊沿海定居點和人魚社區，竊取武器和寶藏。這引發了人魚與梅洛之間的衝突，也導致陸地住民誤解，錯誤地將梅洛的襲擊歸咎於人魚。

學者們認為梅洛的起源能追溯到水生食人魔、墮落人魚，甚至更為恐怖的存在。
然而，這些寬泛理論卻並未揭示這些怪物的真實面目，而是暴露了在我們熟知的海岸之外，潛藏的可怕未知。

——李歐蒙

### 特質 Traits

**水陸兩棲 Amphibious。**梅洛可以在空氣和水中呼吸。

### 動作 Actions

**多重攻擊 Multiattack。**梅洛使用啃咬、爪擊或魚叉發動共計兩次攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+6，觸及5尺。_命中：_6（1d4+4）穿刺傷害，並且目標陷入中毒狀態，持續至梅洛的下個回合結束。

**爪擊 Claws。**_近戰攻擊檢定：_+6，觸及5尺。_命中：_9（2d4+4）揮砍傷害。

**魚叉 Harpoon。**_近戰或遠程攻擊檢定：_+6，觸及5尺或射程20/60尺。_命中：_11（2d6+4）穿刺傷害。若目標生物體型不超過大型，則梅洛將目標直線拉近至多15尺。
