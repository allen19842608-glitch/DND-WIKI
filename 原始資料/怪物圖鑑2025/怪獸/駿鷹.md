# 駿鷹 Hippogriff

環遊世界的獵人和坐騎

**棲息地：**草原，丘陵，山地；**寶藏：**無

半是獵鳥半是馬，駿鷹就是這樣一種威風的生物。它們以獨行的旅行者和牲畜為目標，在遷徙途中伺機狩獵。駿鷹可能會在旅途中載著騎手以換取食物或是其他幫助。駿鷹的遷徙持續數月乃至數年，而賢者常常會預測它們的路線，擲一次駿鷹目的地表或從中選擇一個結果，以此啟發駿鷹可能前往的目的地。

**駿鷹目的地**

| **1d6** | **駿鷹正在前往……** |
| --- | --- |
| 1 | 被雲霧籠罩的遺蹟 |
| 2 | 低懸的月亮、星辰或是其他天體 |
| 3 | 浮島上的魔法花園 |
| 4 | 能看見巨大地畫的山頂 |
| 5 | 尖塔頂被駿鷹蛋填滿的巢穴 |
| 6 | 通往妖精荒野或上層位面的傳送門 |
