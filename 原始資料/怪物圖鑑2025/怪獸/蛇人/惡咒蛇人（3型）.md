# 惡咒蛇人 Yuan-ti Malisons

惡咒蛇人帶有致死的毒液，而有些還能將其化為魔法性的打擊。它們同樣可以變形為蛇，以便它們伺機發動突襲，或是蜿蜒遁去而不留痕跡。
惡咒蛇人顯化出的蛇類特徵使他們在戰鬥中異常致命。它們存在著三種普遍類型：

## 3型 Type 3

這種惡咒蛇人腰部以上是人類，但腰部以下卻延展為巨蛇的盤蜷身軀。

### 特質 Traits

**魔法抗性 Magic Resistance。**蛇人對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**蛇人發動兩次毒素迸發攻擊，並使用施法施展_暗示術 Suggestion_（若可用）。

**毒素迸發 Poison Burst（僅蛇人形態）。**_近戰或遠程攻擊檢定：_+5，觸及5尺或射程120尺。_命中：_12（2d8+3）毒素傷害。

**絞纏 Constrict。**_力量豁免檢定：_DC13，單一5尺內不超過中型的生物。_失敗：_21（4d8+3）鈍擊傷害。目標陷入受擒狀態（逃脫 DC13），且目標陷入束縛狀態直至擒抱結束。

**施法 Spellcasting（僅蛇人形態）。**該蛇人施展以下一道法術，無需材料成分並使用感知作為施法屬性（法術豁免 DC13）：

**_隨意：_**_化獸為友 Animal Friendship_（僅蛇）

**_每項2/日：_**_暗示術 Suggestion_

### 附贈動作 Bonus Actions

**變形 Shape-Shift。**蛇人變形為中型的蛇，或變回其真實形態。若其死亡，則其保持在當前的形態不變。除註明部分外，其各形態下游戲數據均相同。蛇人著裝或攜帶的任何裝備都不會隨之變化。
