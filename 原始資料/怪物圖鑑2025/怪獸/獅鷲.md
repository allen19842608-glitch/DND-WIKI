# 獅鷲 Griffon

陸空兩棲的威武獵手

**棲息地：** 寒帶，海岸，草原，丘陵，山地；**寶藏：**無

獅鷲結合了猛禽和大型貓科生物的特徵（通常是鷹和獅），併兼具二者的精準與兇猛。一些稀有品種的獅鷲同時具有禿鷲和豹子的特徵，還有一些品種則是獵鷹和老虎的結合。無論外表如何，獅鷲通常與皇室相關，被稱為萬獸之王。
獅鷲身上有著無數的故事，擲一次獅鷲故事表或從中選擇一個結果，以此啟發關於獅鷲的故事。

**獅鷲故事**

| **1d6** | **傳說獅鷲……** |
| --- | --- |
| 1 | 會攻擊它們巢穴領空的任何東西 |
| 2 | 會對殺死它們的人降下詛咒，使其為百獸厭棄 |
| 3 | 能生出具有超凡治療功效的蛋 |
| 4 | 喜歡馬肉更勝過其他所有 |
| 5 | 會效忠於它們孵化後第一眼看見的生物 |
| 6 | 不會攻擊具有皇室血統之人 |

人們認為我們在城市高空飛行是為了避開風向標或是晾衣繩之類的玩意兒。而事實上，假如獅鷲聞到下面有多少馬肉在晃盪，比法師亂飛和蚊蠅更糟的事就要發生了！

——修達·霍溫特，深水城獅鷲騎兵團退休成員

### 動作 Actions

**多重攻擊 Multiattack。**獅鷲發動兩次撕裂攻擊。

**撕裂 Rend。**_近戰攻擊檢定：_+6，觸及5尺。
_命中：_8（1d8+4）穿刺傷害，若目標生物體型不大於中型，則其被獅鷲的兩隻前爪擒抱，陷入受擒狀態（逃脫 DC14）。
