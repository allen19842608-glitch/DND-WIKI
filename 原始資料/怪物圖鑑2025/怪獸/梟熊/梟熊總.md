# 梟熊 Owlbears

完美魔法捕食者

**棲息地：**森林；**寶藏：**無

很久很久以前，狂亂魔法師們結合禽類銳利的雙眸、厚實的羽毛、尖利的喙以及熊一般強壯的體格創造了梟熊。儘管起源於魔法，梟熊已遍佈多元宇宙的曠野並繁衍生息。
梟熊棲息在獨特的巢穴中，擲一次梟熊巢穴特徵表或從中選擇一個結果，以此啟發梟熊巢穴值得注意之處。

**梟熊巢穴特徵**

| **1d4** | **梟熊巢穴中包含……** |
| --- | --- |
| 1 | 前任居住者——例如強盜、狼群或是龍——的證明 |
| 2 | 鑲嵌著硬幣或其他寶物的成堆粒狀反芻物 |
| 3 | 有著1d6枚梟熊蛋的巢 |
| 4 | 一條穿過大地或空心樹的通道 |
