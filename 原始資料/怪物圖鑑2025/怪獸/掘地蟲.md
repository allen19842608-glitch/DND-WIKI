# 掘地蟲 Ankheg

穴居的昆蟲掠食者

**棲息地：** 森林，草原；**寶藏：**無

掘地蟲是一種體型巨大的昆蟲，它們在地表附近挖洞，修建了一座座蜿蜒曲折的地下迷宮。掘地蟲會從這些隧道中突然衝出，用它們那滴著酸液的雙顎和噴吐出的消化酶來溶解併吞下體型比它們小的獵物。
掘地蟲是農民們的剋星，農民們放羊的家畜很容易成為這些怪物的獵物。許多掘地蟲都獨自狩獵，但是在食物豐足的地區有時會有數十窩掘地蟲聚集，給城鎮帶來威脅。只有徹底掃清掘地蟲的隧道，並且清理乾淨它們的卵，這種怪物的巢穴才能真正被掃清。
掘地蟲的隧道大致呈圓柱形，經常散落著掘地蟲的食物殘渣和埋在土裡的寶藏。擲一次掘地蟲隧道發現物表或從中選擇一個結果，以此啟發能在掘地蟲的隧道內找到的物品。

**掘地蟲隧道發現物**

| **1d8** | **掘地蟲的隧道里有……** |
| --- | --- |
| 1 | 另一條通往幽暗地域的隧道（可能是天然形成的，也有可能是石鑿出來的）。 |
| 2 | 一座被隧道挖開的地下遺蹟或墓穴。 |
| 3 | 一窩1d4枚新產的掘地蟲卵，每枚敲碎的卵可用作一瓶強酸。 |
| 4 | 一頭死去的掘地蟲以及另一頭更加致命的捕食者的蹤跡。 |
| 5 | 一片掘地蟲的甲殼，可以用作一面盾牌。 |
| 6 | 在一灘酸液附近有一個裝有 2d6 GP 的袋子。 |
| 7 | 一隻流浪的家養或林間動物。 |
| 8 | 一個慘遭蹂躪的稻草人。 |

雖然它們也吃土裡的東西，但掘地蟲更青睞新鮮的肉——你的牛，你的狗，還有你。

——菲爾·詹金斯，奇瓦克的賢者

### 特性 Traits

**掘道者 Tunneler。**掘地蟲能夠以其一半的掘穴速度掘穴通過堅硬的岩石，並在其身後留下直徑10尺的地道。
