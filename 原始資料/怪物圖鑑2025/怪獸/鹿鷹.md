# 鹿鷹 Peryton

有翼狩心者

**棲息地：** 丘陵，山地；**寶藏：**武備

鹿鷹是恐怖的獵食者，它們喜好獵殺類人生物，尤其是人類和精靈，勝過其他任何。鹿鷹生著強壯的鳥類身軀和帶有獠牙的雄鹿頭，它們偏好自天空俯衝攻擊旅行者。詭異的是，其投下的影子輪廓好似人影。由於這超自然的怪象，人們相信鹿鷹是被詛咒的人類或精靈，亦或者鹿鷹以惡人屍體為食的食腐鳥。
鹿鷹會掏出獵物的心臟，將這些器官帶回它們的巢穴。這也引發了許多圍繞鹿鷹的迷信。擲一次鹿鷹迷信表或從中選擇一個結果，以此啟發鹿鷹偷取心臟的理由。

**鹿鷹迷信**

| **1d4** | **如果鹿鷹收集了足夠多的心臟，那麼……** |
| --- | --- |
| 1 | 這些心臟可以實現一個邪惡的願望。 |
| 2 | 鹿鷹會恢復原狀。 |
| 3 | 每顆心臟都會孵出一隻新的鹿鷹。 |
| 4 | 通往下層位面的傳送門便會開啟。 |

### 特性 Traits

**飛掠 Flyby。**鹿鷹飛行離開敵人的觸及時不會引發藉機攻擊。

### 動作 Actions

**多重攻擊 Multiattack。**鹿鷹發動一次角刺攻擊和一次禽爪攻擊。

**角刺 Gore。**_近戰攻擊檢定：_+5，觸及5尺。 _命中：_7（1d8+3）穿刺傷害，若鹿鷹在此次攻擊前立即向著目標直線移動了30+尺，則目標額外受到9（2d8）穿刺傷害。

**禽爪 Talons。**_近戰攻擊檢定：_+5，觸及5尺。 _命中：_8（2d4+3）揮砍傷害。若類人目標因此傷害生命值降至0，鹿鷹掏出目標的心臟來殺死目標。
