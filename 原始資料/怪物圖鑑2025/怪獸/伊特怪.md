# 伊特怪 Ettercap

劇毒蛛形綁匪

**棲息地：** 森林；**寶藏：**器具

伊特怪是一種類似蜘蛛的獵手，潛伏在森林深處，尋找獵物並將受害者拖進蛛網密佈的巢中。這些惡毒的掠食者貌似蛛形綱動物，但雙足行走，身軀駝背。它們因劇毒的啃咬和和射出蛛網捕捉受害者的能力而臭名昭著。伊特怪經常以小團體的形式和巨蜘蛛與普通蜘蛛群一同捕獵。
伊特怪經常在它們生活環境中過度捕獵。如果不加以控制，伊特怪很可能會用網和被包成繭的剩飯堆滿整片森林，使得伊特怪和妖精們發生衝突。惡毒的伊特怪會不擇手段地折磨作為食物的妖精；它們更喜歡恐嚇那些比他們小的妖精，比如**皮克精 Pixies**以及**小仙靈 Sprites**。伊特怪幾乎不會立即把智慧生物吞食，而是會先把獵物裹成繭，恐嚇折磨數日，再飽餐一頓。
伊特怪會避開火焰，因為火焰能快速燒盡它們的蛛網，還有它們安家的枯木。

### 特性 Traits

**蛛行術 Spider Climb。**伊特怪可以在難以攀爬的表面上攀爬，包括沿著天花板移動，且不需要為此進行屬性檢定。

**蛛網行者 Web Walker。**伊特怪在蛛網上移動時無視蛛網造成的移動限制，且與蛛網接觸期間，伊特怪可以知道其他與該蛛網接觸生物的準確位置。

### 動作 Actions

**多重攻擊 Multiattack。**伊特怪發動一次啃咬攻擊和一次爪擊攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_5（1d6+2）穿刺傷害外加2（1d4）毒素傷害，且目標陷入中毒狀態，持續至伊特怪的下個回合開始。

**爪擊 Claw。** _近戰攻擊檢定：_+4，觸及5尺。 _命中：_7（2d4+2）揮砍傷害。

**絞網 Web Strand。**
_敏捷豁免檢定：_DC12，30尺內伊特怪可見的不超過大型的生物。 _失敗：_目標陷入束縛狀態，持續至蛛網被摧毀（AC10；HP5；對火焰傷害具有易傷；免疫鈍擊、毒素、心靈傷害）。

### 附贈動作 Bonus Actions

**收網 Reel。**伊特怪將30尺內因其絞網動作陷入束縛的一名生物向直線拉近至多25尺。
