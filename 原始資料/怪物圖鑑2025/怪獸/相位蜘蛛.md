# 相位蜘蛛 Phase Spider

轉移位面的蜘蛛伏擊者

**棲息地：** 荒漠，森林，草原，丘陵，異界（以太位面），幽暗地域，城市；**寶藏：**任意

相位蜘蛛突然出現，頃刻發起攻擊，眨眼間又消失不見。這些馬匹大小的魔法蜘蛛是以太位面的特有物種。它們自霧氣騰騰的巢穴中穿過以太邊界，窺視物質位面。當它們發現獵物時，它們先是靠近目標，然後轉移或是“相位”移動到物質位面發起攻擊。它們在存在位面間穿梭，從出乎意料的方位發起攻擊，直至獵物被制服或被迫逃離。
相位蜘蛛比起普通蜘蛛更加聰明，但卻膽小得多。若是它們相對於在以太位面看到或者追趕它們的生物數量不佔優勢，它們通常就會逃跑。不過幽靈和類似的精魄是個例外，相位蜘蛛從這些靈魂處獲得食物，將它們作為獵物首選。

某些賢者曾說過，每年有四次你與相位蜘蛛佔據以太同位點，而你渾然不覺。

——馬庫斯·萬德斯，權威性存疑

### 特性 Traits

**以太視界 Trait Name。**若相位蜘蛛身處物質位面，其能夠看見60尺內的以太位面，反之亦然。

**蛛行術 Spider Climb。**相位蜘蛛可以在難以攀爬的表面上攀爬，包括沿著天花板移動，且無需為此進行屬性檢定。

**蛛網行者 Web Walker。**相位蜘蛛在蛛網上移動時無視蛛網造成的移動限制，且與蛛網接觸期間，相位蜘蛛可以知道其他與該蛛網接觸生物的準確位置。

### 動作 Actions

**多重攻擊 Multiattack。**相位蜘蛛發動兩次啃咬攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+5，觸及5尺。 _命中：_8（1d10+3）穿刺傷害外加9（2d8）毒素傷害。若目標因此傷害生命值降至0，目標傷勢穩定，並陷入中毒狀態，持續1小時。中毒期間，目標還會陷入麻痺狀態。

### 附贈動作 Bonus Actions

**以太漫遊 Ethereal Jaunt。**相位蜘蛛自物質位面傳送至以太位面，或反之。
