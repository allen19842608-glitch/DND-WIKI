# 亡命惡犬 Death Dog

雙頭的疫病傳播者

**棲息地：** 荒漠；**寶藏：**無

亡命惡犬是它們所居住的土地上的惡疫。這些兇猛的雙頭犬會伏擊它們認為比自己弱小的生物，尤為偏好受傷和病弱的獵物。它們會肆無忌憚地發起攻擊，儘可能用染疫的牙口感染儘可能多的生物。即使被趕走，亡命惡犬也會在受害者附近地帶徘徊，讓感染削弱獵物後再度發起進攻。
傳說常將亡命惡犬與惡毒的死亡之神、冥界和被詛咒的君王聯繫在一起。這些故事都是基於亡命惡犬所傳播的疫病。
擲一次亡命惡犬疫病症狀表或從中選擇一個結果，以此啟發亡命惡犬咬傷傳播的疫病症狀。這些症狀只是表面的，不會改變亡命惡犬啃咬動作的實際效果。當生物不再陷入亡命惡犬咬傷帶來的中毒狀態時，這些症狀也會消失。

**亡命惡犬疫病症狀**

| **1d6** | **亡命惡犬的疫病會造成……** |
| --- | --- |
| 1 | 受害者身上出現了許多犬科動物的牙印，彷彿還被惡犬緊緊咬住。 |
| 2 | 受害者的身體逐漸乾枯，彷彿正暴露在沙漠的高溫之下。 |
| 3 | 受害者會被只有他自己能聽到的聲音擾亂心神，這些聲音像是來自遠處的嗥叫或是各種模糊耳語。 |
| 4 | 受害者的血肉像屍體一樣開始腐爛。 |
| 5 | 受害者渾身發癢，彷彿他的皮膚下面有跳蚤或沙子。 |
| 6 | 邪惡的符號逐漸浮現在受害者的身體上，並不斷蔓延。 |

……而彼之悲愴將如餓犬悄然行於汝之疆土。直至滄海餘沙，耀陽成燼。

——來自輝煌沙漠的泥板殘片

### 動作 Actions

**多重攻擊 Multiattack。**亡命惡犬發動兩次啃咬攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_4（1d4+2）穿刺傷害。若目標生物體型不超過大型，其承受以下效應。_體質豁免檢定：_DC12。_首次_失敗：__目標陷入中毒狀態。中毒期間，目標的生命值上限在完成長休時無法恢復。此後每24小時目標重複豁免，成功則終止其身上的該效應。_後續失敗：_中毒目標的生命值上限減少5（1d10）。
