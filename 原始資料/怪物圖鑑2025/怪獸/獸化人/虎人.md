# 虎人 Weretiger

猛虎之威的獸化者

**棲息地：** 荒漠，森林，草原；**寶藏：**武備

虎人可化身為老虎或半虎半人形態。他們雖然可以隨意或在其魔法本質驅使下變形，但多數虎人是夜行生物，入夜便化為獸形。有一些虎人的變形與弦月、季節或重大事件相關。虎人多視這種能力為天賜恩典或家族榮光，常以此守護歷史重地。擲一次虎人守護表或從中選擇一個結果，以此啟發虎人守護之物為何。

**虎人守護**

| **1d4** | **虎人守護著……** |
| --- | --- |
| 1 | 傳奇武器或權力象徵。 |
| 2 | 預言中英雄的試煉之地。 |
| 3 | 稀有的魔法動植物群落。 |
| 4 | 蘊有魔力的神聖泉水。 |

我追獵邪惡如猛虎逐食，但要讓邪惡長屈於人下，光憑利刃可不夠。得靠拳頭、血性，有時候還得耍點手段。

——虎人，德爾梅爾·聚角

**HP** 120（16d8+48）

### 動作 Actions

**多重攻擊 Multiattack。**虎人使用抓撓或長弓發動共計兩次攻擊。其可以將其中一次攻擊替換為一次啃咬攻擊。

**啃咬 Bite（僅虎與混合形態）。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_12（2d8+3）穿刺傷害，若目標是類人生物，則其受到下述效應。
體質豁免檢定：DC13。_失敗：_目標被詛咒。若被詛咒目標的生命值降至0，作為代替，目標變成受 DM 控制的一隻具有10生命值的**虎人 Weretiger**。_成功：_目標在24小時內免疫此虎人的詛咒。

**抓撓 Scratch。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_10（2d6+3）揮砍傷害。

**長弓 Longbow（僅類人與混合形態）。**_遠程攻擊檢定：_+4，射程150/600尺。_命中：_11（2d8+2）穿刺傷害。

### 附贈動作 Bonus Actions

**潛步 Prowl。**虎人移動至多等於其速度一半的距離且不會引發藉機攻擊。虎人可以在此次移動結束時執行躲藏動作。

**變形 Shape-Shift。**虎人變形為類人與虎的混合形態（大型），或虎形態（大型），或變回其真實的類人形態。除體型以外，其各形態下游戲數據均相同。虎人著裝或攜帶的任何裝備都不會隨之變化。
