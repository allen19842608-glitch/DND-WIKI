# 角鬥士 Gladiator

英勇鬥士與奪金戰士

**棲息地：** 任意；**寶藏：**武備，個體

角鬥士是挑戰怪物、挑戰彼此、挑戰其他險境的職業鬥士。一些角鬥士戰鬥下去的理由只是為了謀生，而另一些則是單純享受於這種演出的刺激——但無論如何，角鬥士都知道在戰鬥表演中保持觀眾興奮的重要意義。擲一次角鬥士演武特色表或從中選擇一個結果，以此啟發一名角鬥士在戰鬥中會表現出什麼獨特之處。

**角鬥士演武特色**

| **1d6** | **在挑戰中，這名角鬥士會……** |
| --- | --- |
| 1 | 將自己勢在必得的勝利獻給一尊神靈、統治者、愛上的貴族、或是觀眾中的一員。 |
| 2 | 穿戴著怪物主題的斗篷與面具。 |
| 3 | “審判”敵人，評判其對手的作戰方式是否英勇。 |
| 4 | 引領觀眾們一齊唱起一首激昂的戰歌。 |
| 5 | 試圖從敵人身上奪走某種“戰利品”。 |
| 6 | 從觀眾、預兆、甚至是寵物身上得到建議。 |

### 動作 Actions

**多重攻擊 Multiattack。**角鬥士發動三次矛攻擊。其可以將其中一次攻擊替換為使用盾擊。

**矛 Spear。**_近戰或遠程攻擊檢定：_+7，觸及5尺或射程20/60尺。_命中：_11（2d6+4）穿刺傷害。

**盾擊 Shield Bash。**_力量豁免檢定：_DC15，單一5尺內角鬥士可見的生物。_失敗：_9（2d4+4）鈍擊傷害。若目標生物體型不超過中型，則其陷入倒地狀態。

### 反應 Reactions

**格擋 Parry。**_觸發：_角鬥士在持握武器期間因近戰攻擊檢定被命中。_響應：_角鬥士令其對抗那次攻擊的 AC+3，可能令那次攻擊改為失手。
