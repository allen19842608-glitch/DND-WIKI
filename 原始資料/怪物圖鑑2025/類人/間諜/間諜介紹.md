# 間諜 Spies

滲透者與諜報員 

**棲息地：**任意；**寶藏：**器具，個體

為實現僱主的目的，間諜們能蒐集信息，散播流言，亦會操縱民眾。間諜們久經訓練，擅長誘導、操縱、滲透，以及在需要之時迅速跑路。許多間諜都依靠易容、假名、或是代號來掩蓋真實身份。擲一次間諜假身份表或從中選擇一個結果，以此啟發一名間諜會偽裝成什麼。

**間諜假身份**

| **1d4** | **這名間諜偽裝成一位……** |
| --- | --- |
| 1 | 吟遊詩人或是在各地旅行的演藝者。 |
| 2 | 被怪物或反派抓住的俘虜，或是它的僕從。 |
| 3 | 來自遙遠之地的貴人或旅客。 |
| 4 | 從過去、未來或異世界而來的訪客。 |
