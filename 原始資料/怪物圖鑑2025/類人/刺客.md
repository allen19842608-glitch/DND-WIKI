# 刺客 Assassin

僱傭殺手 

**棲息地：** 任意；**寶藏：**器具，個體

刺客是專業的殺手，它們擅長悄悄接近受害者，在不被發現的情況下發動攻擊。大多數刺客殺人都是有目的性的——有的是因為有人出錢買受害者的命，有的是為了自己的邪惡大業。刺客們擅使毒藥以及其他殺人利器，並攜帶能助其潛入安全區域或避免抓捕的道具。 許多刺客都遵守某種職業準則，或是表現出某種標誌性的怪癖。擲一次刺客作案風格表或從中選擇一個結果，以此啟發這名刺客有什麼獨特的習慣。

**刺客作案風格**

| **1d6** | **這名刺客的惡名源於……** |
| --- | --- |
| 1 | 為受害者安排戲劇情節一般的“精彩”死亡。 |
| 2 | 藏在大型物件中，例如一套鎧甲，或是傢俱內部的空洞。 |
| 3 | 在做案之後留下某件簽名性質的物品，例如名片、鮮花、貝殼、甚至是牙齒。 |
| 4 | 冒充名人、聖人或是僕役。 |
| 5 | 從受害者身上收取“紀念品”。 |
| 6 | 使用具有某種特定顏色或氣味的毒藥。 |

## 刺客 Assassin

*中型或小型類人，中立*

**AC** 16　**先攻** +10（20）

**HP** 97（15d8+30）

**速度** 30尺

### 特質 Traits

**反射閃避 Evasion。**當刺客受到一個允許其進行敏捷豁免來只承受一半傷害的效應影響時，其豁免成功時不受傷害，豁免失敗時只承受一半傷害。其無法在失能期間使用此特質。

### 動作 Actions

**多重攻擊 Multiattack。**刺客使用短劍或輕弩發動共計三次攻擊。

**短劍 Shortsword。**_近戰攻擊檢定：_+7，觸及5尺。_命中：_7（1d6+4）穿刺傷害外加17（5d6）毒素傷害，且目標陷入中毒狀態直至刺客的下個回合開始。

**輕弩 Light Crossbow。**_遠程攻擊檢定：_+7，射程80/320尺。_命中：_8（1d8+4）穿刺傷害外加21（6d6）毒素傷害。

### 附贈動作 Bonus Actions

**巧妙動作 Cunning Action。**刺客執行疾走、撤離或躲藏動作。
