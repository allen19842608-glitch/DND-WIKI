# 德魯伊 Druid

自然的維護者與管理者

**棲息地：** 任意；**寶藏：**聖物，個體

德魯伊們駕馭原初魔法，遵循古老教義，與動物和其他玄秘存在緊密聯結，捍衛著廣袤自然，淨化著世界的疾病。這些魔法使可能是隱居於某地的隱士，亦可能從屬於某一神秘組織。擲一次德魯伊使命表或從中選擇一個結果，以此啟發這名德魯伊如何使用魔法踐行其使命。

**德魯伊使命**

| **1d6** | **這位德魯伊是一位……** |
| --- | --- |
| 1 | 與傷害自然的破壞型文明抗爭的復仇戰士。 |
| 2 | 幫助旅者們安全穿過棲息著妖精、野獸與植物之國度的嚮導。 |
| 3 | 獨自守護著作為其家園的大地、海洋、甚至是天空的隱士。 |
| 4 | 修復自然界的創傷的旅者，治癒天災與人禍給世界留下的傷痕。 |
| 5 | 鬆散組織的成員，堅守著古老的儀式，守衛著自然的秘密。 |
| 6 | 監視著現實世界的基石、警惕著來自異界之威脅的衛士。 |

### 動作 Actions

**多重攻擊 Multiattack。**德魯伊使用荊藤法杖或蒼翠之力發動共計兩次攻擊。

**荊藤法杖 Vine Staff。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_7（1d8+3）鈍擊傷害外加2（1d4）毒素傷害。

**蒼翠之力 Verdant Wisp。**_遠程攻擊檢定：_+5，射程90尺。_命中：_10（3d6）光耀傷害。

**施法 Spellcasting。**德魯伊施展以下一道法術，使用感知作為施法屬性（法術豁免 DC13）：

**_隨意：_**_德魯伊伎倆 Druidcraft，動物交談 Speak with Animal_

**_每項2/日：_**_糾纏術 Entangle，雷鳴波 Thunderwave_

**_每項1/日：_**_動物信使 Animal Messenger，大步奔行 Longstrider，月華之光 Moonbeam_
