# 活化物件 Animated Objects

獲得生命的平凡物件

**棲息地：**城市 ；**寶藏：**無

魔法可以操縱尋常物件，使其執行簡單的任務。這些被活化的物件或許是不起眼的工具與裝飾，卻能忠誠地守護其創造者。這些物件聽從創造它們的力量或魔法使的簡單指令。如若無人看管，它們可能會長久守護某地，或是重複執行某項工作，直至損耗殆盡。
擲一次活化物件啟靈表或從中選擇一個結果，以此啟發是何種魔法激發這件道具的行動能力。

**活化物件啟靈**

| **1d10** | **此物件的活化源自於……** |
| --- | --- |
| 1 | 一位天族或邪魔，它使用此物件來保護或折磨某個凡人。 |
| 2 | 一場魔法與科技的結合，例如鍊金魔法和外星科技。 |
| 3 | 某人的本源，其曾被一名超自然魔術師轉化。 |
| 4 | 一位妖精，以此作為它遊戲或詭計的一部分。 |
| 5 | 機緣巧合，歷經百年使用後誕生出一絲生命。 |
| 6 | 魔法使需要一位守衛或僕從。 |
| 7 | 魔法樂器的旋律，賦予其靈性。 |
| 8 | 一個附身在物件上的精魂。 |
| 7 | 狂野魔法、失誤法術、或混亂神器。 |
| 8 | 一位強大心能者的意志。 |
