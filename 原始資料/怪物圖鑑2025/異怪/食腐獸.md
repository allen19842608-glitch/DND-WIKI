# 食腐獸 Otyugh

垃圾堆中的老饕

**棲息地：** 幽暗地域；**寶藏：**任意

食腐獸為食而生——越噁心的食物越受其親睞。它們將所有觸手可及且非其族類的生物視為其無盡饕餮生涯中的一餐。它們盤踞於垃圾場、下水道、受汙染的廢墟，和諸如此類的汙濁深淵之中，貪婪地吞食垃圾、腐屍及任何可以被觸鬚塞入其滔天巨口中的東西。有些人會通過投餵垃圾來招募食腐獸作為他們的守衛，儘管它們令人作嘔，但足夠警覺。
食腐獸經常將自己埋在垃圾堆下，通過長有眼球的莖須觀察周圍的情況。它們會利用亮閃閃的垃圾和心靈感應來引誘生物靠近，隨即用其帶刺的觸鬚和汙穢巨口發起攻擊。擲一次食腐獸誘餌表或從中選擇一個結果，以此啟發食腐獸如何引誘獵物靠近。

**食腐獸誘餌**

| **1d4** | **為了吸引潛在的大餐，食腐獸……** |
| --- | --- |
| 1 | 將觸鬚偽裝成垃圾。 |
| 2 | 用食腐獸語唱著誘人的歌謠。 |
| 3 | 用心靈感應發送信息，例如“這兒有好東西！”或“救命啊！我太美味了？” |
| 4 | 用心靈感應發送一副巨大寶石，扭曲武器，或受潮糕點的圖像。 |

### 動作 Actions

**多重攻擊 Multiattack。**食腐獸發動一次啃咬攻擊和兩次觸鬚攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+6，觸及5尺。_命中：_12（2d8+3）穿刺傷害，且目標陷入中毒狀態。每當中毒生物完成長休時，其承受以下效應。_體質豁免檢定：_DC15。_失敗：_目標的生命值上限減少5（1d10），並且其生命值上限無法恢復直至中毒狀態結束。
_成功：_中毒狀態結束。

**觸鬚 Tentacle。**_近戰攻擊檢定：_+6，觸及10尺。_命中：_12（2d8+3）穿刺傷害。若目標生物體型不超過中型，其被兩條觸鬚之一擒抱，陷入受擒狀態（逃脫 DC13）。

**觸鬚猛擊 Tentacle Slam。**_體質豁免檢定：_DC14，受擒於食腐獸的每名生物。_失敗：_16（3d8+3）鈍擊傷害，且目標陷入震懾狀態直至食腐獸的下個回合開始。_成功：_僅半傷。
