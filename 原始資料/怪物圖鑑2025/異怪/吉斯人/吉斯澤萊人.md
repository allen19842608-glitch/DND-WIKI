# 吉斯澤萊人 Githzerai

求極現實的探險家

**棲息地：** 異界（混沌海）；**寶藏：**奧秘，個體

吉斯澤萊人是枯瘦的人形生物，他們的生理構造與吉斯洋基人完全一致。與此同時，他們與吉斯洋基人共享一段同樣的歷史——皆遭遇過奪心魔在生理與心靈上的改造（詳見“吉斯洋基人”）。吉斯澤萊人深知其民族在肉體與心智上均被前靈吸怪奴役者所操控。他們從未屈從於這種程序式的改造，而是遵循首位領袖澤錫蒙的教導，重塑身心以尋求平靜。
吉斯澤萊人通過靈能在多元宇宙的混亂區域中創造寧靜隱秘的庇護所。此類堡壘多數漂流於混沌海位面，但吉斯澤萊聚落亦存在於無底深淵、元素混沌與妖精荒野。吉斯澤萊人建立這些封閉的庇護所旨在磨礪其靈能、參悟多元宇宙真諦，並躲避吉斯洋基人與奪心魔。

吾等吉斯澤萊渴求挑戰，為使澤錫蒙歸來時見證吾輩之完備，故吾等奔赴呼嘯混沌海，築造嶄新之家園。

——伊斯·門尼爾-阿格-吉斯，吉斯澤萊領袖

## 與吉斯人相關的冒險 Adventures with Gith

角色們可能會以多種方式捲入涉及吉斯澤萊人與吉斯洋基人的衝突。擲一次吉斯人衝突表，或從中選擇一個結果，以此啟發這些古老宿敵的相關冒險。

**吉斯衝突**

| **1d8** | **冒險者們將……** |
| --- | --- |
| 1 | 被要求向巫妖女王維拉基斯傳遞信息或神秘包裹，或從其處接收此類物品。 |
| 2 | 受一隻偽裝的噬腦怪慫恿，追捕一名行蹤不定，難以捕獲的吉斯領袖。 |
| 3 | 被懇求協助遭吉斯洋基人摧毀聖地的吉斯澤萊逃難者。 |
| 4 | 受託延續或破壞吉斯洋基人與紅龍的同盟關係。 |
| 5 | 受邀與吉斯洋基人會獵靈吸怪 |
| 6 | 被要求揭發某位面國家或法驅艦船上的吉斯人間諜。 |
| 7 | 受派執行任務，探明英雄吉斯或澤錫蒙最後已知的蹤跡。 |
| 8 | 負責將陣亡吉斯洋基騎士的佩劍歸還其族人。 |
