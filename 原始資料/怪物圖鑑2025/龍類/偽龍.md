# 偽龍 Pseudodragon

善變玲龍

**棲息地：** 海岸，荒漠，森林，丘陵，山地，城市；**寶藏：**奧秘

偽龍棲居於風光旖旎的荒野，尤愛獵物易捕、生活閒適之地。其如巨龍般悠然自得，於蒼木峭壁間築起小巢，綴以瑩石彩貝與無主珍寶，並對其寶庫嚴加看護。
偽龍能長到大型家貓的大小，一般通體覆有赤褐鱗甲。也有一些偽龍擁有異色鱗片或是斑紋，但均與其巨龍遠親迥異。
諸多魔法使都想討好偽龍，希望其成為他們的魔寵。偽龍的靈慧心智與魔法抗性堪稱絕佳夥伴，在某些施法者圈子中，豢養偽龍更被視為一種身份象徵。
偽龍多耽於逸樂。它們可能傾向幫助那些以其嗜好之物討好它們的人。反之，怠慢偽龍魔寵者，恐遭其棄如敝履。擲一次偽龍嗜好表或從中選擇一個結果，以此啟發偽龍喜歡何種禮物。

**偽龍嗜好**

| **1d10** | **偽龍想要……** |
| --- | --- |
| 1 | 可佩戴的浮誇配飾。 |
| 2 | 故友或舊主的遺物。 |
| 3 | 異域珍饈，如斧嘴鳥蛋卷或猛獁奶酪。 |
| 4 | 兄弟姐妹、競爭對手或主人的私人物品。 |
| 5 | 亮閃閃的禮物，從寶石到鮑魚殼均可。 |
| 6 | 柔軟床墊與絨布玩偶。 |
| 7 | 某位名廚的招牌甜點。 |
| 8 | 耗時費心的美容療程。 |
| 9 | 聆聽枕邊故事或摯愛曲調。 |
| 10 | 戰利品與氣派頭銜。 |

想取悅偽龍的話，最好把自己當成它的魔寵。

——賈拉茲，偽龍之友

**HP** 10（3d4+3）

**速度** 15尺，飛行60尺

### 特性 Traits

**魔法抗性 Magic Resistance。**偽龍對抗法術和其他魔法效應時進行的豁免檢定具有優勢。

### 動作 Actions

**多重攻擊 Multiattack。**偽龍發動兩次啃咬攻擊。

**啃咬 Bite。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_4（1d4+2）穿刺傷害。

**蟄刺 Sting。**_體質豁免檢定：_DC12，單一5尺內偽龍可見的生物。_失敗：_5（2d4）毒素傷害，且目標陷入中毒狀態，持續1小時。失敗差值5或更多：目標在中毒期間還會陷入昏迷狀態，昏迷在其受到傷害或被目標5尺內的一名生物用一個動作搖醒時提前結束。
