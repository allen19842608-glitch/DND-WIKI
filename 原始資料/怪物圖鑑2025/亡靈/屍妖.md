# 屍妖 Wight

採命之屍兵

**棲息地：** 荒漠，異界（墮影冥界），沼澤，幽暗地域，城市；**寶藏：**武具

屍妖由一些冷血兵勇的屍體轉化而來，以內在的邪惡敗德作為驅動力。與喪屍不同，它們保留著生前的記憶，繼續實行其邪惡的計劃。
屍妖經過復生回到人間之後，仍然會繼續生前的惡行，但如今則是源自對生命力的渴望。屍妖能夠使用汲取活物生命的攻擊。死於屍妖毒手的類人生物將在一天後復生為**喪屍 Zombie**，成為屍妖順從的手下。
令屍妖復生的原因多種多樣。擲一次屍妖動機表或從中選擇一個結果，以此啟發屍妖為何危害生者。

**屍妖動機**

| **1d8** | **屍妖復生是為了...** |
| --- | --- |
| 1 | 在某個特定晚上挑戰一切經過其墳墓的人。 |
| 2 | 征服其自認為有宣稱的土地。 |
| 3 | 繼續令其被判處死刑的犯罪。 |
| 4 | 追隨其生前的邪惡主人。 |
| 5 | 履行生前未竟的誓言。 |
| 6 | 為復生它的教派或邪神效忠。 |
| 7 | 證明自己的古往今來最偉大的勇士。 |
| 8 | 尋求其被偷走的心臟或其他寶藏。 |

### 特性 Traits

**日照敏感 Sunlight Sensitivity。**若屍妖身處陽光下，其進行的屬性檢定和攻擊檢定具有劣勢。

### 動作 Actions

**多重攻擊 Multiattack。**屍妖使用死靈劍或死靈弓發動攻擊兩次攻擊。其可以將其中一次攻擊替換為使用吸取生命。

**死靈劍 Necrotic Sword。**_近戰攻擊檢定：_+4，觸及5尺。_命中：_6（1d8+2）揮砍傷害，外加4（1d8）暗蝕傷害。

**死靈弓 Necrotic Bow。**_遠程攻擊檢定：_+4，射程150/600尺。_命中：_6（1d8+2）穿刺傷害，外加4（1d8）暗蝕傷害。

**吸取生命 Life Drain。**_體質豁免檢定：_DC13，單一5尺內生物。
_失敗：_6（1d8+2）暗蝕傷害，目標的生命值上限減少等於其受到傷害的數值。被此攻擊殺死的類人生物會在24小時後再活化為受屍妖控制的**喪屍 Zombie** ，除非該生物被複活或其屍體被摧毀。屍妖以此法同時能控制的喪屍數上限為十二。
