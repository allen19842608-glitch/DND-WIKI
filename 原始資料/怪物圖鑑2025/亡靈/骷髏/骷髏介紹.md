# 骷髏 Skeleton

白骨之惡

**棲息地：**異界（墮影冥界），幽暗地域，城市；**寶藏：**無

各種死靈法師和惡靈都會喚起骷髏。這些骷髏有的來自遠古遺骸，有的則是懷揣惡意的新鮮白骨，但都會為了召喚者的目標勞作不休，通常會擔任守護者、士兵或勞工的職責。也有些骷髏被複活時沒有任何指令，不過這是極少數情況了。擲一次骷髏默劇表或從中選擇一個結果，以此啟發這種未接收指令的骷髏的行為。

**骷髏默劇**

| **1d6** | **這些骷髏自行其便，於是它……** |
| --- | --- |
| 1 | 給死去主人的墳頭郵寄餐盤或老舊的信件。 |
| 2 | 和其他骷髏不斷作戰鬥訓練，被砍成了一堆會動的碎片。 |
| 3 | 復現著生前的各種娛樂方式，比如演戲、跳舞或讀書。 |
| 4 | 幹一種熟悉的工作，比如打掃、烹飪、挖礦或祈禱。 |
| 5 | 重複著臨死前的那刻。 |
| 6 | 回到生前保護的地方站崗。 |
