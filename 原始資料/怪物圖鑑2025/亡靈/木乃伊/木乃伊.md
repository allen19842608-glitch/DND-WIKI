# 木乃伊 Mummy

普通的木乃伊一般由牧師、貴族或衛道士的遺骸以特殊的死後儀式處理而來。有些是通過亞麻布或者黏土裹身，也有通過泥炭、冰、魔法或者其他方式保存下來的。
擲一次木乃伊復甦表或從中選擇一個結果，以此啟發木乃伊復活的原因。

**木乃伊復甦 Mummy Resurrections**

| **1d8** | **木乃伊復活是為了……** |
| --- | --- |
| 1 | 捍衛製作時就預定保護的聖地。 |
| 2 | 服從木乃伊領主的召喚。 |
| 3 | 對抗某個死而復生的仇敵。 |
| 4 | 保護後代免受古老的威脅。 |
| 5 | 懲罰詛咒己身者的後代。 |
| 6 | 奪回墳墓中保存的寶藏。 |
| 7 | 侍奉在其墓前祈禱之人。 |
| 8 | 殺掉一切所見活物。 |

### 動作 Actions

**多重攻擊 Multiattack。**木乃伊發動兩次腐朽拳擊攻擊，並使用恐怖怒視。

**腐朽拳擊 Rotting Fist。**_近戰攻擊檢定：_+5，觸及5尺。_命中：_8（1d10+3）鈍擊傷害，外加10（3d6）暗蝕傷害。若目標為生物，則其被詛咒。受詛咒期間，目標無法恢復生命值，也無法在完成長休時恢復生命值上限，並且詛咒每持續24小時，其生命值上限降低10（3d6）。若生物因此攻擊生命值降至0，則其立即死亡並化為塵土。

**恐怖怒視 Dreadful Glare。**_感知豁免檢定：_DC11，單一60尺內木乃伊可見的生物。_失敗：_目標陷入恐慌狀態，直至木乃伊的下個回合結束。_成功：_目標在24小時內免疫此木乃伊的恐怖怒視。
