# 前言：如何使用怪物 How to Use a Monster

每個怪物都是冒險的源泉。這本龍與地下城的怪物圖鑑涵蓋了各式各樣的怪物，無論是怪異的還是異想天開的、莊嚴的還是怖人。請從中選出您最喜愛的那些怪物，並將它們融入您的 DND 遊戲中。
《**怪物圖鑑**》（2025）與《**玩家手冊**》（2024）以及《**城主指南** 》（2024）一樣，是 DND 的核心基礎規則之一，需配合上述書籍使用。本書專為地下城主（DM）設計，提供了由 DM 控制的各類生物——無論敵友——的遊戲數據，這些數據以數據卡的形式呈現。本書以首字母順序\*向你呈現這些怪物的章節，以及收錄有各類動物的附錄 A。
官方 DND 冒險均引用了本書中的怪物。您可結合本書怪物以及《城主指南》中的自定義怪物規則和遭遇構建規則，打造自己的冒險。請參閱附錄 B（譯註：不全書未錄入），瞭解有助於您構建冒險的怪物列表。
譯註：為方便使用，不全書以生物類型為大類，生物子類為小類進行排版，由於其中部分同類怪物包含不同生物類型的子怪（如吸血鬼中包含類人的血僕和亡靈的吸血鬼），因此在兩種生物類型種均有出現，並非排版錯誤。

**2025版本中有何新內容？**
**本書為5版《**怪物圖鑑**》的2025版本。若您讀過2014版本，本書的大部分內容會讓您感到熟悉，因為基礎規則和怪物種類是相同的。書中大部分內容包含新增或重新設計的元素，且本書中的怪物取代了舊版書中的版本。以下是一些重點：**
**更多怪物 More Monsters。**怪物數量已增加至超過500張數據卡。
**全新怪物 New Monsters。**數十種新怪物，包括更多高等級威脅，為各個等級的角色們提供挑戰。
**優化規則 Refined Rules。** 所有數據卡均已更新，以提升易用性與遊戲平衡性。
**改進數據卡 Enhanced Stat Blocks。** 新的數據卡設計和語言優先呈現關鍵的遊戲細節。
**通用分組 Versatile Groups。** 非玩家角色不再單獨置於附錄，而是與其他怪物一同出現，並能用來代表任何類人種族中的個體。
**改進編排 Improved Organization。** 怪物現按名稱首字母順序統一排列，同一怪物的變體集中歸類。
**擴展列表 Expanded Lists。** 附錄 B 整合並擴展了2014版《城主指南》中出現的怪物列表。 2014版《怪物圖鑑》中的所有怪物均已收錄於本書，或有相同 CR 的對應替代方案（在附錄 B 中有作詳細說明）。
