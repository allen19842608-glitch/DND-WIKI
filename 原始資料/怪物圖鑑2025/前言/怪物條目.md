# 怪物條目 Monster Entries

本書主體由怪物條目構成，每個條目標題下方包含以下部分。

### 棲息地 Habitat

怪物的棲息地條目會標註其典型的棲息區域。按棲息地分類的怪物列表見附錄 B。
譯註：怪物的棲息地包括寒帶、海岸、荒漠、森林、草原、丘陵、山地、沼澤、幽暗地域、水下、城市以及異界。

### 寶藏 Treasure

怪物的寶藏條目表明該生物是否囤積寶物，以及其偏好的寶物類型，具體定義如下：
**任意 Any。**該怪物的寶庫可包含金錢類寶藏以及任意種類的魔法物品。
**個體 Individual。**該怪物不囤積寶藏，但可能攜帶金錢類寶藏。
**寶藏主題 Treasure Theme（奧秘 Arcana，武備 Armaments，器具 Implements，聖物****Relics）。**該怪物的寶庫以標註主題的魔法物品為主。《**城主指南** 》詳述了各主題對應的寶庫配置規則。
**無 None。**該怪物不關心寶藏。其攜帶的寶藏都是偶然所得。怪物擁有的任何寶藏都是其數據卡裝備條目中列出的裝備之外的額外物品。《**城主指南**》提供了更多關於怪物寶藏的信息。

### 敘事描述 Narrative Description

怪物基礎信息之後，是適用於該怪物在多元宇宙中任何地方的詳細信息。您可以在使用怪物時自定義這些細節，以令其適配您的冒險。

### 特殊巢穴 Special Lairs

一些怪物會改變巢穴周邊的環境。此類生物的**區域效應 regional effects**將在巢穴一節詳細描述。怪物在其巢穴內還可能變得更加強大，具體的增強方式還在其數據卡中給出。
