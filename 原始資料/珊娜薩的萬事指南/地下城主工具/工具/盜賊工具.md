# 盜賊工具

**盜賊工具 Thieves' Tools**

專用於撬鎖和解除陷阱的盜賊工具，也許是冒險者們最常用的工具了。熟練掌握這些工具還可以瞭解陷阱和鎖的基本知識。

**組件 Components。**盜賊工具包括一把小銼刀、一套開鎖器、一面安裝在金屬柄上的小鏡子、一把窄刃剪刀和一把鑷子。

**歷史 History。**你對陷阱的知識能讓你在回答關於以陷阱出名的名勝的問題具有額外的洞察力。

**調查 Investigation、察覺 Perception。**你在搜索陷阱時具有額外的洞察力，因為你已熟知各類陷阱的外在跡象。

**設置陷阱 Set a Trap。**如同你可以解除陷阱一樣，你也可以設置陷阱。你可以在短休中使用手頭上的物品製造陷阱。你進行一次檢定，檢定的最終結果將作為他人發現或解除該陷阱的 DC 值。陷阱造成的傷害值取決於製造它所用的材料（例如毒藥或武器），或等同於你檢定結果的一半，這將由 DM 決定。

**盜賊工具 Thieves' Tools**

| --- | --- |
| 溜門撬鎖 | 可變 |
| 解除陷阱 | 可變 |
