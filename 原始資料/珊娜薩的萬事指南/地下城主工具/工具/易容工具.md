# 易容工具

**易容工具 Disguise Kit**

對於偽裝者來說，易容工具是必不可少的，它可以讓使用者輕易地改頭換面。

**組件 Components。**易容工具包括化妝品、染髮劑、小道具，以及幾套衣服。

**欺瞞 Deception。**在某些情況下，一副偽裝可以提高你撒謊的能力。

**恐嚇 Intimidation。**合適的偽裝會讓你看起來更可怕，不管你是想假扮成瘟疫患者來嚇跑路人或是裝成暴徒以恐嚇一幫惡棍。

**表演 Performance。**巧妙的化妝可以提升觀眾的體驗，前提是化妝要設計得當，能夠喚起想要的反應。

**遊說 Persuasion。**人們往往會信任穿制服的人。如果你偽裝成一個權威人物，你與他人的交涉會更有說服力。

**易容 Create Disguise。**你可以在長休中製造一套偽裝物品。完成後你可以花費1分鐘時間來變裝。為了避免過度的關注，你一次只能攜帶一套偽裝，除非你有一個背包或類似的方法來隱藏它們。每套偽裝重1磅。

在其他時候，需要10分鐘來製作一套適當修改外觀的偽裝，而大幅改變外觀則需要30分鐘。
