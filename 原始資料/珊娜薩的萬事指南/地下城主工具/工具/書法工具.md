# 書法工具

**書法工具 Calligrapher's Supplies**

書法將寫字昇華為富有美感的藝術形式。

書法家用獨特的風格創作出賞心悅目的文字。他們的工具也提供了驗證文稿真偽的能力，前提是書法家要花費數個小時來不斷臨摹文稿，以掌握其書寫風格和結構特徵。

**組件 Components。**書法工具包括墨水、一打羊皮紙，以及三支羽毛筆。

**奧秘 Arcana。**雖然書法對於破解魔法密文來說沒什麼作用，但是書法工具熟練項至少能讓你判斷出這堆鬼畫符的作者是誰。

**歷史 History。**該工具熟練項可以在進行分析或調查文本內容的成功檢定中獲得好處，例如古代文稿、卷軸，還有包括石頭上的符文、壁畫中的內容或者諸如此類的其他文本。

**解讀藏寶圖 Decipher Treasure Map。**該工具熟練項意味著你具有解讀地圖的專業知識。你可以進行一次智力檢定以確定地圖的年代，地圖是否包含任何隱藏的信息，或類似的內容。
