# 工具熟練

**工具熟練 Tool Proficiencies**

工具熟練項是用來突出角色背景和專業水平的有效途徑。然而在遊戲進行中，工具的使用有時與技能的使用重疊，而且應該在何種情況下如何使用它們也不夠明確。本節提供了各種工具可以在遊戲中使用的方法。

**工具與技能一起使用 Tools and Skills Together**
工具相比起技能而言，它更加具有專業性質。歷史技能的熟練可以應用在過去的所有大事件之上，但文書偽造工具卻只能用來製作偽造文件與少數別的物品。因此，有機會在這兩種熟練項之間選擇其一的角色為什麼要去選擇工具熟練項而不是技能熟練項呢？

**檢定優勢 Advantage**
如果一個工具的使用和一個技能的運用都適用於同一個檢定，而一個角色同時具有該工具和該技能的熟練，那麼可以考慮允許這個角色在檢定時具有優勢。這個簡單的收益對於鼓勵玩家獲取工具熟練大有幫助。在下文的工具說明中，這種益處通常被描述為額外的洞察力（或類似的東西），這意味著增加了檢定成功的機會。

**額外獎勵 Added Benefit**
此外，考慮給有相關技能和相關工具熟練的人一個檢定成功後的額外獎勵。這種獎勵可以是提供更詳細的信息，或者也可以模擬不同類型的檢定成功的效果。例如，一個具有石匠工具熟練的角色成功地通過感知（察覺）檢定在石牆中找到一扇密門。這個角色不僅注意到密門的存在，而且你可以決定該角色的工具熟練項使其在一個智力（調查）檢定中自動成功，知道這扇密門該如何打開。

**工具詳述 Tool Descriptions**
**以下各節詳細介紹了《玩家手冊》中所提供的工具，以及如何在戰役中使用這些工具的建議。**

**組件 Components。**以下每項工具說明都會在開頭說明這套用品或工具都由什麼部件組成。具有工具熟練項的角色知道所有部件的用法。

**技能 Skills。**當一個角色具有工具和技能熟練項時，每一種工具都可能在與某些技能配合使用時提供檢定的優勢。

作為 DM，你可以允許一個角色在使用指定技能進行檢定時具有優勢。以技能名稱開頭的段落描述了這些可選項。但要注意的是，這些好處只適用於具有對應工具熟練項的人，而不是僅僅攜帶了該工具的人。

聯繫到技能時，工具熟練項的意思其實是有些抽象的；具體來講，它假定了具有相應工具熟練項的角色同時也瞭解相關行業或專業方面的事情，儘管這些事情不一定跟使用本工具相關。

此外，你可以考慮給角色進行技能檢定時一些額外信息或好處。本文也給出了滿足相關條件的例子和建議。

**特殊用途 Special Use。**顧名思義，將具有熟練項的工具用於特殊用途往往會帶來特殊的好處。

**難度等級示例 Sample DCs。**每一節末尾的表格列出了該工具所適用的一些用途，以及必要屬性檢定的推薦 DC 值。
