# 出售魔法物品

出售魔法物品絕非易事。騙子和小偷總是在尋找一個容易得手的目標。即使角色們找到了一個合法的買家，他們也不一定能得到理想的報價。

資源

為你的魔法物品尋找一個買家需要一個工作周的時間和100gp 的花費，用於推廣銷售。同一時間你只能選擇一件物品出售。

決議

想要出售魔法物品的角色必須進行魅力（遊說）檢定來決定買家的報價。角色也可以選擇拒售，而不是浪費工作周再次嘗試。使用魔法物品基礎價格表和魔法物品報價表來決定具體銷售價格。

表：魔法物品基礎價格

| 物品稀有度 | 基礎價格 |
| --- | --- |
| 普通 | 100gp |
| 非普通 | 400gp |
| 珍稀 | 4,000gp |
| 極珍稀 | 40,000gp |
| 傳說 | 200,000gp |

表：魔法物品報價

| 檢定值 | 結果 |
| --- | --- |
| 1-10 | 50%的基礎價格 |
| 11-20 | 100%的基礎價格 |
| 21+ | 150%的基礎價格 |

難題

出售魔法物品的最大難題是會引來小偷、騙子和其他任何想要東西但不想付錢的人。其他群眾或許也會試圖破壞交易以保護自己的業務，或者詆譭角色是一個不合法的賣家。

角色進行出售魔法物品的每個休整期都有10%的機會引發難題，出售魔法物品難題如表中示例。

表：出售魔法物品難題

| d8 | 難題 |
| --- | --- |
| 1\* | 角色的敵人偷偷安排購入這件物品並用於對付角色。 |
| 2\* | 物品被盜。 |
| 3\* | 你的競爭對手散佈這件物品是假貨的謠言。 |
| 4 | 有個術士宣稱他對這個物品有與生俱來的所有權，並要求角色們交給他。 |
| 5\* | 這件物品的舊主，或者他倖存的盟友，發誓要用力量奪回它。 |
| 6\* | 買家在買之前被謀殺。 |
| 7 | 買家兇惡的聲譽彰顯了這個物品一定會被拿去用於犯罪。 |
| 8\* | 這件物品是神聖秩序失落的遺物。 |

\*可能涉及對手
