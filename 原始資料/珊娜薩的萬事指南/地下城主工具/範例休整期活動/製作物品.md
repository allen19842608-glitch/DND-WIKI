# 製作物品

有錢有閒又有適當工具的角色，可以利用休整期製作護甲、武器、衣物、或其他非魔法機關。

資源

角色需要合適的工具來製造物品，並且原材料是物品售價的一半。為了確定為了創造這件物品需要多少個工作周，將它的成本除以50。一個角色可以在一個工作周內完成多件物品，只要它們的合計成本在50gp 以下。

對於成本高於50gp 的物品，只要正在進行的工作被存放在一個安全的位置，角色就可以通過一段長週期來完成它。

多個角色可以齊心協力來完成任務。將製作物品所需的時間除以一同工作的角色數量。作為 DM，你有權決定在一件物品的製作上最多可以有多少角色進行協作。一個特別小的物品，例如戒指，可能只允許1至2名勞工製作，但一個大的、複雜的項目可能允許4名或以上的工人。

一位角色為了製造物品必須對相應的工具擁有熟練，並且要能訪問適應的設備。作為 DM，你有權對角色是否擁有正確的設備來造物進行判斷。下表提供了一些範例。

| 熟練 | 物品 |
| --- | --- |
| 草藥工具 | 抗毒劑，治療藥水 |
| 皮匠工具 | 皮甲，靴子 |
| 鐵匠工具 | 盔甲，武器 |
| 紡織工具 | 斗篷，長袍 |

這裡假設了一個角色可以用列表上的價格出售被造物品。

製作魔法物品

魔法物品的製作不僅僅需要時間、精力和金錢。創造一件魔法物品是一項長期工程，涉及了一次或多次冒險以追蹤稀有材料和有關造物的神秘學識。

治療藥水和魔法卷軸是以下規則的例外。更多信息，請參閱“混合治療藥水”在下面的小節以及“抄錄法術卷軸”在第12頁。

在最開始，玩家需要一件魔法物品的配方來創造它。配方有點像是一個食譜。它列出了所需要的材料以及製作物品所必須的步驟。

一件物品總是需要一些特別的材料來完成它。材料的範圍可以從雪怪的皮膚到水元素位面的渦流中取來的一小瓶水。尋找材料應當作為冒險的一部分來進行。

魔法物品成分表格建議了角色為了獲取材料所必須面對的生物挑戰等級。注意，面對一個生物並不代表角色們必須從這些生物的屍體上來獲取物品。生物或許會守衛一片區域或資源，而那正好是角色們想要得到的。

表：魔法物品成分

| 物品稀有度 | CR 範圍 |
| --- | --- |
| 普通 | 1-3 |
| 非普通 | 4-8 |
| 珍稀 | 9-12 |
| 極珍稀 | 13-18 |
| 傳說 | 19+ |

選擇一個適合這件物品主題的怪物或地點。理想情況下，這兩者都應該呈現出近似的元素或本質。例如，水手盔甲可能需要一隻水詭的精髓。一把魅惑法杖可能需要一名特定的奧等羅斯魔（Arcanaloth）的合作——而它則只有在你完成它的任務以後才會提供幫助。創造一把威力法杖也許依賴於尋找一枚被魔法之神曾碰觸過的古老石頭，而它正被一隻多疑的獅身人面像（Androsphinx）所守護。

除了面對一隻特定生物，創造一件物品還需要其他材料、工具、等等的金幣成本，具體取決於物品的稀有度。這些價值，以及角色為了完成物品所需要花費的時間，被展現在魔法物品創造時間和成本表中。如果要創造消耗品，把表裡列舉的金錢和創造時間減半。

表：魔法物品創造時間和成本

| 物品稀有度 | 成本 | 工作周 |
| --- | --- | --- |
| 普通 | 50gp | 1 |
| 非普通 | 200gp | 5 |
| 珍稀 | 2,000gp | 50 |
| 極珍稀 | 20,000gp | 100 |
| 傳說 | 100,000gp | 500 |

為了製作魔法物品，角色必須要有合適的工具熟練，就像是正常製作其他物品那樣。或者，角色需要熟練於奧秘技能。

難題

製造一件物品、尤其是魔法物品的難題往往牽涉到尋找一件工作所需的稀有物品以完工。難題、也即是角色在創作過程中也許要面對的副產品，在當他們要創造魔法物品時是足以激發他們興趣的。製造一套盔甲或者是一雙鞋子可能不會在角色的生活中引發什麼嚴肅的難題。

表：製作物品難題

| d8 | 難題 |
| --- | --- |
| 1\* | 有謠言認為你正在製作的物品是不安定的，有可能會對整個社會造成威脅。 |
| 2\* | 你不知道為什麼，每個人都認為你的工作需要你進行血祭，但這只是他們說的而已。 |
| 3\* | 你的工具被盜了，你必須去買一套新的。 |
| 4 | 一位當地的法師對你的工作很感興趣並堅持來視察你。 |
| 5\* | 一位強大的貴族為你的工作開出了巨大的價碼，並且他不習慣被拒絕。 |
| 6\* | 一個矮人氏族指責你竊取了他們的隱秘學識從而完成你的工作。 |
| 7 | 一名聖武士接近你並且宣稱你正在製造的物品是他完成一件英雄般壯舉的關鍵所在。 |
| 8\* | 你的競爭者散佈謠言說你的造物質量低劣並且毫無疑問會失敗。 |

\*可能涉及對手

混合治療藥水

治療藥水的製作在物品製作中屬於特別的項目，區別於其他魔法物品。一個熟練於草藥師工具的角色可以製作它們。製作它們所需要的時間和金錢被概述在創造治療藥水表中。

表：創造治療藥水

| 類型 | 時間 | 成本 |
| --- | --- | --- |
| 治療藥水 | 1天 | 25gp |
| 高等治療藥水 | 1工作周 | 100gp |
| 強效治療藥水 | 3工作周 | 1,000gp |
| 極效治療藥水 | 4工作周 | 10,000gp |
