# 宗教服務

具有宗教信仰的角色可能會希望把他們的休整期時間用於服務廟宇中。這項活動有可能使他們得到寺院領導者的恩惠。

資源

執行宗教服務需要角色拜訪，並經常性參與，一個信仰和風俗與角色一致的神殿。宗教服務需要花費一個工作周的時間，沒有金幣成本。

決議

角色選擇智力（宗教）或者魅力（遊說）之一進行檢定。檢定的結果決定了你從服務中獲得的好處，如宗教服務表中所示。

表：宗教服務

| 檢定值 | 結果 |
| --- | --- |
| 1-10 | 沒有效果。你沒有留下長期印象。 |
| 11-20 | 你得到一項恩惠。 |
| 21+ | 你得到兩項恩惠。 |

恩惠是在未來提供幫助的一種保證。它可以被用在要求神廟幫助處理一項政治問題，提供一項社會援助，或者是降低牧師50%的施法成本。

同一時間內，一個角色所能持有的恩惠數目不能高於1+他的魅力調整值（至少1項）。

難題

神廟有可能成為政治和社交詭計的迷宮。即使是在最善意的教派也有可能陷入於黨爭之中。服務於神廟有可能使人物被捲入這些類似的鬥爭當中。
