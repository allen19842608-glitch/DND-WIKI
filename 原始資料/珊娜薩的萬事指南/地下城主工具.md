# 地下城主工具

Dungeon master’s tools

作為地下城主，你負責監督遊戲並把玩家們經歷的故事編織在一起。你是保持這一切進展的人，這一章是為你準備的。它為您提供了新的可選規則，以及一些用於創建並運行冒險和戰役的進階工具。它是《城主指南》中的工具和建議的補充。

本章從可選規則開始，旨在幫助你更順利地運行遊戲的某些部分。這一章深入探討了幾個話題——構建遭遇、隨機遭遇、陷阱、魔法物品和休整期——這些都與你如何創造和演繹你的冒險有關。

本章的內容是為了給你提供方便，而不是反過來制約你。你可以忽略掉任何你不需要的部分，並且隨你心意來定製自己的規則。遊戲規則是為你和你所運行的遊戲服務的。一如既往，讓它們成為你自己的工具。
