# 狂熱者道途

**狂熱者道途 Path of the Zealot**

一些神靈鼓勵的追隨者們投身於殘酷的戰鬥狂怒中。這些野蠻人是狂熱的戰士，他們引導自己的憤怒轉化為強大的神賜力量。
在 DND 世界中有許多神都會鼓勵自己的追隨者尋求狂熱者道途。最著名的是費倫的 坦帕斯 Tempus ，以及灰鷹的 海克斯托 Hextor 和 厄瑞斯努 Erythnul 。一般來說，那些培養狂熱者的神往往是偏向於戰鬥、破壞和暴力等神職。當然，它們不一定全是邪惡的，還是有少數例外是善良的。

**狂熱者道途特性**

| **野蠻人等級** | **特性** |
| --- | --- |
| 3rd | 神性之怒，神之勇者 |
| 6th | 專心熾志 |
| 10th | 狂熱威儀 |
| 14th | 怒不畏死 |

**神性狂怒 Divine Fury**
從你在3級選擇此道途開始，你可以引導神性怒火，將其注入你的武器打擊中。狂暴期間，你在每個自己回合中用武器攻擊命中的第一個生物會受到等同於1d6+你野蠻人等級的一半 的額外傷害。此傷害的類型為暗蝕或光耀；你在你得到此特性時選擇它的類型。
**諸神勇士 Warrior of the Gods**
在3級時，你的靈魂被無盡的戰鬥所烙印。若一個法術只具有讓你起死回生（而非令你變為亡靈）的效果，例如法術 死者復活 raise dead ，則施法者在對你施展這一法術時不需要材料成分。
**狂熱專注 Fanatical Focus**
在6級時，驅使你憤怒的神力也能庇護你免遭干擾。狂暴期間，若你豁免檢定失敗，你可以重新投擲該豁免檢定，但你必須接受重骰後的結果。你每次狂暴中只能使用此能力一次。
**狂熱之姿 Zealous Presence**
在10級時，你學會了引導神聖之力，向他人傳授你的狂熱。以一個附贈動作，你憤怒的怒吼並釋放出一道蘊含神聖能量的戰吼。選擇你周圍60尺範圍內至多10個能聽到你戰吼聲的其他生物，直到你的下個回合開始前，他們進行的所有攻擊檢定與豁免檢定均具有優勢。
一旦你使用了此特性，直到你完成了一次長休為止你都不能再次使用它。
**怒不畏死 Rage beyond Death**
從14級開始，驅使你狂暴的神力允許你忽視致命的打擊。
狂暴期間，具有0點生命值並不會使你陷入 昏迷 Unconscious 。不過你仍然需要進行死亡豁免，你在0生命值下受到傷害時依舊計算豁免失敗次數。然而，若你因為未通過死亡豁免檢定而即將死去時，只要你仍處於狂暴狀態，你將拒絕死亡。而如果你的狂暴結束後你仍保持0點生命值，那麼你將死亡。
