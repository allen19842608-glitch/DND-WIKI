# 戰爭魔法（戰法師）

**戰爭魔法 War Magic**

![](<../../Xanathar’s signature.png>)

戰爭魔法？它會讓你變成一名戰法師麼？我聽說這群人啊，他們都穿的一身紫。然後我看你穿的不紫 ... 哦，那你失格了！換個職業去！

許多奧術學院專門培養用於戰爭的法師。戰爭之傳承精妙地融合了塑能與防護的機理，而非專精於獨一學派。它既授予施法者增進法術威力的技巧，同時也為法師提供了改良防禦能力的手法。這個奧術傳承的追隨者們被稱為戰法師。他們將他們的魔法視為武器和盔甲，比任何一塊鋼鐵都更為堅韌的材料。戰法師在戰鬥中行動迅速，用他們的法術奪取對戰局的戰術控制。他們的法術迅猛非常，而他們的防守技巧挫敗了對手的反擊勢頭。戰法師也善於導引其他施法者的魔法能量反過來攻擊他們。
於恢弘的大戰中，戰法師時常與塑能師、防護師和其他類型的法師相共事。塑能師最常嘲笑戰法師分心於攻守之間，而一位戰法師的經典回應是：“死人可丟不了火球。”

**戰爭魔法特性**

| **法師等級** | **特性** |
| --- | --- |
| 2nd | 奧術偏斜，戰術之智 |
| 6th | 魔力潮湧 |
| 10th | 耐久魔法 |
| 14th | 偏斜罩幕 |

**奧術偏斜 Arcane Deflection**
在2級時，你學會了編織魔法以更強韌的面對傷害。當你被一次攻擊擊中、或失敗於一次豁免時，你可以使用你的反應來在對抗那次攻擊的 AC 上獲得+2加值，或在那次豁免檢定中獲得+4加值。
當你使用此特性後，直到你的下個回合結束為止你都不能施展戲法之外的法術。
**戰術之智 Tactical Wit**
從2級起，你對於戰略格局的急速把控讓你能在戰鬥中快速的反應。你在先攻檢定中獲得等同於你智力調整值的加值。

**魔力潮湧 Power Surge**
從6級起，你可以將魔法能量存於體內並於之後增幅你危險異常的法術。以這種方式存儲的能量。便被稱為一股魔力潮湧。
你可以儲存至多等同於你智力調整值（至少1）股的魔力潮湧。當你完成一次長休時，你的魔力潮湧數量將變回一股。當你成功用 解除魔法 dispel magic 或 法術反制 counterspell 終止或打斷一個法術時，你可以從被你挫敗的法術中竊得魔力，以此獲得一股魔力潮湧。而當你在沒有任何一股魔力潮湧的情況下完成一次短休時，你也能獲得一股魔力潮湧。
每回合一次，當你用一個法師法術對一個生物或物件造成傷害時，你可以消耗一股魔力潮湧來對那個目標造成等同於你的法師等級半數的額外力場傷害。
**耐久魔法 Durable Magic**
從10級起，你引導的魔法也能幫你阻絕傷害。在你專注於一個法術期間，你的 AC 與你所進行的任何豁免檢定具有+2加值。
**偏斜罩幕 Deflecting Shroud**
在14級時，你的 奧術偏斜 Arcane Deflection 被灌注了致命的魔法。當你使用你的奧術偏斜特性時，你可以讓魔法能量從你身上湧出。選擇至多三個你周圍60尺內的可見目標，它們將受到你的法師等級半數的力場傷害。
