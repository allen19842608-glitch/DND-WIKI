# 幽域追獵者

**幽域追蹤者 Gloom Stalker**

![](<../../Xanathar’s signature.png>)

所以你就這麼躲在黑暗裡？你應該知道全世界——除了人類——都能看穿黑暗的對吧？我們都看得見你！踮腳走路又沒法讓你隱形。

幽域追獵者居身於致暗之地：地表深處，暗巷之間，太古叢林，和其他任何光無法照亮的地方。很多人進入到這種地區都會有種強烈的不安，但是幽域追獵者卻能在黑暗中大膽冒險，在敵人能夠觸及到更開闊的地區之前搜尋並襲擊他們。這種遊俠經常能在幽暗地區中被找到，但是他們會前往任何邪惡勢力蟄伏的地區。

**幽域追獵者特性**

| **遊俠等級** | **特性** |
| --- | --- |
| 3rd | 幽域追獵者魔法，恐懼伏擊，陰影視野 |
| 7th | 鋼鐵意志 |
| 11th | 追獵如風 |
| 15th | 如影隨行 |

**幽域追獵者魔法 Gloom Stalker Magic**
3級起，每當你在此職業達到特定等級時你都能學會一個額外的遊俠法術，如幽域追獵者法術表所示的那樣。這些法術對你視為遊俠法術，且它們不計入你的遊俠已知法術總數中。

**恐懼伏擊者 Dread Ambusher**
在第3級時，你精通於伏擊的藝術。你的先攻檢定獲得等同於你感知調整值的加值。
在每一場戰鬥中你的第一個回合的開始時，你的步行速度增加10尺，持續直至該回合結束。如果你在該回合進行攻擊動作，則你可以做一次額外的武器攻擊，作為那次攻擊動作的一部分。如果那次攻擊成功命中，目標還將受到額外1d8點傷害，額外傷害類型與武器相同。
**幽影視覺 Umbral Sight**
自3級起，你獲得60尺黑暗視覺。如果你已經從種族特質中獲得了黑暗視覺，則改為那一黑暗視覺範圍增加30尺。
你還擅長迴避依賴黑暗視覺的生物。在黑暗中，你對於任何依靠黑暗視覺觀察你的生物而言視為 隱形 Invisible 的生物。
**鋼鐵心智 Iron Mind**
7級時，你已經磨鍊出用來抵禦來自於你的獵物的精神影響能量的能力。你獲得感知豁免的熟練。如果你已經有此熟練項，作為代替，你獲得智力豁免、或魅力豁免的熟練（由你選擇）。
**追獵如風 Stalker's Flurry**
在11級時，你學會了以出人意料的速度來發動攻擊，以至於你能夠將一次失手轉化為另一次攻擊。每個你的回合一次，當你的一次武器攻擊未命中時，你可以作出另一次武器攻擊，作為同一動作的一部分。
**如影隨行 Shadow Dodge**
15級起，伴隨著一縷圍繞在你身邊的神奇暗影，你能以某種讓人始料未及的方式躲閃。無論何時，當一名角色對你進行一次攻擊檢定，且那次檢定不具有優勢時，你能用反應對其施加劣勢。你必須在知曉攻擊檢定的結果之前使用此特性。
