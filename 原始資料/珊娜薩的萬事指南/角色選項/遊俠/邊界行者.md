# 邊界行者

**邊界行者 Horizon Walker**

![](<../../Xanathar’s signature.png>)

你根本不可能走到世界邊界，因為它會不斷地遠離你。Boom！
我嚇到你了麼？我嚇到了，肯定嚇到了。

邊界行者會保護世界不受其他位面的威脅，也從那些妄圖利用異界魔法摧殘現有世界的惡徒。他們會找到傳送門並看守他們，會為了追捕他們的敵人而穿梭於內層位面與外層外面。這些遊俠也是多元宇宙中任何守護位面秩序與生靈勢力的盟友——尤其是那些向善的龍類、妖精、與元素。

**邊界行者特性**

| **遊俠等級** | **特性** |
| --- | --- |
| 3rd | 邊界行者魔法，偵測傳送門，位面戰士（1d8） |
| 7th | 以太漫步 |
| 11th | 閃現打擊，位面戰士（2d8） |
| 15th | 靈體防禦 |

**邊界行者魔法 Horizon Walker Magic**
3級起，每當你在此職業達到特定等級時你都能學會一個額外的遊俠法術，如邊界行者法術表所示的那樣。這些法術對你視為遊俠法術，且它們不計入你的遊俠已知法術總數中。

**偵測傳送門 Detect Portal**
在3級時，你得到了偵測位面傳送門的魔法感官。以一個動作，你偵測在你周圍1裡的範圍內距離你最近的位面傳送門，並以此知曉它於你之間的距離和方向。
一旦你使用了此特性。直到你完成一次短休或長休前你都無法再次使用它。
詳見《城主指南》第二章的“位面旅行”章節，以瞭解位面傳送門的範例。
**位面戰士 Planar Warrior**
3級時，你學會了如何通過吸取多元宇宙的能量來強化你的攻擊。
以一個附贈動作，選擇你周圍30尺範圍內的一名你可見的角色。本回合內你對其的下一次武器攻擊命中時，本次攻擊將造成力場傷害，且目標額外受到來自於該攻擊的1d8力場傷害。當你的在此職業上到達11級時，這一額外傷害將變為2d8。
**以太漫步 Ethereal Step**
在7級時，你習得了如何踏入以太位面。以一個附贈動作，你能夠用此特性施展法術 以太化 etherealness ，無需法術位。但是這個法術在當前回合結束時結束。
一旦你使用了此特性，直到你完成一次短休或長休前你無法再次使用它。
**閃現打擊 Distant Strike**
在11級時，你得到了能夠在眨眼之間穿梭於位面之中的能力。當你執行 攻擊 Attack 動作時，你能夠在每一次攻擊前傳送10尺到一片你可見的未佔據空間內。
如果你在 攻擊 Attack 動作中，攻擊了至少兩個不同的生物，則你可以額外發動一次攻擊，以攻擊第三個生物。
**靈體防禦 Spectral Defense**
在15級時，你的位面傳送能力使你能在戰鬥中流轉於空間邊緣以減少傷害。當你因一次攻擊而受到傷害時，你可以用你的反應以獲取那次攻擊傷害中包含的所有類型的抗性，持續直至當前回合結束。
