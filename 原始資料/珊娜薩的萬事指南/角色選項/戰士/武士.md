# 武士

**武士 Samurai**

武士是一種以堅決的戰鬥意志擊潰對手的戰士。他的信念幾乎堅不可摧，擋著他道的敵人只有兩種選擇：要麼死，要麼戰鬥到死。

**武士特性**

| **戰士等級** | **特性** |
| --- | --- |
| 3rd | 附贈熟練項，戰意 |
| 7th | 雅臣 |
| 10th | 不懈 |
| 15th | 燕返 |
| 18th | 生死流轉 |

**附贈熟練項 Bonus Proficiency**
當你在3級選擇此範型時，選擇以下技能之一，你獲得其熟練項：歷史、洞悉、表演、或遊說。或者作為代替，你可以改為學會一門由你自選的語言。
**戰意 Fighting Spirit**
3級起，你在戰鬥中的氣勢能武裝你，並使你攻擊更加精準致命。在你的回合中，你可以用附贈動作為你本回合發動的任何武器攻擊提供優勢。此外，使用這一附贈動作時，你還能獲得5點臨時生命值。臨時生命的數值會在你到達特定戰士等級後增加，在10級後增加至10點，在15級後增加至15點。
你能使用該特性三次，而完成長休後，你重獲所有已被消耗的使用次數。
**雅臣 Elegant Courtier**
7級起，你對於細節的嚴謹和專注讓你能勝任各種公共場合。當你進行魅力（遊說）檢定時，本次檢定獲得等同於你感知調整值的加值。
你的自控能力也讓你獲得了感知豁免的熟練。如果你已經有此熟練項，作為代替，你獲得智力豁免、或魅力豁免的熟練（由你選擇）。
**不懈 Tireless Spirit**
10級起，當你投擲先攻時，若你戰意的使用次數已被用盡時，你將重獲一次使用次數。
**燕返 Rapid Strike**
15級起，你學會了如何將精準轉化為迅捷的連擊。當你在自己回合中執行了 攻擊 Attack 動作，且你在其中某次對抗某一目標的攻擊檢定中具有優勢，你就可以放棄那次檢定的那一優勢，轉而額外對那個目標發動一次攻擊作為本次攻擊動作的一部分。每回合你只能這麼做一次。
（譯註：歧義極大的文本，但有兩點是已知的：從原文來看它只需要“放棄那次攻擊的那個優勢”，而不是“那次攻擊無法受益於優勢”；新的攻擊確實沒寫不享受優勢，不是沒翻譯出來，是原文就沒寫。）
**生死流轉 Strength before Death**
18級起，你的戰意能延緩死亡的到來。如果你受到會將你的生命值降到0且不會立即殺死你的傷害時，你可以用你的反應來延緩陷入 昏迷 unconscious，且你能立刻進行一個額外的回合並打斷當前回合。如果你在這個額外回合中，以0生命值的狀態承受傷害，則仍舊如往常一樣計為一次死亡豁免失敗，且三次死亡豁免失敗依舊會殺死你。當這個額外回合結束時，如果你的生命值為0，你依舊會陷入昏迷。
一旦你使用了這個特性，直到你完成一次長休前你都不能再次使用它。
（譯註：雖然這裡沒有明確說，但根據《玩家手冊》中戰鬥章節的反應規則來看，反應打斷了其他生物的回合後，反應結束生物將可以繼續進行自己的回合。）

**邊欄：騎兵，武士，騎兵 Cavaliers, Samurai, and History**
是的，現實世界中騎兵與武士都是實際存在的，我們創作的這兩個戰士範型時參考了流行文化（民間傳說、影視作品、以及漫畫書）的形象，而非參考實際的歷史故事。我們想在遊戲中做的是那些在電影聚光燈下、英雄史詩要素齊全的武術範型，而不是創造兩個現實歷史的複製品。
