# 魔射手

**魔射手 Arcane Archer**

![](<../../Xanathar’s signature.png>)

我討厭箭矢！它們的射程比我的眼波射線遠太多了！這就是為什麼我喜歡一直待在室內。題外話，天空真是個靠不住的破地方。

一個魔射手會學習能將魔法注入到攻擊中併產生超自然效果的獨特精靈箭技。魔射手是精靈中最精銳的戰士。他們會駐足守望精靈國土的邊界，致力於觀察那些入侵者並在那些怪物和入侵者來到精靈的居住地之前用注魔箭矢擊敗他們。在這數個世紀之間，這種精靈箭技已經被其他能夠在魔法和箭藝中找到平衡的種族習得。

**魔射手特性**

| **戰士等級** | **特性** |
| --- | --- |
| 3rd | 魔箭學識，奧術射擊（2種） |
| 7th | 注魔箭矢，曲線射擊，奧術射擊（3種） |
| 10th | 奧術射擊（4種） |
| 15th | 有箭無患，奧術射擊（5種） |
| 18th | 奧術射擊（6種，強化射擊） |

**魔箭學識 Arcane Archer Lore**
在3級時，你熟知那些魔法理論或某些自然之秘——那些通常只為精靈軍事傳統的研習者準備的學識。你獲得奧秘技能與自然技能之一的熟練項（由你選擇），且你習得戲法 魔法伎倆 prestidigitation 與戲法 德魯伊伎倆 druidcraft 之一（由你選擇）。
**奧術射擊 Arcane Shot**
在3級時，你學會了在射擊時為箭矢施放一些特殊的魔法效應。當你獲得這個特性時，你習得兩種由你選擇的奧術射擊選項（見下方的“奧術射擊選項”一節）。
每回合一次，當你在攻擊動作中，來用短弓或者長弓射出箭矢時，你可以為你的箭矢挑選一個你擁有的奧術射擊選項並適用。除非一個選項寫明瞭它不需要攻擊檢定，否則你均可以在射出箭矢命中生物後再決定是否使用選項。你擁有兩次使用此能力的機會，而且你在完成一次短休或長休後重新獲得所有已被消耗的使用次數。
當你到達特定戰士等級時，你可以習得一個額外的奧術射擊選項：7級，10級，15級和18級。而所有的選項在你戰士等級達到18級時將會獲得強化。
**注魔箭矢 Magic Arrow**
在7級時，你獲得了為箭矢中注入魔力的能力。當你用短弓或長弓射出非魔法箭矢時，你都可以將其轉變為魔法箭矢，用以克服對非魔法攻擊與傷害的抗性或免疫。魔法將在箭矢命中或未命中目標後立刻消失。
**曲線射擊 Curving Shot**
在7級時，你學會如何引導偏離的箭矢到新的目標上。當你使用魔法箭矢進行的攻擊檢定未命中時，你可以用附贈動作來指定距原本目標不超過60尺的另一目標，對其重骰本次攻擊檢定。
**有箭無患 Ever-Ready Shot**
15級起，無論戰鬥何時開始，你永遠準備著你的魔箭。投擲先攻時，如果你已耗盡你的奧術射擊使用次數，則你重獲一次使用次數。

**奧術射擊選項 Arcane Shot Options**

奧術射擊 Arcane Shot 特性允許你在特定等級時選擇數個選項。
以下選項以首字母順序排列。它們均為都是魔法性的效應，且每一個選項都對應著一個法術學派。
如果選項要求生物進行豁免檢定，你的奧術射擊豁免 DC 等同於8+你的熟練調整值+你的智力調整值。

**放逐矢 Banishing Arrow**
你用你的防護魔法來暫時放逐你的目標到一片妖精荒野的無害區域內。被這根箭矢擊中的生物必須通過一次魅力豁免。豁免失敗將被放逐。當被這種方式放逐時，目標速度降為0，陷入 失能 Incapacitated 。而在目標下一個回合結束時，它將重新出現在被放逐前的位置上。如果該位置被佔據，則它在最近的未佔據空間出現。
當你在此職業上達到18級後，目標被箭攻擊命中時還會額外受到2d6點力場傷害。

**欺詐矢 Beguiling Arrow**
你的惑控魔法讓箭矢暫時欺騙目標。被這根箭矢擊中的生物會額外受到2d6點心靈傷害，之後，選擇那目標周圍30尺範圍內的一個你的盟友。受擊目標必須通過一次感知豁免，若豁免失敗將被所選盟友**魅惑 Charmed**。此魅惑效應會持續到你的下一回合開始前，但倘若所選盟友攻擊它、對它造成傷害、或迫使它進行一次豁免時，此魅惑狀態將提前結束。
當你在此職業上達到18級後，箭矢的額外心靈傷害增加為4d6。

**爆裂矢 Bursting Arrow**
你將塑能學派的強烈力場魔法能量注入到箭中，而這股能量將在你的攻擊後爆炸。緊隨這發箭矢擊中生物之後，目標與其周圍10尺範圍內的所有的生物都將分別受到2d6點力場傷害。
當你在此職業上達到18級後，箭矢的爆炸力場傷害增加為4d6。

**虛弱矢 Enfeebling Arrow**
你讓死靈魔法纏繞在你的箭矢上。被這根箭矢擊中的生物將額外受到2d6點暗蝕傷害。且目標必須通過一次體質豁免，豁免失敗時他的武器攻擊造成的傷害將減半，持續直至你的下個回合開始前。
當你在此職業上達到18級後，箭矢的額外暗蝕傷害增加為4d6。

**纏繞矢 Grasping arrow**
當這根箭矢打擊它的目標時，咒法魔法會創造一團毒性荊棘緊緊纏繞目標。被這根箭矢擊中的生物將額外受到2d6點毒素傷害，且它的速度減少10尺。此外，被擊中的生物在每個回合首次移動時（至少1尺距離；不包括傳送），他也會受到2d6點揮砍傷害。被擊中的生物或其他能觸碰到它的角色可以用一個動作來嘗試解除荊棘，此時，它們需要通過一個對抗你的奧術射擊 DC 的力量（運動）檢定來解除荊棘。荊棘會在1分鐘後消失。如果你再次使用該選項，它將提前消失。
當你在此職業上達到18級後，箭矢的額外毒素傷害和揮砍傷害增加為4d6。

**穿梭矢 Piercing Arrow**
你使用變化魔法，使你的箭矢獲取以太之能。當你使用該選項時，你本次攻擊不進行攻擊檢定，取而代之，這隻箭會向前釋放出劃出一條1尺寬、30尺長的直線。這隻箭會無害地穿過物品，且無視掩護。而每一個在這條直線上的生物都必須通過一次敏捷豁免。豁免失敗時，生物會受到被箭矢攻擊命中的傷害，外加1d6點額外的穿刺傷害。豁免成功則只會受到半數傷害。
當你在此職業上達到18級後，箭矢的額外穿刺傷害增加為2d6。

**追蹤矢 Seeking arrow**
利用預言魔法，你賦予你的箭自尋目標的能力。當你使用該選項時，你本次攻擊不進行攻擊檢定，取而代之，選擇一名在過去的1分鐘裡你見過的角色。這隻箭會立刻飛向那名角色，如果可能的話，這隻箭矢會繞開一切轉角並忽視半身掩護與四分之三掩護。如果目標在箭的射程範圍之外，或你與它之間沒有合適箭矢飛行的暢通路徑，箭會在飛行到最大距離後消失。否則目標必須通過一次敏捷豁免。豁免失敗時，那個生物會受到被箭矢攻擊命中的傷害，外加1d6點額外的力場傷害，且你可以得知目標所在的確切位置。豁免成功時，目標只會受到半數傷害，且你也無法得知其具體方位。
當你在此職業上達到18級後，箭矢的額外力場傷害增加為2d6。

**遮影矢 Shadow Arrow**
你讓幻術魔法附著在你的箭上，使其能用暗影矇蔽敵人的視野。被這根箭矢擊中的生物將額外受到2d6點心靈傷害，且目標必須成功通過一次感知豁免。若豁免失敗，目標將在你的下個回合開始前，無法看見其5尺之外的任何事物。
當你在此職業上達到18級後，箭矢的額外心靈傷害增加為4d6。
