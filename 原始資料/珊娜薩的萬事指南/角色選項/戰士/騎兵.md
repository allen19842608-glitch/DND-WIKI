# 騎兵

**騎兵 Cavalier**

![](<../../Xanathar’s signature.png>)

所以意思是不同階級的玩劍人會有不同的名字作以區分？為啥啊？我試試看：大劍玩家，小劍玩家......不對，這聽起來在說他們的劍的大小而不是他們身份的大小......那，這套怎麼樣：帶劍的大沙包，帶劍的小沙包！

這騎兵範型十分擅長乘騎作戰。他們通常出身於貴族，成長在宮廷，騎兵往往在家族中領導騎兵隊衝鋒陷陣或在國家慶典中擔任儀仗或守衛。他們學習如何在衝鋒時保護他人不受傷害，經常以保護者的身份服務於他們的長官或者弱者。他們被強迫去懲奸除惡或取得榮耀，他們中的一些戰士會為了在冒險中提升自己而離開了他們的安逸生活。

**騎兵特性**

| **戰士等級** | **特性** |
| --- | --- |
| 3rd | 附贈熟練項，生而為騎，堅定之印 |
| 7th | 守護戰技 |
| 10th | 堅守戰線 |
| 15th | 衝鋒陷陣 |
| 18th | 警戒守衛 |

**附贈熟練項 Bonus Proficiency**
當你在3級選擇此範型時，選擇以下技能之一，你獲得其熟練項：馴獸、歷史、洞悉、表演、或遊說。或者作為代替，你可以改為學會一門由你自選的語言。
**生而為騎 Born to the Saddle**
3級起，你無時不刻透露著你作為騎手的精湛技藝。你為進行避免從坐騎上摔下所進行的豁免檢定具有優勢。只要你未失能，當你從你的坐騎上摔落且摔落高度不超過10尺時，你能夠雙腳著陸。
此外，騎上一個生物或從騎乘生物身上下來只需要花費你5尺的移動力，而非你速度的一半。

**堅定之印 Unwavering Mark**
從3級起，你能恐嚇你的敵人，將他們的攻擊抑制下來並反以懲戒之。當你以一次近戰武器攻擊命中一名敵人時，你為其賦予印記。印記會持續存在到你的下一個回合結束時，而如果你陷入 失能 Incapacitated 、死亡、或有其他人賦予該敵人印記時，這個效果會提前結束。
如果一個具有你印記的敵人身處你周圍5尺範圍內，他們以除你以外的生物為目標的攻擊檢定將具有劣勢。
此外，如果具有你印記的敵人對除你之外的任何其他人造成了傷害，則在下一個你的回合中，你可以以附贈動作對該敵人進行一次特殊的近戰武器攻擊。你的本次攻擊檢定具有優勢，若擊中，攻擊用的武器還會對目標額外造成等同於你戰士等級一半的傷害。
無論你為多少名角色賦予了印記，你能夠發動特殊攻擊的次數等同於你的力量調整值次（至少1次），當你完成一次長休時，你重獲全部已被消耗的次數。
**守護戰技 Warding Maneuver**
7級起，你學會如何抵禦向你、你的坐騎、或你周圍生物襲來的攻擊。只要你持用著一把近戰武器或一面盾牌，當你或你周圍5尺範圍內你可見的生物被一次攻擊命中時，你能以一個反應，投擲1d8並將骰值加入被攻擊生物的 AC 中，如果這次攻擊仍然命中了，則被攻擊目標將具有本次攻擊傷害的抗性。
你能夠使用該特性的次數等同於你的體質調整值次（至少1次），當你完成一次長休時，你重獲全部已被消耗的次數。
**堅守戰線 Hold the Line**
10級起，你成為了阻擊敵人的大師。當有生物在你觸及範圍內移動了5尺或更多的距離，那個生物將會引發你的藉機攻擊。且，當你以藉機攻擊擊中了一個生物時，那個生物的速度將被降低為0，持續直至本回合結束。
**衝鋒陷陣 Ferocious Charger**
從15級起，無論你是否乘騎著你的坐騎，你永遠能夠擊潰你的敵人。每個你的回合一次，如果你在攻擊一個生物前至少直線移動了10尺，且這次攻擊成功命中，那麼目標就必須通過一次力量豁免（DC8+你的熟練加值+你的力量調整值），豁免失敗將應擊 伏地 Prone 。
**警戒守衛 Vigilant Defender**
18級起，以你的極致警覺，你能察覺並應對一切危險。戰鬥中，你在每個其他生物的回合中可以進行一次額外的特殊反應。這一反應只能用於發動藉機攻擊，且你不能在同一回合中既使用特殊反應與又使用你原本的反應。

**邊欄：騎兵，武士，騎兵 Cavaliers, Samurai, and History**
是的，現實世界中騎兵與武士都是實際存在的，我們創作的這兩個戰士範型時參考了流行文化（民間傳說、影視作品、以及漫畫書）的形象，而非參考實際的歷史故事。我們想在遊戲中做的是那些在電影聚光燈下、英雄史詩要素齊全的武術範型，而不是創造兩個現實歷史的複製品。
