# 法師

_巫藝需要理解，瞭解魔法怎樣而又為何運作。我們努力增進對其的理解，並已然鑄就數個世紀以來文明的超卓進步。--幻術師金寶_

世間僅有少數人能施行魔法，而在他們之中，法師站在此技藝之巔。縱然是他們中最差勁的，也能夠操縱魔力並嘲笑大自然的法則。而他們中學識最為淵博者，其法術能讓整個世界為之戰慄。法師為他們的技藝付出最昂貴的代價便是時光。學習、授課與實驗耗費數年的光陰，以求駕馭魔法並將之牢記於心。對於冒險的法師與其他嚮往著魔法的至高境界的施法者來說，學習永不終結，對力量與知識的渴求亦如是。

假若你正在扮演一個法師，利用好這個機會，使得你的角色不僅僅是一個老套的唸咒機。使用下面的建議添加一些有趣的細節，詮釋你的法師與世界的交互方式。

_哦，我喜歡這個把戲。_

_嗨，法師，你現在不能使用魔法咯。_

_哦，現在你可以了。_

_哦，現在你又不能了，哈哈哈！_

_\--__⦿_

法術書

你的法師角色最為珍貴的財富--你的法術書，可能看起來平淡無奇，封面並未暗示著裡面的內容。或者你可能佈置一些特別之處，就如同許多法師那樣，創造一個與眾不同的法術書。假如你還沒有這樣的玩意兒，你的目標之一可能便是找尋一個讓你不同於他人的法術書--因其獨特的外觀或製造手段。

| D6 | 法術書 |
| --- | --- |
| 1 | 鐵鑄卷冊，酸蝕為文。 |
| 2 | 一個破損的卷宗，寫滿了僅有你能識別的象形文字。 |
| 3 | 寫滿咒文的長帶的皮革，為便於攜帶而纏於法杖之上。 |
| 4 | 刻有符文的石頭，存於布袋之中。 |
| 5 | 一本被龍炎所焚壞的書，裸露出其中的法術筆跡。 |
| 6 | 由完全漆黑的紙面組成的卷冊，筆跡僅於昏暗與黑暗中可見。 |

野心

鮮有法師扛起魔法研習的重擔而不抱有個人目的。許多法師將魔法作為獲得切實利益的工具，亦或是追求物質，亦或是渴求地位，亦或是為了自己，亦或是為了同伴。對於另外一些法師，魔法的理論本身極富吸引力，推動這些法師們追逐知識，以支撐奧法的新論或驗證舊說。除了那些顯而易見的理由，為什麼你的法師角色學習魔法？你想達到怎麼樣的成就？如果你沒有仔細思量過這些問題，你現在就可以這樣做，而你給出的答案很可能會影響你未來的路。

| D6 | 野心 |
| --- | --- |
| 1 | 你將證明，諸神並未如人們所想像得那般強大。 |
| 2 | 你學海的終點乃是不朽。 |
| 3 | 假若你能充分了解魔法，你能夠解鎖其全部的威能以開創一個平等的新紀元。 |
| 4 | 魔法是危險的工具，你以之保衛你所愛。 |
| 5 | 奧術的威能必須從濫用者手中奪去。 |
| 6 | 你將成為，世上數代人所能見過的，最偉大的法師。 |

怪癖

夜以繼日孤苦的研習，會對任何人的社交能力造成負面影響。縱然是一開始就不同於凡人的法師，亦不例外。一兩個怪癖未必是缺點，其提供趣味或是成為多種多樣的標籤。假如你的角色擁有一個怪癖，它是身體上的抽搐亦或是心靈上的？你是因為它才在某些圈子裡變得眾所皆知的嗎？你是否為克服之而鬥爭，亦或是擁抱了那使你名聲更盛的戲言。

| D6 | 怪癖 |
| --- | --- |
| 1 | 你無止地跺腳並時常惹惱周邊的人。 |
| 2 | 你記憶力超乎凡人，但你可以毫不顧忌地假裝心不在焉--如果這符合你的目的的話。 |
| 3 | 你從不在看看天花板上懸掛什麼之前就走進一個房間。 |
| 4 | 你最為珍愛的財富是一個放在藥瓶裡的死蟲子。 |
| 5 | 當你希望他人離開你時，你便開始自顧自地說話。 |
| 6 | 你的時尚感和妝容，或更多缺乏的東西，時常讓人誤以為你是個乞丐。 |
