# 德魯伊

_即使是在死亡之中，每個生物也都在扮演著它們的角色以維持巨大的平衡。但是現在失衡的因素在增長，一種力量在試圖支配自然。這對於凡人種族而言是毀滅性的影響。他們所採取的行為遠離了自然，由於他們，更多的腐化即將到來。作為德魯伊，我們主要通過保護和教育，來維持巨大的平衡，但有些時候我們也不得不奮發圖強，對抗危險並將其消滅。_

_\--薩芙蘭，大德魯伊_

　　德魯伊是自然世界的守護者，這也同時意味著他們必須成為自然的聲音，說出那些對一般人而言太過於微妙以至於無法聽見的真相。許多人因為發現了他們親近自然的本質而成為了德魯伊；自然的力量、循環和流動通過驚歎和頓悟填充了他們的內心和靈魂。一些民間的智者和賢者都曾學習過自然，並寫下記錄它的力量與神秘的卷冊，但區別於他們，德魯伊是一種特殊存在：從某一刻開始，他們能表現出這種自然力量，產生魔法般的現象從而將他們與自然的精魂、與生命的流動聯繫在了一起。由於他們的這種力量太過於強大和詭秘，德魯伊通常會被他們周圍的人尊敬、迴避或者是恐懼。

　　你的德魯伊角色或許會成為自然真正的崇敬者，或許是由於蔑視文明而只能從荒野中尋求藉慰。或者你的角色也可以成為一個想要努力將文明世界帶入曠野之中，致使它們和諧相處的城市之子。你可以使用以下部分來充實你的德魯伊，無論你的角色如何進入這個職業之中。

珍視的物品

　　一些德魯伊會帶著一個或更多的聖物，或者是對於他而言有深刻個人意義的物品。這些物品不一定是魔法的，不過一定在概念性或精神性上存有與德魯伊的內心相聯繫的重要意義。

　　當你決定你的角色珍視的物品是什麼時，想一想關於它的起源故事：你如何得到這個物品，它為何而言對你重要？

| 1 | 矗立在你村子中心的相遇樹上的一條枝丫。 |
| 2 | 從神聖之河的源頭採集的一小瓶河水。 |
| 3 | 被捆束在一起的特殊草木。 |

| 6 | 由你的導師親手繼承給你的一把小小的金色鐮刀。 |

精神嚮導

　　許多德魯伊會感覺到與自然中某種具體存在之間強烈的聯繫，例如一種水體，一種動物，一種樹木，或者是一種其他植物。你認同這由你選擇的嚮導；通過它的行為或者是它的本質，它樹立了一種使你願意效仿的榜樣。

| d6 | 精神嚮導 |
| --- | --- |
| 1 | 紫杉樹提醒著你不斷更新自己的思想和靈魂，讓舊的死去，新的生長。 |
| 2 | 橡樹象徵了力量和活力。在橡樹之下冥想讓你的身體和心靈重新堅韌且不被動搖。 |
| 3 | 河流的永恆流動讓你聯想到世界的偉大跨度。你提醒自己在行動時要考慮到自然的長遠利益。 |
| 4 | 海洋彷彿一個持續攪動著混沌力量的鍋爐。它令你接受，變化是維持自我在世界中繼續存在的必要因素。 |
| 5 | 飛鳥是最好的證明，即使最渺小的生物也能存活下來，只要它們遠離爭端。 |
| 6 | 狼的習性展示了個人力量在集群面前的微不足道。 |

導師

　　對於未來的德魯伊而言，尋求一名長老或指導者（或者被發現）來教導它們魔法藝術的基礎並非不同尋常。大多數德魯伊從青年時期就開始跟隨導師進行訓練，並且導師在塑造學生的態度和信仰時也扮演了重要的角色。

　　如果你的角色從其他人那兒接受了訓練，他會是怎樣的個體？你們之間關係的本質是什麼？你的導師是否灌輸給你一個獨特的前景，或者是影響了你選擇道路去實現你的目標？

| d6 | 導師 |
| --- | --- |
| 1 | 你的導師是一個智慧的樹人，它在以年為單位的時間跨度中教育著你，而非幾天或幾個月。 |
| 2 | 你被一個樹妖所教導，她同時也是一扇通往無底深淵的休眠傳送門的守望者。在訓練期間，你被託付了從隱藏的威脅中守衛這個世界的責任。 |
| 3 | 你的導師總是用獵鷹的形態與你交流。你從來沒見過導師的人形樣貌。 |
| 4 | 你和其他幾個年輕人被同一個老德魯伊教導，直到其中有一個人背叛了你的小組並且殺死了你的導師。 |
| 5 | 你的導師只用幻象與你見面。你從來沒有見過這個人，你甚至不能確定是否它真的以凡人的形態存在過。 |
| 6 | 你的導師是一個熊人，他教導你要對所有活物一視同仁。 |
