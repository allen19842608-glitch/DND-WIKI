# 製圖師

陷域繪出破局途

製圖師是領航員中的拔尖子與善於偵察的特工。藉由製圖師自己的造物，他們能標出威脅的位置、為盟友避免危險、甚至雕刻出能夠到達遙遠地點的傳送門。

**3級：行業工具 Tools of the Trade**
**你獲得以下增益。**
**工具熟練 Tool Proficiency。**你獲得書法工具和製圖工具的熟練項。如果你已經擁有其中之一的熟練項，則你獲得另一種你選擇的工匠工具的熟練（或如果你有全部兩種熟練，選擇另外兩種）。
**卷軸製造 Scroll Crafting。**當你使用《玩家手冊》的製造規則製作_法術卷軸 Spell Scroll_時，製造所需花費的時間減半。

**3級：製圖師法術 Cartographer Spells**
當你到達製圖師法術表中特定的奇械師等級時，你就始終準備著表中對應的法術。
**製圖師法術 Cartographer Spells**

| **奇械師等級** | **法術** |
| --- | --- |
| 3 | _妖火 Faerie Fire，光導箭 Guiding Bolt，治癒真言 Healing Word_ |
| 5 | _物件定位術 Locate Object，心靈尖刺 Mind Spike_ |
| 9 | _召雷術 Call Lightning，鷹眼術 Clairvoyance_ |
| 13 | _放逐術 Banishment，生物定位術 Locate Creature_ |
| 17 | _探知術 Scrying，傳送法陣 Teleportation Circle_ |

**3級：冒險者的地圖匣 Adventurer's Atlas**
**每當你持握著製圖工具完成一次長休時，你可以觸碰至少兩名、至多1+你智力調整值名（至少2名）生物（其中一個可以是你自己），用該工具創造一套魔法地圖。每個目標都會獲得一份持續顯示所有地圖持有者相對位置、但對其他人來說無法辨認的魔法地圖。地圖會一直存在，直到你死亡或你再度使用這一特性為止，屆時，你以此特性創造的還存在著的所有地圖都會立刻消失。攜帶魔法地圖期間，所選目標獲得以下增益：**

-   **警覺 Awareness。** 目標進行的先攻檢定具有1d4加值。
    
-   **定位 Positioning。** 目標知曉其他所有與自身處於同一存在位面的地圖持有者所在的位置。當需要能夠看到效果目標施展一道法術或創造某個效應時，持有地圖者可以無視其視覺或掩護，選擇另一個地圖持有者為目標。只要另一位地圖持有者仍在該效果範圍之內。
    

**3級：地圖魔法 Mapping Magic**
**你獲得以下增益。**
**照明繪圖 Illuminated Cartography。**你可以無需消耗法術位地施展_妖火 Faerie Fire_。受影響的生物將會如同墨水描繪一般清晰。你可以這麼做的次數等於你的智力調整值（最小為1次）。你在完成長休時重獲所有已消耗的使用次數。
**傳送門躍 Portal Jump。**在你的回合內，你可以花費等於你速度一半的移動力（向下取整）傳送至位於你或你30尺內持有你冒險者的地圖匣地圖的生物10尺內的你可見的未佔據空間。若你的速度為0，你不能使用此增益。

**5級：精準引導 Guided Precision**
**每回合一次，每當你施展一道製圖師法術表的法術或在以攻擊檢定命中受你_妖火 Faerie Fire_影響的生物時，你可以將你的智力調整值加到該法術或攻擊造成的其中一個傷害擲骰中。**
此外，受到傷害不會使你失去_妖火 Faerie Fire_的專注。

**9級：靈機一動 Ingenious Movement**
當你使用靈光一閃特性時，作為該次反應的一部分，你或一名由你選擇的30尺內的自願生物可以傳送至多30尺至一處你可見的未佔據空間中。

**15級：萬能地圖匣 Superior Atlas**
你的冒險者的地圖匣特性強化了，你獲得以下增益：

-   **安全歸處 Safe Haven。** 當地圖持有者的生命值被降至0（但沒被立刻殺死）時，該生物可以摧毀它的地圖，該生物的生命值變為等於你奇械師等級的兩倍，並傳送至你或另一個地圖持有者周圍5尺內的一處未佔據空間中。
    
-   **徑路悉曉 Unerring Path。**如果你自己也是冒險者的地圖匣特性中的地圖持有者之一，你可以無需法術位、無需準備、無需法術成分地施展_尋路術 Find the Path_ 。此特性一經使用，在你完成長休前都無法再次使用。
