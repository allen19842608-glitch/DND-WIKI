# 陰影龍紋特工

## 幽影 Shadow-Marked Agent

費亞蘭和蘇蘭尼家族的特工主要是精靈，他們將隱匿和諜報行動與精湛的表演藝術融為一體——而龍紋後裔們則用陰影魔法增強了這些技藝。這個數據卡可以為這兩家中任一一家服務。
儘管費亞蘭家族的特工在從事間諜活動之外通常不會從事藝人或藝術家的工作，但他們和其他家族成員一同接受了這些藝術的廣泛訓練。而相對的，蘇蘭尼家族的特工通常既是藝術家又是間諜。

### 動作 Actions

**多重攻擊 Multiattack。**特工發動兩次影刃攻擊。

**影刃 Shadow Knife。**_近戰或遠程攻擊檢定：_+8，觸及5尺或射程20/60尺。_命中：_10（2d4+5）穿刺傷害，外加14（4d6）暗蝕傷害，並且目標直到其下個回合結束速度降低10尺。

**施法 Spellcasting。**特工施展以下一道法術，無需任何材料成分並使用魅力作為施法屬性（豁免 DC14）：

**_隨意：_**_易容術 Disguise Self，次級幻象 Minor Illusion_

**_每項1/日：_**_行動無蹤 Pass without Trace_

### 附贈動作 Bonus Actions

**陰影化篷 Shadow Cloak。**直到特工的下個回合開始，其獲得隱形狀態。該隱形狀態會在特工進行一次攻擊檢定後立即提前結束。
