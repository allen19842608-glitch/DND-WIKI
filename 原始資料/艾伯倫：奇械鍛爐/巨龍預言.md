# 巨龍預言

巨龍預言的語言極其象徵化且很大程度上取決於條件。它並非預先鋪陳好的事件序列，而是對因果關係的探索——它描述了某一存在領域的事物，將如何因另一領域的變動而發生。
學者們有時將巨龍預言視為謎題，解開它本身就是一種獎賞。他們將預言的每一個獨立片段視為一個獨立的挑戰，並探索某一特定的行動序列如何能促成預言的實現。
然而，那些真正關注預言的不滅存在——主要是密閣巨龍和邪魔砂主——則將每個片段視為一個宏大整體的微小碎片。從這種更廣闊的視角來看，一個片段或詩節會層層遞進，引發下一個事件，上演一幕橫跨數十載、數百載乃至千萬載的戲劇。這些不滅者相信，每一個詩節都將及時實現，而他們的目標僅僅是將命運的方向導向某一側。
作為本導言開篇的預言詩節極具代表性，裡面的每一句都允許不同的解讀。請思考以下可能性：
**"鐵牛之息。"** 這些詞可能指字面意義上的**石化鐵牛 Gorgon**，也許是經過魔法改造或注入了光耀能量，使其氣息能夠恢復健康、起死回生或賦予物體生命。或者，它們可能指的是坎尼思家族，因為該家族的標誌正是石化鐵牛。（密閣的成員尤其相信凡人身上的出現龍紋，正是為了讓這些人參與到預言的故事中。）這些詞也可能指坎尼思工匠們給他們製造的戰俑"賦予生命"。
**"而興造化。"** 這些詞很容易讓人聯想到鐵匠鍛爐中的火焰，尤其是當它與前一句的鐵牛之息——坎尼思家族聯繫起來時。此外，它們可能指的是從舊事物的灰燼中誕生出新事物，或是在終末戰爭的多年暴力之後，凡人的激情（心中之火）轉向追求創造。
**"高塔再峙。"** 這些詞可以籠統地指災難後重建的建築，或者特指薩恩墮落區的某個建築項目（那個街區大部分仍然只是一座倒塌高塔的殘骸）。此外，它可能指某一家族血脈的復興，有卓越的後裔從衰落的家族中崛起；他們的"再探穹蒼"可能反映了崇高的抱負，也可能指他們實際駕駛著飛艇。
**"餘燼潛燃。"** 絕望中燃起希望是對這些詞最直接的解讀。然而，鑑於該詩節早前對火焰的提及，這裡的餘燼不一定是積極的——它可能指的是沉寂已久的破壞性火焰再次猛烈燃燒，或者甚至指的是一顆紅龍蛋的孵化。
**"五將出，龍將隕。"** 解讀這一句的最佳方式是將其視為對你戰役中角色的指代（如果角色數量多於或少於五人，你可以調整數字）。如果一條巨龍是你戰役中的主要反派，或是某個暴虐的統治者，甚至是任何容易被象徵為巨龍的事物，這種解讀尤為貼切。

### 使用預言 Using the Prophecy

以這個預言片段為例，作為地下城主的你該如何將其融入艾伯倫的戰役中呢？
從結局入手。假設最後一句指的是你的角色們將導致戰役中主要反派的隕落。如果你正在使用本書中的某個戰役模板，"龍將隕"可能指代以下反派之一：
**薩恩求實 Sharn Inquisitives（見第四章）。** 販賣名為龍血的危險毒品、危害薩恩民眾的達斯克組織，或者是一位因使用龍血而使其龍化的強大反派。
**龍紋陰謀 Dragonmarked Intrigue（見第五章）。** 與密閣相關的巨龍，或是某一龍紋家族的領袖。
**莫格雷夫遠征 Morgrave Expeditions（見第六章）。** 翡翠利爪教團的領袖罪髓女士（詳見《艾伯倫：從終末戰爭中崛起》），她擁有龍族血統；或是一位具有龍形外觀的邪魔霸主（如羅·睹契室，詳見《艾伯倫：從終末戰爭中崛起》）。
以這個高潮結局為目標，來規劃簡單的戰役情節——即一系列看似毫無關聯的四場事件，每一場都與預言片段的一行相呼應。在每一步中，角色們都可能遭遇試圖將預言實現導向不同方向的其他人物。其中一些人可能希望角色們推翻作為反派的巨龍；另一些人則可能希望角色們導致另一條巨龍的隕落。還有一些人，則可能希望五頭龍神提亞馬特崛起，實現該片段最後一行的預言，導致所有龍紋家族的覆滅。
