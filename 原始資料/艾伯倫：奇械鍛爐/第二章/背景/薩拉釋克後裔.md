# 薩拉釋克家族後裔

**屬性值：**體質、智力、感知
**專長：**探尋龍紋（見“龍紋專長”）
**技能熟練：**察覺和生存
**工具熟練：**選擇一種賭具
**裝備：**選擇 A 或 B：(A)賭具（同上所選）、攀爬工具、高檔服裝、狩獵陷阱、鐐銬、2GP；或(B)50GP。

當其他家族的後裔們尚在養尊處優時，在薩拉釋克家族成長的你，從幼年起便懂得了何為獨立自強。作為一個底蘊尚淺的新興豪門，你們雖在資源上稍顯匱乏，卻擁有足以彌補一切的鬥志與決心。薩拉釋克肩負著尚未實現的昭昭天命，而你正是其中不可或缺的一環。無論是短兵相接的戰場，還是爾虞我詐的交際，你都深諳狩獵之道：審視敵手，洞察破綻，並不計代價地奪取最終勝利。
