# 科拉瓦

數個世紀以來，那些人類與精靈的後裔已經在科瓦雷發展出了獨特的社群和傳統，而黎蘭達家族和梅丹尼家族的崛起則鞏固了他們族群身份上的認同。生活在這些社群之中的人將自己稱為科拉瓦，這是一個精靈語詞彙，意為"科瓦雷的子嗣"，他們如此自稱也是因為他們對"半精靈"這個稱呼感到牴觸。
許多科拉瓦秉持著身為"溝通之橋樑"的理念，他們相信自身的使命在於推動不同文化與種族間的交流和合作。奉行這一人生哲學的科拉瓦往往會成為吟遊詩人、外交官、調停者或翻譯官。另一些科拉瓦則痴迷於自身同妖精的遙遠鏈接，他們致力於在物質位面和瑟蘭尼斯的妖精荒野間構築橋樑。這些科拉瓦往往會成為德魯伊，或與至高妖精宗主締結契約的魔契師。

**科拉瓦特質 Khoravar Traits**
**生物類型：**類人
**體型：**中型（約4-6尺高）或小型（約2-4英尺高），在選取此種族時選擇
**速度：** 30尺

作為一名科拉瓦，你擁有以下特殊特質。
**黑暗視覺 Darkvision。** 你擁有60尺黑暗視覺。
**精類血統 Fey Ancestry。** 你在為避免或結束魅惑狀態進行的豁免中具有優勢。
**妖精贈禮 Fey Gift。**你知曉戲法_交友術 Friends_ 。每當你完成一次長休時，你可以將該戲法替換為牧師、德魯伊或法師法術表中的一道不同戲法。你在使用此特性進行施法時使用的施法屬性為智力、感知或魅力（在你選擇此種族時進行選擇）。
**昏睡抗力 Lethargy Resilience。** 當你在為避免或結束昏迷狀態進行的豁免中失敗時，你可以令其變為成功。此特質一經使用，直到你完成1d4次長休前不能再次使用。
**多才多藝 Skill Versatility。** 你獲得由你選擇的一項技能或工具的熟練。每當你完成一次長休時，你可以將其替換為另一技能或工具的熟練。
