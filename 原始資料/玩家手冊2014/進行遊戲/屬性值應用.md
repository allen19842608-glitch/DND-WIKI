# 第七章：屬性值應用

六項屬性值是生物個體身心特色的核心指標：

l **力量 Strength**，體能的量化

l **敏捷 Dexterity**，靈活度的量化

l **體質 Constitution**，耐受力的量化

l **智力 Intelligence**，記憶與思維能力的量化

l **感知 Wisdom**，直覺與感受能力的量化

l **魅力 Charisma**，個性氣質的量化

一個角色是否聰敏強壯?是否才智兼備?是否靈敏結實？這些素質皆由屬性值進行定義，這其中的項目可能會作為其強項或是短板。
遊戲中的三種主要擲骰（屬性檢定、豁免檢定和攻擊檢定），均依賴六項屬性值進行。而其擲骰的基本規則為：擲一粒 d20，加上從六項屬性值之一所導出的調整值，然後將總結果與目標值相比較。
本章將詳細說明屬性檢定和豁免檢定的應用方式，其中還囊括了遊戲裡怪物進行活動時的基本規則。關於攻擊檢定的規則將在第9章中進行說明。
