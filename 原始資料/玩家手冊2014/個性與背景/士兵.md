# 士兵

**士兵 Soldier**

你記憶中的生活就只有戰爭。由於自幼受訓，你學習了各種武器與護甲的使用方式，掌握了各種求生技巧，因而也懂得如何在戰場中存活。你可能曾是一支國家常規軍或一支僱傭兵團中的一員，又或者是最近戰場上一支戰績標榜的民兵部隊中的一員。
當你選擇此背景時，與你的 DM 一起討論你所屬軍事組織的具體信息，以及你在其內的軍銜高低，還有你在軍事生涯所經歷的具體事件。你曾出任於一支常規軍、城市守衛，亦或鄉村民兵？又或者是作為一名貴族或商人的私人保鏢，或是一名僱傭兵。

**技能熟練項：**運動，威嚇

**工具熟練項：**一種賭具，載具（陸運）。

**裝備：**一枚軍銜徽記，一件從某個倒下的敵人身上得到的戰利品（一把匕首，毀壞的武器或是軍旗碎片），一套骨骰或一組紙牌，一套普通服裝，以及一個裝有10 gp 的小包

#### 特性：軍銜 Feature: Military Rank

你作為士兵時曾獲得過軍銜。那些忠於你之前所在組織的士兵仍會承認你的權威與影響，而其中軍銜比你低的人甚至依然會遵從你的命令。憑藉軍銜的影響，你可以向其他士兵臨時徵用簡單的裝備或馬匹。並且還可以憑此隨意通過那些承認你軍銜的友方軍隊大營和堡壘。

#### 建議特徵 Suggested Characteristics

戰爭的恐怖連同兵役中的嚴苛紀律在所有的士兵心中刻下了印記，塑造了他們的理想，凝成了牢固的牽絆，甚至還會在他們身上留下傷疤，或是使他們變得對恐懼、羞愧和憎恨等情緒更加敏感。

| **d8** | **特點** |
| --- | --- |
| 1 | 我總是表現的恭敬有禮。 |
| 2 | 我的心中總是縈繞著戰爭時的記憶，那些殘暴的畫面總是揮之不去。 |
| 3 | 我曾失去太多的朋友，而現在已經很難交個新的朋友了。 |
| 4 | 我的軍事生涯曾經歷過各種情況，所以我能以此講出許多鼓舞人心而又發人深省的故事。 |
| 5 | 我能盯著一隻地獄犬看而毫不畏縮。 |
| 6 | 我喜歡強壯的感覺並且樂於打壞東西。 |
| 7 | 我有著粗俗的幽默感。 |
| 8 | 我迎難而上直面問題。一個簡單直接的解決方案是通往成功的最佳路徑。 |

| **d6** | **理想** |
| --- | --- |
| 1 | **大義 Greater Good****。**我們的使命即是為保衛他人而獻出自己的生命。(善良) |
| 2 | **責任 Responsibility****。**我服從權力，並且只做必須做的事。（守序） |
| 3 | **獨立 Independence****。**盲目的服從命令，某種意義上就相當於接受暴君統治。（混亂） |
| 4 | **力量 Might****。**生活與戰爭一樣，只有更強大的一方才能獲勝。（邪惡） |
| 5 | **自持自重 Live and Let Live****。**不該以理想之名行殺戮之事，或是以其名義發動戰爭。（中立） |
| 6 | **國家 Nation****。**我的城市、國家和人民是最重要的事。（任意） |

| **d6** | **牽絆** |
| --- | --- |
| 1 | 我依然會以性命保護曾一起共事之人。 |
| 2 | 有人在戰場上救過我的命。因而現在我也不會丟下任何一個朋友。 |
| 3 | 榮譽即吾命。 |
| 4 | 我永遠不會忘記隊伍曾遭受到的慘敗，以及當時的敵人。 |
| 5 | 那些與我同袍的人值得為之豁出性命。 |
| 6 | 我為那些無法為他們自己戰鬥的人而戰。 |

| **d6** | **缺點** |
| --- | --- |
| 1 | 我們曾在戰場上面對的兇暴的敵人依然會令我恐懼的發抖。 |
| 2 | 除那些久經沙場的武士外，任何人都不值得我尊重。 |
| 3 | 我曾在戰場上犯了一個嚴重的錯併為此傷害了許多生命——而我為了能守住這個秘密願意做任何事。 |
| 4 | 我對敵人的仇恨盲目而缺乏理性。 |
| 5 | 我遵從法律，而不管其律條是否會招致不幸。 |
| 6 | 我在犯錯時寧可吞掉自己的護甲也不願承認。 |
