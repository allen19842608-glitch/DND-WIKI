# 騙子

**騙子****Charlatan**

你與人交流時總是很有一套方法。你明瞭對方的動機，並且在進行幾分鐘交談和若干引導性提問後，就能如瀏覽兒科書般輕易的剖析對方的一切。而你也非常樂於以這份實用的天賦為冒險牟利。
你瞭解人們的欲求，並給予，或者答應給予相應的事物。人們的一般常識是警惕那些說過頭的甜言蜜語，而你的技巧卻能繞過這些常識。這瓶粉色藥水絕對能治癒您那糟糕的皮疹，這神奇的油膏（其實就是一些撒了點銀粉的油脂）能讓您重煥青春活力，剛好城裡的那座橋要被拍賣了。這些天花亂墜的謊言在你的嘴裡就如同事實一般。

**技能熟練項：**欺瞞，巧手

**工具熟練項：**易容工具，文書偽造工具

**裝備：**一套高檔服裝，一套易容工具，一些你自選的行騙道具（十個裝滿五顏六色液體的塞口瓶子，一套作弊骰子，一套暗號紙牌，或者一枚捏造的公爵璽戒），以及一個裝有15 gp 的小包

#### 偏好騙局 Favorite Schemes

每個騙子都有比較偏愛的騙局手法。選擇一個偏好騙局，或者擲骰隨機決定。

| **d6** | **騙局** |
| --- | --- |
| 1 | 我在博弈遊戲中作弊。 |
| 2 | 我造假幣或者偽造文件。 |
| 3 | 我滲透進他人生活中，掌握其把柄，奪取他其財產。 |
| 4 | 我像換衣服一樣換身份。 |
| 5 | 我在街角靠巧手耍把戲。 |
| 6 | 我說服別人花一大筆辛苦錢買不值錢的垃圾。 |

#### 特性：假身份 Feature: False Identity

你可以偽裝成另一個身份，還附帶關於該身份的相關的人證物證，並且必須先喬裝打扮來讓你進入角色。此外，你還可以偽造含有官方格式和私人筆跡的文書，前提是你必須曾見過此類文件以及目標的筆跡以作範本。

#### 建議特徵 Suggested Characteristics

騙子是將真實身份隱藏在各式面具後的多面手。他們能映照出人們想見願信之物及其看待世界的方式。只是他們的真我有時會被良心不安，舊敵或者信任危機等問題所困擾。
