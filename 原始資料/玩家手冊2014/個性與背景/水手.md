# 水手

**水手 Sailor**

你在海船上忙碌了許多年月。在那些日子裡，你曾直面狂野風暴、深海巨獸，或是其他許多能把你的小舟捲進深海的危險。你的初戀即是那遙遠的海平線，不過現在是時候找些新活計。
與 DM 討論設定你曾經所駕駛的船隻的相關信息。那是一艘商船、軍艦，亦或是探索船、海盜船？它威名遠揚，還是不為人知？它航線所至之處多還是少？它如今仍在航行，還是已經失蹤，或是和上面的水手一道沉入海底？

你在船上的職位是什麼——水手、船長、領航員、廚師，還是別的什麼職務？船長是誰，大副又是誰？你是帶著同伴們的祝福離艦，還是狼狽地從船上出逃？

**技能熟練項：**運動，察覺

**工具熟練項：**領航工具，載具（水運）

**裝備：**一根挽纜栓（短棒），50尺絲繩，兔腳或穿孔小石頭一類的護身符（或從第5章的飾品列表中擲骰決定），一套普通服裝，以及一個裝有10 gp 的小包

#### 特性：船家路子
Feature: Ship’s Passage

在必要時，你可以為團隊謀得免費的順風船進行旅行。你可能是搭上曾經效力過的船隻，也可能是遇到與你交好的另一艘船（可能一位你曾經的同船水手所指揮的船隻）。因為你是請求對方幫助（而非僱傭），所以你不能讓行程和日程全然滿足自己的要求。到達目的地的具體時間將由 DM 做決定。而作為免費搭乘的報酬，你和你的隊友必須在航行中加入船員的行列幫忙做工。

#### 變體水手：海盜
Variant Sailor: Pirate

你在由一個恐怖的海盜撫養長大，這個殘忍的殺人犯教會了你如何在血腥而危險的世界中生存。期間，你沉溺於在公海上劫掠，並將那些無辜者送入海底。熟悉恐懼和殺戮滋味的你，成為了許多港口間流傳的惡名。
當決定在你的航海生涯中加入海盜元素時，則你可以用惡名特性（見邊欄）代替船家路子特性。

#### 變體特性：惡名
Variant Feature: Bad Reputation

如果你的角色使用水手背景，則你可以選擇這個背景特性代替船家路子特性。
無論你走到哪裡，人們都會因你的惡名而恐懼。你在身處文明社區時，可以免受一些細微的犯罪指控（例如在酒館吃霸王餐或者踢壞商店的大門等），只因人們不敢冒險向當局告發你的劣行。
