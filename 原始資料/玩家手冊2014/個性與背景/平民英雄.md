# 平民英雄

**平民英雄 Folk Hero**

你來自社會階級的底層，但是卻命中註定要經歷許多磨難。家鄉的人們已經將你視為他們的鬥士，而命運也正感召著你去對抗各地壓迫平民百姓的暴君和怪物。

**技能熟練項：**馴獸，生存

**工具熟練項：**一種工匠工具，載具（陸運）。

**裝備：**一套工匠工具（由你選擇），一把鏟子，一個鐵鍋，一套普通服裝，以及一個裝有10gp 的小包

#### 命定事件 Defining Event

從前你與民眾一同從事某一項單純的專職工作，你的可能是專職的農民，礦工，僕役，牧羊人，伐木工或是掘墓人等。但是由於某件事的發生，你便走上了一條不同的道路並標誌著你此後的追求將更加偉大。選擇或投骰隨機決定一個命定事件以標誌著你成為人們心中英雄的時機。

| **d10** | **命定事件** |
| --- | --- |
| 1 | 我挺身而出反抗某位暴君的代理人。 |
| 2 | 我在一起自然災害中救了人。 |
| 3 | 我獨自一人對抗一隻可怕的怪物。 |
| 4 | 我偷竊了一名腐敗商人的錢財再用來幫助窮人。 |
| 5 | 我領導一支民兵擊退了一支入侵的軍隊。 |
| 6 | 我闖進某位暴君的城堡，並從中偷取武器武裝民眾。 |
| 7 | 我訓練農民們以農具作武器抵抗某位暴君的士兵們。 |
| 8 | 為反對一項不公法令，我發起了一場象徵性的抗議活動，隨後當地領主就將其廢止了。 |
| 9 | 一隻天族，妖精或是類似的其他生物賜我予祝福，或是揭示了我的秘密血統。 |

#### 特性：好客鄉民 Feature: Rustic Hospitality

你因來自平民階層而在鄉民群眾中倍感舒適。除非鄉民們已經認為你會帶來危險，否則你總能在普通人群中找到一個地方以供躲藏，休息或復原。他們能夠掩護你逃脫法辦，或者逃離追殺你的人，只是他們並不會為你而犧牲自己的性命。

#### 建議特徵 Suggested Characteristics

平民英雄是與平民同甘共苦的一員。大多數平民英雄都將其卑微的出身視為美德而非遺憾，並且其家鄉的社群在他們看來依然十分重要。
