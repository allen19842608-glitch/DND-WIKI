# 隱士

**隱士 Hermit**

你過著隱居生活——棲身於修道院這種與世無爭之地，或是孤身一人獨自生活。在遠離塵世紛擾的生活中，你獲得了內心的平靜與安寧，或許也從中領悟了苦苦追尋的人生真諦。

**技能熟練項：**醫藥，宗教

**工具熟練項：**草藥工具

**語言：**自選一門語言

**裝備：**一個卷軸匣，用來裝納研究成果和祈禱詞的筆記，一張冬用毯子，一套普通服裝，一套草藥工具，以及5 gp

#### 隱居生活 Life of Seclusion

為何你遺世獨立，而又為何重踏塵世？你可以和 DM 共同商討決定隱居的原因，也可以依下表選擇或擲骰隨機決定。

| **d8** | **隱居生活** |
| --- | --- |
| 1 | 我正在尋求靈魂的啟迪。 |
| 2 | 我遵守修會教規，參與集體清修。 |
| 3 | 我因不白之冤而被流放。 |
| 4 | 某件事情改變我人生的大事使我棄世而去。 |
| 5 | 我為了能潛心於藝術、文字或音樂而去尋找一處僻靜之地。 |
| 6 | 我要與自然溝通而遠離文明世界。 |
| 7 | 我是一座古代遺蹟或一件古代遺物的看守人。 |
| 8 | 我是一名追尋聖人，聖地或聖遺物的朝聖者。 |

#### 特性：研究發現 Feature: Discovery

你寂寥的長期隱居令你發現了某些獨特而強大的秘密。這項發現的具體內容與你的隱居的理由密切相關。你或許是找到了與宇宙真相，神本質，異界大能或是自然之力等相關的偉大真理。你也可能是發現了某處任何人都未曾發現的地點。你可能揭露了久被遺忘的真相，或是發掘出了久遠史前的遺物。或者，你也可能是發現了那些一手導致你流放的傢伙們相關的情報，而那也就是你重返凡世的契機。

#### 建議特徵 Suggested Characteristics

某些隱士很好的適應了隱居生活，也有些人苦於這種生活的寂寥苦苦等待著同伴到來。無論他們是選擇擁抱空寂還是渴望著逃離這一切，獨居生活都塑造了他們的態度和理想。少數人甚至會因脫離社會過久而變得瘋瘋癲癲。

| **d8** | **特點** |
| --- | --- |
| 1 | 由於在隱居生活中鮮少說話，現在的我更偏好用肢體語言交流，或者偶爾咕噥幾聲。 |
| 2 | 即使泰山崩於眼前，我依然心如止水。 |
| 3 | 修會的主持無論何時都能說出至理哲言，而我也想分享得此等睿智。 |
| 4 | 我對受難者抱有強烈的同情心。 |
| 5 | 我對於禮儀和社會常識一無所知。 |
| 6 | 我將周遭發生的一切視作冥冥天意的一部分。 |
| 7 | 我時常陷入自我冥思中無法自拔，絲毫不顧周圍的事物。 |
| 8 | 我正致力完成一套哲學理論，且樂於與人分享其理念。 |

| **d6** | **理想** |
| --- | --- |
| 1 | **大義 Greater Good****。**我的天賦註定要為所有人謀利，而非為一己之私。（善良） |
| 2 | **邏輯 Logic****。**絕對不能讓情緒干擾我們對正確、真實和理智的思考。（守序） |
| 3 | **解放思想 Free Thinking****。**探究精神和好奇心是學術進步的支柱。（混亂） |
| 4 | **力量 Power****。**清修和冥想是通往神秘力量或魔法之力的道途。（邪惡） |
| 5 | **自持自重 Live and Let LIve****。**胡亂插手他人事務只會造成麻煩。（中立） |
| 6 | **自知 Self-Knowledge****。**如果你能自知，那麼就無所不知。（任意） |

#### 其他隱士 Other Hermits

這裡所述的隱士背景特別之處是其設定了一個避世研習或祈禱的場所。如果你想要扮演一個在荒野離群索居的粗獷隱居者，也可以參考化外之民背景。而如果你想扮演的角色要更偏宗教色彩，則可以參考侍僧背景。或者你也可以扮演一名騙子，假裝自己是一個睿智而神聖的人以騙取虔誠蠢蛋們為你提供幫助。
