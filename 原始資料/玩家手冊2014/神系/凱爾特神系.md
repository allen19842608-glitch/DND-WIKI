# 凱爾特神系

**凱爾特神系****The Celtic Pantheon**

據說每個靈魂深處都潛藏著野性，包括夜裡}人的雁叫，還有穿過鬆林的颯颯風聲，以及莫名出現在一顆橡樹上的紅色槲寄生，而這一切正是凱爾特諸神的居所。祂們從溪流中噴湧而出，因橡樹的力量而變得強大，因林地與闊野而變得美麗。在林地居民們為樹幹上呈現的面容，或是溪流發出的耳語呼喚出其聖命名時，正是這些神使自身在現世顯身的一刻。
德魯伊常常如同牧師一樣侍奉凱爾特諸神，祂們與德魯伊崇拜的自然力量密切相關。
