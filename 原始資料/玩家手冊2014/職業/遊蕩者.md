# 遊蕩者

示意同伴等待後，半身人匍匐進地城的大廳中。她耳貼門板，再用掏出的工具眨眼之間將鎖撬開，便隨即消失在陰影中。而她的戰士朋友則走上前來一腳踢開大門。
一個人類在同伴們為其做好伏擊準備前，安靜的潛伏在小巷的陰影中。她的目標那個聲名狼藉的奴隸販子穿過巷道時，正好被同伴們的大聲呼喊吸引而前來查探，只是他的咽喉在發出聲音前就已經被刺客的刀刃悄然割斷。
侏儒忍笑鬆了鬆手指，然後魔術般地從守衛的腰帶上抬起了那串鑰匙。轉瞬之間，她就手拿鑰匙站在大開的牢門旁，準備好隨時帶著夥伴們開溜。
遊蕩者依靠隱匿與技巧，並針對敵人的弱點以建立優勢。他們總有解決問題的訣竅，並以此證明才智與變通才是成功冒險團隊的基礎。

**技能和精準 Skill and Precision**

遊蕩者致力於掌握多種技能的使用方法，並以此完善其作戰能力，因此他們在許多領域的專業知識都讓其他角色難以企及。很多遊蕩者專注於潛行和騙術，而另一些則精於針對地城環境的有效技能，諸如攀爬、搜索、解除裝置和開鎖。
戰鬥時的遊蕩者則是更偏愛狡猾而非蠻橫。與其用密集攻擊放倒敵人，他們更喜歡針對敵人的弱點部位進行精準打擊。遊蕩者們用近乎超自然的本領規避危險，而其中少數還會學習運用詭術魔法作為其能力的補充。

**陰暗生活 A Shady Living**

每個城鎮都會有一些遊蕩者。他們大多以竊賊、刺客、扒手和騙子等工作維生，因而人們對該職業的印象並不太好。這些無賴通常會組織起一些盜賊行會或犯罪家族。而獨立行動的遊蕩者也數量龐大，還偶爾會招募學徒一起進行誆騙和搶劫的行當。不過仍有少量的遊蕩者經營著老實的行當，如鎖匠，調查員或者滅鼠專家由於工作於常見到恐鼠（以及鼠人）的下水道而危險性頗高的職業。

成為冒險者的遊蕩者中，既有守法者也有違法者。他們有的是決定到藏寶室追尋財富的慣犯，另一些則投入冒險生活以逃避法律的制約。此外，有一些遊蕩者甚至會為進入某個特定遠古遺蹟或隱藏寶庫中尋寶，而進行針對性的研究和鍛鍊。

**創建遊蕩者 Creating a Rogue**

創建一個遊蕩者角色時，可以先考慮該角色與法律的關係。你有是有犯罪前科，或現在就是一名罪犯嗎？或者，你是逃離了法律制約，還是逃離了一名憤怒的盜賊行會會長？或者，你是不是為了尋求更大的冒險與財富而離開了行會？是貪婪驅使你前去冒險還是其他的想法？
是什麼機緣導致你離開了之前的生活？你是不是在某次大騙局或大劫案中犯下了嚴重的錯誤而使你不得不重新審視自己的事業？也許你的搶劫計劃僥倖成功，而你也帶著那足以擺脫貧困生活的錢財踏上旅途。是不是漫遊的慾望驅使你離家出遊？也許你忽然跟家族或導師隔絕了聯繫，而你決定去尋找新的生活支柱與意義。又或許你的新朋友某個冒險者團隊的成員讓你明白了自己的某項天賦可以讓你以另一種方式過活或受僱。

#### 快速建卡 Quick Build

你可以按以下建議快速創建一名遊蕩者。首先，你將最高屬性分配給敏捷。如果你想精於調查或者打算選擇詭術師範型，則將次高屬性分配給智力。如果你打算著重於騙術或者社交，則將次高屬性分配給魅力。然後，選擇騙子背景。

## 職業特性 Class Features

作為一名遊蕩者，你獲得以下職業特性。

後續升級生命值：第一級之後，每個遊蕩者等級5（1d8）＋你的體質調整值

**專精 Expertise**

第1級起，你選擇兩個已有技能熟練項，或者一個技能熟練項和盜賊工具熟練項。此後你進行該項目的檢定時，可以使用雙倍的熟練加值。
第6級時，你可以再選擇另外兩個已有的技能熟練項（或盜賊工具熟練項）從該特性中獲益。

**偷襲 Sneak Attack**

第1級起，你就知道如何精確地攻擊分心的敵人。每當你的攻擊命中一個生物時，如果該攻擊的攻擊檢定帶有優勢，則可以造成額外1d6的傷害。該傷害每回合可以產生一次，且造成傷害的攻擊必須使用帶靈巧屬性的武器或遠程武器。
如果目標生物身邊5尺內還有其他與之敵對的未失能生物，則只要你的攻擊檢定不具有劣勢，就可以發動偷襲。（但仍需要靈巧或遠程武器）
你的偷襲傷害也將會隨遊蕩者職業等級的提升而提高，其具體數值見“遊蕩者職業表”。

**盜賊黑話 Thieves’ Cant**

作為一名遊蕩者，你在平時的練習中學會了盜賊間的黑話。盜賊黑話是一門混合了土話、術語和密語的秘密語言，掌握這門語言後，你可以在平時對話中不落痕跡的加入隱藏信息。而只有另一個懂盜賊黑話的生物才能看懂這些隱藏信息。不過這種交流方式需要花費四倍於直接交流所需要的時間。
另外，你還習得一套用以傳達簡單短小信息的秘密符文和標識。它能發佈的內容諸如某地區是否危險，是否受盜賊公會管轄，附近是否有戰利品，附近的人是否好主顧或者路上是否有安全的房屋以供庇護。

**巧妙動作 Cunning Action**

第2級起，你精妙的反應與身手使你的行動無比迅速。你在戰鬥中每回合可執行一次附贈動作，撤離 Disengage、疾走 Dash 或躲藏 Hide 三種動作項其中之一。

**遊蕩者範型 Roguish Archtype**

第3級時，你選擇學習一種特定的戰鬥範型。你可以從盜賊 Thief、刺殺 Assassin 或者詭術師 Arcane Trickster 中選擇其一。隨後，你將在第3，第9，第13、第17級時獲得所選範型的相應特性。

**屬性值提升 Ability Score Improvement**

當你達到第4、第8、第10、第12、第16、第19級時，你可以選擇一項屬性值提升2點，或是選擇兩項屬性各提升1點。不過你不能通過該特性讓屬性值超過20。

**直覺閃避 Uncanny Dodge**

第5級起，當一個你能看見的敵人攻擊命中你時，你可以用反應讓此次攻擊的傷害減半。

**反射閃避 Evasion**

第7級起，你可以靈巧躲過某些特定的區域效應，比如紅龍的火焰吐息或是法術_冰風暴__Ice storm_。你在成為某一範圍效應影響對象時，若該效應允許你通過成功的敏捷豁免來使傷害減半，則你在該豁免成功時不受傷害，而豁免失敗時只受一半傷害。

**可靠才能 Reliable Talent**

第11級起，你自身技能經過精煉而更趨於完美。每當你進行的屬性檢定可以使用熟練加值時，你可以將 d20骰中9或以下的結果都視為10。

**聽聲辨位 Blindsense**

第14級起，只要能聽到聲音，你就可以定位身邊10尺內躲藏或隱形的生物。

**靈活心智 Slippery Mind**

第15級起，你的心理素質獲得了大大的加強，並因此獲得感知豁免的熟練項。

**捉摸不定 Elusive**

第18級起，你飄忽不定的身形讓敵人攻擊時無從下手。除非你處於失能狀態，否則以你為目標的攻擊檢定無法取得優勢。

**幸運一擊 Stroke of Luck**

第20級時，你掌握了一手非凡技巧，讓你可以隨時把握自己的成功之時。當你的攻擊未命中時，可以直接更改判定為命中。或者，當你的屬性檢定失敗時，可以直接將 d20骰的結果視為20。
你必須完成一次短休或長休後才能再次使用該特性。
