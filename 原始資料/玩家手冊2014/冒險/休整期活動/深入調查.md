# 深入調查

**深入調查 Researching**

休整是進行調查的好時機，讓你有機會對戰役中發掘到的秘聞進行深入的調查研究。調查活動可以是在圖書館中翻閱封塵破爛的古書卷冊，或是請當地人喝酒套話。
進行調查活動時，由 DM 來決定所調查的目標信息是否存在，需要花費多少日來發掘，以及是否有其他限制（例如，必須找到特定的人，書卷，或地點）。DM 也可能要求你進行一次或多次屬性檢定，比如，進行智力（調查）檢定以找出蛛絲馬跡，或者進行魅力（遊說）檢定以獲得某人出力相助。當你達成所有條件後，就會獲得所尋找的信息（假如存在的話）。
每完成一日調查活動，需要花費1 gp 的開銷。而這部分花費不包括在生活方式的開支中。（見第5章的文本）
