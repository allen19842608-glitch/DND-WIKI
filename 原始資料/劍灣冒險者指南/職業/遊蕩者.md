# 遊蕩者

**遊蕩者 Rogues**

有些人的能力不在於劍或巫藝，而在於安靜的行動、靈巧的動作和隱匿。這樣的人才在大城市裡徘徊時總會從事一些非法活動，但其天賦卻能很好的用於對付危險的怪物和失落的寶藏。
國度的許多大型城市中有藏著無數互相競爭的竊賊窩點。一些地方，比如博德之門 Baldur's Gate 就有由遊蕩者控制其所有活動的組織。大多數竊賊的窩點都是秘密的聚會地點，它們通常設置在城市地底，而且一旦被發現就會迅速搬走。
深水城曾一度作為北地最大盜賊行會——影賊 Shadow Thieves 的老家。深水城諸領主擊垮行會之後，其領導人被迫逃離城市（該組織仍在安姆運作）。現在的深水城裡仍存在著竊賊乃至刺客，只是它們現在都是以小團體活動或是單獨個體活動的狀態。
這些搶劫者將自己的冒險活動當普通的假期，並美其名曰誠信買賣 Honest Trade，遊蕩者們在此時可以不受譴責的發揮自己的能力，並在歌曲與傳說中被人接受。許多竊賊都經營著這樣的生活，他們遵守的一套規矩可以讓自己擺脫文明地區的麻煩卻又能令自己維持富足——其實那就是聲稱自己的財富是來自洗劫古老陵墓與怪物巢穴，而不是來自文明地區富人們的宅邸與生意場。
一些遊蕩者認識到當自己帶著一份王室文書時，可以更輕鬆的扒走別人的錢袋，因此許多遊蕩者其實是外交官、朝臣、有影響力的商販和情報中介，而不僅僅是那些盛名在外的竊賊和刺客。這樣的遊蕩者會更容易融入文明社會，他們大多是充當社會機器輪軸上的潤滑劑，而不是工作的扳手。
