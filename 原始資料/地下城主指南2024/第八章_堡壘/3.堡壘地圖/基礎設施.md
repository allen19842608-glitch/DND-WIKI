# 基礎設施

**基礎設施 Basic Facilities**

角色的堡壘最初擁有兩個免費的基礎設施，由該角色的玩家在**基礎設施 Basic Facilities**表格中選定。所選的兩個設施中，一個設施的空間為狹窄，另一個則為寬敞（見**設施空間**表格）。堡壘可以擁有多個同種的基礎設施。

**基礎設施 Basic Facilities**

-   臥室
    
-   餐廳
    
-   客廳
    
-   庭院
    
-   廚房
    
-   儲藏室
    

每個基礎設施都配有非魔法的傢俱以及與該設施相配的裝飾。

基礎設施並沒有任何遊戲性上的作用，但它們可以提供角色扮演的機會，也能增強堡壘的真實性。一個擁有廚房的堡壘和沒有廚房的堡壘運作方式並不會有任何差別，但前者給你和玩家們提供了一個有趣的新地點，可以作為一次團的起始場景，用作角色之間討論的場所，或者用於引入新的非玩家角色 NPC。

角色可以花費金錢和時間來增添新的基礎設施或擴大已有的基礎設施，如下文所述。多個基礎設施的增添與擴大工作可同時進行，而在此期間角色無需待在自己的堡壘內。

### 增添基礎設施 Adding Basic Facilities

角色可以花費金錢和時間以在自己的堡壘內增添新的基礎設施。增添基礎設施所需的時間和金錢基於其空間大小，如以下表格所示。

**增添基礎設施 Adding Basic Facilities**

| **設施空間** | **價格** | **所需時間** |
| --- | --- | --- |
| 狹窄 | 500GP | 20天 |
| 寬敞 | 1000GP | 45天 |
| 龐大 | 3000GP | 125天 |

### 擴大基礎設施 Enlarge Basic Facilities

擴大一個基礎設施並無任何遊戲性上的作用，但角色可能會為了美觀或想要擴大堡壘規模而擴大基礎設施。

角色可以花費金錢和時間來將自己堡壘內的某個基礎設施擴大一級，如以下表格所示。

**擴大基礎設施 Adding Basic Facilities**

| **設施空間** | **價格** | **所需時間** |
| --- | --- | --- |
| 狹窄到寬敞 | 500GP | 25天 |
| 寬敞到龐大 | 2000GP | 80天 |
