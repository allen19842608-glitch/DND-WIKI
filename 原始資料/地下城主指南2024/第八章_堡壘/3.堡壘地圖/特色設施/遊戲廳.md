# 遊戲廳

**遊戲廳 Gaming Hall**
**_9級堡壘設施_**

**先決**：無
**空間** ：龐大
**僱員**：4
**指令**：貿易

遊戲廳提供娛樂活動，例如象棋、飛鏢、卡牌或骰子。

**貿易：賭場 Gambling Hall** ：當你對此設施下達貿易指令時，設施僱員將遊戲廳變為一個賭場，持續 7 天時間。在第七天結束時，擲 d100 並根據下列表格來決定你作為莊家賺了多少錢。

| **d100骰點** | **贏得的錢** |
| --- | --- |
| 01-50 | 1d6\*10GP |
| 50-85 | 2d6\*10GP |
| 86-95 | 4d6\*10GP |
| 96-100 | 10d6\*10GP |
