# 神器

###### 崇善之書 Book of Exalted Deeds

_奇物，神器（需同調）_
_崇善之書是對多元宇宙中一切善行的權威論述，在多個宗教中都有著重要地位。這本書並非是針對特定信仰的聖經典籍，為其編作的作者在書頁之間留下了他們對真實美德的看法，幫助指引眾生擊退邪惡。_
崇善之書很少在某地長留。它會在被閱讀完畢時自行消失，並在多元宇宙的另一角落重現，然後為瀕臨滅絕的世界帶來道德的希望與明燈。曾經有人嘗試複製這本鉅著，但都無法成功捕捉到其魔法本質，也無法傳達其對具有純粹心靈和堅定信念者的神奇增益。
一把天使之翼樣式的堅固鎖釦守護著聖書的內頁。只有與聖書成功同調的生物才能將其打開。一旦開啟聖書，與之同調的生物必須花費80小時對其閱讀研究，以理解其內容並從中獲得增益。
其他生物也可以閱讀書頁內的文字，只是無法得知其深層的含義，也無法從中獲得增益。試圖閱讀聖書的邪魔、亡靈或下層位面神明的侍從將受到24d6點光耀傷害，該傷害無視抗性和免疫，並且無法以任何方式減免。因此傷害生命值降至0的生物，將瞬間消失並被摧毀，只留下其所有物，然後書本消失，生物與其的同調結束。
崇善之書的增益只會在你努力行善時持續。若你在10日內沒有做出任何善舉或慷慨的行為，又或者你主動實行一項邪惡行為，你將失去聖書所提供的所有增益。
**天堂之謐 Celestial Clam**。與此書保持同調期間，你具有心靈傷害抗性與對**魅惑**和**恐慌**狀態的免疫。在你花費足夠的時間閱讀研究此書後，該增益將變為永久生效。
**神聖感知 Divine Wisdom**。在你花費足夠的時間閱讀研究此書後，你的感知提升2，至多提升至24。
**魔法啟迪 Enlightened Magic**。在你花費足夠的時間閱讀研究此書後，你用以施展法術而消耗的法術位均視為高一環的法術位。
**神光 Halo**。在你花費足夠的時間閱讀研究此書後，你獲得護體神光，該神光發出半徑10尺的明亮光照以及額外10尺的微光光照，你能夠以一個**附贈動作**令神光解除或顯現。神光顯現期間，其令你的魅力（遊說）檢定具有優勢。此外，神光的明亮光照範圍內的邪魔與亡靈對你的攻擊檢定具有劣勢。
**隨機詞條 Radom Properties**。崇善之書具有下列隨機詞條（見本章“神器”）：

-   2項次要增益詞條
    
-   2項主要增益詞條
    

**摧毀聖書 Destroying the Book**。崇善之書無法被摧毀。然而，將聖書浸入冥河後，其內文字和圖像將會消失殆盡，且在1d100年裡失去其力量。

###### 穢惡之書 Book of Vile Darkness

_奇物，神器（需同調）_
這本骯髒的手稿的內容被受惡人視為美酒佳餚。其記載的內容如此可怕，以至於簡單一瞥那潦草的書頁也會招致厄運。
很多人認為穢惡之書出自巫妖神維克那的手筆。他在該書中記錄了自己每種病態的主張，每種的腐敗的想法以及每個他經歷或計劃的邪惡魔法。
其他邪惡踐行者也為這本邪穢知識大全添加了自己的內容。這些後續作者添加的內容顯而易見，他們將自己書寫的內容縫入這本鉅著中，又或者直接在已有的內容上進行註解或續寫。有的書頁缺失、撕毀，或是被墨跡、血跡或劃痕完全覆蓋導致無法分辨其原文。
自然界無法容忍該書的存在。普通植物在該書面前將枯萎，普通動物也不願意靠它太近。該書會漸漸破壞任何其觸碰之物，連與該書接觸過久的石頭也會逐漸化作粉末。
每當一名非邪魔非亡靈的生物與穢惡之書同調時，該生物進行一次 DC17的魅力豁免，失敗則被魔法轉化為一隻由 DM 操控的**幼蟲魔 Larva**。只有_祈願術 Wish_才能逆轉這種邪惡的轉變。
與此書同調的生物必須花費80小時對其閱讀研究，以消化其內容並使用其修改屬性值、無休形態、法術、穢惡學識、穢惡靈言詞條。
穢惡之書的只會在你盡心作惡時留在你的身邊。若你在10日內沒有做出至少一項惡行，又或者你主動完成一項善舉，穢惡之書就會消失，你與其的同調立即結束，你將失去此書所提供的所有增益。若你在與此書保持同調期間死亡，一個邪惡實體將奪走你的靈魂，你的靈魂被囚禁期間，你無法以任何方式復活。
**修改屬性值 Adjusted Ability Scores**。你選擇的一項屬性提升2，至多提升至24；同時你選擇的另一項屬性降低2，至多降低至3。然後此書無法再次修改你的屬性值。
**無休形態 Tireless Form**。只要此書在你身上，你就對**力竭**狀態具有免疫。
**隨機詞條 Radom Properties**。穢惡之書具有下列隨機詞條（見本章“神器”）：

-   3項次要增益詞條
    
-   1項主要增益詞條
    
-   3項次要減益詞條
    
-   2項主要減益詞條
    

**法術 Spells**。持握此書並持握其期間（譯註：原文如此），你可以從書中施展以下法術（豁免 DC18）：

-   _活化死屍 Animate Dead_
    
-   _死亡法陣 Circle of Death_
    
-   _支配怪物 Dominate Monster_
    
-   _死亡一指 Finger of Death_
    

一旦你使用此書施展了某道法術，直至下個黎明前你都無法再次從中施展那道法術。
**穢惡學識 Vile Lore**。每當你進行智力檢定以回憶有關邪惡事物的信息（例如有關惡魔的傳說）時，你可以參考穢惡之書。若如此做，你在檢定上具有優勢。
DM 可以酌情決定，令此書揭露一些凡人不該知曉的秘辛，如強大邪魔的真名、轉化死亡騎士或巫妖的秘儀或惡至不可呼名者撰寫的失落法術。
**穢惡靈言 Vile Speech**。只要此書在你身上，你就能夠以**魔法**動作，以汙穢的死語唸誦書頁上的咒文。每當你如此做時，你受到1d12心靈傷害，且每名位於你15尺內的非邪魔非亡靈生物均受到3d6心靈傷害。
**摧毀邪書 Destroying the Book**。穢惡之書的書頁可以被撕下，但這些頁面上的邪惡學識最終都會回到書中——通常是在新的作者向其中添加頁面時。
如果一名**熾天神使 Solar**將此書撕成兩半，此書將被摧毀1d100年，之後它將在多元宇宙的某個遙遠角落重新生成。
一名與此書維持同調100年的生物可以發現隱藏在書中的密文。將其翻譯成天界語並大聲朗誦時，唸誦者與此書都將被一道光芒摧毀。然而，只要邪惡還存於多元宇宙之間，這本書就會在1d10×100年後重新生成。

###### 伊格薇爾伏惡魔志 Demonomicon of Iggwilv

_奇物，神器（需同調）_
這篇記錄著深淵之無限層級及其居民的論文，由**伊格薇爾伏**撰寫，被公認為是多元宇宙中最詳細且最褻瀆的惡魔學著作。這本書記載了關於深淵與惡魔的所有褻瀆事項，無論其有多古遠或者多時新。惡魔們曾試圖刪減過其中的文本，雖部分內容已從書脊上撕下，但大部分篇章仍存，並不斷揭示著惡魔的秘密。這本書隱藏著一塊神秘的深淵位面碎片，使得此書無論被撕掉多少頁，也會時刻保持更新，這本書也不僅僅只是滿足於成為一本參考材料。
**深淵學識 Abyssal Lore**。每當你進行智力檢定以辨別有關惡魔的信息或進行與深淵相關的感知（求生）檢定時，你都可以參考惡魔志。若如此做，你在檢定上具有優勢。
**封印 Containment**。惡魔志的前十頁是空白的，持握此書期間，你能夠以**魔法**動作指定一名你可見的被困在防護法陣中的邪魔，其必須成功通過一次 DC20的魅力豁免，否則將被困在惡魔志的一張空白頁中，空白頁上將寫滿有關被困生物廣為人知的名字與其墮落事蹟的文字。此動作一經使用，直至下個黎明你都無法再次使用。
當你完成一次長休時，若你與惡魔志存在於同一位面，則書中所困的生物可以嘗試附身你，你進行一次 DC20的魅力豁免，豁免失敗則被該生物附身，其將如操控傀儡一般操控你。附身生物能夠以一個**魔法**動作釋放你並顯現在離你最近的未佔據空間中。豁免成功，則該邪魔在之後七天內無法再次嘗試附身你（但另一名被困於書中的邪魔仍可嘗試附身）。
當此書被發現時，已記錄有1d4名邪魔——通常是各種種類的惡魔。
**迷惑 Ensnarement**。攜帶此書期間，每當你施展只針對邪魔的_防護法陣 Magic Circle_或對邪魔施展_異界誓縛 Planar Binding_ 時，無論你使用什麼環階的法術位（若有），該法術都將以九環版本施展。此外，邪魔在對抗這些法術的豁免檢定中具有劣勢。
**鞭笞邪魔 Fiendish Scourging**。攜帶此書期間，你施展的法術對邪魔進行傷害擲骰時，你取可能的最大值，無需擲骰。
**隨機詞條 Random Properties**。惡魔志具有下列隨機詞條（見本章“神器”）：

-   2項次要增益詞條
    
-   1項次要減益詞條
    
-   1項主要減益詞條
    

**法術 Spells**。此書具有8充能，並在每日黎明時重獲1d8已消耗的充能。持握此書期間，你能夠以**魔法**動作從中施展下列法術之一（豁免 DC20）。表中表明瞭你施展對應的法術需要消耗多少充能。

| **法術** | **充能消耗** |
| --- | --- |
| _塔莎狂笑術 Tasha's Hideous Laughter_ | 0 |
| _防護法陣 Magic Circle_ | 1 |
| _異界誓縛 Planar Binding_ | 2 |
| _魔魂壺 Magic Jar_ | 3 |
| _異界誓盟 Planar Ally_ | 3 |
| _位面轉移 Plane Shift_ （僅限至無底深淵） | 3 |
| _邪魔召喚術 Summon Fiend_ | 3 |

**摧毀惡魔志 Destroying the Demonomicon**。要摧毀這本書，必須有六位不同的惡魔領主分別撕下書內六分之一的頁數。書頁被撕下後會在24小時內恢復。而在所有書頁被撕下與恢復之前，任何打開剩餘裝訂部分的人都會被傳送到一處隱藏在書中的新生深淵層級。這處領域具有一定自我意識且十分危險，中心處有一件遺失許久的神器，**弗拉茲-厄魯之杖 Fraz-Urb'luu's Staff** 。如果法杖被帶離這處口袋位面，魔典會立刻變成一本《反序古典 Tome of Zyx》普通而過時的抄本，這本書是創造惡魔志的基底。法杖一旦出現，惡魔領主弗拉茲-厄魯會立刻知曉。

###### 龍珠 Orb of Dragonkind

_奇物，神器（需同調）_
很久以前，在龍槍的設定中，精靈與人類對色彩巨龍發動了一場慘烈的戰爭。在最後世界接近崩潰之際，大法師諸塔的法師們齊聚一堂，鑄造了五顆龍珠來幫助擊敗巨龍。五顆龍珠分給了五座法師塔，他們憑藉龍珠的力量克敵制勝。法師們用龍珠引誘龍族，然後以強大的法術轟殺之。
隨著大法師諸塔在後來的年代中倒塌，其持有的五顆龍珠也相繼被摧毀或遺失在傳說之中。相傳仍然有三顆保存完好的龍珠流傳在世。雖然它們的魔法在幾個世紀中被扭曲變換，但其呼喚巨龍的原始功能卻依然健全，還能在一定程度上控制龍族。
每顆龍珠內都包含著一條邪惡巨龍的精神，對任何嘗試從中引出魔法的企圖懷有憤恨。那些試圖使用龍珠但意志不堅定的人有時會發現自身實為被龍珠所蠱惑。
龍珠是一枚直徑約10寸的蝕刻水晶球。使用時，其直徑增長至20寸，並且在內部縈繞著迷霧。
與龍珠維持同調期間，你能夠以**魔法**動作窺視龍珠深處。然後你必須進行一次 DC 15的魅力豁免。若豁免成功，你將可以控制龍珠直至同調中斷。若豁免失敗，你將被龍珠**魅惑** 直至同調中斷。
被龍珠魅惑期間，你不能自行中斷同調，而龍珠可以對你隨意施展_暗示術 Suggestion_（豁免 DC 18），並蠱惑你助推其邪惡目標。龍珠裡的巨龍精神有著各種需求：殲滅某個特定社團或組織；從龍珠中解放；四處折磨世人；傳播提亞馬特信仰，或是由 DM 決定的其他事情。
**隨機詞條 Random Properties** 。龍珠具有下列隨機詞條（見本章“神器”）：

-   2項次要增益詞條
    
-   1項次要減益詞條
    
-   1項主要減益詞條
    

**法術 Spells**。龍珠具有7充能，並在每日黎明時重獲1d4+3已消耗的充能。你能以龍珠施展下表中的法術（豁免 DC18）。表中表明瞭你施展對應的法術需要消耗多少充能。

| **法術** | **充能消耗** |
| --- | --- |
| _偵測魔法 Detect Magic_ | 0 |
| _晝明術 Daylight_ | 1 |
| _防死結界 Death Ward_ | 2 |
| _探知術 Scrying_（豁免 DC18） | 3 |
| _療傷術 Cure Wounds_ （9環版本） | 4 |

**呼喚巨龍 Call Dragons** 。控制龍珠期間，你能夠以**魔法**動作 令龍珠發出心靈感應呼喚，此呼喚向所有方向延伸40英里。範圍內的色彩龍族將被迫以最直接的路線儘可能快的來到龍珠處。龍族神祇（如提亞馬特）不受此呼喚影響。被龍珠喚來的色彩龍族可能因其非自願的到來與你敵對。該詞條一經使用，一小時內你都無法再次使用。
**摧毀龍珠 Destroying an Orb** 。龍珠的 AC 為20，當其受到+3魔法武器或法術_解離術_ 的傷害時，龍珠被摧毀。其餘任何事物都無法摧毀龍珠。
