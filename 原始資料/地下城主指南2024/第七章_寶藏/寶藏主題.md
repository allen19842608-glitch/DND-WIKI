# 寶藏主題

**寶藏主題 Treasure Themes**

正如《怪物圖鑑》中所述，怪物們有著屬於自己的寶藏偏好。這些偏好將會表現為“主題”，如寶藏主題表中所總結的那樣，這可以幫助你決定角色們在怪物的寶庫中找到了怎樣的寶藏。
有關如何在冒險中安放寶藏的建議，見第四章“**冒險獎勵**”。
如果要隨機決定作為寶藏發現的魔法物品，請使用本章末尾的表格。
**寶藏主題表**

| **主題** | **對應寶藏** |
| --- | --- |
| 奧秘 | 寶石以及超自然或充盈魔能的魔法物品 |
| 武備 | 錢幣或貿易金條以及在戰中很有用的魔法物品 |
| 器具 | 錢幣、貿易金屬條或商業貨物以及側重於實用性的魔法物品 |
| 聖物 | 藝術品以及具有宗教起源或歸宿的魔法物品 |
