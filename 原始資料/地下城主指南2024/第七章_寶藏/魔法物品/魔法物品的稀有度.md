# 魔法物品的稀有度

**魔法物品的稀有度 Magic Item Rarity**

每件魔法物品都具有一項稀有度，用以大致衡量某件物品與其他魔法物品相比所擁有的力量。其稀有度如**魔法物品稀有度與價格**表所示。
稀有度為普通的魔法物品，比如**治療藥水_Potion of Healing_**，數量最多。而神器，比如**奧喀斯之杖_Wand of Orcus_**，則是獨一無二的無價之寶，極難獲得。

### 魔法物品根據稀有度的定價 Magic Item Values by Rarity

稀有度為普通的魔法物品往往可以在小鎮或城市中買到。非普通與珍稀的魔法物品則通常只能在城市中找到。而更珍稀的魔法物品則只在某些特殊地點有售，比如黃銅之城或印記城。若你允許角色在你的戰役中買賣魔法物品，則稀有度可以幫助你為這些物品訂立價格。**魔法物品稀有度與價格**表中提供的價格以 GP 為單位，但賣家也可能會要求以某項服務而非錢幣來支付。
若一件魔法物品內含某件在玩家手冊中所列出且擁有購買價格的物品（例如一把武器或一套護甲），則將該物品的價格與該魔法物品的價格相加。例如， **+1護甲**（板甲）的價格為5500gp，即一件珍稀魔法物品的價格（4000gp）與一件板甲的價格（1500gp）之和。
**魔法物品稀有度與價格 Magic Item Rarities and Values**

| **稀有度** | **價格\*** |
| --- | --- |
| 普通 | 100gp |
| 非普通 | 400gp |
| 珍稀 | 4000gp |
| 極珍稀 | 40000gp |
| 傳說 | 200000gp |
| 神器 | 無價之寶 |

\*除**法術卷軸_Spell scroll_**外，所有消耗品的價格減半。一張法術卷軸的價格為該卷軸抄寫時所需成本（在玩家手冊中已標明）的兩倍。
